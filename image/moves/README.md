# 技イラストのゲーム配置用フォルダ

ここにあるWebPは、すべて**未配置を示すプレースホルダー**である。完成したレスラー技絵ではない。

## フォルダ構成

技ごとのサブフォルダは作らない。すべてのファイルをこの `moves` フォルダ直下に並べ、各技は次の3ファイルで識別する。

| ファイル | 役割 |
|---|---|
| `NN_slug_attacker.webp` | 攻め側。ゲーム側で攻め手の色を付ける。 |
| `NN_slug_defender.webp` | 受け側。ゲーム側で受け手の色を付ける。 |
| `NN_slug_overlay.webp` | 黒い輪郭・影など、両者の上に重ねる要素。 |

全カードは512×512 WebPで、画像内に `PLACEHOLDER`、優先度、担当レイヤー、技名を明記している。実技絵と見誤らないことを優先しており、最終素材と同じ透明仕様にはしていない。

## 収録範囲

- P0: ゲームで大技として扱う全技（`styleMoves` の威力 `d >= 11`）
- P1: 先行して作った基本30技
- P2: 小技は意図的に未作成。大技のカバーを優先する。

大技の正規名・スタイル・共用可否・制作順は、[大技カバレッジ計画](../../docs/move-illustration-coverage-plan-v0.1.md)を正本とする。

## 置換手順

1. ユーザー作成のポーズ・カメラ参照を受け取る。
2. 1024pxの `raw.png` と透過 `master.png` を制作元 `assets/moves` に保存する。
3. 人物を attacker / defender / overlay に分ける。
4. このフォルダ直下の同じ技番号・slugを持つ3ファイルを、512pxの最終WebPに置き換える。
5. プレビューカードが残っていなければ、その技はゲーム配置済みと判断できる。

以前の30枚の合成プレビューは、削除せず [assets/moves/provisional-512-webp](../../assets/moves/provisional-512-webp) に退避している。

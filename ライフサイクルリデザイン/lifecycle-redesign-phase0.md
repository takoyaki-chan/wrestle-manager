## 2. 現行の年齢カーブ

### 2.1 選手の初期年齢

| 所属 | 年齢範囲 | 備考 |
|------|----------|------|
| AI団体 (S/A/B) | 15〜33歳 | `15 + rng(0,18)` |
| ドラフト候補 | 16〜19歳 | `16 + rng(0,3)` |
| FA（既存プール） | 18〜24歳 | `18 + rng(0,6)`（新規参入）|
| FA（復帰組） | 保存された年齢をそのまま使用 | |
| スカウト候補 | 15〜22歳 | 分布: 15-16(40%), 17(25%), 18-19(20%), 20-22(15%) |
| 緊急補充 | 18〜20歳 | `18 + rng(0,2)` |

### 2.2 成長倍率 `ageMultiplier(age)`

| 年齢帯 | 倍率 | 意味 |
|--------|------|------|
| ≤17歳 | 0.8 | 新人: 体がまだできていない |
| 18〜19歳 | 1.1 | 急成長期の入口 |
| 20〜22歳 | **1.3** | **黄金の成長期** |
| 23〜25歳 | 1.0 | 安定成長 |
| 26〜28歳 | 0.6 | 仕上げ段階 |
| 29〜30歳 | 0.15 | ほぼ停止 |
| 31〜32歳 | 0.05 | 微成長 |
| 33歳以上 | **0** | **成長なし** |

#### 特性による修正

| 特性 | 効果 |
|------|------|
| 早熟 | ≤21歳: ×1.3 / ≥26歳: ×0.7 |
| 晩成 | ≤21歳: ×0.8 / 26〜32歳: ×1.4 |
| 遅咲き | ≤25歳: ×0.8 / 26〜34歳: mul = max(mul, 0.9) |

### 2.3 成長量の計算

- **GROWTH_SEASON_BASE = 8.0**（1シーズンの成長予算、4ステ合計、ageMul=1.0時）
- 練習:試合の予算配分 = 6:4（practiceShare = 0.6）
- 1練習あたり: `seasonBudget × 0.6 × share / 9週`
- 試合1回あたりの基本成長: 0.35
- trainCapの上位15%で減速開始（convergenceRatio = 0.15）

### 2.4 成長のピーク年齢と典型的なキャリア

**典型パターン（通常特性の選手）**:
- 16歳入団 → 20〜22歳が最も成長（ageMul 1.3）
- 23〜25歳で安定成長（ageMul 1.0）
- 26歳以降は成長鈍化（ageMul 0.6）
- 29歳以降はほぼ成長停止

## 3. 衰退・引退システム（wear ベース）

### 3.1 wear（累積摩耗）蓄積

- **蓄積開始年齢**: `28 + durability`（durability: N(0,2)で-4〜+4）
  - 最速24歳、標準28歳、最遅32歳
- **年間の基本蓄積**: 10 ± 3（7〜13）
- ボーナス加算:
  - 年間平均試合数 ≥ 40: +3
  - シーズン中の怪我回数 × 2
  - 強化練習12週以上: +2
  - durability による軽減（マイナス補正）
- 最終値: `max(1, baseWear + wearBonus)`

### 3.2 wearによる効果

| wear帯 | ラベル | 衰退量/stat | 引退確率 |
|---------|--------|------------|----------|
| 0〜19 | （全盛期） | なし | 0% |
| 20〜39 | ⚠ 衰え | 1〜2 | 0% |
| 40〜59 | ⬇ 衰退期 | 2〜4 | **20%** |
| 60〜79 | ⬇⬇ 限界 | 3〜5 | **50%** |
| 80以上 | — | — | **確定引退** |

### 3.3 年齢ベースの衰退（DECAY_TABLE）

| 年齢帯 | 衰退発生確率 (pw/sp/te/st) | 衰退量 |
|--------|---------------------------|--------|
| 30〜32歳 | 20%/25%/10%/15% | 各1 |
| 33〜34歳 | 40%/50%/20%/35% | 各2 |
| 35歳以上 | **100%/100%/100%/100%** | pw3/sp3/te2/st3 (+ mn 5%で1) |

### 3.4 年齢ベースの引退確率（RETIRE_CFG）

| 年齢 | 引退確率 |
|------|----------|
| 35歳 | 30% |
| 36歳 | 50% |
| 37歳 | 75% |
| 38歳 | 90% |
| 39歳以上 | 確定 |

- voluntaryThreshold: OVR < Notion × 0.60 が2シーズン連続 → 自主引退
- decayFloor: Notion × 0.70 を下限として衰退

### 3.5 backstory における peakAge

- 経歴自動生成時の peakAge = `26 + rng(0,4)` → 26〜30歳

### 3.6 引退勧告（プレイヤーアクション）

- 発動条件: `age >= 30` **または** `wear >= 20`
- 受諾率計算に wear が大きく影響:
  - wear 60+: +40%, wear 40+: +25%, wear 20+: +10%

## 4. 引退までの典型的なタイムライン

### ケース A: 標準的な選手（durability 0）

```
16歳: 入団（シーズン1）
20-22歳: 黄金の成長期（ageMul 1.3）
23-25歳: 安定成長（ageMul 1.0）
26-28歳: 成長鈍化（ageMul 0.6）
28歳: wear蓄積開始（年10前後） ← シーズン13
29-30歳: 成長ほぼ停止（ageMul 0.15）
31歳: wear ~20（軽度衰退開始） ← シーズン16
33歳: wear ~40（本格衰退、引退確率20%）← シーズン18
35歳: wear ~60+（限界、引退確率50%）+ 年齢ベース引退30% ← シーズン20
36-38歳: 高確率で引退
```

**入団〜引退: 約17〜22シーズン**

### ケース B: 耐久型（durability +4）

```
32歳: wear蓄積開始（4年遅延）
36-38歳: ようやく本格衰退
```

**入団〜引退: 約20〜24シーズン**

### ケース C: ガラスの身体型（durability -4）

```
24歳: wear蓄積開始（4年前倒し）
30歳頃: 本格衰退
```

**入団〜引退: 約14〜18シーズン**

### 結論

**→ 9〜10シーズンでクリアに到達する場合、ほぼすべての初期メンバーが現役中。世代交代は発生しない。**

| イベント | 現行条件 | 年齢への依存 |

### 5.2 ライバリーシステム

| レベル | 必要試合数 | MQボーナス |

### 5.3 契約更新

- シーズン開幕前のオフシーズン第4週に実施
- trust ベース（低trust選手との交渉イベント）
- 年齢は直接参照していないが、衰退→パフォーマンス低下→trust低下の間接影響あり

### 5.4 スカウト・FA

| 項目 | 現行値 |
|------|--------|
| スカウト候補年齢 | 15〜22歳（分布偏り） |
| FA年齢上限 | 20歳超えで自動引退（プロ入り断念） |
| 緊急補充年齢 | 18〜20歳 |
| ドラフト年齢 | 16〜19歳 |

### 5.5 経済バランス

- GROWTH_SEASON_BASE = 8.0 は48週ベースで設計
- 選手の育成投資回収期間は現行の長いキャリアを前提
- 30歳・35歳時点でassessedValue再評価（reassess）

### 5.6 AI団体

- AI団体選手の加齢: シーズン末に `age += 1`
- AI団体のwear蓄積: `baseWear(年齢帯依存) - durability`
- AI引退判定: `checkRetirement(rng, fighter)` — wearベース（プレイヤーと同一ロジック）

### 5.7 引退セレモニー・ラストラン

- ラストラン: 引退勧告受諾後4週間の猶予期間
- 引退試合ボーナス: 因縁相手との試合で外部MQ+3〜5
- 引退セリフ: `age ≤ 25` / `≤ 30` / `> 30` で分岐

## 6. 「48 = 1年」の前提がハードコードされている箇所

- `engine.js:910` — 絶対週数計算: `(season - 1) * 48 + week`
- `engine.js:6103` — `if (s.week > 48)` シーズン末判定
- `engine.js:8954` — バリデーション: `week < 1 || week > 48`
- 季節表記: 春/夏/秋/冬 × 12週 = 48

→ 今回のスコープ（ターン数は変えず加齢カーブのみ変更）では**これらは変更不要**。

## 8. 現状の問題点まとめ

1. **選手のキャリアが長すぎる**: 標準的な選手で入団〜引退が17〜22シーズン
2. **衰退開始が遅い**: wear蓄積開始が28歳（14年目以降）、本格衰退は33歳前後
3. **9〜10シーズンでクリア可能**: 初期メンバーが全員現役のままクリアに到達
4. **世代交代が発生しない**: 上記の結果、ロスター入れ替えの戦略的判断が不要
5. **選手の「物語」が完結しない**: 上り坂→ピークだけで終わり、衰退→引退→次世代が体験できない

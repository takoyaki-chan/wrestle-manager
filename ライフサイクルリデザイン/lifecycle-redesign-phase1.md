## 3. Wear蓄積開始年齢

**新**: `23 + durability`（平均23歳）
**旧**: `28 + durability`（平均28歳）

durability範囲(-4〜+4)による実効範囲:
- 脆い選手(dur=-4): **19歳**から蓄積 → 超早熟型
- 平均(dur=0): **23歳**から蓄積
- 頑丈(dur=+4): **27歳**から蓄積 → ベテランとして長く活躍

### スカウト候補の年齢分布（新）

```
40%: 16-17歳（原石・育成枠）

15%: 20歳（完成度高め、伸びしろ少ない）
```

旧: 15-16(40%) / 17(25%) / 18-19(20%) / 20-22(15%)
→ 全体を+1年シフト、上限を20歳に短縮

### FA pool除外年齢

**新**: **≥ 21歳** で dormantPool から除外
**旧**: ≥ 22歳

## 5. AI団体の年齢分布設計

AI団体は `17 + rng(0,11)` で **17-28歳** の幅を持たせる。

ゲーム開始時のAI団体に以下が混在するイメージ:
- **17-19歳**: 若手・育成中（ピーク前）
- **20-22歳**: 全盛期のエース格
- **23-25歳**: 衰退が始まった中堅
- **26-28歳**: 引退間近のベテラン（wear蓄積済み、衰退中）

→ プレイヤーが「S級のエースが数シーズンで引退する」のを目撃でき、世界観の説得力が増す。
→ AI団体も世代交代を経験するため、ランキングの変動が生まれやすくなる。

## 7. 新ライフサイクル（最終版）

17歳入団・durability=0の標準的な選手:

| S | 年齢 | ageMul | Wear累計 | 状態 |
|---|------|--------|---------|------|
| S1 | 17→18 | 0.70→1.00 | 0 | 新人・成長開始 |
| S2 | 18→19 | 1.00→1.30 | 0 | 成長加速 |
| S3 | 19→20 | **1.30** | 0 | **黄金期** |
| S4 | 20→21 | 1.30→1.00 | 0 | 安定成長 |
| S5 | 21→22 | 1.00 | 0 | 安定成長 |
| S6 | 22→23 | 1.00→0.50 | 0→~10 | **Wear蓄積開始・成長鈍化** |
| S7 | 23→24 | 0.50 | ~20 | **衰え開始（⚠）** |
| S8 | 24→25 | 0.50→0.10 | ~30 | 成長ほぼ停止・衰退進行 |
| S9 | 25→26 | 0.10 | ~40 | **本格衰退・引退圏（⬇）** |
| S10 | 26→27 | 0.10→0 | 50+ | 引退目前 |
| S11 | 27→28 | 0 | 60+ | **限界（⬇⬇）** |

### 特性による分岐例

**早熟選手（早熟特性 + durability=-2）**:
- S2(18歳)で ageMul 1.30×1.3 = **1.69** → 爆発的成長
- S5(21歳)で Wear蓄積開始（23-2=21）
- S7(23歳)で ageMul 0.50×0.7 = 0.35 + Wear 20+ → 急速に衰退
- **キャリア実質6シーズン**。短く太い。

**晩成選手（晩成特性 + durability=+2）**:
- S2(18歳)で ageMul 1.00×0.8 = 0.80 → 成長遅い
- S5(21歳)で ageMul 1.00×1.4 = **1.40** → ここからが本番
- S8(24歳)で ageMul 0.50×1.4 = 0.70 → まだ成長できる
- Wear蓄積は25歳(S8)から → 衰退開始はS10(27歳)
- **キャリア実質10+シーズン**。後半型の大器。

**遅咲き選手（遅咲き特性）**:
- S4(20歳)まで ageMul×0.8 → 序盤は伸び悩み
- S5(21歳)から max(mul, 0.9) → 安定して成長し続ける
- S12(29歳)まで成長可能 → **超ロングキャリア**

→ 特性によるキャリア差が現行より**劇的に広がる**。
→ 「早熟を即戦力で使い倒す」「晩成を我慢して育てる」「遅咲きをロングスパンで活用する」という戦略の幅。

## 8. 変更しないもの

以下は現行のまま据え置き:

- **GROWTH_SEASON_BASE**: 8.0（到達OVRは十分達成可能と判断）
- **Wear増加量**: baseWear 7-13 + ボーナス（蓄積速度は現行のまま）
- **WEAR_TABLE の閾値**: 0-19全盛/20-39衰え/40-59衰退/60-79限界/80+確定引退
- **applyDecay のdecay量**: wear区間ごとの減少量は変更なし
- **引退メカニズム**: wear 40+で20%、60+で50%、80+で確定（変更なし）
- **自主引退**: OVR < Notion×0.60 が2シーズン連続（変更なし）
- **シーズン構造**: 48ターン/年（変更なし）
- **ライバリー閾値**: 因縁2回/宿敵4回/宿命7回（変更なし）
- **クリア条件**: シーズン末ランキング1位（変更なし、難度は様子見）

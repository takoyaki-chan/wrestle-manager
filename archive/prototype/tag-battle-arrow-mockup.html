狙い: 攻撃者→被攻撃者の方向を「矢印」と「流れるラベル」で一瞬で判別できるようにする。
通常攻撃: shaft が scaleX 0→1 で走る (0.45s) + head 矢じりが追いつく + label が上に浮かぶ (1.0s)。
カウンター: 段階1を 0.55s で完走させた後、短い間 (200ms) を挟み、段階2を「反対向き・太さ2倍・フォント拡大・stage flash」で発火。返しが起きた瞬間がハッキリ分かる。
シングル側への展開: 実装は CSS アニメ + 汎用クラス (.attack-arrow, .ltr/.rtl, .counter-reversal) で、tag-battle 以外にも後日展開可能な形で切り出す。
CONTROLS: 通常攻撃 / カウンター / リセット　—　矢印 0.45s + ラベル 1.0s + カウンター段差 200ms

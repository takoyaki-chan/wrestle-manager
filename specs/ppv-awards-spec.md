# PPV + 年末表彰式 — 詳細仕様書

> 設計確定: 2026-02-25（セッション12 打ち合わせ）

## 概要

シーズン最後の大イベントとして**PPV（年間最大興行）**と**年末表彰式**を実装する。PPVは全団体合同の大会で、エントリー制＋対戦相手不明という独自の体験を提供。表彰式は3賞＋チャンピオン紹介＋殿堂入りを1つずつ発表。

---

## Part 1: PPV（年間最大興行）

### 1.1 年末の全体フロー

```
Week 44: PPVエントリー締切
  └─ プレイヤーが出場選手を選ぶ
  └─ 対戦相手は不明。エントリー後の変更不可
  └─ タイトルホルダーは自動エントリー（1枠消費）

Week 44-47: 通常運営
  └─ エントリー選手が怪我 → 不戦敗確定
  └─ 緊張感のある4週間

Week 48: PPV当日
  └─ PPV専用BGM
  └─ 大会名＋ロゴ風タイトル表示
  └─ 1試合ずつカード発表（相手の顔＋一言セリフ＋煽り文）
  └─ バトルエンジンで観戦可能
  └─ 効果は通常興行と同じ（人気・ヒート変動）

→ オフシーズンへ
  ├─ Week 1: シーズン末処理 → 引退演出 → 表彰式
  ├─ Week 2: スカウト
  ├─ Week 3: ドラフト
  └─ Week 4: 新シーズン開始
```

### 1.2 出場枠数

全団体合同の大会。各団体のランク（＝ランキング順位）に応じて出場枠数が決まる。

| ランク | 枠数 |
|:------:|:----:|
| S級（1位） | 5枠 |
| A級（2位） | 4枠 |
| B級（3位） | 3枠 |
| 4位 | 2枠 |
| **合計** | **14名 → 7試合** |

**タイトルホルダーの自動エントリー**: プレイヤー団体のチャンピオンは自動的に1枠を消費してエントリーされる。残りの枠を自由に選択。

### 1.3 エントリーUI

Week 44の管理画面でエントリーフェーズが開始：

```
━━ PPVエントリー ━━
大会名: [大会名表示]
出場枠: 2枠（4位）

[👑 自動エントリー]
  高島さや（チャンピオン）

[残り1枠を選択]
  ○ 桜庭あかり (OVR 78, 人気 62)
  ○ 天羽ひかり (OVR 71, 人気 55)
  ○ ...

※ エントリー後の変更はできません
※ エントリー選手が出場不能になった場合、不戦敗となります

        [ エントリー確定 ]
```

### 1.4 エントリー後の怪我リスク

Week 44〜47の4週間、エントリー選手は通常通り興行やトレーニングに参加する。この間に怪我した場合：

| 怪我の重さ | 影響 |
|-----------|------|
| 軽傷（1〜2週離脱） | 復帰がPPV前なら出場可能 |
| 中傷（3〜4週離脱） | PPVまでに復帰できない → **不戦敗** |
| 重傷（5週以上） | **不戦敗確定** |

不戦敗の場合、対戦相手の勝利（不戦勝）として処理。MQ計算は行わない。

**プレイヤーへの選択**: 重要な選手をエントリーするリスクと、弱い選手で安全にいくリスクのトレードオフ。

### 1.5 マッチメイクアルゴリズム

PPVのカード編成は**「最も盛り上がるカード」**を自動生成する。プレイヤーは対戦相手を選べない。

**制約:**
- 同じ団体同士は対戦しない

**優先順位:**
1. **因縁（ライバルリー）** — rivalriesが成立している組み合わせを最優先でマッチング
2. **盛り上がりスコア** — 残りの選手は以下のスコアで最適組み合わせを探索

```
盛り上がりスコア = (OVR合計) + (人気合計 × 0.5) - (OVR差 × 2)
```

- OVR合計が高い → 実力者同士
- 人気合計が高い → スター対スター
- OVR差が小さい → 接戦が期待できる

3. **タイトルホルダーの配置** — チャンピオンの試合はメインイベント（最終試合）付近に配置

**試合順:**
盛り上がりスコアの昇順で配置。前座 → セミファイナル → メインイベントの順に盛り上がっていく。

#### BGM

PPV専用BGMを用意。通常の management BGM から切り替え。
- PPV開始時に専用BGMを再生
- 試合中はバトルBGM（既存）

### 1.7 PPVの結果

| 項目 | 仕様 |
|------|------|
| 人気変動 | 通常興行と同じ |
| ヒート変動 | 通常興行と同じ |
| 収入 | なし（合同大会のため自団体の収益にはならない） |
| careerRecord | PPV出場は記録しない（通常の試合扱い） |
| 特別な効果 | なし。PPVは体験そのものがご褒美 |

## Part 2: 年末表彰式

### 2.1 タイミング

オフシーズン Week 1 の末尾。引退演出の後に実行。

```
オフWeek 1:
  1. applySeasonEnd（成長・衰退・wear蓄積）
  2. 引退判定 → 引退演出ポップアップ
  3. ★ 年末表彰式 ★
```

### 2.2 発表の流れ（5段階）

1賞ずつ発表。ファンファーレで開始。

```
[ファンファーレ SE]

━━ シーズン○ 年末表彰式 ━━

    1. 🌟 新人王
    2. 🎬 ベストマッチ
    3. 👑 MVP
    4. 🏆 タイトルチャンピオン
    5. 🏛️ 殿堂入り（該当者あれば）

```

### 2.3 各賞の選出ロジック

#### ① 新人王

| 項目 | 仕様 |
|------|------|
| 対象 | **全団体**のその年デビュー1年目の選手 |
| 選出基準 | 年末時点のOVR最高 |
| 該当なしの条件 | 1年目選手が全団体で0人（極めて稀） |

```
対象選手の抽出:
  - プレイヤー団体: roster内で careerSeasons === 1 の選手
  - AI団体: 各aiOrgs[orgId].roster内で careerSeasons === 1 の選手
  - 全対象からOVR最高の1名を選出
```

**表示:**
```

│                          │

│   OVR 62                 │
│                          │
│     [ 次へ ]              │

```

#### ② ベストマッチ

| 項目 | 仕様 |
|------|------|
| 対象 | **各団体1試合ずつ**（計4試合） |
| プレイヤー団体 | そのシーズンの最高MQ試合（実データ） |
| AI団体 | MQを生成して代用 |
| 選出基準 | 4試合中、MQ最高の試合 |

**AI団体のMQ生成:**
```js
// AI団体のシーズンベストMQを生成
function generateAIBestMQ(rng, aiOrg) {
  // 団体の上位2選手のOVR平均をベースに
  const sorted = [...aiOrg.roster].sort((a,b) => ov(b) - ov(a));
  const topAvg = (ov(sorted[0]) + ov(sorted[1])) / 2;

  // ティアベースの基準値
  const tierBase = { S: 75, A: 65, B: 55 }[aiOrg.tier] || 55;

  // MQ = (topAvg * 0.6 + tierBase * 0.4) + random(-10, +10)
  const baseMQ = topAvg * 0.6 + tierBase * 0.4;
  const mq = Math.round(baseMQ + rng.int(-10, 10));

  // 対戦カード情報も生成
  return {
    mq: clamp(mq, 30, 98),
    fighter1: sorted[0].name,
    fighter2: sorted[1].name,
    orgName: aiOrg.name
  };
}
```

**表示:**
```

│                              │
│   高島さや vs 桜庭あかり      │
│   あなたの団体               │
│   MQ 87                     │
│                              │
│     [ 次へ ]                  │
└──────────────────────────────┘
```

#### ③ MVP

| 項目 | 仕様 |
|------|------|
| 対象 | **各団体のエース1名ずつ**（計4名） |
| 選出方法 | MVPスコアで比較 |

**各団体からのエース選出:**
- プレイヤー団体: `OVR + 人気 × 0.5 + タイトル保持ボーナス(20)` が最高の選手
- AI団体: 同上の計算で各団体1名

**MVPスコア（4名の比較用）:**
```js
function calcMVPScore(rng, fighter, isPlayerOrg) {
  const base = ov(fighter) + fighter.popularity * 0.5;

  // タイトル保持ボーナス
  const titleBonus = isCurrentChampion(fighter) ? 20 : 0;

  // ランダム幅（全候補共通）
  const random = rng.int(-15, 15);

  return base + titleBonus + random;
}
```

**バランス上の重要ポイント:**
- 各団体1名ずつなので、S-tierの数の暴力は発生しない
- ランダム幅 ±15 で、OVR差15程度なら逆転可能
- プレイヤー団体のエースは常に25%の基礎確率を持つ
- 成熟したプレイヤー団体（エースOVR 85+、人気70+）は有利だが確定ではない

**検証すべき数値例:**

| 団体 | エースOVR | 人気 | タイトル | ベーススコア | ランダム後の範囲 |
|------|:--------:|:----:|:-------:|:-----------:|:---------------:|
| S級 | 90 | 80 | なし | 130 | 115〜145 |
| A級 | 82 | 65 | なし | 114.5 | 99.5〜129.5 |
| プレイヤー | 85 | 70 | あり | 140 | 125〜155 |
| B級 | 72 | 50 | なし | 97 | 82〜112 |

→ プレイヤー（タイトル持ち）は有利だが、S級のエースも射程圏内。B級は厳しいが不可能ではない。

**表示:**

│                          │
│     [顔画像]              │
│   高島さや (28歳)         │

│   OVR 85 / 人気 70       │
│                          │

└──────────────────────────┘
```

#### ④ タイトルチャンピオン

| 項目 | 仕様 |
|------|------|
| 対象 | 現在のタイトル保持者 |
| 表示内容 | 選手名、団体名、防衛回数 |

AI団体のチャンピオン情報は `championScore` から推定するか、AI団体にも個別のタイトルトラッキングを持たせる（要検討）。

最小実装: プレイヤー団体のチャンピオンのみ表示。AI団体は「各団体の王者」としてエースの名前を表示。

#### ⑤ 殿堂入り

| 項目 | 仕様 |
|------|------|
| 対象 | そのシーズンに引退した選手（`retiredFighters`） |
| 条件 | `totalTitleWins + totalDefenses >= 13` or グランドスラム |
| 該当なし | 表彰式でスキップ（何も表示しない） |

**殿堂入り演出:**
```

**殿堂入り後の処理:**
- `retiredFighters` から該当者を `hallOfFame` に移動
- `hallOfFame` に保存する情報:

```js
hallOfFame.push({
  id: fighter.id,
  name: fighter.name,
  portrait: fighter.portrait,
  orgName: '所属団体名',
  activeYears: 'S1〜S12',
  titleReigns: fighter.careerRecord.totalTitleWins,
  totalDefenses: fighter.careerRecord.totalDefenses,
  peakOVR: fighter.careerRecord.peakOVR,
  peakOVRSeason: fighter.careerRecord.peakOVRSeason,
  inductionSeason: currentSeason,
  achievement: 'グランドスラム' // or null
});
```

- 非該当者は `retiredFighters` から削除（データ破棄）

## Part 4: 実装順序の推奨

1. **表彰式（Part 2）を先に実装** — PPVなしでもオフシーズンに表彰式だけ動かせる
2. **PPVエントリーUI** — Week 44のエントリーフェーズ
3. **PPV当日演出** — カード発表＋煽り文＋観戦
4. **PPV専用BGM** — 最後に追加

# セリフ口調仕様 v1.0(口調バイブルのspecs昇格)

- 昇格: 2026-08-12(Fable)。2026-08-11の口調バイブル確立+全34セル・約910セル改訂の全直し完走を受けて確定仕様化
- 本仕様は**全セリフ執筆・レビューの物差し**。ゲーム内の全共通セリフ(タイプ×性格キーのテーブル)はこの仕様に適合していなければならない
- 規範文書(この3つが本仕様の一部):
  - **セル別口調シート**: `docs/tone-bible/<属性>×<性格>.md` 34枚(骨格/語尾セット/性格変調/禁句/アンカー見本)
  - **アンカー表**: `docs/tone-bible-anchors.md`(セルの声=アンカー選手の既存セリフ)
  - **裁定記録**: `docs/tone-bible/00-裁定待ちリスト.md`(全59項目、裁定完了。番号引用の正)

## 1. 二軸構造

- セリフの分岐は **archetype(第一)× personality(第二)**。性格単独で分けると口調が崩壊する
- archetype 7種: `standard`(標準)/`ojousama`(お嬢様)/`cool`(クール)/`delinquent`(ヤンキー)/`polite`(丁寧)/`composed`(鷹揚)/`seductive`(蠱惑)
- personality 7種: `normal`(ノーマル)/`bold`(強気)/`quiet`(寡黙)/`shy`(内気)/`easygoing`(お気楽)/`earnest`(真面目)/`emotional`(感情的)
- 実在セルは34(全キャラ127名の実分布)。テーブルは全49セルを定義してよいが、実在しないセルの執筆は骨格+性格変調からの外挿とし、レビュー優先度は低い
- フォールバック: **アーキタイプを保ったまま性格を落とす → 標準の口調へ**(2026-08-01確立)

## 2. アンカー制

各セルの「声の正」はアンカー選手の既存セリフ(表は `docs/tone-bible-anchors.md`)。
セルの骨格に迷ったらアンカーの実セリフに立ち返る。アンカー以外の個体差(真鍋の文語調、西川の女性語尾、堂前の超短文など)は**骨格に取り込まない**。

## 3. 全セル共通の鉄則

1. **個体固有の口癖・自称・異名を共通セリフに入れない**(裁定41「共有してるんだから。あらゆるタイプでそう」)。個別セリフ限定
2. **一人称は極力出さない**。必要な行だけ**漢字「私」**(裁定53)。例外: 内気(shy)帯のみひらがな「わたし」可 / お嬢様帯は「わたくし」の採用実績あり(2026-08-12 Keisuke改稿)/ 大河内個人は両用(裁定33・個別セリフの領分)。「俺」「あたし」「アタシ」「ワタシ」は不可
3. **二人称は極力呼ばない**。必要時は「あなた」基調、標準×強気=アンタ、ヤンキー=あんた(裁定55)。クールは対社長でも呼びかけほぼなし
4. **対社長の敬語**: 仕様として許容だが、**強気(bold)帯は非敬語可**(裁定59追記2)。卑屈語彙(「拾ってくれた恩」「私なんか」型)は全帯NG
5. **中性カジュアル語尾は許容**(「〜だよ」「〜じゃん」等、今時の女性が普通に使う範囲)。**柄の悪い男系語尾(だぜ/だろうが/てめえ)はNG** — 例外はヤンキー骨格内の伝法(じゃねえ/かよ等)のみ温存(検品06)
6. **身体・抽象メタファー禁止**(2026-08-12裁定): 「体が言う」「鏡が教える」「走る(=努力する)」「呼吸しやすい」型は一読で意味が取れず不可。生活語彙の具体表現で書く。定着した慣用句(「体は正直」「鏡は嘘つかない」)は境界線上 — 使用時は要注記
7. **固有名詞(大会名・団体名・選手名)を共通セリフに入れない**。名称はヘッダー/地の文が背負う。セリフは指示語主体(名称入りは1割以下)
8. **語彙の重さ=世界の実態**(悲壮度較正)。FA=所属がないだけ、減俸=年次査定。人生の破滅として書かない
9. **表記**: !? は全角。三点リーダーは「……」系で統一(セル慣行に従う)。半角記号は使わない
10. **長さ**: 頭上吹き出し1〜2行(目安20〜70字)。クール・寡黙系はさらに短くてよい(クール×寡黙は普通の短文20〜30字も混在可=裁定23)

## 4. 属性別の骨格サマリ(詳細は各セル口調シート)

| 属性 | 骨格の要点 | 主要裁定 |
|---|---|---|
| 標準 | 現代の標準語。性格でカジュアル度が振れる | お気楽=宇田川準拠のギャルノリ(19)/真面目=井沢の大人の落ち着き(28)/寡黙=早見の乾いた短文 |
| お嬢様 | **語彙で品格を作り、装飾語尾(ですわ)はアクセント程度**。乱発しない | 「！」は真面目帯中心/ノーマルは装飾語尾ほぼゼロ(富岡準拠) |
| クール | 言い切り・体言止め・低温。呼びかけをしない | 一人称は出しても出さなくてもよい(21)/寡黙の断片+短文混在(23) |
| ヤンキー | 伝法(じゃねえ/かよ)は骨格内温存。normal/bold/easygoing=タメ口、quiet/shy/earnest/emotional=対社長「っす」体 | 一人称も漢字「私」(アタシ廃止) |
| 丁寧 | 敬語基調 | 寡黙=言葉を選ぶ岸準拠・絶句系は個体差(26)/真面目のタメ口は激情時のみ(27)/お気楽=木ノ内のはしゃぎが地(20) |
| 鷹揚 | 大人の余裕。タメ口が地(独白・試合後の一言も常体=口調シート「鷹揚×真面目」アンカー準拠)。**対社長の改まった場面のみ** earnest がです・ます | 強気は中性語尾(「〜なんだ」「だよ」)で女性的アクセント控えめ |
| 蠱惑 | 色気と余裕。友達口調の馴れ馴れしさと混同しない(F07汚染の教訓) | 感情的=取り乱しではなく敵意が漏れるセクシー系(29) |

## 5. スコープ

- 対象: タイプ×性格キーの**共通セリフ全テーブル**(データ宣言+実行文内テンプレート。書き出しEXCEL約14,800行が母数)
- 対象外: キャラ個人セリフ(victory-lines等、裁定57)/ 話者不特定の軸なしセリフ(ファンの声等)/ `_該当者なし` ブック(裁定56)
- 既知の未整備: 派閥COMMON1/COMMON5(leaderDemand/leaderQuoteA 72行)は話者の口調軸が無い(ロードマップに要判断として記録)

## 6. 執筆・レビューの運用

1. 新セリフ起草時は「該当セルの口調シート+裁定記録+アンカー既存セリフ」を必ず参照させる(起草はOpus、指示書にセル資料パスを明記)
2. Fableが鉄則§3への適合をレビュー → Keisukeが全文レビュー(文章系は全文チェック必須)
3. セリフ編集EXCELとの往復: 反映(apply)→書き出し(export)の順を守る(書き出しは破壊的)。レビュー結果は原本ブックの改訂列(G)へ書き戻す
4. セル移動(personality/archetype変更)は裁定事項。移動時はアンカー表・口調シート・関係システムへの影響(相性補正/決断傾向)を確認する

## 設計思想

「社長室は社長のすべての仕事が行われる場所」——ケアも、スカウトの書類も、レンタルの契約書も、机に届く書類の種類が違うだけ。選手との重要な話——契約交渉も解雇の面談も——この部屋で行われる。

## §1 統合対象と現状

| 機能 | 現在の場所 | 統合後 |
|------|-----------|--------|
| ケア決裁（6書類） | 🏛️ 社長室タブ（実装済） | そのまま（決裁タブ） |

| ドラフトイベント | scoutEvent 独立画面 | 画面自体は維持、出発地点を社長室に変更 |

## §2 ナビゲーション構造の変更

### §2.1 トップバー（変更後）

```
📅 今週 | 🎤 興行準備 | 👥 団体 | 🏛️ 社長室 | 🏆 ランキング | 📊 データベース | 🏢 経営 | 📋 ログ | 💾 セーブ | ❓ ヘルプ
```

- **「🔍 スカウト」タブを廃止**。スカウト機能は社長室に統合
- 🏛️ 社長室が4番目に繰り上がる（旧スカウト位置）
- トップバーが11→10個に

### §2.2 社長室の内部タブ

```
┌─────────────────────────────────────────────┐
│  HUD: 日付 | 資金 |     （タブ別に出し分け）   │
├─────────────────────────────────────────────┤
│  [📋 決裁]   [🔍 スカウト]   [🤝 レンタル]    │
├─────────────────────────────────────────────┤
│  壁 + 窓（季節）                              │
│  机 ── 書類がタブに応じて入れ替わる ─────     │
└─────────────────────────────────────────────┘
```

### §2.3 内部タブのビジュアル

タブは「机の上に出ている書類フォルダの見出し」のメタファー。

- アクティブタブ: クリーム色背景 (`rgba(237,228,208,0.08)`) + 下線 (`var(--paper)`)
- 非アクティブタブ: 透明背景 + `var(--text-sub)` 文字
- フォント: `Noto Sans JP` 13px bold

### §2.4 タブバッジ

数字ではなく**存在通知**に徹する:

- **📋 決裁** — バッジなし（案件があるかは開けばわかる）
- **🔍 スカウト** — ドラフト開催週のみ「📰」バッジ表示。通常時はバッジなし
- **🤝 レンタル** — 契約中がある場合のみ小さなドット通知。数字は出さない

### §2.5 HUD右側のタブ別出し分け

| タブ | HUD右側の表示 |
|------|-------------|
| 📋 決裁 | 決裁枠 ⚡4/6 + 印鑑6個 |
| 🔍 スカウト | 所属 5/8名、紹介枠 6名 |
| 🤝 レンタル | レンタル枠 1/3枠、残り 2枠 |

### §2.6 デフォルトタブ

- 通常時: **📋 決裁**
- ドラフト開催週（offWeek 3 / Q3第5週）: **🔍 スカウト**
- `G._shachoshitsuTab` で最後に見ていたタブを記憶

### §2.7 外部からの遷移

既存コードで `showScreen('scout')` を呼んでいる箇所はすべて `showScreen('shachoshitsu')` + スカウトタブ選択に書き換える。

## §3 Phase A: 契約交渉の社長室化

### §3.1 変更方針

オフシーズン第2週の契約交渉が発生すると、社長室画面に遷移し、壁+窓+机の背景を使った専用の交渉レイアウトで行う。`careOverlay` モーダルは使わない。

### §3.2 交渉画面レイアウト

```
壁エリア（上半分）:
  壁+窓の画像（季節: 冬 = オフシーズン）
  選手のポートレイト（96px、フェードイン）
  吹き出しでセリフ表示
  態度バッジ（💰 昇給要求 / 🚪 移籍志願 / ⚡ 突発退団）

机エリア（下半分）:
  机画像を背景に使用
  「交渉書類」風カード（document-blank.webp テクスチャ）を1枚配置
  カード内に金額情報と選択肢ボタン
```

**実装済みビジュアル仕様（2026-04-15 仕上げ）**:
- 交渉カード背景: `var(--paper)` クリーム色 + `border:1px solid rgba(80,60,40,0.30)` の枠線。幅400px
  - テクスチャ・回転は不使用（文字可読性優先）
- カードアニメーション: `translateY(10px)` フェードイン、イージング `cubic-bezier(0.22,1,0.36,1)`
- speaker: `cubic-bezier(0.22,1,0.36,1)` + 18px スライドイン
- bubble: 0.18s ディレイ + 12px 横スライドイン、backdrop-blur 強化
- 態度バッジ: ボーダー付き強調、突発退団の紫を `#b07dd0` に変更

### §3.3 フロー変更

```
offWeek 2 進行 → weekPhase='contractNegotiation' 設定
  → showScreen('shachoshitsu') + 特殊モード（内部タブ非表示）
  → 社長室画面内で交渉シーケンスを逐次表示:
    1. サマリー画面（社長室背景 + 対象者一覧カード on 机）
    2. 個別交渉画面（社長室背景 + 選手 on 壁前 + 選択肢 on 机）×N人
    3. リアクション画面（社長室背景 + 選手セリフ）
    4. 結果サマリー画面（社長室背景 + 結果カード on 机）
  → advanceWeek
```

### §3.4 実装のキーポイント

- `showContractNegotiationModal` 等6つのモーダル関数を社長室画面内レンダリングに書き換え
- `shachoshitsuContent` の `innerHTML` を直接差し替え（`careOverlay` 不使用）
- 交渉中は内部タブを非表示にし、トップバーのナビゲーションもロック
- コールバックチェーン（processNext パターン）は維持
- `careOverlay` を使う他のモーダル（選択型イベント等）は一切変更しない

## §4 Phase B: 解雇の社長室化

### §4.1 変更方針

解雇ボタンを押すと社長室に画面遷移し、選手との「最後の面談」シーンを挟んでから実行する。

### §4.2 解雇面談のフロー

```
選手ポップアップ「🚪 この選手を解雇する」
  → ポップアップを閉じる
  → 社長室画面に遷移（特殊モード: 解雇面談）
  → 壁前に選手ポートレイト + 別れのセリフ（性格別）
  → 机上に確認カード:
     [解雇を実行する] — 既存の releaseFighter ロジック実行
     [やっぱりやめる] — 社長室（通常モード）に戻る
  → 実行後: 社長室で結果表示
```

### §4.3 別れのセリフ（性格×6パターン）

| 性格 | セリフの傾向 |
|------|-------------|
| bold | 「次はもっといい場所で暴れてみせます」 |
| quiet | 「……お世話に、なりました」 |
| easygoing | 「まあ、こういうこともあるよね。元気で！」 |
| earnest | 「至らない点があったなら、申し訳ありませんでした」 |
| emotional | 「嘘でしょ……！ まだやれるのに……！」 |
| normal | 「短い間でしたが、ありがとうございました」 |

### §4.4 実装のキーポイント

- `App.releaseFighter(charId)` のロジック自体は変更しない
- `App.startReleaseInterview(charId)` を新設（社長室遷移 + 面談表示）
- カード登録中の解雇不可チェックは面談開始前（ボタン押下時）に維持

## §5 Phase C: スカウト/レンタルの机上統合

### §5.1 スカウトタブ — 3列履歴書カード

FA候補を「スカウト調査報告書」＝**履歴書スタイル**のカードとして表示。

```
┌────────────────────┐
│ [フリー]    [有望]  │  ← 左: 所属タグ、右: ティアタグ
│                     │
│  ┌───────────────┐  │
│  │               │  │
│  │  UPPER IMAGE  │  │  ← アッパー画像（上半身）
│  │               │  │
│  └───────────────┘  │
│                     │
│  赤羽 あかり  22歳  │
│     52 OVR          │
│  Striker / Heel     │
│                     │
│  PWR ██████░ 62     │  ← 5ステータスバー
│  SPD █████░░ 55     │
│  TEC ████░░░ 48     │
│  STA █████░░ 53     │
│  MNT ████░░░ 45     │
│                     │
│  契約金 380万        │
│  給与 8万/週         │
│                     │
│ [📋 詳細] [✒️ 契約] │
└────────────────────┘
```

**レイアウト**: 3列グリッド（max-width 832px）、gap 18px。1カード幅 ≈264px。
**ページ送り**: 3枚ずつ。◀ ▶ ボタンでバサッと入れ替わる（stagger 付きフェードイン）。
**紙画像**: 約264×460px 縦長（新規アセット）。

### §5.2 知名度不足の候補の表示

契約不可の候補は「見えるが手が届かない」演出で表示する:

- **末尾に回す**: 契約可能な候補を先に表示
- **グレーオーバーレイ**: カード全体に灰色を被せる（紙色を `#c8c4bc` にくすませる）
- **アッパー画像もモノクロ調**: `filter: grayscale(0.8) brightness(0.85)`
- **「契約不可」スタンプ**: 赤い半透明の斜めスタンプを書類上に重ねる
- **ボタン**: 「⛔ 知名度不足」で無効化
- **ホバーツールチップ**: 「団体人気がB以上で交渉可能」等の具体的条件を表示

### §5.3 スカウトタブの情報表示

サマリーバー（タブ直下）:
```
所属: 5/8名 ｜ FA: 12名 ｜ 紹介枠: 6名（四半期入替）
```

### §5.4 ドラフトイベントとの連携

ドラフト開催週（offWeek 3 / Q3第5週）:

- 社長室のデフォルトタブが **🔍 スカウト** に切り替わる
- 机の上に**週刊グラップルの速報紙面**が置かれている（既存の新聞風イントロをそのまま使用）
- 「⚖ ドラフトへ」ボタン = **社長室を出てドラフト会場に向かう**
- scoutEvent 画面（ダークテーマの交渉会場）は一切変更しない
- ドラフト終了後、今週画面に戻る

メタファー: 社長が朝出勤して、机の上にドラフト速報の新聞が届いている。読んで「よし、行くか」とドラフト会場に出かける。

### §5.5 レンタルタブ — 4列×2行 小型カード

レンタル候補を小型カード（196×148px）で表示。8枚が一画面に収まる。

```
┌──────────────────┐
│ [EMPRESS]         │  ← 供給元タグ
│ 👤 朝比奈はるか   │
│    Grappler/BF    │
│       54 OVR      │
│ 245万/期 [1期▼]   │
│    [🤝 契約]      │
└──────────────────┘
```

**レイアウト**: 4列グリッド（決裁と同じ幅196px）、gap 10px 16px。2行で最大8枚。
**ソート**: 金額の安い順 ▲ / 高い順 ▼ を右上のボタンで切り替え。
**紙画像**: 196×148px 小型紙（新規アセット）。

### §5.6 契約中レンタルの表示

契約中のレンタル選手は**机の上に置かない**。壁エリアの右下にミニカードとして退避:

```
壁右下:
  ┌───────────────────────────┐
  │ 👤 相川あおい ← NOVA  残18週 │
  └───────────────────────────┘
```

- レンタルタブ表示中のみ壁に出現
- 名前・供給元・残り週数のみのコンパクト表示
- 背景: `rgba(30,28,22,0.85)` + `backdrop-filter:blur(4px)`

## §6 オフシーズン中の社長室

3タブとも常に表示。使えない機能はタブ内で穏やかに制限する。

| タブ | オフシーズン時の表示 |
|------|-------------------|
| 📋 決裁 | 空の机。メモ書き1枚「オフシーズン — 案件なし」 |
| 🔍 スカウト | FA一覧は**閲覧可能**（下見用）。契約ボタンは無効化「オフシーズン中は契約できません」。offWeek 3 では新聞＋ドラフト導線 |

壁の窓は冬景色。静かな社長室の雰囲気。

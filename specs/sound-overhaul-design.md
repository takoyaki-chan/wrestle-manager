### 1.2 主な問題点

**① notifyの乱用（14箇所）**
ロード完了、週進行、イベント発生、アワード切替、成長通知、エンディングステップ……すべて同じ音。プレイヤーにとって「何が起きたか」が音で区別できない。

**② fanfareの乱用（8箇所）**
シーズン開幕、アワード各スライド、エンディング演出、タイトル設立など大小様々なイベントに同じ音。「特別感」が薄れている。

**③ 未使用SFX 4種（impact, championship, seasonEnd, powerup）**
定義だけあり呼ばれていない死にコード。

**④ typeof Audio ガード不統一**
ui-common.js後半で追加されたコードは `typeof Audio !== 'undefined'` ガード付き、前半は無し。統一されていない。

**⑤ BGMジングルとSFXの名前衝突**
`victory` と `championship` がSFXとBGMジングル両方にあり紛らわしい。

**⑥ 文脈に合わない音の選択**
- hoverがホバー以外（カード展開、イベント表示など）に使用
- fanfareが軽いUI操作（タイトル設立通知など）に使用
- notifyがアワード式のスライド切替に使用（もっと荘厳な音が適切）

## 2. 再設計方針

### 2.1 SFX再分類

音をカテゴリ分けし、各カテゴリ内で使い分けを明確にする。

#### 【UIカテゴリ】 — 即座の反応音（短い・控えめ）

| 新SFX名 | 用途 | 設計方針 |
|---|---|---|
| click | ボタンクリック・タブ切替 | 据置。短いタップ音 |
| hover | ホバーのみ | 据置。極小のトーン |
| select | 項目選択・確認 | 据置。上昇3音 |
| deselect | 解除・キャンセル | 据置。下降音 |
| error | 操作エラー全般 | 据置。低音ブザー2連 |
| save | セーブ確認 | 据置 |

#### 【進行カテゴリ】 — ゲームフロー音

| 新SFX名 | 用途 | 設計方針 |
|---|---|---|
| tick | 週送り・軽い進行 | 据置 |
| notify | 軽い通知（情報表示） | 据置。ただし使用箇所を厳選 |
| **event** ★新規 | イベント発生・成長通知 | notifyより一段重い「ポワン」系 |
| **reveal** ★新規 | スライド切替・段階的表示 | アワード式等のステップ音。柔らかいシンバルタッチ |

#### 【経済カテゴリ】 — 金銭関連音

|---|---|---|

## 3. 新規SFX音のデザイン案

### event（イベント発生音）
- notifyより少し長く、温かみのある「ポォン」
- sine波 2音の上昇（E5→G5）＋微弱なリバーブ的テール
- notifyとの差別化: より丸い音色、やや低めの帯域

### reveal（スライド切替音）
- ソフトなシンバルブラシ ＋ 微かなベル音
- ハイパスノイズ（短い）＋ 高域sine波の減衰
- 「次のページをめくる」感覚、繰り返し聞いても不快にならない控えめさ

### award（受賞発表音）
- ベル2〜3個のハーモニクス ＋ きらめきノイズ
- bellPartialベースで、fanfareほど派手でなく品がある
- C5-E5-G5のベルハーモニクス ＋ ハイパスノイズのスパークル

### tension_hit（緊張ヒット音）
- 短いドラムロール → シンバル一打
- noiseLP(ロール) → noiseHP(シンバル) ＋ 低域 osc で重み

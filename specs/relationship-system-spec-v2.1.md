## v2.1 改訂サマリ

他団体戦の接触頻度が極端に低い（年1回未満、特定ペアでは数年に1回）という運用実態に対し、現状の関係値処理は rivalry のみ ×2.0 倍率がかかり、bond は同団体戦と同じ扱いだった。これを **「他団体戦は1試合で帯を動かす重い接触」** として再設計する。

| 項目 | v2.0 | v2.1 |
|------|------|------|
| 他団体戦 rivalry倍率 | ×2.0 | ×2.0（据え置き） |
| 他団体戦 rivalry上限 | +35/試合 | +35/試合（据え置き） |
| 他団体戦 bond倍率 | なし | **bondDelta < 0 のとき ×1.5**（新設） |
| 他団体戦 基本Bond税 | なし | **両方向 -2〜-5**（新設、参加2名のみ） |
| M-CO1 好敵手認定 | — | **新設**（クロスOrg + MQ≥80 → bond両側 +6〜+10、M-04のbond部分を上書き） |
| M-CO2 抗争和解 | — | **新設**（クロスOrg + 因縁決着 → bond両側 +12〜+20、M-10のbond部分を上書き） |
| M-10決着 matches閾値 | 4+（共通） | **同団体4+、クロスOrg3+** |

## 設計原則

1. **非対称が核** — AからBへの感情と、BからAへの感情は独立。片思い・一方的敵意が自然に生まれる
2. **接触がすべてを動かす** — 同団体・対戦経験がある間は関係が変動し、離れると凍結する
3. **因縁は物語の燃料** — rivalryはMQボーナス・集客に直結するゲーム上最も価値のある関係
4. **bondは空気を作る** — 親密度はロッカールーム士気・信頼・成長環境に間接的に影響する
5. **逓減で鮮度を保つ** — 同じイベントが同じペアで繰り返されると効果が薄れる
6. **他団体は希少接触・大変動**（v2.1新設）— 年1回未満の接触機会で帯が動く重さを与え、結果として「敵対」「好敵手」「単なる対戦相手」に二極分化する

## §3 週次処理（processWeeklyDecay）

### §3.1 接触判定

**接触あり** = 同団体 **OR** 直近2興行（4週）内に対戦

### §3.2 接触ありの場合

**Bond:**
- current > 50: 50方向へ **-0.18〜-0.30**/週 🔧
- current < 50: 50方向へ **+0.18〜+0.30**/週

**同団体Bond天井**: bond 55から減速し **60で停止** 🔧（試合・イベントでのみ60超に到達可能）

**Rivalry:**
- 基本減衰: **-0.28〜-0.5**/週 🔧
- 85+: 追加 **-0.45**/週
- 70–84: 追加 **-0.25**/週
- 50–69: 追加 **-0.12**/週
- knownRival時: 全減衰 **×1/3**（超低速）
- knownRival + rivalry < 60 + 4週ごと: **+0.3〜+0.5**（意識維持）

### §3.3 接触なしの場合

- **Bond**: **凍結**（変動なし）
- **Rivalry**: **-0.16**/週 🔧（≈70週で70→0）。knownRival時は×1/3

### §3.4 性格摩擦（Phase 4）

- 条件: 同団体 + 性格×アーキタイプ相性合計 ≤ -3
- 効果: bond **-0.15**/週 🔧（年間 -7.2pt）

### §3.5 世代近接ボーナス（Phase 4）

- 条件: 同団体 + 年齢差3歳以内
- 効果: bond **+0.1**/週 🔧（年間 +4.8pt、天井とは別枠）

### §3.6 OVR変動効果

**G-04（OVR差拡大）:**
- 条件: OVR差10+ + rivalry 20+ + 高OVR側
- 効果: rivalry **-2〜-4**/週（興味喪失）

**G-05（OVR近接）:**
- 条件: OVR差5以内 + 4週ごと
- 効果: rivalry **+2〜+4**（rivalry 10+の場合）
- 同スタイル追加: rivalry **+1〜+2**
- タイトル圏（org top 5 + 同団体）: rivalry **+0.5〜+1.0** 🔧

### §4.3 片側因縁認知

- 条件: 一方rivalry ≥ 50、他方 < 20（片側因縁）

### §4.4 クロスOrg特例ルール（v2.1新設）

`isCrossOrg = true` の試合（PPV / B3対抗戦 / Warイベント等、context.isCrossOrg で判定）に対し、以下の特例を順に適用する。

#### §4.4.1 適用順序

```
1. クロスOrg基本Bond税を両方向に加算（§4.4.2）
2. M-events を順に適用（M-01〜M-17、§4.2）
   - rivalry変動: ×2.0倍率（v2.0から維持）
   - bond変動: §4.4.3 の方向別乗数を適用
   - M-04: §4.4.4 により M-CO1 に置換
   - M-10: §4.4.5 により M-CO2 に置換、閾値も緩和
3. クロスOrg rivalry上限を適用（+35/試合、v2.0から維持）
4. knownRival自動付与、clamp（v2.0から維持）
```

#### §4.4.2 基本Bond税

```
両方向に bond -2〜-5 🔧 を加算（勝敗・MQ・スタイル無関係）
```

**適用対象**: 試合参加2選手のみ（charIdA, charIdB）。ロスター全体には波及しない。

**数値根拠**:
- 同団体週次回帰幅(-0.18〜-0.30/週)の **10〜25倍**
- 年1試合以下の頻度を想定し、**1接触で確実に「帯」を動かす**設計
- 5試合戦った相手なら -10〜-25pt → 「普通」帯から「苦手」帯へ確実に移行

**乗数との関係**: 基本税は §4.4.3 の方向別乗数の **対象外**（固定値）。

#### §4.4.3 Bond方向別乗数

```
isCrossOrg && bondDelta < 0 → bondDelta *= 1.5
isCrossOrg && bondDelta > 0 → bondDelta *= 1.0（標準、乗数なし）
ただし M-CO1 / M-CO2 / 基本税 は乗数対象外
```

**意図**:
- 負の方向（嫌悪・距離感）には ×1.5 で加速 → 「他団体だから自然と仲が悪くなる」
- 正の方向（好意・友情）には乗数なし → 標準ルートでは関係改善しない
- 例外として M-CO1 / M-CO2 を新設し、**特定の高品質試合でのみ大きな正の動き**を許可

**乗数化される対象イベント例**:
- M-03 圧勝 (-4〜-2) → クロスOrg ×1.5 = **-6〜-3**
- M-11 怪我 (-1〜-3) → ×1.5 = **-1.5〜-4.5**
- M-15 番狂わせ敗者→勝者 (-4〜-2) → ×1.5 = **-6〜-3**
- M-17 凡戦 (-4〜-2 / -2〜-1) → ×1.5 = **-6〜-3 / -3〜-1.5**

**数値根拠（×1.5）**:
- ×2.0だとM-03圧勝で -8〜-4 となり、1試合で1帯（普通→苦手）跨げてしまい激しすぎる
- ×1.5なら、複数の負イベントが同時発火（圧勝＋怪我＋凡戦）した場合に総計 -10pt前後で、ようやく1帯跨ぐ
- 「劇的な事件があった試合」だけ大きく動く設計

#### §4.4.4 M-CO1 好敵手認定

```
条件: isCrossOrg && context.mq >= 80
    （M-04 同条件、クロスOrgで置換発火）
効果:
  bond: 両側 +6〜+10 🔧（固定値、§4.4.3の乗数対象外）
  rivalry: M-04 と同じ +8〜+12（×2.0倍率は適用される）
逓減カウンタキー: "famousMatch:cross-org" として独立カウント
  （同団体の M-04 とは別カウンタにすることで、初回フルウェイト）
```

**数値根拠**:
- 同団体M-04 (+3〜+6) を **2倍弱** に拡大
- 基本税 -2〜-5 を含めて純増 +1〜+8
- 名勝負1回で「普通」帯から「好意」帯入りが届く威力（最大値で +10 → -5基本税控除して +5、bond 50→55→帯境界）
- 5試合のうち1試合が名勝負化したと仮定すると、年1試合の名勝負で確実に好敵手認定が定着

#### §4.4.5 M-CO2 抗争和解

```
条件:
  isCrossOrg && §7.3 因縁決着判定が成立した場合
  （クロスOrg時の対戦回数閾値は 4+ → 3+ に緩和、§7.3）
効果:
  bond: 両側 +12〜+20 🔧（固定値、§4.4.3の乗数対象外）
  rivalry: → 0〜10 にリセット（v2.0 M-10 と同じ）
逓減カウンタキー: なし（決着は本来ペアで1〜2回しか起きないため逓減不要）
```

**数値根拠**:
- 同団体M-10 (+5〜+10) の **約2倍**
- 過去の累積で「嫌悪」帯（bond 0〜19）まで落ちていたペアが、決着試合1回で「苦手」帯（20〜39）または「普通」帯（40〜59）まで戻れる威力
- 「敵対関係を超えた絆」の劇的瞬間として、関係値分布の **好敵手15%枠** を支える主要メカニクス

## §7 因縁称号システム

rivalryの数値に基づくライバル称号。MQボーナスに直結。

### §7.1 称号段階

| 称号 | 昇格条件 | MQボーナス 🔧 |
|------|---------|:----------:|
| 因縁 | tier 0→1: rivalry 30+ / 対戦2+ | +2 |
| 宿敵 | tier 1→2: rivalry 50+ / 対戦3+(since tier1) / bestMQ 70+ | +4 |
| 永遠のライバル | tier 2→3: rivalry 70+ / 対戦3+(since tier2) / bestMQ 80+ | +6 |
| 片側因縁 | 一方rivalry 50+ / 他方30未満 | +1（高い側のみ） |

### §7.2 降格条件

| 現在 | 降格先 | 条件 |
|------|--------|------|
| 永遠 → 宿敵 | rivalry ≤ 50 |
| 宿敵 → 因縁 | rivalry ≤ 35 |
| 因縁 → なし | rivalry ≤ 20 + 48週未対戦 |

### §7.3 決着

**標準条件（同団体 / 同orgまたは未指定）**:
- rivalry ≥ 60 + 相互対戦 **4+** + MQ ≥ 50

**クロスOrg条件（v2.1新設）**:
- isCrossOrg = true の場合、相互対戦数閾値を **4+ → 3+** に緩和
- rivalry / MQ 閾値は据え置き

**効果（v2.0 から変更なし、ただしクロスOrgはM-CO2に置換）**:
- bond +5〜+10、rivalry → 0〜10にリセット（同団体）
- **クロスOrgはM-CO2発火: bond +12〜+20、rivalry → 0〜10**（§4.4.5）
- tier/matchesSinceTier/bestMQSinceTier もリセット
- 4週クールダウン
- orgPop +1.5〜+2.5 🔧、pop +4〜+6 🔧

**実装注意**:
- 現状 `Engine.title.checkResolution`（management.js）は対戦回数閾値を明示的に強制していないため、本spec改訂と合わせて **同団体 4+ / クロスOrg 3+** の matches 閾値を追加する必要がある
- 既存の rivalry / MQ ガードは維持しつつ、matches ガードを追加する形

## §14 期待される関係値分布（auto-sim検証目標）

v2.1 適用後、auto-sim 100シーズン（10seed × 10season）における**他団体間ペアの関係値分布**は以下を目標とする：

| 分布 | 想定割合 | bond帯 | rivalry帯 | 体感 |
|------|:------:|--------|----------|------|
| 敵対 | 50% | 嫌悪〜苦手 (<40) | 因縁帯 (60+) | 「対戦するたびに距離が広がった相手」 |
| 単なる対戦相手 | 25% | 普通 (40-59) | ライバル視〜因縁 (40+) | 「数回戦ったが特段思い入れはない」 |
| 好敵手 | 15% | 好意〜深い絆 (60+) | 因縁〜宿命 (60+) | 「敵対関係を超えた絆を結んだ相手」 |
| その他 | 10% | — | — | エッジケース（短期離脱 / 早期引退等） |

「絶対敵対」にはならず、しかし**多数派は敵対**、**少数派が好敵手**という二極化分布になる想定。

## 設計原則

1. **ローテーション管理を生む** — 全員毎興行フル出場は不可能。誰を休ませるかがゲーム判断
2. **万全でも怪我する** — コンディション100でも基本怪我率は0にならない
3. **後遺症はすぐ見えない** — 決定は怪我時、発覚は復帰後数試合経ってから。リロード対策
4. **克服の可能性を残す** — 後遺症は低確率で乗り越えられる。使い続けた者への報酬
5. **経済システムと連動** — 怪我→治療費＋欠場→カード品質低下→収入減の連鎖

## §2 コンディション消耗

### §2.1 消耗源

| イベント | 消耗量 🔧 | 備考 |
|---------|:--------:|------|
| 通常練習 | −5 | 毎週発生 |
| プロモ選択時 | −2 | 練習より身体負荷が軽い |
| 完全休養 | 0 | 消耗なし（回復のみ） |
| 試合出場 | 後述の計算式 | 試合内容により変動 |

### §2.2 試合消耗の計算式

```
試合消耗 = 20 + (被ダメージ率 × 15) + (試合ターン数 × 0.5) 🔧
```

| 補正 | 倍率 🔧 |
|------|:------:|
| タイトルマッチ | ×1.3 |
| 特別興行 | ×1.2 |
| 通常興行 | ×1.0 |

#### 試合消耗の目安

| シナリオ | ターン | 被ダメ率 | 消耗 |
|---------|:-----:|:-------:|:----:|
| 軽い試合（圧勝） | 12 | 30% | 31 |
| 標準的な試合 | 18 | 60% | 38 |
| 激闘（接戦） | 22 | 80% | 43 |
| タイトルマッチ激闘 | 24 | 85% | 57 |

## §3 コンディション回復

### §3.1 回復量

| 状況 | 週回復量 🔧 | 備考 |
|------|:--------:|------|
| 通常（練習あり） | +15 | 基本回復 |
| 完全休養（練習も休む） | +25 | その週の成長はゼロ |

### §3.2 施設Lvボーナス

| 施設Lv | 回復ボーナス 🔧 |
|:------:|:------------:|
| Lv1（初期） | +0 |
| Lv2 | +1 |
| Lv3 | +2 |
| Lv4 | +3 |
| Lv5 | +5 |

### §3.3 固有特性による補正

| 特性 | 効果 🔧 |
|------|--------|
| 回復力 | 週回復量 +5 |
| 鉄人 | 試合消耗 ×0.8 |

### §3.4 2週サイクルのコンディション推移

| 週 | イベント | 計算 | 実質変動 |
|---|---------|------|:-------:|
| 試合週 | 練習(−5) + 試合(−35) + 回復(+15) | | −25 |
| 非試合週 | 練習(−5) + 回復(+15) | | +10 |
| **2週合計** | | | **−15** |

→ 毎興行フル出場すると2週で約15ずつ下がる。**6〜8興行連続**出場でコンディション危険域に到達。ローテーション必須の設計。

### §3.5 自動休養設定

プレイヤーが選手ごとに**自動休養ライン**を設定可能。

```
設定例: コンディション 40 以下で自動的に完全休養
```

| 項目 | 仕様 |
|------|------|
| 設定単位 | 選手ごと |
| 設定値 | 任意（0〜80の範囲で設定可。0＝オート無効） |
| デフォルト値 | 30 🔧 |
| 動作 | 設定値以下になった週、自動的に完全休養。練習・プロモも行わない |
| 表示 | 「○○は自動休養中です」の通知 |

## §5 怪我システム

### §5.1 怪我発生タイミング

試合中に判定。**コンディション100でも発生しうる**。

### §5.2 怪我発生率

```
怪我率 = 基本怪我率 × コンディション補正 × 特性補正 🔧
```

| 条件 | 基本怪我率 🔧 |
|------|:----------:|
| 試合出場 | 5% |
| 強行出場（怪我離脱中） | 40% |

| 特性 | 補正 🔧 |
|------|:------:|
| 頑丈さ | ×0.5 |
| ガラスの身体 | ×1.5 |
| 古傷あり（1箇所につき） | +5% |

### §5.3 怪我の発覚と試合内処理

**フェーズC方式: 試合中に発生＋重症度は試合後に判明**

#### 試合中の処理
1. 毎ターン、被ダメージ時に怪我判定を実行
2. 怪我発生 → 試合中に演出発生
   - 実況：「○○が膝を押さえている！」「動きが明らかにおかしい！」
3. 怪我発生後のターンから**パラメータ一律−15%**の低下を適用 🔧
4. 怪我後、**TKO判定率が+15%** 🔧
5. 試合は続行（レフェリーストップで終わる可能性が上がる）

#### 試合後の処理
1. 怪我の重症度を判定（下表）
2. 離脱期間・治療費を確定
3. 週末レポートで「○○は△△の怪我で×週間の離脱」と表示

### §5.4 重症度判定

| 重症度 | 判定確率 🔧 | 離脱期間 🔧 | 治療費（万）🔧 |
|:-----:|:---------:|:---------:|:-----------:|
| 軽傷 | 60% | 1〜2週 | 20 |
| 中傷 | 25% | 3〜6週 | 80 |
| 重傷 | 12% | 8〜16週 | 200 |
| 重傷＋後遺症判定 | 3% | 8〜16週 | 200 |

※「ガラスの身体」特性：中傷以上の比率が10%UP（軽傷50%/中傷30%/重傷16%/重傷+後遺症4%）

### §5.5 強行出場

怪我離脱中の選手を無理に出場させるオプション。

| 項目 | 仕様 |
|------|------|
| 対象 | 軽傷・中傷の選手のみ（重傷は出場不可） |
| 怪我率 | 40%（通常の8倍） |
| パフォーマンス | 全パラメータ ×0.80 |
| 悪化リスク | 再怪我時、重症度が1段階上がる（軽傷→中傷、中傷→重傷） |
| UI | 🔴 赤色警告＋確認ダイアログ「本当に出場させますか？」 |

## §6 古傷システム

### §6.1 古傷化条件

| 条件 | 古傷化確率 🔧 |
|------|:----------:|
| 同一選手の3回目以降の怪我 | 30% |
| 重傷からの復帰時 | 15% |

### §6.2 古傷の効果

| 効果 | 値 🔧 |
|------|------|
| 怪我発生率 | 恒久的に +5%（1箇所につき） |
| 後遺症の部位集中 | 古傷と同じ部位に後遺症が発生しやすくなる（出現重み ×2.0）🔧 |
| シーズン開幕コンディション | 75（通常より−5） |

### §6.3 古傷の蓄積

- 古傷は複数持ちうる（膝の古傷＋首の古傷、等）
- 古傷2箇所以上：引退判定に影響（34歳以降の引退確率UP）
- 古傷3箇所以上：33歳から引退判定開始

## §7 後遺症システム

### §7.1 設計思想

> **「決定は怪我時、発覚は復帰後しばらく経ってから」**
> セーブ・リロードによるやり直しを防止する。プレイヤーが後遺症の存在を知った時には、もう何週も前のセーブデータに戻らなければ回避できない状態にする。

### §7.2 後遺症の発生

| 項目 | 仕様 |
|------|------|
| 判定タイミング | **重傷発生時に内部決定** |
| 発生確率 | 重傷の25% 🔧 |
| 内部保持 | 隠しフラグ。UIに一切表示しない |
| 影響の適用開始 | **復帰直後から適用**（ただしプレイヤーには見えない） |
| 発覚タイミング | **復帰後3〜5試合を消化した時点** 🔧 |

### §7.3 後遺症の種類と効果

後遺症は怪我の部位に対応するパラメータに永続マイナス補正を与える。

| 部位 | 影響パラメータ | 低下値 🔧 | 出現重み |
|------|:----------:|:--------:|:-------:|
| 膝 | SPD | −5 | 25% |
| 足首 | SPD −3, STA −2 | 計−5 | 15% |
| 肩 | PWR | −5 | 20% |
| 首 | PWR −3, MNT −3 | 計−6 | 10% |
| 腰 | STA | −5 | 20% |
| 手首 | TEC | −4 | 10% |

### §7.4 後遺症の隠蔽と発覚

#### 隠蔽期間中（復帰〜発覚まで）

- パラメータ低下は**内部的に適用済み**
- ステータス画面の数値は**低下後の値を表示する**（ただし後遺症の存在は表示しない）
- プレイヤーは「あれ、数値が思ったより低いな…」と感じることができる
- 怪我からの復帰直後なので「まだ本調子じゃないのかも」と解釈しうる

#### 発覚イベント

復帰後3〜5試合消化時に発生：

```
[イベント演出]
「○○の動きにかつてのキレがない…
  あの怪我の影響が残っているようだ。」

[ステータス画面更新]
  SPD 85 → SPD 80（膝の後遺症: −5）
  ※ 数値自体は復帰時からすでにこの値だった
```

### §7.5 シーズン開幕時の補正

| 状態 | 開幕コンディション 🔧 |
|------|:------------------:|
| 後遺症持ち | 70 |

## §8 後遺症の克服

### §8.1 設計思想

> 後遺症は「絶望的な永続デバフ」ではなく「乗り越えられる可能性がわずかにある試練」。
> 後遺症を負った選手を見捨てずに使い続けたプレイヤーへの報酬。

### §8.2 克服条件

全条件を満たした上で、毎週の判定で低確率発生：

| 条件 | 値 🔧 |
|------|------|
| 後遺症発覚後の試合消化数 | **20試合以上** |
| その間のMQ★★★以上の好勝負 | **3回以上** |
| 毎週の克服判定確率 | **3%** |

→ 最速でも約40週（ほぼ1シーズン）。期待値では1年半〜2年程度。

### §8.3 克服に影響する固有特性

| 特性 | 効果 🔧 |
|------|--------|
| 負けず嫌い | 克服判定確率 +1%（3%→4%） |
| 努力家 | 必要試合数 −5（20→15試合） |

### §8.4 克服イベント

```
[イベント演出]
「○○が動きのキレを取り戻した！
  あの怪我を完全に克服したようだ——！」

[ステータス更新]
  SPD 80 → SPD 85（膝の後遺症: 克服）
  ※ パラメータが後遺症前の値に全回復
```

### §8.5 克服の効果

| 項目 | 効果 |
|------|------|
| パラメータ | 後遺症による低下が**全回復** |
| 人気 | 個人人気 **大UP**（名勝負以上の上昇幅） |
| 団体Heat | **+15** 🔧 |
| MQボーナス | 克服後の次の3試合、MQに**+10**ボーナス 🔧 |

## §9 システム連携サマリー

| 連携先 | コンディションとの関係 |
|-------|---------------------|
| **経済** | 怪我→治療費（§5.4）。欠場→カード品質低下→集客減→収入減 |
| **育成** | 完全休養＝成長ゼロのトレードオフ。施設投資で回復量UP |
| **バトルエンジン** | コンディション低下→パラメータ補正（§4.1）。試合中の怪我→性能低下（§5.3） |
| **Heat** | 主力欠場→好カードが組めない→Heat低下→集客減の悪循環 |
| **MQ** | コンディション60未満の出場→MQペナルティ（§4.1） |
| **固有特性** | 回復力/鉄人/頑丈さ/ガラスの身体/負けず嫌い/努力家 が影響 |
| **後遺症克服** | 使い続けた選手への報酬。克服時に人気・Heat・MQにボーナス |

## §10 確定事項（セッション内で決定）

| # | 項目 | 決定 | 備考 |
|---|------|------|------|
| 1 | 怪我部位の決定ロジック | **完全ランダム**（均等確率） | スタイル依存は入れない。シンプルに |
| 2 | 古傷と後遺症の部位連動 | **連動あり** | 古傷がある部位に後遺症が出やすくなる（出現重み ×2.0）→ §6.2に反映済み |
| 3 | 後遺症のUI表示 | **発覚後に赤or紫で明示表示** | 発覚前は演出なし（数値は下がっているが理由表示なし）。発覚後はステータス画面に「膝の後遺症(SPD−5)」を赤/紫の目立つ色で表示 |
| 4 | 複数後遺症の累積 | **上限なし＋3個以上で引退勧告** | 引退勧告は強制ではない。プレイヤーが「それでも使う」と判断可能。ただし怪我率が跳ね上がるため長期運用は困難 |
| 5 | 怪我離脱中のプロモ | **軽傷のみ可能** | 中傷・重傷は完全離脱（練習もプロモも不可）。長期離脱の本当の怖さを出す |
| 6 | コンディションの表示精度 | **5段階アイコン** | 好調/通常/疲労/消耗/限界のアイコン表示。数値は内部管理のみ |

### §10.1 後遺症3個以上の引退勧告

| 後遺症数 | 効果 |
|:--------:|------|
| 1〜2個 | 通常の後遺症効果のみ |
| 3個 | 引退勧告イベント発生。怪我率さらに +10% 🔧 |
| 4個以上 | 毎シーズン末に引退判定（年齢に関係なく）🔧 |

引退勧告を蹴った場合：
- プレイヤーは引き続き出場させられる
- ただし怪我率の累積で現実的にはそう長くは使えない
- 「満身創痍でリングに上がり続けるベテラン」というドラマが自然に生まれる

### §10.2 怪我離脱中の行動制限

| 怪我重症度 | 試合 | 練習 | プロモ |
|:---------:|:----:|:----:|:-----:|
| なし | ○ | ○ | ○ |
| 軽傷 | ×（強行出場は可） | × | **○** |
| 中傷 | ×（強行出場は可） | × | × |
| 重傷 | × | × | × |

### §10.3 コンディション表示アイコン

| コンディション帯 | アイコン | 色 |
|:--------------:|:------:|:--:|
| 80〜100 | 😊 好調 | 緑 |
| 60〜79 | 🙂 通常 | 白/グレー |
| 40〜59 | 😓 疲労 | 黄 |
| 20〜39 | 😰 消耗 | 橙 |
| 0〜19 | 🔴 限界 | 赤 |

※ プレイヤーには数値を見せない。体感で管理させることでリアリティを出す。

# 人間関係システム設計スペック v0.1

## 概要

選手同士の人間関係を非対称2軸でシミュレートするシステム。
全キャラ間（9,506方向）で追跡し、試合・イベント・団体所属等のゲーム内行動に基づいて変動する。
将来的に派閥システム、人物相関図UIへと発展させる。

---

## 1. データモデル

### 1.1 基本2軸

| 軸 | 名称 | 範囲 | デフォルト | 意味 |
|---|---|---|---|---|
| 親密度 | bond | 0〜100 | 50 | 信頼・好意 ↔ 嫌悪・侮蔑 |
| 競争意識 | rivalry | 0〜100 | 0 | 相手をライバルとして意識する度合い |

### 1.2 親密度の帯域

| 範囲 | ラベル | 意味 |
|---|---|---|
| 0〜19 | 嫌悪・侮蔑 | 積極的に嫌っている |
| 20〜39 | 苦手・不信 | 関わりたくない |
| 40〜59 | 普通 | 特別な感情なし（デフォルト50） |
| 60〜79 | 好意・信頼 | 仲が良い |
| 80〜100 | 深い絆・盟友 | 強い信頼関係 |

### 1.3 競争意識の帯域

| 範囲 | ラベル | 意味 |
|---|---|---|
| 0〜19 | 眼中にない | デフォルト。意識していない |
| 20〜39 | 少し意識 | 気になる存在 |
| 40〜59 | 明確にライバル視 | 勝ちたい相手 |
| 60〜79 | 因縁レベル | 強い執着 |
| 80〜100 | 宿命のライバル | 人生を懸けた相手 |

### 1.4 非対称モデル

関係は**方向別**に管理する。AがBに抱く感情と、BがAに抱く感情は独立。

```
relationships: {
  "charA→charB": { bond: 72, rivalry: 45 },
  "charB→charA": { bond: 38, rivalry: 12 },
  ...
}
```

- 全キャラ98人 → 98×97 = 9,506方向
- データ量：約330KB（GameStateへの影響は軽微）
- 週次処理コスト：約2ms以下

### 1.5 象限マップ

|  | 競争意識 高 | 競争意識 低 |
|---|---|---|
| **親密度 高** | 好敵手（尊敬し合うライバル） | 仲間・盟友 |
| **親密度 低** | 宿敵（憎しみ合う因縁） | 侮蔑・嫌悪（相手にする価値もない） |

## 2. 変動ルール

### 2.1 自然減衰（接触状態による分岐）

#### 接触あり（同団体 OR 直近4週以内に対戦）

| 値 | 挙動 | 速度 |
|---|---|---|
| bond（50より上） | 50方向に微減 | -0.2〜-0.3/週 |
| bond（50より下） | 50方向に微増 | +0.2〜+0.3/週 |
| rivalry | 微減 | -0.1〜-0.2/週 |

日常的に顔を合わせている関係。極端な感情はゆっくり中央に引かれるが、イベントによる変動と比べて非常に小さい。

#### 接触なし（別団体 AND 対戦なし）

| 値 | 挙動 | 速度 |
|---|---|---|
| bond | **凍結（変動なし）** | 0/週 |
| rivalry | 超低速減衰 | -0.1/週 |

会っていない関係は**ほぼ凍結**される。最後に接点があった時の感情がそのまま保存される。rivalryのみ非常にゆっくり冷めるが、70→0まで700週（約13年）かかるため実質的にほぼ凍結。

#### 設計意図

- 「10年ぶりに再会した元同僚に、当時の感情がそのまま蘇る」を再現
- 一律減衰の不自然さを解消
- 接触ありの減衰もイベント変動より十分小さい → 関係の積み上がりは実感できる

### 2.2 再接触イベント

凍結されていた関係が再接触（同団体に合流、対抗戦で再戦）した時、凍結値に基づいて反応イベントを発火できる。

| 条件 | イベント | 効果 |
|---|---|---|
| bond 80以上で再接触 | 旧友との再会 | 双方モチベ上昇 |
| bond 20以下で再接触 | 因縁の相手と同じ屋根の下 | ロッカールーム雰囲気悪化 |
| rivalry 60以上で再接触 | あの時の決着をつける | カード候補として浮上 |

## 3. イベント別影響マトリクス

### 3.1 試合関連

| イベント | bond影響 | rivalry影響 | 備考 |
|---|---|---|---|
| 通常興行で対戦 | ±0〜微増 | 微増 | 日常の一戦。大きくは動かない |
| 僅差の好勝負 | +2〜+4 | +5〜+8 | 互いの実力を認める |
| 一方的な圧勝（勝者→敗者） | ±0 | -3〜-5 | 興味を失う |
| 一方的な圧勝（敗者→勝者） | -2〜-4 | +5〜+10 | 悔しさで意識。非対称が顕著 |
| 名勝負（MQ80超） | +3〜+6 | +8〜+12 | 大きな共有体験 |
| タッグ組んで勝利 | +3〜+5 | ±0 | 信頼が深まる |
| タッグ組んで敗北 | -1〜-3 | +1〜+3 | 不信＋競争心 |
| PPV/GRAND FINALで対戦 | ±0 | +10〜+15 | 大舞台は強烈に刻まれる |
| タイトルマッチで対戦 | ±0 | +8〜+12 | タイトルを懸けた争い |

### 3.2 団体運営・契約関連

| イベント | bond影響 | rivalry影響 | 備考 |
|---|---|---|---|
| 同団体に長期所属（週次） | +0.2〜+0.5/週 | ±0 | 仲間意識（自然減衰と相殺〜微プラス） |
| FA/スカウトで入団 | 既存→新人: -3〜+3 | ±0 | 警戒or歓迎（ランダム） |
| 選手が他団体に移籍（残った側→去った側） | -8〜-15 | +5〜+10 | 裏切り感。でも意識はする |
| 引退（親しかった相手→引退者） | -5〜-10 | rivalryは凍結→超低速減衰 | 喪失感 |
| 契約更新成功 | 団体メンバー→本人: +1〜+2 | ±0 | 残ってくれた安堵 |
| 契約更新失敗（退団） | 移籍と同様 | 移籍と同様 | |

### 3.3 ケア・マネジメント関連

| イベント | bond影響 | rivalry影響 | 備考 |
|---|---|---|---|
| encourage | 対象→団体全体: +1〜+2 | ±0 | ケアされた感謝 |
| refresh_leave付与 | 同上 | ±0 | |
| camp/party実施 | 参加者同士: +2〜+4 | ±0 | 共同体験 |

| 連敗中の選手を起用し続ける | 本人→団体: +2〜+3 | ±0 | 見捨てないでくれた |
| 連敗中の選手を干す | 本人→団体全体: -3〜-5 | ±0 | 見捨てられた |

### 3.4 成長・実力変動関連

| イベント | bond影響 | rivalry影響 | 備考 |
|---|---|---|---|

## 4. ライバル称号システムとの統合

### 4.1 レイヤー構造

```
【下層】人間関係データ（bond / rivalry の数値、毎週変動）
    ↓ 条件を満たすと
【上層】ライバル称号（因縁/宿敵/永遠のライバル、離散的な状態遷移）
```

- 人間関係数値はMQに**直接影響しない**
- ライバル称号のMQボーナス（因縁+2/宿敵+4/永遠のライバル+6）は従来通り維持
- 称号の発動・維持・降格条件を人間関係データから導出する

### 4.2 称号昇格条件

#### 因縁（MQ+2）
- 双方rivalry 30以上、または片方rivalry 50以上
- 直接対決2回以上

#### 宿敵（MQ+4）
- 因縁状態で、双方rivalry 50以上
- 因縁認定後に直接対決3回以上
- うち1回がMQ70以上

#### 永遠のライバル（MQ+6）
- 宿敵状態で、双方rivalry 70以上
- 宿敵認定後に直接対決3回以上
- MQ80以上が1回以上

### 4.3 称号降格条件

#### 因縁 → 消滅
- 双方のrivalryが20以下に低下
- 4シーズン（48週）以上対戦なし
- 履歴には「過去の因縁」として残る（相関図でグレー表示）

#### 宿敵 → 因縁に降格
- 双方のrivalryが35以下に低下

#### 永遠のライバル → 宿敵に降格
- 双方のrivalryが50以下に低下
- 通常は起きにくい（引退やOVR乖離時に発生しうる）

### 4.4 片側因縁

非対称モデルならではの新状態。

- Aのrivalryが50以上、Bのrivalryが30未満
- Aの視点では「因縁の相手」として表示
- Bの視点ではまだ表示されない
- MQボーナスは**片側のみ＝+1に減額**（一方だけ燃えてる試合）

#### 「認知」イベント
片側因縁状態での試合結果により：
- Aが勝利 or 僅差の接戦 → Bのrivalryが急上昇（眼中になかった相手に苦戦した衝撃）
- Aが大敗 → Aのrivalryが低下しうる（力の差を思い知る）、bondも低下（屈辱）

### 4.5 週次処理フロー

```
tickWeek:
  ├─ 試合結果 → bond/rivalry 更新
  ├─ 同団体所属 → bond 微増
  ├─ 接触状態判定 → 自然減衰 or 凍結
  ├─ OVR変動 → rivalry 再計算（近い相手を意識）
  ├─ ケア/イベント → bond 変動
  │
  ├─ 【称号判定】
  │   ├─ 片側因縁チェック（片方rivalry50超）
  │   ├─ 双方因縁チェック（双方rivalry30超＋対戦数）
  │   ├─ 宿敵昇格チェック
  │   ├─ 永遠のライバル昇格チェック
  │   └─ 降格チェック（rivalry低下＋対戦空白期間）
  │
  └─ 【再接触イベント判定】
      └─ 凍結状態から接触ありに変わったペアに対してイベント発火
```

## 5. 初期値生成

### 5.1 ベース

全ペア一律：bond=50、rivalry=0

### 5.2 アーキタイプ相性マトリクス

性格（personality）× アーキタイプ（archetype）の組み合わせに相性補正を設定し、ベース値に加算してランダム散らしを加える。

#### 親密度補正の方向性（具体値は実装時に調整）

| 組み合わせ | 補正方向 | 理由 |
|---|---|---|
| 同じ性格同士 | + | 似た者同士で波長が合う |
| bold × quiet | - | テンションの差 |
| earnest × easygoing | - | 真面目と適当の衝突 |
| emotional × cool | - | 熱量の差がストレス |
| delinquent × ojousama | -- | 世界観の衝突 |
| earnest × earnest | ++ | 努力を認め合う |

#### 競争意識補正の方向性

| 条件 | 補正方向 | 理由 |
|---|---|---|
| OVR差5以内 | + | 実力が近いと意識 |
| 同世代 | + | 同期意識 |
| bold同士 | + | 負けず嫌い同士 |
| quiet × quiet | - | 張り合わない |

### 5.3 バックストーリー付き初期関係（オプション）

ゲーム開始時に2〜4組だけ特別な初期関係をランダム生成：
- 同期入団ペア（bond高め）
- 元タッグパートナー（bond高め＋rivalry中程度）
- 過去の遺恨ペア（bond低め＋rivalry高め）

将来的にNotionキャラDBに「初期関係」カラムを追加すれば手動設定も可能。

- 「親密度が高いグループ」= 派閥の核

## 8. 設計原則

- **人間関係システムはMQに直接影響しない。** ライバル称号のMQボーナスのみが試合に影響する。
- **非対称が前提。** AがBに抱く感情と、BがAに抱く感情は独立。
- **接触がなければ凍結。** 一律減衰ではなく、接触状態に応じた挙動分岐。
- **称号は昇格も降格もする。** 人間関係は移ろうもの。
- **数値は実装時に精査。** 本スペックの数値は方向性を示すもの。①スケール文脈 ②他要素との相対比較 ③意図するプレイ体験 の3点で最終調整する。

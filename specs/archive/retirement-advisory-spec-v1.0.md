## 設計思想

引退は「起きたことを受け入れる」だけでなく、**プレイヤーが選手の最終章を演出できる**仕組みにする。ただし数値は一切見せず、**コーチの助言を通じて「手触り」で判断する**。

## §1 引退勧告

### §1.1 概要

プレイヤーが選手に「引退勧告」を出せる。選手が受諾すれば**引退ロード**（ラストラン）に入り、最後の興行で引退試合を経て正式引退。

解雇との違い：
- **引退** = 物語の完結。経歴に「引退」が刻まれ、殿堂入り候補になる
- **解雇** = 物語の打ち切り。FAプールに戻るだけ（既存機能。変更なし）

### §1.2 勧告の条件（乱用防止）

以下の**いずれか**を満たす選手のみ「引退勧告」ボタンが有効になる。

| 条件 | 意図 |
|------|------|
| wear ≥ 20（⚠衰え 表示あり）🔧 | 体に衰えが見え始めた選手 |
| キャリア8シーズン以上 🔧 | 十分に闘った選手 |
| 年齢28歳以上 🔧 | 女子プロレスは若さが武器。28歳は区切りとして自然 |

**条件を満たさない選手**: ボタンは非活性（グレーアウト）。ツールチップで「まだ引退を勧められる状況ではありません」と表示。若手や全盛期の選手に引退の名誉は与えられない。不要なら解雇を使う。

※ wear 20 は標準選手で約30歳（蓄積開始28歳から2年後）。年齢28歳条件は wear が溜まる前でも「円満引退」を選べるようにする救済ルート。

### §1.3 受諾判定

#### 内部受諾率（プレイヤーには非表示）

```javascript
function calcAcceptance(fighter, G) {
  let rate = 50;  // ベース50% 🔧

  // wear段階ボーナス
  const wear = fighter.wear || 0;
  if (wear >= 60)      rate += 40;  // 末期: もう限界 🔧
  else if (wear >= 40) rate += 25;  // 本格衰退 🔧
  else if (wear >= 20) rate += 10;  // 軽度衰退 🔧

  // 実績
  const isChamp = G.titles?.world?.championId === fighter.id;
  if (isChamp) rate -= 30;          // 王座保持中: 手放したくない 🔧
  const hasWonTitle = (fighter.careerRecord?.history || [])
    .some(ev => ev.type === 'titleWin');
  if (!hasWonTitle) rate += 10;     // 無冠: 諦めがつきやすい 🔧

  // 信頼度（4段階）
  const trust = fighter.trust ?? 50;
  if (trust >= 80)      rate += 20;   // 深い信頼: 団体の判断を全面的に尊重 🔧
  else if (trust >= 60) rate += 10;   // 良好: 素直に聞く姿勢 🔧
  else if (trust >= 40) rate += 0;    // 普通: 中立 🔧
  else if (trust >= 20) rate -= 10;   // 不信: やや反発 🔧
  else                  rate -= 25;   // 敵対的: 強く反発 🔧

  // 直近シーズン勝率
  const winRate = calcRecentWinRate(fighter, G);
  if (winRate <= 0.4) rate += 10;   // 勝てていない: 自覚がある 🔧

  return Engine.util.clamp(rate, 5, 95);  // 最低5%、最高95% 🔧
}
```

#### 判定タイミング

ボタン押下時に即時判定。結果はセリフ付きポップアップで表示。

### §1.4 受諾時のフロー

```
引退勧告ボタン押下
  → 受諾判定
  → 【受諾】→ 受諾セリフポップアップ
             → fighter.lastRun = true（ラストラン状態）
             → fighter.lastRunWeek = G.week（開始週記録）
  → 【拒否】→ 拒否セリフポップアップ
             → fighter.trust -= 5 🔧
             → fighter.retireAdviceCooldown = 48 🔧（同シーズン再勧告不可）
             → 拒否後反応判定（A:B = 70%:30% 🔧）
               A. 見返しモード: fighter.proveMode = 4（4週間MQ+2ブースト）
               B. ロッカールーム動揺: lockerRoomMorale -= 2
```

### §1.5 受諾セリフ

| 条件 | 方向性 | 例 |
|------|--------|-----|
| 衰退期＋無冠 | 静かな納得 | 「…わかった。潮時だよね」 |
| 衰退期＋元王者 | 未練と覚悟 | 「最後にいい試合がしたい」 |
| 末期 | 感謝 | 「ありがとう。言ってくれて助かった」 |
| 低勝率 | 自覚 | 「自分でもわかってた。もう追いつけないって」 |
| Heel | 照れ隠し | 「…別にアンタに言われなくても辞めるつもりだったわよ」 |

### §1.6 拒否セリフ

| 条件 | 方向性 | 例 |
|------|--------|-----|
| 王座保持中 | 怒り | 「チャンピオンに引退しろって？ 冗談はやめて」 |
| 信頼度低い | 反発 | 「あたしを追い出す気？ そう簡単にはいかないわよ」 |
| まだ闘志あり | 意地 | 「まだ終わらない。あたしはまだ闘える」 |
| Heel | 挑発 | 「引退？ 次の興行を見てなさい。後悔させてあげる」 |

### §1.7 拒否後の反応

拒否された場合、**信頼-5 + クールダウン** に加えて以下のいずれかが発生する。

| 反応 | 確率 | 効果 | 期間 |
|------|:----:|------|------|
| A. 見返しモード 🔥 | 70% 🔧 | 「悔しさ」をバネに奮起。試合MQに+2ボーナス | 4週間 🔧 |
| B. ロッカールーム動揺 | 30% 🔧 | 団体と選手の間に微妙な空気。ロッカールーム士気-2 | 即時（自然回復に任せる） |

**見返しモードの設計意図**: 拒否されたことがマイナスだけでなく「あ、頑張ってるな」と思える反応が返ってくる。選手に人間味が出る。ただしステータス自体は上がらないので、頑張っても勝てなければ翌シーズンの再勧告は通りやすくなる（勝率低下→+10）。

**士気動揺の設計意図**: -2はほぼ誤差。「拒否したらロッカールームが荒れた」まではいかないが、「ちょっとざわついた」程度のフレーバー。勧告を試すこと自体への萎縮を防ぐために軽微にする。

```javascript
// 拒否後反応
if (Engine.rng.float(rng) < 0.70) {
  fighter.proveMode = 4;  // 見返しモード: 4週間
} else {
  G.lockerRoomMorale = Math.max(0, (G.lockerRoomMorale || 50) - 2);
}
```

## §2 引退ロード（ラストラン）

### §2.1 概要

引退勧告を受諾した選手は**ラストラン状態**になる。次の興行（最大4週以内）で引退試合を組める。

| 項目 | 仕様 |
|------|------|
| 状態フラグ | `fighter.lastRun = true` |
| 期間 | 次の興行まで（最大4週 🔧） |
| 期間超過時 | 引退試合なしで自動引退（演出はあり） |
| UI表示 | 選手名の横に「🌅ラストラン」バッジ |

### §2.2 ラストランの効果

| 効果 | 値 | 意図 |
|------|:---:|------|
| 試合の内部MQ加算 | +3 🔧 | 「最後の試合」の特別感 |
| メインに組んだ場合の追加MQ | +5 🔧 | 花道をメインで用意する報酬 |
| ファン期待度に自動追加 | MQボーナス+5 🔧 | ファンが引退試合に注目する |

※ MQボーナスは外部MQとしてPass 2で処理（MQ_EXTERNAL_CAPの内数）

### §2.3 引退試合の演出

引退試合を興行カードに組み込んだ場合：

1. 試合結果画面で「🌅 ○○ ラストマッチ」の特別ヘッダー表示
2. 試合後に引退演出ポップアップが発動（v1.3-3の演出に合流）
3. 引退ルートは `player_retire` として `careerRecord.history` に記録
4. セリフは v1.3-3 の分岐テーブルに「勧告受諾型」カテゴリを追加（感謝寄り）

### §2.4 王座保持中の引退試合（特殊ケース）

王座保持中の選手が引退勧告を受諾した場合（受諾率は-30で低いが、末期や信頼度が高ければ通りうる）、**引退試合がそのままタイトルマッチになる**。

| 項目 | 仕様 |
|------|------|
| 自動タイトルマッチ化 | ラストマッチにタイトルマッチフラグを付与 |
| 対戦相手の扱い | プレイヤーが選ぶ。「誰にベルトを託すか」の判断 |
| 勝敗 | バトルエンジン通り（忖度なし）。チャンプが勝つこともある |
| チャンプが勝った場合 | 引退＋王座返上。「最後まで王者のまま去った」演出 |
| チャンプが負けた場合 | 引退＋王座移動。「後継者にベルトを託した」演出 |
| MQボーナス | ラストラン+3、メイン+5 に加え、タイトルマッチ+10（既存） |

**セリフ例（勝って引退）**:
- 「このベルトは返すわ。最後まで負けなかったこと…それだけが誇り」
- 「勝ち逃げ？ ええ、そうよ。チャンピオンらしいでしょ」

**セリフ例（負けて引退）**:
- 「…託したわよ。あとは頼んだ」
- 「最後に最高の相手と闘えた。悔いはない」

### §2.5 引退試合を組まなかった場合

ラストラン開始から4週経過 or 興行が2回過ぎた時点で自動引退。引退演出ポップアップは出る（試合なし版）。

## §3 引き留め

### §3.1 概要

自動引退判定（wear確率型/シーズン末）が発動したとき、**現行の「送り出す」一択ではなく選択肢を出す**。

```
┌────────────────────────────────┐
│  ○○（33歳）が引退の意思を     │
│  示しています。                │
│                                │
│  「もう体が限界なの…」         │
│                                │
│  [ 送り出す ]  [ 引き留める ]   │
└────────────────────────────────┘
```

### §3.2 引き留めの条件

- **怪我引退（壊滅的怪我 / wear超過型）は引き留め不可**。運命として受け入れるしかない
- **wear 80+（確定引退）も引き留め不可**
- **シーズン末の確率引退（wear 40-79）のみ引き留め可能**

### §3.3 引き留めのリスク

| ペナルティ | 値 | 意図 |
|-----------|:---:|------|
| wear加算 | +10 🔧 | 無理をさせている |
| 次シーズン怪我確率上昇 | +5% 🔧 | 体に負荷がかかる |
| 同一選手の引き留め上限 | 2回まで 🔧 | 永久延命防止 |
| 3回目以降 | 引き留めボタン消滅 | もう引き留められない |

### §3.4 引き留め成功時のセリフ

| 条件 | 例 |
|------|-----|
| 元王者 | 「…もう少しだけ。最後にもう一度、あのベルトに手を伸ばしたい」 |
| 信頼高い | 「アンタがそう言うなら…もう少しだけ頑張ってみるよ」 |
| Heel | 「フン…まだ使い道があるってことね。いいわ、付き合ってあげる」 |

### §3.5 引き留め後に壊滅的怪我が発生した場合

特殊演出（将来拡張枠。v1.0では通常の怪我引退演出と同じ）。

## §4 コーチの引退アドバイス

### §4.1 概要

引退勧告の受諾率（数値）はプレイヤーに**一切見せない**。代わりに、**コーチが助言として「通りそうかどうか」を教えてくれる**。

### §4.2 アドバイスの表示タイミング

引退勧告ボタンを押す**前**に確認できる。選手詳細画面で引退勧告条件を満たしている選手に対し、コーチが担当している場合に助言テキストが表示される。

```
┌──────────────────────────────────────┐
│  選手詳細画面                         │
│  ...                                 │
│  🌅 引退勧告                          │
│  💬 鶴見「衰えも見えてきたし、         │
│      本人も受け入れると思いますよ」     │
│  [引退を勧める]                       │
└──────────────────────────────────────┘
```

### §4.3 アドバイスの精度（観察眼ランク連動）

コーチの**観察眼**ランクによって、助言の具体性と精度が変わる。

| 観察眼ランク | 助言の質 | 揺らぎ 🔧 |
|:---:|------|:---:|
| E〜D | アドバイスなし。「…ちょっとわかりません」 | — |
| C | 大まかな感触（2段階）。的外れあり | 25% |
| B | 3段階の評価。信頼できるがたまに外れる | 15% |
| A | 4段階の精密な読み。ほぼ正確 | 5% |

### §4.4 助言テキスト

内部で算出した受諾率を**ランクに応じた粒度で言語化**する。

#### Cランク（2段階＋揺らぎ25%）

```
受諾率 50%以上 → 肯定系
受諾率 50%未満 → 否定系
（25%の確率で逆を言う）
```

| 判定 | テキスト例 |
|------|---------|
| 肯定 | 「多分、受け入れてくれると思いますよ」 |
| 肯定 | 「本人もそろそろかなって感じはありますね」 |
| 否定 | 「うーん…まだ早いかもしれませんね」 |
| 否定 | 「本人はまだやる気ですよ。難しいかと」 |

#### Bランク（3段階＋揺らぎ15%）

```
受諾率 70%以上 → 高確信
受諾率 40〜69% → 五分五分
受諾率 40%未満 → 厳しい
（15%の確率で1段階ずれた評価を言う）
```

| 判定 | テキスト例 |
|------|---------|
| 高確信 | 「本人も覚悟しているようです。通ると思いますよ」 |
| 高確信 | 「体の衰えは本人が一番わかってますから。大丈夫でしょう」 |
| 五分五分 | 「正直、半々ですね。受け入れるかどうかは本人次第です」 |
| 五分五分 | 「気持ちは揺れてると思います。タイミング次第かと」 |
| 厳しい | 「まだ本人には闘志がありますね。断られる覚悟はしてください」 |
| 厳しい | 「目が死んでないですよ、あの選手。引退は早いかと」 |

#### Aランク（4段階＋揺らぎ5%）

```
受諾率 80%以上 → ほぼ確実
受諾率 60〜79% → 通りそう
受諾率 40〜59% → 微妙
受諾率 40%未満 → 厳しい
（5%の確率で1段階ずれる）
```

| 判定 | テキスト例 |
|------|---------|
| ほぼ確実 | 「間違いなく受け入れます。本人もそのつもりです」 |
| ほぼ確実 | 「あの選手、次の身の振り方まで考え始めてますよ」 |
| 通りそう | 「多分通るでしょう。本人も薄々わかってますから」 |
| 通りそう | 「練習後の表情を見ていると…受け入れると思います」 |
| 微妙 | 「正直読めないです。本人の中でも揺れてる感じですね」 |
| 微妙 | 「闘志はあるけど体がついてこない…複雑な状態です」 |
| 厳しい | 「止めた方がいい。あの目はまだ引退する目じゃない」 |
| 厳しい | 「断言しますが、今は無理です。怒らせるだけですよ」 |

### §4.5 コーチ不在 or 担当外の場合

引退勧告対象の選手に**コーチがついていない場合**：

- アドバイスなし。勧告ボタンだけが表示される
- プレイヤーは「感覚で判断する」しかない
- これ自体がコーチを雇う動機になる

**コーチはいるが、対象選手が担当外の場合**：

- 最も低い精度のアドバイス（Cランク相当の2段階評価）を提供
- テキスト：「担当じゃないから確信はないですが…」の前置き付き

### §4.6 実装上の配置

```javascript
Engine.coach.getRetireAdvice(G, fighterId) → {
  coachId,       // 助言したコーチ（null = 不在）
  coachName,
  accuracy,      // 内部用: 'none' | 'low' | 'mid' | 'high'
  text,          // 表示テキスト
  isInaccurate   // デバッグ用: 揺らぎで外れたか
}
```

## §5 UI設計

### §5.1 選手詳細画面への追加

引退勧告条件を満たす選手の詳細画面に、以下を追加：

```
┌────────────────────────────────────────────┐
│  ← 選手名（33歳）  ⚠衰え                    │
│  ...既存の選手情報...                         │
│                                              │
│  ─── 引退 ───                                │
│  💬 鶴見「多分通るでしょう。本人も…」          │
│  [🌅 引退を勧める]                            │
│                                              │
│  ─── 契約 ───                                │
│  [🚪 この選手を解雇する]                      │
└────────────────────────────────────────────┘
```

- 「引退」セクションと「契約」セクションを明確に分離
- 引退勧告条件を満たさない選手は「引退」セクション自体を非表示
- ラストラン中の選手は「🌅 ラストラン中（引退試合をカードに組みましょう）」表示

### §5.2 カード編成画面

ラストラン中の選手がいる場合：

- 選手選択リストで「🌅」アイコン付き
- カードに組むと試合枠に「ラストマッチ」表示

### §5.3 引き留めポップアップ（§3.1）

既存の引退演出ポップアップ（v1.3-3）のボタンを差し替え：

```
現行:  [ 送り出す ]
新規:  [ 送り出す ]  [ 引き留める ]
```

- wear 80+、怪我引退の場合は「送り出す」（or「……」）のみ
- 引き留め上限到達時も「送り出す」のみ

## §8 バランス検証用シナリオ

### 引退勧告の受諾率シミュレーション

# v1.4 世界観演出システム — 設計仕様書

> 基準文書: docs/world-setting.md（世界観設定）
> 参照: docs/master-spec.md（現行仕様）

---

## 概要

ゲーム世界が「生きている」感覚を演出するシステム。プレイヤーの団体だけでなく、業界全体が動いていることを伝える。2つの表示形態を持つ。

| 要素 | 役割 | 表示場所 | 頻度 |
|------|------|----------|------|
| ティッカー | 軽いニュースの常時表示 | manage画面上部（1行スクロール） | 毎週更新 |
| 新聞パネル | 大事件の報道 | ポップアップ（複数枚めくり可） | イベント発生時のみ |

テキストのトーンは **スポーツ紙風**。女性プロレスが国民的スポーツである世界観に合わせ、熱量のある見出しと短い本文で構成する。

---

## 1. ティッカー（ニュースバー）

### 1.1 表示仕様

- manage画面のヘッダー直下に1行で横スクロール表示
- 週送り（advanceWeek）のたびに内容を更新
- manage画面以外（バトル観戦・表彰式・ランキング等）では非表示
- CSSアニメーションによる左方向スクロール
- 複数のニュース項目を「◆」等の区切りで連結

### 1.2 ニュースソース

ティッカーに表示する情報カテゴリ。毎週、該当するイベントからランダムに3〜5件を選出。

| カテゴリ | 対象 | 例文 |
|----------|------|------|
| 興行結果 | AI団体 | 「◆ 〇〇プロレス、今週も超満員！勢いが止まらない」 |
| 連勝記録 | 全団体 | 「◆ △△選手が破竹の5連勝！次のタイトル挑戦者か」 |
| 連敗・不調 | 全団体 | 「◆ □□選手に元気がない…ファンから心配の声」 |
| フレーバー | 全団体 | 「◆ ××選手がバラエティ番組に出演、意外な一面を見せる」 |
| 負傷情報 | AI団体 | 「◆ ○○プロレスの△△選手が練習中に負傷か」 |
| スカウト動向 | 業界全般 | 「◆ 今年の新人は粒揃いとの評判」 |
| 経済 | AI団体 | 「◆ □□プロレス、観客動員が伸び悩む…」 |
| 一般 | 業界全般 | 「◆ 来月のPPV、注目カードは？」「◆ 殿堂入り予想が業界で話題に」 |

### 1.3 生成ロジック

```
Engine.news.generateTicker(G) → string[]
```

- tickWeek実行後に呼び出し
- GameStateから各団体の状態（興行結果・選手成績・イベント）を参照
- 該当イベントをスキャンし、テンプレートに流し込み
- 3〜5件をランダム選出して返す
- テンプレートはdata.jsに定義（NEWS_TICKER_TEMPLATES）

## 2. 新聞パネル（業界ニュース）

### 2.1 表示仕様

- ポップアップオーバーレイとして表示
- 複数記事がある場合は左右矢印またはスワイプでめくれる
- 各記事は見出し（大文字・太字）＋本文（2〜3行）＋関連選手の顔画像（あれば）
- 「閉じる」ボタンで全記事を一括閉じ
- 背景はスポーツ新聞風のデザイン（やや黄色がかった紙面イメージ）

### 2.2 トリガーイベント

新聞パネルは以下のイベント発生時にのみ表示される。いずれも発生頻度が低いため、枚数制限は設けない。

| イベント | 対象 | 見出し例 |
|----------|------|----------|
| 王座交代 | AI団体 | 「激震！〇〇プロレスの王座が動いた！△△が新王者に」 |
| 長期政権達成（10回防衛） | 全団体 | 「伝説へ――△△選手、前人未到の10回防衛達成」 |
| ブレークスルー | AI団体 | 「新星爆誕！□□選手が覚醒、一夜にして別人に」 |
| スランプ深刻化 | AI団体 | 「心配される××選手の不調…いつになったら復活？」 |
| モチベ喪失 | AI団体 | 「引退か――××選手から闘志が消えた？」 |
| 殿堂入り | 全団体 | 「栄光の殿堂入り！△△選手の輝かしいキャリアを振り返る」 |
| 引退（名選手） | 全団体 | 「ありがとう△△――リングに別れを告げた戦士」 |
| 引き抜き成功 | プレイヤー団体関連 | 「電撃移籍！△△選手が〇〇プロレスに加入」 |

### 2.3 生成ロジック

```
Engine.news.generateHeadlines(G, events) → Article[]

Article = {
  headline: string,    // 見出し
  body: string,        // 本文2〜3行
  characterId?: string, // 関連選手（顔画像表示用）
  type: string         // イベント種別
}
```

- tickWeek/シーズン末処理の中で、トリガーイベントをeventsキューに蓄積
- 週の処理完了後にまとめてArticle配列を生成
- UI側でポップアップ表示
- テンプレートはdata.jsに定義（NEWS_HEADLINE_TEMPLATES）

## 3. 長期政権王者の「伝説」記録

### 3.1 仕様

- チャンピオンの防衛回数を追跡（既存のcareerRecordで対応済み）
- 一定回数到達時に新聞パネルで報道
- マイルストーン: 5回防衛（鉄壁）、10回防衛（伝説）、15回防衛（神話）
- 選手詳細ポップアップの経歴にも記載

### 3.2 テキスト例

- 5回: 「盤石！△△選手、5度目の防衛に成功。王座を脅かす者はいるのか」
- 10回: 「伝説へ――△△選手、前人未到の10回防衛。その強さに対戦者も脱帽」
- 15回: 「もはや神話。△△選手の王座は誰にも止められない」

## 4. 引き抜き成功時の業界反響

### 4.1 仕様

- プレイヤーがAI団体から選手を引き抜いた際、新聞パネルで報道
- 引き抜かれた団体の反応（悔しさ）と、業界の注目度を演出
- 選手のOVR/人気に応じてニュースの大きさを変える

### 4.2 テキスト例

- 高OVR: 「電撃移籍！△△選手が〇〇プロレスに加入。□□プロレスは大打撃か」
- 中OVR: 「△△選手が移籍。〇〇プロレスの戦力強化なるか」

---

## 5. 殿堂入り選手の業界誌掲載

### 5.1 仕様

- 殿堂入り確定時に新聞パネルで報道
- 選手のキャリアサマリー（戦績・タイトル歴）を本文に含む
- 年末表彰式とは別に、ニュースとしても流れることで重みを出す

## 6. データ定義（data.js追加分）

### 6.1 NEWS_TICKER_TEMPLATES

イベント種別ごとにテンプレート配列。`{name}` `{org}` `{count}` 等のプレースホルダを使用。各カテゴリ最低5パターン。

### 6.2 NEWS_HEADLINE_TEMPLATES

イベント種別ごとにheadline + bodyのテンプレートペア配列。各イベント最低3パターン。

## 7. 実装対象ファイル

| ファイル | 変更内容 |
|----------|---------|
| engine.js | `Engine.news`名前空間追加（generateTicker / generateHeadlines） |
| data.js | NEWS_TICKER_TEMPLATES / NEWS_HEADLINE_TEMPLATES追加 |
| app.js | tickWeek後のニュース生成フック / eventsキュー管理 |
| ui-common.js | ティッカー表示関数 / 新聞パネルポップアップ（めくり機能） |
| ui-render.js | manage画面へのティッカーDOM挿入 |
| index.html | ティッカーCSS（スクロールアニメ） / 新聞パネルCSS（紙面風デザイン） |

---

## 8. アーキテクチャ準拠

- Engine.news = 純粋関数（DOM禁止）。GameStateとeventsを受け取り、テキストデータを返すのみ
- UI表示はui-common.js / ui-render.jsで処理
- テンプレートデータはdata.jsに集約
- ティッカー内容はGameStateに保存しない（毎週再生成）
- 新聞パネルのeventsキューはGameState内に一時保存し、表示後にクリア

---

## 9. 世界観テキスト作成ガイドライン

docs/world-setting.md に準拠。特に以下を遵守：

- プロレスが「当たり前」の世界であるトーンを保つ
- 選手が本業を持っていることを時折反映（「教壇に立つ傍ら、リングでも無敵の△△選手」等）
- スポーツ紙風の熱量（感嘆符、体言止め、煽り気味の見出し）
- 男性がリングで戦う描写はしない
- 過度にリアリティを求めない（「こういう世界だから」で成立する部分はそのまま）

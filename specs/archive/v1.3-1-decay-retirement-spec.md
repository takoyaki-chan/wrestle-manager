# v1.3-1: 衰退・引退システム改修 — 詳細仕様書

> 設計確定: 2026-02-25（セッション12 打ち合わせ）

## 概要

現行の年齢ベース衰退・引退（35歳開始）を、**durability（個人耐久値）+ wear（累積摩耗）方式**に全面置き換え。サッカー等のプロスポーツに近いキャリアカーブを実現する。標準的な選手は28歳で衰退開始、32〜33歳で引退。

---

## 1. 新パラメータ

### 1.1 durability（個人耐久値）

| 項目 | 仕様 |
|------|------|
| 生成タイミング | `makeChar` 時に確定 |
| 分布 | 正規分布、平均0、σ=2、四捨五入で整数化 |
| 実質範囲 | -4〜+4（±2σでほぼ収まる） |
| 可視性 | **非表示**（プレイヤーに見えない） |
| 変更 | 不変（一度決まったら変わらない） |

**効果**: 衰退開始年齢 = `28 + durability`

| durability | 衰退開始 | 選手タイプ |
|:----------:|:--------:|-----------|
| -4 | 24歳 | 極端な早熟（稀） |
| -2 | 26歳 | 早熟型 |
| 0 | 28歳 | 標準 |
| +2 | 30歳 | タフ |
| +3 | 31歳 | 鉄人 |
| +4 | 32歳 | 超鉄人（稀） |

### 1.2 wear（累積摩耗）

| 項目 | 仕様 |
|------|------|
| 蓄積開始 | `28 + durability` 歳のシーズン末から |
| 初期値 | 0 |
| 格納先 | `fighter.wear`（数値） |
| 可視性 | **非表示** |

---

## 2. wear蓄積ロジック

### 2.1 蓄積タイミング

`Engine.growth.applySeasonEnd` で、各選手に対して年1回計算。

### 2.2 計算式

```
if (fighter.age < 28 + fighter.durability) → wear蓄積なし

baseWear = 10 + random(-3, +3)    // 基本7〜13の幅

補正:
  年間試合数40以上         → +3
  シーズン中の怪我回数 × 2  → +2〜6
  intensive多用（※1）      → +2
  rest運用が半分以上（※2）  → -3
  durability               → -durability

finalWear = max(1, baseWear + 補正合計)  // 最低1は蓄積する
fighter.wear += finalWear
```

※1 「intensive多用」の定義: シーズン中にintensive練習を12週以上実施
※2 「rest運用が半分以上」の定義: schedule='rest' の週が24週以上

### 2.3 wear蓄積の実例

| タイプ | durability | 開始歳 | 年間wear | 30歳wear | 33歳wear |
|-------|:----------:|:------:|:--------:|:--------:|:--------:|
| 標準 | 0 | 28歳 | ~10 | ~20 | ~50 |
| 鉄人 | +3 | 31歳 | ~7 | 0 | ~14 |
| 早熟 | -2 | 26歳 | ~12 | ~48 | — (引退済) |
| 酷使された標準 | 0 | 28歳 | ~16 | ~32 | ~80 |

## 3. wear閾値と効果

| wear | 状態 | ステータス減少 | 引退確率 | UI表示ラベル |
|:----:|------|:-------------:|:--------:|:-----------:|
| 0〜19 | 全盛期 | なし | なし | なし |
| 20〜39 | 軽度衰退 | -1〜2/年（全ステ） | なし | ⚠ 衰え |
| 40〜59 | 本格衰退 | -2〜4/年（全ステ） | 20%/年 | ⬇ 衰退期 |
| 60〜79 | 末期 | -3〜5/年（全ステ） | 50%/年 | ⬇⬇ 限界 |
| 80+ | — | — | 確定 | — |

**ステータス減少の適用**: applySeasonEnd 内で、現行の applyDecay を置き換える形で実装。wear閾値に基づいて減少量をランダム決定し、全5ステ（pw/sp/te/st/mn）に適用。

**UI表示**: 選手詳細・ロスター一覧で、wear 20以上の選手にラベルを表示。衰えが始まったことはプレイヤーに見せる（現実でも見ればわかるため）。

## 4. 引退ルート（4種）

### 4.1 シーズン末引退（wear蓄積型）

| 項目 | 仕様 |
|------|------|
| 判定タイミング | オフシーズン第1週（applySeasonEnd後） |
| 条件 | wear閾値に基づく確率判定（上記テーブル参照） |
| 演出 | 引退演出ポップアップ（穏やかなトーン） |
| ボタンラベル | 「送り出す」 |

### 4.2 怪我引退（wear超過型）

| 項目 | 仕様 |
|------|------|
| 判定タイミング | 重傷発生時に即時判定 |
| 条件 | `wear + 怪我重さボーナス` が80を超えたら引退確定 |
| 怪我重さボーナス | 軽傷=5、中傷=15、重傷=25（要調整） |
| 演出 | 興行結果画面の直後にポップアップ（無念のトーン） |
| ボタンラベル | 「……」 |

※ ベテラン（wear 50〜70）が重傷を負うと引退ラインを超えやすい。

### 4.3 壊滅的怪我（career-ending injury）

| 項目 | 仕様 |
|------|------|
| 判定タイミング | 重傷発生時に追加判定（4.2とは独立） |
| 基本確率 | 2〜3% |
| ベテラン補正 | wear 40以上の場合、5〜8% |
| 効果 | **年齢・wear問わず引退確定** |
| 演出 | 最もショックが大きい演出。若手なら夢が断たれる絶望 |
| ボタンラベル | 「……」 |

**頻度の目安**: 全団体98人で、1シーズンに0〜1人発生するかどうか。数シーズンに1回あるかないかの稀少イベント。ショックの価値を保つため、頻度は意図的に低く抑える。

**特殊ケース: 王座保持中の壊滅的怪我**
- チャンピオンが怪我で引退 → 王座返上が同時発生
- 団体経営に大きな影響を与えるドラマチックな事件

### 4.4 自主引退（既存ルート・残す）

| 項目 | 仕様 |
|------|------|
| 条件 | OVRがNotionの60%未満が2シーズン連続 |
| 用途 | 衰退以外の理由で落ちぶれた選手の救済ルート |
| 判定タイミング | オフシーズン第1週 |

## 5. キャリア例

### 標準的な選手（durability 0）
```
16歳  入団（ドラフト）
16-22  成長期
22-27  全盛期
28歳   wear蓄積開始
30歳   wear ~20 → ⚠ 衰え（軽度衰退）
32歳   wear ~40 → ⬇ 衰退期（引退判定20%開始）
33-34歳 大半が引退
```

### 鉄人（durability +3）
```
16-30  全盛期が長い
31歳   wear蓄積開始（年間~7）
34歳   wear ~20 → ようやく衰え始める
36-37歳 引退判定に到達
38歳まで残ればニュースになるレベル
```

### 早熟型（durability -2）
```
16-25  全盛期
26歳   wear蓄積開始（年間~12）
28歳   wear ~24 → もう衰え始める
30歳   wear ~48 → 引退判定
31歳前後で引退
```

### 酷使された標準選手
```
28歳   wear蓄積開始（怪我×2 + intensive → 年間~16）
30歳   wear ~32
31歳   wear ~48 → 引退判定
→ 大事に使った選手より2年早く壊れる
```

### 若手の壊滅的怪我（最も衝撃的）
```
22歳   OVR急成長中、「来シーズンはエース」と期待
22歳   重傷 → 2〜3%の確率で壊滅的怪我 → 即引退
→ wearは0だが、壊滅的怪我はwear無関係で発生する
```

## 6. 既存システムとの置き換え

| 現行 | 新規 |
|------|------|
| `Engine.growth.applyDecay`（年齢ベースの衰退） | wear閾値ベースの衰退に置き換え |
| `Engine.rival.checkRetirement`（年齢ベースの引退確率テーブル） | wear閾値ベースの引退判定に置き換え |
| 35歳: 30%, 36歳: 50%, 37歳: 70%, 38歳: 90%, 39歳+: 確定 | **全廃** |
| 自主引退（Notion60%未満×2シーズン） | **残す** |

### 6.1 makeChar への追加

```js
// 既存の makeChar 末尾に追加
durability: Engine.career.generateDurability(rng),  // 正規分布 μ=0 σ=2
wear: 0,
```

### 6.2 マイグレーション

既存セーブの選手に `durability` と `wear` がない場合：
- `durability`: 年齢から推定して振る（既にベテランの選手に不利にならないよう配慮）
- `wear`: 年齢と `28 + durability` の差から概算で後付け

---

## 7. AI団体への適用

AI団体の選手にも同じdurability/wearシステムを適用する。AIシーズン末処理（`processSeasonEnd`）内でwear蓄積と引退判定を行う。AI選手は試合数やintensiveの概念がないので、`baseWear + durability補正` のみで蓄積。

# v1.3-2 成長システム改訂 & 怪我デバフ仕様書

> **前提**: v1.3-1 (decay-retirement) 実装済み。`wear`, `durability` フィールドが全選手に存在する。

---

## §1 目的と設計思想

### §1.1 目的

1. 能力値成長のメインソースを **練習** から **試合経験** へ移す
2. 怪我が成長を長期的に阻害する **怪我デバフ (growthPenalty)** を導入する
3. v1.3-1 で TODO だった `seasonInjuries` フィールドを実装し、wear 蓄積の「怪我回数×2補正」を解禁する
4. 重傷を選手の **経歴 (career history)** に記録する

### §1.2 設計思想 — 試合は「分岐点」

試合はハイリスク・ハイリターンの場である。

- **リターン**: 練習では得られない大きな成長、調子上昇のチャンス
- **リスク**: 怪我 → 成長デバフ → スランプ → キャリア下降

試合を重ねることで、**調子よく伸びていく選手** と **怪我で落ちていく選手** に自然と分かれる。
この分岐がキャリアのドラマを生む。プレイヤーは「誰をどれだけ試合に出すか」で団体の未来を決める。

練習は安全だが成長は緩やか。試合に出さなければ大きくは伸びない。
しかし出しすぎれば怪我のリスクが高まり、一度スランプに入ると長期間苦しむ。

## §2 成長ソースの再設計

### §2.1 現行の成長（変更前）

現在、`tickWeek` 内の練習処理で能力値が上昇する。試合による成長は存在しない。

### §2.2 新しい成長モデル

成長は **2つのソース** から発生する。いずれも `tickWeek` 内で処理。

| ソース | 頻度（月間目安） | 1回あたりの成長量 | 月間合計（目安） | 性質 |
|--------|-----------------|-------------------|-----------------|------|
| 練習 (training) | 約4回 | **0.2〜0.5** | 0.8〜2.0 | ローリスク・ローリターン。安定した底上げ |
| 試合 (match) | 約2回 | **1.5〜3.0** | 3.0〜6.0 | ハイリスク・ハイリターン。成長の主軸 |

> **月間比率**: 試合成長が全体の **約70〜75%** を占める。
> 試合に出なければ選手は伸びない。しかし出せば怪我のリスクを負う。

### §2.3 試合成長の計算

試合終了時、出場した **両選手** に成長判定を行う。

```
matchGrowthBase = 1.5

// 対戦相手補正（格上と戦うほど成長）
opponentBonus = clamp((opponent.ovr - self.ovr) / 15, -0.3, +0.8)

// 試合内容補正（接戦ほど成長）
closeMatchBonus = (ラウンド数が最大ラウンドの70%以上) ? 0.5 : 0.0

// 勝敗補正（負けから学ぶ）
resultBonus = (勝利) ? 0.0 : 0.2

// 最終成長量
matchGrowth = matchGrowthBase + opponentBonus + closeMatchBonus + resultBonus
// 範囲: 概ね 1.2 〜 3.0
```

### §2.4 試合成長と調子の連動

試合後、怪我が **発生しなかった** 場合:
- **調子上昇チャンス**: 30% の確率で調子 +1（上限あり）
- 接戦ボーナス: 接戦だった場合、さらに +20%（合計50%）

試合後、怪我が **発生した** 場合:
- 調子上昇なし
- 中傷以上: 調子 **-1〜-2**（スランプの入り口）

> ※ 調子システムが未実装の場合、この節は調子実装時に有効化。TODO コメントで残す。

### §2.5 成長対象ステータスの選択

試合成長で上昇するステータスは **1〜2個をランダム選択**（rng使用）。

- 選択確率は均等（5ステータス各20%）
- 成長量 = `matchGrowth` の値を選択数で割って加算（2個選択時は各 matchGrowth/2）
- 能力値上限: **100**（100を超えない）

### §2.6 練習成長の調整

練習による成長量を現行の **約40%** に下方修正する。

- 現行ロジックで算出された成長量に `× 0.4` を掛ける
- それ以外の練習ロジック（対象ステータス選択など）は変更なし

## §3 怪我デバフ (growthPenalty)

### §3.1 データ構造

選手オブジェクトに `growthPenalty` フィールドを追加:

```javascript
growthPenalty: {
  remainingWeeks: Number,   // デバフ残存週数
  multiplier: Number,       // 成長効率（0.0〜1.0、1.0 = ペナルティなし）
  source: String            // 'minor' | 'moderate' | 'severe'
} | null
```

`null` = デバフなし。

### §3.2 怪我発生時の付与

`Engine.injury.check` で怪我が発生した際、重傷度に応じて `growthPenalty` を設定:

| 重傷度 | remainingWeeks | multiplier | 欠場週数との関係 |
|--------|---------------|------------|----------------|
| minor（軽傷） | 6 | 0.7 | 欠場 2〜3週 + 復帰後3〜4週デバフ残存 |
| moderate（中傷） | 14 | 0.4 | 欠場 6〜8週 + 復帰後6〜8週デバフ残存 |
| severe（重傷） | 24 | 0.15 | 欠場 12〜16週 + 復帰後8〜12週デバフ残存 |

> 欠場中は試合に出られないため実質成長ゼロ。デバフは復帰後の **練習成長・試合成長の両方** に適用。
> 重傷からの復帰直後は成長効率 15%。怪我が重なるとキャリアが急激に下降する。

### §3.3 デバフの適用

`tickWeek` 内で成長量を計算した後、`growthPenalty` が存在する場合:

```javascript
if (fighter.growthPenalty) {
  actualGrowth = baseGrowth * fighter.growthPenalty.multiplier;
  fighter.growthPenalty.remainingWeeks--;
  if (fighter.growthPenalty.remainingWeeks <= 0) {
    fighter.growthPenalty = null;  // デバフ解除
  }
}
```

### §3.4 デバフの上書きルール

デバフ中に再度怪我をした場合:
- 新しい怪我のほうが **重い** → 新しいデバフで上書き
- 新しい怪我のほうが **軽いか同等** → 既存デバフを維持（残り週数が多いほうを採用）

### §3.5 スランプの連鎖メカニズム

怪我デバフは以下の連鎖を生む可能性がある:

```
重傷 → growthPenalty(24週, ×0.15)
  → 長期離脱で成長停滞
  → 復帰後もデバフで成長鈍化
  → wear蓄積（seasonInjuries×2）
  → 翌シーズンの decay 増加
  → 能力値低下 → 試合で不利 → さらに怪我しやすく…
```

この負のスパイラルが「落ちていく選手」を自然に生み出す。
一方、怪我なく試合を重ねた選手は成長 + 調子上昇で「伸びていく選手」になる。

## §4 重傷の経歴記録 (Career History)

### §4.1 データ構造

選手オブジェクトに `careerHistory` 配列を追加（汎用的な経歴記録用）:

```javascript
careerHistory: [
  {
    type: String,       // 'injury' | 'injury_retirement' | 将来: 'title_win' 等
    week: Number,       // 発生した週（gameState.week）
    season: Number,     // 発生したシーズン
    detail: String      // 表示用テキスト
  }
]
```

### §4.2 記録条件

**moderate（中傷）以上** の怪我を記録する。minor（軽傷）は記録しない。

```javascript
if (injury.severity === 'moderate' || injury.severity === 'severe') {
  fighter.careerHistory.push({
    type: 'injury',
    week: gameState.week,
    season: gameState.season,
    detail: `${injury.description}（${severity_label}・${injury.weeksOut}週離脱）`
  });
}
```

### §4.3 壊滅的怪我による引退

v1.3-1 の `retireType` 付き怪我（壊滅的怪我）で引退する場合も記録:

```javascript
fighter.careerHistory.push({
  type: 'injury_retirement',
  week: gameState.week,
  season: gameState.season,
  detail: `${injury.description}により引退`
});
```

### §4.4 UI 表示

選手詳細ポップアップの経歴セクションに `careerHistory` を時系列で表示。

```
【経歴】
Season 2, Week 15 — 右膝靭帯損傷（重傷・16週離脱）
Season 3, Week 8  — 首の負傷（中傷・7週離脱）
```

> `careerHistory` は将来的にタイトル獲得・名勝負などの記録にも使えるように汎用設計とする。


`applySeasonEnd` の最後に `fighter.seasonInjuries = 0` でリセット。

## §8 バランス目安

20歳の選手が1シーズン活動した場合（年間 約24試合 + 練習約40週 想定）:

### 怪我なしパターン（順調な成長）
- 試合成長: 24試合 × 平均2.0 = **+48**（1〜2ステに分散）
- 練習成長: 40週 × 平均0.3 = **+12**
- → 各ステータス平均 **+12〜15** 程度の成長
- 調子も上がりやすく、好循環

### 軽傷1回パターン（小さなつまずき）
- 欠場3週で試合 -2〜3 試合、デバフ6週間 ×0.7
- → 各ステータス平均 **+10〜13** 程度

### 重傷1回パターン（キャリア危機）
- 欠場14週で試合 -8〜10 試合、デバフ24週間 ×0.15
- → 各ステータス平均 **+3〜6** 程度
- wear も +2 加算、翌シーズンの decay 増加
- → ここから持ち直すか、さらに落ちるかの分岐点

### 練習のみ（試合出場なし）
- → 各ステータス平均 **+2〜3** 程度（ほぼ横ばい）

> ※ 数値は目安。テストプレイで調整。

# 難易度選択（補助金なしモード）実装指示書

## 概要

ゲーム開始時に難易度を選択できるようにする。「通常モード」はこれまで通り、「上級モード（補助金なし）」は育成補助金が一切支給されない。経済テーブルやバランス調整は一切不要。

## 変更一覧

### 1. GameState にモードフラグ追加（engine.js — createInitialState）

```js
// initState に追加
difficultyMode: 'normal', // 'normal' | 'hard'
```

### 2. getSubsidy にモード判定を追加（engine.js）

**現行:**
```js
getSubsidy(orgPop) {
  for (const s of SUBSIDY_TABLE) if (orgPop <= s.max) return s.val;
  return 0;
},
```

**変更後:**
```js
getSubsidy(orgPop, difficultyMode) {
  if (difficultyMode === 'hard') return 0;
  for (const s of SUBSIDY_TABLE) if (orgPop <= s.max) return s.val;
  return 0;
},
```

呼び出し側（tickWeek, app.js 等）で `G.difficultyMode` を渡すように修正。

### 3. ゲーム開始画面にモード選択UI追加

ドラフト画面の前、または新規ゲーム開始ボタンの直後に選択画面を挿入。

```
┌─────────────────────────────────┐
│  難易度を選択してください        │
│                                 │
│  ◉ 通常モード                   │
│    地域振興助成金あり            │
│    （orgPop 40まで補助金支給）    │
│                                 │
│  ○ 上級モード                   │
│    補助金なし                    │
│    （すべて自力で稼ぐ）          │
│                                 │
│        ［ゲーム開始］            │
└─────────────────────────────────┘
```

UIデザインはゲーム既存のダークテーマに合わせる。

### 4. 補助金バッジの表示制御（ui-render.js）

上級モードの場合、`dispSubsidy` バッジを非表示にする（補助金が0なので既存ロジックで自動的に非表示になるはず。動作確認のみ）。

### 5. 補助金打ち切り通知のスキップ（engine.js）

```js
// v1.7: 育成補助金打ち切り通知
if (state.orgPop < 40 && popResult.orgPop >= 40) {
  events.push('🏛️ 団体人気が40に到達！ ...');
}
```

上級モードではこの通知をスキップ（補助金がないので打ち切りもない）。

### 6. ヘッダーまたは収支レポートにモード表示（任意）

プレイ中にどのモードか分かるように、収支レポートや設定画面のどこかに「上級モード」表示を入れる。小さいバッジ程度でOK。

### 7. セーブデータ互換性

既存セーブに `difficultyMode` がない場合は `'normal'` として扱う（マイグレーション）。

## 変更しないもの

- SUBSIDY_TABLE: そのまま（通常モードで使用）
- SPONSOR_TABLE: そのまま
- BROADCAST_TABLE: そのまま
- 初期資金 5,000万: そのまま（両モード共通）
- 給与計算、会場、興行収入: すべてそのまま

## 設計根拠

通常モード（現行そのまま）:
- orgPop 40到達まで累計約3,000万の補助金
- 最低残高: 約2,700万（安全圏）

上級モード（補助金なし、他は同一条件）:
- 補助金: 0
- 最低残高: 約508万（興行ミスで死ぬライン）
- 非興行週は毎週-116万がそのまま刺さる
- 「経営の怖さ」を味わえるハードコア体験

コード変更が最小限で、既存バランスに一切影響しない。

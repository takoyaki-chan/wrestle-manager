# v1.4 年末表彰式 — 実装仕様書

> Claude Code向け。リポジトリ: https://github.com/takoyaki-chan/wrestle-manager
> 設計確定: 2026-02-25（セッション13）
> 参照: specs/ppv-awards-spec.md（全体設計）

## 概要

オフシーズン Week 1 の引退演出完了後に「年末表彰式」を実行する。
5賞を1つずつポップアップで発表し、最後に全受賞者一覧を表示する。
殿堂入り該当者がいれば hallOfFame に移動し、retiredFighters を清掃する。

## 1. Engine側の変更

### 1.1 `Engine.awards` モジュール新設

```js
Engine.awards = {

  /**
   * 表彰式の全データを生成（純粋関数）
   * @param {Object} rng
   * @param {Object} state - offWeek 1 処理完了後の GameState
   * @returns {Object} awards データ
   */
  generate(rng, state) {
    return {
      season: state.season,
      rookieOfYear: Engine.awards.selectRookie(state),
      bestMatch: Engine.awards.selectBestMatch(rng, state),
      mvp: Engine.awards.selectMVP(rng, state),
      champions: Engine.awards.getChampions(state),
      hallOfFame: Engine.awards.checkHallOfFame(state)
    };
  },

  /** ① 新人王: 全団体の careerSeasons===1 から OVR 最高 */
  selectRookie(state) { ... },

  /** ② ベストマッチ: プレイヤー=実データ, AI=生成MQ */
  selectBestMatch(rng, state) { ... },

  /** ③ MVP: 各団体エース1名 → MVPスコア比較 */
  selectMVP(rng, state) { ... },

  /** ④ チャンピオン紹介: プレイヤー=実データ, AI=エース */
  getChampions(state) { ... },

  /** ⑤ 殿堂入り判定: retiredFighters から条件合致者 */
  checkHallOfFame(state) { ... },

  /**
   * 殿堂入り確定処理: retiredFighters → hallOfFame 移動
   * @returns 新しい state
   */
  applyHallOfFame(state, inductees) { ... }
};
```

### 1.2 各賞の選出ロジック詳細

#### ① selectRookie(state) → { id, name, orgName, ovr } | null

```
対象選手の収集:
  1. state.roster から careerSeasons === 1 の選手 → orgName = state.orgName || 'あなたの団体'
  2. Object.entries(state.aiOrgs) から各 roster の careerSeasons === 1 の選手
     → orgName = RIVAL_ORGS.find(o => o.id === orgId).name
  3. 全対象から Engine.util.ov() 最高の1名を選出
  4. 該当なし → null（表彰式でスキップ）
```

#### ② selectBestMatch(rng, state) → { fighter1, fighter2, orgName, mq }

```
プレイヤー団体:
  state.seasonStats.bestMQ と bestMQMatch をそのまま使用
  { fighter1, fighter2, orgName: state.orgName, mq: state.seasonStats.bestMQ }

AI団体（各団体1試合ずつ）:
  RIVAL_ORGS.forEach で各団体のベストMQを生成:
    sorted = aiOrg.roster を OVR 降順ソート
    topAvg = (ov(sorted[0]) + ov(sorted[1])) / 2
    tierBase = { S: 75, A: 65, B: 55 }[推定tier] || 55
      ※ 推定tier: rankings から orgId を探してランク→tier変換
        1位=S, 2位=A, 3位=B, 4位以降=null→55
    baseMQ = topAvg * 0.6 + tierBase * 0.4
    mq = clamp(Math.round(baseMQ + Engine.rng.int(rng, -10, 10)), 30, 98)
    { fighter1: sorted[0].name, fighter2: sorted[1].name, orgName, mq }

全4試合から mq 最高の1試合を選出
```

#### ③ selectMVP(rng, state) → { id, name, orgName, ovr, popularity, score }

```
各団体からエース1名を選出:
  エース = roster 内で (ov(f) + f.popularity * 0.5 + (isChampion ? 20 : 0)) が最高の選手

  プレイヤー団体:
    isChampion = state.titles?.world?.championId === f.id
  AI団体:
    isChampion = false（AI王座なし → エース=OVR+人気で代用、タイトルボーナスなし）

MVPスコア計算（4名の比較）:
  score = ov(f) + f.popularity * 0.5 + (isChampion ? 20 : 0) + Engine.rng.int(rng, -15, 15)

最高スコアの1名を選出
```

#### ④ getChampions(state) → Array<{ id, name, orgName, defenses, isPlayer }>

```
champions = []

プレイヤー団体:
  championId = state.titles?.world?.championId
  if (championId) {
    champ = state.roster.find(c => c.id === championId)
    champions.push({ id, name, orgName, defenses: state.titles.world.defenses, isPlayer: true })
  }

AI団体:
  各団体のエース（OVR最高の選手）を「王者」として表示
  defenses は表示しない（null）
  champions.push({ id, name, orgName, defenses: null, isPlayer: false })
```

#### ⑤ checkHallOfFame(state) → Array<inductee>

```
対象: state.retiredFighters（プレイヤー団体の引退者のみ）
  ※ AI引退者はretiredFightersに含まれていないので自動的に対象外

条件: (totalTitleWins + totalDefenses >= 13) OR グランドスラム
  ※ 現状グランドスラムは団体王座1種のみなので実質 13回ルールのみ有効

該当者ごとに:
  {
    id, name,
    orgName: state.orgName || 'あなたの団体',
    activeSeasonsStart: careerRecord.history のdebutイベントのseason || 1,
    activeSeasonsEnd: state.season,
    titleReigns: careerRecord.totalTitleWins,
    totalDefenses: careerRecord.totalDefenses,
    peakOVR: careerRecord.peakOVR,
    peakOVRSeason: careerRecord.peakOVRSeason,
    inductionSeason: state.season
  }
```

#### applyHallOfFame(state, inductees) → newState

```
inducteeIds = inductees.map(i => i.id)
newHallOfFame = [...(state.hallOfFame || []), ...inductees]
newRetiredFighters = [] // 全員クリア（殿堂以外も破棄）
return { ...state, hallOfFame: newHallOfFame, retiredFighters: newRetiredFighters }
```

## 2. App側の変更

### 2.1 advanceWeek フック

現在の流れ:
```
advanceWeek()
  → Engine.advanceWeek(G)
  → pendingRetirements があれば showRetirementPopups()
  → refreshAll()
```

新しい流れ:
```
advanceWeek()
  → Engine.advanceWeek(G)
  → pendingRetirements check
    → あれば showRetirementPopups(retirements, onDone)
      → onDone: pendingAwards check → showAwardsCeremony()
    → なければ直接 pendingAwards check → showAwardsCeremony()
  → refreshAll()
```

具体的な変更（app.js advanceWeek 内）:

```js
// v1.3-3 既存: 引退ポップアップ表示
if (pendingRetirements && pendingRetirements.length > 0) {
  refreshAll();
  showRetirementPopups(pendingRetirements, () => {
    // v1.4: 引退演出完了後に表彰式
    App._checkAndShowAwards();
  });
  return;
}

// v1.4: 引退者なしでも表彰式チェック
App._checkAndShowAwards();
refreshAll();
```

新メソッド:
```js
_checkAndShowAwards() {
  const pendingAwards = G.pendingAwards;
  if (!pendingAwards) return;
  // transient fieldをクリーン
  const { pendingAwards: _, ...cleanG } = G;
  G = cleanG;
  Storage.autoSave();
  // 表彰式ポップアップ開始
  showAwardsCeremony(pendingAwards, () => {
    // 表彰式完了後: 殿堂入り処理
    if (pendingAwards.hallOfFame && pendingAwards.hallOfFame.length > 0) {
      G = Engine.awards.applyHallOfFame(G, pendingAwards.hallOfFame);
    } else {
      // 殿堂該当なし → retiredFighters 清掃のみ
      G = { ...G, retiredFighters: [] };
    }
    // lastAwards を seasonStats に保存（seasonHistory 用）
    G = { ...G, lastAwards: pendingAwards };
    Storage.autoSave();
    refreshAll();
  });
},
```

### 3.2 ui-common.js — showAwardsCeremony

```js
/**
 * 年末表彰式を順番に表示
 * @param {Object} awards - Engine.awards.generate() の結果
 * @param {Function} onDone - 全表示完了後のコールバック
 */
function showAwardsCeremony(awards, onDone) {
  // 表示キューを構築（各賞のレンダラー関数の配列）
  const steps = [];

  // 0. タイトル画面
  steps.push(() => _renderAwardsTitle(awards.season));

  // 1. 新人王
  if (awards.rookieOfYear) {
    steps.push(() => _renderRookieAward(awards.rookieOfYear));
  }

  // 2. ベストマッチ
  if (awards.bestMatch) {
    steps.push(() => _renderBestMatchAward(awards.bestMatch));
  }

  // 3. MVP
  if (awards.mvp) {
    steps.push(() => _renderMVPAward(awards.mvp));
  }

  // 4. チャンピオン紹介
  if (awards.champions && awards.champions.length > 0) {
    steps.push(() => _renderChampionsAward(awards.champions));
  }

  // 5. 殿堂入り（該当者ごとに1画面ずつ）
  if (awards.hallOfFame && awards.hallOfFame.length > 0) {
    awards.hallOfFame.forEach(inductee => {
      steps.push(() => _renderHallOfFame(inductee));
    });
  }

  // 6. 全受賞者一覧
  steps.push(() => _renderAwardsSummary(awards));

  // キュー実行
  let idx = 0;
  window._awardsNext = () => {
    document.getElementById('awardsOverlay').classList.remove('active');
    idx++;
    if (idx < steps.length) {
      setTimeout(() => { steps[idx](); document.getElementById('awardsOverlay').classList.add('active'); Audio.play('notify'); }, 300);
    } else {
      window._awardsNext = null;
      if (onDone) onDone();
    }
  };
  // 開始
  steps[0]();
  document.getElementById('awardsOverlay').classList.add('active');
  Audio.play('fanfare');
}
```

各レンダラーの要件:

**_renderAwardsTitle(season):**
- `━━ シーズンN 年末表彰式 ━━` を表示
- ボタン「開始」

**_renderRookieAward(rookie):**
- 🌟 新人王 🌟
- 顔画像（getPortraitUrl）、名前、年齢、所属団体、OVR
- ボタン「次へ」

**_renderBestMatchAward(match):**
- 🎬 ベストマッチ 🎬
- 「fighter1 vs fighter2」、所属団体、MQ値
- 顔画像は2人分横並び（取得可能なら）
- ボタン「次へ」

**_renderMVPAward(mvp):**
- 👑 MVP 👑
- 顔画像、名前、年齢、所属団体、OVR、人気
- ボタン「次へ」

**_renderChampionsAward(champions):**
- 🏆 タイトルチャンピオン 🏆
- 全団体の王者を一覧表示（プレイヤー団体は防衛回数あり、AI団体は名前のみ）
- ボタン「次へ」

**_renderHallOfFame(inductee):**
- 🏛️ 殿堂入り 🏛️
- 「金の盾」風レイアウト: 顔画像、名前、所属団体、現役期間、獲得回数、防衛回数、最高OVR
- ボタン「拍手」
- CSS: `.awards-box.hall-of-fame` クラス付与
- SE: Audio.play('fanfare') を再度鳴らす

**_renderAwardsSummary(awards):**
- ━━ シーズンN 年末表彰式 結果 ━━
- 全賞の受賞者を一覧
- ボタン「新シーズンへ」（or offWeek 2以降の処理が続く場合は「次へ」）

## 8. 実装時の注意事項

- **Engine内は純粋関数**: DOM操作禁止。awards.generate() は state を受け取って awards データを返すだけ
- **UI側でキュー制御**: showAwardsCeremony() は引退ポップアップと同じキューパターンで1画面ずつ表示
- **Audio.play**: タイトル画面で 'fanfare'、殿堂入りでも 'fanfare'、それ以外は 'notify'
- **pendingAwards は transient**: autoSave の前にクリーンすること
- **ポップアップの z-index**: 表彰式 = 270（引退 = 260、イベント = 250 の上）
- **煽り文・セリフは表彰式では不要**（PPV実装時に追加）

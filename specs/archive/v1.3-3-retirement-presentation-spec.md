# v1.3-3/4: 引退演出 — 詳細仕様書

> 設計確定: 2026-02-25（セッション12 打ち合わせ）

## 概要

引退する選手に**「人間を感じる」演出**を提供する。全選手共通のポップアップ構成で、セリフの内容だけが性格・キャリア・引退状況に応じて変わる。殿堂級の選手も同じ演出（一言多い程度）。殿堂入り自体は年末表彰式で発表。

---

## 1. 演出ポップアップ構成

```
┌────────────────────────────────┐
│                                │
│         [顔画像]               │
│       選手名 (年齢)            │
│                                │
│   ━━ ○○年間の軌跡 ━━          │
│                                │
│   S1  🎓 ドラフト入団          │
│   S3  🏆 団体王座 獲得          │
│   S3  🛡️ 防衛3回              │
│   S5  ⚔ 対抗戦 vs 紅蓮プロレス │
│   S7  📈 全盛期 OVR 84         │
│                                │
│   通算 247勝 198敗 12分         │
│                                │
│  ┌──────────────────────────┐  │
│  │「……ありがとう。            │  │
│  │  この団体で闘えて、        │  │
│  │  あたしは幸せだったよ」    │  │
│  └──────────────────────────┘  │
│                                │
│          [ ボタン ]             │
└────────────────────────────────┘
```

### 1.1 構成要素

| 要素 | 内容 |
|------|------|
| 顔画像 | `getPortraitUrl(fighter.id)` で取得。なければデフォルトアイコン |
| 選手名 | `fighter.name` |
| 年齢 | `fighter.age` 歳 |
| 軌跡タイトル | 「○○年間の軌跡」（`careerSeasons` 年間） |
| 経歴 | `careerRecord.history` から主要イベントを抜粋（後述） |
| 通算成績 | `wins` 勝 `losses` 敗 `draws` 分 |
| セリフ | 引退ルート × キャリア × 性格で分岐（後述） |
| ボタン | 引退ルートに応じたラベル |

### 1.2 経歴の抜粋ルール

`careerRecord.history` から以下のタイプを表示。多すぎる場合は最大8件に絞る。

| type | 表示形式 |
|------|---------|
| `debut` | `S{season} 🎓 {via}入団（{orgName}）` |
| `titleWin` | `S{season} W{week} 🏆 団体王座 獲得` |
| `titleDefense` | まとめて `🛡️ 防衛{最大count}回` |
| `titleLoss` | `S{season} W{week} 団体王座 陥落` |
| `war` | `S{season} ⚔ 対抗戦 vs {opponentOrg}（{勝利/敗北}）` |
| `summit` | `S{season} 🏆 頂上決戦 vs {opponentOrg}（{勝利/敗北}）` |
| `transfer` | `S{season} 📋 {toOrg}に移籍` |
| `peakOVR` | `S{season} 📈 全盛期 OVR {ovr}`（最大値のみ1件） |

**絞り込み優先度**（8件を超える場合）:
1. debut（必ず表示）
2. titleWin / titleLoss（必ず表示）
3. summit（優先）
4. war（2件まで）
5. transfer（2件まで）
6. peakOVR（必ず表示）
7. titleDefense（まとめて1行）

## 2. 引退ルート別の演出差異

### 2.1 シーズン末引退

| 項目 | 仕様 |
|------|------|
| 発生タイミング | オフシーズン第1週、引退判定後 |
| トーン | 穏やか。キャリアを振り返る |
| ボタンラベル | 「送り出す」 |
| 複数人の場合 | 1人ずつ順番にポップアップ表示 |

### 2.2 怪我引退（wear超過型 / 壊滅的怪我）

| 項目 | 仕様 |
|------|------|
| 発生タイミング | 興行結果画面の直後、怪我報告と同時 |
| トーン | 突然の別れ。無念、未練 |
| ボタンラベル | 「……」 |
| 特殊表示 | 怪我の種類を表示（例：「右膝前十字靭帯断裂」） |

### 2.3 殿堂級の選手

通常の引退演出と同じ構成。ただし：
- セリフが1行多い可能性がある（任意）
- 殿堂入り自体は年末表彰式で正式発表

## 3. セリフ分岐テーブル

### 3.1 決定ロジック

セリフは以下の優先順で1つ選択：

```
1. 引退ルート（怪我 or シーズン末）
2. 怪我引退の場合 → 年齢層（若手/全盛期/ベテラン）
3. シーズン末引退の場合 → キャリア実績（王座経験/無冠）
4. 性格（role: Heel/Babyface/Neutral + traits）
```

### 3.2 セリフカテゴリ

| # | 引退ルート | 条件 | セリフの方向性 | 例 |
|---|-----------|------|-------------|---|
| A1 | シーズン末 | 王座経験あり | 達成感、感謝 | 「頂点からの景色は、忘れない」 |
| A2 | シーズン末 | 無冠 | 悔しさの中の誇り | 「ベルトには届かなかった。でも、後悔はない」 |
| A3 | シーズン末 | Heel | 強がり、照れ隠し | 「フン…勝手に泣いてんじゃないわよ」 |
| A4 | シーズン末 | 長期在籍（10年+） | 団体への愛着 | 「ここが、あたしの全部だった」 |
| B1 | 怪我 | 若手（25歳以下） | 夢の途中で断たれた無念 | 「まだ何も成し遂げてないのに…」 |
| B2 | 怪我 | 全盛期（26〜30歳） | 最も残酷。「これからだったのに」 | 「体がね…もう言うことを聞かないの」 |
| B3 | 怪我 | ベテラン（31歳+） | 体の限界を受け入れる覚悟 | 「わかってた。いつか来るって」 |
| B4 | 怪我 | 王座保持中 | 王座返上＋無念 | 「このベルト…まだ返したくなかった」 |

### 3.4 セリフ選択アルゴリズム

```
function selectRetirementLine(fighter, route) {
  // route: 'season_end' | 'injury_wear' | 'injury_career_ending'

  if (route === 'injury_wear' || route === 'injury_career_ending') {
    // 怪我引退
    if (isCurrentChampion(fighter))       → B4_champion_injury
    else if (fighter.age <= 25)           → B1_young
    else if (fighter.age <= 30)           → B2_prime
    else                                  → B3_older
  } else {
    // シーズン末引退
    if (fighter.role === 'Heel')          → A3_heel
    if (fighter.careerRecord.totalTitleWins > 0) → A1_champion
    if (fighter.careerSeasons >= 10)      → A4_veteran
    else                                  → A2_uncrowned
  }

  // カテゴリ内からランダム選択
  return randomPick(RETIREMENT_LINES[category]);
}
```

## 4. 実装フック

### 4.1 シーズン末引退

現在の `advanceWeek` offWeek 1 で引退者を `retiredFighters` に保存している（v1.3-2で実装済み）。ここにポップアップ表示のトリガーを追加：

```
advanceWeek (offWeek 1)
  → applySeasonEnd（成長・衰退）
  → 引退判定
  → retiredFighters に保存（v1.3-2で実装済み）
  → G.pendingRetirements = [...retirees]  ← NEW
  → refreshAll → 引退ポップアップ表示ループ
```

### 4.2 怪我引退

怪我処理（`Engine.injury` 内）で重傷判定時に追加チェック：

```
重傷発生
  → wear超過チェック (wear + 重傷ボーナス >= 80?)
  → 壊滅的怪我チェック (2〜3%, ベテランは5〜8%)
  → いずれかに該当 → fighter を roster から除去 + retiredFighters に追加
  → G.pendingInjuryRetirement = fighter  ← NEW
  → 興行結果表示後にポップアップ表示
```

### 4.3 王座返上の連動

怪我引退の選手がチャンピオンだった場合：
- `Engine.title.validateChampion` が自動的に王座空位にする
- ポップアップ内に「王座返上」の表示を追加

## 5. 殿堂級との演出差（v1.3-4）

当初は「格上げ対象に大演出」として別タスクだったが、**設計方針変更**:

- 引退演出は全選手共通の1種類
- 殿堂級の選手は**セリフが1行多い可能性がある程度**
- 殿堂入り発表は年末表彰式（ppv-awards-spec.md 参照）で行う
- よって v1.3-3 と v1.3-4 は統合して実装

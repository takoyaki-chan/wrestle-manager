## 設計原則

1. **trainCap距離ベース** — 予算配給ではなく「上限までの距離」が成長速度を決める。上限に近づくほど自然に減速する
2. **年齢は残酷** — 若いうちは伸び、ピークを過ぎると衰える。これは変えない
3. **コーチと環境が差を生む** — 同じ素質でもコーチ・練習強度・試合経験で到達度が変わる
4. **到達率91–92%が着地点** — ブレイクスルーなしでtrainCapの91–92%に収束する設計

---

## §1 核心式（練習成長）

```
statGrowth = baseLearning × (remaining / trainCap) × ageMul × coachMul × bonus × variance × intensiveMul
```

| 変数 | 説明 |
|------|------|
| `baseLearning` | **3.0** 🔧 |
| `remaining` | trainCap[stat] - current[stat] |
| `remaining / trainCap` | 自然逓減ブレーキ（上限接近で0に近づく） |
| `ageMul` | 年齢倍率（§2） |
| `coachMul` | コーチ倍率（§3） |
| `bonus` | 特性ボーナス（§4） |
| `variance` | 週次ランダム揺れ（§5） |
| `intensiveMul` | 追い込み倍率（§6） |

---

## §2 年齢倍率（ageMul）

年齢に応じた成長効率の変化。

| 年齢帯 | 倍率 | 意味 |
|--------|------|------|
| 16–18 | 1.3–1.1 | 成長期（伸びやすい） |
| 19–21 | 1.0 | 標準期 |
| 22–24 | 0.85–0.70 | 減速期 |
| 25–27 | 0.55–0.35 | 衰退開始 |
| 28+ | 0.25以下 | 老年期（ほぼ伸びない） |

## §7 試合成長

### §7.1 計算式

```
matchGrowth = (matchGrowthBase + opponentBonus + closeMatchBonus + resultBonus + coachMatchBonus) × ageMul
```

### §7.2 各要素

| 要素 | 計算 | 範囲 |
|------|------|------|
| matchGrowthBase | **0.5** 🔧 | 固定 |
| opponentBonus | clamp((oppOVR - selfOVR) / 15, -0.2, 0.5) | 格上ほど大きい |
| closeMatchBonus | MQ ≥ 65 → **0.3** 🔧, else 0 | 好試合で成長 |
| resultBonus | 敗北 → **0.2** 🔧, else 0 | 負けから学ぶ |
| coachMatchBonus | コーチの試合成長ボーナス | コーチ依存 |

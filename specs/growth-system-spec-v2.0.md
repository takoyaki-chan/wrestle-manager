## 設計原則

1. **trainCap距離ベース** — 予算配給ではなく「上限までの距離」が成長速度を決める。上限に近づくほど自然に減速する
2. **年齢は残酷** — 若いうちは伸び、ピークを過ぎると衰える。これは変えない
3. **コーチと環境が差を生む** — 同じ素質でもコーチ・練習強度・試合経験で到達度が変わる
4. **到達率91–92%が着地点** — ブレイクスルーなしでtrainCapの91–92%に収束する設計

## §1 核心式（練習成長）

```
statGrowth = baseLearning × (remaining / trainCap) × ageMul × coachMul × bonus × variance × intensiveMul
```

| 変数 | 説明 |
|------|------|
| `baseLearning` | **3.0** 🔧 |
| `remaining` | trainCap[stat] - current[stat] |
| `remaining / trainCap` | 自然逓減ブレーキ（上限接近で0に近づく） |
| `ageMul` | 年齢倍率（§2） |
| `coachMul` | コーチ倍率（§3） |
| `bonus` | 特性ボーナス（§4） |
| `variance` | 週次ランダム揺れ（§5） |
| `intensiveMul` | 追い込み倍率（§6） |

### §6.1 追い込みの代償 — 消耗（growth-rebalance v1.0 / 2026-07-26 確定）

追い込みは**効きが逓減しない**。代わりに**選手の消耗（wear）**として代償を払う。
逓減だけだと「効率が悪くなるので待てば済む」になり判断が生まれないため、
「この子を今燃やすか、長く使うか」という選択に変えるのが設計意図。

`seasonIntensiveWeeks`（シーズン内の追い込み週数・**非連続**で積算）を主軸に、
`decayStartAge`（= `23 + 実効耐久`、実効耐久は **−3〜+3 に丸められる**ので **20〜26歳**）の
前後で扱いを変える。

| 時期 | 挙動 | 定数 |
|---|---|---|
| `decayStartAge` **到達前** | wear には一切載せず、**`strainDebt`（隠れた負債）として溜める**。この間プレイヤーには何の兆候も出ない | `strainDebtPerIntensiveWeek: 0.25` |
| `decayStartAge` **初到達シーズン** | 溜まった `strainDebt` を **wear へ一括清算**し、`strainDebt` を 0 に戻す | — |
| `decayStartAge` **到達後** | そのシーズンの追い込み週数に比例して wear を加算 | `intensiveWearPerWeek: 0.15` |

- 清算は `prevAge < decayStartAge` の**初到達シーズンのみ**。毎年二重に払わせない
- 延命術コーチの `getWearMult`（×0.50）は `strainDebt` 清算分にも掛かる
- 追い込み中の練習負傷は `seasonInjuries` に計上され、`wearBonus += seasonInjuries × 2` として消耗に載る。**自団体・AI団体の両方で計上する**（2026-07-26 まで自団体だけ数え落としていた）

**AI団体は追い込みの消耗を払わない（意図的・2026-07-26 Keisuke 裁定）**

AI団体の週次練習は `seasonIntensiveWeeks` を積まないため、AI選手は追い込みを重ねても
`wear` / `strainDebt` が増えない。**この代償を払うのは自団体だけ**。

対称にすればAI選手の選手寿命が縮み、リーグ全体の年齢構成が変わる。
現行のゲームバランスに問題が無いため、**あえて対称にしない**。
バグではないので直さないこと。変えるならリーグ全体の再計測とセット。

**係数の根拠**: 40シーズン×2シード×4候補の実測。全員を毎週追い込む最大乱用コホートで
引退年齢の中央値が 26.6歳 → **24.5歳**、キャリア長 9.0 → **7.0シーズン（−22%）**。
`0.35/0.6` 以上は飽和して `0.5/0.85` と区別がつかなくなるため採用しない。

### §6.2 プレイヤーへの伝え方

数値は**一切表に出さない**。伝わる経路は3つだけ。

1. **コーチの匂わせセリフ** — 対象選手が「シーズン8週以上追い込まれている」か「練習負傷中」のとき、コーチ観察レポートを 35% で `strain_vague` / `strain_named` / `strain_injured` に差し替える（`COACH_VOICE_REPORT_LINES`、8系統×3種＝48本）。**道場バナーの頭上吹き出し**に出る。実測でシーズンあたり 0.9〜2.4回、常用していなければ 0回。観察眼の誤認（`isInaccurate`）は適用しない
2. **⚡ボタンのツールチップ** — 押す前に代償が分かるようにする
3. **ヘルプ「峠と引退」** — 「若いうちは何も起きず、峠にさしかかった年に一度に返ってくる」構造の説明

**既知の課題（未解決）**: 成長は3〜5年でカンストする一方 `decayStartAge` は中央値24歳のため、
**全盛期の窓がほとんど無い**。係数では解決しない構造問題として別途起票済み（ロードマップ参照）。

## §7 試合成長

### §7.1 計算式

```
matchGrowth = (matchGrowthBase + opponentBonus + closeMatchBonus + resultBonus + coachMatchBonus) × ageMul
```

### §7.2 各要素

| 要素 | 計算 | 範囲 |
|------|------|------|
| matchGrowthBase | **0.5** 🔧 | 固定 |
| opponentBonus | clamp((oppOVR - selfOVR) / 15, -0.2, 0.5) | 格上ほど大きい |
| closeMatchBonus | MQ ≥ 65 → **0.3** 🔧, else 0 | 好試合で成長 |
| resultBonus | 敗北 → **0.2** 🔧, else 0 | 負けから学ぶ |
| coachMatchBonus | コーチの試合成長ボーナス | コーチ依存 |

## 設計原則

1. **会場は選ぶもの** — popReqを撤廃。どの会場でも選べるが、ガラガラのリスクを負う
2. **カードが客を呼ぶ** — 試合カードの魅力（因縁・実力差・初顔合わせ）が集客を左右する
3. **勢いは伝播する** — 満員が続けば勢いがつき、ガラガラが続けば客足が遠のく
4. **正確な予測はさせない** — プレイヤーには「ざっくり予測」のみ。数字のスプレッドシート化を防ぐ

## §4 興行全体の集客力（Show Draw）

### §4.1 ポジション重み

| 位置 | 重み 🔧 |
|------|:------:|
| メイン | 1.0 |
| セミ | 0.7 |
| 第3試合 | 0.5 |
| 以降 | 0.35 |

### §4.2 計算式

```
showDraw = Σ(appeal × positionWeight) + nonMatchPromo × 2
```

試合不足ペナルティ:
- 2試合以上不足: × **0.70** 🔧
- 1試合不足: × **0.85**

# 🎭 特殊試合形式オプション設計書 v0.1

> **ステータス**: 🟠 ドラフト（議論用）
> **作成日**: 2026-04-16
> **位置付け**: 通常興行のカード編成時に選択可能な試合形式。特別興行ではない
> **依存（予定）**: weekly-gameloop-spec-v1.0 / battle-engine-spec-v4.2 / tag-match-system-spec-v0.1

---

## 設計原則

1. **通常興行で使える戦略オプション** — 年1回の特別興行ではなく、プレイヤーが興行ごとに選べる試合形式
2. **使い所の判断がゲームになる** — 使用制限＋リスクとリターンで、無闇に使えない設計
3. **personality・スタイルに意味が出る** — 各形式ごとに有利な選手タイプが異なり、ロスターの多様性が価値になる
4. **MQ・集客での差別化** — 特殊形式は集客ボーナスがあるが、編成制約がある

---

## §1 実装する3形式

| 形式 | 概要 | 1興行の使用上限 🔧 |
|------|------|:----------------:|
| アイアンマッチ（60分1本勝負） | 時間制限付き、フォール数勝負 | 1試合まで |
| ハードコア＋ケージ | 融合型。ヒール選手有利イベント発生 | 1試合まで |
| 6人タッグエリミネーション | 3対3、勝ち残り式 | 1試合まで（タッグシステム必須） |

すべて**メイン or セミファイナル限定**で使用可能（アンダーカード不可）。

---

## §2 アイアンマッチ（60分1本勝負）

### §2.1 ルール

| 項目 | 仕様案 |
|------|------|
| 試合時間 | 60分固定 🔧 |
| 勝敗 | フォール・サブミッション・反則を複数回取得可能。60分経過時点でフォール数が多い方の勝ち |
| 引き分け | 同数の場合は引き分け（タイトルマッチ扱いなら王者防衛） |
| 消耗 | 通常の **×1.5** 🔧（消耗激化） |

### §2.2 ステータス影響

- **STA（スタミナ）・MNT（メンタル）の重要度が大幅UP**
- STAが低い選手は後半で一気にペース崩壊
- MNTが低い選手は接戦でミスを誘発

### §2.3 ボーナス 🔧

| 項目 | 値 |
|------|---|
| MQ基本ボーナス | +10 |
| 集客ボーナス | ×1.2 |
| タイトルマッチと重複可 | ○ |

### §2.4 制約

| 制約 | 仕様 |
|------|------|
| 出場選手condition | **70以上必須** 🔧 |
| 年齢 | 制限なし（ただしベテランは不利） |
| 使用頻度 | 1興行1試合、シーズン最大**6試合** 🔧（濫用防止） |

## §3 ハードコア＋ケージ（融合型）

### §3.1 ルール

| 項目 | 仕様案 |
|------|------|
| 会場設定 | ケージ内、反則解禁、凶器使用可 |
| 審判 | **介入判定が大幅弱体化** 🔧 |
| 勝利条件 | フォール・サブミッション・TKO |
| 消耗 | 通常の **×1.4** 🔧 |

### §3.2 ヒール選手有利イベント

試合中に一定確率でトリガーされる特殊イベント：

| イベント | 発生条件 | 効果 |
|---------|---------|------|
| 凶器持ち込み | ヒール側、MNT判定成功 | ダメージ+、審判見落とし判定 |
| セコンド乱入 | ヒール側、bond高いセコンド所持 | 2-on-1状態、ベビー不利 |
| ケージ外放出 | ヒール側、PWR判定成功 | ベビーのコンディション大幅低下 |
| 反則連発 | ヒール選手のpersonality=bold/emotional | 審判カウント遅延、フォール有利 |

personality別確率 🔧:
- `bold`, `emotional`: ヒールイベント発生率 ×1.5
- `earnest`, `shy`: ×0.5（性格的にラフ戦向いてない）

### §3.3 ボーナス 🔧

| 項目 | 値 |
|------|---|
| MQ基本ボーナス | +8 |
| 集客ボーナス | ×1.25 |
| 因縁決着補正 | rivalry ≥ 2 の試合なら MQ+5 |

### §3.4 制約

| 制約 | 仕様 |
|------|------|
| 出場選手 | 必ず1名はヒール寄りpersonality（bold/emotional/quiet）を含む |
| 怪我リスク | **通常の×1.5** 🔧（ケージ外放出で軽傷〜中傷判定） |
| 使用頻度 | 1興行1試合、シーズン最大**4試合** 🔧 |

## §4 6人タッグエリミネーション

### §4.1 ルール

| 項目 | 仕様案 |
|------|------|
| 人数 | 3対3 |
| 形式 | フォール・サブミッションで1名ずつ脱落。先に相手3名全滅したチームの勝ち |
| 試合時間 | 時間制限なし（全員脱落まで） |
| エンジン | タッグマッチエンジン（tag-match-system-spec）を6人対応に拡張 |
| 消耗 | 通常の **×1.3** 🔧 |

### §4.2 ステータス影響

- **タッチ・介入の戦略性が増大**（3人体制で逃げ場が多い）
- **ケミストリー（3名平均bond）の重要度UP**
- エースが残り2名を抜くホットフィニッシュ展開

### §4.3 ボーナス 🔧

| 項目 | 値 |
|------|---|
| MQ基本ボーナス | +12 |
| 集客ボーナス | ×1.3 |
| 「最後の1人残し勝利」発生時 | 残留者の人気+5、MQ+3 |

### §4.4 制約

| 制約 | 仕様 |
|------|------|
| 出場人数 | 6名（自団体のみ or 自団体+フリー選手混成） |
| タッグシステム | 本実装必須（現状v0.1） |
| 使用頻度 | 1興行1試合、シーズン最大**3試合** 🔧 |

## §5 カード編成UI

### §5.1 試合枠ごとのオプション選択

興行準備画面で、試合枠ごとに形式を選択：

```
【試合 #5 (メインイベント)】
選手: 山田 vs 佐藤
形式: [通常 ▼] 
       通常
       ★アイアンマッチ（残り5回）
       ★ハードコア+ケージ（残り3回）
       ★6人タッグエリミ（要6名、残り2回）
```

### §5.2 警告表示

- condition不足 → 赤字警告
- personality条件不満 → 黄字注意
- シーズン使用上限 → 選択不可

### §5.3 推奨カード連動

- rivalry≥2の因縁カード → 「ハードコア+ケージ」を推奨
- タイトルマッチ候補 → 「アイアンマッチ」を推奨
- 団体内派閥抗争 → 「6人タッグエリミ」を推奨

## §6 未決定事項・論点

### 🔴 前提条件の論点

- [ ] **タッグシステム本実装の優先順位** — 6人タッグエリミは前提条件として必須
- [ ] **シーズン使用上限の妥当性** — アイアン6/ケージ4/6人タッグ3 はバランス要検証
- [ ] **既存バトルエンジンへの拡張規模** — アイアンマンは時間制ルール追加、ケージは介入判定改修、6人タッグは大規模拡張

### 🟡 バランス論点

- [ ] MQボーナス値（+10/+8/+12）は適切か
- [ ] 集客ボーナス（×1.2/×1.25/×1.3）は適切か
- [ ] ハードコアのpersonality別倍率（×1.5/×0.5）の開き
- [ ] 怪我リスク×1.5は厳しすぎないか

### 🟡 追加検討候補

- [ ] **金網マッチ以外のハードコア亜種**（街道マッチ、電流爆破など）
- [ ] **ランバージャックマッチ**（ロスター全員がリング外で乱入阻止）
- [ ] **30分1本勝負の短縮版アイアン**（中堅レベルで使える）
- [ ] **ノンタイトル混合**（タイトルマッチ以外で特殊形式を許容するか）

### 🟡 UI論点

- [ ] 使用回数の可視化（シーズン通しての残り回数表示）
- [ ] 試合形式のロック/解放条件（orgPop連動など）
- [ ] 過去使用履歴の参照（どの選手がどの形式でどう戦ったか）

## §9 将来の温存案（メモ）

ブレスト時に出た案で、今回は採用しないもの：

- **OVR制限トーナメント** — 「人気得点 + 人気÷OVR 係数」の合算上位8名を選ぶ中堅スター大会。第3の特別興行候補として温存
- **3対3ガントレット** — 勝ち抜き団体戦。対抗戦(rivalry war)と被るため一旦保留
- **バトルロイヤル** — システム設計が重く、システム検討から必要
- **レジェンド復帰興行** — 引退選手データの保持が前提

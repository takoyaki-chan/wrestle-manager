## 設計原則

1. **trainCap距離ベース** — 予算配給ではなく「上限までの距離」が成長速度を決める。上限に近づくほど、指数ブレーキによりさらに重くなる
2. **年齢は残酷** — 若いうちは伸び、ピークを過ぎると衰える。これは変えない
3. **コーチと環境が差を生む** — 同じ素質でもコーチ・練習強度・試合経験で到達度が変わる
4. **能動カンストを抑える** — 放置層を一律に底上げせず、上限接近時と追い込み連用時の上振れを抑える
5. **業界一律** — 共通成長式のためAIにも指数ブレーキが適用され、AIトップ層のOVR低下は意図的な変更である（Keisuke承認済み）

## §1 核心式（練習成長）

`GROWTH_CONFIG.brakeGamma` は **1.3**。`remaining = trainCap - current`、`current < trainCap` のとき、実装は次の順で計算する。

```
ratio        = (remaining / trainCap) ^ 1.3
baseGain     = 3.0 × ratio × ageMul × coachMul × rookieMul × gritMul
rawGain      = baseGain × bonus × weeklyVariance
intensiveMul = intensiveHeatTable[_heat]（追い込み時のみ。_heat 未設定は 0）
finalGain    = max(0, round(rawGain × intensiveMul × 10) / 10)
statGrowth   = min(ceil(finalGain), trainCap - current)
```

追い込みでない場合の `intensiveMul` は **1.0**。`brakeGamma === 1.0` のときだけ旧互換として `remaining / trainCap` をそのまま使うが、現行値は **1.3** である。

| 変数 | 説明 |
|------|------|
| `baseLearning` | **3.0** 🔧 |
| `remaining` | trainCap[stat] - current[stat] |
| `(remaining / trainCap) ^ 1.3` | 指数収束ブレーキ。旧v2.0の線形 `remaining / trainCap` より上限接近時の成長を強く抑える |
| `ageMul` | 年齢倍率（§2） |
| `coachMul` | コーチ倍率（§3） |
| `rookieMul` | 新人育成の倍率（§3.2） |
| `gritMul` | 根性練習の倍率（§3.2） |
| `bonus` | 特性ボーナス（§4） |
| `weeklyVariance` | 週次ランダム揺れ（§5） |
| `intensiveMul` | 追い込み倍率。自団体では熱量テーブル（§6） |

練習成長後には、状態・環境に応じて `growthPenalty`、スランプ／モチベーション喪失、絶好調、合宿、専属トレーナー、孤立、関係性、警告trustの各乗算が適用される（§8）。

## §2 年齢倍率（ageMul）

年齢に応じた成長効率の変化。以下は特性による専用テーブル上書きがない場合の実装値であり、**実装を正とする**。

| 年齢 | 特性なしの実装値 |
|------|-------:|
| 17歳以下 | 0.70 |
| 18歳 | 1.00 |
| 19–20歳 | 1.15 |
| 21–22歳 | 1.00 |
| 23–24歳 | 0.50 |
| 25–26歳 | 0.10 |
| 27歳以上 | 0.00 |

`早熟`、`晩成`、`遅咲き` はそれぞれ専用の年齢テーブルでこの値を上書きする。放置層（AI・非注力選手）の底上げは行わず、年齢減衰カーブの挙動を変更して旧v2.0との乖離を是正することもしない。これは「下位が育たないことは不満にならない」とする Keisuke 裁定（2026-07-30）であり、将来の変更は別途再計測を要する。

|------|------|

### §6.1 追い込みの熱量逓減（v2.1）

自団体選手の追い込みでは、成長計算時点の `_heat` をテーブル添字として使う。`_heat` が未設定なら 0 として扱うため、最初の追い込みは **×1.8**、以降は **×1.6 → ×1.4 → ×1.2 → ×1.0** と低下する。`_heat` はテーブル末尾の添字 4 を超えない。

| 行動 | `_heat` の更新 | 成長倍率への影響 |
|------|----------------|------------------|
| 追い込み | `min(_heat + 1, 4)` | 更新前の添字を使う。最初は×1.8 |
| 通常練習 | `max(0, _heat - 1)` | 次回追い込みの効きが1段階回復 |
| 休養 | `max(0, _heat - 2)` | 次回追い込みの効きが2段階回復 |
| プロモ、怪我、休暇、レンタル | 更新なし | `_heat` は変化しない |

逓減するのは**成長効果だけ**である。追い込みごとの負傷判定、コンディション消耗、`seasonIntensiveWeeks` の加算は熱量によって減額しない。したがって、§6.2 の `wear` / `strainDebt` の代償も満額で積算される。連打だけが最適にならず、間欠運用を選択肢にする設計である。

**未実装の可視化**: `_heat` の値も、効きが落ちている事実も、現状はプレイヤーに一切見えない。数値を表示せず、将来は道場コメントと選手の顔つきで「体が重そうだ」と仄めかす方針だが、セリフ起案・表示は別タスクであり未実装である。

AI団体の `processAIWeek` は `_heat` を更新せず、AI追い込みの追加倍率には `intensiveMult` の **×1.8** を用いる。一方で、AIも `calcGrowth` を通るため、§1 の指数収束ブレーキは適用される。

### §6.2 追い込みの代償 — 消耗（growth-rebalance v1.0 / 2026-07-26 確定）

`seasonIntensiveWeeks`（シーズン内の追い込み週数・**非連続**で積算）を主軸に、`decayStartAge`（= `23 + 実効耐久`、実効耐久は **−3〜+3 に丸められる**ので **20〜26歳**）の前後で扱いを変える。

| 時期 | 挙動 | 定数 |
|---|---|---|
| `decayStartAge` 到達前 | wear には載せず、`strainDebt` として溜める | `strainDebtPerIntensiveWeek: 0.25` |
| `decayStartAge` 初到達シーズン | 溜まった `strainDebt` をwearへ一括清算し、`strainDebt` を0に戻す | — |
| `decayStartAge` 到達後 | そのシーズンの追い込み週数に比例してwearを加算 | `intensiveWearPerWeek: 0.15` |

- 清算は `prevAge < decayStartAge` の初到達シーズンのみ。毎年二重に払わせない
- 延命術コーチの `getWearMult`（×0.50）は `strainDebt` 清算分にも掛かる
- 追い込み中の練習負傷は `seasonInjuries` に計上され、`wearBonus += seasonInjuries × 2` として消耗に載る。自団体・AI団体の両方で計上する
- AI団体の週次練習は `seasonIntensiveWeeks` を積まないため、AI選手は追い込み由来の `wear` / `strainDebt` を負わない。この非対称は意図的であり、バグとして是正しない

### §6.3 AI団体の活動wear（v2.1）

AI選手は季末処理で加齢し、`age >= 23 + 実効耐久` のとき、既存の基礎wear等に加えて次を加算する。

```
aiMatchWear = round((wins + losses + draws) × 0.05)
```

`aiMatchWearCoef` は **0.05**。これはプレイヤーの活動由来wearの**3〜6割相当**に留める。AIはケア・休養管理ができないため、プレイヤーと同格の活動wearを負わせてライバルが自壊することを避けるためである。

## §7 試合成長

### §7.1 計算式

```
matchGrowth = (matchGrowthBase + opponentBonus + closeMatchBonus + resultBonus + coachMatchBonus) × ageMul
```

### §7.2 各要素

| 要素 | 計算 | 範囲 |
|------|------|------|
| matchGrowthBase | **0.5** 🔧 | 固定 |
| opponentBonus | clamp((oppOVR - selfOVR) / 15, -0.2, 0.5) | 格上ほど大きい |
| closeMatchBonus | MQ ≥ 65 → **0.3** 🔧, else 0 | 好試合で成長 |
| resultBonus | 敗北 → **0.2** 🔧, else 0 | 負けから学ぶ |
| coachMatchBonus | コーチの試合成長ボーナス | コーチ依存 |

## 設計原則

1. **Bond/Rivalry だけでも対立は起きる** — moraleや trustは背景の増幅係数に過ぎず、派閥と対立の主軸はペア関係（Bond/Rivalry）の集約
2. **派閥は物語装置、最適化対象ではない** — 数値効果は控えめに、ドラマの起点としての役割を重視
3. **数値は嘘をつかない** — 派閥は既存の bond/rivalry から自然に浮かび上がるクラスタであり、勝手に作られた概念ではない
4. **数値は見せない、帯とフレーバーで見せる** — 対立度・勢いは内部値、UI にはフレーバー表現のみ
5. **リーダー・幹部クラスの対決でのみ盛り上がる** — 末端同士の対立は効果を持たない。「強い選手同士の抗争」が派閥を意味あるものにする
6. **既存バランスを壊さない** — appeal加算は排他・キャップで制御し、rivalry/タイトル/派閥の重複による暴走を防ぐ

## §1 データモデル

### §1.1 派閥（Faction）

```
GameState.factions = [
  {
    id: number,                      // 派閥ID（連番）
    name: string,                    // 「○○組」リーダー名ベース
    leaderId: number,                // リーダーの fighter.id
    memberIds: number[],             // 全メンバーの fighter.id（leader含む）
    type: 'loyal' | 'rivalrous',     // 忠誠型 / 対立型（対立相手がいる）
    authoritativeTag: boolean,       // F01でAを選んで結成された場合 true（権威化）
    dictatorTag: boolean,            // F07でAを複数回選んだ場合 true（独裁化）
    momentum: number,                // 勢い -100〜+100
    createdSeason: number,
    createdWeek: number,
    lastLeaderChangeSeason: number,  // 後継発生時の更新用
    lastLeaderChangeWeek: number,
  },
  ...
]
```

### §1.2 対立度（Hostility）

**矢印モデル（非対称）**: 派閥A→B と B→A を別々に持つ。

```
GameState.factionHostility = {
  "fA>fB": 60,   // 派閥Aから派閥Bへの敵意
  "fB>fA": 45,   // 派閥Bから派閥Aへの敵意
  ...
}
```

| 帯 | 範囲 | フレーバー |
|----|------|-----------|
| 冷え込み | 0–19 | 表面的には無関心 |
| 小競り合い | 20–39 | たまに衝突する程度 |
| 抗争 | 40–59 | 明確な敵対関係 |
| 泥沼 | 60–79 | 憎悪が日常化 |
| 血みどろ | 80–100 | 殲滅戦 |

### §1.3 勢い（Momentum）

派閥ごとに独立（ペアではない）。-100〜+100 の符号付き整数。

| 帯 | 範囲 | フレーバー |
|----|------|-----------|
| 隆盛 | +60以上 | 乗りに乗っている |
| 上昇 | +30〜+59 | 勢いが増している |
| 平常 | -29〜+29 | 標準 |
| 陰り | -59〜-30 | 陰りが見える |
| 衰退 | -60以下 | 崩壊寸前 |

### §1.4 イベントクールダウン

```
GameState.factionEventCooldowns = {
  "F04:fA>fB": { lastTriggeredWeek: number },
  "F05:fA": { lastTriggeredWeek: number },
  ...
}
```

## §2 検出・ライフサイクル

### §2.1 発生条件（発生イベントが発動することで顕在化）

常時自動検出ではない。週次で発生チェックを走らせ、条件を満たすと発生イベントをキューに積む。

**忠誠型発生（F01）発火条件:**
- 自団体ロスターが **10人超** 🔧
- 現在の派閥数が **0**
- OVRトップ3のいずれかを核に、その選手から bond **60以上** 🔧 のフォロワーが **2人以上**（※ v0.2 閾値変更: 65→60。実測bond分布が50後半〜60台に張り付いており、65だと13年プレイでも発生しないため）
- 週次チェックで **60%** 🔧 の確率でイベント発動

**対立型発生（F02）発火条件:**
- 自団体ロスターが **10人超**
- 現在の派閥数が **0 または 1**
- 相互 bond **55以上** 🔧 のクラスタが2つ同時存在し、クラスタ間の平均 rivalry が **40以上** 🔧（※ v0.2 閾値変更: 60→55）
- 週次チェックで **80%** 🔧 の確率でイベント発動

### §2.2 メンバー加入

派閥存在時、週次で以下を判定:

- 対象: 無派閥選手（ロスターに所属、派閥未所属）
- 条件: 既存メンバーとの **平均bond が 60以上** 🔧 になった選手
- 発動: 条件を満たした選手ごとに、該当 bond 平均値に応じた確率で加入
  - bond 60〜69: 20%/週 🔧
  - bond 70〜79: 40%/週 🔧
  - bond 80以上: 60%/週 🔧
- 勢いによる修正（対立型のみ）:
  - 派閥の勢い +30超: 加入率 ×1.5 🔧
  - 派閥の勢い -30未満: 加入率 ×0.7 🔧
- UI通知: ログに静かに「○○が○○組に加わったようだ」

### §2.3 メンバー離脱（寝返り以外）

週次で以下を判定:

- 条件: リーダーへのbondが **40未満** 🔧 に低下
- 発動率: 10%/週 🔧
- 勢いによる修正（対立型のみ）:
  - 派閥の勢い -30未満: 離脱率 ×1.5 🔧
  - 派閥の勢い -60未満: 離脱率 ×2.0 🔧、さらにメンバー全員 trust -0.3/週追加 🔧

### §2.4 メンバー消滅

- メンバー数が **3人未満** になった派閥は自動消滅
- 対立派閥があった場合、その派閥の勢い -3〜-5（張り合いを失う）
- 消滅は即時、通知のみ（演出イベントはなし）

### §2.5 リーダー喪失時の後継判定

リーダーが退団・引退・長期離脱（8週以上の重傷等）のいずれかになった時点で F03 を発動。§9.3 を参照。

### §2.6 派閥制度の解散

1つの派閥がロスターの **80%以上** 🔧 を占めた場合、派閥制度そのものを解散:

- 全派閥を消滅させる
- 対立度・勢いをクリア
- authoritativeTag / dictatorTag もクリア
- 通知: 「派閥は事実上、団体そのものとなった。派閥という区分は意味を失った」
- §2.1 の発生条件を再び満たした時点で、新たに派閥が発生しうる

## §3 属性決定ルール

### §3.1 リーダー

派閥内 **OVR最上位** の選手。

### §3.2 幹部

リーダーを除いた派閥内 **OVR上位2人**。合計で派閥の「顔役」は3人（リーダー＋幹部2名）。

### §3.3 派閥名

リーダー名をベースに「○○組」形式で自動生成。リーダーが交代した場合は派閥名も更新される。

### §3.4 派閥類型

強く分類しない。基本は「リーダー+子分」の構造で、メンバーの年齢分布やスタイルは副次的情報。類型ごとの特殊効果は設けない。

## §4 対立度の変動ルール

### §4.1 初期化

対立型派閥が成立した時点で、A→B と B→A の対立度を初期化:

- F01からの発展（忠誠型→対立型）: 平均rivalry値をそのまま採用（対称的、中庸）
- F02発生イベント:
  - C（調停）: A→B と B→A を **30〜45** 🔧（対称、低め）
  - A/B（肩入れ）: 肩入れされた側への敵意を高める（矢印非対称）
    - 支持された側→敵対派閥: **55〜70** 🔧
    - 敵対派閥→支持された側: **65〜80** 🔧
  - D（静観）: 平均rivalry値（対称、中庸）

### §4.2 週次変動

**上昇要因:**

| 要因 | 変動量 🔧 | 方向 |
|------|---------|------|
| 派閥幹部級試合で敗北 | 敗者派閥→勝者派閥 **+3〜+5** | 矢印 |
| 派閥リーダー同士の試合で敗北 | 敗者派閥→勝者派閥 **+3〜+5**（上記に追加） | 矢印 |
| D-F系列シリアスイベント（F04/F07/F08） | **+5〜+15** | イベントごとに指定 |

**減衰要因:**

| 要因 | 変動量 🔧 | 方向 |
|------|---------|------|
| 時間減衰 | **-0.3/週** | 両方向 |
| 派閥間メンバー平均bondが50超 | 追加 **-0.3/週** | 両方向 |
| リーダー交代（F03継承） | 現値 **×0.7** | 両方向（世代交代で希薄化） |

末端メンバー同士の試合は対立度に影響しない（代表戦ではない）。

### §4.3 効果

| 対立度（両方向の平均） | 効果 |
|-------------------|------|
| 40+ | 派閥抗争マッチ属性の集客加算発動 +5 appeal 🔧 |
| 60+ | 集客加算 +10 appeal 🔧、寝返り率 ×0.7（忠誠心強化） 🔧 |
| 80+ | F08対立ヒートアップイベントの発動条件解放 |
| 20未満 | F06和解イベントの発動条件解放 |

## §5 勢いの変動ルール

### §5.1 初期化

派閥成立時、勢い = 0。F02発生イベントでの初期修正は §9.2 を参照。

### §5.2 週次変動

| 要因 | 変動量 🔧 |
|------|---------|
| 幹部級試合で勝利 | 勝者派閥 **+8〜+12**、敗者派閥 **-8〜-12** |
| リーダー同士の試合で勝利 | 勝者派閥 **+15〜+20**、敗者派閥 **-15〜-20** |
| 時間減衰 | 絶対値を0方向へ **-1.0/週** |

末端メンバーの試合は勢いに影響しない。

### §5.3 効果（対立型派閥のみ適用）

| 勢い | 効果 |
|------|------|
| +30超 | 無派閥選手の加入率 ×1.5 🔧、メンバー離脱率 ×0.7 |
| +60超 | さらに加入率補正、敵対派閥メンバーが寝返り候補化（F04の条件成立確率+） |
| -30未満 | 離脱率 ×1.5 🔧、加入率 ×0.7 |
| -60未満 | 離脱率 ×2.0、メンバー trust 追加減衰 **-0.3/週** 🔧（沈む船） |

忠誠型派閥には勢い概念を適用しない（敵対派閥が存在する場合のみ意味を持つ）。

## §6 派閥抗争マッチ（集客加算）

### §6.1 適用条件

既存の因縁カードの**追加属性**として機能。新規の試合カテゴリは作らない。

- 両者が異なる派閥に所属
- 両者がそれぞれの派閥の **リーダーまたは幹部**（§3参照）
- 派閥間の対立度（両方向の平均）が **40以上**

上記すべてを満たす場合のみ、「派閥代表戦」タグが自動付与される。

### §6.2 加算値

| 対立度（両方向の平均） | 加算 appeal 🔧 |
|-------------------|-------------|
| 40〜59 | +5 |
| 60〜79 | +10 |
| 80以上（通常時） | +10 |
| 80以上 + F08対決として発動 | +15〜+20（§9.8参照） |

MQ加算は一切しない。

### §6.3 重複制御ルール

**案A（排他）＋キャップ**で制御:

1. **派閥抗争appealと rivalry appeal は排他**: 同じ試合で重複した場合、`max(rivalryAppeal, 派閥抗争appeal)` のみ採用
2. **F08直接対決ボーナス**は上記とは別枠で加算されるが、タイトル戦と同時発動時は ×0.5
3. **因縁系ボーナス合計の上限キャップ**: rivalry + 派閥 + F08 の合計が **+30** 🔧 を超えた場合、30に丸める
   - 乱闘蓄積（pendingClashBonus）は別枠として扱い、このキャップには含めない
   - タイトル戦・ファン期待・初顔合わせも別枠

### §6.4 計算順序（calcMatchAppeal 内）

既存の calcMatchAppeal に以下を追加:

1. rivalry appeal を算出（既存）
2. 派閥抗争条件を判定し、派閥 appeal を算出
3. F08発動中の試合なら F08ボーナスを算出、タイトル戦との同時発動なら ×0.5
4. **排他処理**: `rivalryAppealEffective = max(rivalryAppeal, 派閥抗争appeal)`
5. **キャップ処理**: `feudSum = rivalryAppealEffective + F08ボーナス` を +30でクランプ
6. 他のappeal要素（タイトル、ファン期待、初顔合わせ、乱闘、ヒールvsベビー、OVR拮抗）を加算
7. totalAppeal を返す

## §7 UI仕様（案X: 団体タブ＋データベース分散）

選手名の下に、派閥所属を小さくテキスト表示:

- 無派閥: 「中立」または表示なし

数値は一切出さない。

## §8 D系列独立枠（イベント発動制御）

### §8.1 B系列との分離

既存のB系列大型イベント（B1〜B4、発生率2.5%/週、クールダウン8週）とは別の **D系列独立枠** として派閥イベントを管理。

理由: 派閥イベントは条件成立時に必ず発火すべき種類のイベントであり、B系列のランダム抽選枠に入れると条件を満たしても他イベントに負けて発動しないケースが生じる。

### §8.2 発動制御

| イベントID | 条件成立後の発動率 🔧 | クールダウン 🔧 | 備考 |
|----------|-------------------|--------------|------|
| F01 忠誠型結成 | 60%/週 | なし（一度限り） | 派閥0時のみ |
| F02 対立型結成 | 80%/週 | なし | 派閥0または1時 |
| F03 リーダー喪失 | 即時発動 | なし | 喪失時自動 |
| F04 寝返り | 30%/週 | 12週 | ペアごと |
| F05 派閥内亀裂 | 40%/週 | 12週 | 派閥ごと |
| F06 和解の兆し | 50%/週 | 16週 | 派閥ペアごと |
| F07 リーダーの横暴 | 40%/週 | 12週 | 派閥ごと |
| F08 対立ヒートアップ | 50%/週 | 24週 | 派閥ペアごと |

### §8.3 競合解決

同じ週に複数のFイベント条件が成立した場合、以下の優先順位で1つだけ発動:

1. F03（リーダー喪失、最優先）
2. F08（対立ヒートアップ、緊急性）
3. F04（寝返り）
4. F05（派閥内亀裂）
5. F07（リーダー横暴）
6. F06（和解）
7. F01/F02（結成は派閥0の場合のみ、自然と競合しない）

## §9 D-F系列イベントカタログ

### §9.1 F01 忠誠型結成

**発火条件**: §2.1 の忠誠型発生条件を満たす。

**ドラマ**: ロッカールームで、ある選手の周りに自然と子分たちが集まっている。リーダー格が場を仕切り、周囲がそれに従う空気ができつつある。

**演出**: 中量版（4シーン＋結果演出）

- シーン1: ロッカールーム導入、ナレーション
- シーン2: リーダーのセリフ（性格×アーキタイプで分岐、最低8パターン）
- シーン3: フォロワー1〜2人のセリフ
- シーン4: 社長の判断（選択肢）
- シーン5: 結果演出

**選択肢と効果:**

| 選択 | 効果 |
|------|------|
| A: リーダーを正式に立てる | リーダー trust **+5〜+8**、派閥成立、メンバー間bond **+3〜+5**、**authoritativeTag** 付与、ロッカールーム士気 **-2〜-4** |
| B: 今はそれどころじゃないと釘を刺す | リーダー trust **-5〜-8**、派閥成立せず、フォロワー→リーダー bond **-5〜-8**、他メンバー trust 変動なし、ロッカールーム士気 **+1〜+3**、クールダウン12週 🔧 |
| C: 静観する | 派閥成立、特別な数値効果なし、D-F系列が以降自然頻度で発動 |

---

### §9.2 F02 対立型結成

**発火条件**: §2.1 の対立型発生条件を満たす。

**ドラマ**: ロッカールームが2分されている。○○派と△△派、それぞれリーダーがいて、対立が目に見える形になった。

**演出**: 中量版（4シーン＋結果演出）

- シーン1: ロッカールーム導入、2派閥の視覚的分離
- シーン2: 一方のリーダーのセリフ
- シーン3: もう一方のリーダーのセリフ
- シーン4: 社長の判断（選択肢）
- シーン5: 結果演出

**選択肢と効果:**

| 選択 | 効果 |
|------|------|
| A: ○○派を中心に回す | 派閥A成立、派閥B成立、A→Bリーダー trust **+5〜+8**、Bリーダー trust **-5〜-8**、対立度 A→B=55〜70, B→A=65〜80、勢い A+20〜+30, B-10〜-20 |
| B: △△派を中心に回す | A/B逆転版 |
| C: 両者を呼び出して調停 | 両派閥成立、両リーダー trust **-3〜-5**、対立度両方向 30〜45（対称）、勢い両方0、両リーダー→メンバー bond 一時低下 |
| D: 静観する | 両派閥成立、対立度は平均rivalryを継承、勢い両方0、trust変動なし |

### §9.3 F03 リーダー喪失

**発火条件**: 派閥リーダーが退団・引退・長期離脱（8週以上の重傷）のいずれか発生時、即時発動。

**選択肢なし（報告型イベント）**: 残ったメンバーの OVR 最上位者（後継候補）を特定し、旧リーダーOVRとの比率で自動分岐。

**分岐ロジック:**

| 後継候補OVR / 旧リーダーOVR | 結果 |
|--------------------------|------|
| 83%以上 🔧 | **通常継承** |
| 70〜82% 🔧 | **大動揺の確率発動**（50%で動揺、50%で継承） |
| 70%未満 | **解散** |

**通常継承の効果:**
- 派閥名が後継者名に更新
- 対立派閥との対立度（両方向）×0.7
- 後継者 trust **+3〜+5**
- 後継者→旧リーダー bond **+3〜+5**
- メンバー全員 trust **-3〜-6**（動揺）
- lastLeaderChangeWeek 更新

**大動揺の効果（動揺分岐時）:**
- メンバー全員 trust **-8〜-12**
- メンバー間 bond **-5〜-10**
- 後継候補→旧リーダー bond **+10〜+15**（残像の美化）
- 対立派閥がある場合、その勢い **+15〜+25**（弱った隙を突く）
- 派閥は継承される

**解散の効果:**
- 派閥が消滅、全メンバー無派閥化
- 元メンバー全員 trust **-5〜-8**
- 旧リーダーへの bond が高かった順に影響大
- 敵対派閥があった場合、その派閥の勢い **-3〜-5**（対立相手を失う）

**演出**: 軽量版。ナレーション中心＋残メンバー1人のセリフ。

### §9.4 F04 寝返り

**発火条件**:
- 対立型派閥が存在する
- あるメンバーが、敵対派閥メンバーとのbond平均が **70以上** 🔧
- かつ、リーダーとの bond が **40未満** 🔧
- 対象は1人（条件を満たす複数がいる場合は最も該当度が高い1人）
- クールダウン12週（同ペアで再発しない）

**選択肢と効果:**

| 選択 | 効果 |
|------|------|
| A: 放置 | 対象選手が敵対派閥に加入、元派閥メンバー trust **-3〜-6**、元派閥勢い **-15〜-25**、敵対派閥勢い **+15〜+25**、対立度（元派閥→敵対派閥）**+15〜+20** |
| B: 対象選手と面談 | 対象 trust **+5**、一時回避、12週後再判定 |
| C: リーダーに告げ口 | 対象 trust **-5〜-8**、寝返り阻止、対象→リーダー rivalry **+10〜+15**、**派閥内に火種**（F05発火条件確率+） |

**演出**: 中量版。対象選手が敵対派閥メンバーと親しげに話すシーンから開始。

### §9.5 F05 派閥内亀裂

**発火条件**:
- 忠誠型派閥が存在する（対立型からは発動しない）
- 派閥メンバーが **5人以上** 🔧
- リーダーへのbondが **35未満** 🔧 の「不満分子」が **2人以上**
- 不満分子同士の相互 bond が **60以上** 🔧（結託している）

**選択肢と効果:**

| 選択 | 効果 |
|------|------|
| A: リーダーに助言する | リーダー trust **+3〜+5**、リーダーから不満分子へのbond修復行動、不満分子 trust **+3〜+5**、60%で分裂回避、40%で一時回避（12週後再発動） |
| B: 不満分子に味方する | **派閥分裂成立**、不満分子を核とした新派閥が誕生、新リーダーは不満分子のOVR最上位、**対立型への自動遷移**（対立度初期40〜55）、元リーダー trust **-8〜-12** |
| C: 静観 | 70%で自然分裂（Bと同じ結果、ただし社長への好感度変動なし）、30%で亀裂継続 |

**演出**: 中量版。不満分子の陰口・リーダーへの不満の声から開始。

## §10 イベント連鎖マトリクス

派閥イベントは連鎖的に発動する設計。主な連鎖経路:

```
F01-A（権威化）
  └→ F07（リーダー横暴）発動確率+
       ├→ F07-A（認める）→ dictatorTag → F07発動確率更に+
       │    └→ 悪循環 → F05発動確率+
       └→ F07-C（幹部重用）→ F05発動確率+

F01-C（静観）
  └→ 時間経過 → F02発動条件（忠誠型1→対立型2）
       または F05（亀裂）発動 → F05-B で分裂 → 対立型2派閥へ

F02 / F05-B（対立型成立）
  ├→ 対立度+ → F08（ヒートアップ）
  │    └→ F08-A 直接対決 → 試合結果次第で対立度・勢い大変動
  ├→ 片側が勢い-60以下 → F04（寝返り）発動条件+
  │    └→ F04-A 放置 → 対立度+
  └→ 時間経過/bond+ → F06（和解）

F04-C（告げ口）
  └→ 派閥内火種 → F05発動確率+

F03（リーダー喪失）
  ├→ 83%以上継承 → 派閥継続、対立度×0.7
  ├→ 70-82% 動揺 → メンバー大幅trust低下
  └→ 70%未満 解散 → 派閥消滅、対立相手の派閥も勢い低下
```

## §11 セリフ方針

CLAUDE.md「テンプレセリフ禁止」「性格ごとに一人称・語尾・感情の出し方を変える」に従う。

- F01/F02 のリーダーセリフは、各性格（normal/bold/quiet/easygoing/earnest/emotional）×アーキタイプ（normal/ojousama/delinquent/cool/seductive/polite）ごとに **最低2〜3パターン** 用意
- F03（継承者）、F04（寝返り対象）、F05（不満分子）、F07（リーダー）、F08（両リーダー）についても同様
- セリフの格納場所: `src/data-faction-dialogue.js`（新規ファイル）または `src/data.js` の追記
- spec には例示のみ、量産は実装フェーズ

| 性格 | アーキタイプ | セリフ例 |
|------|-------------|---------|

実装時に各性格×アーキタイプ組合せで量産。

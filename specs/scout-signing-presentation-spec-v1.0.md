## §1 台詞の分岐軸

### §1.1 分岐の優先順位

```
①特性トリガー台詞（特定のtraitsを持つ場合、50%で差し替え）
  ↓ 発動しなければ
②汎用台詞（role × context × 年齢帯 で選択）
```

### §1.2 分岐軸の詳細

| 軸 | 値 | 影響 |
|----|-----|------|
| **role** | Babyface / Neutral / Heel | 口調・態度の基本トーン |
| **context** | direct / competition_won / fa_signing | 状況による感情の違い |
| **年齢帯** | young (15-17) / standard (18-22) / mature (23+) | 敬語度合い・初々しさ |
| **traits** | 特定のtraitsがある場合のみ | 一部台詞を上書き（§3参照） |

## §7 台詞選択関数（getSigningLine）

### §7.1 実装イメージ

```javascript
function getSigningLine(fighter, context) {
  // Step 1: trait台詞のチェック（50%の確率で発動）
  if (Math.random() < 0.50) {
    const traitLine = getTraitSigningLine(fighter.traits, context);
    if (traitLine) return traitLine;
  }

  // Step 2: 汎用テーブルから role × context × ageGroup で選択
  const ageGroup = (fighter.age <= 17) ? 'young'
                 : (fighter.age <= 22) ? 'standard'
                 : 'mature';
  const role = (fighter.role || 'Neutral').toLowerCase();
  const pool = SCOUT_SIGNING_LINES[role]?.[context]?.[ageGroup]
            || SCOUT_SIGNING_LINES.neutral.direct.standard;
  return pool[Math.floor(Math.random() * pool.length)];
}
```

## 0. 位置付け

B3「他団体からの挑戦状」は **外から仕掛けられる側**。本仕様はその **逆方向** ——
自団体選手が他団体選手に対して強い感情（憎悪 or 好敵手）を抱いたとき、
**選手側から社長に「あの相手と組ませてくれ」と直訴する**ドラマイベント。

社長は YES / NO を選ぶだけ。試合に技を指示しない、舞台を作るかどうかを決める。
発火頻度は意図的に絞り、**1シーズン最大 2 件、年1〜2回の特別な瞬間**として扱う。

## 1. 発火条件

### 1.1 heat 計算式

打診者（自団体）→ 相手（他団体）の片方向関係性から算出：

```
heat = rivalry
     + max(0, 50 - bond) × 0.8       // 憎しみ加算
     + max(0, bond - 75) × 0.6        // 好敵手加算（bond 75 超で加算）
     + (rivalry ≥ 70 ? +10 : 0)       // 強rivalryブースト

発火: heat ≥ 90
```

| 例 | rivalry | bond | heat | 判定 |
|---|---|---|---|---|
| 純粋な憎悪 | 50 | 0 | 50 + 40 = 90 | ✓ |
| 高 rivalry 標準 | 80 | 50 | 80 + 0 + 10 = 90 | ✓ |
| 友情ライバル | 60 | 90 | 60 + 0 + 9 + 0 = 69 | ✗ |
| 強い友情ライバル | 80 | 95 | 80 + 0 + 12 + 10 = 102 | ✓ |
| 一方通行の無関心 | 30 | 50 | 30 + 0 = 30 | ✗ |

打診者の性格による補正は **行わない**（誰でも打診し得る。性格差はセリフで表現）。

### 1.2 前提条件（AND）

- 打診者: 自団体所属、`!injury && !forcedRest && !suspended`
- 相手: 他団体所属、相手団体が disbanded でない
- プレイヤー団体 `orgPop ≥ 15`
- シーズン第3週以降（開幕直後は出さない）
- 直近8週以内に当該ペアの対戦実績なし

### 1.3 発火頻度ガード（年1〜2回への絞り込み）

| ガード | 値 |
|---|---|
| 抽選サイクル | 4週に1回（月1回判定） |
| シーズンクォータ | 最大 2 件 / シーズン |
| 同一相手団体クォータ | 最大 1 件 / シーズン |
| 同一打診者 CD | 24 週 |
| 同一ペア CD | 36 週（NO 選択時は 52 週に延長） |
| 候補からの選定 | heat 最上位の 1 組のみ |

抽選週に heat ≥ 90 の候補が複数あっても、**最も heat が高い 1 組のみ** が打診として表面化。残りは次サイクル以降に持ち越し。

## 2. UI フロー（S6 決裁シーケンス準拠）

### 2.1 打診モーダル（Office カテゴリ）

`src/ui-common.js` の `_mdlAOpen` / 決裁モーダル基盤を流用。

**構成**：
- ヘッダー：「直訴」バッジ + 打診者の所属タグ
- 中央: 打診者ポートレート（頭上吹き出しで一人称セリフ）⇔ 相手選手ポートレート
- ステータス比較：所属 / OVR / 直近 H2H 戦績
- フレーバー1行：社長視点で関係性を読み解く一文（**数値そのものは出さない**）
  - 例（純粋憎悪型）：「○○の中で、何かが煮詰まっている」
  - 例（好敵手型）：「○○は△△との次の一戦を待ち続けている」
- 選択肢 2 択：
  - **「この舞台、組もう」** （YES）
  - **「今は時期じゃない」** （NO）

打診者セリフは性格 × heat タイプ（憎悪型 / 好敵手型）でテンプレ分岐（§4）。

### 2.2 YES 選択時

- 次回プレイヤー興行に **専用団体戦スロット** として挿入（通常カードを潰さない、独立イベント枠）
- 興行画面のカードに「果たし状」バッジ表示
- 試合直前ポップアップで経緯を1行ナレーション
- 相手団体は **必ず受諾**（プレイヤー体験のストレス低減）

### 2.3 NO 選択時

- 数値変動なし
- 打診者の `condition` を一時的に1段階悪化（次戦のパフォーマンスに影響、寸評セリフが荒れる）
- 同一ペア CD を 36→52週 に延長
- ティッカーに本人の落胆/不満セリフ（性格別、§4）

## 3. 試合フォーマット：挑戦側仕掛けの団体戦イベント

単独試合ではなく、**3 vs 3 の小型団体戦**として開催。B3（他団体からの挑戦状）の対称。

### 3.1 構成

| 役割 | 選出ロジック |
|---|---|
| 自団体・先発 | 打診者で固定 |
| 自団体・残り 2 名 | 自動選出（OVR 上位、または打診者と bond が高いメンバー優先。プレイヤーは選ばない） |
| 相手団体・3名 | AI 選出（打診相手は固定で含む） |

社長が選手選出に介入しない理由：このイベントは **選手の意志で動くドラマ** なので、社長の手は YES/NO までに限定する。

### 3.2 試合進行

- 形式：3 vs 3 シングル連戦（既存タッグマッチ基盤を流用検討、実装時に再評価）
- 興行枠：通常カードと並列の独立イベント枠
- 演出：試合前バッジ「果たし状」+ 経緯ナレーション + 専用入場演出（最低限）

### 3.3 結果記録

- `H2H.history` に `type: 'challenge_request_match'` で記録
- `orgWarRecord` にも対戦結果を反映
- `career history` に打診者・相手選手両方に専用 type で記録
- 新聞ヘッドライン：専用テンプレ（勝利/敗北/接戦で分岐）

### 3.4 数値変動

打診時点では **何も動かさない**（打診そのものは自然な感情の発露）。動くのは判断後：

| シナリオ | 打診者 → 相手 | 打診者 → 自団体内 |
|---|---|---|
| YES（試合実施） | 試合結果に従う通常変動 | bond +1〜+2（社長への信頼） |
| NO（社長却下） | 影響なし | trust 影響なし、condition 一時悪化のみ |

「数字は繊細に使え」原則に従い、安易な加減算を避ける。NO の重みは **キャラの振る舞い** で見せる。

## 4. セリフ設計（最重要）

### 4.1 打診者セリフ（モーダル頭上吹き出し）

**性格 × heat タイプ** のマトリクスで用意。最低 **各性格 × 各タイプ × 3 パターン** = 7性格 × 2タイプ × 3 = 42 パターン。

| 性格 | 憎悪型（bond < 50） | 好敵手型（bond ≥ 75） |
|---|---|---|
| hot | 怒気、直接的、短文 | 高揚、挑発的だが明るい |
| composed | 抑制された冷気、敬語まじり | 静かな闘志、敬意を含む |
| proud | 矜持、見下し気味 | 誇り、対等宣言 |
| quiet | 言葉少な、視線で語る | 短いが熱がある |
| emotional | 感情の吐露、長め | 涙混じりの嬉しさ |
| seductive | 妖しい誘い | 妖艶な敬意 |
| competitive | 戦闘モード、勝負宣言 | 純粋な勝負欲 |

鷹揚（composed）は `oyou-style-guide.md` に準拠。

### 4.2 相手選手のリアクションセリフ（試合前ポップアップ等）

**性格 × アーキタイプ × 関係性タイプ × 格差** の軸で多様化。最低 **各性格 × 3 パターン以上** = 21 パターン以上。

軸：
- 性格 7 種
- アーキタイプ（ace / tactician / brawler 等）
- 関係性タイプ（友情ライバル / 純粋憎悪 / 一方通行）
- 格差（相手OVR > 打診者 / 同格 / 打診者の方が格上）

### 4.3 NO 選択時の打診者セリフ（ティッカー）

性格別、最低各 2 パターン = 14 パターン。
落胆 / 不満 / 諦めの色合いを性格で出し分ける。

### 4.4 格納場所

- `src/data.js` または `src/victory-lines.js` に新規セクション追加（実装時に判断）
- セリフテンプレ ID は `CR_*`（Challenge Request）プレフィクスで統一

GameState 追加フィールド（保存対象）：

```js
G.challengeRequest = {
  pendingThisWeek: null,         // 今週の打診（モーダル表示前）
  acceptedThisSeason: 0,         // シーズン内受諾数
  perOrgThisSeason: { orgId: count },
  cdByFighter: { fighterId: lastWeek },
  cdByPair: { "A>B": lastWeek }
}
```

`null` フォールバックでセーブ互換性確保。

## 6. 検証

- 発火頻度：auto-sim 100 シーズン × 5 シードで、年あたり打診件数の中央値が **1〜2 件** に収まること
- 不変条件：heat 計算が NaN にならない、CD ガードが正しく機能する
- セリフ：全性格 × heat タイプの組み合わせでテンプレが必ず引けること（fallback 文言を 1 つ用意）

## 設計原則

1. **PPVへの橋渡し** — 秋末で挑戦者を決定し、冬PPVの最終戦で統一王座戦を実施
2. **4団体横断の頂点** — 各団体のメジャー王座とは別枠の、プロレス界全体の最高峰
3. **年1回の重み** — 統一王座戦はシーズンに1度だけ。常に誰かが1年間「絶対王者」として君臨する
4. **実力＋所属のバランス** — 弱小団体からも代表を出したいが、S級団体のエース落選は不自然。出場権決定方式に工夫が必要

## §1 統一王座の新設

### §1.1 既存タイトルとの関係

現状のタイトル体系（title-system-spec-v1.0）は各団体内完結の3階級（メジャー/準メジャー/マイナー）。統一王座はこの上位概念として新設する。

| 格 | 名称（案） | 範囲 | 年間開催 |
|----|-----------|------|---------|
| 統一王座（新設） | 統一女子プロレス王座 等 🔧 | 4団体横断 | 年1回（PPVのみ） |
| メジャー王座 | 無差別級王座 等 | 自団体内 | 通年防衛戦 |
| 準メジャー | ハイパーファイト王座 等 | 自団体内 | 通年防衛戦 |
| マイナー | ライジング王座 等 | 自団体内 | 通年防衛戦 |

### §1.2 統一王者の扱い

| 項目 | 仕様案 |
|------|------|
| 王者の所属 | どの団体に所属していてもよい（初期はnull=空位） |
| 戴冠 | 秋トーナメント勝者 vs 現王者の試合で決定（PPVメイン） |
| 空位時 | 秋トーナメント勝者 vs 準優勝者で決定戦（PPVメイン） |
| 防衛戦 | 年1回（次シーズンのPPVのみ） |
| 秋トーナメント出場 | **王者は出場不可**（自動的にPPVメイン進出） |
| 称号効果 🔧 | 人気+15、MQ+5ボーナス、保持1シーズン |

### §1.3 初代王座決定戦

初回シーズン（または統一王座設立時）は空位からスタート：
- 秋トーナメント決勝=統一王座決定戦（PPV待たず）とするか
- 秋トーナメント優勝者 vs 準優勝者でPPVメインを戦うか

→ 未決定

## §2 出場権決定方式

### §2.1 論点

**OVR素直方式**（OVR上位8名）
- ✅ シンプル、実力主義
- ❌ 弱小団体から誰も出られないリスク
- ❌ プレイヤーのOVR上位が固まると「身内ばかり」になる

**団体順位配分方式**（ランキング順位別の枠数）
- ✅ 各団体から必ず代表が出る
- ❌ S級団体のエースが落選する不自然
- ❌ 4位団体の「枠を埋めるだけ」の選手が出てくる

**ハイブリッド方式（推薦）**
- 各団体から最低1名保証枠（王者除く）
- 残り枠はOVR上位から埋める
- S級エースの落選も、弱小団体の孤立も防ぐ

### §2.2 ハイブリッド方式の具体案（8名）

| 枠 | 配分 | 内訳例 |
|----|------|-------|
| 団体保証枠 | 4名 | 各団体のOVR最上位1名（統一王者除く） |
| 実力枠 | 4名 | 残りの選手からOVR上位4名 |

### §2.3 除外条件

- 統一王者（防衛戦に自動進出）
- 怪我中（長期離脱）
- レンタル選手
- ロスター不足団体（保証枠は実力枠に転用）

### §2.4 代替案: 団体ランキング連動配分

| 団体順位 | 枠数 🔧 |
|---------|:------:|
| 1位 | 3 |
| 2位 | 2 |
| 3位 | 2 |
| 4位 | 1 |

この方式の場合、S級団体のOVR上位が3名入る形になり自然。

## §3 トーナメント進行

### §3.1 規模

| 項目 | 仕様案 |
|------|------|
| 出場者数 | **8名**（統一王者除く） 🔧 |
| 形式 | シングルエリミネーション |
| 試合数 | 準々決勝4 + 準決勝2 + 決勝1 = 7試合 |
| 期間 | **Week 36の1興行で全7試合**（ジュニアトーナメント準拠） |

### §3.2 シード配置

出場権決定時のOVR順でシード：
- 第1シード vs 第8シード
- 第2シード vs 第7シード
- 第3シード vs 第6シード
- 第4シード vs 第5シード

同団体対決は準々決勝では回避（可能な限り）。

### §3.3 試合条件

| 項目 | 仕様案 |
|------|------|
| condition | 80固定 🔧 |
| matchTier | 2（ビッグマッチ） |
| エンジン | 通常バトルエンジン |
| 怪我 | なし（condition固定） |
| 試合間回復 | コンディション25%消耗→50%回復 🔧 |

### §3.4 PPV統一王座戦への接続

| 状況 | 試合形式 |
|------|---------|
| 統一王者あり | 秋トーナメント優勝者 vs 現王者 がPPV最終戦 |
| 統一王座空位 | 秋トーナメント優勝者 vs 準優勝者 がPPV最終戦（王座決定戦） |

**既存PPVの「頂上決戦」との関係**（要整理）:
- 現状PPVメインは「ランク1位エース vs ランク2位エース」の頂上決戦
- 統一王座戦を導入すると、メインが置き換わる可能性
- 頂上決戦を残すか、統一王座戦に吸収するかは論点

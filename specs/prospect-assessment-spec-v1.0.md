# 見立て評価(prospect assessment)仕様 v1.0

> 2026-07-30 確定・実装完了。Keisuke裁定:「逸材などの評価に初期能力値も入れる」
> 「評価にはランダム性があり必ずしも本当ではない」「超逸材は最大2%以内」
> 「全体分布が従来の感触に収まることが最優先」「初期ドラフトのOVR下限は撤廃」
> 実装: `src/management.js` `Engine.scout.calcProspectAssessment` / `PROSPECT_EVAL`

## 1. 何を直したか

従来のティア判定 `getTier(potTotal, curTotal)` は `potTotal >= minPot` **OR** `curTotal >= minCur` で、
若手の評価が実質**潜在値だけ**で決まっていた。初期値が異様に低い設計のキャラ
(高島さや: 初期合計109 / 潜在合計760)が**毎回『逸材』表示**になり、
「育てれば強い」という設計意図がラベルからネタバレしていた。
本番経路の実測(150シード)で、年次ドラフト級に登場した15回すべてが『逸材』だった。

## 2. 対象範囲 — 「これからの選手」を見る3系統だけ

| 系統 | 生成/評価経路 | 適用 |
|---|---|---|
| 毎年のドラフト級 | `generateScoutReport` → 候補へ上書き | ✅ |
| 社長室・シーズン中スカウト | 同上(同じ関数) | ✅ |
| 初期ドラフト | `generateDraftConfig` の値付け + `Engine.draft.getCandidateInfo` | ✅ |
| **FA・所属選手** | `calcAssessedValue`(現行) | ❌ **対象外** |

FAを外すのは**経済を動かさないため**(FA開始時の分布 逸材32%/有望49%/原石19% と
価格帯・reqPop門・elite ticket の挙動を現行のまま凍結する)。
FA判定は今も潜在値主導だが、FAは完成品中心でネタバレの実害が薄い。
将来FAも直す場合は価格帯の再設計とセットで行うこと。

## 3. 式

```
見立てscore = 今の実力(cur合計)
            + 伸びしろ(pot合計 − cur合計) × 実現見込み(年齢) × (1 + ブレ)
```

- **実現見込み** REALIZE: ≤18歳 0.85 / ≤21歳 0.70 / ≤24歳 0.50 / ≤27歳 0.30 / それ以上 0.15
- **ブレ** JITTER: ≤18歳 ±20% / ≤21歳 ±12% / ≤24歳 ±8% / それ以上 ±5%
  - **伸びしろ項のみ**に掛ける。今の実力は試合を見れば分かる情報なので揺らさない
  - 導出元は `(state.rngSeed, キャラid)` → **同一プレイ内で固定・別プレイでは別の顔**。
    同じ子が翌年のドラフト級に残ってもブレは同じ(年齢が進むぶんだけ score が動く)
- **ティア**: SCORE_TIERS { 超逸材 770 / 逸材 690 / 有望 600 / 原石 570 / 素材 それ未満 }
- **価格**: 同じ score から帯内位置→べき乗カーブ(2.0)→市場ブレ(0.85〜1.15)→年齢補正。
  ラベルと値段で情報が割れないようにする

しきい値は**本番経路150シードの分布からの採寸値**(目標: 年次ドラフト級で超逸材~2%、
逸材・有望は従来の感触を維持)。キャラデータを大きく改定したら採寸し直すこと
(手順: `test/prospect-assessment-test.js` と同じ経路で score 分布を取り、
超逸材=p98 / 逸材=p68 / 有望=p16 / 原石=p3 を5刻みに丸める)。

## 4. 分布実測(150シード・本番経路)

| | 超逸材 | 逸材 | 有望 | 原石 | 素材 |
|---|---|---|---|---|---|
| 年次ドラフト級(旧) | 0.0% | 35.0% | 60.6% | 4.4% | 0% |
| **年次ドラフト級(新)** | **2.1%** | 27.5% | 55.7% | 11.0% | 3.8% |
| FA開始時(不変) | 0.0% | 32% | 49% | 19% | 0% |
| 初期ドラフト(旧) | 0.0% | 11.1% | 60.5% | 28.4% | 0% |
| **初期ドラフト(新)** | 0.2% | 10.0% | 33.2% | 19.6% | **37.0%** |

- 超逸材が**年に約1〜2%**(≒10年に1人)だけ出るようになった。従来は構造的に0%
- 高島さやの年次での見え方: プレイごとに 有望/逸材/原石 と揺れる(「必ず逸材」が消えた)
- 初期ドラフトは素材表示が増えた(入場係数0.55〜0.625で削った実力を正直に見るため)。
  **これは意図した変化** — 旗揚げドラフトは無名の若手を安く拾う場になり、価格も下がる

## 5. 初期ドラフトの入口変更

- 候補プールの **OVR下限40を撤廃**(上限70は維持)。初期値が異様に低い原石も
  「安くて謎の子」として並びうる(150シードで高島さや4回出現)
- 安価保証(§3.6): `<=120万` で足りないシードは**安い順**で2名まで埋める
  (新価格は下限が上がり、120万以下が存在しないシードがあるため)
- 逸材保証・ROSTER_CFG のしきい値(850/740)は**真の潜在値のまま**(触っていない)。
  保証は「本物が混ざる」ことの保証であり、**表示ラベルは見立てなので一致しない**ことがある
  — 保証枠の子が『有望』や『素材』と表示されるのは正常(それが隠れ蓑)

## 6. 不変条件(test/prospect-assessment-test.js が守る)

1. 年次ドラフト級: 超逸材 0%超〜5%以下・逸材20-38%・有望45-65%
2. FAに素材・超逸材が出ない(=見立て式がFAへ漏れていない指紋)、FA逸材22-42%
3. pot==cur の選手はブレの影響を受けない(見立て=実力で決定的)
4. 同一プレイ内でティア・スコアは固定(価格用rngを何度回しても動かない)
5. 同じ子なら17歳評価 > 26歳評価(pot>curのとき)
6. 初期ドラフト: OVR40未満が候補に並びうる・2番目に安い候補が300万以下(95%以上のシード)
7. 高島さやが「必ず逸材」に戻らない

## 7. 関わるが触っていないもの

- `Engine.rival.getPotentialRank`(AIの保有・放出判断) — **真の潜在値**を見る。AIの内部判断は
  見立てに依存しない(ラベルはAI入札(draft-negotiation)とプレイヤーに共通=どちらも同じ見立てで騙される)
- コーチの評価コメント(`getEvalComment`) — 別系統の情報開示(観察眼)。従来どおり
- `reassess`(戴冠・防衛・重傷での査定更新) — 現行のまま

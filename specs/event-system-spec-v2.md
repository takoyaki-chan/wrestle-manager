# イベントシステム & ファン期待度 仕様書 v2

## 概要

本仕様書は、Wrestle Manager における2つの新システムの設計を定義する。

1. **イベントシステム** — 練習週の「進むボタンを押すだけ」問題を解消する
2. **ファン期待度** — 観客側からカード編成に圧力をかける仕組み

両システムは Phase 1 として同時に実装する。

---

## 設計思想

### 解決すべき問題
- 現行の月サイクル（練習→練習→興行→練習）において、練習週にプレイヤーの意味ある意思決定がほぼ存在しない
- 全体の約2/3の週が「進むボタンを押すだけ」になっている

### 設計原則
- **予測不能性**: イベント発生回数は固定しない。0回の月も3回の月もある
- **重さのグラデーション**: 通知だけのものから興行に影響する大型まで3層構造
- **長期バリエーション**: 「型」×「特性セリフ」×「状況パラメータ」の掛け算で体感の繰り返し感を排除
- **トレードオフ**: 選択肢に正解がなく、状況によって最適解が変わる

## Part 1: 隠しパラメータ — 信頼度 (trust)

### 1-1. 設計方針

隠しパラメータは**信頼度の1本**に統合する。「この社長についていけるか」というプレイヤーとの関係性を表す軸。

フラストレーション・モチベーション・信頼度の3分割は複雑すぎ、かつフラストレーションとモチベーションがほぼ逆相関するため1つで十分。イベント時の反応パターン（直訴するか黙って去るか）の分岐は、隠し数値ではなく**既存の特性システム**で制御する。

### 1-2. 基本仕様

- **範囲**: 0〜100
- **初期値**: 50
- **プレイヤーへの表示**: 直接の数値は非表示。通知型イベント（N5: 噂・前兆）で間接的にヒントを与える

### 1-3. 上昇要因

| 要因 | 変動量 | 備考 |
|---|---|---|
| 興行に出場して勝利 | +3 | 基本的な報酬 |
| 興行に出場したが敗北 | +1 | 出してもらえた事実に対する最低限の信頼 |
| 好試合に出場（MQ70+） | +2（追加） | 勝敗問わず |
| タイトルマッチに組まれた | +5 | 信頼されている感 |
| 直訴に応えた | +8 | 最も直接的な信頼回復 |
| 約束を履行した | +8 | 言ったことを守った |
| 休養願いに応じた | +3 | 体を気遣ってくれた |
| ファンの声イベント発生 | +2 | この団体にいてよかった |

### 1-4. 下降要因

| 要因 | 変動量 | 備考 |
|---|---|---|
| 興行に出場できなかった月 | -8 | 最大の不満要因 |
| 連敗（2連敗以降、1敗ごと） | -3 | 「ちゃんとカード考えてる？」 |
| 直訴を却下された | -10 | |
| 約束を破った | -15 | 最も致命的 |
| 休養願いを無視された | -5 | |
| タイトルに長期間絡めない（人気60+、3ヶ月超過後から） | -2×超過月数 | 累積加速。4ヶ月目-2、5ヶ月目-4、6ヶ月目-6…最大-12 |
| 自然減衰 | -1/月 | 何もしないと少しずつ下がる |

### 1-5. メンタル値の影響

メンタルは「試合の勝敗を決める能力値」ではなく、**「信頼度の変動特性を決める人間性パラメータ」**として再定義する。

- **下降の減衰**: メンタルが高いほど下降量が緩和。係数: `下降量 × (1.0 - mental/200)`
- **上昇の増幅**: メンタルが低いほど上昇量が増幅。係数: `上昇量 × (1.0 + (100-mental)/200)`
- **自然回復**: 毎月 `mental/50` の微量回復（メンタル100で+2、メンタル50で+1、メンタル25で+0）

つまり低メンタルの選手は**下がりやすく上がりやすい**。感情の振れ幅が大きく、扱いにくいが手をかければ応えてくれる。高メンタルの選手は安定しているが、良い待遇を続けても信頼度の上昇は穏やか。

| メンタル帯 | 特徴 |
|---|---|
| 高 (80+) | 信頼度が安定。下がりにくいが上がりにくい。団体の柱。 |
| 中 (40-79) | 標準的な反応。 |
| 低 (1-39) | 信頼度が激しく変動。下がりやすいが上がりやすい。ブレークスルーも出やすい。扱いが難しいがドラマが生まれる。 |

### 1-6. 閾値とイベント発生

| 信頼度帯 | 起きやすいイベント | 特性による分岐 |
|---|---|---|
| 70+ | 特訓志願、後輩指導、自主練成果（ポジティブ系） | — |
| 40〜69 | 通常状態。イベント発生に特別な偏りなし | — |
| 25〜39 | 直訴系イベント発生 | 熱血・生意気 → 直訴する / クール・内向 → 噂・前兆（N5）が出るだけ |
| 25未満 | 退団示唆・引き抜き | 熱血・生意気 → 最後通牒的な直訴 / クール・内向 → 突然の退団示唆 |

**クール・内向系の選手は前兆が通知型イベント（N5）でしか現れない。** プレイヤーが見落とすとある日突然退団の話が来る。これが「普段からロスター全体に気を配る」動機になる。

## Part 2: 資金投入アクション（プレイヤーケア）

信頼度を能動的にケアする手段。練習週に「お金を使って選手を大事にする」判断ポイントを与える。

### 2-1. 設計方針

- 単発でお金を払い、即座に効果が見えることの**気持ちよさ**を重視
- バリエーションを持たせ、「何に使うか」の選択自体を楽しめるようにする
- 全部やれるほど資金はない → 毎月「どこに投資するか」のトレードオフが生まれる
- お金を使った瞬間に選手の顔+セリフが出る**フィードバック**を必ず入れる

### 2-2. 個人向けアクション（特定の選手に使う）

| アクション | コスト目安 | 効果 | 備考 |
|---|---|---|---|
| **ボーナス支給** | 低 | 信頼度+5 | 汎用的。ただし同じ選手に連続使用すると効果逓減（「金で黙らせてる」） |
| **専属トレーナー手配** | 中 | 一定期間成長速度UP + 信頼度+4 | 「お前に投資するぞ」 |
| **コスチューム新調** | 低〜中 | 人気+小 + 信頼度+3 | 見た目変更の演出があれば更に良い |
| **メディア露出の手配** | 中 | 人気+中 + 信頼度+3、練習休み | お金を払ってTV/雑誌を仕込む |
| **怪我の特別治療** | 高 | 離脱期間を短縮（2週→1週等） | 怪我イベント発生時のみ選択可 |

### 2-3. 団体全体向けアクション（全員に効く）

| アクション | コスト目安 | 効果 | 備考 |
|---|---|---|---|
| **打ち上げ・慰労会** | 中 | 全員の信頼度+小、ロッカールーム空気改善 | 興行後に開催。選手間交流イベント派生の可能性 |
| **合宿** | 高 | 全員の成長+中、信頼度+小 | 1週消費。選手間交流イベント派生の可能性 |
| **施設改善** | 非常に高 | 練習効率の恒久的な底上げ | 長期投資。段階的に強化可能 |

### 2-4. イベント対応としての資金投入

イベントシステムの選択肢の中に「お金で解決する」ルートを用意する。

- **引き抜き対応** → 契約金を積んで引き止め
- **スポンサー撤退危機** → 自腹で補填して関係維持
- **選手の不満** → 待遇改善で応える（月額コスト増）
- **怪我の選手** → 特別治療費を出す

### 2-5. フィードバック演出

**すべての資金投入アクションで、選手の顔アイコン＋一言セリフを表示する。**

例：
- ボーナス支給 → 「ありがとうございます！次の試合、頑張りますね！」（熱血）
- ボーナス支給 → 「…どうも」（クール、ただし信頼度は上がっている）
- コスチューム新調 → 「えっ、本当ですか！？ 早く着てみたい！」
- 打ち上げ → 複数選手の顔が並んで「お疲れ様でした〜！」

## Part 3: イベントシステム

### 3-1. 発生タイミングと確率

- **判定タイミング**: 各週の開始時（「進む」ボタン押下後）
- **基本発生率**: 各週 25%（4週のうち平均1回だが、0回も3回もありうる）
- **発生数**: 1週に最大1件（複数同時は避ける）
- **種別の重み付け**:
  - 通知型: 50%
  - 選択型: 40%
  - 大型: 10%
- **興行週**: イベントは発生しない（興行自体が十分なコンテンツ）

### 3-2. イベント型一覧

#### 通知型（選択不要、一言で流れる）

世界が動いている感を出す。判断不要だが、ロスターへの愛着を育てる。

| ID | 型名 | 動的要素 | 発生条件 | 効果 |
|---|---|---|---|---|
| N1 | 自主練成果 | 選手×能力値 | trust 60+ | 対象能力が微上昇 |
| N2 | 選手間の交流 | 選手A×選手B×関係性 | 同じ団体に2名以上 | 相性が微変化（良い方向） |
| N3 | コンディション変動 | 選手×体調 | ランダム | コンディション一時低下 |
| N4 | ファンの声 | 選手×人気帯 | 人気30+の選手 | 人気が微上昇、trust+2 |
| N5 | 噂・前兆 | trust閾値接近 | trustが閾値に接近中 | 効果なし（プレイヤーへのヒント） |

**N5の重要性**: 隠しパラメータの間接的なヒント。「○○が最近不満そうにしている…」= trustが閾値に近づいているサイン。特にクール・内向系の選手では、N5が唯一の警告になるケースがある。

#### 選択型 — 選手起点（状況依存型）

選手のtrust値や状態から発生。関わる選手が毎回異なるため、同じ型でも体験が変わる。

| ID | 型名 | 発生条件 | 選択肢（2〜3択） |
|---|---|---|---|
| S1 | タイトル挑戦要求 | trust 50以下 かつ人気/連勝が一定以上、タイトル未保持 | 受ける（次回興行にカード制約） / 却下（trust-10） / 「まだ早い」（条件付き約束→履行義務発生） |
| S2 | 対戦要求（因縁） | 因縁相手がいる選手、trust 50以下 | 組む（MQボーナス） / 「時期じゃない」（因縁維持、trust微減） / 別の相手を提案（trust微回復） |
| S3 | 休養願い | コンディション低い選手 | 休ませる（1週離脱、回復大、trust+3） / 励ます（回復小、trust変動） / 無視（怪我リスク増、trust-5） |
| S4 | 不満・退団示唆 | trust 25未満、特性が熱血・生意気の場合は直訴、クール・内向は突然発生 | 待遇改善（資金-、trust回復） / 出場約束（カード制約、約束フラグ発生） / 放出覚悟で突っぱねる（退団リスク） |
| S5 | 特訓志願 | trust 70+ | 許可（成長+、怪我リスク小） / 通常練習を指示 / 別の練習を提案（能力偏り調整） |
| S6 | 後輩指導の申し出 | ベテラン選手（在籍期間長い）、trust 50+ | 受ける（指定若手の成長+、ベテランの練習効率-） / 断る / 指導相手を指定 |

#### 選択型 — 外部起点（汎用型）

団体外部から発生。テキストバリエーションで鮮度を保つ。

| ID | 型名 | 発生条件 | 選択肢（2〜3択） |
|---|---|---|---|
| E1 | メディア出演オファー | 人気上位の選手 | 出す（人気+、練習休み、コンディション-） / 断る / 別の選手を推薦 |
| E2 | スポンサー提案 | orgPop帯に応じて内容変化 | 受ける（資金+、条件付き制約あり） / 断る |
| E3 | 合同練習の誘い | ランダム | 参加（全員成長小、1週消費） / 辞退 |
| E4 | スカウト情報 | ランダム | 獲得に動く（資金-、来月加入） / 見送り / 様子見（次月まで保留） |
| E5 | 営業試合依頼 | 資金が少ない時に出やすい | 受ける（資金+、選手疲労+） / 断る |
| E6 | 他団体からの引き抜き | 人気高い選手、trust低い選手 | 待遇交渉で引き止め（資金-） / 放出（資金+） / 説得（trust依存で成否） |

#### 大型イベント（稀に発生）

通常のイベントより影響が大きく、興行カードや経営に直接影響する。

| ID | 型名 | 発生条件 | 影響 |
|---|---|---|---|
| B1 | 練習中の怪我 | 低確率、コンディション低いほど確率上昇 | 数週離脱、興行カード再編を迫られる。特別治療（資金）で期間短縮可 |
| B2 | 選手間の深刻な対立 | 因縁悪化、ロッカールーム空気低下 | 放置でチーム全体悪化 / 仲裁 / 試合で決着 |
| B3 | ファンからの大型リクエスト | orgPop高い時 | 期待カード提示、応えると集客大ボーナス、無視し続けるとorgPop微減 |
| B4 | スポンサー撤退危機 | 業績低迷時 | 条件を呑む（制約受入） / 自腹で補填（資金-） / 突っぱねる（スポンサー喪失） |

### 3-3. セリフ・テキストシステム

#### 特性別セリフ分岐

各イベント型に対し、選手の特性に応じたセリフバリエーションを持たせる。

**例: S1（タイトル挑戦要求）の場合**

| 特性 | セリフ例 |
|---|---|
| 天才 | 「私がベルトを巻くのは当然でしょ？」 |
| 努力家 | 「ずっと準備してきました…チャンスをください」 |
| 生意気 | 「あの程度のチャンピオン、私が引きずり下ろしてあげますよ」 |
| クール | 「…そろそろ、私の番だと思いますが」 |
| 熱血 | 「お願いします！どうしてもあのベルトが欲しいんです！」 |
| デフォルト | 「タイトルマッチの機会をいただけませんか？」 |

**実装方針**: 各イベント型 × 主要特性 3〜5パターン + デフォルト1パターンを用意。全イベント型で合計60〜100のセリフテンプレートを作成。テンプレート内に `{wrestlerName}`, `{rivalName}`, `{titleName}` 等のプレースホルダを使用し、状況に応じて動的に埋める。

#### テキストテンプレートのデータ構造案

```javascript
const eventDialogues = {
  S1: {
    genius:    ["{wrestlerName}「私がベルトを巻くのは当然でしょ？」"],
    hardworker:["{wrestlerName}「ずっと準備してきました…チャンスをください」"],
    cheeky:    ["{wrestlerName}「{championName}程度のチャンピオン、私が引きずり下ろしてあげますよ」"],
    default:   ["{wrestlerName}「タイトルマッチの機会をいただけませんか？」"]
  },
  // ... 他のイベント型
};
```

### 3-4. UI表示

- **通知型**: 画面上部にトースト通知。選手の顔アイコン＋一言テキスト。数秒で消えるか、クリックで閉じる。
- **選択型**: モーダルダイアログ。選手の顔アイコン＋セリフ＋選択肢ボタン（2〜3個）。各選択肢に簡潔な結果ヒント（「人気+、練習休み」等）を付記。
- **大型**: 選択型と同じモーダルだが、視覚的に区別（枠の色、アイコン等）して重要度を伝える。
- **資金投入時**: 選手の顔アイコン＋特性別の反応セリフ。支払い額と効果を明示。

## Part 4: ファン期待度システム

### 4-1. 概要

ゲーム内の状況から「ファンが次に見たいカード」を自動生成し、カード編成に対する外部圧力をかける仕組み。

### 4-2. 期待カードの発生条件

以下の条件を満たすカードの組み合わせから、最大2〜3件を「ファン期待カード」として提示する。

| 条件 | 優先度 |
|---|---|
| 因縁相手同士でまだ再戦していない | 高 |
| 前回の試合が僅差の好勝負だった（MQ高い + 結果が接戦） | 高 |
| チャンピオンに明確な挑戦者がいるのに試合が組まれていない | 高 |
| 人気上位同士でまだ未対戦 | 中 |
| 連勝中の選手 vs チャンピオン | 中 |

### 4-3. 表示と効果

- **表示場所**: 興行準備画面（カード編成画面）に「ファンの声」として常時表示
- **表示形式**: 「ファンは○○ vs △△の試合を待ち望んでいる！」
- **効果**:
  - 期待カードを実際に組む → その試合の**集客ボーナス + MQボーナス**
  - 期待カードを2ヶ月以上放置 → **orgPop微減**（-1〜2/月）
  - 期待カードを実現し好試合になった場合 → 新たな因縁や期待が派生する可能性

### 4-4. 更新タイミング

- 毎月の興行終了後に再評価
- 実現されたカードは期待リストから消える
- 新たな因縁や試合結果から新しい期待カードが生成される

### 4-5. プレイヤーの判断

ファン期待度の面白さは「応えるか、引っ張るか」の判断にある。

- **すぐ応える**: ボーナスを確実に得る。ただしビッグイベントまで温存したかったカードを消費してしまう
- **引っ張る**: 期待が高まる（将来のボーナスが増加する可能性）が、長すぎるとorgPop減
- **無視する**: 別の戦略を優先するが、ファン離れのリスク

## Part 5: ロッカールームの空気 (lockerRoomMorale)

団体全体の雰囲気を表す隠しパラメータ。

- **範囲**: 0〜100
- **初期値**: 60
- **上昇要因**:
  - 興行成功（平均MQ高い）: +3
  - 選手間対立の解決: +5
  - 打ち上げ・慰労会の開催: +5
  - 合宿の実施: +3
- **減少要因**:
  - 未解決の選手間対立1件につき: -3/月
  - trust 25未満の選手1名につき: -2/月
  - 退団者発生: -10
- **効果**:
  - 高い（70+）: ポジティブなイベント（交流、自主練）が出やすい
  - 低い（30以下）: ネガティブなイベント（対立、不満）が連鎖しやすい

## Part 6: 実装上の注意点

### 既存システムとの接続
- イベントシステムはブレークスルー/スランプの既存イベント基盤を拡張する形で実装
- trust はレスラーオブジェクトに追加フィールドとして持たせる
- ファン期待度は因縁システム・対戦履歴システムの上に構築
- 資金投入アクションは既存の経済システムと接続

### 段階的実装の推奨順序
1. trust パラメータの追加 + メンタル効果の接続
2. 通知型イベント（N1〜N5）— 最小限のUIで動作確認
3. 資金投入アクション（個人向け + 団体向け）

### バランス調整ポイント
- イベント発生率（25%を基準に調整）
- trust の増減量（シミュレーション v2 を基準にプレイテストで調整）
- ファン期待カードの放置ペナルティの強さ
- メンタルの影響係数（下降減衰・上昇増幅）
- 資金投入アクションのコストと効果のバランス
- ボーナス支給の逓減率

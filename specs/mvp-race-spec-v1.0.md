## 1. 原則

- **MVPは「その年の働き」を測る。** ベルトの格(殿堂pt・人気・動員)はMVPが背負わない
- **勝って当たり前の試合は評価されない。** 王座戦の1勝は相手の格で価値が変わり、格上を倒した勝利は別枠で加点する
- **エースにも取れる点を太くしても多様性は生まれない**(最強の選手は大会も名勝負も総取りするため・2026-09-17実測)。効くのは「エースには原理的に取れない点」= 格上撃破と、相手不在の王者が稼げない難度制
- 賞の側に手を入れて結果を作らない(連続受賞の減点などは**採らない**・2026-09-17 Keisuke裁定「作為的」)

## 2. 配点(`Engine.mvpRace.POINTS`)

### 王座(難度制・v3)

| 項目 | 値 |
|---|---|
| 団体王座 戴冠 | 11 |
| 団体王座 防衛1回 | **13 × 難度** |
| 団体王座 年末保持 | 8 |
| 統一王座 奪取 / 防衛 | **13 × 難度**(1勝対称) |
| 統一王座 年末保持 | 12 |
| 天頂戦での戴冠(won) | 0(天頂戦優勝の点が兼ねる) |

**難度** = `clamp(1 − 0.05 × (自分のOVR − 相手のOVR), 0.3, 1.5)`。互角=1.0、格下10差=0.5、格下14差以上=0.3(下限)、格上10差=1.5(上限)。OVRはその王座戦の時点の値を戦歴イベント(`titleDefense` / `unifiedTitle`)の `selfOvr` / `oppOvr` に残す。**記録の無い旧イベントは難度1.0**(旧セーブ互換・移行処理なし)

### 格上撃破(v3・新設)

| 項目 | 値 |
|---|---|
| 判定 | シングルで、試合時点のOVRが自分より **5以上** 上の相手に勝利 |
| 通常興行 | 8 |
| ビッグマッチ(タイトル戦ほか tier2) | 20 |

選手の `seasonUpsets = { season, normal, big }` に季単位で数える(戦歴は増やさない)。負けは減点しない。数える経路: AI団体の興行 / 自団体の興行(決済 `processSettlement`)。**未カバー**: PPV・天頂戦・JT・春タッグ・秋の対抗戦・AI間の統一王座戦(100季実測で全経路の88%を捕捉)

### 今年の伸び(v3・新設)

- 人気の伸び(今季首 `seasonStartPop` からの増分)× **0.5**、**上限12**。下がっても減点なし
- 決め手にならない大きさに抑える(Keisuke裁定「伸びの評価は大きくしない」)

| 春のタッグリーグ 優勝 / 準優勝 | 8 / 4 | **30 / 15**(PPV優勝と同格) |

OVR素点(=OVR) / ドーム メイン4 / 名勝負 MQ85・90・95=3・4・5 / 季最高MQ(70超過分) / 歴代MQ記録更新5 / 対抗戦 勝16・負−12 / B3 辞退−4・拒否4 / 団体順位 1位10・2位5 / 人気(50超×0.4)+集客(30超×0.3)

## 3. 内訳と表示

- `breakdown`: `ovr, ppv, title, unified(統一王座の文脈があるときのみ), dome, mq, war, b3, orgRank, draw, tenchosen, autumnWar, springTag, upset, growth, junior` + `meta`
- `title` / `unified` は整数に丸める(新聞4面が `+${bd.title}` とそのまま出すため)
- 実績チップ(`_collectFactChips`): 「格上撃破{n}回」(⚡)/「ジュニアトーナメント優勝・準優勝」(🌱)を追加。2位以下のピル候補に「🏅大会」(天頂戦+秋+春+JTの合計)と「⚡格上撃破」を追加(上位4つだけ出る)
- 文言はJA原文が `MVP_RACE_TEXTS.factChip`(data.js)、ENは `i18n/template-ledger.json` → `src/lang-en-templates.js`。UIラベル「大会」「格上撃破」は `i18n/ui-ledger.json` → `src/lang-en.js`

## 4. 不変条件(`test/mvp-race-new-events-test.js` / `test/unified-title-p4-test.js`)

1. 格の記録が無い防衛は従来どおり13点(旧セーブ互換)
2. 難度は相手が強いほど非減少・下限0.3/上限1.5で頭打ち・防衛は必ず正の加点
3. 統一王座の奪取=防衛(同じ相手なら同点)/ 統一戦1勝≥団体王座防衛 / 年末保持≥団体王座の年末保持 / 統一フル稼働年≤団体王座フル稼働年
4. 格上撃破は単調増加・負けは減点しない・季が変わればカウンタは新しく始まる・閾値未満は数えない
5. 人気の伸びは上限で止まる・下がっても減点なし・季首スナップショットが無ければ0
6. 新カテゴリ(格上撃破/伸び/JT)は該当なしなら0(既存の合計を変えない)

## 5. 較正の記録(100季 seed42・通常年PPV合成・auto-sim)

| 指標 | v1(〜1.36) | v2(1.37) | **v3実装** |
|---|---|---|---|
| MVPが統一王座絡み | 67〜79% | 67 | **57** |
| 団体王座だけの選手のMVP | 33 | 33 | **39** |
| 王座に絡まないMVP | 0 | 0 | **4** |
| 前年と同じ選手がMVP | 47/99 | 47 | **30** |
| 最長連続受賞 | 7年 | 7年 | **4年** |
| 100年でMVPを獲った人数 | 24 | 24 | **27** |

- 統一王座戦の勝者−敗者OVR差は中央値16、団体王座防衛は中央値6(3割が10以上)、現MVPの王座戦は中央値10 → 難度制は「相手不在の王者」に効く
- 控えめな配点(難度の振れ幅小・撃破3/8・大会+8〜16)では4ルート全部入れても結果不変。動いたのは本仕様の強さから(受動評価の「中」)
- 王座に絡まないMVPが100年に2〜4回=稀だが起きる。これ以上は撃破点を大きくするしかなく「多少」を超える

# 成長イベントシステム仕様書 v1.0

> **ステータス**: 設計完了・実装待ち
> **前提**: v1.3-2（試合成長・growthPenalty）実装済み
> **依存**: バランステスト結果により一部数値を最終調整

---

## §1 設計思想

### §1.1 核心ルール

**「1つの出来事に高い確率ではなく、いろんなことに対してものすごく低い確率が積み重なっている」**

全てのイベント判定は極小確率。しかし判定回数が多いため、シーズンを通して見れば誰かしらには起きる。プレイヤーは「いつ、誰に起きるか」を予測できない。

### §1.2 プレイヤーの介入

プレイヤーはイベントに**直接介入できない**。ブレークスルーもスランプも、これまでのプレイヤーの采配（誰を試合に出すか、誰にコーチをつけるか、練習か休養か）の**結果**として発生する。起きた後にコントロールすることはできない。

### §1.3 悪いことは重なる

怪我→スランプ→モチベ喪失の連鎖を許容する。個々の確率は低いが、不運が重なればキャリアが崩壊する。これが「ストレスが低すぎる」問題への解答となる。

## §2 ブレークスルー

### §2.1 概要

試合後に**極低確率**で発生する急成長イベント。1ステータスが即座にジャンプする。

### §2.2 発生タイミング

**試合直後**（試合結果画面の直後にポップアップ）。因果関係が明確になるようにする。

### §2.3 発生条件と確率

足切りラインは固定MQ値ではなく、**その選手にとって特別な試合だったか**で判断する。複数の条件それぞれに独立した確率補正がつき、条件が重なるほど確率が上がるが、全部揃っても決して高くない。

#### 判定テーブル

まず基礎確率 0%（条件を満たさなければ判定自体が走らない）。以下の条件を加算。

| 条件 | 確率加算 | 備考 |
|------|:-------:|------|
| 対戦相手のOVRが自分より10以上高い | +0.8% | 格上チャレンジ |
| 対戦相手のOVRが自分より20以上高い | +1.2%（上と重複しない） | 大格上チャレンジ |
| その試合のMQが自分のキャリアベストMQを更新した | +1.0% | 自己最高の試合 |
| タイトルマッチだった | +0.5% | 大舞台補正 |
| 接戦だった（MQ 70+） | +0.5% | 好試合補正 |
| 敗北した | +0.3% | 負けて学ぶ |
| 選手が25歳以下 | +0.3% | 若手の伸びしろ |

**合計上限: 3.5%**（全条件が揃った最大ケース）

#### 計算例

- 20歳の若手が、OVR15上の格上と接戦して負けた。キャリアベストMQ更新。
  - 0.8 + 1.0 + 0.5 + 0.3 + 0.3 = **2.9%**
- 28歳のベテランが、同格との普通の試合に勝った。MQ 60。
  - どの条件にも該当しない → **0%（判定なし）**
- MQ 80+が常態化している強豪ロスターでも、「格上チャレンジ」「キャリアベストMQ更新」は発生しにくい → インフレしない

#### 年間期待値

プレイヤー団体10人、年間24興行×3試合＝72回の判定機会。平均確率を0.5〜1.0%とすると、**年間0〜1人**。2人出ればラッキー。

### §2.4 効果

| 項目 | 値 |
|------|-----|
| 対象ステータス | 1つをランダム選択（5ステ均等） |
| ジャンプ量 | +3〜6（rngで決定） |
| 上限 | trainCapを超えない |

### §2.5 絶好調期間への連鎖

ブレークスルー発生時、**15%の確率**で絶好調期間が連鎖発動する（§3参照）。

### §2.6 演出

ポップアップ表示（引退演出と同等の扱い）:
- 選手の顔画像（大）
- 「💥 ブレークスルー！」タイトル
- 上昇したステータスと上昇量の表示（例: 「PWR +5！」）
- セリフ（スタイル・性格別に数パターン）
- 効果音: 専用SE
- ボタン: 「素晴らしい」

絶好調が連鎖した場合は、同じポップアップ内に「🔥 絶好調突入！」を追加表示。

### §2.7 データ記録

`fighter.careerRecord.history` に記録:
```javascript
{ type: 'breakthrough', season, week, stat, gain }
```

`fighter.careerHistory` にも記録（選手詳細で表示）:
```javascript
{ type: 'breakthrough', season, week, detail: 'PWR +5 のブレークスルー！' }
```

## §3 絶好調期間

### §3.1 概要

数週間〜十数週間、成長が微増しパフォーマンスが向上する「波に乗っている」状態。

### §3.2 発生条件

- ブレークスルー発生時に15%で連鎖（§2.5）
- （将来拡張: 他のトリガーを追加可能）

### §3.3 効果

成長微増とパフォーマンス微増の**両方を控えめに**載せる。

| 効果 | 値 | 備考 |
|------|-----|------|
| 練習成長倍率 | ×1.15 | 既存の練習成長に乗算 |
| 試合成長倍率 | ×1.15 | 既存のmatchGrowthに乗算 |
| 一時OVRバフ | +2 | 試合時のOVR計算に加算。成長・MQ計算に影響 |
| 一時人気バフ | — | なし（過剰なインフレ防止） |

### §3.4 期間

| 項目 | 値 |
|------|-----|
| 基本期間 | 8〜16週（発生時にrngで決定） |
| 早期終了 | 重傷を負った場合、即座に終了 |

### §3.5 データ構造

```javascript
fighter.hotStreak = {
  remainingWeeks: Number,  // 残り週数
  ovrBuff: 2               // 一時OVRバフ
} | null
```

### §3.6 演出

- ロスター一覧・選手詳細に **🔥アイコン** を表示
- 「🔥 絶好調」ラベル
- ポップアップは§2.6のブレークスルー演出に含める（単独発生の場合は軽いテキスト通知）

### §3.7 週次処理

`tickWeek` 内で毎週:
```
if (fighter.hotStreak) {
  fighter.hotStreak.remainingWeeks--
  if (fighter.hotStreak.remainingWeeks <= 0) {
    fighter.hotStreak = null
    // テキスト通知: 「○○の絶好調期間が終了した」
  }
}
```

成長計算時: 既存の成長量に `× 1.15` を乗算（練習・試合の両方）。

OVR計算時: `Engine.util.ov(fighter)` に hotStreak.ovrBuff を加算（表示・試合・MQ計算に反映。trainCap判定には使わない）。

## §4 スランプ

### §4.1 概要

精神的な不調。成長が停止し能力が微減する。**いつ治るかわからない**。固定の終了週を持たず、回復確率（momentum）を蓄積していく方式。

### §4.2 発生条件と確率

全て**極小確率**。いろんな瞬間に判定が走る。

| トリガー | 確率 | 備考 |
|----------|:----:|------|
| 怪我（moderate以上）からの復帰時 | 3.0% | 復帰した週に1回だけ判定 |
| 重傷（severe）からの復帰時 | 5.0% | 復帰した週に1回だけ判定 |
| 試合敗北時 | 0.8% | 1%未満を厳守 |
| growthPenalty終了時（怪我デバフ解除） | 2.0% | 「治ったけど精神が…」 |

#### 既存スランプ・絶好調との排他

- 絶好調期間中はスランプ判定をスキップ
- 既にスランプ中は新たなスランプは発生しない（ただしモチベ喪失への悪化判定は走る）

### §4.3 効果

| 効果 | 値 | 備考 |
|------|-----|------|
| 練習成長 | 完全停止（×0） | |
| 試合成長 | 完全停止（×0） | |
| 能力微減 | 毎週 -0.2〜-0.5（ランダム、1ステをランダム選択） | 下限: Notion値の70% |
| 一時OVRデバフ | -1 | 精神的に本来の力が出ない |
| 人気 | 変動なし | スランプ自体は人気に影響しない |

### §4.4 回復メカニズム — momentum蓄積方式

スランプには**固定の終了週がない**。毎週「回復判定」が走り、蓄積された回復確率（momentum）で判定する。

#### データ構造

```javascript
fighter.slump = {
  recoveryMomentum: Number,  // 蓄積された回復確率（%）。初期値 0
  weeksSinceStart: Number,   // スランプ開始からの経過週数
  ovrDebuff: -1              // 一時OVRデバフ
} | null
```

#### 毎週の回復判定

```
回復確率 = 基礎確率(2%) + recoveryMomentum
rng判定 → 回復成功ならスランプ解除
```

#### momentum の増減

| イベント | momentum への効果 | 備考 |
|----------|:----------------:|------|
| 何もない週（時間経過） | +0.3% | 安静ボーナス |
| 試合出場（MQ問わず） | +0.5% | リングに立つこと自体が刺激 |
| 良い試合（MQ 65+） | +1.5% | 手応えのある試合 |
| 名勝負（MQ 80+） | +2.5% | 大きな手応え |
| 怪我発生 | **0にリセット** | 最も残酷。蓄積がゼロに |
| 試合敗北 | **8%の確率で0にリセット** | 低確率だが重なると泥沼 |

#### 回復シナリオ

**パターンA: 安静のみ（試合に出さない）**
- 毎週 +0.3%
- Week 10: 2% + 3% = 5%、Week 20: 8%、Week 30: 11%
- 中央値: **約28週（7ヶ月）**

**パターンB: 隔週で試合（MQ 65前後）**
- 月2回の良い試合で +1.5%、試合出場で +0.5%、時間経過 +0.3/週
- 中央値: **約16週（4ヶ月）**

**パターンC: 途中で怪我（Week 10でリセット）**
- 蓄積ゼロからやり直し → 中央値 **30週超え**

**パターンD: 怪我2回＋敗北リセット**
- 40週以上。1シーズンまるまる抜けない可能性
- モチベ喪失への悪化判定が毎週走る

### §4.5 演出

**発生時**: ポップアップ
- 選手の顔画像
- 「📉 スランプ…」タイトル
- セリフ（トリガー別に数パターン。怪我復帰後: 「体は治ったはずなのに…動けない」、敗北後: 「あの負けから…何かがおかしい」等）
- ボタン: 「見守る」

**回復時**: ポップアップ
- 「💪 スランプ脱出！」
- セリフ（「やっと…やっと戻ってこれた」等）
- ボタン: 「おかえり」

**継続中**: ロスター一覧・選手詳細に **📉アイコン** + 「スランプ中」ラベル

### §4.6 データ記録

`fighter.careerHistory` に記録:
```javascript
// 発生時
{ type: 'slump_start', season, week, trigger: 'injury_recovery' | 'defeat' | 'penalty_end' }
// 回復時
{ type: 'slump_end', season, week, duration: weeksSinceStart }
```

## §5 モチベ喪失

### §5.1 概要

スランプの最悪の悪化形態。成長が完全停止し、回復が極めて困難。最悪の場合、自主引退のトリガーになる。

### §5.2 発生条件

| トリガー | 確率 | 備考 |
|----------|:----:|------|
| スランプ中（毎週判定） | 1.5% | スランプが長引くほど判定回数が増える |
| スランプ中に敗北 | 2.5% | 追い打ち |
| 試合に出ていない週が8週連続 | 1.0% | 長期放置のペナルティ |

### §5.3 効果

| 効果 | 値 | 備考 |
|------|-----|------|
| 練習成長 | 完全停止（×0） | スランプと同じ |
| 試合成長 | 完全停止（×0） | |
| 能力微減 | 毎週 -0.3〜-0.8（スランプより大きい） | 下限: Notion値の65% |
| 一時OVRデバフ | -2 | 深刻な精神的落ち込み |

### §5.4 回復メカニズム

スランプと同じmomentum方式だが、**蓄積速度が半分**。

| イベント | momentum への効果 | 備考 |
|----------|:----------------:|------|
| 何もない週 | +0.15% | スランプの半分 |
| 試合出場 | +0.25% | |
| 良い試合（MQ 65+） | +0.8% | |
| 名勝負（MQ 80+） | +1.5% | |
| 怪我発生 | **0にリセット** | |
| 試合敗北 | **12%の確率で0にリセット** | スランプより高い |

基礎回復確率: **1%**（スランプの半分）

中央値: **40〜60週**。1シーズン以上。

### §5.5 自主引退への連鎖

モチベ喪失が**24週以上**続いた場合、毎週 **2%** の確率で自主引退を申し出る。既存の引退システム（wear/durability）とは独立した判定。

### §5.6 演出

**発生時**: ポップアップ
- 選手の顔画像
- 「😞 モチベーション喪失…」タイトル
- セリフ（「もう…何のために闘ってるのかわからない」等）
- ボタン: 「……」

**回復時**: ポップアップ
- 「🌅 再起！」
- セリフ（「まだ…やれる。やってみせる」等）
- ボタン: 「待ってた」

**継続中**: ロスター一覧に **😞アイコン** + 「モチベ喪失」ラベル

### §5.7 データ記録

```javascript
{ type: 'motivation_loss_start', season, week }
{ type: 'motivation_loss_end', season, week, duration }
// 自主引退の場合は既存の retire イベントに reason: 'motivation' を追加
```

## §6 判定フロー（tickWeek内）

```
1. 怪我処理（既存）
   └→ 怪我復帰した選手にスランプ判定（§4.2）

2. growthPenalty カウントダウン（既存）
   └→ penalty解除された選手にスランプ判定（§4.2）

3. 絶好調カウントダウン（§3.7）
   └→ 重傷で即終了チェック

4. スランプ中の選手:
   a. momentum蓄積（§4.4 — 時間経過分 +0.3%）
   b. 回復判定
   c. モチベ喪失への悪化判定（§5.2）

5. モチベ喪失中の選手:
   a. momentum蓄積（§5.4 — +0.15%）
   b. 回復判定
   c. 24週超え → 自主引退判定（§5.5）

6. 練習成長処理（既存）
   └→ スランプ/モチベ喪失中は ×0
   └→ 絶好調中は ×1.15

7. 試合処理（興行週のみ）
   a. 試合実行
   b. 試合成長（既存）
      └→ スランプ/モチベ喪失中は ×0
      └→ 絶好調中は ×1.15
   c. ブレークスルー判定（§2.3 — 両選手に対して）
   d. スランプ中の momentum 更新（試合MQに応じて §4.4）
   e. 敗北した選手にスランプ判定（§4.2 — 0.8%）
   f. スランプ中 + 敗北 → momentum リセット判定（8%）
   g. モチベ喪失中 + 敗北 → momentum リセット判定（12%）

8. 能力微減処理（スランプ/モチベ喪失中の選手）
```

## §9 AI団体への適用

### §9.1 概要

成長イベントはAI団体にも適用する。ただしAI団体は `aiSeasonGrowth`（シーズン末一括計算）で処理されるため、**年間確率に換算してシーズン末に一括判定**する。

AI団体に起きたイベントはプレイヤーに**業界ニュースとして通知**される。

### §9.2 AI ブレークスルー（シーズン末判定）

| 項目 | 値 |
|------|-----|
| 判定対象 | AI団体の全選手 |
| 年間発生確率 | 8%/人（S級）、6%/人（A級）、4%/人（B級） |
| 効果 | 1ステータスが +3〜6 ジャンプ（プレイヤーと同一） |
| 絶好調連鎖 | なし（AI団体は週次処理がないため省略） |

#### 計算例
- S級団体（16人ロスター）: 16 × 8% = 期待値 **1.3人/年**
- A級団体（13人）: 13 × 6% = 期待値 **0.8人/年**
- B級団体（10人）: 10 × 4% = 期待値 **0.4人/年**

### §9.3 AI スランプ / モチベ喪失（シーズン末判定）

| イベント | 年間発生確率 | 効果 |
|----------|:-----------:|------|
| スランプ | 5%/人 | その選手のシーズン成長量を **50%カット** |
| モチベ喪失 | 1%/人 | その選手のシーズン成長量を **0** + 能力微減（-2〜-4を1ステに） |

スランプとモチベ喪失は排他（同一選手に両方は発生しない。モチベ喪失が優先）。

### §9.4 プレイヤーへの通知

AI団体の成長イベントは **シーズン末の業界ニュース** としてプレイヤーに伝える。フレーバーイベントと同じ業界誌風テンプレートを使用。

#### ブレークスルー通知

```
📰 週刊女子プロレス — 「{org名}の{選手名}、覚醒！ {stat}が急成長」
📰 月刊プロレスマガジン — 「衝撃！ {選手名}のブレークスルーに業界騒然」
📰 スポーツ報知 — 「{org名}の新星{選手名}、別人のような成長を見せる」
```

テンプレートは6種程度用意し、ランダム選出。

#### スランプ通知

```
📰 週刊女子プロレス — 「{org名}の{選手名}、不調が深刻化。今シーズンは精彩を欠く」
📰 月刊プロレスマガジン — 「{選手名}にスランプの影。{org名}に暗雲」
```

#### モチベ喪失通知

```
📰 週刊女子プロレス — 「{org名}の{選手名}、モチベーション喪失か。練習にも姿を見せず」
📰 スポーツ報知 — 「{選手名}の引退危機？ {org名}関係者が明かす深刻な状況」
```

### §9.5 通知の表示タイミング

シーズン末のオフウィーク処理（`advanceWeek` offWeek1）で、AI団体の `processSeasonEnd` 後にイベント結果をまとめて `events` 配列に追加。通常のシーズン末イベントログに流れる形。

特に脅威度の高いイベント（S級団体のエースがブレークスルー等）は、**単独ポップアップ**で強調表示する。

#### 脅威ポップアップの条件

| 条件 | 演出 |
|------|------|
| S級団体の選手がブレークスルー | ⚠ 脅威ポップアップ（「強敵がさらに強くなった…」） |
| 隣接ランク団体の選手がブレークスルー | ⚠ 脅威ポップアップ |
| 上位団体のエースがスランプ/モチベ喪失 | 📰 好機ポップアップ（「チャンスかもしれない…」） |
| それ以外 | ログに流れるのみ |

# レンタルシステム 実装仕様書

## 概要

プレイヤーが外部から選手を一時的に借りて自団体の興行に出場させるシステム。
序盤の人材不足カバーと、顔ぶれの新鮮さ確保が主な目的。

## 供給元

### ライバル団体
- ライバル団体の選手をレンタル可能
- **制限：団体内ランキング上位3名は借りられない**（エース格の除外）
- それ以外の選手は自由にレンタル可能

### フリーエージェント
- フリーエージェントプールからもレンタル可能
- 特に制限なし

## 契約条件

### 同時レンタル人数
- 最大 **2〜3名**（ロスター枠の一定割合）
- 具体的な算出式は実装時に調整

### レンタル期間
- **シーズン単位**で選択
- 最短1シーズン、最長4シーズン
- 途中解約 **不可**
- 契約満了で **自動返却**

### 費用
- **前払い一括**
- ⚠️ **価格カーブは仮値で実装すること**（経済パラメータ全体調整時に正式決定）
- 仮値の目安：選手レベルに応じた段階的な料金。低レベル帯は非常に安く、高レベル帯は急激に高くなる指数的スケーリング
- 複数シーズン契約時の割引も将来的に検討

## レンタル選手の扱い

### 試合
- 通常興行：**出場可**
- タイトルマッチ：**出場不可**

### 練習・育成
- 育成画面には **表示されない**（プレイヤーが練習メニューを組むことはできない）
- レンタル選手はAI自動で **疲労が出にくい練習** を行っている扱い
- プレイヤーの管理コストはゼロ。「試合に出すだけ」の存在

### 成長
- レンタル期間中も **成長する**
- ただし自団体のコーチ設定は **適用されない**
- 元の所属先の設定に従って成長（フリーエージェントの場合はデフォルト設定）

### 怪我
- 怪我しても **契約続行**（途中返却なし）
- レンタルした選手が怪我するリスクはプレイヤーが負う

### 人気度
- レンタル選手の **個人人気：通常通り上昇**
- **団体人気への貢献：通常の半分**（50%）

## UI

### 配置
- 団体メンバー一覧の下に **「レンタル枠」として分離表示**
- 団体所属選手とは明確に区別できるようにする

### レンタル契約フロー（想定）
1. レンタル市場画面を開く
2. 供給元を選択（ライバル団体 / フリーエージェント）
3. 利用可能な選手一覧が表示される（ライバル団体の場合、上位3名は除外済み）
4. 選手を選択 → 詳細情報確認
5. レンタル期間を選択（1〜4シーズン）
6. 費用を確認 → 契約確定（前払い一括）

## 未決定事項（実装時は仮値・仮実装で対応）

- [ ] レンタル費用の価格カーブ（経済パラメータ全体調整時に決定）
- [ ] 同時レンタル人数の具体的な算出式（固定値2〜3名 or ロスター比率）
- [ ] 複数シーズン契約の割引率

## 実装上の注意

- 費用関連のパラメータは定数として一箇所にまとめ、後から調整しやすくすること
- ゲームの5つの設計原則に従うこと（ロジックとUI分離、イミュータブルな状態管理など）
- WMの既存コードベースのアーキテクチャに合わせること

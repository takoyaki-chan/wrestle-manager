## §1 士気雰囲気テキストの段階（`Engine.lockerRoom.getAtmosphereText`）

道場ヘッダーの雰囲気1行。表示時に `ds = clamp(morale + noise, 0, 100)` を計算し段階を選ぶ。

| 項目 | 値 |
|---|---|
| 段階閾値 | **L1: ds≤24 / L2: ≤41 / L3: ≤57 / L4: ≤65 / L5: 66+** |
| 表示ノイズ | **int[-4, 4]**（観測の揺らぎ。moraleそのものには触れない） |
| 文面 | `ATMOSPHERE_TEXTS`（data.js）— P1で無変更 |

- 旧割付（0-20/21-40/41-60/61-80/81+、ノイズ±10）は実効レンジと不一致で、L5と空気ログgoodトーンの到達率が実測0%、ケアなし世界の8割の週がL3「特に変わった様子はない」だった（G12）
- 較正実測（--careあり/なし各40季×シード42,7919）: ケアなし=中央値33がL2に落ち、L3は22〜35%。ケアあり=L4が65〜72%で常態、L5が15〜19%で時々
- ノイズを±4へ絞った理由: 帯幅が約20→約10になったため。「ノイズ≒帯幅の半分」の比を維持しないと表示が毎週2〜3段ちらつき信号にならない
- ケアなしでもL4+が約8〜19%出るのは仕様（士気の第一因子は興行MQ。好調期に良い顔をするのは嘘ではない）

## §2 信頼40〜55帯の低調サイン（🌫）

「💭よそよそしい」（trust<40）とボーナス書類の発動条件（<60）の間の帯が画面のどこにも出ず、ケアを打つきっかけが消えていた盲点20ptを埋める常設サイン。

- **点灯**: trust 40〜55 / **消灯**: 57以上（ヒステリシス。56で毎週チラつかせない）
- **出る場所**: ロスターカードのバッジ行（熱量😮‍💨と同列の状態アイコン様式）+ 道場の立ち姿の右下
- **ホバー/タップ**: 様子の一文（`QUIET_SIGN_LINES` 3種、ui-render.js）。**選手IDで固定** — 同じ選手には常に同じ一文
- **出さない場所**: モーダル / 週次レポート行 / ティッカー（常設サインのみ）
- ヒステリシスの記憶は ui-render.js 内の `Map` のみ。**GameStateにもセーブにも書かず、エンジンは一切読まない**。リロード後は素のtrust帯から再導出
- trust<40 は従来どおり💭よそよそしい（濃い段階）が受け持つ

## §4 社長室の導線と決裁枠（⚡）の可視化

1. **navバッジ（🏛️社長室の金ドット）**: `Engine.shachoshitsu.hasActionableDocs(G)` — **発動条件つき書類**（activationCondition非null: bonus/party/special_treatment/relationship_repair）が1枚以上あり、その週まだ決裁していないものが残っているとき。常時発動書類（休暇/招聘/合宿/メディア）は数えない。**未読方式**: その週に社長室を開くとドットは消え、翌週に案件が残っていれば/新たに出れば再点灯（新聞バッジ`G._bigNewsUnread`と同系統）。金=Officeの色（新聞の赤=速報と意味を分ける）
2. **⚡残量のトップバー常設**: 「決裁 ⚡n/6」。満タン時のみ淡い明滅（`dp-full-breathe`、次の回復が捨てられるサイン。`prefers-reduced-motion`対応）。ツールチップ「⚡ 決裁枠 / 社長室の書類を決裁するのに使う / 4週ごとに2回復（上限6）」+満タン時「次の回復は捨てられる」
3. **机のカード**: 今週決裁済みの団体書類は消さず朱印「決裁済」付きで残す（`getAvailableDocs(state, {includeWeekUsed:true})` は机の描画専用。既定falseの返り値は従来と完全同一 — 決裁可否判定・auto-simの母集団は不変）。クリックハンドラは外す（押せるのに弾かれる状態を作らない）
4. **対象選択モーダルの選手CD**: クールダウン中の選手も一覧から消さず「あと n週」+グレーで後方に並べる（選択不可）。全候補がCD中のときのトースト「この書類は対象の選手がまだ受け取ったばかりです」

**不変条件**: DPの回復量・上限・消費、書類の発動条件・cooldown判定は一切不変（表示のみ）。

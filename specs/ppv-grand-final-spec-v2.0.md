## 設計原則

1. **シーズンのクライマックス** — Week 48、全4団体が集う年間最大イベント
2. **ランキングが物を言う** — 団体順位がエントリー枠数と報酬を決める
3. **因縁の大舞台** — 団体を超えた因縁カードが優先的にマッチメイクされる
4. **頂上決戦** — ランク1位 vs 2位のエース対決がメインイベント

## §3 マッチメイク

### §3.1 興奮度スコア

```
excitement = ovrSum + popSum × 0.5 - ovrGap × 2
```

| 変数 | 計算 |
|------|------|
| ovrSum | ov(f1) + ov(f2) |
| popSum | pop(f1) + pop(f2) |
| ovrGap | \|ov(f1) - ov(f2)\| |

### §3.2 マッチ優先度

1. **因縁カード**（rivalryLevel ≥ 1）: 最優先
2. **興奮度スコア**: 残りの最適ペアリング
3. **カード配置**: 興奮度昇順（前座→メイン）

### §3.3 制約

- **同団体対決は禁止**

### §9.3 PPV 会話テーブル（2026-08-01 実装完了・task-75）

`src/ppv-lines.js` / picker は `pickPpvLine(scene, speaker, other, state)`。

**この表の肝は「相手選手が喋る」こと。** 自団体の選手が自分の勝敗を語るのではなく、
**対戦相手がこちらへ言葉を投げる**。だから因縁の有無で色が変わる。

| scene | 場面 | 話者 | 出る場所 |
|---|---|---|---|
| `summitPre` | 頂上決戦 直前 | 両者 1本ずつ | 進行画面の大カード（`renderPPVProgram`） |
| `summitLose` | 頂上決戦 決着後 | **敗者** | 結果ポップアップの敗者側吹き出し + 新聞の頂上決戦記事 |
| `oppOnLoss` | 自団体が**勝った** | **負けた相手** | 結果ポップアップの敗者側吹き出し |
| `oppOnWin` | 自団体が**負けた** | **勝った相手** | 結果ポップアップの勝者側吹き出し（汎用勝利セリフを差し替え） |

#### 枝分かれ

各 scene が `grudge`（rivalry 60+）と `plain` の2枝を持つ。
因縁は**その2人の間で強いほうの向き**で見る（非対称2軸なので片方だけ燃えていても因縁扱い）。

- `oppOnLoss.grudge` — 悔しげ。認めたくない、次はやる
- `oppOnLoss.plain` — 素直に負けを認める / 相手を称える
- **`oppOnWin.grudge` — 侮辱・侮り。ここだけが悪意を出す枠**。他の枠へ混ぜない。
  侮り方は口調で変える（慇懃無礼 / 冷たい失望 / 拍子抜け / 慇懃な侮蔑 / 直接的な脅し / 嘲弄 / 断定的な格付け）
- `oppOnWin.plain` — 普通の勝者。過剰に煽らない

キー規約は `TENCHOSEN_FINAL_LINES` と同じ
（`${archetype}_${personality}` → `${archetype}_normal` → `standard_normal`）。

#### 発火条件（不変条件）

**アンダーカードで毎試合喋らせない。** 全7試合に出すとくどい。

| カード | 条件 |
|---|---|
| 頂上決戦 | **無条件**（年間最大の舞台で負けた側が無言なのは演出の穴） |
| アンダーカード | 自団体 vs 他団体、かつ 因縁(rivalry 60+) / 番狂わせ(敗者OVR − 勝者OVR ≥ 8) / 大熱戦(MQ 75+) のいずれか |
| 他団体同士のカード | **出さない**（「こちらへ投げる言葉」が成立しない） |
| 引き分け | 出さない |

実測（40シーズン）: 自団体が絡む決着カードの約1割、1興行あたり0.2回。
頂上決戦が無条件なので、興行としては毎回1枚は出る。

#### UI 接続

結果ポップアップ（`showEventMatchResultPopup`）は元から**左右に吹き出しの予約枠**を持つ
（発言が無い側を空枠にして左右の画像の高さを揃えるため）。敗者側のセリフは
`opts.loserLine` でその空枠を埋める。渡さなければ従来どおり空枠のまま。

> **既存の `PPV_SUMMIT_VICTORY_LINES`（47本）は残す。** 頂上決戦の勝者はそのまま。

## §13 新聞記事生成（頂上決戦）

PPV終了後、翌週の週刊グラップル一面記事を `_newsSummitResult` から生成する。
**実装箇所**: app.js `finalizePPV()` でペイロード保存、management.js `storyMaker` で見出し・本文生成。

### §13.1 ペイロード（`_newsSummitResult`）

app.js が h2h 更新前のタイミングで以下を保存する:

| フィールド | 説明 |
|-----------|------|
| `playerInvolved` | 自団体が頂上決戦に参加したか（false=TVモード） |
| `playerName / playerId / playerOrgName` | 自団体側選手・団体名 |
| `aiName / aiId / aiOrgName` | 相手側選手・団体名 |
| `winnerName / winnerId / loserName / loserId` | 勝敗を団体問わず明示 |
| `won` | 自団体勝利フラグ（playerInvolved=falseなら常にfalse） |
| `mq / finType / finMove / finishPhase / turns` | 試合結果（match-engine.js から） |
| `winnerHpFinal / winnerHpMax / loserHpFinal / loserHpMax` | 接戦判定用 |
| `playerRank / aiRank` | 試合時点のランキング順位 |
| `priorH2h` | h2h更新前の過去対戦記録 `{wins, losses, draws, matches}` |
| `winnerLine` | 自団体勝利時のみ、`PPV_SUMMIT_VICTORY_LINES` から1本 |

### §13.2 見出しテンプレート

優先順位で評価し、最初にマッチした条件を採用:

| 条件 | 見出し |
|------|------|
| 過去3戦以上+MQ80+ | `🏆 因縁の頂上決戦 — {winner}、{N}度目の対戦で{loser}を下す` |
| 接戦(HP残<18%)+MQ80+ | `🏆 {playerName} vs {aiName} 死闘の末 — {winner}が栄冠` |
| MQ80+ | `🏆 {playerName} vs {aiName} — 歴史に刻まれる頂上決戦、{winner}に軍配` |
| 圧勝(HP残≥55%) | `🏆 {winner}、{loser}を完封 — {winnerOrg}が頂点に立つ` |
| 接戦(HP残<18%) | `🏆 {playerName} vs {aiName} — 接戦を制し{winner}が勝利` |
| 自団体敗北 | `🏆 頂上決戦 — {ai}、{player}を下し頂点へ` |
| その他 | `🏆 頂上決戦 {playerName} vs {aiName} — {winner}が制す` |

「vs 相手団体」のような団体名のみの見出しは廃止。必ず両選手名を記載する。

### §13.3 本文構成

5要素を順に組み立てる（条件次第で省略あり）:

1. **舞台設定**: `第{S}年度・第{W}週 PPV GRAND FINAL メインイベント。` + ランキング順位付き対戦カード
2. **試合内容**: ターン数 + 接戦/圧勝の文体スイッチ + フェーズ（序盤/中盤/終盤/長期戦） + `Engine.formatFinish()` の決め技フォーマット + HP残量演出
3. **試合の格付け**: MQ80+「歴史に残る一戦」/ MQ70+「見応えある決戦」/ MQ50+「MQ{N}を記録」/ それ以下「期待された熱戦には届かなかったが…」
4. **因縁・対戦履歴**: 過去3戦以上で「因縁の決着戦」、1〜2戦で「再戦での決着」（priorH2h.matches で分岐）
5. **勝者セリフ**: 自団体勝利時のみ、`PPV_SUMMIT_VICTORY_LINES` のキャラ別セリフを引用

### §13.4 設計原則の対応

- **数値は嘘をつかない**: 接戦/圧勝/格付けは全て試合エンジンの実数値（HP残量・MQ・ターン数）から判定
- **キャラのドラマ**: 勝者セリフはキャラの personality×archetype 別に定義された固有セリフを引用（テンプレ「やったー！」を使わない）
- **シーズンのクライマックスにふさわしい記事**: ランキング・因縁履歴・決め技・接戦度を盛り込み、メインイベントの重みを表現

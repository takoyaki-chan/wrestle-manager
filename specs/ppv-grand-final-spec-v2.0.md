## 設計原則

1. **シーズンのクライマックス** — Week 48、全4団体が集う年間最大イベント
2. **ランキングが物を言う** — 団体順位がエントリー枠数と報酬を決める
3. **因縁の大舞台** — 団体を超えた因縁カードが優先的にマッチメイクされる
4. **頂上決戦** — ランク1位 vs 2位のエース対決がメインイベント

---

## §1 解放条件

| 項目 | 仕様 |
|------|------|
| 解放条件 | orgPop ≥ **30** 🔧 |
| 解放フラグ | `ppvUnlocked`（一度解放したら永続） |
| 未解放時 | TV観戦モード（AI団体のみで開催） |

---

## §2 エントリー（Week 43）

### §2.1 枠数

| 団体順位 | 枠数 🔧 |
|---------|:------:|
| 1位 | 5 |
| 2位 | 4 |
| 3位 | 3 |
| 4位 | 2 |
| **合計** | **14名 → 7試合** |

### §2.2 プレイヤー選出

- 王者は自動エントリー（1枠消費）
- 残り枠はプレイヤーが選択
- 対象外: 怪我中、レンタル選手
- 確定後ロック（変更不可）

### §2.3 AI選出

- OVRランキング順（高い順）
- 怪我選手除外
- エース優先

---

## §3 マッチメイク

### §3.1 興奮度スコア

```
excitement = ovrSum + popSum × 0.5 - ovrGap × 2
```

| 変数 | 計算 |
|------|------|
| ovrSum | ov(f1) + ov(f2) |
| popSum | pop(f1) + pop(f2) |
| ovrGap | \|ov(f1) - ov(f2)\| |

### §3.2 マッチ優先度

1. **因縁カード**（rivalryLevel ≥ 1）: 最優先
2. **興奮度スコア**: 残りの最適ペアリング
3. **カード配置**: 興奮度昇順（前座→メイン）

### §3.3 制約

- **同団体対決は禁止**

---

## §4 頂上決戦（Summit Match）

| 項目 | 仕様 |
|------|------|
| 対戦 | ランク1位エース vs ランク2位エース |
| 配置 | 常にメインイベント（最終試合） |
| バトルポイント | 勝者 **+10** / 敗者 **-10** 🔧 |

### §4.1 プレイヤー参加条件

- 団体ランク2位以内 → プレイヤーの最高OVR選手が出場
- ランク3位以下 → AI同士の頂上決戦を観戦

---

## §5 試合処理

### §5.1 試合条件

| 項目 | 仕様 |
|------|------|
| condition | **80**（全選手固定）🔧 |
| matchTier | **2**（ビッグマッチ） |
| エンジン | 通常バトルエンジン |

### §5.2 結果処理（applyPPVResults）

| 処理 | 内容 |
|------|------|
| 因縁MQボーナス | 通常通り適用 |
| 因縁決着判定 | checkResolution 実行 |
| 試合成長 | 通常成長処理 |
| matchupLog | 対戦履歴に追加 |
| ブレイクスルー | 判定あり |
| careerBestMQ | 更新判定あり |
| スランプ/モチベ喪失 | 判定あり |

### §5.3 なし処理

- 怪我なし（condition=80固定のため）
- orgPop変動なし（合同大会のため）

### §6.1 順位賞

| 団体順位 | 報酬(万) 🔧 |
|---------|:---------:|
| 1位 | 300 |
| 2位 | 200 |
| 3位 | 150 |
| 4位 | 100 |

## §7 怪我代替

Week 48開始時に全エントリーの怪我チェック:
- 怪我選手 → 最高OVRの非怪我ロスター選手で代替
- ロスター不足 → 試合数削減

---

## §8 TV観戦モード

orgPop < 30（未解放）の場合:
- PPV自体はAI同士で開催
- 全試合結果（勝者・敗者・MQ）を表示
- 頂上決戦結果＋バトルポイント変動表示
- 報酬なし

---

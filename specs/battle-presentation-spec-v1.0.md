# バトル観戦プレゼンテーション仕様 v1.0

**確定日**：2026-08-02  
**対象**：シングル戦Replay観戦画面  
**基準モック**：`docs/ui/mockups/battle-presentation-pattern-c-v4.html`

## 1. 境界

本仕様は、試合開始前に完成した `result.frames` をどう見せるかだけを定義する。`Engine.battle.simulateMatch()`、勝敗、技選択、ダメージ、命中、カウンター、決着、キックアウト、MQ、HP、モメンタム数値効果、フェーズ、技データ、出現確率、乱数シードおよび乱数消費順は変更しない。

```text
simulateMatch() が試合全体を確定
  → result.frames
  → battle-engine-main.js が順送り
  → 実況・技説明・画像・SFXへ変換
```

観戦、スキップ、再生速度、カメラ、正確な数値の表示切替、1フレーム戻る操作によって、確定済みの試合結果は変化しない。

## 2. 画面構成

1. 上段HUD：選手face、名前、HP、ターン、フェーズ、モメンタム。
2. ライブリング：会場背景と両選手のfull画像を最大面積で表示する。
   - BIG MATCH／RIVALRY MATCH情報はリング上端中央の小型文字バッジに収め、独立した全幅帯や装飾用の選手画像を置かない。
3. ライブリング下端：角型の中央実況パネル。
4. 下段ドック：左選手データ、中央の攻防ログ＋技説明、右選手データ。
5. 最下段操作：中央に「次の攻防」、左右に補助操作。

選手データはupper画像、OVR、ロール、スタイル、5能力バーを常時表示する。右側は画像から内側へ情報が伸びる鏡映しとし、能力バーも右端から左へ伸ばす。同種情報を左青／右赤のような側固定色では区別しない。

## 3. 実況と技説明

- 実況は「誰の技が、相手の体勢や試合の流れをどう変えたか」を自然文で示す。
- 通常実況に正確なダメージ値は書かない。
- 技説明欄は技カテゴリー、技名、初心者向けの動作説明、結果を表示する。
- 「正確な数値」がオンのときだけ、技説明欄へ `DMG` と `PWR` を表示する。
- 攻防ログは新しい行を先頭へ追加し、古いログのために最新行が見えなくならないようにする。

## 4. カメラ

| モード | 仕様 |
|---|---|
| 自動 | 通常は全景。終盤の決定的局面のみアップ |
| 全景 | full画像の膝上を中心に、両者とリングを同時に見せる |
| アップ | full画像を拡大し、上半身と表情を優先する |

自動アップの対象は、End/Climaxにおける高威力技、クリティカル、カウンター、およびフェーズを問わないフォール、丸め込み、ギブアップ、TKO、キックアウト、決着である。アップは最低でも次の攻防まで保持し、毎ターン無意味に全景と往復しない。

full画像は全キャラクター共通の固定キャンバスと同一縮尺を前提とし、画像内の頭上余白が身長差を表す。アップ時に選手別の拡大率・身長補正は加えない。両者を同一倍率で拡大し、キャンバス上端を画面内に残したまま下側だけをクロップする。これにより長身選手の頭切れを防ぎつつ、小柄な選手の頭上余白と目線差を保持する。アップ倍率はライブリングの縦横比に応じて自動的に抑え、利用者によるウィンドウサイズ調整を前提にしない。

背景画像・カラーグレード・照明は、攻撃時に移動する選手パネルとは別の固定レイヤーに置く。背景へ負の `z-index` を使わず、選手の移動や拡大時にも黒い親パネルが露出しない構造とする。

## 5. 維持する演出

- MISS表示と回避フラッシュ
- 攻撃方向矢印、カウンター反転表示
- 大技の溜め、技名スプラッシュ、衝撃フラッシュ
- ダメージ数値、画面シェイク、危険域表示
- HP帯に基づくダメージ台詞／ボイス
- 因縁・フェーズ・決着前カットイン
- フォール、丸め込み、キックアウト、ギブアップ、TKOの進行演出
- 勝者台詞、勝利オーバーレイ、結果表示
- 既存SFXと親画面へのBGM／決着通知

上記は表示レイヤーとして新しいライブリングへ重ねる。発火条件や数値条件は変更しない。

## 6. 操作

- 「次の攻防」は画面最下段の中央に置き、最大のクリック対象とする。
- 左側は「ひとつ戻る」「自動再生」「1×／2×／3×」。
- 右側は「自動／全景／アップ」「正確な数値」。
- 1操作で進むReplayフレームは1つだけとし、演出中の二重進行を防ぐ。
- モバイルはリング→攻防情報→両選手データの順で縦積みし、操作を下端へ固定する。

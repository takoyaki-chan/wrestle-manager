# バトル観戦プレゼンテーション仕様 v1.0

**確定日**：2026-08-02  
**改定**：2026-09-25 §8「大ダメージの段」を追加(Keisuke裁定K-6)  
**対象**：シングル戦Replay観戦画面(§8はタッグ観戦も対象)  
**基準モック**：`docs/ui/mockups/battle-presentation-pattern-c-v4.html`

## 1. 境界

本仕様は、試合開始前に完成した `result.frames` をどう見せるかだけを定義する。`Engine.battle.simulateMatch()`、勝敗、技選択、ダメージ、命中、カウンター、決着、キックアウト、MQ、HP、モメンタム数値効果、フェーズ、技データ、出現確率、乱数シードおよび乱数消費順は変更しない。

```text
simulateMatch() が試合全体を確定
  → result.frames
  → battle-engine-main.js が順送り
  → 実況・技説明・画像・SFXへ変換
```

観戦、スキップ、再生速度、カメラ、正確な数値の表示切替、1フレーム戻る操作によって、確定済みの試合結果は変化しない。

## 2. 画面構成

1. 上段HUD：選手face、名前、HP、ターン、フェーズ、モメンタム。
2. ライブリング：会場背景と両選手のfull画像を最大面積で表示する。
   - BIG MATCH／RIVALRY MATCH情報はリング上端中央の小型文字バッジに収め、独立した全幅帯や装飾用の選手画像を置かない。
3. ライブリング下端：角型の中央実況パネル。
4. 下段ドック：左選手データ、中央の攻防ログ＋技説明、右選手データ。
5. 最下段操作：中央に「次の攻防」、左右に補助操作。

選手データはupper画像、OVR、ロール、スタイル、5能力バーを常時表示する。右側は画像から内側へ情報が伸びる鏡映しとし、能力バーも右端から左へ伸ばす。同種情報を左青／右赤のような側固定色では区別しない。

## 3. 実況と技説明

- 実況は「誰の技が、相手の体勢や試合の流れをどう変えたか」を自然文で示す。
- 通常実況に正確なダメージ値は書かない。
- 技説明欄は技カテゴリー、技名、初心者向けの動作説明、結果を表示する。
- 「正確な数値」がオンのときだけ、技説明欄へ `DMG` と `PWR` を表示する。
- 攻防ログは新しい行を先頭へ追加し、古いログのために最新行が見えなくならないようにする。

## 4. カメラ

| モード | 仕様 |
|---|---|
| 自動 | 通常は全景。終盤の決定的局面のみアップ |
| 全景 | full画像の膝上を中心に、両者とリングを同時に見せる |
| アップ | full画像を拡大し、上半身と表情を優先する |

自動アップの対象は、End/Climaxにおける高威力技、クリティカル、カウンター、およびフェーズを問わないフォール、丸め込み、ギブアップ、TKO、キックアウト、決着である。アップは最低でも次の攻防まで保持し、毎ターン無意味に全景と往復しない。

full画像は全キャラクター共通の固定キャンバスと同一縮尺を前提とし、画像内の頭上余白が身長差を表す。アップ時に選手別の拡大率・身長補正は加えない。両者を同一倍率で拡大し、キャンバス上端を画面内に残したまま下側だけをクロップする。これにより長身選手の頭切れを防ぎつつ、小柄な選手の頭上余白と目線差を保持する。アップ倍率はライブリングの縦横比に応じて自動的に抑え、利用者によるウィンドウサイズ調整を前提にしない。

背景画像・カラーグレード・照明は、攻撃時に移動する選手パネルとは別の固定レイヤーに置く。背景へ負の `z-index` を使わず、選手の移動や拡大時にも黒い親パネルが露出しない構造とする。

## 5. 維持する演出

- MISS表示と回避フラッシュ
- 攻撃方向矢印、カウンター反転表示
- 大技の溜め、技名スプラッシュ、衝撃フラッシュ
- ダメージ数値、画面シェイク、危険域表示
- HP帯に基づくダメージ台詞／ボイス
- 因縁・フェーズ・決着前カットイン
- フォール、丸め込み、キックアウト、ギブアップ、TKOの進行演出
- 勝者台詞、勝利オーバーレイ、結果表示
- 既存SFXと親画面へのBGM／決着通知

選手個人に付く大技の溜め、危険域、闘志、丸め込み等の発光は、選手パネルの矩形へ `box-shadow` を掛けない。透過full画像のアルファ輪郭へ `drop-shadow` を掛け、画像キャンバスの四角形が見えない演出にする。全画面フラッシュやリング中央の衝撃表示はこの制約の対象外とする。

決着後に選手本人が話すセリフは、通常ゲームの会話規則どおり白い吹き出しに黒文字で表示する。実況文とは視覚的に分離する。

タッグのタッチ演出は、交代カードの矩形外周ではなく入場選手のfull画像輪郭を光らせる。フォール等のアップ時はリング上の選手だけを拡大し、画面外の控え画像は拡大・発光アニメーションの対象にしない。

タッグ決着画面は勝者の選手セリフと実況を主役とし、敗者セリフは表示しない。勝者セリフ本文へパートナーや対戦相手のフルネームを動的挿入しない。パートナーの名前は呼び名(基本は名字、話し手→相手の絆85以上で下の名前。`specs/call-name-spec-v1.0.md`)で入れてよい。勝者セリフは口調×性格別の2本(`TAG_MATCH_WIN_LINES`。うち1本は `{partner}` で相手を呼ぶ)と口調別の名前なし3本(`TAG_MATCH_WIN_NAMELESS_LINES`)の計5本から等確率で抽選する(名前を呼ぶ行は5回に1回。K-14、2026-09-25)。呼び名は観戦画面に絆が無いため親(app.js `tagMatchCallNames`)が決めて `matchInfo.callNames['話し手id:相手id']` で渡し、取れないときは名前入りの行を引かない。敗者の顔・名前は簡潔な結果情報としてのみ残してよい。

上記は表示レイヤーとして新しいライブリングへ重ねる。発火条件や数値条件は変更しない(ただし大ダメージ系の発火条件は、2026-09-25 のK-6で§8の相対定義へ改めた)。

## 6. 操作

- 「次の攻防」は画面最下段の中央に置き、最大のクリック対象とする。
- 左側は「ひとつ戻る」「自動再生」「1×／2×／3×」。
- 右側は「自動／全景／アップ」「正確な数値」。
- 1操作で進むReplayフレームは1つだけとし、演出中の二重進行を防ぐ。
- モバイルはリング→攻防情報→両選手データの順で縦積みし、操作を下端へ固定する。

## 8. 大ダメージの段(2026-09-25 Keisuke裁定K-6)

演出の山場は、ダメージの絶対値ではなく**被弾側の最大HPに対する割合**で決める。旧定義(大ダメージ `dmg≥15`、赤フラッシュ等 `dmg≥20`)は、最大HPの式(通常 141+2.5×ST・大一番 272+3.5×ST)でダメージ全体が膨らんだ結果、同格戦の命中の9割超で成立し、山場の演出と被弾セリフが毎ターン出ていた。

判定はエンジン(`Engine.battle.isBigHit` / `isHeavyHit`、定数は `match-engine.js` 先頭の `BIG_HIT_HP_PCT` / `HEAVY_HIT_HP_PCT`)が行い、観戦フレームの `action` に焼く。観戦iframe(シングル・タッグ)は読むだけで、ダメージ値から再計算しない(最大HPを正しく知っているのはエンジンだけ。タッグの観戦iframeは最大HPを近似で持つ)。勝敗・MQ・乱数・試合の数値には関与しない。

| 段 | 条件 | フラグ | 使う演出 |
|---|---|---|---|
| 大ダメージ | 被弾側の最大HPの12%以上 | `action.isCrit` | BIG HIT表示、金の大きいダメージ数字、強いシェイク、技名スプラッシュ、自動カメラのアップ(End/Climax)、実況「深く入った！」、被弾セリフ/ボイスの抽選入口、フレーム間隔1300ms、実況ログの「大ダメージ！」注記 |
| 特大 | 同18%以上 | `action.isHeavy` | 赤フラッシュ、ヒット音1.3倍、タッグの大技の溜め、フレーム間隔+2000ms |

- 被弾セリフ/ボイスは大ダメージのときだけ抽選し、HP帯(66%超: セリフ40% / 34〜66%: セリフ15%・ボイス50% / 33%以下: ボイス60%)で使い分ける(CLAUDE.md「ダメージセリフ/ボイスの発動ルール」)。入口は `pickDamageLine(fighter, action, hpRatio)` の `action.isCrit`。
- 開幕大技の命中は常に大ダメージ(実況ログも固定で「大ダメージ！」)。特大は実ダメージで判定する(開幕大技は最大HPの20%以上なので、現状は常に特大)。
- シングルの大技の溜め(技威力14以上の確率発動)は特大とは別条件。溜めが走るフレームは、特大でなくても+2000msの間を確保する(次の攻防が溜めに重ならないように)。
- `isHeavy` を持たない旧フレーム(更新前にセーブされた大会の観戦データ)は、従来の `dmg>=20` で読む。
- MQの「大技(10ダメ以上)」項は別物で、この段とは連動しない。

実測(同格の平坦ステ、各800試合、試合ごとに新品rng):

| | 大ダメージ/試合 | 特大/試合 | 被弾カットイン/試合(旧定義) |
|---|---|---|---|
| 通常戦 OVR55〜120 | 3.8〜4.4(命中の約3割) | 0.95〜1.3 | 1.8〜2.1(3.8〜4.0) |
| 通常戦 実ロスターの格差カード(OVR差15〜30) | 4.2 | 2.1 | 1.7(2.8) |
| 大一番 OVR55〜120 | 2.3〜3.0 | 0(実ロスターの近接カードで0.05) | 1.3〜1.5(5.9〜6.3) |
| タッグ OVR55〜100 | 17〜19(命中の6〜7割) | 2.4〜3.3 | 7.7〜8.0(7.8〜10.1) |

- 大ダメージは End/Climax に集中する(通常戦で Climax 65〜78%・End 22〜33%、大一番は Climax のみ)。特大は通常戦の Climax だけで出る。
- 被弾時のHP帯は、66%超が1〜8%、34〜66%が約5割、33%以下が4割強。このため被弾セリフ(長文)は1試合約0.4回、ボイスは約1.5回になる。

# 鷹揚（おうよう）口調 スタイルガイド

ノーマル/標準口調が28人に膨らんでテンプレ感が強くなった問題への対処として、新口調「鷹揚」を導入する。本ドキュメントはセリフ書き手（人間およびClaude Code）向けの口調定義書。

## 1. キー命名（決定事項）

**英語キー: `composed`**

理由:
- 既存archetypeキーは `normal`, `ojousama`, `delinquent`, `cool`, `seductive`, `polite` の6種で、`ojousama` 1つを除き英語。英語側に揃える方が多数派ルールに従う。
- `composed` は「落ち着いた・動じない・冷静さを保った」の意で「鷹揚」のニュアンスを最も短く正確にカバーする。
- 候補比較: `magnanimous`（度量大きい・長い）/ `unflappable`（動じない・口語的すぎる）/ `oyou`（ローマ字・他キーと不揃い）。`composed` がベスト。

日本語ラベル: **「鷹揚」**（generate-dialogue-workbooks.js の `ARCHETYPE_LABELS` に登録）

## 3. 鷹揚口調の定義

### 一行で言うと
> **「ゆったり構えて細かいことに動じない、ほのかな自信を匂わせる大人の口調」**

### 4つの核となる要素
1. **動じない** ─ 喜怒哀楽を露骨に表に出さない。大事件に対しても「ま、そういうこともあるよ」のテンション。
2. **ほのかな自信** ─ 結果に自信を持っているが、誇示しない。声高に勝利宣言しない。
3. **間がある** ─ 性急に言葉を継がない。「…」を効果的に使う。
4. **短く切る** ─ 語尾を引き延ばさない。長文より短文を好む。

### 既存口調との位置関係
- 「普通（=ノーマル/標準）」より一段だけクールで、一段だけ自信がある。
- 「クール」ほど冷たくなく、「お嬢様」ほど取り澄ましていない。
- ベビーフェイスにもニュートラルにもヒールにも振れる中性的な口調。

## 4. 文体ルール

### 語尾
- ✅ 短く切る: 「行くよ」「やろうか」「いいね」「だろうね」
- ✅ 含み: 「…かな」「…かもね」「…だろうね」
- ❌ 伸ばさない: 「行くよぉ」「やろうかぁ」← 鷹揚らしさが消える
- ❌ ビックリマーク濫用: 1セリフに「!」は0〜1個まで。「!!」は基本使わない

### 句読点・記号
- 「…」（三点リーダー）を**間を作る道具として**積極的に使う
- 「…まあ」「…ふぅん」「…そうか」のような独白風の入り方が鷹揚らしい
- 改行や段落を分ける必要がある場面では、力強い宣言ではなく「呟き→本題」のリズム

### 一人称・二人称
- 一人称は性格に合わせる（ノーマル鷹揚なら「私／俺」、お気楽鷹揚なら「あたし／オレ」）
- 二人称は「君／あんた／あなた／お前」のうち、性格に合うものを選ぶ。「貴様」は乱暴すぎる、「あなた様」は丁寧すぎる
- 鷹揚に固有の選択肢ではなく、性格×役割で自然に決める

### 頻出する語彙（鷹揚らしさを出す道具）
- 「まあ」「ふぅん」「なるほど」「そうか」「いいよ」「別に」
- 「こんなもんかな」「悪くないね」「上等だ」「やるね」
- 「焦らない」「慌てない」「落ち着いて」
- 「次があるから」「まだまだ」「これから」

### 避けるべき表現
- ❌ 絶叫・絶頂・激情:「うぉぉぉ!!」「いやぁぁ!!」
- ❌ 弱音・口ごもり:「あ、あの…」「で、でも…」← それは内気
- ❌ 過剰な敬語:「〜でございます」「〜ですわ」← それは丁寧/お嬢様
- ❌ 過剰な砕け:「やべぇ!」「マジで!?」← それはヤンキー/お気楽
- ❌ 取り乱し:「どうしよう」「信じられない」を素直に言う
- ❌ ベタな勝利宣言:「やったー!」「最高!」「優勝だー!」

## 5. 性格×鷹揚 のニュアンス早見表

| 性格 | 鷹揚と組んだときの像 | 例: 試合前の意気込み |
|---|---|---|
| ノーマル鷹揚 | 経験を積んだ大人。動じないベテラン。 | 「…ま、いつも通りやろうか」 |
| 強気鷹揚 | 王者の余裕。ガツガツしない強さ。 | 「来なよ。受けて立つから」 |
| 真面目鷹揚 | 騒がない実直さ。淡々とこなす職人。 | 「準備はできてる。やるだけだ」 |
| お気楽鷹揚 | ヌケた大物感。軽いのに動じない。 | 「ま、なんとかなるっしょ。行くよ〜」 |
| 寡黙鷹揚 | 普段以上に静か、しかし重みがある。 | 「……行く」 |
| 内気鷹揚 | ※適合性低い。無理に作らない | （非推奨） |
| 感情的鷹揚 | **ギャップ造形**。普段は怒りっぽいが、決定的な場面では怒りを呑み込んで静かになる | 「…黙れ。…リングで話そう」 |

「鷹揚」は本質的に**情緒の振れ幅が小さい**口調なので、**内気との組み合わせは概念矛盾**を起こす。内気は鷹揚枠に振り分けない方針で良い。

### 感情的×鷹揚 の特殊扱い

⚠️ **前提**: 本作の「感情的(emotional)」は基調が**怒りっぽい・短気・沸点が低い**タイプ。ただし完全な怒り一辺倒ではなく、**たまに取り乱す・声が震える・我を忘れる**こともある(基調7〜8割が怒り系、2〜3割が取り乱し系)。涙ぐみ系のヒロインではない、感情が漏れ出すタイプ。

感情的×鷹揚は一見矛盾だが、**ギャップ造形**として成立する。設計コンセプト:

- 普段は短気で、カッとなって悪態をつく・噛み付く・時に取り乱すキャラが、**勝負の場面・決定的な瞬間だけ怒りを呑み込んで静かになる**
- 怒りや動揺が消えるのではなく、**沸点を超えた感情が逆に低温化する**(熱い怒り → 冷たい怒り、震える声 → 押し殺した声)
- 普段の罵倒・舌打ち・突っかかりが、修羅場では**短い沈黙と低い声**に変わる
- 「沸点の低さ」と「本気の場面の冷静さ」のコントラスト自体がキャラ性

書き方の指針:
- 通常の鷹揚口調より**わずかに棘か震えを残す**(語尾を切る、突き放す、含み笑い、または一瞬の声の揺れ)
- 怒鳴り散らし・取り乱しはNG。代わりに**「感情を圧縮した一言」**を使う
- 例: 「…黙れ」「…後で覚えてろ」「…ふざけてるのか、それとも本気か」
- 罵倒の後に「…」を置いて急に冷えるリズムも有効
- 「お前」「てめえ」のような乱暴な二人称は使ってOK、ただし**音量を上げない**
- ごくたまに、押し殺した声の震えを示唆してもいい(「…っ…そうかよ」)
- 普通の感情的キャラの「ふざけんな!!」「うるせえ!!」「うぅっ…!!」とは正反対のトーン

シーン例:
- 挑発を受けた時: 普通の感情的「ふざけんな! やんのか!?」 / 感情的鷹揚「…ふぅん。…そう来るんだ」
- 大舞台前: 普通の感情的「絶対ぶっ潰してやる!!」 / 感情的鷹揚「…言葉はいらない。リングでやる」
- 勝利直後: 普通の感情的「ざまあみろ!! 誰が最強だ!?」 / 感情的鷹揚「…これで分かったろ。次はないよ」
- 敗北直後: 普通の感情的「くっそ…!! 認めねえ!!」 / 感情的鷹揚「…(舌打ち)…次は、こうはいかない」

## 6. 例文：シーン別 普通 vs 鷹揚

### シーン1: 試合勝利直後
- 普通: 「やった！勝った！次も頑張るよ！」
- 鷹揚: 「…ま、こんなもんかな。次もこの調子で行こう」

### シーン2: 試合敗北直後
- 普通: 「悔しい…！絶対リベンジする！」
- 鷹揚: 「完敗だね。次までに、もう少し詰めようか」

### シーン3: ライバルからの挑発
- 普通: 「はぁ？何言ってんの！？やってやるよ！」
- 鷹揚: 「ふぅん…まあ、好きに言えばいいよ。リングで答えるから」

### シーン4: ファンからの声援
- 普通: 「みんなありがとう！大好き！」
- 鷹揚: 「みんな、ありがとう。…ちゃんと届いてるよ」

### シーン5: コーチの指示への返事
- 普通: 「はい！頑張ります！」
- 鷹揚: 「了解。やってみるよ」

### シーン6: 大舞台への出場が決まった瞬間
- 普通: 「やった！夢のような話だ！」
- 鷹揚: 「…なるほど。じゃあ、応えないとね」

### シーン7: ヒール側の鷹揚（強気鷹揚・ヒール役）
- 普通(強気): 「あたしが最強だよ！文句あるか！」
- 鷹揚(強気): 「あたしが頂点。…それだけだよ」

### シーン8: ベビー側の鷹揚（ノーマル鷹揚・ベビー役）
- 普通: 「みんなのために頑張るよ！」
- 鷹揚: 「みんなが見ててくれるなら、応えないとね」

### シーン9: 試合中・大技を受けた直後
- 普通: 「くっ…！まだだ…！」
- 鷹揚: 「…効くね。でも、まだだよ」

### シーン10: 決め技を出す瞬間
- 普通: 「これで決める！」
- 鷹揚: 「…そろそろ、終わらせようか」

## 7. 書き手向け チェックリスト

セリフを書いた後、以下を確認:

- [ ] 「!!」が複数ついていないか
- [ ] 語尾が伸びていないか（「〜よぉ」「〜だよぉ」）
- [ ] 大声・絶叫表現が入っていないか
- [ ] 「…」が1つは入っているか（必須ではないが、入っていると鷹揚らしさが出る）
- [ ] 文が長すぎないか（1セリフ40字を超えたら見直し）
- [ ] 同じ性格の「普通」セリフをそのままコピーしていないか
- [ ] 内気・感情的の口癖が混ざっていないか
- [ ] 「俺は最強だ!」のようなベタな自慢になっていないか（自信は匂わせる程度）

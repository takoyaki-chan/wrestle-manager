## 3. 全選手一覧（サブタブ: 👤 全選手）

### 3.1 表示対象

| 対象 | 表示 | 備考 |
|------|:----:|------|
| プレイヤー団体の所属選手 | ✅ | orgLabel = プレイヤー団体名 |
| NPC S級団体の選手 | ✅ | orgLabel = 団体名 + 🟡Sバッジ |
| NPC A級団体の選手 | ✅ | orgLabel = 団体名 + 🔵Aバッジ |
| NPC B級団体の選手 | ✅ | orgLabel = 団体名 + 🟢Bバッジ |
| フリーエージェント | ✅ | orgLabel = 「FA」バッジ |
| dormantPool（出現待ち） | ❌ | **絶対に非表示** |
| 引退済み選手 | ❌ | 殿堂サブタブで扱う |

### 3.2 情報可視性

**方針A（全公開）を採用。** 全選手のOVR・個別ステータスを含むすべての情報が閲覧可能。

### 3.3 一覧テーブル設計

#### カラム構成

| カラム | 幅 | ソート | 備考 |
|--------|-----|:------:|------|
| 顔アイコン | 40px | — | face画像 36px丸（既存portrait方式） |
| 名前 | flex | 五十音 | クリックでポップアップ表示 |
| 団体 | 100px | 団体名 | バッジ表示（色分け） |
| スタイル | 70px | スタイル名 | 既存badge-Styleクラス |
| OVR | 50px | 数値 | 太字。75以上は金色、60以上は白 |
| 年齢 | 40px | 数値 | — |
| 人気 | 50px | 数値 | dispPop表示 |

#### 初期ソート

OVR降順（業界最強の選手が上に来る）

#### ソート切り替え

テーブルヘッダーをクリックでトグル（昇順/降順）。現在のソートキーに `▲`/`▼` インジケータ表示。

#### フィルタ

テーブル上部にフィルタバー：

```
[団体: 全て ▼]  [スタイル: 全て ▼]  [🔍 名前検索...]
```

- **団体フィルタ**: 全て / プレイヤー団体 / 各NPC団体名 / FA
- **スタイルフィルタ**: 全て / Grappler / Striker / Submission / Speed / Allround / Brawler
- **名前検索**: 部分一致。入力即時フィルタ

#### 件数表示

フィルタバーの右端に `全98名 / 表示中: 98名` のように表示。

### 3.4 行クリック → ポップアップ

行全体がクリッカブル。クリックで `showFighterPopup(id, source)` を呼び出す。source は所属団体に応じて `'roster'` / `'ai:orgId'` / `'fa'` を設定。

## 4. 選手ポップアップ刷新

### 4.1 画像変更

| 項目 | 現行 | 新仕様 |
|------|------|--------|
| 画像 | `face_*.png` 140×140px | `upper/upper_*.webp` 全身上半身 |
| サイズ | 140×140 角丸正方形 | **200×300** 角丸長方形 |
| フォールバック | イニシャル文字 | 既存face画像 → イニシャル |
| 背景 | なし（パネル背景に溶け込み） | 透過背景そのまま（暗いパネル上に映える） |

#### 画像パス解決

```javascript
function getUpperUrl(id) {
  return PORTRAIT[id] ? `../image/upper/upper_${PORTRAIT[id]}.webp` : '';
}
```

ポップアップではまず `getUpperUrl()` を試行。onerror時は既存 `getPortraitUrl()` にフォールバック。

**ポップアップ以外の画面（ロスター一覧、ランキングなど）では引き続きface画像を使用。** アッパーボディ画像はポップアップ専用とする。

### 4.2 ポップアップサイズ

| 項目 | 現行 | 新仕様 |
|------|------|--------|
| max-width | 380px | **640px** |
| max-height | 85vh | 90vh |
| レイアウト | 縦1カラム | **左右2カラム（ヘッダー部）** |

### 4.3 ヘッダーレイアウト（左右分割）

### 4.4 レーダーチャート仕様

#### 描画方式

Canvas 2D（外部ライブラリ不使用）。HTML5 Canvas要素をポップアップのDOMに挿入。

#### 軸

5軸: PW（上）→ SP（右上）→ TE（右下）→ ST（左下）→ MN（左上）
※時計回り配置

#### 表示要素

- **グリッド線**: 20 / 40 / 60 / 80 / 100 の5段階。薄いグレー線
- **軸ラベル**: 各軸端にPW/SP/TE/ST/MN。軸ごとの固有色で表示
- **データ多角形**: スタイルカラー（例: Grappler=#bb8fce）で塗り。不透明度0.25
- **データ頂点**: 小さい丸ドット
- **数値**: 各頂点の近くに値を表示（オプション、レイアウトが詰まるなら省略）

#### サイズ

- Canvas: 200×200px
- チャート半径: 80px（余白20pxで軸ラベル収容）

### 4.5 能力タブの構成

レーダーチャートとステータスバーを**横並び**で配置。

```
左: レーダーチャート (200×200)
右: ステータスバー5本（既存デザインベース、幅を広げて数値見やすく）
```

その下に、**試合関連情報セクション**を新設：

| 項目 | 内容 | 表示条件 |
|------|------|----------|
| 因縁関係 | 対象選手名 + 強度（Warm/Hot/On Fire） | rivalries に存在する場合 |
| ファン期待度 | 「○○ vs △△ が見たい！」 | fanExpectations に含まれる場合 |
| 通算戦績 | ○勝○敗（勝率○○%） | ロスター選手のみ。NPC非表示 |
| 特性効果 | 各特性の効果テキスト | traits配列が非空の場合 |

※ 特性タグ自体はヘッダー部に表示するが、効果の詳細テキストは能力タブ内のこのセクションで展開表示する。

### 4.6 戦績・経歴タブ / 管理タブ

現行のまま。変更なし（ただしポップアップ幅拡大に伴い自然に余裕が生まれる）。

## 6. ライバル団体比較（サブタブ: ⚔ 団体比較）

### 6.1 概要

各団体を5つの指標で評価し、レーダーチャートで2団体を重ねて比較する。

### 6.2 比較軸（5軸）

| 軸 | 算出方法 | 100の目安 |
|----|---------|-----------|
| エース力 | TOP3選手の平均OVR | OVR90 |
| 層の厚さ | ロスター全員の平均OVR | OVR75 |
| 将来性 | 25歳以下の選手の平均potTotal | potTotal 400 |
| 団体人気 | orgPop | 100 |
| スター度 | 人気50以上の選手数 × 20 | 5人(=100) |

※ 各軸は0〜100にスケーリングして表示。

### 6.3 UI構成

```
┌─────────────────────────────────────────────────────┐
│  [プレイヤー団体 ▼]  vs  [比較先団体 ▼]            │
├─────────────────────────────────────────────────────┤
│                                                      │
│         エース力                                     │
│          ╱╲                                          │
│    スター度   層の厚さ                               │
│          ╲╱                                          │
│    団体人気   将来性                                  │
│                                                      │
│   (Canvas 300×300, 2つの多角形を重ねて描画)          │
│   プレイヤー団体 = 金色(#d4a843)                     │
│   比較先団体 = そのランク色                           │
│                                                      │
├─────────────────────────────────────────────────────┤
│  エース力:     78 vs 85  (+7)                        │
│  層の厚さ:     62 vs 58  (-4)                        │
│  将来性:       71 vs 45  (-26)  ★ 圧勝              │
│  団体人気:     45 vs 72  (+27)  ★ 大差              │
│  スター度:     40 vs 60  (+20)                       │
└─────────────────────────────────────────────────────┘
```

### 6.4 比較先セレクタ

ドロップダウンで NPC 3団体から選択。プレイヤー団体は固定（左側）。

### 6.5 差分表示

各軸の数値差を表示。差が20以上なら「★ 圧勝/大差」のラベル付与。

## 7. 技術設計

### 7.1 新規ファイル・関数

#### index.html 変更

- `.nav-bar` にデータベースボタン追加
- `#screen-database` セクション追加
- `.fighter-popup-box` の `max-width: 380px` → `640px`
- レーダーチャート用CSS追加

#### data.js 変更

- `getUpperUrl(id)` 関数追加

#### ui-render.js 変更

- `renderDatabase()` 関数新規追加
  - `renderDatabaseFighters()` — 全選手一覧
  - `renderDatabaseHallOfFame()` — 殿堂
  - `renderDatabaseOrgCompare()` — 団体比較

#### ui-common.js 変更

- `showFighterPopup()` 全面改修
  - アッパーボディ画像対応
  - レーダーチャート描画
  - 試合関連情報セクション追加
- `drawRadarChart(canvas, stats, options)` — 汎用レーダーチャート描画関数
  - 選手ポップアップ用（5軸: PW/SP/TE/ST/MN, 200×200）
  - 団体比較用（5軸: エース力/層の厚さ/将来性/団体人気/スター度, 300×300）
  - options で色・サイズ・2データ重ね表示を制御

### 7.2 データ収集ヘルパー（Engine層）

`Engine.database` 名前空間を新設（純粋関数のみ）：

```javascript
Engine.database = {
  // 全選手を収集（dormantPool除外）
  getAllFighters(state) → [{...fighter, orgId, orgName, orgTier}]
  
  // 団体比較用スコア算出
  getOrgCompareScores(state, orgId) → {ace, depth, potential, popularity, starPower}
};
```

### 7.3 パフォーマンス考慮

- 全選手一覧は全団体ロスター + FA を結合するため、最大で100名超。テーブル描画は軽量HTMLで十分（仮想スクロール不要）
- レーダーチャートはCanvas描画。ポップアップ表示のたびに再描画（コスト微小）
- ソート/フィルタは配列操作のみ。DOM再構築はrenderDatabase再呼び出し

### 7.4 既存画面への影響

- **ランキング画面**: 変更なし。団体比較はデータベースタブに集約
- **ロスター画面**: 変更なし。face画像のまま
- **スカウト画面**: 変更なし。FAの重複表示は意図的（スカウト画面はアクション用、データベースは閲覧用）

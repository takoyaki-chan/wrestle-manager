# 契約更新交渉イベント仕様書
# Contract Renewal Negotiation Event Spec

**バージョン:** v1.0  
**作成日:** 2026-03-05  
**ステータス:** ドラフト

---

## 1. 概要

シーズン開幕時に発生する、選手との1対1の契約更新交渉イベント。
毎年全選手と更新を行うが、大多数は自動残留。**トラストが低い選手だけが「意見あり」として交渉対象になる。**

キャラクターの内面が言葉と表情で表出する、ゲーム内で最も人間味のあるイベント。

---

## 2. 基本ルール

| 項目 | 内容 |
|---|---|
| タイミング | シーズン開幕時、週進行の前に1回 |
| 対象 | ロスター全選手（毎年更新、契約年数の概念なし） |
| 自動残留 | トラストが一定以上の選手は交渉不要、自動で残留 |
| 意見あり | トラストが低い選手のみ交渉フェーズに登場 |
| 引き留めコスト | 資金（ボーナス/昇給）で支払う |

---

## 3. 態度の種類（2パターン）

### 3-1. 昇給要求

- **発生条件:** トラストがやや低い〜中低のゾーン
- **選手の主張:** 待遇への不満、評価されていないという感覚
- **深刻度:** 中程度。対応次第で穏便に収まる

### 3-2. 移籍志願

- **発生条件:** トラストが非常に低い
- **選手の主張:** この団体を離れたい、やり直したい
- **深刻度:** 高い。引き留めにはコストが必要、失敗もありうる

---

## 4. プレイヤーの対応フロー

### 4-1. 昇給要求への対応

```
【昇給要求】
  ├─ A: 昇給を受ける（給与アップ）
  │    → 残留、トラスト回復
  │
  ├─ B: 交渉する（中間案を提示）
  │    ├─ 選手が受諾 → 少額アップで残留、トラスト微回復
  │    └─ 選手が拒否 → 態度悪化
  │         ├─ 移籍志願に発展
  │         ├─ 不満を抱えたまま残留（トラスト大幅低下）
  │         └─ 即退団（稀、トラストが極端に低い場合のみ）
  │
  └─ C: 拒否する
       → 態度悪化（移籍志願リスク上昇、トラスト大幅低下）
```

### 4-2. 移籍志願への対応

```
【移籍志願】
  ├─ A: 引き留める（ボーナス支出）
  │    ├─ 成功 → 残留、トラスト少し回復（根本的不満は残る可能性）
  │    └─ 失敗 → それでも退団
  │
  ├─ B: 理由を聞く（中間選択肢）
  │    → 選手が不満の理由を語る（運営へのフィードバック）
  │    → その後、引き留める or 送り出す を選択
  │
  └─ C: 送り出す（放出を受け入れる）
       → 退団
```

### 4-3. 退団した選手の行き先

以下のいずれか（詳細ロジックは後日設計）:

1. ライバル団体に移籍
2. フリーエージェントになる
3. 引退する

---

## 5. 演出仕様

### 5-1. 全体構成

**会話パート 7割：結果サマリー 3割**

1. **全体サマリー画面（軽く）** — 「シーズン○ 契約更新 ／ 意見あり：○名」
2. **1対1の交渉（メイン）** — 選手の顔を表示、セリフ付き、選択肢提示
3. **結果サマリー（あっさり）** — 残留○名 / 退団○名 / 昇給○名

### 5-2. 1対1交渉画面の構成

```
┌──────────────────────────────┐
│  [選手の顔]                  │
│                              │
│  「社長、少し話が             │
│    あるんですけど…」          │
│                              │
│  ── セリフが展開 ──           │
│                              │
│  [選択肢A]  [選択肢B]        │
│        ([選択肢C])            │
└──────────────────────────────┘
```

選択後、選手のリアクション台詞 → 次の選手へ遷移

## 6. セリフ生成システム

### 6-1. 2層構造：性格 × コンテキスト

```
セリフ = テンプレート(性格タイプ, 態度タイプ)
       + 差し込み(在籍年数, 出場回数, 成績, ライバル名, 初期メンバーフラグ)
       + 分岐(プレイヤーの選択)
```

### 6-2. 第1層：性格タイプ（トーンを決定）

| 性格タイプ | 昇給要求のトーン | 移籍志願のトーン | 退団時のトーン |
|---|---|---|---|
| 強気 | 突きつける | 宣言する | 強がる |
| 内向的 | おどおど切り出す | 申し訳なさそう | 静かに去る |
| 飄々 | 軽く聞いてくる | さらっと言う | 笑って別れる |
| 真面目 | 筋を通して伝える | 悩み抜いた末に | 礼を尽くす |
| 感情的 | 怒りが混じる | 涙ぐむ | 恨みか感謝、極端に出る |

### 6-3. 第2層：コンテキスト変数（中身を決定）

#### 在籍期間

| 在籍年数 | 差し込み例 |
|---|---|
| 1年目 | 「まだ1年ですけど」 |
| 2〜3年 | 「ここで過ごした○年間」 |
| 4年以上 | 「もう○年になるんですね……長かったな」 |

#### 出場回数

| 出場頻度 | 効果 |
|---|---|
| 少ない | 不満の理由に直結（「あんまり試合に出してもらえなかった」） |
| 多い | 感謝の重みが増す（「たくさんリングに立たせてもらいました」） |

#### 初期メンバーフラグ

- `true` の場合、専用セリフが追加される
- 例：「旗揚げからいたんですよ、私。最初からここにいたんです。」

#### 直近の成績

| 成績 | 効果 |
|---|---|
| 好成績 | 昇給要求の説得力（「結果は出してたと思うんですけどね」） |
| 不振 | 移籍志願の自己嫌悪（「自分でも分かってます、最近ダメだって」） |

#### ライバル関係の有無

- 団体内にライバルがいる場合、退団時に言及
- 例：「○○とまだ決着ついてないけど……もういいです」
- 未完のドラマが途切れる切なさを演出

### 6-4. テンプレート数の目安

- 性格5種 × 態度2種 × 選択分岐3パターン ＝ **基本30セリフセット**
- コンテキスト差し込みにより体感バリエーションは大幅に拡張

## 7. セリフサンプル

### サンプル①：強気 × 昇給要求 × 好成績 × 在籍2年

**導入：**
> 「社長、話があります。」
>
> 「去年の私の成績、把握してますよね。客も呼んだ、勝ちも積んだ。」
>
> 「2年やって、これだけやって、この給料は正直ナメてると思ってます。」
>
> 「正当な評価をしてほしい。それだけです。」

**昇給受諾時：**
> 「……ありがとうございます。」
>
> 「分かってくれる社長で良かった。今期も全力でやりますよ。」

**拒否時：**
> 「…………。」
>
> 「そうですか。分かりました。」
>
> 「でもね社長、私だって我慢の限界ってものがあるんで。そのつもりでいてください。」

---

### サンプル②：内向的 × 移籍志願 × 在籍4年 × 初期メンバー × 出場少ない

**導入：**
> 「あの……社長、お時間いいですか……？」
>
> 「もう4年になるんですね、ここ。旗揚げの時からいたんですよ、私。」
>
> 「でも……ずっと、試合に出してもらえなくて……。」
>
> 「私がいなくても変わらないんじゃないかなって……そう思っちゃうんです。」

**引き留め成功時：**
> 「えっ……そこまでしてくれるんですか……？」
>
> 「で、でも……私なんかにそんな……。」
>
> 「…………。」
>
> 「……もう少しだけ、頑張ってみます。」

**送り出し時：**
> 「……ありがとうございます。」
>
> 「ここで過ごした時間、無駄じゃなかったって、思いたいです。」
>
> 「お世話になりました……。」

---

### サンプル③：飄々 × 昇給要求 × 初期メンバー × ライバルあり

**導入：**
> 「やっほー、社長。いやー、毎年この時期って緊張しますよね。」
>
> 「あのね、お金の話なんですけど。いやー、言いにくいなー。」
>
> 「ぶっちゃけ、もうちょい欲しいなーって。ダメ？」

**拒否時：**
> 「あはは、やっぱりー？ そうだと思ったー。」
>
> 「まあいいですよ。そこまで深刻じゃないんで。」
>
> 「でもいつか上げてくださいね？ 約束ですよー？」

**退団時（放出受入時）：**
> 「あはは、まあそうなりますよねー。」
>
> 「旗揚げからいたのにな〜。なんか不思議。」
>
> 「あ、○○にはよろしく言っといてください。決着つかなかったなーって。」

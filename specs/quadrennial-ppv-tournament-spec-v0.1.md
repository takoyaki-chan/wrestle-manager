## 設計原則

1. **オリンピックイヤー** — 4年に一度だけ、年間最大イベントが特別な形に化ける。周期そのものが価値
2. **通常PPVの尺を守る** — 8名シングルエリミ7試合 ≒ 通常年の7試合+頂上決戦。興行の長さは変えない
3. **優勝は記録と名誉** — 数値バフなし（2026-07-17 決定）。「4年に一度の覇者」はキャリアの勲章として経歴・年代記・殿堂に刻まれる
4. **狭き門** — 出場8名（通常年14名）。エントリーされること自体が栄誉

## §2 エントリー（Week 43）

### §2.1 枠数

| 団体順位 | 枠数（通常年） | 枠数（トーナメント年） |
|---------|:------:|:------:|
| 1位 | 5 | **3** |
| 2位 | 4 | **2** |
| 3位 | 3 | **2** |
| 4位 | 2 | **1** |
| 合計 | 14名 | **8名** |

### §2.2 選出

- 王者自動エントリー・プレイヤー選択・AI選出(OVR順)・除外条件(怪我/レンタル)はすべて通常PPV準拠（ppv-grand-final-spec §2）
- ランク4位（1枠）で王者がいる場合は王者のみ。王者不在なら自由選択

## §3 トーナメント

### §3.1 形式

| 項目 | 仕様 |
|------|------|
| 規模 | 8名シングルエリミネーション |
| 試合数 | 準々決勝4 + 準決勝2 + 決勝1 = **7試合**（通常年の7試合+頂上決戦とほぼ同尺） |
| シード | エントリー確定時のOVR順。1vs8 / 4vs5 / 2vs7 / 3vs6 の標準ブラケット |
| 同団体対決 | 初戦（準々決勝）では可能な限り回避 |
| メイン | **決勝戦**（トーナメント年は頂上決戦を開催しない — 決勝が代替） |

### §3.2 試合条件・消耗

- condition 初期80 / matchTier 2 / 怪我なし（イベント標準）
- ラウンド間の消耗持ち越しは**連戦消耗モジュール**（autumn-gauntlet-war-spec §3、実測連動 B案）を使用:
  - `wear = 12 + (1 - 残HP率) × 20`
  - ラウンド間 recovery = wear累計の **2/3 回復** / floor **50** 🔧
  - 決勝進出者は概ね condition 65〜70 で決勝を戦う想定。年間最高峰の決勝が凡戦にならないよう回復高め・床高めに設定
- 因縁MQボーナス等の試合処理は通常PPV準拠（applyPPVResults 系）

## §4 ポイント・報酬（2026-07-17 仮確定 → auto-sim 実測で最終調整）

### §4.1 対戦ポイント

| 試合 | 対戦pt |
|------|:------:|
| 決勝 | 勝者 +7 / 敗者 -7（通常年の頂上決戦 `summit` の載せ替え） |
| 準々・準決 | 移動なし 🔧 |

### §4.2 シーズン実績ポイント

| イベント | 加点 | アイテムID |
|---------|:----:|-----------|
| トーナメント優勝者所属団体 | **20pt**（通常年の PPV 15pt の代わり） | `ppvT_${season}` |

減衰モデル（1年満額→×0.5/年）により「オリンピック覇者の栄光も次の大会までに色褪せる」— 4年周期と噛み合う設計。

### §4.3 殿堂ポイント

| 実績 | pt |
|------|:--:|
| トーナメント優勝 | **+8**（通常年の頂上決戦勝利 5 の上位。4年に一度しか取れない最高峰） |

### §4.4 称号・記録（効果なし — 2026-07-17 決定）

- 優勝者に「第N回大会覇者」🔧名称未定 — **数値効果は一切なし**。記録と名誉のみ
- `careerRecord.history` に記録:

```js
{ type: 'ppvTournament', season, result: 'champion'|'runnerUp'|'semiFinal'|'firstRound' }
```

- 表示先: 選手詳細 / 経歴年表 / 殿堂ハイライト文 / 年代記

### §4.5 賞金 🔧

| 順位 | 賞金 |
|------|------|
| 優勝 | ¥3,000万 |
| 準優勝 | ¥1,200万 |
| ベスト4 | ¥500万 |

※ 通常年PPVの報酬体系と整合を実装時確認。

## §5 通常PPVとの差分整理

| 項目 | 通常年 | トーナメント年 |
|------|--------|---------------|
| エントリー | 14名（5/4/3/2） | 8名（3/2/2/1） |
| カード | 興奮度マッチメイク7試合 + 頂上決戦 | ブラケット7試合 |
| 因縁カード優先 | あり | **なし**（ブラケットに従う。因縁MQボーナス自体は適用） |
| メイン | 頂上決戦（ランク1位vs2位エース） | トーナメント決勝 |
| 対戦pt | summit ±7 | 決勝 ±7 |
| シーズン実績 | 15pt | 20pt |
| 殿堂pt | 5 | 8 |

## 設計原則

1. **オリンピックイヤー** — 4年に一度だけ、年間最大イベントが特別な形に化ける。周期そのものが価値
2. **業界総力戦の尺** — 16名シングルエリミ15試合。通常年（7試合+頂上決戦）の約2倍の尺を持つ、4年に一度だけ許される大興行（2026-07-18 決定。v0.1の「通常PPVの尺を守る」8名案を破棄）
3. **優勝は記録と名誉** — 数値バフなし（2026-07-17 決定）。「4年に一度の覇者」はキャリアの勲章として経歴・年代記・殿堂に刻まれる
4. **実力がものを言う** — 全試合ビッグマッチルール。長尺で乱数のブレが収束し、実力差がシビアに現れる。番狂わせは起きにくいからこそ、起きたとき本物になる（2026-07-18 決定）

## §2 エントリー（Week 43）

### §2.1 枠数（2026-07-18 Keisuke 裁定で確定）

**特別招待 2名 + 団体枠 14名 = 16名**の2段構成。

**① 特別招待枠（先行確定・2名）** — 団体枠の選出より先に確定する

| 枠 | 選出 |
|----|------|
| 個人ランキング 1位 | 業界個人ランキングの首位選手 🔧 参照ランキングの実体（RP/バトルポイント系）は実装時に確定 |
| 人気 1位 | 全団体横断で人気値が最も高い選手 |

- 所属団体を問わず自動エントリー。**団体枠の消費なし**（その団体は特別招待とは別に団体枠をフルに使える）
- 2枠が同一人物の場合: 人気側を次点（人気2位）に繰り下げ 🔧
- 怪我・レンタル等の除外条件に該当する場合は次点繰り上げ

**② 団体枠（14名）** — 特別招待の2名を除いた選手から選出

| 団体順位 | 枠数 |
|---------|:----:|
| 1位 | 5 |
| 2位 | 4 |
| 3位 | 3 |
| 4位 | 2 |

通常年 PPV と同配分。v0.2 の 5/4/4/3 案は破棄。

### §2.2 選出

- 王者自動エントリー・プレイヤー選択・AI選出(OVR順)・除外条件(怪我/レンタル)は団体枠側で通常PPV準拠（ppv-grand-final-spec §2）
- 特別招待該当者が王者の場合も特別招待側で処理（団体枠を消費しない）
- ロスター不足団体（下位AI団体で枠を満たせない場合）は枠を繰り上げて上位団体に再配分 🔧 実装時にエッジ確認

## §3 トーナメント

### §3.1 形式

| 項目 | 仕様 |
|------|------|
| 規模 | **16名シングルエリミネーション**（2026-07-18 決定、8名案から変更） |
| 試合数 | 1回戦8 + 準々決勝4 + 準決勝2 + 決勝1 = **15試合** |
| シード | エントリー確定時のOVR順。1vs16 / 8vs9 / 4vs13 / 5vs12 / 2vs15 / 7vs10 / 3vs14 / 6vs11 の標準ブラケット |
| 同団体対決 | 1回戦では可能な限り回避（シード近傍スワップで解消） |
| メイン | **決勝戦**（トーナメント年は頂上決戦を開催しない — 決勝が代替） |

### §3.2 試合条件・消耗

- **全試合ビッグマッチルール**（matchTier 2: `BIGMATCH_MAX_T` / `BIGMATCH_PHASES` / `BIGMATCH_ENG` 適用）。長尺ルールにより実力差が結果に反映されやすい（2026-07-18 明文化。通常PPVも tier 2 だが、本大会は1回戦から決勝まで全15試合を tier 2 固定とする）
- condition 初期80 / 怪我なし（イベント標準）
- ラウンド間の消耗は**全ラウンド持ち越し**（連戦消耗モジュール = autumn-gauntlet-war-spec §3、実測連動 B案）:
  - `wear = 12 + (1 - 残HP率) × 20`
  - ラウンド間 recovery = wear累計の **2/3 回復** / floor **50** 🔧
  - **注意**: v0.1（8名・最大3試合）で仮置きした回復2/3・floor50は、16名化で優勝者が最大4試合を戦うため再較正が必要。決勝が凡戦にならないラインを **auto-sim で決勝MQ分布を通常年PPVと比較**して決める
- 因縁MQボーナス等の試合処理は通常PPV準拠（applyPPVResults 系）

## §4 ポイント・報酬（2026-07-17 仮確定 → auto-sim 実測で最終調整）

### §4.1 対戦ポイント

| 試合 | 対戦pt |
|------|:------:|
| 決勝 | 勝者 +7 / 敗者 -7（通常年の頂上決戦 `summit` の載せ替え） |
| 1回戦〜準決勝 | 移動なし 🔧 |

### §4.2 シーズン実績ポイント

| イベント | 加点 | アイテムID |
|---------|:----:|-----------|
| トーナメント優勝者所属団体 | **20pt**（通常年の PPV 15pt の代わり） | `ppvT_${season}` |

減衰モデル（1年満額→×0.5/年）により「オリンピック覇者の栄光も次の大会までに色褪せる」— 4年周期と噛み合う設計。

### §4.3 殿堂ポイント（2026-07-18 Keisuke 裁定でベスト4まで拡張）

| 実績 | pt |
|------|:--:|
| トーナメント優勝 | **+8**（通常年の頂上決戦勝利 5 の上位。4年に一度しか取れない最高峰） |
| 準優勝 | **+5**（毎年の頂上決戦勝利と同格 — 4年に一度の決勝進出はそれだけ重い） 🔧 |
| ベスト4（準決勝敗退2名） | **+3** 🔧 |

毎年のPPVより重い傾斜。1大会あたりの放出は 8+5+3×2=19pt（4年周期なので年平均 約4.75pt ≒ 通常年 summit 5pt/年と同水準でインフレしない）。

### §4.4 称号・記録（効果なし — 2026-07-17 決定）

- **大会名「天頂戦」で確定**（2026-07-18 Keisuke 裁定）。正式表記は冠付き2段: 「全国女子プロレス最強王者決定戦」（小さめフォント）の下に「天頂戦」（大）。称号は「**第N回 天頂戦 覇者**」 — **数値効果は一切なし**。記録と名誉のみ


- 表示先: 選手詳細 / 経歴年表 / 殿堂ハイライト文 / 年代記

## §6.5 関係性ドラマ（2026-07-18 方針決定・詳細DRAFT）

4年に一度の大舞台は関係性が動く場でもある。試合結果から絆/因縁が生まれ・激発展し、**セリフを交えたドラマ**として見せる。

### 方針（Keisuke 裁定）

- この大会の試合をきっかけに、良好な関係が生まれることも、悪い関係が激しく発展することもある
- セリフは**キャラクター属性（archetype 7種）ごとに書き分け**、「このキャラだから喋っている」感覚をプレイヤーに与える。テンプレ禁止
- **発生条件は関係性の文脈**（2026-07-18 裁定）: ドラマが出るのは「**すでに因縁/絆の文脈があるペア**」または「**この試合で因縁が生まれる条件を満たしたペア**」だけ。文脈がなければ**何も出さない**（不在の説明も出さない — 静かにスキップ）
- **下限0・上限1〜2件** 🔧: 毎大会必ず出るものではない。「あったりなかったり」のランダム性・希少性こそが「ドラマがあった」という実感を生む。抽選で無理に配らない

### トリガー分類（叩き台 🔧 実装前に別途詰める）

| 分類 | 条件案 | 関係変化案 |
|------|--------|-----------|
| 名勝負 | 準決勝以上で MQ 閾値超え | 相互 rivalry+bond 上昇（好敵手系。M-CO1 好敵手認定との接続を検討） |
| 番狂わせ / 屈辱 | シード差の大きい敗北・ヒールの敗北 | 敗者→勝者の片方向 rivalry 激発展 |
| 同門対決の後遺症 | 同団体・同派閥対決の実現 | bond 低下 or 逆に深化（関係性・性格で分岐） |

※ いずれの分類も**発火は関係性文脈が前提**: 「既存 rivalry/bond が閾値以上のペア」または「上記条件を強く満たし新たに因縁が生まれるペア」だけが候補になる。候補ゼロの大会は**発生なし**でよい（演出フォールバック不要）。閾値 🔧 は実装時に auto-sim で発生頻度を実測して較正（体感「2大会に1〜2回」程度を目安 🔧）

### 実装接続（想定）

- 既存機構: relationships の bond/rivalry 2軸 / h2h.history / relationship-flags / glimpse 系演出（吹き出しは頭上 `.fc1m-bubble` 系、下段クリームパネル禁止）
- **セリフは全 archetype 7種**（normal / composed / ojousama / delinquent / cool / seductive / polite）**× 役割 × 分類でパターン化し、各パターン複数本のバリエーションを持つ**（2026-07-18 Keisuke 裁定「かなりバリエーションを増やして全属性でパターンを作る」。モックの仮セリフは雰囲気承認済み）。役割構成: 名勝負=敗者(認める)+勝者(返し) / 屈辱=敗者(因縁を刻む) / 同門=亀裂(敗者)・深化(敗者) の5役割
- セリフ草案: `docs/quadrennial-drama-lines-draft-v0.1.md`（Opus 草案 → Keisuke 1次レビュー反映済み v0.2。composed は oyou-style-guide 準拠、汎用テンプレのため相手の名指しなし）
- **年齢条件**（2026-07-18 裁定）: 「4年後の再戦」を前提とするセリフは、**話者または相手が30歳超 🔧 なら選択肢から除外**（4年後に現役でいる保証のない相手に再戦を誓わせない）。草案の【年齢条件】タグで管理
- **同門(D/E)のセリフは「同じ団体なのに」系のメタ言及をしない**（2026-07-18 裁定）: 同門でも大会で当たれば本気で戦うのが礼儀。亀裂は「祝いの言葉が上滑りする気まずさ」だけで表現する
- 詳細設計（発火判定・変化量・モーダルUI）は実装前に本仕様の改訂 or 別spec化 🔧

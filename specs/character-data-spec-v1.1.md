# ■ 第2部：パラメータ設計

## 2.1 基本パラメータ（5種）

game-design-v0.1 §3.1.1 に準拠。ゲーム内では **0〜200の200段階制** を採用。

| パラメータ | 略称 | 説明 |
|-----------|------|------|
| パワー | PWR | 打撃・投げの威力、パワー技の成功率 |
| スピード | SPD | 行動順、回避率、空中技の精度 |
| テクニック | TEC | 命中率、関節技の精度、カウンター率 |
| スタミナ | STA | HP最大値、HP回復、長期戦耐性 |
| メンタル | MNT | キックアウト率、ギブアップ耐性、逆転力 |

## 2.2 潜在値カーブ（傾斜式）

Notionには **0〜100スケール** で記録。ゲームでは以下の公式で潜在値に変換:

```
潜在値 = min(185, round(初期値 × 1.3 + 60))
```

**設計意図**:
- 一律×2ではなく、**弱いキャラほど伸びしろが大きい**傾斜カーブ
- 強キャラの天井を185に抑え、200スケール中「誰も天井に届かない」緊張感を維持
- 弱キャラも育成すれば中堅レベルまで到達可能

**実効倍率の変化**:

| 初期値 | 潜在値 | 実効倍率 | 成長余地 | 該当帯 |
|------:|------:|--------:|--------:|:------|
| 95 | 184 | 1.94x | +89 | トップ選手 |
| 80 | 164 | 2.05x | +84 | 上位 |
| 65 | 144 | 2.22x | +79 | 中堅 |
| 50 | 125 | 2.50x | +75 | 発展途上 |
| 35 | 106 | 3.03x | +71 | 弱い |
| 20 | 86 | 4.30x | +66 | 最弱 |
| 11 | 74 | 6.73x | +63 | 最弱 |

**代表キャラの育成MAX到達時**:
- 阿武隈塔子（初期合計400）→ 潜在合計820（倍率2.05x）
- 高津小春（初期合計365）→ 潜在合計775（倍率2.12x）
- 阿部みのり（初期合計219）→ 潜在合計584（倍率2.67x）= パラ平均117相当
- 佐藤ヨーコ（初期合計98）→ 潜在合計428（倍率4.37x）= パラ平均86相当
- 高島さや（初期合計109）→ 潜在合計442（倍率4.06x）= パラ平均88相当

# ■ 第4部：コーチシステム

## 4.1 コーチの役割

コーチは選手の育成効率を向上させるNPC。プレイヤーが雇用・解雇する。
各コーチは得意分野を持ち、その分野のパラメータ成長率にボーナスを与える。

## 4.2 コーチデータ構造

```json
{
  "id": "coach_xxx",
  "name": "コーチ名",
  "type": "coach",
  "specialty": ["pwr", "spd"],
  "tier": "A",
  "cost": 50,
  "bonus": { "primary": 1.30, "secondary": 1.15 },
  "traits": ["厳しい指導"],
  "profile": { "age": 45, "background": "..." }
}
```

## 4.3 コーチ固有特性

| 特性 | 効果 |
|------|------|
| 厳しい指導 | 成長ボーナス+5%だが怪我率も微増 |
| 褒めて伸ばす | メンタル成長にわずかなボーナス |
| スパルタ | STAの成長に追加ボーナス |
| 理論派 | TEC成長にわずかなボーナス |
| 人脈 | スカウト評価の精度が上がる |
| 再起の達人 | 怪我からの復帰が早くなる |

## 4.5 コーチのゲーム内効果

```
成長率 = 基本成長率 × 年齢補正 × コーチ倍率

コーチ倍率:
  Sティア: primary=1.40, secondary=1.25（全パラメータに均等適用）
  Aティア: primary=1.30, secondary=1.15
  Bティア: primary=1.25, secondary=1.10
```

同時雇用上限: 3名 / 契約単位: 4週間 / 同一specialty重複: 最大値採用

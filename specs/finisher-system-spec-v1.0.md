# フィニッシャーシステム設計書 v1.0

> 作成: 2026-03-04
> ステータス: 設計完了・実装未着手

---

## 1. コンセプト

フィニッシャーは**演出レイヤー専用**の機能である。エンジンの勝敗計算・ダメージ計算には一切影響を与えない。

エンジンが出した技の結果を、キャラ固有の必殺技名・技種・決着方法に**見かけ上差し替える**ことで、「出た！」という興奮と「このキャラクターらしいな」というキャラ愛を生む。

### CLAUDE.md との整合

- **「数値は嘘をつかない」** — フィニッシャーはエンジン結果を変えない。演出のみ
- **「キャラクターの人生を覗き見る」** — 固有必殺技でキャラの個性を一発で刻む
- **「スポットライトは自然に巡る」** — 確率発動なので、出る試合・出ない試合がある。出たときが特別な瞬間になる

---

## 2. 発動条件

### 2.1 前提条件

- 攻撃側キャラにフィニッシャーデータが設定されていること
- 設定のないキャラは従来通りの技名表示（フォールバック）

### 2.2 トリガー

エンジンが**高ダメージ技**（damage値が一定以上）を選択したターンで、フェーズに応じた確率判定を行う。

### 2.3 発動確率（目安・要調整）

| フェーズ | 発動率 | 想定 |
|---------|--------|------|
| Opening | 1〜2% | まず出ない。出たら事件 |
| Mid | 3〜5% | 極めて稀 |
| End | 10〜15% | たまに出る |
| Climax | 25〜35% | ここで出る想定。ただし毎回ではない |

- 1試合に出るか出ないか、という頻度を目指す
- 確率的に2回出ることもごく稀にありうる（ハードリミットは設けない）
- 勝ち試合で出る可能性がそこそこある、負け試合ではさらに稀、くらいのバランス
- **具体的な数値は実装後のテストプレイで調整する**

---

## 3. 差し替えロジック

フィニッシャーが発動した場合、以下を上書きする：

| 項目 | 通常時 | フィニッシャー発動時 |
|------|--------|---------------------|
| 技名表示 | エンジンが選んだ技名 | フィニッシャー固有名 |
| 技種表示 | エンジンが選んだ技種 | フィニッシャーで定義した技種 |
| 決着方法 | エンジンの判定通り | フィニッシャーで定義した決着方法に差し替え可能 |

### 3.1 決着方法の差し替え

例：エンジンが関節技→ギブアップと判定しても、フィニッシャーが投げ技として定義されていれば、表示上は投げ技→フォールに切り替える。

- エンジン内部の結果（勝敗・ダメージ量）は一切変更しない
- 表示上の技種と決着タイプのみ差し替える

## 4. データ構造

### 4.1 キャラデータへの追加

```javascript
// data.js — キャラクター定義に追加
finisher: {
  name: "紫電キャメルクラッチ",   // 固有技名
  type: "submission",            // 表示上の技種（throw/strike/submission/aerial等）
  finishType: "pin",             // 決着時の表示（pin/submission/tko）
}
```

### 4.2 設定方針

- **全員に設定する必要はない**。人気キャラ、技名を思いついたキャラに絞る
- 未設定キャラは従来通り（フィニッシャーが発動しない）
- 段階的に追加可能。最初は10〜20キャラ程度から

## 5. 演出

### 5.1 カットイン演出（battle-engine.html）

フィニッシャー発動時、試合画面に以下の演出を重ねる：

1. **画面フラッシュ**（白、0.45秒フェードアウト）
2. **画面揺れ**（0.4秒）
3. **カットイン帯**（画面中央を横断、フル幅）
   - 左側: キャラ顔画像の切り抜き（既存face画像を流用）
   - 右側: フィニッシャー技名（大文字）＋キャラ名
   - 背景: 赤グラデーション＋速度線＋金枠ライン
   - 1.8秒表示後フェードアウト
4. **専用SE**（フリー素材から調達。「シャキーン」的な金属音＋インパクト音）

### 5.2 顔画像の切り抜き方式

- 既存の顔画像（256×256px）を拡大表示し、中央付近を切り抜き窓（220×150px）で見せる
- 新規画像の作成不要。全キャラの顔画像がそのまま使える
- `margin-top` / `margin-left` で切り出し位置を調整

### 5.3 カラーバリエーション（検討中）

| 色 | 用途案 |
|----|--------|
| 赤 | 標準フィニッシャー |
| 青 | クール系キャラ用 |
| 金 | 決着確定時 |

- 色分けが必要かは実装後に判断。赤一色でも成立する

### 5.4 試合ログへの反映

試合結果テキストにもフィニッシャー技名を表示する。

```
「上野原ゆいの紫電キャメルクラッチが炸裂！」
```

## 6. 実装計画

### Step 1: データ追加（小）
- data.js にフィニッシャーフィールド追加（初期10〜20キャラ分）
- キャラ名と技名のリストはけいすけさんが決定

### Step 2: エンジン判定（中）
- simulateMatch内で、高ダメージ技選択時にフィニッシャー発動判定を追加
- 発動時はmatchResult / ターンログに `finisherTriggered: true` + 差し替え情報を付与
- エンジン内部の計算には一切影響しない（純粋に戻り値へのメタデータ追加）

### Step 3: 観戦モード演出（中〜大）
- battle-engine.html にカットインHTML/CSS/アニメーションを追加
- 顔画像切り抜き処理
- SE再生（ファイルはけいすけさんが調達）

### Step 4: 試合ログ反映（小）
- 試合結果テキスト・ログ表示にフィニッシャー技名を差し込む

### Step 5: 調整（小）
- テストプレイで発動確率の調整
- 顔切り抜き位置の微調整（キャラごとに必要なら）

## 概要

v1.4 表彰式の初回実装に対する **UI全面改修**。
枠画像（7枚）を導入し、顔画像を大きく、選手セリフを追加し、豪華な表彰式体験を実現する。

## 1. 全体デザイン方針

### 1.1 枠画像

7枚の枠画像を使用。全て **同一画像サイズ、同一透過エリア（中央約440×560px）**。
装飾の豪華さだけが異なる。

| ファイル名 | 用途 | 格 |
|-----------|------|-----|
| award-frame-a.png | タイトル画面 | ★★★ |
| award-frame-b.png | 新人王 | ★★ |
| award-frame-c.png | ベストマッチ | ★★★ |
| award-frame-d.png | MVP | ★★★★ |
| award-frame-e.png | チャンピオン | ★★★★★ |
| award-frame-f.png | 殿堂入り | ★★★★★（別格・荘厳） |
| award-frame-g.png | 全受賞者一覧 | ★★★ |

配置先: `image/` フォルダ

### 1.2 CSS実装方針

- ポップアップの `max-width` を **500px** に拡大（旧400px）
- 枠画像は `.awards-box` の `background-image` として設定
- `background-size: 100% 100%` でフィット
- コンテンツは `padding` で枠の内側に配置（透過エリアに収まるよう調整）
- 枠画像ごとのCSS追加エフェクトは **不要**（枠画像自体で差別化済み）
- 殿堂入りのみ HTML構造を別格にする（§6参照）
- 背景: 現行の `rgba(0,0,0,0.9)` を維持

### 1.3 賞ごとの枠画像切り替え

各レンダラー関数で `.awards-box` に `data-frame` 属性を設定し、CSSで切り替え:

```css
.awards-box[data-frame="a"] { background-image: url('../image/award-frame-a.png'); }
.awards-box[data-frame="b"] { background-image: url('../image/award-frame-b.png'); }
/* ... g まで */
```

## 2. セリフシステム

### 2.1 分岐方式

**role（5種）× 賞** で分岐。ただし全セリフがrole色を出すわけではなく、
汎用的な一般セリフも混ぜる（8パターン中 3〜4個はrole非依存の汎用）。

使用する fighter プロパティ:
- `fighter.role`: エース / テクニシャン / パワー / スピード / オールラウンダー

### 2.2 セリフ数

1賞あたり **8パターン**。rng でランダム選出。

### 2.3 AI団体選手のセリフ

**プレイヤー団体選手と同じセリフプールから選出**。
AI選手もALL_CHARSベースで role を持っているので、同じ分岐ロジックが適用可能。

### 2.4 セリフデータ構造（data.js）

```js
const AWARD_LINES = {
  rookie: [
    // 8パターン（role寄り + 汎用混合）
    // 新人の初々しさ、驚き、感謝、決意
  ],
  bestMatch: [
    // 8パターン（勝敗に触れない。相手への敬意、試合の充実感）
    // 両者が喋るので「いい試合だった」「最高の相手だった」トーン
  ],
  mvp: [
    // 8パターン（role寄り + 汎用混合）
    // 貫禄、自信、感謝、団体への思い
  ],
  champion: [
    // 8パターン（role寄り + 汎用混合）
    // 王者の威厳、防衛への決意、挑戦者への言及
  ],
  hallOfFame: [
    // 8パターン（殿堂専用。引退セリフとは別の感情）
    // 殿堂入りの感動、後輩への思い、歴史に名を刻む喜び
  ]
};
```

合計: 5賞 × 8パターン = **40セリフ**

## 4. ベストマッチ画面（枠C）

### 4.1 レイアウト

**左右対称**。顔サイズ優先。

```
┌────────── 枠画像C ──────────┐
│                              │
│    🎬 ベストマッチ 🎬        │
│                              │
│   [顔画像]      [顔画像]     │
│    選手名1       選手名2     │
│  OVR/スタイル   OVR/スタイル │
│                              │
│         VS （小さく）         │
│                              │
│     MQ 82 / 〇〇プロレス     │
│                              │
│  「技巧と力の激突、            │
│   観客を熱狂させた一戦」      │
│        ↑ フレーバー一言       │
│                              │
│  選手1「…いい相手だった」     │
│  選手2「また戦いたい」       │
│        ↑ 両者セリフ          │
│                              │
│       [ 次へ ]               │
└──────────────────────────────┘
```

### 4.2 顔画像サイズ

2人横並びなので、単独表示より小さくなるが **最低100px** は確保。

### 4.3 VSの扱い

顔画像の邪魔にならない位置（顔の下、名前の間あたり）に小さく表示。

### 4.4 対戦情報

- 両者の名前＋OVR＋スタイル
- MQ値
- 所属団体名
- **フレーバー一言**（MQ値や対戦スタイルに基づく自動生成テキスト）

### 4.5 セリフ

**両者それぞれ1セリフ**。勝敗には一切触れない。
お互いを称える・試合の充実感を語るトーン。
AWARD_LINES.bestMatch から2つ選出（重複しないよう）。

### 4.6 AI団体の試合の場合

AI団体選手の顔画像も **表示する**（ALL_CHARSベースなので portrait-map.js で取得可能）。
セリフもプレイヤー選手と同じプールから選出。

## 6. チャンピオン画面（枠E）

### 6.1 表示団体数

**上位3団体**のみ。4位（B級）は省略して格差をつける。

### 6.2 レイアウト

1画面に全員。1位を大きく、2位3位は小さく。

```
┌────────── 枠画像E ──────────┐
│                              │
│    🏆 チャンピオン 🏆        │
│                              │
│       [1位 顔画像 大]        │
│        1位 選手名            │
│    〇〇プロレス / OVR / 人気  │
│    防衛N回（プレイヤーのみ）   │
│  「頂点は譲らない」← 大きく   │
│                              │
│  [2位顔小]  [3位顔小]        │
│   選手名     選手名          │
│  団体/OVR   団体/OVR         │
│  人気        人気             │
│  セリフ小    セリフ小         │
│                              │
│       [ 次へ ]               │
└──────────────────────────────┘
```

### 6.3 1位チャンピオンの顔サイズ

**最大**（推奨 160〜180px）。「ドカーン」感を出す。

### 6.4 2位3位チャンピオンの顔サイズ

1位より明確に小さく（推奨 70〜80px）。

### 6.5 情報量

| 項目 | プレイヤー王者 | AI王者 |
|------|-------------|--------|
| 名前 | ✅ | ✅ |
| 顔画像 | ✅ | ✅ |
| 所属団体名 | ✅ | ✅ |
| OVR | ✅ | ✅ |
| 人気 | ✅ | ✅ |
| 防衛回数 | ✅ | ❌（データなし） |

### 6.6 セリフ

- **全員セリフあり**（AI王者も）
- 1位のセリフは **大きく目立たせる**
- 2位3位のセリフは小さく
- AWARD_LINES.champion から3つ選出（重複しないよう）

### 6.7 プレイヤーが4位の場合

プレイヤー団体の王者は表示されない。上位3つのAI団体のみ表示。

## 11. Engine側の追加変更

### 11.1 awards.generate の返り値拡張

各賞のデータに `role` を含める（セリフ分岐に必要）:

```js
rookieOfYear: { id, name, orgName, ovr, age, role } // ← role 追加
mvp: { id, name, orgName, ovr, popularity, role, score } // ← popularity, role 追加
bestMatch: { fighter1: { name, ovr, role }, fighter2: { name, ovr, role }, orgName, mq } // ← 各fighter に ovr, role 追加
champions: [{ id, name, orgName, ovr, popularity, role, defenses, isPlayer, rank }] // ← popularity, role, rank 追加
hallOfFame: [{ ...(既存フィールド), role }] // ← role 追加
```

### 11.2 チャンピオン: 上位3団体フィルタ

`Engine.awards.getChampions()` で rankings の上位3団体のみ返す。
4位団体の王者は含めない。

## 12. セリフ作成ガイドライン

### 共通ルール
- 勝敗には一切触れない
- キャラが生きている感じを出す
- 8パターン中 4〜5個はrole寄り、3〜4個は汎用
- 一文〜二文程度の短さ
- 全角30文字以内を目安

### 賞ごとのトーン
| 賞 | トーン | 例 |
|----|--------|-----|
| 新人王 | 初々しさ、驚き、感謝、決意 | 「まだ夢みたいです……精一杯やります！」 |
| ベストマッチ | 相手への敬意、試合の充実感 | 「最高の相手だった。また戦いたい」 |
| MVP | 貫禄、自信、感謝、覚悟 | 「この一年、全てを懸けた結果だ」 |
| チャンピオン | 王者の威厳、防衛への決意 | 「この頂は誰にも渡さない」 |
| 殿堂入り | 感動、後輩への思い、歴史 | 「この場所に名前が刻まれるなんて……」 |

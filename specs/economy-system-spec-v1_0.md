## 設計原則

1. **コーチ費を基準にスケーリング** — S級コーチ週80万を「高コスト」の基準点とする
2. **表示単位は万円** — 内部計算・UI表示ともに万円単位。端数なし
3. **序盤は赤字前提** — 団体を育てて黒字化するまでがサバイバル期間
4. **Heatが経済を動かす** — 勢いを維持しないと収支が回らない構造
5. **🔧マーク = 調整可能パラメータ** — 実装後のバランスチューニング対象

## §1 選手給与

Overall（5パラメータ平均）に連動。成長すれば給与も上がる＝「強い選手を抱えるコスト」がゲーム判断になる。

| Overall帯 | ランク | 週給（万）🔧 | 想定キャラ層 |
|:---------:|:------:|:-----------:|:------------|
| 〜49 | 新人 | 8 | 入団直後 |
| 50〜64 | 若手 | 18 | 育成中 |
| 65〜79 | 中堅 | 35 | 一線で戦える |
| 80〜89 | 主力 | 60 | エース候補 |
| 90〜99 | トップ | 100 | 団体の顔 |
| 100〜109 | スター | 150 | 覇権級の戦力 |
| 110〜 | レジェンド級 | 200 | 到達者はごくわずか |

### ロスター規模別 週給合計の目安

| 構成 | 週給合計（万） |
|------|:------------:|
| 5人（新人中心） | 50〜100 |
| 8人（中堅中心） | 200〜350 |
| 10人（トップ混在） | 400〜600 |

### 設計意図

- S級コーチ（週80万）≒ トップ選手1人の維持費（週100万）→「コーチに投資するか、戦力を維持するか」のトレードオフ
- レジェンド級（週200万）はコーチS級2.5人分 → 抱え続けるだけで経営圧迫。引退時期の判断に影響

## §3 興行収入

2週に1回の興行が**最大の収入源**。集客力がすべてを左右する。

### §3.1 会場テーブル

| 会場ランク | キャパ（人）🔧 | 開催コスト（万）🔧 | 解放条件 |
|:---------:|:------------:|:----------------:|:--------|
| 公民館 | 200 | 30 | 初期から |
| 小ホール | 500 | 80 | 団体人気 20 以上 |
| 中ホール | 1,500 | 200 | 団体人気 40 以上 |
| アリーナ | 5,000 | 500 | 団体人気 60 以上 |
| 大会場 | 15,000 | 1,200 | 団体人気 80 以上 |
| ドーム | 40,000 | 3,000 | 団体人気 95 以上 |

### §3.2 チケット単価

| 会場ランク | 単価（万/人）🔧 |
|:---------:|:-------------:|
| 公民館 | 0.3 |
| 小ホール | 0.4 |
| 中ホール | 0.5 |
| アリーナ | 0.6 |
| 大会場 | 0.7 |
| ドーム | 0.8 |

### §3.3 集客計算

```
基本集客   = 団体人気 × 会場キャパ係数 🔧
カード補正 = メインイベント選手の個人人気合計 × 0.3 🔧
Heat補正   = Heatランクボーナス（下表）

実集客 = min(会場キャパ, (基本集客 + カード補正) × Heat補正)
```

#### Heat集客倍率

| Heatランク | 集客倍率 🔧 |
|:---------:|:----------:|
| COLD | ×0.7 |
| NEUTRAL | ×1.0 |
| WARM | ×1.2 |
| HOT | ×1.5 |
| HEAT | ×1.8 |

### §3.4 興行利益の計算

```
チケット収入 = 実集客 × チケット単価
興行利益     = チケット収入 − 開催コスト
```

### §3.5 収入例

| シナリオ | 会場 | 集客 | チケット収入 | 開催コスト | **利益** |
|---------|------|:----:|:----------:|:---------:|:-------:|
| 序盤（満員） | 公民館 | 200 | 60万 | 30万 | **30万** |
| 中盤（7割入り） | 中ホール | 1,000 | 500万 | 200万 | **300万** |
| 中盤（Heat:HOT） | 中ホール | 1,500 | 750万 | 200万 | **550万** |
| 終盤（8割入り） | アリーナ | 4,000 | 2,400万 | 500万 | **1,900万** |
| 覇権級（満員） | ドーム | 40,000 | 32,000万 | 3,000万 | **29,000万** |

## §4 その他収入

### §4.1 グッズ収入

興行時に発生。人気選手がいるほど増加。

```
グッズ収入 = Σ（ロスター内 個人人気上位3名の個人人気 × 2万）🔧
```

- 発生タイミング: 興行ごと（2週に1回）
- 人気50の選手3名 → 300万/興行
- 人気80の選手3名 → 480万/興行

### §4.2 スポンサー収入

団体人気に応じた安定収入。毎週発生。

| 団体人気帯 | 週収入（万）🔧 |
|:---------:|:------------:|
| 0〜19 | 0 |
| 20〜39 | 20 |
| 40〜59 | 60 |
| 60〜79 | 120 |
| 80〜94 | 250 |
| 95〜100 | 400 |

### §4.3 放映権収入

一定の団体人気に達すると解放される追加収入。毎週発生。

| 条件 | 週収入（万）🔧 |
|------|:------------:|
| 団体人気 70〜84 | 100 |
| 団体人気 85〜94 | 200 |
| 団体人気 95〜 | 400 |

## §7 収支バランスシミュレーション

### §7.1 序盤（開始〜団体人気20到達まで）

```
【2週間の収支】
支出: 165万/週 × 2      = 330万
興行: 利益30万 + グッズ20万 = 50万
スポンサー: 0万
─────────────────────────
2週あたり: −280万
初期資金5,000万 → 約35週（8ヶ月強）の猶予
```

**序盤のゲーム性**: 赤字は避けられない。初期資金を溶かしきる前に団体人気20に到達して小ホールを解放し、収入を増やす必要がある。

### §7.2 中盤（団体人気40〜60、NEUTRAL時）

```
【2週間の収支】
支出: 450万/週 × 2         = 900万
興行: 利益300万 + グッズ200万 = 500万
スポンサー: 60万/週 × 2      = 120万
─────────────────────────
2週あたり: −280万（まだ赤字）
```

**中盤のゲーム性**: NETURALのままでは赤字が続く。HeatをWARM以上に維持して集客×1.2以上を確保すれば黒字化の道が開ける。好カードを組み続ける＝Heat維持＝経営の生命線。

### §7.3 中盤（同条件、Heat:HOT時）

```
【2週間の収支】
支出: 450万/週 × 2         = 900万
興行: 利益550万 + グッズ200万 = 750万
スポンサー: 60万/週 × 2      = 120万
─────────────────────────
2週あたり: −30万（ほぼ収支均衡）
```

Heat:HEATまで上げれば黒字転換。**Heatが経済のキーファクター**であることが数値上も裏付けられる。

### §7.4 終盤（団体人気80、アリーナ解放後）

```
【2週間の収支】
支出: 800万/週 × 2            = 1,600万
興行: 利益1,900万 + グッズ400万 = 2,300万
スポンサー: 250万/週 × 2       = 500万
放映権: 100万/週 × 2           = 200万
─────────────────────────
2週あたり: +1,400万（安定黒字）
```

**終盤のゲーム性**: 経営は安定するが、スター選手の高額給与・コーチ費・施設維持で油断すると赤字に転落。覇権を維持するためのコスト管理。

## §8 経済に影響するシステム連携

| 連携先 | 影響 |
|-------|------|
| **Heat** | 集客倍率に直結。HOT以上で経営が回り始める |
| **MQスコア** | 名勝負→個人人気UP→グッズ収入増・集客増 |
| **ライバル度** | 決着戦→両者人気大UP→興行収入に間接効果 |
| **コンディション** | 怪我→治療費＋欠場→興行カードの質低下→収入減 |
| **育成/コーチ** | コーチ投資→選手成長→Overall上昇→給与も上昇 |
| **タイトル** | チャンピオン保持→団体人気ボーナス→スポンサー増 |
| **プロモ** | プロモ選択→個人人気UP→グッズ・集客に貢献 |

Tag Match Prototype Codex

Wrestle Manager 本体は読み取り専用のままにして、タッグ専用の進行層を外出しで試す独立プロトタイプです。 タッチ攻防、孤立、ホットタグ、カットイン、ダブルチーム、タッグMQまでを一枚で検証できます。

Match Summary

単発シミュレーションの結果。セグメント、勝敗帰属、イベント密度、タッグMQをまとめて表示します。

Batch Report

10 seeds x 10 matches の自動検証。偏りやイベント頻度のざっくり確認用です。

Play-by-Play

ターンごとの試合ログ。ホットタグやカットインなどは強調表示します。

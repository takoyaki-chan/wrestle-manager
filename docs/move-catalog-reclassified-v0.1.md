# 再配置後・全技カタログ v0.1

`Technique` プールを廃止し、同プールの12技と一部の共有技を再配置した将来案。ゲームの `src/data.js` はまだ変更していない。

## 再配置後の抽選構造

```text
使用可能技 = 共通技（72）+ スタイル技 + 装備した個人技（初期1 + 育成2、最大3）
丸め込み = 共通技の rollup だけを独立抽選
Technique = 廃止。単独のスタイル・抽選比率・選手枠を持たない。
```

- 個人技候補は、対象スタイルの選手が個人技スロットへ加えられる候補であり、全員へ自動的には追加しない。
- ビッグブーツはGrapplerのスタイル技へ移す。スナップ・スープレックスは削除する。サモアンドロップとタイガードライバーは共有技から外し、個人技候補へ移す。
- ウラカン・ラナとラ・マヒストラルは共有の丸め込み定義のまま、Aerialだけが独立丸め込み抽選で使える。スタイル技には移さない。
- 既存スタイル技のうち、他の派手技を個人技に移す判断は後続の選定で行う。

## 個人技スロットの前提

- 初期持ち技1枠 + 育成解放2枠、最大3枠。
- 個人技は特別な威力補正を持たず、使える技の候補へ追加される。
- 個人技候補の採用可否は、選手のスタイル・体格・キャラクター性・育成経路を基準に後から選ぶ。

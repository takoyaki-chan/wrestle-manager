# Wrestle Manager 開発ロードマップ（更新版）

## 現在の課題
「月に1回の試合と練習フェーズの繰り返し」が単調。練習週の約2/3が「進むボタンを押すだけ」になっている。

---

## Phase 1: ゲーム体験の根本改善（最優先）

**目標**: 毎ターンに意味ある判断が存在する状態を作る

**推奨**: Claude Code で Opus モデルを使用（特性別セリフの品質がゲーム体験の核になるため）

### Step 1: 信頼度パラメータ + メンタル再定義 ✅ 実装済み
- レスラーオブジェクトに trust (0-100, 隠しパラメータ) を追加
- メンタル値を信頼度の変動係数として再定義（mentalCoeff: 0.5〜1.5）
- 自然減衰(-1/月)、メンタル依存の増幅/減衰/自然回復の実装
- initState / makeChar / makeAIFighter / マイグレーション対応済み

### Step 2: 通知型イベント（N1〜N5） ✅ 実装済み
- 非興行週に25%確率で発生（Engine.eventSystem.generateEvent）
- トースト通知UI（選手顔アイコン＋特性別一言テキスト）
- N1:信頼低下兆候 / N2:好調報告 / N3:練習態度 / N4:人間関係 / N5:噂・前兆
- NOTIF_EVENT_TEXTS (data.js) に特性別テンプレート格納

### Step 3: 資金投入アクション ✅ 実装済み
- 個人向け: ボーナス支給(trust+8)、コスチューム新調(pop+5,trust+5)、専属トレーナー(4週×1.3倍成長)、メディア露出(pop+8)、特別治療(condition+30)
- 団体向け: 打ち上げ(全員trust+3)、合宿(全員condition+10)
- 💝ケアボタン → モーダルUI → 顔アイコン＋特性別反応セリフ
- ボーナス逓減: _bonusRepeat カウンターで効果半減
- _trainerBuff: weeksLeft/mult管理、processManageで成長計算に乗算適用
- resetSeasonalCounters: offWeek 4でシーズンカウンタリセット

### Step 4: 選択型イベント（S1〜S5, E1〜E6） ✅ 実装済み
- モーダルダイアログUI（careOverlay共用、選手顔＋特性別セリフ＋選択肢ボタン）
- S4:待遇不満 / S3:練習相談 / E6:退団希望 / S1:対戦要求 / S5:休養申出 / E1:不仲発生 / E5:スランプ相談
- 条件判定: trust閾値、condition、人気差、資金状況で発生分岐
- CHOICE_EVENT_DIALOGUES (data.js) に特性別テンプレート格納
- applyChoiceEffect: 純粋関数でroster/funds/lockerRoomMorale変更を返却

### Step 5: ファン期待度 ✅ 実装済み
- Engine.fanExpect.generate: 因縁ペア(優先度3) → 王者vs挑戦者(優先度2) → 人気対決(優先度1)、最大3件
- カード編成画面に「ファンの声」パネル表示（✓マークで達成状況表示）
- 実現時: MQ+5ボーナス（executeShow Pass 2で適用）
- Engine.fanExpect.countMatched: カード内の達成数カウント

### Step 6: 大型イベント（B1〜B4）
- 練習中の怪我、選手間対立、ファン大型リクエスト、スポンサー撤退危機
- 資金による解決ルート含む
- 工数: 中

### Step 7: セリフバリエーション拡充 + バランス調整
- プレイテストに基づく数値調整
- セリフパターンの追加（反復感の排除）
- ボーナス逓減率、面談効果等の細かい調整
- 工数: 中（継続的）

## Phase 2: プレイの方向性・動機付け

**目標**: 数シーズン遊んだ後のマンネリ防止

- **ファン期待度の拡張**: より多様な期待パターン、長期的な期待の蓄積
- **物語的な目標イベント**: 「○○にふさわしい舞台を用意できるか？」等、大型イベント（B枠）の一種として実装。KPI的な数値目標ではなく、ドラマの文脈を持った目標
- **ロッカールームの空気の可視化**: 間接的なヒント表示

---

## Phase 3: ゲームの個性を確立

**目標**: 「女子プロレスのドラマを演出するゲーム」としての独自性

- **ストーリーアーク**: 数ヶ月にわたる抗争を管理。完結時に大きな収益
- **練習システムのリデザイン**: メニュー選択制、コーチ割当の再設計

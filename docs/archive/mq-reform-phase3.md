# MQ改修 Phase 3: ドラマ減点再調整 + auto-sim最終検証

**前提**: Phase 1・Phase 2 完了後に着手すること。

---

## 1. 目的

Phase 1 で以下の変更を行った結果、baseMQ が全体的に上昇している:
- キックアウトバグ修正 → fall/tko キックアウトがドラマ回復に反映されるようになった
- 「長すぎ」ペーシングペナルティ撤廃

この上昇分を吸収し、MQ分布が適切になるようドラマ減点パラメータを再調整する。

---

## 2. 調整対象パラメータ

engine.js の simulateMatch 内:

```javascript
let dramaPenalty = 30;  // ← この初期値を引き上げる案
dramaPenalty -= Math.min(totalKickouts, 2) * 8;    // ← 回復量を引き下げる案
dramaPenalty -= Math.min(totalCounters, 3) * 2.5;
dramaPenalty -= Math.min(leadChanges, 3) * 1.5;
dramaPenalty -= Math.min(bigMoves, 6) * 0.4;
```

**調整の方針**: 初期値引き上げ or 回復量引き下げ or その組み合わせ。
auto-simの結果を見ながら決定する。

---

## 3. auto-sim による検証手順

### 3-1. まず現状のMQ分布を計測

Phase 1+2 適用済みの状態で auto-sim 100シーズン（10シード × 10シーズン）を実行し、以下を記録:
- OV帯別の baseMQ 平均・中央値・最大値
- 星分布（☆/★/★★/★★★/★★★★/★★★★★）
- 最終MQ（外部ボーナス込み）の平均・最大値
- 100点到達率

### 3-2. 目標分布

| avgOV | baseMQ平均 | 最終MQ平均 | ★★★★★到達 |
|:-----:|:---------:|:---------:|:---------:|
| 30 | 15〜25 | 20〜35 | 不可能 |
| 50 | 25〜35 | 35〜50 | 不可能 |
| 70 | 45〜55 | 55〜70 | 極めて稀 |
| 80 | 55〜65 | 65〜80 | 稀（外部全盛り） |
| 90 | 65〜75 | 75〜90 | 可能（好条件時） |
| 100 | 75〜85 | 85〜100 | 到達可能 |

**設計意図**:
- OV70以下で★★★★★はほぼ不可能
- OV80台で外部全盛りならギリギリ★★★★★圏内
- OV90+で条件が揃えば★★★★★到達
- 100点はOV100同士 + 完璧な試合展開 + 外部全盛りでのみ

### 3-3. パラメータ調整 → 再検証

目標分布と実測の差に基づいてパラメータを調整し、再度 auto-sim で検証。
分布が目標に収まるまで繰り返す。

---

## 4. 最終検証

パラメータ確定後、auto-sim 100シーズン ALL CLEAR を確認:
- エラーなし
- MQ分布が目標範囲内
- 経済バランス（集客・収入）に大きな崩壊がないこと
- orgPop推移が安定していること

## 修正1: 殿堂pt計算バグ

### 現象
橘玲美: 王座2回 / 防衛25回 → 殿堂pt: 0 と表示されている。
`calcHofPoints` の計算式（titleWins + defenses + JT×7 + PPV×9）に基づけば
最低でも 2 + 25 = 27pt でレジェンド（★★★）になるはず。

### 原因調査
HOFエントリ生成時に `hofPoints` が正しく計算・保存されていない可能性。
既存セーブデータの `hallOfFame` エントリに `hofPoints` フィールドが欠落しているか、
`careerRecord` の `totalTitleWins` / `totalDefenses` が引退時に正しく反映されていない可能性。

### 対応
1. `checkHallOfFame` および `applyHallOfFame` で hofPoints を必ず計算して保存する
2. マイグレーション: 既存HOFエントリに hofPoints がない場合、保存済みの titleReigns + totalDefenses から再計算
3. hofLevel も再計算して反映（12=★、18=★★、25=★★★）
4. 盾画像・ランクテキストも hofLevel に連動して正しく表示

## 修正2: グリッド一覧のカード幅縮小

### 現状
カード1枚が大きすぎて、一画面で見れる殿堂入り者の数が少ない。

### 変更
- カードの横幅を縮小する。現状のカード幅から **20〜30%程度狭める**
- 盾アイコンのサイズを 80px → **60px** に縮小
- 顔アイコンは 36px のまま
- テキストのフォントサイズを微調整（名前は現状維持、それ以外を1px程度小さく）
- **2列グリッドは維持**。カードが狭くなった分、左右の余白が生まれて見やすくなる
- 目標: 3〜4人分のカードが一画面（スクロールなし）で見渡せる状態

## 修正3: 詳細ポップアップの情報密度強化

### 現状の問題
詳細ポップアップに以下の情報が欠落しており、「開いた意味」が薄い。

### 追加すべき情報

#### A. キャリアハイライト年表（最重要）

ウイニングポストの重賞リスト風に、固有名詞の実績を時系列で並べる。
`careerHighlights` 配列（hall-of-fame-expansion-v2.0.md §2.1 参照）を使用。

表示形式:
```
━━ キャリアハイライト ━━

S3   👑 戦妃門王座 初戴冠
S4   🛡️ 戦妃門王座 5度防衛
S5   🛡️ 戦妃門王座 10度防衛
S6   💔 戦妃門王座 陥落（12度防衛の末に）
S8   👑 戦妃門王座 2度目の戴冠
S9   🛡️ 戦妃門王座 5度防衛
S10  💔 戦妃門王座 陥落（13度防衛の末に）
```

- 左にシーズン番号（dim色、等幅）
- 右にアイコン＋実績テキスト
- アイコン: 👑王座獲得 / 🛡️防衛マイルストーン / 💔陥落 / 🏟️JT優勝 / 🏆PPV優勝

`careerHighlights` が空の場合（既存セーブ互換）:
`careerRecord.history` があれば `buildCareerHighlights` で動的に構築。
それもなければ通算実績の数字のみ表示（現状と同等のフォールバック）。

#### B. 引退時情報

```
引退時OVR: 72（35歳）
```

`retireOVR` と `retireAge` をHOFエントリに保存し表示。
既存データにない場合は非表示（レイアウト崩れなし）。

#### C. 殿堂ランクの正しい表示

hofLevel に応じて:
- ★ 殿堂入り（12pt以上）
- ★★ ゴールド殿堂（18pt以上）
- ★★★ レジェンド（25pt以上）

ランクテキストの色:
- ★ = #bdc3c7（silver）
- ★★ = #d4a843（gold）
- ★★★ = #f39c12（bright gold）+ グロー演出

#### E. ポップアップのビジュアル仕様

| 要素 | 仕様 |
|------|------|
| ポップアップ幅 | 画面幅の80%程度（最大500px） |
| 盾画像 | 上部中央に120px幅 |
| 顔画像 | 80×80 丸型。hofLevel に応じた枠色 |
| 全身画像 | `getUpperUrl(id)` で取得。ある場合のみ表示。高さ150px、中央揃え |
| キャリアハイライト | シーズン番号を等幅で左揃え。テキストは通常フォント |
| 通算実績 | 2×2グリッド。数字を太字 |
| レジェンド特別演出 | ★★★の場合: 盾画像の周囲にbox-shadowでゴールドグロー |
| スクロール | ポップアップ内容が画面に収まらない場合は内部スクロール |

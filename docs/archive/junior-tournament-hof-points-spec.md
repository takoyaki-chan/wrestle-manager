## 1. U-20 ジュニアトーナメント

### 1.1 概要

- **名称**: ジュニアトーナメント（仮）
- **開催週**: 秋 Week 1（= シーズン Week 25）
- **形式**: 1日トーナメント（同一週内で全試合処理）
- **主催**: 国家（リーグ基金から賞金支出。団体財政に影響なし）
- **参加**: 強制（国家召集。団体・選手に拒否権なし）

### 1.2 選出ルール

- 対象: 全団体（プレイヤー団体 + AI団体）の **age ≤ 20** の選手
- 選出基準: OVR上位順
- 人数:
  - 8名以上 → 上位8名でトーナメント（準々決勝→準決勝→決勝 = 3ラウンド）
  - 4〜7名 → 上位4名でトーナメント（準決勝→決勝 = 2ラウンド）
  - 3名以下 → **不開催**
- 怪我中の選手は除外（次のOVR順の選手が繰り上げ）

### 1.3 試合処理

| ラウンド | 試合数（8名の場合） | エンジン | 備考 |
|----------|---------------------|----------|------|
| 準々決勝 | 4試合 | 通常マッチエンジン | — |
| 準決勝 | 2試合 | 通常マッチエンジン | — |
| 決勝 | 1試合 | ビッグマッチエンジン | 特別演出あり |

4名トーナメントの場合は準決勝（通常）→ 決勝（ビッグマッチ）の2ラウンド。

### 1.4 コンディション持ち越し

1日トーナメントのため、各ラウンド間でコンディションが持ち越される。

- **各試合後の固定回復**: 25%
- 計算: `condition = Math.min(100, postMatchCondition + 25)`
- 準々決勝で消耗 → 準決勝・決勝で不利、というドラマが自然に発生
- 3位決定戦は**なし**

### 1.5 賞金（国庫支出）

| 順位 | 賞金 | 支給先 |
|------|------|--------|
| 優勝 | ¥1,000万 | 所属団体 |
| 準優勝 | ¥500万 | 所属団体 |
| 3-4位（準決勝敗退） | ¥250万 | 所属団体 |
| 5-8位（準々決勝敗退） | ¥0 | — |

※国庫支出だが、賞金は選手の所属団体のfinanceに入る。選手個人の賞金総額記録はない。

### 1.6 記録

`careerRecord` に以下を追加:

```
juniorTournamentWins: Number    // 優勝回数
juniorTournamentAppearances: Number  // 出場回数
```

`history` 配列にイベントを追加:

```
{ type: 'juniorTournament', season: N, result: 'champion' | 'runnerUp' | 'semiFinal' | 'quarterFinal', prize: Number }
```

### 1.7 画面遷移とauto-sim

- **通常プレイ**: Week 25到達時に**専用画面に遷移**。トーナメント表→各試合マッチカード→試合→結果を順に表示
- **auto-sim**: 結果処理のみ（専用画面なし）。エンジンでトーナメント全試合をシミュレートし、結果をstateに格納

### 1.8 演出（大型イベント）

PPVに匹敵する大型イベントとして以下の演出を想定（実装優先度は別途決定）:

- トーナメント表（ブラケット）UI
- 決勝はビッグマッチ演出（カットイン等）
- 専用マッチカード画面
- 結果のニュースティッカー / 新聞記事
- 「○○選手がジュニアトーナメントに召集されました」通知

## 2. PPV Grand Final 賞金（新設）

既存の「出場報酬」（ランク別: 300/200/150/100万円）はそのまま維持。
それとは別に、PPV Grand Final の**試合結果に基づく賞金**を国庫から支出:

| 順位 | 賞金 | 支給先 |
|------|------|--------|
| PPVメインイベント勝者 | ¥2,000万 | 所属団体 |
| PPVメインイベント敗者 | ¥1,000万 | 所属団体 |
| 3-4位 | ¥500万 | 所属団体 |

**PPV「優勝」の定義**: サミット戦（メインイベント）の勝者。名実ともにトップ団体のトップ選手＝業界最強を証明するタイトル。殿堂ポイントの「PPV優勝 9pt」もこの勝者に付与。

`careerRecord` に追加するフィールド名: `ppvMainEventWins`（サミット戦勝利回数）

## 3. 殿堂ポイント制（Hall of Fame Points）

### 3.1 現行からの変更

**現行**: `totalTitleWins + totalDefenses >= 13` の単一条件
**新**: ポイント制に移行。複数の実績がポイントに変換され、合計で判定。

### 3.2 ポイント配分

| 実績 | ポイント | 備考 |
|------|---------|------|
| タイトル獲得 | 1pt / 回 | 自団体チャンピオン獲得1回につき |
| タイトル防衛 | 1pt / 回 | 自団体チャンピオン防衛1回につき |
| ジュニアトーナメント優勝 | 7pt / 回 | 年1回・U-20限定の希少性 |
| PPV Grand Final 優勝 | 9pt / 回 | シーズン最高峰イベント |

### 3.3 殿堂入りライン

**12pt 以上**で殿堂入り対象。

### 3.4 殿堂レベル（格）

| ポイント | レベル | 表示 | 意味 |
|----------|--------|------|------|
| 12〜17pt | ★ | 殿堂入り | 一流選手の証 |
| 18〜24pt | ★★ | ゴールド殿堂 | 時代を代表する名選手 |
| 25pt+ | ★★★ | レジェンド | 歴史に残る伝説 |

### 3.5 旧条件との互換性

| キャリアパターン | ポイント計算 | 結果 |
|-----------------|-------------|------|
| タイトル獲得+防衛 計12回 | 12pt | ★ 殿堂入り |
| ジュニア優勝 + タイトル計5回 | 7+5 = 12pt | ★ 殿堂入り |
| ジュニア優勝 + PPV優勝 + タイトル1回 | 7+9+1 = 17pt | ★ 殿堂入り |
| PPV優勝 + タイトル計3回 | 9+3 = 12pt | ★ 殿堂入り |

### 3.6 キャリアパス例

| タイプ | 実績 | pt | レベル |
|--------|------|-----|--------|
| 叩き上げ王者 | タイトル獲得3 + 防衛10 | 13 | ★ |
| エリート若手 | ジュニア優勝 + タイトル計5回 | 12 | ★ |
| PPV覇者 | PPV優勝 + タイトル獲得4 + 防衛5 | 18 | ★★ |
| 三冠 | ジュニア優勝 + PPV優勝 + タイトル2回 | 18 | ★★ |
| 完全無欠 | ジュニア優勝 + PPV優勝 + タイトル獲得5 + 防衛10 | 31 | ★★★ |

### 3.7 実装上の変更点

`checkHallOfFame()` の変更:

```javascript
// 旧: (rec.totalTitleWins || 0) + (rec.totalDefenses || 0) >= 13
// 新:
const titlePt = (rec.totalTitleWins || 0) + (rec.totalDefenses || 0);
const juniorPt = (rec.juniorTournamentWins || 0) * 7;
const ppvPt = (rec.ppvMainEventWins || 0) * 9;
const hofPoints = titlePt + juniorPt + ppvPt;
if (hofPoints >= 12) { /* 殿堂入り */ }
```

殿堂入りデータに `hofPoints` と `hofLevel` (1/2/3) を付与。

`careerRecord` に追加が必要なフィールド:
- `ppvMainEventWins: Number` — PPV Grand Final 優勝回数（既存データに存在しなければ追加）

## 4. データフロー概要

```
Week 25 到達
  → Engine.juniorTournament.select(state)  // U-20 OVR上位選出
  → トーナメント処理（3 or 2ラウンド）
    → 各試合: Engine.simulateMatch() / ビッグマッチ
    → ラウンド間: condition += 25 (cap 100)
  → 結果を careerRecord に記録
  → 賞金を careerRecord に記録
  → 殿堂ポイント用フィールド更新

Week 48 (PPV)
  → 既存PPV処理
  → PPV優勝者の careerRecord.ppvMainEventWins を更新
  → PPV賞金を careerRecord に記録

引退時
  → checkHallOfFame(): ポイント制で判定
  → hofPoints / hofLevel を算出して殿堂データに含める
```

## 5. 選手セリフ演出

### 5.1 方針

- 既存Glimpseシステムと同じ **personality × archetype** テンプレート方式
- 性格: normal / bold / easygoing / earnest / quiet / shy
- アーキタイプ: _default / ojousama / delinquent / seductive / polite / cool
- **「若手だから」という特別扱いはしない。** あくまで各選手の性格・属性を守る
- ただし全体トーンとして「この大舞台で勝ちたい」という気持ちはベースに流れる
- セリフは吹き出し表示（白背景 #f0f0f0 + 黒文字、UI共通ルール準拠）

### 5.2 セリフタイミング（全5箇所）

| # | タイミング | 表示場面 | セリフの性質 |
|---|-----------|---------|-------------|
| 1 | 召集通知 | Week 25冒頭。自団体選手が選出された通知 | 「選ばれた」ことへの反応。誇り・覚悟・意外性 |
| 2 | 各試合前（マッチカード） | 準々決勝〜決勝の対戦カード表示時 | 対戦相手への意気込み・挑発・静かな決意 |
| 3 | 各試合後（勝者） | 試合結果表示時 | 勝利の実感。次戦への意志。まだ終わってない感 |
| 4 | 決勝前（特別） | 決勝マッチカードの特別演出 | 両者のセリフを対比表示。最大のボルテージ |
| 5 | 優勝後 | 優勝確定時の演出 | 優勝スピーチ。達成感・感謝・野心 |

### 5.3 セリフ例（性格 × タイミング）

**① 召集通知**

| 性格 | セリフ例 |
|------|---------|
| bold | 「当然。呼ばれなかったら怒ってたわ」 |
| earnest | 「精一杯、やらせていただきます…！」 |
| easygoing | 「お、選ばれちゃった。ラッキー」 |
| quiet | 「……わかった」 |
| shy | 「え、私が…？ …頑張らなきゃ」 |
| normal | 「選ばれたからには、全力で戦う」 |

**② 試合前（マッチカード）**

| 性格 | セリフ例 |
|------|---------|
| bold | 「目の前の相手を叩き潰す。それだけよ」 |
| earnest | 「どんな相手でも、やることは変わりません」 |
| easygoing | 「楽しんでいこう。でも、負けないけどね」 |
| quiet | 「……やる」 |
| shy | 「緊張する…でも、逃げない」 |
| normal | 「相手がどうとかじゃない。自分の試合をする」 |

**④ 決勝前（特別・対比表示）**

| 性格 | セリフ例 |
|------|---------|
| bold | 「ここまで来て負けるわけないでしょ。最後も私が獲る」 |
| earnest | 「この舞台に立てることが…嬉しい。だから全部出し切ります」 |
| easygoing | 「決勝かー。ま、ここまで来たらやるしかないっしょ」 |
| quiet | 「……最後の一試合」 |
| shy | 「震えてるのは…きっと、嬉しいからだと思う」 |
| normal | 「あと一つ。勝てば優勝。それだけ考える」 |

**⑤ 優勝後**

| 性格 | セリフ例 |
|------|---------|
| bold | 「言ったでしょ？ 私が最強だって」 |
| earnest | 「支えてくれたみんなのおかげです…！」 |
| easygoing | 「いやー、ほんとに勝っちゃった。最高！」 |
| quiet | 「……勝った」 |
| shy | 「信じられない…。でも…嬉しい…！」 |
| normal | 「この優勝を、次のステップにする」 |

※アーキタイプ（ojousama/delinquent/seductive/polite/cool）による分岐も実装時に追加。上記はpersonality × _default の基本パターン。

  }

## 6. 新聞報道（競馬新聞スタイル）

### 6.1 方針

- 競馬のスポーツ紙のような情報密度と熱量。出走表・予想・展望・レース後詳報
- **新聞は複数ページ制を導入。** 通常週は1ページだが、ジュニアトーナメント週は2〜3ページ構成
- Engine.newspaper に組み込み、黒田記者のトーンで記事を生成
- トーナメント記事は最優先（priority最高）で必ずトップ記事になる

### 6.2 新聞の複数ページ化

現在の `weeklyNewspaper` は1ページ分の stories 配列。これを拡張：

```javascript
weeklyNewspaper: {
  pages: [
    { stories: [...] },           // 1ページ目
    { stories: [...] },           // 2ページ目（大型イベント時のみ）
    // ...
  ],
  pageCount: 1  // 通常は1。トーナメント/PPV週は2-3
}
```

UIでページ送りボタン（「次のページ →」）を追加。通常週はボタン非表示。

### 6.3 トーナメント前週（Week 24）の新聞

**1ページ目（通常記事）**: 通常の週刊記事

**2ページ目（トーナメント特集）**: 出場選手一覧 + 展望記事

内容:
- 「第○回ジュニアトーナメント出場選手決定！」見出し
- 出場8名（or 4名）の一覧表（名前・所属団体・OVR・年齢・スタイル）
- 黒田記者の展望コメント（OVR1位を本命視しつつ、伏兵に言及）
- 組み合わせ抽選結果（トーナメント表のテキスト版）

**記事トーンの例:**
> 「今年のジュニアトーナメントは粒揃いだ。筆頭は○○（××所属、OVR XX）。しかし△△（□□所属）の勢いも侮れない。波乱の予感がする。」

### 6.4 トーナメント当週（Week 25）の新聞

**1ページ目（トーナメント速報）**: トップ記事 = 優勝者

内容:
- 「○○、若き栄冠！ 第○回ジュニアトーナメント制覇」大見出し
- 決勝の結果サマリー（MQ、展開の質に応じたトーン）
- 優勝賞金1,000万円に言及
- 準優勝者にも言及

**2ページ目（全試合詳報）**:

内容:
- 準々決勝〜決勝の全試合結果一覧
- 各試合のMQ・勝敗・注目ポイント
- 「大会ベストバウト」的な記事（最高MQの試合をピックアップ）
- 敗退選手へのフォローコメント

**3ページ目（総括・未来展望）**（オプション）:

内容:
- 「今大会を振り返って」黒田記者のコラム
- 優勝者の今後の展望（「このままプロのトップ戦線でも活躍できるか」）
- 過去の優勝者との比較（2年目以降のデータがあれば）

### 6.5 新聞 Priority 設定

```javascript
Engine.newspaper.PRIORITY に追加:
  juniorTournamentPreview:   250,  // 前週展望（PPVサミットより上）
  juniorTournamentResult:    260,  // 当週結果（最優先）
```

### 6.6 黒田記者の記事テンプレート

MQやOVR差に応じてトーンを分岐：

| 決勝の状況 | 記事トーン |
|-----------|-----------|
| MQ 80+ | 「歴史に残る名勝負だ」「決勝に相応しい激闘」 |
| MQ 60-79 | 「見応えのある決勝戦」「力の拮抗した好勝負」 |
| MQ 40-59 | 「やや一方的な展開」「実力差が出た形」 |
| MQ < 40 | 「期待外れの決勝」「消化不良の感は否めない」 |
| OVR下位が優勝 | 「番狂わせ！」「誰がこの結末を予想しただろうか」 |

キャラ単位で書き直しフェーズに入る前に、明確な穴だけ埋めておく必要がある。

## 作業1: RETIREMENT_CHAMPION_WORRY_LINES の設計変更(重要)

**現状の問題:**
既存実装では `RETIREMENT_CHAMPION_WORRY_LINES` が **性格別** で7行登録されている
(お気楽/シャイ/ノーマル/寡黙/強気/感情的/真面目)。属性は `全属性共通`。

しかしこの設計では、例えば **お嬢様属性のキャラ** が引退検討時にベルト空白を
気にするセリフが、性格側(例えばノーマル)のセリフで出てしまい、
お嬢様らしくないセリフが表示される問題がある。

**修正方針:**
- **既存の性格別7行を削除**
- **属性別7行に置き換える**(デフォルト/丁寧/クール/お嬢様/蠱惑/不良/鷹揚)
- データ構造も `RET_CHAMPION_WORRY_ARCHETYPE` と同じ **archetype単位** にする

**対応データ:**
tier3a-fixes.xlsx の source が `RETIREMENT_CHAMPION_WORRY_LINES` の7行を参照。
notes 列に `REPLACE_ALL` と記載あり。既存7行は全削除してから新7行を追加すること。

**関連ソース:**
この修正の結果、`RETIREMENT_CHAMPION_WORRY_LINES` と `RET_CHAMPION_WORRY_ARCHETYPE`
の2つがほぼ同じ役割になる。統合できるなら統合を検討してもよいが、既存の
呼び出し箇所への影響を確認してから判断すること。統合が困難なら並存のままでOK。

## 注意事項

### 内容は叩き台

tier3a-fixes.xlsx のセリフ内容は**叩き台**。形式を合わせて反映するだけで OK。
後日、ユーザーがキャラ単位で全セリフを見直し、違和感のある部分を直す予定。
品質調整・吟味は不要。

### `> 2` / `> 3` は今回対象外

既存で `> 2` や `> 3` パスがほぼ空(1〜3行のみ)の状態だが、これらは
「バリエーション代替セリフ」であり、動作上は `> 1` があれば機能するため
今回は対象外とする。ユーザー判断で将来的に埋める可能性がある。

### 既存セリフは残す

今回の作業は「既存を削除して書き換え」ではなく「欠落分を追加」。
作業1(RETIREMENT_CHAMPION_WORRY_LINES)のみ例外で、REPLACE_ALL 指定あり。

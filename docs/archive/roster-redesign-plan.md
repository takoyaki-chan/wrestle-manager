# 団体画面ブラッシュアップ 実装計画（確定版）

## 概要

団体（roster）画面の所属選手詳細パネルをウイニングポスト風に全面リデザインし、
スタッフ欄のアイコン形状変更、カラーテーマ（G1クリーム）適用を行う。

道場バナー（`_renderRosterDojoHeader()`）は**一切変更しない**。

参照Mockup: `archive/prototype/roster-detail-redesign-v9.html`

---

## 決定事項まとめ（承認済み）

| 項目 | 決定内容 |
|------|----------|
| 信頼（trust）表示 | **育成タブに載せない**。セリフから類推させる設計。既存のケア選択肢ヒント（「信頼が上がる」等）はそのまま |
| やる気表示 | **育成タブに載せない**。「やる気」という独立パラメータは存在しない。hotStreak/slump/motivationLossは既存バッジで十分 |
| 開発率ラベル | **「開発率」**（既存コードのまま） |
| growthLog保持 | **無制限**（入団から引退まで全記録保持）。**引退時に削除** |
| growthLog記録対象 | **自団体の選手のみ**。AI団体・FA選手は対象外 |
| スマホ表示 | 上に立ち絵（高さ200px縮小）→ 下に情報タブの縦積み |

## 変更1: 選手詳細パネルのリデザイン

### 現状
- カード展開 → フラットなステータスバー5本 + コーチアサインselect
- `_renderRosterTrainingPanel()` が描画

### 新構造

```
┌─────────────────────────────────────────────┐
│ [折り畳みカード行 — 現行とほぼ同じ]         │
├──────────┬──────────────────────────────────┤
│          │ [能力] [成長経過] [育成] ← タブ   │
│  full    │                                  │
│  画像    │  （選択タブの内容）               │
│ 220px    │                                  │
│          │                                  │
│ 名前     │                                  │
│ 情報     │                                  │
│ オーバー │                                  │
│ レイ     │                                  │
├──────────┴──────────────────────────────────┤
```

#### 左カラム（立ち絵エリア 220px）
- `full_${PORTRAIT[id]}.webp`（512×768）を `object-fit:cover` で表示
- 下部にグラデーションオーバーレイ → その上に重ねる:
  - 選手名（`color:#3a3220`、グラデーションclipは使わない）
  - 身長 ｜ 在籍年数
  - スタイル/ロール バッジ
  - 戦績（○×△）＋ 王者バッジ等
  - ステータスバッジ（絶好調、スランプ、負傷等）

#### 右カラム — タブ①「能力」
- OVR大表示（Bebas Neue 40px）
- traits表示（右寄せ小文字）
- 5ステータスバー（**現在値のみ。Capバーは非表示**）
  - バーの色はクリーム背景用（PW:#c03030, SP:#1a8a4a, TE:#2060a0, ST:#b06010, MN:#7040a0）
- 各ステの +シーズン成長値
- 「伸びしろ大」「成長中」「残僅か」「MAX」のラベル（既存ロジック流用）
- 補足行: 人気、体調、給与
- note: 「MNは試合経験で成長します」

#### 右カラム — タブ②「成長経過」
- `growthLog` から週別成長ログをタイムライン表示
- `max-height:220px` + `overflow-y:auto` でスクロール
- 各行: Week番号、イベント内容（練習/試合結果）、成長値
- シーズン区切り線で前シーズンも遡れる
- 下部に今シーズン累計サマリー

#### 右カラム — タブ③「育成」
5項目のみ:
- 担当コーチ: selectドロップダウン（既存`changeCoachAssign()`流用）
- コーチ効果: 成長倍率、スタイルバッジ、専門一致、trait
- 成長傾向: 矢印表示（既存`getGrowthTendency()`流用）
- 開発率: 数値%＋バー（既存`getPotentialPct()`流用、ラベル「開発率」）
- フィジカル: テキスト表示（`Engine.retirement.getDeclinePresentation(c)`のstage流用）

##### フィジカルのラベル（既存stageから導出）
| stage | 表示 |
|---|---|
| none | 良好 |
| early | わずかに衰えの兆候 |
| major | 衰退期 |
| terminal | 限界 |

※ 信頼・やる気の項目は**載せない**

## 変更3: カラーテーマ（G1クリーム）

### 適用範囲
「本拠地・オフィス系」の画面にクリームを適用。試合系・メタ系はダークのまま。

| 画面 | テーマ | 備考 |
|------|--------|------|
| 今週 | ダーク | 現行のまま |
| 興行準備 | ダーク | 試合・会場の雰囲気 |
| **団体** | **クリーム** | 道場・本拠地 |
| **スタッフ募集（coach）** | **クリーム** | 団体の延長 |
| **スカウト** | **クリーム** | オフィス業務 |
| **ランキング** | **クリーム** | 情報閲覧 |
| **データベース** | **クリーム** | 情報閲覧 |
| **収支** | **クリーム** | 数字・テーブル部分。**グラフ部分のみ黒ベース維持** |
| ログ | ダーク | システムUI |
| セーブ | ダーク | システムUI |
| ヘルプ | ダーク | システムUI |

## 変更4: 成長経過ログのデータ構造（新規）

### データ構造
各選手に `growthLog` 配列を追加。

```javascript
c.growthLog = [
  {
    season: 2,
    week: 12,
    type: 'practice',     // 'practice' | 'match' | 'rest' | 'injury' | 'event'
    detail: 'パワー重点', // スケジュール名 or 試合説明
    deltas: { pw: 0.8 },  // 成長量
    opponent: null,        // match時のみ: 相手名
    result: null,          // match時のみ: 'win' | 'lose' | 'draw'
    eventTag: null,        // optional: '🔥絶好調' '📉スランプ突入' 等
  },
  // ...
];
```

### 記録ルール
- **自団体の選手のみ記録**（AI団体・FAは対象外）
- **無制限保持**（入団時点から全週分）
- **引退時に `growthLog` を削除**
- 記録タイミング: `advanceWeek()` 内の成長計算後

### セーブデータ互換性
- `growthLog` がない既存データはマイグレーションで空配列を付与
- `_migrated_growthLog` フラグで管理

## 実装順序

### Phase 1: データ基盤
1. `growthLog` 記録ロジックを `advanceWeek()` 内に追加
2. セーブデータマイグレーション追加
3. 引退処理で `growthLog` 削除
4. auto-sim 100シーズンでデータ蓄積を検証

### Phase 2: UI基盤
5. body背景を `#24221e`（セピアグレー）に変更
6. ダークパネルを `#181614`/`#12110e`（ダークウォーム）に変更（旧ネイビー `#121220`/`#0e0e15` から）
7. roster画面用のG1クリームカラー変数定義
8. `.portrait` の `border-radius` を `10px` に変更

### Phase 3: 詳細パネル描画（メイン作業）
7. `_renderRosterTrainingPanel()` → 新関数 `_renderRosterDetailPanel(c, hired)` に置換
8. 左カラム: full画像 + オーバーレイ + 情報
9. 右カラム: タブ切り替えUI
10. タブ①能力: ステータスバー（Capなし）＋基本情報
11. タブ②成長経過: `growthLog` タイムライン + スクロール
12. タブ③育成: コーチアサイン + 開発率 + フィジカル（信頼・やる気なし）
13. 負傷中の表示（育成タブ操作無効化）

### Phase 4: クリームテーマの他画面適用
14. スタッフ募集（coach）画面
15. スカウト画面
16. ランキング画面
17. データベース画面
18. 収支画面（グラフ部分は黒ベース維持）

### Phase 5: 検証
19. auto-sim 100シーズン（growthLog蓄積 + 引退時削除の検証）
20. 全選手の展開/折り畳み/タブ切り替え動作
21. レンタル選手の表示（詳細パネルなし）
22. 負傷選手の表示
23. モバイル幅レイアウト確認
24. クリーム適用全画面の文字視認性チェック

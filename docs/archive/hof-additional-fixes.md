## 修正A: 殿堂ptバグ

### 現象
橘玲美: 王座2回 / 防衛25回 → 殿堂pt: 0 と表示されている。
`calcHofPoints` の計算式（titleWins + defenses + JT×7 + PPV×9）に基づけば
最低でも 2 + 25 = 27pt でレジェンド（★★★）になるはず。

### 対応
1. `checkHallOfFame` および `applyHallOfFame` で hofPoints を必ず計算して保存する
2. マイグレーション: 既存HOFエントリに hofPoints がない場合、保存済みの titleReigns + totalDefenses から再計算
3. hofLevel も再計算して反映（12=★、18=★★、25=★★★）
4. 盾画像・ランクテキストも hofLevel に連動して正しく表示

## 修正C: 詳細ポップアップの情報密度強化

### 現状の問題
詳細ポップアップの情報量が全く足りない。設計書で決めたキャリアハイライト年表、引退時情報、正しいランク表示が入っていない。

### 追加すべき情報

#### C-0. 異名の自動生成

殿堂入り時の実績から条件判定し、最も格の高い1つを自動付与。HOFエントリに `epithet` として保存。

| 優先度 | 条件 | 異名 |
|:---:|------|------|
| 1 | 防衛20回以上 | 「絶対王者」 |
| 2 | 1度の獲得で防衛15回以上 | 「無敵の長期政権」 |
| 3 | ★★★レジェンド | 「生ける伝説」 |
| 4 | 王座3度以上獲得 | 「不死鳥」 |
| 5 | 防衛10回以上 | 「鉄壁の女王」 |
| 6 | JT優勝＋王座獲得 | 「二冠の覇者」 |
| 7 | PPV優勝2回以上 | 「大舞台の主」 |
| 8 | 王座1回＋防衛5回以上 | 「名王者」 |
| 9 | JT優勝のみ（王座なし） | 「若き日の輝き」 |
| 10 | 上記いずれにも該当しない | 「殿堂の誇り」 |

上から順に判定し、最初にマッチしたものを採用。
NPC・プレイヤー団体問わず同じロジック。

#### C-0b. 経歴に基づく語り文の自動生成

殿堂入り時の実績データ（王座回数、防衛数、スタイル、在籍期間、異名等）から
テンプレート組み合わせで紹介文を自動生成。HOFエントリに `biography` として保存。

構成（3文程度）:
1. **導入文** — 所属団体＋在籍期間＋異名を含む一文
2. **実績文** — 主要な実績を自然言語で記述
3. **締め文** — スタイルに基づく選手像の一文

テンプレート例:

```js
// 導入文テンプレート（在籍期間で分岐）
const intro = [
  // 10シーズン以上
  `${orgName}に${seasons}シーズンの歳月を刻んだ${epithet}。`,
  // 5〜9シーズン
  `${orgName}の歴史に名を刻む${epithet}。`,
  // 4シーズン以下
  `短くも鮮烈なキャリアを駆け抜けた${epithet}。`,
];

// 実績文テンプレート（王座回数×防衛数で分岐）
const achievement = [
  // 王座3回以上
  `${titleWins}度の戴冠、通算${defenses}度の防衛はいずれも団体史に燦然と輝く金字塔である。`,
  // 王座1〜2回＋防衛10以上
  `通算${defenses}度の防衛は、その圧倒的な強さの証明であった。`,
  // 王座1〜2回＋防衛5〜9回
  `${titleWins}度の王座獲得と${defenses}度の防衛で団体を支えた。`,
  // 王座あり＋防衛少
  `王座に${titleWins}度就き、その名を歴史に刻んだ。`,
  // 王座なし（JT/PPVのみで殿堂入り）
  `タイトルこそ手にしなかったが、大舞台での輝きは誰もが認めるものだった。`,
];

// 締め文テンプレート（スタイルで分岐）
const closing = {
  Grappler:   'その重厚なグラップリングの前に、挑戦者たちは次々と膝を屈した。',
  Striker:    '鋭い打撃で幾多の名勝負を生み出した闘士であった。',
  Submission: '極めの技術は芸術の域に達し、対戦相手に恐れられた。',
  Speed:      '誰にも捉えられないスピードで、観客を魅了し続けた。',
  Allround:   'あらゆる局面に対応する万能さが、長きにわたる活躍を支えた。',
  Brawler:    '荒々しくも力強いファイトで、会場を沸かせ続けた。',
};
```

生成例（橘玲美の場合）:
> *戦妃門に10シーズンの歳月を刻んだ絶対王者。2度の戴冠、通算25度の防衛はいずれも団体史に燦然と輝く金字塔である。極めの技術は芸術の域に達し、対戦相手に恐れられた。*

#### C-2. 引退時情報・異名・語り文の保存

HOFエントリに以下のフィールドを追加保存:

```js
{
  ...既存フィールド,
  retireOVR: 72,           // 引退時OVR
  retireAge: 35,           // 引退時年齢
  epithet: '絶対王者',      // 異名（C-0で自動生成）
```

表示: `引退時OVR: 72（35歳）`
既存データにない場合: epithet / biography は表示時に動的に生成してフォールバック。retireOVR / retireAge がない場合は非表示。

## 修正D: レガシーポイント計算方式の変更

### 変更前
- プレイヤー: `hallOfFame.length × 10`（上限50）
- S級: 固定50 / A級: 固定30 / B級: 固定15

### 変更後
```
レガシー = 初期値 + 殿堂pt + 対抗戦pt（上限50）
```

```js
calcLegacyScore(state, orgId) {
  const allHof = state.allHallOfFame || {};
  const hofList = orgId === 'player'
    ? (allHof.player || state.hallOfFame || [])
    : (allHof[orgId] || []);

  // 初期値（団体の既存の格）
  const BASE_LEGACY = { player: 0, org_s: 50, org_a: 30, org_b: 15 };
  const base = BASE_LEGACY[orgId] || 0;

  // 殿堂入りポイント（ランク別重み付け）
  let hofPt = 0;
  hofList.forEach(h => {
    const level = h.hofLevel || 1;
    if (level >= 3) hofPt += 13;      // ★★★ レジェンド
    else if (level >= 2) hofPt += 10;  // ★★ ゴールド
    else hofPt += 8;                   // ★ 殿堂入り
  });

  // 対抗戦通算勝利ポイント（5勝ごとに1pt）
  const battleWins = (state.battleWinsTotal || {})[orgId] || 0;
  const battlePt = Math.floor(battleWins / 5);

  const cap = 50;
  return Math.min(cap, base + hofPt + battlePt);
}
```

| 団体 | 初期値 | 成長 | 上限 |
|---|---|---|---|
| S級 | 50 | もう天井 | 50 |
| A級 | 30 | 殿堂＋対抗戦で育つ | 50 |
| B級 | 15 | 殿堂＋対抗戦で育つ | 50 |
| プレイヤー | 0 | ゼロから積み上げ | 50 |

### 追加フィールド
`state.battleWinsTotal = { player:0, org_s:0, org_a:0, org_b:0 }`
- 対抗戦の結果確定時に勝者団体の累計を+1
- マイグレーション: 既存セーブでは全団体0から開始

### `RANKING_CONFIG` の変更
- `hallOfFameLegacyPerInductee` を廃止

### ツールチップ更新
ランキング画面の Legacy「?」を以下に変更:
```
団体の歴史の重み（上限50pt）
初期値: S級50 / A級30 / B級15 / プレイヤー0
殿堂入り: ★8pt / ★★10pt / ★★★13pt
対抗戦: 通算5勝ごとに1pt
```

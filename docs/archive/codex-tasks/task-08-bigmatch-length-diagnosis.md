## 背景と問題意識

task-07 の計測で、ビッグマッチの Climax 到達率が **11.85%**、Climax 平均滞在が **0.28ターン**、終了フェーズの最多が **Mid（44.10%）** という結果が出た。額面どおりなら「大舞台に起承転結が存在しない」ことになる。

しかし**この数字は信用できない**。理由は2つ。

### 疑い①: 最大HPと試合長が釣り合っていない

| | 最大HP（st60想定） | 平均ターン数 |
|---|---|---|
| 通常試合 | `100 + st×1.8` ≒ 208 | 12.22 |
| ビッグマッチ | `170 + st×2.2` ≒ 302 | 約12.5 |

ビッグマッチのHPは通常の約1.45倍あり、さらに `pinAttemptHpThreshold` は厳しく（0.25 vs 0.35）、`kickoutMax` も多い（3 vs 2）。順当なら17〜18ターン持つはずが、実際は通常試合と同じ長さで終わっている。**計算より4〜5ターン短い。**

### 疑い②: 消耗持ち越し試合がサンプルに混入している

ジュニアトーナメント / 秋の勝ち残り戦（E-4）/ 天頂戦（C-6）はいずれもビッグマッチ扱いであり、かつ **`_hpOverride` による連戦消耗の持ち越しで開始HPが削られている**。

ビッグマッチのサンプル2,279試合にこれらが大量に混ざっているなら、観測された「Mid終了44%」は**フェーズ設計の欠陥ではなく消耗持ち越しの正常な結果**である可能性が高い。決着ターン分布に **T7 の 7.81%** という不自然なピークがあることもこの疑いを裏付ける（全快なら300近いHPが7ターンで尽きるのは考えにくい）。

### 本タスクの目的

**切り分けないままバランス調整に進むと、全快の試合が無用に長くなる。**同一条件での比較を行い、正しい数字を出すことが本タスクの唯一の目的である。

## 計測内容

### A. 実戦サンプルの分離再計測

`node test/auto-sim.js 100 42` のビッグマッチ集計を、以下の2群に**分けて**出す。

1. **全快スタート群** — `_hpOverride` が適用されていない試合
2. **消耗持ち越し群** — `_hpOverride` により開始HPが最大値未満の試合

各群について報告する項目:

- 試合数と全体に占める割合
- 平均ターン数
- 終了フェーズ分布（Opening / Mid / End / Climax / 時間切れ）
- Climax（turn 19）到達率
- 決着ターンのヒストグラム（T1〜T24）
- フェーズ別の平均滞在ターン数
- フィニッシュ級の出現回数／試合、0回率
- 決着タイプの内訳（フォール / ギブアップ / TKO / 判定）

さらに**消耗持ち越し群については開始HP％の分布**を、由来大会別（ジュニアトーナメント / 秋の勝ち残り戦 / 天頂戦 / その他）に分けて出すこと。

### B. 統制比較（本タスクの中核）

**サンプル構成の違いを排除した直接比較を行う。**実戦サンプルは通常試合とビッグマッチでカード構成（OVR差の分布・選手層）が異なるため、そのままでは比較にならない。

以下の条件で新規に計測スクリプトを組む:

- **同一の固定カード**を用いる（同じ選手ペア／同じステータス）
- **全員が全快スタート**（`_hpOverride` を一切使わない）
- **同一シード系列**で、通常ルールとビッグマッチルールの両方を走らせる
- OVR差を **0 / 5 / 10 / 15 / 20** の5帯に固定し、各帯・各ルールで **10,000試合以上**

各帯・各ルールについて報告する項目:

- 平均ターン数
- 終了フェーズ分布
- Climax到達率、フェーズ別の平均滞在ターン数
- 決着ターンのヒストグラム
- フィニッシュ級の出現回数／試合
- 決着タイプの内訳
- 格上勝率

**この表が「同じ条件ならビッグマッチは通常試合より何ターン長いのか」への答えになる。**

### C. HPの実測

Bの各帯について、**試合開始時の最大HPの実測平均**を通常／ビッグマッチ別に出す。設計上の 1.45倍が実際に効いているかを確認する。

あわせて、**1ターンあたりの平均ダメージ**を通常／ビッグマッチ別・フェーズ別に出すこと。HPが1.45倍あるのに試合が伸びていないなら、ダメージ側が食っている可能性がある。ここが判明すれば原因が確定する。

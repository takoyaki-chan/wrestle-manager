## このドキュメントの目的

派閥システム v0.8 (Phase 1b 完了) 時点で、派閥は **生まれて・喧嘩して・決着して・消える** までのライフサイクルが完備されている。しかし「血みどろの抗争」と呼べる凄惨さ・物語性が現状のプレイ体験では薄い。本計画は **派閥対決を時系列の物語として体験できる** 状態を目指し、4 つの実装フェーズに分けて整理する。

## 2. 実装フェーズ全体像

```
Phase A: F08-A 直接対決 演出強化（試合前後モーダル）
   ↓ 既存F08の上に演出を載せるだけ。最小コスト・最大効果。
Phase B: F09 派閥対抗戦 + 抗争ポイント制
   ↓ 派閥対決の本丸。シリーズ戦の演出も含む大物。
Phase C: F11 派閥宣戦布告
   ↓ 派閥単位の公式抗争宣言。F09発火を能動的に手繰る手段。
Phase D（将来構想）: F12 リーダー構想 / F13 標的指名 / 派閥解体マッチ
   ↓ 本計画では具体実装せず、骨格のみ記録
```

優先度は Keisuke 直接指示： **Phase A → B → C** までを揃える。Phase D は計画として残すのみ。

## 3. Phase A — F08-A 直接対決 演出強化

### 3.1 設計思想

CLAUDE.md「テンプレセリフ禁止」「数値は嘘をつかない」「鮮烈に見せる」に従い、**血みどろの対立は数値ではなく演出で見せる**。試合前後の2つのモーダルで、リーダー同士の感情を直接ぶつけ合う。

### 3.2 試合前モーダル（confrontation）

#### 発動タイミング
- showCard 内の F08 ロックされた試合がフォーカスされる直前
- 既存の `showRivalryPopups` (rivalry50+ 因縁宣戦布告) と**排他**：F08優先で出し、rivalry宣戦布告はスキップ

#### モーダル構成（subject-duel レイアウト）
```
┌──────────────────────────────────────┐
│  [BGM: bgm_tension_v1.mp3 静かに開始]  │
│                                        │
│  ナレーション:「○○組と△△組――その夜、 │
│       両派閥のリーダーが直接拳を交える」 │
│  ─────────────────────────────────    │
│   [Aリーダー肖像]    VS    [Bリーダー肖像] │
│      ○○組              △△組          │
│  ─────────────────────────────────    │
│   "Aリーダーのセリフ（性格×アーキタイプ）"│
│   "Bリーダーのセリフ（性格×アーキタイプ）"│
│                                        │
│   [試合へ進む →]                       │
└──────────────────────────────────────┘
```

#### セリフ要件
- 性格 6種 × アーキタイプ 6種で分岐、normal フォールバック
- **テンプレ表現禁止** — 「絶対に負けない」「お前を倒す」のような汎用セリフは避ける
- **対立の温度を反映** — hostility が 80+ では明確に憎悪を含む表現、60-79 では挑発的、40-59 では冷ややかな対峙

#### セリフ例（叩き台）
| 性格 | アーキタイプ | hostility 80+ |
|------|-------------|--------------|
| bold | delinquent | "今夜、あんたの組は終わる。覚悟しときな" |
| earnest | normal | "あなたたちのやり方は……許せない。今日で決着をつける" |
| quiet | cool | "……話すことは、もうない" |
| emotional | ojousama | "ええ、わたくしも引きませんわ。これは戦争です" |

### 3.3 試合後モーダル（aftermath）

#### 発動タイミング
- F08 ロックされた試合が `finalizeShow` 経由で結果確定した直後
- 引き分けは出さない（勝敗確定時のみ）

#### モーダル構成（victor-vanquished レイアウト）
```
┌──────────────────────────────────────┐
│  [BGM: 試合終了の余韻、静まる]            │
│                                        │
│  ナレーション:「決着。○○組が△△組を    │
│       下した――しかし、戦いは終わらない」 │
│  ─────────────────────────────────    │
│   [勝者肖像（中央大）]                  │
│      "勝者から敗者への一言"            │
│   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─        │
│   [敗者肖像（小・暗転気味）]            │
│      "敗者の悔しさ、呻き、捨て台詞"     │
│  ─────────────────────────────────    │
│   ナレーション結び:「敗者派閥は、深い    │
│       傷を負って夜の闇に消えていった」   │
│                                        │
│   [閉じる]                             │
└──────────────────────────────────────┘
```

#### 「血みどろ」感の出し方
- 勝者セリフは **踏みつけるような・容赦のない口調**。「次は誰だ」「これがあんたの限界かよ」など
- 敗者セリフは **強がり / 呻き / 捨て台詞 / 沈黙** から HP残量と性格で選択
- ナレーションは派閥単位の「傷」を語る — 「敗者派閥は割れた」「○○組の威信は地に落ちた」

#### セリフテーブル新設
- `FACTION_F08_PRE_MATCH_LINES_A` / `FACTION_F08_PRE_MATCH_LINES_B`
- `FACTION_F08_POST_MATCH_WINNER_LINES`
- `FACTION_F08_POST_MATCH_LOSER_LINES`
- すべて 6性格 × 6アーキタイプ × 最低2-3パターン
- 量産は Phase A 実装時に実施（叩き台はこの計画書）

### 3.4 派閥関係への追加変動（演出と数値の連動）

既存の F08-A 試合結果は `variationMultiplier: 1.5` で動かしているが、ここに **「血みどろ」追加効果** を加える：

| 項目 | 既存 | Phase A 追加 |
|------|------|------------|
| 勝者派閥 momentum | +12〜+18（×1.5） | 既存維持 |
| 敗者派閥 momentum | -12〜-18（×1.5） | 既存維持 |
| hostility 両方向変動 | ×1.5 | 既存維持 |
| **敗者派閥末端メンバー trust** | 変動なし | **追加 -2〜-4**（リーダー敗北の動揺） |
| **敗者派閥リーダー → 勝者リーダー rivalry** | 変動なし | **追加 +8〜+12**（直接的な敵意） |
| **勝者派閥メンバー → リーダー bond** | 変動なし | **追加 +2〜+4**（団結強化） |
| **F02③ resolution との重複** | あり | resolution 側を優先（重複加算しない） |

これらは「血みどろ」感を**数値の波及**でも表現する仕掛け。ただし数値はモーダルに出さず、後続の選手の不満イベントや F04 寝返り発火確率の自然上昇という形で結果として現れる。

## 4. Phase B — F09 派閥対抗戦 + 抗争ポイント制

### 4.1 設計思想

派閥対決を **「単発リーダー戦」から「シリーズ抗争」に拡張**する。日常の試合が累積し、ある閾値で F09 が大物として発火し、F09 で動いたポイントで決着する——という時系列の物語構造を作る。

### 4.2 抗争ポイント制（過去議論 2026-04-23 確定値）

#### データモデル

```
GameState.factionRivalryPoints = {
  "fA-fB": {                        // 派閥IDペア（昇順ソート）
    factionAId: number,
    factionBId: number,
    pointsA: number,                // A側の累積ポイント
    pointsB: number,                // B側の累積ポイント
    startedSeason: number,
    startedWeek: number,
    lastUpdatedWeek: number,
  },
  ...
}
```

#### ポイント計算ルール

**試合ベースポイント**:
| マッチ位置 | ベース |
|----------|-------|
| トップ同士（リーダー vs リーダー） | 10pt |
| 2番手同士（幹部 vs 幹部） | 6pt |
| 3番手同士 | 4pt |
| 4番手以降 | 2pt |

**補正乗算**（複数同時適用可）:
| 補正 | 倍率 |
|------|------|
| 下剋上（OVR下位が上位を倒す） | ×1.2 |
| タイトル戦 | ×1.5 |
| メインイベント | ×1.5 |
| タッグ試合 | ×0.5 |

**派閥規模倍率**（小さい方の派閥サイズで決まる、F09 以外で適用）:
| 小さい方のサイズ | ベース倍率 |
|---------------|----------|
| 3人 | ×1.5 |
| 4人 | ×1.25 |
| 5人以上 | ×1.0 |

#### 決着条件

1. **先取 100pt** → 抗争決着（勝者派閥 / 敗者派閥確定）
2. **40週経過** → F06 強制発火（プレイヤーが和解 / 決裂を選ぶ強制イベント）
3. **派閥消滅** → ポイント破棄、勝者なし
4. **hostility 両方向20未満が4週継続** → 自然沈静化、勝者なし

### 4.3 F09 派閥対抗戦（過去議論確定値）

#### 発火条件

- 対立型派閥（`inHostility: true`）が2つ存在
- 両方向 hostility ≥ 70
- 両派閥の OVR上位5名合計の差が 15% 以内（5名に満たない場合は在籍人数分、最低3名）
- 両派閥とも momentum ≥ -20
- クールダウン 52週

**後半補正**（物語終盤にクライマックスを誘う）:
| プレイ年週 | 確率倍率 |
|----------|---------|
| 〜52週 | ×1.0（基準値） |
| 〜104週 | ×1.3 |
| 〜156週 | ×1.5 |

#### F09 規模

- **3対3〜5対5** のシングル戦（小さい方の派閥サイズに合わせる、最大5）
- 組み合わせは**OVR順位マッチ推奨**（トップ同士、2番手同士、3番手同士、…）
- メイン〜セミ下の連続3〜5枠を**固定**（プレイヤーは差し替え不可、`_f09Locked` フラグ）
- 興行名が自動で「○○組 vs △△組 対抗戦」に変更

#### F09 のポイント計算（特例）

- 各試合の基本ポイントに **×1.8 倍率**（派閥規模倍率は適用しない）
- **興行勝ち越しボーナス**: 勝利数の多い派閥に **+15pt**

→ F09 一発で **30〜70pt** 動く想定。決着の主戦場になる。

#### F09 演出構成（3スロット）

```
[スロット1] 興行冒頭 — 対抗戦オープニング演出
   ナレーション「○○組 vs △△組、ついに全面対決」
   両派閥メンバー全員のポートレイト並列表示
   両リーダーの宣戦セリフ
   
[スロット2 〜 N] 各試合
   試合前: 簡略版F08-A 風 confrontation（軽量）
   試合: 通常進行
   試合後: 簡略版 aftermath（軽量、勝敗ポイント表示）
   
[最終スロット] 興行終了 — 対抗戦結果演出
   両派閥の獲得ポイント表示
   勝ち越し派閥にスポット
   抗争全体の決着なら追加セレモニー（敗者派閥の崩壊 ナレーション）
   敗者派閥リーダーの捨て台詞
```

### 4.4 勝者・敗者効果（決着時）

**勝者派閥**:
- momentum +40
- 全メンバー trust +5、メンバー → リーダー bond +5
- 派閥抗争 appeal ボーナスを 12週間継続加算
- `factionTimeline` に `RESOLVED_BY_POINTS` エントリ追加

**敗者派閥**:
- momentum -30
- 全メンバー trust -5
- F04（寝返り）発火確率 ×2 を 12週間
- F05（亀裂）発火確率 ×2 を 12週間
- リーダーが authoritativeTag を持っていれば喪失
- → 「再結束 or 崩壊の岐路」（§10連鎖マトリクスの重要分岐点）

**両派閥共通**:
- hostility 両方向 -40
- `factionRivalryPoints` エントリ削除
- F08 / F09 クールダウンリセット

### 4.5 UI仕様（派閥タブ）

抗争中ペアに「抗争進行度バー」を表示：

```
🔥 ○○組 vs △△組 抗争中（48週目）
  ○○組  ████████▒▒▒▒▒▒  47pt
  △△組  █████▒▒▒▒▒▒▒▒▒  32pt
  決着まで あと53pt
```

- 数値は表示する（既存の hostility と違い、ポイントは「進行度」として可視化する方が物語性が増す）
- 強制和解までのカウントダウン表示（残り○週）

## 5. Phase C — F11 派閥宣戦布告

### 5.1 設計思想

F09 が「自然に湧き上がる大物」だとしたら、F11 は「派閥が自ら手繰り寄せる宣戦」。プレイヤーが社長として、派閥リーダーから「○○組と全面対決を望みます」という直訴を受けて承認する形。承認すれば F09 発火条件のうち hostility 70 のハードルを下げる促進効果を持つ。

### 5.2 概要（詳細は Phase B 完了後に別計画書で詰める）

- 発火条件: hostility ≥ 50 + リーダー trust ≥ 50 + 派閥 momentum ≥ +10 + クールダウン 36週
- 演出: ステージ全画面、リーダー直訴 → 社長判断
- 選択肢: A 承認（F09 発火条件のうち hostility 閾値を50に緩和、12週間） / B 棚上げ（リーダー trust -5）/ C 禁止（リーダー trust -10、authoritativeTag 喪失リスク）
- ナレーション: 「○○組から正式な宣戦布告が届いた。受けるか、退けるか――」

### 5.3 やらないこと（Phase C 概要段階）

- ❌ 自動承認（社長の判断を経由しない宣戦布告は意味を持たない）
- ❌ 数値ブースト（F11 が直接 momentum を上げない、F09 の発火条件を促進するに留める）
- ❌ 抗争中以外での宣戦布告（hostility ≥50 が前提）

## 8. 全体を通して守る原則（CLAUDE.md準拠）

1. **キャラクターのドラマに見える** — 派閥対決の演出はすべて「その子の言葉と感情」で語る。テンプレ排除
2. **社長の視点から自然** — F09 / F11 は社長が知り得て介入できる範囲に収める
3. **数値の動きに説得力** — ポイント・hostility・momentum の変動はすべて試合結果という客観事実から導かれる
4. **演出が浮かぶ** — 各イベントの演出イメージを実装前にこの計画書で確定済み
5. **既存バランスを壊さない** — 集客 appeal は既存の `+30` キャップと排他処理を維持
6. **派閥は物語装置、最適化対象ではない** — ポイントを表示するが、それは「進行度」であって「最適化スコア」ではない設計

## 9. 確認したい事項（Keisuke へ）

### Q1. Phase A 試合前モーダルの規模感
- ① ステージ全画面（重量級、F08 モーダル並みの存在感）
- ② careOverlay 中量版（既存F08モーダルと同系統、軽快）
- ③ 簡易ポップアップ（既存 confrontation popup と同程度、3秒で消える）

→ 推奨は **②** （F08 モーダルとの統一感、かつ試合進行のテンポを殺さない）

### Q2. F09 開催形式
- ① **1興行集中**（1夜で対抗戦の全試合を消化、当該興行の名前が変わる）— 過去議論の確定値
- ② 3週連続シリーズ（3つの興行にわたって展開、毎週ポイントが動く）
- ③ ハイブリッド（小規模対抗戦は ①、大規模は ②）

→ 過去議論では ① で確定。Phase B 開始時にこの確認を再度取る

### Q3. 抗争ポイントの可視化
- ① 派閥タブの進行度バーで数値表示（`47pt` のように具体的に）
- ② 帯フレーバーのみ（「優勢」「拮抗」「劣勢」のような文字）
- ③ 数値 + フレーバー併用

→ 推奨は **①** （ポイント制は「進行度」が物語を駆動するので、隠すと意味がなくなる）

### Q4. Phase A の優先度
今すぐ着手するか、Phase B（F09）を先に進めるか。

→ 推奨は **Phase A 先行**。F08 は既に発火しており、その演出強化は短納期で体感を底上げできる。F09 は新規アーキで時間がかかるので、Phase A で「血みどろ感」を確認してから Phase B に入ると、F09 演出設計が一段スムーズになる。

## 設計思想

### 「ひとつ屋根の下」

育成は「選手一人一人を個別に鍛える」のではなく「場の質をマネジメントする」ことが中心。

- **コーチは「個別指導」** — 担当3人の成長速度を直接ブースト
- **ロッカールームは「全体場」** — 雰囲気をテキストで間接的に伝える。数値メーターは出さない
- **固有特性は「その選手の個性」** — コーチや場に乗る形で効果を発揮（コーチ効果と被らない）

## §1 コーチシステム

### §1.1 基本構造（セッション31確定事項を継承）

- コーチ全員「練習を見る人」（同職種内で誰を選ぶかのゲーム）
- 格：C / B / A の3段階（Sは将来拡張用に保留）
- 1コーチ担当3人まで。コーチが付かない選手も存在（「誰に付けるか」が経営判断）
- セリフ敬語統一。状況に応じた情報提供
- 高格コーチはorgPop低いと来ない

### §1.2 能力値（E〜Aの5段階ランク、Sは将来用）

| 能力 | 効果 |
|---|---|
| 指導力 | 担当選手の成長速度に直結 |
| 観察眼 | コーチ報告の「質」に影響。高ランクほど具体的で有用な助言 |

トレードオフ：指導力は「育成速さ」、観察眼は「情報質」。両方高いコーチは稀。

### §1.3 指導力ランクの成長倍率 🔧

| ランク | 倍率 | 体感 |
|:---:|:---:|---|
| なし | ×1.00 | 基準。成長はするが壁を超えるのに時間がかかる |
| E | ×1.05 | ほぼ誤差 |
| D | ×1.08 | わずかに感じる |
| C | ×1.12 | いないよりマシ。安いなりの効果 |
| B | ×1.18 | 明確に違う。育成の本命 |
| A | ×1.25 | かなり速い。エース候補に全力投資 |
| (S) | ×1.35 | 将来用 |

**コーチなし = ×1.0。救済なし。**シンプルに差がつく。

### §1.4 得意スタイル（1つ）

- パワー型 / スピード型 / テクニック型 / オールラウンド
- 選手のスタイルと一致 → 指導力効果に **+0.05 加算** 🔧
- 不一致でもペナルティなし（ボーナスがないだけ）

計算例：A級コーチ（パワー型）にGrappler（PWR主力）の選手をつけた場合
→ PWR成長倍率 = 1.25 + 0.05 = **×1.30**

設計意図：B級一致（1.23）≒ A級不一致（1.25）→「安いB級でもスタイル合えば十分戦える」選択肢

### §1.5 コーチ特性（6種）

| 特性 | 効果 |
|---|---|
| 新人育成 | OVR60以下選手の成長速度さらに上昇 |
| ベテラン調整 | OVR80以上選手の衰え（ピーク後低下）遅延 |
| コンディショニング | 担当選手のコンディション消耗軽減＋怪我確率低下 |
| 実戦主義 | 試合に出すほど成長しやすい（試合経験ボーナス増） |
| 引き出し上手 | 担当選手の試合MQにわずかボーナス |
| 人脈持ち | スカウト候補に追加選手が出現する確率アップ |

※ 旧「フィジカル管理」と「メンタルケア」を「コンディショニング」に統合

### §1.6 コーチ枠（orgPop連動）

| 枠数 | 条件 | 担当可能選手数 |
|:---:|---|:---:|
| 1枠 | 初期〜 | 最大3人 |
| 2枠 | orgPop 25 | 最大6人 |
| 3枠 | orgPop 50 | 最大9人 |

### §1.7 コスト（格内でばらつく価格帯方式）

| 格 | 雇用費の幅 | 給料/週の幅 | 中央値 | 出現条件 |
|:---:|---|---|:---:|---|
| C | 30〜80万 | 5〜12万 | 8万/週 | 最初から |
| B | 150〜300万 | 18〜35万 | 25万/週 | orgPop 30前後 |
| A | 400〜800万 | 50〜90万 | 70万/週 | orgPop 55前後 |

### §1.8 コーチプール

- 総数：30〜40人（C多め、A少なめ）
- 毎シーズン5〜8人の雇用候補を提示
- 雇用中コーチは継続（シーズン変わっても勝手にいなくならない）
- 見送った候補は次シーズンで入れ替わる（同じ人がまた来ることもある）
- 既存8人はリデザインしてプールの一部にする（顔画像あり）
- 残り22〜32人は顔画像なし（絵文字アイコンで対応）

## §2 観察眼システム

### §2.1 コーチ報告の仕組み

| 項目 | 仕様 |
|---|---|
| 発生タイミング | 非興行週、4週に1回程度 |
| 対象 | 担当選手1名について報告 |
| 表示場所 | manage画面の練習場エリア下部に吹き出し表示 |

### §2.2 ランク別の情報レベル

| ランク | 報告の質 | 例 |
|---|---|---|
| E〜D | 雰囲気のみ（誰のことかすら不明） | 「最近、練習に身が入っているようです」 |
| C | 選手名が出る | 「高津選手、調子が良さそうですね」 |
| B | パラメータがわかる | 「高津選手のスピードが伸びてきています」 |
| A | 天井接近の示唆（trainCapの間接情報） | 「高津選手のスピード、そろそろ頭打ちかもしれません」 |

### §2.3 揺らぎ

報告は100%正確ではない。「コーチの言うことが絶対」にしない。

| ランク | 的外れ確率 🔧 |
|:---:|:---:|
| E〜D | — （元々曖昧なので的外れも何もない） |
| C | 20% |
| B | 20% |
| A | 5〜10% |

### §3.2 練習場の風景イラスト

| 項目 | 仕様 |
|---|---|
| サイズ | 1200 × 200px |
| 形式 | WebP、200KB以内推奨 |
| 内容 | プロレス練習場（リング＋ロッカースペース複合） |
| トーン | ダークテーマに馴染む暖色系、やや彩度控えめ |
| 配置 | CSS `width: 100%` でレスポンシブ縮小 |

### §3.3 雰囲気テキスト（5段階＋揺らぎ）

#### 表示判定ロジック

```javascript
// 表示のたびにノイズを加える
displayScore = lockerRoomMorale + randomRange(-10, +10)  🔧

// 5段階判定
if (displayScore <= 20)  → 段階1
else if (displayScore <= 40) → 段階2
else if (displayScore <= 60) → 段階3
else if (displayScore <= 80) → 段階4
else → 段階5
```

実値が境界付近の場合、週ごとに違う段階が表示されうる。プレイヤーは数値を逆算できない。

#### テキストパターン（各段階3〜4パターンからランダム選択）

**段階1（displayScore 0〜20）：**
- 😶「練習場が静まり返っている」
- 😶「誰も目を合わせようとしない」
- 😶「重い空気が漂っている」

**段階2（displayScore 21〜40）：**
- 🌥「どこかよそよそしい空気がある」
- 🌥「最低限のメニューだけこなしている」
- 🌥「会話が少ない」

**段階3（displayScore 41〜60）：**
- ☁「淡々とメニューをこなしている」
- ☁「いつも通りの練習風景」
- ☁「特に変わった様子はない」
- ☁「黙々と汗を流している」

**段階4（displayScore 61〜80）：**
- 🌤「声が飛び交っている」
- 🌤「練習に熱が入っている」
- 🌤「選手同士でアドバイスし合っている」
- 🌤「活気のある練習場」

**段階5（displayScore 81〜100）：**
- 🔥「自主練する選手が増えている」
- 🔥「練習場に笑い声が響いている」
- 🔥「全員の目つきが違う」
- 🔥「チーム全体に勢いがある」

## §4 施設システム廃止後の吸収先

施設システムは廃止確定（セッション31）。各効果の吸収先：

| 旧施設効果 | 吸収先 | 仕組み |
|---|---|---|
| 成長速度 | コーチ指導力 | §1.3の倍率テーブル |
| 怪我回復 | ケアアクション | 特別治療一本化（既存） |
| コンディション回復 | **一律固定** | 旧施設ボーナス消滅。練習週+15、休養週+25のまま |
| プロモ効果 | orgPop連動 | orgPop高いほどプロモ効率UP |
| スカウト割引 | orgPop連動 | 詳細は別途 |

**コンディション回復ボーナスはorgPop連動にしない。**「強者がさらに強くなる」構造を避ける。

## §6 固有特性リデザイン

### §6.1 設計原則

| 領域 | 所属 | 理由 |
|---|---|---|
| 成長速度に直接関わるもの | コーチ側 | 指導者の専門性 |
| 先天的な成長カーブの形 | 選手側 | 生まれ持った体質 |
| 怪我・体質 | 選手側 | コーチが体質を変えるのは不自然 |
| 試合内容 | 選手側 | 試合中のパフォーマンスは選手自身 |
| 団体の空気 | 選手側 | 人間性の問題 |
| 育成の質を変える | コーチ側 | 指導方法の違い |

### §6.2 変更点

| 特性 | 変更内容 |
|---|---|
| **努力家** | 効果変更：~~練習成長+15%~~ → **成長の週次ランダム下限が0.5→0.75に上昇**（下振れしにくい。上限は変わらない） |

```javascript
// 通常の選手
weeklyVariance = randomRange(0.5, 1.5)  🔧

// 努力家の選手
weeklyVariance = randomRange(0.75, 1.5)  🔧
```

「破天荒」がハイリスク・ハイリターン型、「努力家」がローリスク・平均リターン型。対極の関係。
既存セリフ（「コツコツやっていきます」等）との整合性も維持。

### §6.3 確定固有特性リスト（25種）

変更があったもののみ記載。他はtraits-v2.1.mdから変更なし。

| # | 特性名 | カテゴリ | 効果（v1.0） |
|---|---|---|---|
| 10 | 努力家 | 育成・成長 | **週次成長ランダム下限 0.5→0.75**（旧：練習成長ボーナス） |

# 試合画面UI刷新 実装計画

## Phase 0: 下準備
- `data.js` に `getFullUrl(id)` 関数を追加
- `getUpperUrl(id)` が実際にstand画像パスを返している問題の整理（関数名リファクタ or 新規 `getStandUrl` 追加）
- upper画像のパス（`image/upper/upper_{name}.webp`）を返す正しい関数の確認・整備

## Phase 1: レイアウト刷新（見た目の土台）
- HUDバーをConcept Fベースに刷新
- 中央パネルを全中央寄せ化
  - ターン表記: T8 → ターン 8
  - 実況ナレーション: 16px太字化
  - 技名: 18px太字化
  - バトルログ: 9px縮小化
  - 左ボーダー廃止
- 選手パネル情報エリアの変更
  - スタイル名を正式名称に（Power Fighter → Grappler等）
  - ライバルバッジ追加（両パネル）
  - タイトルマッチ時ベルト表示
  - 名前クリック → showFighterPopup連携

## Phase 2: ダメージ表現の刷新
- 旧演出の廃止: `exhausted`、`critical`（画像暗転系）、`flash-hit`
- 通常ダメージ: shake + ダメージ数字ポップアップ（既存の改修）
- クリティカル: 画面フラッシュ + 強shake + 金色52px大数字
- HP25%以下: 足元赤グロー（height:45%, 130%幅、0.45 opacity）

## Phase 3: カットインシステム刷新
- 既存のcutin-overlayをupper画像ベースに置き換え
  - cutin-portrait: 56×56丸face → 100×150矩形upper
  - cutin-text: 15px → 20px太字化
  - 全てクリックで消す方式に変更（自動消去廃止）
- ダメージセリフ追加（赤系配色、性格×属性分岐）
- ダメージボイス追加（濃い赤、28px、属性のみ分岐）
- セリフデータの分岐構造を整備（性格×属性テーブル）

## Phase 4: ビッグムーブ演出
- セリフカットイン + bigmoveCharge SE → 技名表示 → bigmoveImpact SE + ダメージ
- 発動条件のロジック実装（ダメージ閾値判定、1試合0〜3回制限）
- 決め技系セリフデータの追加（性格×属性）

## Phase 5: カウンター演出
- ビッグムーブと同じ導入 → 技名表示 → COUNTER!スライドイン（防御側方向から）+ 技名吹き飛ばし
- カウンターSEの差し替え（重い衝撃音「バケッ！」）
- カウンター判定ロジックとの連携

## Phase 6: 対戦カード紹介画面
- battle-engine.html内に試合前画面を新設
- full画像2体のポスター構図（幅50%、object-fit:cover、object-position:center 95%）
- 中央テキスト（興行名、試合番号、試合形式、選手名VS、対戦成績、バッジ）
- NEXTボタン → ゴングフラッシュ → FIGHT! → パネルスライドインの遷移演出

## Phase 7: 統合テスト・調整
- 各演出の連続発動テスト（ビッグムーブ→カウンター→ダメージセリフの連鎖等）
- SE音量バランス調整
- 対戦カード → バトル → 決着までの通しフロー確認

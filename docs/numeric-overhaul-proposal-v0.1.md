## 1. なぜ全体見直しが必要か(診断の要約)

### 1a. 絶対値アンカーの腐食

当初のステ帯(50〜80級)を前提に書かれた式が、現在のステ帯(90〜130超)で意味を失っている。

| 箇所 | 式 | 何が起きているか |
|---|---|---|
| 命中率 | `hitBase(92〜97) + TE×0.17 − SP×0.18`、上限98 | TE×0.17≒17〜22が固定オフセット化し、小〜中技は全員上限張り付き。**TEの差が消える** |
| キックアウト | `MN/100×0.50`、上限0.45 | **MN90で満タン。90超は1ptも効かない** |
| ロープエスケープ | `MN/100×0.45`、上限0.40 | 同上(MN≈89で満タン) |
| カウンター | `3 + TE×0.055 − SP×0.07`、下限2 | 高OVR帯では下限張り付き。TEを盛っても+1〜2pt |
| タッグ タッチ成功 | `(SP−70)×scale`、`((PW+TE)/2−70)×scale` | **「70」が平均だった時代のアンカー**。現在は全員が大幅プラス側 |
| ダメージのTE/SP項 | `+TE×0.115 +SP×0.115`(線形) | 生きているが、PW×0.27の半分以下で存在感が薄い |
| OVシーリング | OV100超の減衰セグメント追加済み | **インフレ対応済みの良い先例**(2026 MQ再設計) |

対照的に ST(HP+2.5/pt)とPW(ダメージ+0.27/pt)は無限線形で常に満額。「ST/PWは実、TE/MNは虚」という
非対称が、調査で観測した「同OVRでST+24が61.7%勝ち、MN+24が最弱」の正体。

### 1b. 個別パッチでは較正できない(プロトタイプ実測)

命中/カウンターの差分化+キックアウトのsoft-knee化だけを試作してエンジンに当てたところ
(各ペア6000試合):

- 良い方向: TE+24の対バランス勝率がOVR60〜120の全帯で50%超に単調化(50.1/52.5/52.7/57.9%)。
  橘実配分(OVR101) vs 倉見実配分(OVR107)が42%台→**52.7%**(TEの差がOVR6差を配分で相殺できる世界になった)
- 副作用: PW+24がOVR100帯で65.0%に暴騰 / MN+24がむしろ弱体化(44.4%) / 同格戦の時間切れ2.6%→0.0% /
  カウンター0.76→0.55回 / 格上OVR+10の勝率71.0%→67.5%

**式1本の差し替えで系全体が連動して動く。** 命中・カウンター・脱出・ピン・momentumは互いに
結合しており、個別修正の積み重ねでは必ずどこかが壊れる。裁定4の「オーバーホール覚悟」は実測からも正しい。

### 1c. エンジンには未解明の創発挙動がある

全員同ステ(100均等)でスタイルだけ変えた対戦で、Strikerは自分の攻撃の8.93%がカウンターされるのに
相手(Allround)は3.08%しかされない(約3倍の非対称)。カウンター率の式は同ステなら同値のはずで、
この非対称は式からは出ない=grit・フィニッシャー頻度・momentumの相互作用による創発。
Brawlerに至ってはミス率・被カウンター・与ダメの全指標で互角以上なのに勝率34.2%。
**機構を計装で特定する前に技データを触ってはいけない**(数字は繊細に使え)。

## 2. 新しい数値原則(「数字の働き方」の再定義)

1. **差分/比率参照**: ステの効きは絶対値でなく「相手との差」または「比率」で書く。
   両者が強くなっても式の意味が変わらない=レンジインフレ耐性。`ovrGapDmgExponent`(OVR比)と
   `ovCeiling`のOV100超セグメントが良い先例
2. **単調性保証**: 盛った1ptは必ず効く。ハードクランプは廃止し、上限が必要な確率は
   soft-knee(現行帯までは現行式のまま、その先は逓減しながら漸近)にする。
   「表示上は強いのに実効ゼロ」を系から根絶する
3. **同格アンカー**: 同ステ同士の試合の姿(平均ターン13.9 / カウンター0.76回 / 脱出0.05回 /
   MQ79.4 / 時間切れ2.6%)を較正の不変条件として固定。全体を作り直しても「試合の見た目」は守る
4. **尖りプレミアム**: 同OVRなら尖りがやや有利、を明示的な較正目標にする(裁定2)

## 3. 段階計画

### P0: 計装+ベースライン凍結(式を触る前に)

- test/ に試合バランス計測ハーネスを新設: スタイル×OVR帯×尖り形のグリッド勝率、同格基礎指標、
  決着タイプ分布、カウンター/grit/フィニッシャーの発生機構トレース
- 現行エンジンの全計測値を「ベースライン」として保存。以後の全変更はこの差分で評価する
- §1cの3倍非対称の機構をここで特定する(P2の前提)
- 成果物: ベースラインレポート+再現ハーネス(以後もずっと使う回帰資産)

### P1: 試合式の再設計(本丸)

- 命中: `hitBase + (TE_atk − SP_def)×k1`(差分化)
- カウンター: `base + (TE_def − SP_atk)×k2`(差分化・上限緩和)。TE凸の見せ場=切り返し
- キックアウト/エスケープ: MN80まで現行式、80超はsoft-knee漸近(上限0.60/0.52へ漸近)。
  プロト式: `0.40 + 0.20×(1 − exp(−(MN−80)/40))`
- ピン耐性(MN×0.20)・終盤粘り(_mnLateMult)は線形で生きているので維持
- ダメージのPW/TE/SP配分(0.27/0.115/0.115)と`ovrGapDmgExponent`は、尖りプレミアム目標と
  格差表現目標を両立する点をグリッドで探す
- 係数はk1/k2/soft-kneeパラメタ/ovrGapDmgExponentの4軸グリッド較正(40季)→採用値100季確認

**較正目標**: +24級尖り(PW/SP/TE/ST)の対バランス勝率がOVR60〜120の全帯で52〜58%。
MN+24は48〜53%(防御ステのため勝率換算は控えめでよい、ただし全帯で死なない)。

**不変条件(対)**: 同格50.0±1.0% / ±40級尖りが60%を超えない(尖り一辺倒の最適解化防止) /
格上OVR+10勝率 71.0%±3pt / 同格アンカー指標±10% / kickoutMax=2維持 / auto-sim不変条件ALL CLEAR

### P2: スタイル間バランス(技プール)

- 現状: 同ステでも平均勝率 Aerial 55.8 / Grappler 53.7 / Allround 53.4 / Submission 50.0 /
  Brawler 44.7 / Striker 42.4%。ただし威力プール(期待d)はほぼ同等で、敗因は創発挙動(§1c)
- P0の機構特定を受けてから、技データ(d値分布/カテゴリ構成)ではなく**機構側**
  (カウンター条件・grit付与・フィニッシャー選択)の較正を優先する
- 較正目標: 全スタイルの同ステ平均勝率を47〜53%に。不変条件: スタイルの「らしさ」
  (カテゴリ構成比・決着技の顔ぶれ)を変えない

### P3: trainCap生成の個性保存(独立・即決可能)

現行 `cap = pot × U(0.55, 0.80)ステ独立` は、pot尖りSD≥12のキャラで31.5%の確率で最強ステが
入れ替わり、尖りSDを0.87倍に薄める。候補を127テンプレ×300生成で比較済み:

| 方式 | 最強ステ保存率 | 尖りSD比 | キャラ間総量ばらつき | 備考 |
|---|---|---|---|---|
| 現行(独立) | 68.5% | 0.87 | SD0.036(基準) | |
| 共通F幅0.10+個別ε±0.075 | 81.3% | 0.74 | 0.036(維持) | 保存は中途半端 |
| 共通F幅0.21+個別ε±0.02 | 94.2% | 0.68 | 0.061(1.7倍) | 当たり外れ拡大が副作用 |
| **ソート方式(推奨)** | **100%** | **1.28** | **0.036(完全維持)** | 独立に引いた係数をpotの順位に再割当 |

**推奨: ソート方式**。分布(各ステ係数・総量ガチャ)は現行と完全同一のまま、potの形が必ず保存され、
むしろ尖りが強調される(尖りSD比1.28)— 裁定2「尖りが強い世界」と方向一致。
トレードオフ: 「生成のたびに形が揺れる」余地はなくなる=キャラの形が固有になる
(三本柱「その子だけの個性」とは整合すると判断)。
適用は新規生成のみ。既存セーブの選手は再生成しない(衰えの履歴を捏造しないのと同じ原則)。

## 3. 選定原則

1. **フィニッシャー優先**（d≥14の★決着技を先に）— 現行試合プールのフィニッシャー候補を全カバーする
2. **Allround全カバー** — 43人と最大勢力なのにフィニッシャー候補が無く、d12〜13大技がそのまま決着技になるため8技全部を埋める
3. **同名バリアント相乗り** — カバレッジ計画の共用3条件（握り・受け姿勢・認識）を満たすものだけ1枚に束ねる
4. **v0.2で固有選定専用技へ抜ける技は初回から除外** — 個人技スロット実装が先のため（§7参照）

## 4. 撮影バッチ（30枚）

撮影契約の要点: 同一カメラ・同一解像度・無地背景・UI非表示、**攻め手は画面右・左向き**、1技につき3パス（完成構図必須、単体2枚は完全分離時必須）。

**向きの緩和（2026-08-12）**: 撮影はポーズが一番きれいに読める向きでよい。標準向きと逆になった場合は台帳に「要反転」と記録し、Codexが取り込み時に**3パス一括で水平反転**して正規化する（3枚バラバラに反転しない — 照合QAが壊れるため）。グレー人形には鏡写しで破綻する非対称要素がなく、ゲーム側も実行時に `move-visual-layer` 全体を反転して使う設計のため安全。180度回転（上下逆）とは別物なので混同しない。

## 7. 除外と後送（理由付き）

- **v0.2で固有選定専用技へ抜ける5技**: ファルコンアロー(48)／みちのくドライバーII(49)／エクスプローダー(50)／フェニックス・スプラッシュ(55)／ハリケーンラナ(47)。現行はAllround/Aerialの大技だが再配置後に基礎プールから抜けるため初回30から除外。絵が無い間は統合仕様のフォールバック（立ち絵+技名）で表示は壊れない。**v0.2実装が長引く場合はみちのくII・フェニックスの繰上げを再検討**（現行43人Allroundのフィニッシャーであるため）
- **タイガー(79)／ドラゴン(80)／フィッシャーマン(81)スープレックス**: ポーズ庫に束があり撮影コスト低。固有選定専用行きだが、個人技スロット実装が近づいたら早取りする
- **丸め込み（スクールボーイ等）**: カバレッジ計画の制作順3（P1段階）へ後送。アキレス腱固め・ネックシザース・首四の字も同じくP1で扱う
- **スワップ候補（庫に束あり）**: フランケンシュタイナー(38, 前後2種)／シャイニング・ウィザード(40, Aerial+Striker相乗り)／アルゼンチン・バックブリーカー(37)／STF(23, v0.2でSubmissionスタイル技化)／ネックハンギングツリー(86)。第2波の改変が難航した技はここから差し替える

## 8. 撮影モデルとグリーンバック規定（2026-08-12 追加）

GPT Imageの人形化で顔・髪・衣装は消えるため、モデル選びの基準は見た目ではなく**識別性とシルエット**のみ。ゲーム内キャラは使わず、**撮影専用の固定2体**を作ってセーブし、全30枚+M0で同一の2体を使う（人形化の攻守判定の安定・カタログ全体の比率一貫・単体パス照合のため）。

| 項目 | 攻め手 | 受け手 |
|---|---|---|
| 明暗 | 暗色系（黒／紺の単色衣装、暗色髪） | 明色系（白／ライトグレーの単色衣装、明色髪） |
| 髪型 | ショート or まとめ髪（長髪は接触部と輪郭を潰すため禁止） | 同左 |
| 衣装 | 装飾なしのレオタード／ワンピース水着型。スカート・リボン・フリル・小物禁止 | 同左 |
| 体型 | 同身長・標準体型・胸は控えめ（絵は全キャラ共用のため体格差をつけない） | 同左 |
| 肌 | **褐色** | **色白** |
| 靴 | シンプルなショートブーツ | 同左 |

- 明暗の向きは人形化後の「攻め手=中間グレー／受け手=明るいグレー」と揃える。GPT Imageの攻守割当が自然に決まり、取り違えも一目でわかる
- **肌も攻守で分ける（攻め手=褐色／受け手=色白、Keisuke発案 2026-08-12）**。レオタード型では画面の大半が肌（腕・脚）であり、卍固め・ロメロ・脚四の字など四肢が絡む関節技の分離ミスは肌同士の接触部で起きる。肌ごと分ければ絡んだ手足の帰属が判別できる
- 背景は標準クロマグリーン単色。**衣装・髪に緑系を一切入れない**（受け手の明色は白／銀寄り。黄緑系禁止）
- 照明はフラットにし、背景に濃い影を落とさない（パイプラインQA「不要な影を残さない」に直結）
- 表情は消えるが、大口開け等で頭部シルエットを変えない
- 最初の試作（16_powerbomb 作り直し）でこの2体を確定し、以後変更しない — パイプラインの「RGB値と線幅は最初の試作で固定」と同じ原則

# Draft Step 4.5: 仕様変更メモ

spec §3〜§7 に対する改訂。ユーザーが別途specに反映予定。

## 変更1: プレイヤー事前選択制

**旧**: 全候補が assessedValue 高い順に自動登壇し、プレイヤーは全員に対して交渉画面を見る
**新**: ドラフト速報画面で★星ボタンをトグルし、最大4名(=獲得上限)を事前選択。交渉画面は選択した候補のみ表示。

- 候補カードに★ボタン追加(金縁+星点灯でトグル)
- ヘッダーに「選択中 N/4」進捗表示
- 未選択で「交渉開始」→ 注意喚起
- spec §3.2/§3.3 に該当

## 変更2: 候補別分岐ロジック

| playerSelected | aiParticipants | 処理 |
|:---:|:---:|:---|
| YES | >= 1 | 交渉画面(セリUI) |
| YES | 0 | 単独指名確認モーダル(Yes→即契約/No→流札) |
| NO | >= 2 | 裏で自動セリ(ヘッドレス)→業界紙風ログ通知 |
| NO | 1 | AI自動落札→ログ通知 |
| NO | 0 | 流札→フリー市場→ログ通知 |

- spec §3.3 の「全候補を順番にセリ」から「選択候補のみセリUI」に変更
- 非選択候補はバックグラウンド処理でプレイヤーの待ち時間を削減

## 変更3: 業界紙まとめ記事

ドラフト全処理完了後に weeklyNewspaper に「今期新人獲得まとめ」ページを追加:
- 各団体の獲得選手一覧
- 注目選手の行き先
- 流札選手一覧

## 変更4: EMPRESS安全網タイミング

変更なし(全候補処理完了後)。通知を§6.4ドラマ演出モーダルに統合。

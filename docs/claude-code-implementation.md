## タスク: コーチシステム抜本改修 — 実装

### 背景
コーチシステムの設計が完了した。添付の `coach-system-redesign-v0.2.md` に全仕様が記載されている。これをゲームに実装する。

### 実装の優先順位

実装は以下の順序で、**1つずつ**進める。1タスク完了ごとに報告して次に進む。

#### Phase 1: データ層（data.js）
1. ALL_COACHESの全35人を新しい能力体系に書き換える
   - gMult（基礎練習効率）を各コーチに設定
   - 特殊能力（abilities配列）を設定
   - フレーバー能力（flavor）を設定
   - 給料・契約金を新しい値に更新
   - 等級（grade: 'A'/'B'/'C'）を設定
2. スタイル名変更: 「Speed」→「Aerial」（表示名・内部名の両方）
3. STYLE_WEIGHTSをv0.2のテーブルに更新（v0.1で確定済みの値）

#### Phase 2: エンジン層（engine.js）
4. コーチ枠拡張システム
   - G.coachSlots（初期1、最大4）
   - 枠拡張の資金投資処理（500万/1,000万/5,000万）
   - A級雇用条件（4枠目開放済みチェック）
5. 特殊能力のエンジン実装（確定値を使用）
   - 延命術: applyDecay/wear計算で×0.50
   - 限界突破: growthCalcでtrainCap+4（コーチ装着中のみ）
   - 弱点克服: growthCalcで最低ステのtrainCap+5
   - スター製造: popularity変動でrawGain×1.2
   - 才能開花: ageMultiplierでペナルティ期の下限0.90
   - 怪我耐性: injury.checkで確率×0.6 + 重傷→中傷40%
   - 人心掌握: trust低下計算で×0.90
   - 闘志注入: スランプ脱出判定で確率×2.0
   - ステ特化: pickGrowthStatで対象ステの選択率×1.40
   - 新人育成: OVR≤50の選手にcalcGrowth×1.5
6. フレーバー能力のエンジン実装（§8の暫定数値を使用）

#### Phase 3: UI層
7. スタッフ室画面の改修
   - 枠拡張ボタンの表示（ロック/解放状態）
   - A級/B級のシルエット表示（未解禁時）
   - コーチカードに能力・フレーバーの表示
8. 解禁演出のGlimpseポップアップ（§7の仕様通り）
   - 2枠目開放時: コーチが喜ぶ
   - B級解禁時: 選手が喜ぶ
   - 3枠目開放時: コーチ2人が喜ぶ
   - 4枠目・A級解禁時: 選手+コーチの特別演出

### 重要な注意事項

- **1タスクずつ進める。** 複数をまとめて実装しない
- **実装前に計画を説明して承認を得る。** いきなりコードを書かない
- game-system-roadmap.md をセッション終了時に更新する
- スクリーンショット検証・ブラウザ起動・サーバー起動は不要（ユーザーが自分でテストする）
- スタイル名「Speed」→「Aerial」の変更は表示テキスト・内部キー・CSSクラスなど全箇所を網羅すること
- 限界突破はコーチを外したらtrainCapが元に戻る実装にすること（外した時点でcapを超えているステは即座には下がらないが、以降の成長天井が元に戻る）

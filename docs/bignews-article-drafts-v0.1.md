## 執筆方針（本ファイル全体で厳守した規範）

- 格言・箴言・気取った締めの一文は禁止。事実の記述で締める（2026-07-16 確定のナレーション方針）
- ベルト／王座に「世界」を冠しない
- **「MQ」等の内部変数名を紙面に出さない**。試合評価は必ず「試合評価」「業界最高評価」と日本語化
- 大会名・団体名などの固有名詞は連呼しない（`{orgName}`・`{stage}`・`{titleName}` は原則1記事に1回）。選手名 `{name}` の反復は既存テンプレ（tenchosenResult 等）に倣い許容
- 選手の鉤括弧つき発言は入れない。「関係者によれば」「場内の反応」など地の文で書く
- 誇張の乱発（「奇跡」「伝説」）を避け、事件の大きさは事実の並べ方で伝える
- データ構造は既存 `NEWS_HEADLINE_TEMPLATES` に合わせた `{ headline, body }` 配列（各 type 3 バリエーション）

## 1. `mqAllTimeRecord` — 歴代最高評価の更新

**発火条件（§5.4）**: 業界の歴代最高試合評価（`state.mqRecord`）が更新された週の新聞。全団体・全経路・PPV・天頂戦も対象（業界記録1本）。priority 300超で一面を保証し `BIG_NEWS_TYPES` に登録。頻度想定＝数シーズンに1回。

**使用変数**: `{name}`（勝者）／`{name2}`（敗者）／`{mq}`（新記録値）／`{prevRecord}`（旧記録）／`{stage}`（舞台: 通常興行/PPV/天頂戦など）／`{orgName}`

### バリエーション

```
A.
headline: 業界最高評価を更新――{name}対{name2}、{mq}点
body: {orgName}の{stage}で行われた一戦が、試合評価{mq}点を記録した。これまでの業界最高は{prevRecord}点。数字の上で、{name}と{name2}の攻防が過去のすべてを上回ったことになる。勝者は{name}。ただ、この点数は勝った側だけのものではない。敗れた{name2}がいなければ、この数字は出ていない。

B.
headline: {mq}点――過去最高の試合評価が生まれた夜
body: {name}が{name2}を下した一戦の評価は{mq}点。旧記録の{prevRecord}点を上回り、業界の歴代最高が更新された。舞台は{stage}。派手な決着ではなかったが、攻防の密度がそのまま数字に出た。狙って出せる記録ではない。この日、それがひとつ塗り替わった。

C.
headline: 歴代最高評価、{mq}点に更新――{name}が刻んだ数字
body: {orgName}のメインで{name}と{name2}が繰り広げた攻防が、試合評価{mq}点を叩き出した。これまでの最高は{prevRecord}点。差はわずかだが、記録は記録だ。勝ったのは{name}。この数字は当分、業界が試合を測るときの基準として残る。
```

**週頭ポップアップ リード文言（号外1行）**
- `号外――業界最高評価を更新する一戦が生まれた`
- `歴代最高評価、{mq}点。記録が塗り替わった`

## 2. `hotProspectDebut` — 大物ルーキーのデビュー

**発火条件（§5.4）**: trainCap-OVR 125+（上位2%級）の新人のデビュー戦が行われた週。素質の数値は紙面に出さず、スカウト筋の評判・関係者の証言として書く。頻度想定＝数シーズンに1回。

**使用変数**: `{name}`／`{orgName}`／`{age}`／`{result}`（勝敗）

### バリエーション

```
A.
headline: {orgName}に逸材――{age}歳{name}、デビュー戦を終える
body: {name}がリングに上がった。{age}歳。デビュー戦は{result}に終わった。数字上の勝敗より、スカウト筋がこの新人に付けていた評価のほうが業界を騒がせている。関係者の間では「ここ数年で一番の素材」との声が入団前から流れていた。実物を見た記者席のざわめきが、その評判を裏づけた。

B.
headline: 数年に一人の素材か――{name}、{age}歳で初陣
body: {orgName}の新人{name}がデビューした。結果は{result}。荒削りな部分は目についたが、体の使い方に{age}歳とは思えない下地がある。複数のスカウトが入団前から動いていたという情報もあり、獲得競争の裏側込みで注目されていた一人だ。今後の伸び方を、業界が黙って見ている段階に入った。

C.
headline: {name}デビュー。場内のざわめきが評判を裏づけた
body: {orgName}の{name}が{age}歳でリングデビュー。デビュー戦そのものは{result}だったが、この日集まった関係者の関心は勝敗の先にあった。育成畑の人間が「化ける」と口を揃える新人は、そう頻繁には出てこない。誇張を嫌う本紙としても、この素材は本物の部類だと書いておく。
```

**週頭ポップアップ リード文言（号外1行）**
- `号外――数年に一人の逸材がデビューした`
- `{orgName}に大型新人。場内がざわついた一夜`

## 3. `fatedRivals` — 期待のライバル関係

**発火条件（§5.4）**: 同年代（年齢差1歳以内）・trainCap-OVR 117+ の逸材が2人、初めて同じ時代に揃った年の、2人目のデビュー戦週。1団体内に限定しない（別団体の場合あり）。頻度想定＝稀。

**使用変数**: `{name}`／`{name2}`／`{orgName}`／`{orgName2}`（別団体の場合あり。同一団体なら両者が同じ団体名になる）／`{age}`

### バリエーション

```
A.
headline: 同年代の逸材が二人――{name}と{name2}、同じ時代に立つ
body: {age}歳前後の有望株が、ほぼ同時期に頭角を現した。{orgName}の{name}と{orgName2}の{name2}。育成関係者の見立てでは、どちらも一団体の看板を背負える器だという。同世代に競う相手がいるかどうかで、選手の伸びは変わる。この二人が並んだこと自体が、今後十年の業界地図に関わってくる。

B.
headline: {name}と{name2}――{age}歳、次の十年を占う二人が出揃った
body: 同学年といっていい二人の有望株が、そろってリングに立つ時代が来た。{orgName}の{name}、{orgName2}の{name2}。ともに早くからスカウト筋の評価が高く、実戦でも下地の違いを見せている。まだ何も成し遂げてはいない。ただ、同じ年頃に競える相手がいる巡り合わせは、そう多くない。

C.
headline: 好敵手の予感――{age}歳の{name}と{name2}が同時代に
body: {orgName}の{name}と{orgName2}の{name2}が、ほぼ同年代で頭角を現した。二人が直接ぶつかったわけではない。それでも、これだけの素材が同じ時期に揃うのは珍しく、業界関係者は早くも先の対戦を口にしている。競う相手の存在が両者をどこまで押し上げるか。答えが出るのは数年先だ。
```

**週頭ポップアップ リード文言（号外1行）**
- `号外――同年代の逸材が二人、同じ時代に揃った`
- `次の十年を占う二人が出揃った`

## 4. `topChampionInjury` — トップ団体王者の重傷

**発火条件（§5.4）**: 業界ランキング1位または2位の団体の現王者が、重傷以上の怪我を負い長期欠場となった週。頻度想定＝稀。（※ AI団体の王者・怪我データの追跡範囲は実装前調査が必要と proposal に明記）

**使用変数**: `{name}`（王者）／`{orgName}`／`{titleName}`／`{weeks}`（欠場見込み週数）

### バリエーション

```
A.
headline: {orgName}の{titleName}王者{name}が重傷、{weeks}週の長期欠場へ
body: 業界上位の一角に痛手。{titleName}を保持する{name}が試合中に負傷し、復帰まで{weeks}週前後を要する見込みとなった。王座を空位とするか暫定を立てるかの判断を迫られ、挑戦戦線は宙に浮く。上位団体の看板が一枚欠けることの影響は、その団体だけにとどまらない。

B.
headline: 王者離脱――{name}が{weeks}週欠場、{titleName}戦線に空白
body: {orgName}の{titleName}王者{name}が重傷を負った。欠場は{weeks}週規模とみられ、防衛ロードは白紙に戻る。ランキング上位団体のトップが長期で不在になるのは、ここ数シーズンでも例がない。空いた頂点を誰が埋めるのか、それとも帰りを待つのか。団体は難しい判断を抱えることになった。

C.
headline: 上位団体に激震。{titleName}王者{name}、長期離脱が決定的
body: {orgName}の看板を背負う{name}が試合で重傷を負い、{weeks}週の欠場が避けられない情勢となった。{titleName}をどう扱うかは団体の判断待ちだが、いずれにせよ王座は当面動かせない。強い王者がいる前提で組まれていた対戦の流れが、根元から止まった。影響の広さは、これから表に出てくる。
```

**週頭ポップアップ リード文言（号外1行）**
- `号外――上位団体の王者が重傷、長期離脱へ`
- `{titleName}戦線に空白。{orgName}の看板が欠けた`

## 実装メモ（P5/P6 担当への申し送り）

- 4 type とも既存 `NEWS_HEADLINE_TEMPLATES` の `{ headline, body }` 構造にそのまま追加できる形で書いた（変数名は proposal §5.4 の指示に準拠）。
- `{result}`（勝敗）は「勝利」「白星」「黒星」等どの語を差すか未確定。本文は「デビュー戦は{result}に終わった」「結果は{result}」の形で、名詞1語が入る前提で組んである。差し込む語の確定が必要。
- `fatedRivals` は同一団体（`{orgName}` == `{orgName2}`）でも別団体でも文が破綻しないよう「{orgName}の{name}と{orgName2}の{name2}」の並列で統一した。同一団体時の軽い重複（同じ団体名が2回）を許容するか、要判断。
- 号外リード文言はモーダル1行チラ見せ用（§5.3）。変数を含まない汎用案と、含む具体案を各 type に1本ずつ用意した。

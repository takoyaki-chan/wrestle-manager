# 殿堂詳細ポップアップ UI修正指示

> 前提: 殿堂入りシステム＋ポイント修正は実装済み
> 本書は詳細ポップアップの見た目・情報密度の修正のみ

---

## 1. 異名をもっと大きく目立たせる

現状: 「絶対王者」がプロフィール情報の中に小さく埋もれている。

変更:
- フォントサイズを大きくする（名前と同程度かやや小さい程度）
- 装飾線（── ──）で囲んで存在感を出す
- 金色（var(--gold)）で表示

```
橘玲美
── 「絶対王者」──
```

---

## 2. 語り文のフォント色を明るくする

現状: フォントが暗くて背景の黒に沈んでいる。読みにくい。

変更:
- 語り文の色を `rgba(232,230,224,0.85)` 程度の明るい白系にする
- 行間はそのままでOK
- イタリック体は維持

---

## 3. 全身画像の背景にグラデーション

現状: 真っ暗な背景にキャラクターが浮いている。

変更:
- 全身画像の背景に薄い暗めグラデーション（中央が少し明るく、端が暗い円形グラデ）を敷く
- 例: `background: radial-gradient(ellipse at center, rgba(255,255,255,0.05) 0%, transparent 70%);`
- キャラクターが背景に馴染むようにする

---

## 4. 引退時OVR・年齢の追加

プロフィールエリアに追加:
```
最高OVR 90（S6）
引退時OVR 72（35歳）
```

`retireOVR` / `retireAge` がHOFエントリにない場合は非表示。

---

## 5. 全体の中央揃え・配置の統一

現状: 情報が左に寄ったり、各要素がバラバラに配置されている。

変更:
- ポップアップ内の全セクションを **中央揃え（text-align: center）** を基本にする
- プロフィールエリア（顔アイコン＋テキスト）は左寄せのままでOKだが、プロフィールブロック自体は中央に配置
- 語り文: 中央揃え
- 通算実績: 中央揃え
- キャリアハイライト: 左揃え（年表なので左の方が読みやすい）だが、ブロック自体は中央配置
- 殿堂pt / 殿堂入りシーズン: 中央揃え
- 各セクション間にセパレータ線を入れてメリハリをつける

---

## 6. キャリアハイライト年表の追加（最重要）

現状: キャリアハイライト年表が入っていない。これが殿堂タブの核心。

`careerHighlights` 配列を使い、固有名詞の実績を時系列で表示。

```
━━ キャリアハイライト ━━

S3   👑 戦妃門王座 初戴冠
S4   🛡️ 戦妃門王座 5度防衛
S5   🛡️ 戦妃門王座 10度防衛
S6   💔 戦妃門王座 陥落（12度防衛の末に）
S8   👑 戦妃門王座 2度目の戴冠
S9   🛡️ 戦妃門王座 5度防衛
S10  💔 戦妃門王座 陥落（13度防衛の末に）
```

- 左にシーズン番号（dim色、等幅フォント）
- 右にアイコン＋実績テキスト
- アイコン: 👑王座獲得 / 🛡️防衛マイルストーン / 💔陥落 / 🏟️JT優勝 / 🏆PPV優勝
- ブロック自体は中央配置、テキストは左揃え

`careerHighlights` が空の場合:
`careerRecord.history` があれば `buildCareerHighlights` で動的に構築。
それもなければこのセクション自体を非表示。

---

## 7. セクション間のセパレータ

各セクションの区切りにセパレータ線を入れる:

```
[盾画像 + ランク]
━━━━━━━━━━━━━━━
[プロフィール（顔＋名前＋異名＋情報）]
━━━━━━━━━━━━━━━
[全身画像]
━━━━━━━━━━━━━━━
[語り文]
━━━━━━━━━━━━━━━
[キャリアハイライト]
━━━━━━━━━━━━━━━
[通算実績]

殿堂pt / 殿堂入りシーズン
[閉じる]
```

セパレータ: `border-top: 1px solid rgba(255,255,255,0.1)` 程度の薄い線。

---

## 全身画像について

`getFullUrl(id)` を使用する（upperではなくfull画像）。
ある場合のみ表示。ない場合はレイアウト崩れなし。高さ200px程度、中央揃え。

---

## 実装の優先順

1. キャリアハイライト年表（核心機能）
2. 中央揃え・配置統一（見た目の基本）
3. 異名の拡大
4. 語り文のフォント色
5. 全身画像グラデーション背景
6. 引退時OVR
7. セパレータ

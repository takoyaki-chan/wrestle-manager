## コアシステム

### 最大HP式と ST の寄与（2026-07-20 追加）
- 最大HP = `hpBase + ST × hpScale`（通常戦は `ENG`、大一番は `BIGMATCH_ENG`）
- **不変条件: HP係数を変更するときは「ST1ポイントが総HPに占める割合」を維持すること。** 旧仕様（`100+ST×1.8`）で 0.87%。この比率が ST とパワー等の力関係を決めており、崩すとキャラクターの個性（スタミナ型）が意味を失う
- 総HPを増やすときは `hpScale` も同じ割合で増やす。`hpBase` だけ増やすと ST の価値が目減りする
- **実例**: task-09（2026-07-20）で平均試合長を伸ばすため `198+ST×1.55` としたところ、ST1ポイントの寄与が 0.87%→0.53% に落ち、大一番で ST90 と ST40 のHP差が +43%→+15% まで縮小した。task-10 で `141+ST×2.50`（通常）/ `272+ST×3.50`（大一番）へ配分を戻して是正

### MQスコア（減点制 v2.0）
- **天井（OVシーリング）**: avgOV≤50: `20+OV×0.60` / ≤80: `50+(OV-50)×1.10` / 超: `83+(OV-80)×0.85`。clamp(15,100)
- **ドラマ減点**: 基本-30。KO×8（上限2回）・カウンター×2.5（上限3）・逆転×1.5（上限3）・大技×0.4（上限6）で回復
- **ペーシング減点**（2026-07-20 現行コードに合わせて修正。**下限のみで上限減点は存在しない**）: Tier別に判定し、大一番(tier2)は 13ターン以上=0 / 10以上=3 / 未満=12、通常戦は 7ターン以上=0 / 5以上=3 / 未満=12。特性「引き出し上手」保持時は各閾値が緩和される（大一番 10/7、通常 5/3）
  - 旧記載「7-14=0、5-16=3、<5=12、17+=6（だらだら）」は実装から失われており誤り。長い試合へのペナルティは無い
- **決着減点**: フォール/ギブアップはフェーズ連動(Climax:0/End:1/他:3)、ピン=0、丸め込み=1、TKO=2、タイムアウト=10
- **外部ボーナスキャップ+15**: 因縁+3/+4/+6、タイトル+5、コーチ+2、超満員+3/大入り+2、会場0-2
- **タイトルマッチ格差ペナルティ**: OVR差>10:MQ-3、>20:MQ-6（キャップ後別途減算）

### Trust（信頼度）
- **基本値**: 出場+1.53/不出場-2.64（noAppearStreak蓄積）
- **舞台追加**: メイン+1.07/タイトル+1.84/因縁+0.77/好試合+0.54
- **Trustグラビティ**: gravity=0.04, anchor=60（出場のみ均衡=60-70）
- **高信頼帯逓減**: trust70+でgainMult適用
- **low帯回復減衰**: trust<40で出場回復に減衰
- **M3低MQ不満**: MQ<40で-0.46/興行
- **ケアOVR傾斜**: 低OVRほど効果大
- **ロッカールーム士気**: trust<40で連続関数ペナルティ+人望/ムードメーカー重複処理

### Bond/Rivalry（人間関係2軸）
- **データ構造**: 非対称2軸（bond/rivalry）×全キャラ間。`relationships["idA>idB"] = {bond, rivalry}`
- **初期値**: ベース(50/0)+同団体ボーナス(+3〜+8)+OVR近接(rivalry+2〜+6)+性格相性マトリクス(σ=2.5)+バックストーリー初期関係2-4組
- **週次処理**: 接触あり→bond50方向微減+rivalry微減、接触なし→凍結+rivalry超低速減衰、同団体+0.2〜+0.5/週
- **同団体ボーナスbond60天井**: bond55から減衰し60で停止。60超は試合/イベントでのみ
- **性格不一致摩擦**: 相性≤-3で-0.15/週
- **世代近接ボーナス**: 年齢差3以内で+0.1/週（別枠、実質65天井）
- **Trust連動**: R1低bond同興行(-0.3/ペア)、R2孤立(-0.4/興行)、R3退団bond低下(-(bond-50)×0.2)、R4ライバル勝利(+0.2)、R5ライバル敗北(-0.3)
- **待遇不満蓄積型**: 給与不公平(-0.4)/後輩高給(-0.6)/タイトル機会なし(-0.5)/ロスター過密(-0.35)
- **試合結果13種**: M-01〜M-13（ベースライン/僅差好勝負/圧勝/名勝負/PPV/タイトル/因縁決着/怪我/連敗/キャリアベスト等）
- **団体運営14種**: O-01〜O-14（入団/退団/引退/残留/解雇/突然離脱/引き抜き/レンタル/prove mode/引退撤回等）
- **ケア/成長/大型10+8+6種**: C系(激励/休暇/合宿/嫉妬等)、G系(ブレークスルー/スランプ/OVR格差等)、E系(対抗戦/対立/メディア/表彰式等)

### 因縁（Rivalry称号 + 決着）
- **称号tier**: 0→1(因縁: rivalry30+/matches2+)→2(宿敵: rivalry50+/mst3+/bmq70+)→3(宿命の相手: rivalry70+/mst3+/bmq80+)
- **降格**: tier3→2(rivalry≤50), tier2→1(≤35), tier1→0(≤20+48週未対戦)
- **片側因縁**: 片方rivalry50+/もう片方30未満→MQ+1。認知イベント(勝利→被攻撃側rivalry+8〜+12)
- **決着**: 2回上限。1回目: 宿敵+試合MQ≥閾値→bond分岐（bond≥50=好敵手🤝 / bond<50=宿怨💀）。2回目: 宿命の相手。MQボーナス: 因縁+2/宿敵+4/宿命+6/好敵手+2
- **宣戦布告/決着ポップアップ**: 2段階演出。4週クールダウン

### 因縁イベント設計（Bond/Rivalry→ゲームプレイ）
- **第1層（双方条件4象限）**: 親友/憎い敵/好敵手的/無関心
- **第2層（非対称条件）**: 片思い/一方的敵意/温度差/クロス非対称（覚醒イベント1.5%/週）
- **trust中間帯（40〜60）**: trustSensitivity感度カーブ（中間帯×1.5/警告帯×1.3/安定帯×1.0/盤石帯×0.7）
- **高rivalryゲーム効果**: 演出充実/orgPop飴と鞭(対戦+0.3〜0.5/放置−0.2/週)/控えめ集客ボーナス(累積上限+8%)

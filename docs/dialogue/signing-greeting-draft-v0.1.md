# 新加入 第一声 セリフ草案 v0.1（スカウト獲得 / FA契約）

- **設計メモ1**: 構造は `EVENT_RENTAL_GREETING_LINES`（data.js L29973〜）に完全準拠。第1キー=personality（data.js の既存並び順 normal→bold→quiet→shy→easygoing→earnest→emotional）、第2キー=archetype、`_default` フォールバック、値は配列。
- **設計メモ2**: 感情の核を経路で分離。**スカウト=「見つけられた／買われた」の誇りと腕試し欲**（動詞は「見つける・見込む・見出す・目をつける」）／**FA=「拾われた恩義・流浪の終わり・見返す」の再起**（動詞は「拾う・流れ着く・もう一度・返す」）。両者で語彙を意図的に重ねない。
- **設計メモ3**: 全本文43文字以内、固有名詞ゼロ（場所は「ここ」等の指示語のみ）。ojousama の「ですわ」はスカウト normal の1本のみに限定し、他セルは語彙（「頂」「御恩」「粗末に」「ご覧に入れる」）で品格を作る。composed は oyou-style-guide 準拠（「…」で間を作る・短く切る・感嘆符0〜1）。

## 実装時の申し送り

- 既存の `EVENT_FA_SIGNING_LINES` / `EVENT_FA_WELCOME_LINES`（data.js L29829/L29901）は「よろしく＋頑張ります」系の汎用挨拶で、本草案の FA_GREETING_LINES（再起・恩義・見返し）とは感情の核が違う。**どの経路がどれを引くか**を実装前に確定させること（重複表示になると同一場面で二重挨拶になる）。
- `EVENT_LINES_BY_KEY` への登録キー案: `scoutGreeting` / `scoutGreetingGeneric` / `faGreeting` / `faGreetingGeneric`。
- `management.js` の archetype ホワイトリスト（`ojousama`/`seductive`/`polite`/`composed` 判定）に本定数が通ることを確認すること。

# Dialogue Expansion Tone Guide (Session F 横断設計原則)

Session F の nested sources 展開時に、全ソース共通で参照する横断トーンルール。
個別ソースで迷ったら、必ずこのシートに戻ること。

---

## 対象ソース

このガイドは以下の nested sources すべてに適用される:

1. `NOTIF_DIALOGUES` (N1-N4)
2. `CARE_REACTION_DIALOGUES` (bonus / bonus_repeat / costume / trainer / media)
3. `CHOICE_EVENT_DIALOGUES` (S1-S6, E1 等)
4. `LARGE_EVENT_DIALOGUES` (B1, B2_fighter1/2, B4系)
5. `GLIMPSE_B_LINES` (GL-01〜GL-10, outcome別)
6. `SNAPSHOT_TEXTS` (G1-G4, R1-R2)

---

## 原則1: polite のネガティブ感情表現

**方針: 敬語ベース + 素の語尾混入 を基本、感情の種類で構文崩しを補助**

### 痛み・疲労・弱音系 → 敬語ベース + 素の混入

崩壊の瞬間だけ素が出る。平時は敬語を維持し、限界点で一瞬だけ素の語尾・感嘆が漏れる。

**OK 例:**
- 「…もう、無理です…っ」
- 「痛……っ、すみません、少し、待ってください…」
- 「だい…じょうぶ、です……ちょっとだけ……」

**NG 例:**
- 「痛いってば!」(敬語崩壊しすぎ → casual の領分)
- 「少々、負傷いたしました」(堅すぎ → 感情が死ぬ)

### 怒り・不満系 → 敬語の構文を崩す

倒置・繰り返し・句点分割で感情を示す。語尾は敬語を維持。

**OK 例:**
- 「どうして…どうしてですか」
- 「納得、できません。わたし、納得できません」
- 「それは……それは、あんまりではないですか」

**NG 例:**
- 「ふざけんな!」(敬語完全崩壊 → NG)
- 「遺憾に存じます」(感情が伝わらない → NG)

### 横断ルール

- 語尾「です/ます」は基本維持、崩れるのは感嘆・繰り返し・倒置で表現
- 「……」「っ」を積極的に使って呼吸や絶句を表現
- 一人称は平時のものを維持(「わたし」「わたくし」等)

## 原則2: seductive の弱い場面

**方針: 試合心理は短文化(C)、日常系は色気維持+素露出の混合(A+B)**

### 試合心理(GLIMPSE_B_LINES) → 短文化

妖艶さは**沈黙**で出す。普段より文量を減らし、余韻で魅せる。

**OK 例:**
- 「……まだ、よ」
- 「ふ、」(笑いかけて途切れる)
- 「こんなところで、終われない……」

**NG 例:**
- 長い独白で色気を語る → 試合中にそんな余裕はない

### 日常系(疲労・孤立・敗北後) → 色気維持 + 素の露出の混合

基本は「余裕の仮面」(A)、ふとした瞬間に語尾の色気が外れる(B)。

**OK 例:**
- 「ふふ…こんな姿、見られたくなかったのに…」(A: 余裕の仮面)
- 「……疲れた。ほんとに、疲れた」(B: 素の露出、〜のよ/〜かしら が外れる)
- 「大丈夫、よ……ちょっとだけ、休ませて」(A→B の移行)

**NG 例:**
- 常に「〜かしら」「〜だわ」を維持 → 不自然、弱さが見えない
- 完全に素に戻る → キャラ崩壊

### 横断ルール

- 色気語尾(〜かしら/〜だわ/〜のよ)を外すのは弱さを見せる瞬間の印
- 試合心理では語数を減らす、日常では語尾で操作

## 原則3: ojousama の崩し度(easygoing/ojousama)

**方針: 一人称と語尾は維持、崩れるのは話題選びと反応速度**

### 維持するもの

- 一人称「わたくし」
- 基本語尾「〜ですわ」「〜ますの」
- 気品ある語彙の基礎

### 崩していいもの

- **反応速度**: メディア取材や衣装プレゼントで急にノリが良くなる、前のめりになる
- **話題選び**: 庶民的な話題(B級グルメ、流行りのお店等)に食いつく
- **感情の素直さ**: 喜びを隠さない、はしゃぐ

### OK 例

- 「まあ!これ、わたくしが着るんですの?嬉しい…!ほんとうに嬉しいですわ!」(素直な喜び)
- 「テレビ出演ですの?あら、あらあら、どうしましょう…やりますわ、もちろんやりますわ!」(反応速度)
- 「え、それ流行ってますの?わたくしも、その、気になっておりまして…」(話題の崩し)

### NG 例

- 「マジで?ヤバい!」(俗語混入 → casual の領分、NG)
- 「わたくしめが…恐縮でございます」(堅すぎ → polite の領分、NG)

## 原則4: quiet/seductive の分量基準

**方針: ソースの性質で分量を3段階に分ける**

### 段階1: NOTIF / CARE_REACTION → 1行で十分

短い反応系。「…」「ありがとう…ございます」で足りる。無理に埋めない。

**OK 例:**
- NOTIF 疲労: 「……つかれた」
- CARE_REACTION bonus: 「……ありがとう」
- CARE_REACTION costume: 「……きれい」

### 段階2: CHOICE_EVENT / LARGE_EVENT → 1行本体 + 短い情景描写1行

セリフ本体は短く、地の文で情景や仕草を補う。

**OK 例:**
- 本体: 「……休みたい」
- 情景: *目を伏せ、小さく息を吐く*

- 本体: 「……いやです」
- 情景: *視線は外さない。声は静かだが、譲らない*

### 段階3: GLIMPSE_B → 心理描写主体、セリフ最小

地の文の心理描写が中心。セリフは最後の一撃として機能させる。

**OK 例:**
- 心理: *息が、乱れる。けれど視線だけは、落とさない。ここで落とせば、すべて終わる*
- セリフ: 「……まだ」

### 横断ルール

- 量を増やそうとして不自然な饒舌にしない
- 沈黙・省略・余韻がこのキャラの**武器**

## 適用チェックリスト

各ソースのセリフ生成時、以下を確認:

- [ ] polite のネガティブは敬語ベース + 素の混入 / 構文崩しになっているか
- [ ] seductive の弱い場面で、試合は短文化 / 日常は色気維持+素露出の混合になっているか
- [ ] ojousama は一人称・語尾を維持し、話題と反応速度で崩しているか
- [ ] quiet/seductive はソースの段階に応じた分量になっているか
- [ ] 一人称が平時のキャラ設定と矛盾していないか
- [ ] 「……」「っ」を適切に使って呼吸・絶句を表現できているか

---

## このガイドの使い方

1. 各 nested source に取り掛かる前にこのガイドを読み返す
2. ソース固有の論点(例: CARE_REACTION の bonus_repeat の慣れ感)は別メモで補足
3. 迷ったら原則に戻る。原則で解決できない場合は新ルールとしてこのガイドに追加

## 用途(改修後に何に使われるか)

社長室での**団体戦挑戦の直訴**。発起人が「自分を含む三人で、他団体へ乗り込んで3連戦を挑みたい」と社長に願い出る、その頭上吹き出し1本。
現行は暫定の archetype 単軸14本(`CHALLENGE_GROUP_PETITION_LINES`)が使われており、本案が承認されれば 34セル×3本 に置き換わる。

画面には別途、**行き先の団体名バッジ・「✈ 遠征興行」「⚔ 3人制・シングル3連戦」のブリーフィングカード・第1試合の対戦相手・同行2名の選択欄**が並ぶ。
つまり**「どこへ」「何人で」「何試合」はヘッダーと地の文が背負っている**ので、セリフは名称を言わず指示語で受ける。

## 改修方針

1. **全面書き直しはしない**。旧文の角度(卑下 / 気負い / 脱力 / 見下し / 焦り など)と語順・語尾はそのまま残し、**1対1前提の語だけを差し替える**
2. 差し替える語は原則ここだけ — 「あの人と / あの方と / あいつと / そいつと / あの相手と」→ 「三人で」+行き先の指示語(あちら / 向こう / あの団体 / あっち)
3. **一人が抜け駆けする話ではなく、三人で乗り込む話**であることが**1本ずつ単独で**読み取れること(セリフは3本からランダムで1本しか出ないため)
4. 敬語/タメ口/「っす」体の別、リーダーの打ち方(`……` か `…` か)は**そのセルの旧文の流儀を維持**する
5. 旧文が既に団体戦でも通る場合は手を入れず「**変更なし**」と明記する

## 制約(全102本に適用)

| 項目 | 内容 |
|---|---|
| 長さ | **全角36字以内**(吹き出し2行クランプ)。旧文が37字だったセルも36字以内へ収める |
| 固有名詞 | **禁止**(鉄則7)。`{org}` プレースホルダは**全廃**し「あの団体 / あちら / 向こう / あっち」で受ける |
| 一人称 | 極力出さない(鉄則2)。必要な行のみ漢字「私」/ 内気帯「わたし」/ お嬢様帯「わたくし」 |
| 二人称 | 極力呼ばない(鉄則3) |
| メタファー | 身体・抽象メタファー禁止(鉄則6)。生活語彙の具体表現で書く |
| 記号 | `！？` は全角、半角記号は使わない(鉄則9)。旧文に残っていた半角 `!` は本案で全角へ是正 |
| 語彙の重さ | 遠征の直訴であって人生の岐路ではない。悲壮に振らない(鉄則8) |

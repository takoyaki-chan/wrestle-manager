# セリフ拡張ギャップ補完 — Claude Code 作業指示書

## 背景

44人の personality/archetype 振り分け変更（コミット `b4afe42`）に伴い、`src/data.js` の各 `_LINES` ブロックに**専用セリフが定義されていないコンボ**が大量発生した。

具体的には、新コンボ（鷹揚関連、ノーマル/クール等）と、既存コンボでもキャラ移動により**今まで0人だったが新たに人が入ったコンボ**で、専用セリフブロックを追加する必要がある。

合計: **32出典 × 平均10コンボ = 336エントリの空白**を埋める作業。

このドキュメントは Claude Code セッションへの作業指示書。`specs/oyou-style-guide.md` も併読のこと（鷹揚口調については特に）。

---

## 全体方針

### 「埋める」とは
各 `_LINES` ブロックに、対象 (personality, archetype) 用の専用セリフ配列を追加する。
例: `RIVALRY_CONFRONTATION_LINES` の `normal` ブロック内に `composed: [...]` を追加。

### 既存セリフを下敷きに
新規コンボのセリフは、**同じ personality の別 archetype セリフ**（または `_default`）を下敷きにして、口調・archetype のニュアンスに合わせて書き換える。完全にゼロから書く必要はない。

### スタイル統一
- 鷹揚関連は必ず `specs/oyou-style-guide.md` を参照
- それ以外は既存の archetype（お嬢様、ヤンキー、蠱惑、クール、丁寧）のセリフ群を読んで文体を吸収してから書く
- 1コンボあたり既存 `_default` や同類セリフと同じ行数を目安にする（通常3〜8行）

### コミット粒度
セッション1回 = 1コミット。出典単位ではなく**セッションで触った範囲全部**を1コミットにまとめる。

## セッション開始テンプレ

各セッションの開始時、Claude Code に以下を投げる:

```
このセッションでは、`src/data.js` のセリフ拡張を行います。
対象出典: [セッション名と出典名のリスト]

参照ドキュメント:
- specs/oyou-style-guide.md (鷹揚口調)
- src/data.js の既存セリフブロック（同じ personality の別 archetype を下敷きに）

作業内容:
1. 各出典で、対象 (personality, archetype) コンボに専用セリフブロックを追加
2. 1コンボあたり3〜8行のセリフ（既存 _default と同じ行数を目安）
3. 既存セリフをそのままコピペせず、archetype に合わせて書き換える
4. 鷹揚（composed）は specs/oyou-style-guide.md の例文と文体ルールに従う

検証:
- node -e "require('./src/data.js')" で構文チェック
- node archive/scripts/generate-dialogue-workbooks.js で Excel 再生成して目視確認

完了後:
- git diff の確認
- 1コミットにまとめる
```

## トラブルシューティング

**Q: どの archetype セリフを下敷きにすればいい？**
A: 同じ personality の他 archetype を見て、雰囲気が一番近いものを参考にする。または `_default`（性格別フォールバック）を改変。

**Q: 鷹揚と他の archetype（例: 蠱惑）でどう書き分ける？**
A: スタイルガイド `specs/oyou-style-guide.md` の文体ルール参照。鷹揚は「動じない・短く切る・…で間を作る」、蠱惑は「妖艶・粘っこい・誘うような語尾」が大原則。

**Q: ノーマル/丁寧 9人もいるのに専用セリフがない出典が多いのはなぜ？**
A: 元々ノーマル/丁寧コンボは少人数で運用されていたため、性格別の `_default` で十分賄えていた。今回の振り分けで人数が増えて専用セリフを書く価値が出た。

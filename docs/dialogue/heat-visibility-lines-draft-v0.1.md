# 追い込みの熱量逓減 可視化セリフ草案 v0.1（選手の様子 / コーチの観察）

## 0. これは何か

`GROWTH_CONFIG.intensiveHeatTable`（1.8 → 1.6 → 1.4 → 1.2 → 1.0）の逓減を、
**数値を一切見せずに「選手の様子」だけで読ませる**ためのセリフ群。

プレイヤーに伝えたい事実はひとつだけ:

> 追い込みを連打すると、代償（体調・怪我・消耗）は満額のまま、得るものだけが減る。
> だから**間欠運用が正解**。

これを「効きが 1.8 から 1.0 に落ちます」と書いてしまうとスプレッドシート最適化ゲームになる。
選手が「体が軽い」→「手応えが薄い」→「何も残らない」と口にするのを見て、
社長が**自分で気づく**形にする。

---

## 1. 状態キーと内部値の対応

| キー | `_heat` | 成長倍率(内部) | 選手の像 |
|---|---|---|---|
| `fresh` | 0 | 1.8 | 体が軽い。やった分がそのまま返る |
| `warm` | 1〜2 | 1.6 / 1.4 | 動けてはいる。ただ返りが細ってきた |
| `heavy` | 3〜4 | 1.2 / 1.0 | 体が重い。こなしても身にならない |

`_heat` は上限が `intensiveHeatTable.length - 1` = 4 なので `heavy` は 3 と 4 の両方を吸収する。

---

## 2. 3状態を見分けさせる設計

セリフを1本ずつ良くするより、**3状態を並べたとき明らかに違う**ことを最優先した。
そのために語彙の役割を固定している。

| 状態 | 軸になる語 | 使ってはいけない語 |
|---|---|---|
| fresh | **軽い / 入る / 素直 / 返ってくる** | 重い・薄い |
| warm | **薄い / 鈍い / 浅い / 乗らない / 落ちた** | 軽い・重い（両端の語を warm に使うと3段が2段に潰れる） |
| heavy | **重い / 残らない / 流れる / 空回り** | 軽い |

fresh と heavy は「軽い ⇄ 重い」で一目で対になる。warm はそのどちらでもない
**"違和感の言語"** だけで構成し、中間だと分かるようにした。

### heavy の温度設定
heavy は**プロが疲れているだけ**。故障でも挫折でもない。
「痛い」「壊れる」「限界」「もうダメ」の語彙は1本も使っていない。
辛さを避けないのはこのゲームの魂だが、ここで悲壮にすると、
本当に怪我・引退が来たときの重さが目減りする。ここは**乾いた疲労**に留めた。

### 「疲れた」を並べない
性格ごとに疲労の出方を変えている。

- **強気** — 認めない。「重い。…でも止まらない」
- **真面目** — 自分を責める。「私の集中が足りないのかな」
- **鷹揚** — 淡々と受ける。「今日やっても、たぶん流れるだけ」
- **お気楽** — 損得で言う。「ザルに水だろ」
- **感情的** — 苛立つ。「やってんのに進まねぇ…!」
- **寡黙** — 短く事実だけ。「…重い。…やっても、抜けていくだけだ」
- **内気** — 申し訳なさに変換。「空回りしてしまって」

「疲れた」という語は選手側75本のうち**0本**。既存の体調低下セリフ（`N3` 系）が
「ちょっと疲れてるだけです」「少し休めば大丈夫です」で埋まっているため、
**体調(condition)の低下と熱量の飽和が混ざって見えないように**意図的に排除した。
熱量は「疲れ」ではなく「**効きの鈍り**」として描く。

## 3. 既存セリフとの非重複

コーチ側は growth-rebalance v1.0 の `strain_*`（48本 / `src/coach-lines.js` L190〜531）と
**役割も語彙も分ける**。

| | strain_*（既存48本） | HEAT_STATE_COACH_LINES（本件） |
|---|---|---|
| 見ている時間 | **将来** — 何年も先に返ってくるツケ | **今週** — 今この一本が効くかどうか |
| 語彙 | 無理を通す / 体に借り / 後で来る / 祟る / 積もる / 軽いうちは | 入っていかない / 返りが薄い / 素通り / 身につかない / 一週抜けば戻る |
| 促す行動 | 長期的に使い方を考えろ | **今週は外せ / 今週は使え** |

既存48本の語（無理・借り・祟る・積もる・後で来る・頑張りすぎ）は本件で**1つも使っていない**。
逆に本件の「返り」「素通り」「一週抜けば」は既存に存在しない。

コーチ heavy 1本目「何をやらせても素通りだ」と選手 normal×cool heavy「何をやっても素通りだ」は
**意図的な呼応**。同じ週に両方出れば、社長は同じ言葉を二人から聞くことになる。

## 5. HEAT_STATE_COACH_LINES（道場でコーチが漏らす観察・21本）

コーチ個別の口調分岐は付けない（`INVITE_AWAKENING_LINES.coachLine` と同じ**全voice共通・中立形**）。
`{name}` は選手名に置換。

```js
// 道場でコーチが漏らす、熱量についての観察。全voice共通の中立形。
// growth-rebalance v1.0 の strain_*（将来のツケ）とは役割が別:
// こちらは「今週この子に追い込みを入れる価値があるか」だけを語る。

    '{name}の体が、新しい動きを素直に飲み込んでいる',
```

### コーチ側の情報設計

3状態それぞれが**社長に別の行動を促す**ように書き分けている。

- `fresh` — 「今だ」「使うなら、ここで」→ **今週使え**
- `warm` — 「詰めすぎたか」「得は薄いぞ」→ **そろそろ考えろ**
- `heavy` — 「一度、外してやってくれ」「一週抜けばまた入る」→ **今週は外せ。そして戻ることも教える**

heavy の 5本目・7本目が**回復ルール（通常練習/休養で戻る）の唯一の明示**。
これがないとプレイヤーは「一度重くなったら終わり」と誤読して追い込みを封印してしまう。
間欠運用が正解だと分かるのはこの2本の役目なので、実装時に落とさないこと。

`heavy` 6本目「怪我を買うようなもの」だけは**代償が満額のまま**であることに触れている。
「効きは落ちたのに危険は落ちない」という一番伝えたい非対称を、
コーチの口から1本だけ言わせる枠。

| 系統 | 内訳 | 本数 |
|---|---|---|
| HEAT_STATE_SELF_LINES | 3状態 × (性格7 `_default` + archetype 18セル) = 25セル × 3 | **75** |
| HEAT_STATE_COACH_LINES | 3状態 × 7本 | **21** |
| 合計 | | **96** |

archetype セルの割り当て（3状態で共通・実装側が一様な表を組めるようにした）:

| 性格 | 割り当てた archetype |
|---|---|
| normal | cool / polite / composed |
| bold | delinquent / ojousama / cool |
| earnest | polite / cool / composed |
| emotional | delinquent / ojousama / composed |

| quiet | cool / composed |
| shy | polite / seductive |

- 「ですわ」は75本中**1本**（bold × ojousama × fresh）のみ。v0.2 の基準を踏襲。
- 全本文 43文字以内。最長は `earnest × polite × heavy` の27文字。

## 7. 実装時の注意

1. **参照順**: `LINES[state][personality][archetype] || LINES[state][personality]._default || LINES[state].normal._default`
2. **表示は頭上の吹き出し**。クリームパネル直置き・地の文はNG。
   吹き出しの中は**セリフだけ**（選手名・所属は吹き出しの外に置く）。
3. `_default` セルは archetype 未割り当ての子を全部吸うので**最も露出が多い**。
   反復が目立つようなら、まずここに2本目を足すのが効く（現状は全セル1本）。
4. `fresh` を毎週出すと画面がうるさい。**`heavy` は常時 / `warm` は控えめ / `fresh` は
   追い込み可能な週だけ**、のように出現頻度に差をつける前提で書いてある。
5. コーチ側は既存 `COACH_VOICE_REPORT_LINES` と**同じ週に両方出さない**こと。
   将来のツケ（strain）と今週の効き（heat）を同時に言われると、
   どちらの話かプレイヤーが切り分けられなくなる。

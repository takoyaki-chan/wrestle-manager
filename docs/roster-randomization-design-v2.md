## 2. 確定した設計方針

### 2.1 人数配分

| 枠 | 人数 | 備考 |
|----|------|------|
| S級 | 16 | 現行通り |
| A級 | 13 | 現行通り |
| B級 | 10 | 現行通り |
| プレイヤー | 5 | fixed 2 + pick 3（現行通り） |
| FA | 17 | 旧9名から増。固定維持ではなく増減する |
| **アクティブ計** | **61** | |
| dormant | **37** | 未登場。年齢は設定されていない |
| **合計** | **98** | 永久に変わらない |

### 2.2 獲得制限

既存の `AI_TIER_LIMITS` を初期配置にも適用する。

| ティア | prodigy上限 | promising上限 |
|--------|:-----------:|:------------:|
| S級 | 無制限 | 無制限 |
| A級 | **3名** | 無制限 |
| B級 | **1名** | 無制限 |

**判定基準（統一済み）**: プレイヤー表示基準に統一する。

| ランク | 基準 | 旧AIロジック（廃止予定） |
|--------|------|----------------------|
| 超逸材 (superElite) | potTotal ≥ 850 | avgPot ≥ 160 → 廃止 |
| 逸材 (elite) | potTotal ≥ 740 | avgPot ≥ 130 → 廃止 |
| 有望 (promising) | potTotal ≥ 690 | — |
| 原石 (raw) | potTotal ≥ 550 | — |
| 素材 (material) | それ以下 | — |

※ AIスカウトロジック（engine.js L1271付近）の `avgPot` 判定を `potTotal` 判定に書き換える。別タスクとして予定に入れる。

### 2.3 S級の上位保証

- **初期配置時のみ**: 超逸材（potTotal ≥ 850）はS級に配置する
- **シーズン中**: 保証なし。自然な獲得に任せる

### 2.4 年齢

**アクティブ選手（61名）**: ニューゲーム時に**15〜33歳で一様ランダム**割り振り。シリーズ設定の年齢は使わない。

**dormant選手（37名）**: 年齢なし。解禁時に**15〜19歳**でランダム割り振り。新人として世界に登場するイメージ。

### 2.5 dormantサイクル（循環型）

```
引退1名 → その選手はdormantへ → dormantから別の1名をFAに解禁（15〜19歳）
```

- **1:1交換が絶対ルール**
- アクティブ61名・dormant37名を常に維持
- 引退選手がdormantに戻るため枯渇しない
- 同じ選手がいつか再登場しうる

**引退ペースの見込み**:
- 各年齢に約5名 → 毎シーズン約5名が35歳到達
- 引退判定: 35歳30% / 36歳50% / 37歳75% / 38歳90% / 39歳確定
- Year 2あたりから引退が始まり、定常的にシーズン3〜5名が循環

### 2.6 ドラフト

FAプールからのランダム選出。現行の `DRAFT_AVAILABLE_IDS` は廃止。

### 2.7 シリーズグループの重み付け

おまけ要素として緩やかに実装する。弱めで構わない。

| グループ | 内容 | 方針 |
|----------|------|------|
| 学園女子プロレス（27名） | 人数最多 | **学校単位**でまとまりやすくする。シリーズとしてはばらけてOK |
| 学生系（約25名） | 女子高生プロレス, JKになった俺, 女子大生 | 少人数シリーズは同団体にまとまりやすく |
| 大人系（約46名） | OL, 団地妻, RQ, 商店街, マドンナ等 | 少人数シリーズは同団体にまとまりやすく |

## 3. 初期配置アルゴリズム

ニューゲーム時の処理フロー:

1. 全98名からランダムにアクティブ61名を選出（dormant37名を分離）
2. アクティブ61名に15〜33歳のランダム年齢を割り振り
3. 超逸材（potTotal ≥ 850）をS級に確定配置
4. 残りをS級→A級→B級→FAの順に配分
   - 各団体の `AI_TIER_LIMITS`（獲得制限）を適用
   - シリーズグループ・学校の緩やかな重み付けを適用
5. FAからドラフト候補を選出 → プレイヤー5名を決定

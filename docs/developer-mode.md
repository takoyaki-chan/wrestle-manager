# 隠し開発者モード運用ガイド

ゲーム内の確認を、最初からプレイし直さずに行うための開発専用機能です。通常プレイでは表示されず、検証時だけ使用します。

## 起動

- ゲーム画面で `Ctrl + Shift + D` を押す。
- 閉じても開発用セーブは消えません。再度同じショートカットで開けます。
- 実装本体は `src/dev-tools.js`、読み込み元は `src/index.html` です。

## できること

- 任意のシーズン・週まで高速進行する。
- 春タッグリーグ編成、夏ジュニア大会、秋4団体勝ち残り対抗戦、冬・天頂戦の直前へプリセットで移動する。
- 現在地を名前付きの開発用チェックポイントとして保存・復元する。
- 開発モードを開いた時点の状態へ戻す。
- 開発用オートセーブを復元する（コンソールでは `WrestleManagerDev.restoreDevAutosave()`）。

高速進行では、選択イベント・興行・ドラフトなどを既定値で処理します。対象週は消化せずに停止するため、その週の大会参加や画面を確認できます。ゲームオーバーまたは対象週の通過が起きた場合は停止し、直前のチェックポイントから条件を調整します。

## セーブの安全性

通常プレイのセーブを検証で汚さないことが最優先です。開発モードを一度でも開いたセッションでは、既存の `Storage.autoSave` 呼び出しを開発用オートセーブへ振り替えます。通常のオートセーブと手動セーブは上書きしません。

ブラウザ `localStorage` のキーは次のとおりです。

| 用途 | キー |
|---|---|
| 開発用オートセーブ | `wm_dev_autosave` |
| 開発開始時の復元地点 | `wm_dev_session_base` |
| 任意チェックポイント | `wm_dev_checkpoint_<timestamp>_<label>` |

これらは通常セーブとは別領域です。必要な再現データは、画面内の「現在地を保存」で残しておき、以後の修正確認に再利用してください。ブラウザのサイトデータを削除すると開発用チェックポイントも削除されます。

## 改修時の注意

- 新しいブロッキング画面・大会参加フェーズ・選択イベントを追加した場合、`resolveDefaultBlockingPhase()` に既定処理を追加する。追加しないと高速進行が止まる、または対象イベントを通過します。
- 新しい一時イベント状態を追加した場合、必要に応じて `clearTransient()` に追加し、次週へ持ち越さないことを確認する。
- 既定の選択は「無効なカードを組まない」「通常プレイの状態を破壊しない」を優先する。物語固有の選択を勝手に再現する用途には使わない。
- `Storage.autoSave` の差し替えを削除・変更する場合は、通常オートセーブと手動セーブが開発モード中に更新されないことを必ず確認する。
- UI変更時は `node test/dev-tools-static-test.js`、必要に応じて対象大会のフローテストと `node test/auto-sim.js` を実行する。

## 開発者向け公開API

デバッグコンソールでは、次の限定APIを利用できます。

```js
WrestleManagerDev.open();
WrestleManagerDev.fastForward(season, week, label);
WrestleManagerDev.saveCheckpoint(label);
WrestleManagerDev.restoreDevAutosave();
```

通常のゲーム画面やプレイヤー向けメニューへ露出しないことを維持してください。

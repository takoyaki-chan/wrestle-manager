# 固有特性リスト v2.1（2025-02-20）

## 設計ルール（仕様書 §7.3.1）
- ON/OFF型
- 1キャラにつき 3〜5個
- 育成で変動なし（固定）。転生時に多少の入れ替わり可能性あり
- スカウト時にも全て確認可能

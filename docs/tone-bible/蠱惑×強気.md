# 口調シート: 蠱惑×強気(草案 v0.1)

- アンカー: **浅見里緒菜**(id57) — 2026-08-11 Keisuke指定

## 口調の骨格(セル共通の土台)

- **一人称**: 私(アンカー「いずれ私が……」。巳沼は「わたし」ひらがな表記——個体固有として維持するか要Keisuke判断)
- **二人称**: 実セリフからは不明——要Keisuke記入
- **語尾セット**: 「〜わ…！」「〜なの。」「〜じゃない。」、言い差しの「……」(「いずれ私が……」)
- **リズム**: 宣言→根拠→余韻。目的を言い切ってから、続きを飲み込む言い差しで野心の大きさを匂わせる
- **テンション帯**: 上限=野心の昂ぶり(「必ず取り戻すわ…！」)、下限=静かな企み(「策略を巡らせるのは得意なの」)。昂ぶっても絶叫にはならない
- **語彙傾向**: 野心と戦略(座/取り戻す/策略/積み上げる)。「正面からだけが勝負じゃない」という搦め手の自認
- **禁句・NG(仮)**: 無邪気なはしゃぎ、自虐、現状への満足(このセルは常に「まだ上」を見ている)

## 性格(強気)による変調

- 蠱惑の余裕に「執着と野心」が乗る帯。ノーマル(橘)が過程を愉しむ余裕なら、強気は目的(座・頂点)へ向かう推進力。勝利は通過点として語られる
- 負けず嫌いが妖艶の皮を破って「…！」で漏れるのがこのセルの特徴。橘の帯には無い熱

## 見本(アンカー既存セリフ=このセルの正)

- 「策略を巡らせるのは得意なの。正面からだけが勝負じゃない。」

## 個体差メモ(セル内のグラデーション)

- **浅見里緒菜**: セルの正。策士の野心。奪還という物語を背負い、執着が最も言語化されている
- **観音崎せりか**: 自己顕示の女王蜂系(「カーストトップの実力、見せつけてあげたわ♪」「全部持ってる私に敵うわけないでしょ？」)。アンカーの策士味は無く、語彙がギャル寄り(カースト/ギャル3人衆)で♡♪が多い。強気の「見せつけ」側を担うが、蠱惑の妖艶さよりギャルの陽性が勝つ瞬間があり要観察
- **巳沼紗霧**: サディズム+支配(「情けなく伸びたその顔♪無様ねぇ♪」)。前2本は橘(蠱惑×ノーマル)のサディスト帯とほぼ同型だが、「わたしに逆らう子は、まとめて折ってあげる」の上下関係宣言(リーダー気質)が強気の根拠。ノーマルとの境界線上にいる

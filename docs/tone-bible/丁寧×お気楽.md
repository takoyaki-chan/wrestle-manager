# 口調シート: 丁寧×お気楽(草案 v0.1)

- アンカー: **木ノ内幸音**(id21) — 2026-08-11 Keisuke指定
- 所属(3名): 木ノ内幸音(id21)、沢登鮎(id101)、戸塚ゆかり(id109)

## 口調の骨格(セル共通の土台)

- **一人称**: 私(「私、やりましたよーっ！」)。ただし主語を飛ばして感情から言うことが多い
- **二人称**: 実セリフに無し——要Keisuke記入
- **語尾セット**: 「〜！」連打、「〜よーっ！」、聞き返しの「〜？」(「えっ、そんな事無い？」)。観客に向くときだけ「〜ましたか！？」の敬語
- **リズム**: 短文の連打(「勝った！楽しい！いい感じ！」)。一文が短く、息の長い説明をしない
- **テンション帯**: 上限=全開のはしゃぎ。下限でも軽い戸惑い止まりで、毒・落胆はこの帯に無い
- **語彙傾向**: 楽しい/最高/いい感じ——快の直球語。戦術・分析の語彙はほぼ出ない
- **禁句・NG**: 皮肉・毒舌、勝敗への執着、堅苦しい敬語の長文
- **★属性名との緊張関係(骨格の未確定点)**: アンカーの声は「丁寧」というより元気はつらつで、丁寧要素は観客向けの「見てましたか！？」程度。むしろ非アンカーの沢登・戸塚のほうが一貫したです・ます。このセルの丁寧さをどこに置くかが骨格の根本——下のKeisuke記入欄で要裁定

## 性格(お気楽)による変調

- 同属性の真面目(過程・課題に言及)やノーマル(油断への自戒)と違い、勝利を無条件に喜ぶ。反省ゼロ、快感情の即時表出
- 深刻さが持続しない。ヒールっぽい試合をしても本人はケロッとしている(「えっ、そんな事無い？」)

## 見本(アンカー既存セリフ=このセルの正)

- 「勝った！楽しい！いい感じ！」
- 「この試合、ヒールっぽかった？　えっ、そんな事無い？」
- 「見てましたか！？ 私、やりましたよーっ！」

## 個体差メモ(セル内のグラデーション)

- **木ノ内幸音**: セルの正。はしゃぎの最大値。ヒール適性持ちなのに本人に自覚がないズレも持ち味
- **沢登鮎**: 常時です・ます(「楽しかったですよ」「ほんと面白いなって」)。アンカーより2段静かな楽しみ方で、「丁寧」の名には一番忠実。相手を立てる締め(「相手が強くてこそですから」)
- **戸塚ゆかり**: アンカーのはしゃぎ+です・ます(「わあ、勝ったー！最高です！」)。両者の中間で、現状の実質的な重心

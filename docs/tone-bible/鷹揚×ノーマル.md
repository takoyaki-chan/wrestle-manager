# 口調シート: 鷹揚×ノーマル(草案 v0.1)

- アンカー: **阿武隈塔子**(id1) — 2026-08-11 Keisuke指定
- 所属(8名): 阿武隈塔子(id1)、楠木なぎさ(id15)、八重樫舞(id27)、松下真理亜(id96)、大山たかみ(id102)、黒岩千晶(id105)、若林美佐子(id110)、相模あずみ(id111)

## 口調の骨格(セル共通の土台)

- **一人称**: 私(「今回は私の勝ちだ」)
- **二人称**: 実セリフからは不明——要Keisuke記入(呼びかけは「ごめんね」「頑張ったね」と直接の労いで済ませており、代名詞が出ない)
- **語尾セット**: 「〜んだ…」「〜だ。」「〜よ」— 断定の「だ」を静かに使う中性的な語り。女性語尾(わ/かしら)は使わない
- **リズム**: 短文。まず相手への一言(ごめんね/頑張ったね)、それから自分のこと。リーダー(…)の余韻で引く
- **テンション帯**: 常に静か。勝っても高揚せず、負かした相手を見下ろさない。上限=穏やかな笑み、下限=しみじみした述懐
- **語彙傾向**: 相手への労いと敬意が第一(「ごめんね」「頑張ったね」「思ったよりも強かった」)。自慢・誇示をしない
- **禁句・NG**: 勝ち誇り・挑発、はしゃいだ感嘆(♪の連発)、饒舌な自分語り

## 性格(ノーマル)による変調

- 鷹揚の「大らかさ・余裕」を平常運転で出す帯。お気楽ほど脱力せず、強気ほど張らず、静かな貫禄がそのまま声になる
- 勝者が先に相手を労う——エースの視線の低さがこのセルの核

## 見本(アンカー既存セリフ=このセルの正)

- 「ごめんね。まだまだ負けられないんだ…」
- 「頑張ったね。今回は私の勝ちだ。」
- 「…思ったよりも強かったよ」

## 個体差メモ(セル内のグラデーション)

- **阿武隈塔子**: セルの正。勝者が先に「ごめんね」と言う、労りの余裕
- **楠木なぎさ**: 「はっはっは！ パワーで押し潰すのが一番気持ちいいぜ！」— 豪傑笑い+「〜ぜ」「かかってきな」。大らかさは同系だが、声量と荒さがアンカーと対極。**移動候補**: ヤンキー×ノーマル(石戸谷「ガハハ！ もっと暴れさせろよ！」と同帯)。Babyfaceの豪傑姐御として鷹揚に残す線もある——裁定はKeisuke
- **八重樫舞**: 「パワーもスピードもスタミナも！ 全部出し切ったよ！」— 直球熱血で、鷹揚の静かな余裕が乗っていない。標準×ノーマル(深町「よしっ、練習通り！」)と同帯に聞こえる。**移動候補**: 標準×ノーマル
- **松下真理亜**: 「こうゆう華やかな舞台も、悪くないわね♪」— 余裕は同帯だが「わね♪」の女性語尾と華やぎ。アンカーより艶側の個体差(蠱惑ほどではない)
- **大山たかみ**: 「…打撃で崩せれば、こんなもんかな」— 低温・淡々。口数は少なく鷹揚×寡黙との境界だが、普通に会話が成立する分量なのでノーマル圏内と判断
- **黒岩千晶**: 「こういう試合、嫌いじゃない。ボロボロになってからが本番だからね」— 静かなタフネス。アンカーの帯に最も近い一人
- **若林美佐子**: 「…相手の癖、途中で読めた。あとは流れに乗っただけ」— 淡々とした述懐で近い。労いより観察が前に出る
- **相模あずみ**: 「ライバルがいるから強くなれる。次もよろしくねっ」— 相手への敬意という視線がアンカーと同じ。「〜ねっ」の跳ねだけ少し若い

# セリフ全直し 実行計画 v0.1(2026-08-11 起案・レビュー待ち)

口調バイブル(34セルの口調シート)を正として、既存セリフ全体を見直す工程の計画。
前提: シートはB項・C項裁定を反映してv0.2確定してから使う(→ `00-裁定待ちリスト.md`)。

## 基本方針: 「全書き換え」ではなく「検品→違反行のみ改訂」

母数は約14,800行(タイプ別11,590+該当者なし3,177)+キャラ個人セリフ群(victory-lines.js等)。
全行を書き直すのは量的に非現実で、口調が合っている行を書き直すのは改悪リスクしかない。
よって **各行を口調シートに照らして検品し、違反行だけを改訂する**。

- 検品の判定基準はシートの骨格(一人称/語尾/テンション帯/禁句)——これが「カードに書いていないことは守られない」の逆用で、シートに書いたことだけを機械的に照合できる
- 改訂はxlsxの既存ワークフローに乗せる: **「改訂」列に書く → Keisukeレビュー → 反映 → 書き出し**(破壊的書き出しルール順守: 書き出し前に未反映改訂を必ず反映)

## 工程

| 工程 | 内容 | 担当 |
|---|---|---|
| P0 | B項・C項裁定 → 口調シートv0.2確定(裁定を骨格に反映) | Keisuke裁定 / Fable反映 |
| P1 | セル単位の検品: 全セリフ行を骨格に照合し、違反行に「違反理由」フラグ(一人称/語尾/禁句/テンション帯)。セル別違反率レポートを出す | エージェント(並列) / Fableが抜き取り検証 |
| P2 | 違反行のみ改訂案を起草し、xlsxの改訂列へ記入 | Opus(セリフ執筆担当) / Fableがdiffレビュー |
| P3 | Keisukeが原本xlsxの改訂列を全文レビュー(直接修正OK) | Keisuke |
| P4 | 反映 → 書き出し → auto-sim・実機確認 | Fable / Keisuke実機 |

- 進行順: **裁定が固まったセルから、かつ大所帯優先**(丁寧×真面目12名 → 標準×真面目9名 → 丁寧×ノーマル8名 → …)。1セル=1バッチで完結させ、セルを跨いだ中途半端を作らない
- P1の検品には**C項(一人称・二人称)の裁定が事実上必須**(一人称違反が検出できない)。B項は該当セル(標準×お気楽・丁寧×お気楽など)の検品開始条件

## スコープ(2026-08-11 Keisuke裁定反映)

1. **_該当者なし.xlsx の3,177行 → 対象外**(「今はいらない」)。対象はタイプ別34冊の11,590行のみ
2. **キャラ個人セリフ(victory-lines等) → 今回の修正には含めない**
3. 改訂の粒度 → 未確定。**パイロット: 標準×強気(568行・骨格完全確定)を先行検品し、違反率と重度/軽度比を実測してから決める**(Fable推奨・実施中)

## 検品・改訂の不変条件(全工程共通)

- **男性的・ボーイッシュ語尾はセル依存で判定する(2026-08-11 Keisuke)**: ヤンキー帯では骨格内の正当な声(「〜だろうが」「じゃねえよ」等)、鷹揚の一部個体(楠木なぎさの「〜ぜ」等)も意図的なボーイッシュ。一律に違反とせず、必ずそのセルの骨格・個体差メモに照らす
- **標準帯の許容幅(2026-08-11 Keisuke)**: 荒々しくない中性カジュアル語尾(「〜だよ」「行くぞ」程度)は今時の女性の声として許容。NGは柄の悪い男系のみ(かよ/じゃねえ/乱暴命令形/伝法)。「全部を女性形語尾に寄せて昭和の女言葉にしない」
- **許容幅の較正2(2026-08-11 改訂差し戻しより)**: 「やってみなよ」級の伝法軽口、対戦の檄としての「来い」は標準帯で許容(NGの伝法は「しときな/来な」級の姐御口調)。真面目帯でも「やった！」「うわあ」級の素直な感嘆は許容(NGは幼さではなく卑屈・軽薄)。検品でこの水準を違反にしない
- **【鉄則】個体固有の口癖・自称・異名は共通セリフに侵食させない(2026-08-11 Keisuke)**: 「この副ちゃんさん」「剛の芝」等はその子の個別セリフ限定。タイプ×性格の共通セリフは全員が共有するため、あらゆるタイプで同じ
- **一人称の統一運用(2026-08-11 裁定19〜54由来)**: 共通セリフでは一人称を極力出さない。必要な行だけ漢字「私」(ひらがな「わたし」・カタカナ「ワタシ」・「あたし」「俺」は共通セリフでは使わない)。選手個別の一人称は個人セリフの工程で扱う。**例外: 内気帯はひらがな「わたし」を維持**(どもり「わ、わたし」の視覚表現とセット・2026-08-11裁定)。**ヤンキー帯も「私」で統一**(2026-08-11裁定: カタカナ「アタシ」は廃止。漢字が硬く浮く箇所のみ、ひらがな「わたし」で馴染ませてよい——「わたしんとこ」等の音便接続)
- **二人称の既定(2026-08-11 Keisuke委任「任せます」・Fable設定)**: 共通セリフでも極力相手の呼称を避け、必要な場合のみ——お嬢様/丁寧/蠱惑/鷹揚/標準=「あなた」、標準×強気=「アンタ」(実績準拠)、ヤンキー=「あんた」、クール=呼ばない(必要時のみ「あなた」)。個別の呼び方(宮ケ瀬の「伊勢原…」等の名指し)は個人セリフの領分

- **アーキタイプ絶対**: 口調を守らない選手セリフは存在させない(性格は第二分岐)
- セリフ内で大会名・固有名詞を連呼しない(名称入りは1割以下、ヘッダー/地の文が名称を背負う)
- テンプレ感情表現(「やったー！」「くやしい…」の量産)禁止
- 内部変数名(morale/MQ等)をプレイヤー向け文言に出さない
- 改訂は必ず「改訂」列へ。既存の「現在」列は上書きしない(diffがKeisukeレビューの材料)
- 例外キャラ(黒江舞の二重人格、穴澤ほのかの二面性、長谷川レオナの意地と情 等)は骨格でなく個体差メモを正として照合する

# 口調シート: 鷹揚×強気(草案 v0.1)

## 口調の骨格(セル共通の土台)

- **一人称**: わたし(アンカーはかな表記「わたしこれでも実力者扱いされてるのよ？」。須藤・山本は漢字「私」——表記ゆれか個体差か要Keisuke確認)
- **二人称**: 実セリフからは不明——要Keisuke記入
- **語尾セット**: 「〜よ！」「〜のよ？」「〜ないでよね」「〜かな？」— 女性語尾で押すが、刺々しくならない
- **リズム**: 自分に問いを立てて自分で答える呼吸(「リングの上は？ もちろん全力よ！」)。圧の前に余裕の一拍が入る
- **テンション帯**: 大人の余裕がベース、その上に全力と負けん気が乗る。上限=朗らかな挑発、下限=不敵な自己確認。悲壮・激昂はない
- **語彙傾向**: 実力・全力・調子。自分の格を自分で語る(「実力者扱いされてるのよ？」)が、嫌味より茶目っ気で言う
- **禁句・NG**: 弱音・悲壮感、幼い感嘆(「やったー！」)、慇懃な敬語、喧嘩腰の恫喝

## 性格(強気)による変調

- 鷹揚の余裕に「舐めるな」の圧を一枚足した帯。ノーマル(阿武隈)が相手を労うのに対し、強気は自分の格を張る
- ただしヤンキー×強気(本郷「強けりゃ勝つんだよ」)のような喧嘩腰にはならない。余裕の笑みのまま圧をかけるのがこのセル

## 見本(アンカー既存セリフ=このセルの正)

- 「外では厳しく、家では陽気♪ …リングの上は？ もちろん全力よ！」
- 「わたしこれでも実力者扱いされてるのよ？あんまり舐めないでよね」
- 「ふぅ…調子上がってきたかな？」

## 個体差メモ(セル内のグラデーション)

- **菊池璃子**: セルの正。外では厳しく家では陽気、の切り替えごと「全力」で束ねる声
- **斎藤麻衣**: 「実力は見ての通りよ。伝わったかしら？」— 若手(早熟)なのに大人びた「わ」「かしら」。アンカーより落ち着いた側の個体差。※データと台詞の食い違いは裁定済み(2026-08-11): **Strikerが正**、「サブミッション技術なら…」のセリフの方を全直しで打撃系に修正する
- **須藤美月**: 「闇試合で鍛えた技…お上品なリングじゃ味わえないでしょ？」— セルの影の側。余裕の凄みは同帯だが、明るさゼロのアウトロー。Heelの振れ幅としてセル内に置くのが当面の判断(挑発に余裕が乗っている点はこのセルの声)
- **山本理香**: **2026-08-11、蠱惑×ノーマルから移籍(裁定済み)。** 妖艶の皮の下が体育会——「打ち合いは好きよ。気持ちの強いほうが勝つしねっ」の全力主義と大人の余裕がアンカー菊池と同帯、というのが移籍理由。「ふふ…あら、終わり? もう少し遊べると思ったのに」には蠱惑時代の名残があり、今後の書き下ろしは「余裕の姐御」側に寄せるのが自然。名残(ふふ/あら)をどこまで残すかは要指定

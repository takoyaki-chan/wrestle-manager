# 設備投資システム — 検討メモ（2026/03/31時点）

## 背景
- 利益率が全フェーズで45-62%、S20で残高52億。金の使い道がない
- 元仕様書: `facility-system-spec.md` を起点に検討

---

## 確定方針

### ✅ 運営費 → 廃止
- orgPop連動の週次コスト案は却下
- 理由①: 赤字でも金をむしる設計は「利益出すぎの緩和装置」として機能しない
- 理由②: 「見えないところで勝手に金が減る」のはプレイヤー体験として最悪
- 理由③: 経営シミュレーションの王道は「買いたいものを増やす」であり、税金的に抜くゲームはほぼない
- → 金の吸い込みは設備投資＋ショップで実現する

### ✅ 設備投資（2種）→ 採用
対象: **リング・トレーニング設備** と **メディカルケア設備** の2種のみ

#### 設備の基本仕様（元仕様から継続）
- 等級C/B/Aで効果と価格が異なる
- 耐久度100%からスタート、毎週自動劣化
- **効果は耐久度に比例**（耐久度70%なら効果も70%）
- 耐久度50%以下で「老朽化」警告、0%で「故障」（効果ゼロ）
- いつでも買い替え可能（残り耐久度は捨てて新品に交換）
- 設備なし = 現行と完全に同じ動作（全ゲッターが中立値を返す）

#### リング・トレーニング設備の効果
| 効果 | C級 | B級 | A級 |
|------|-----|-----|-----|
| 練習成長ボーナス | +5% | +10% | +15% |
| 試合後コンディション消耗軽減 | -1 | -2 | -3 |
| 追込練習コンディション消耗軽減 | -0.5 | -0.8 | -1.2 |

※ MQには一切影響しない

#### メディカルケア設備の効果
| 効果 | C級 | B級 | A級 |
|------|-----|-----|-----|
| 怪我期間短縮 | -1週 | -1週 | -2週(min1) |
| コンディション回復ボーナス | +0.5/週 | +1.0/週 | +1.5/週 |
| wear蓄積軽減 | ×0.9 | ×0.8 | ×0.7 |
| 怪我後成長デバフ軽減 | ×0.9 | ×0.8 | ×0.7 |

#### コードフック箇所
元仕様書 セクション6 に記載済み。変更なし。

### ✅ ショップ（高額アイテム）→ 採用
- **プレイヤー専用**（NPC団体は使わない）
- 金の使い道としての「趣味の散財」枠
- 設備が「合理的に買うべきもの」、ショップは「好きだから買っちゃうもの」

## 未決事項（次回検討）

### 1. 設備の価格・寿命（最優先）
- 元仕様の価格: C級500万 / B級3,000万 / A級15,000万
- 元仕様の寿命は長すぎるという判断あり（A級4シーズン=192週は長い）
- 短縮方向で検討中だったが数値未確定
- **寿命はシーズン単位ではなく週単位で設計する**（確定済み）
- 検討すべきポイント:
  - A級2種のフル維持で赤字になるか、ギリギリ黒字か
  - C:B:A = 1:6:30 の価格比でBが死に選択肢にならないか

### 2. 効果値のsim検証
- 成長+15%が実際のOVR成長にどう影響するか
- wear×0.7がベテラン寿命をどの程度延ばすか（強すぎる可能性あり）
- cond消耗-3の体感度

### 3. ショップの陳列方式
- 常時全種並べる vs ランダム数個を陳列
- ランダムだと「今買わないと消える」焦りで散財を誘えるが、必要な時に店にないストレスもある

### 4. 装備型アイテムのルール
- 1選手1個まで？（1個が自然だが未確定）

### 5. AI団体の設備
- orgTier依存で自動保有させるか
- AI団体も設備なしにするか
- ゲームバランスに直結する論点

### 6. ショップアイテムの追加候補
- 上記4種以外に欲しいものがあるか
- 価格の最終確定

## UI設計（元仕様から継続）
- 設備カードは団体画面の道場ヘッダー下に配置
- 耐久度バー + 効果一覧 + 購入/交換ボタン
- 50%以下で黄色警告バッジ、0%で赤バッジ
- 購入ポップアップでC/B/A級を選択
- 詳細は元仕様書セクション8参照

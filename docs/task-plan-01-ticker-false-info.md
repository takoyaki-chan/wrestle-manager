# BUG-02: ティッカー表示が虚偽の情報を流す — 計画書

## 概要

メニュー画面（manage画面）のティッカー（LINE風スクロール表示）が、実際には起きていない出来事を表示する問題を修正する。

## 現状の問題

### 虚偽情報の発生箇所

`Engine.news.generateTicker()` (engine.js L9928-10071) が問題の根源。以下のカテゴリで実データと乖離した情報が生成される：

#### 1. AI団体負傷情報 (L9981-9991) — 完全にフェイク
```
if (Engine.rng.float(rng) < 0.15) {
  const f = Engine.rng.pick(rng, roster);
  items.push({ cat: 'injury', data: { org: org.name, name: f.name } });
}
```
AI団体のロスターからランダムに選手を選び「負傷」と表示するが、実際にその選手が負傷しているかの確認が一切ない。`f.injury` の存在チェックがなく、健康な選手でも負傷と表示される。

#### 2. フレーバーテキスト (L9969-9978) — 誤解を招く可能性
ランダムな2選手の「合同トレーニング」「カフェで遭遇」等を表示。テンプレート（data.js L7340-7347）に「{name}と{name2}が合同トレーニング」等があるが、実際のrelationshipデータとの整合性がない。これ自体はフレーバーだが、意味のある関係性を暗示してしまう。

#### 3. AI団体興行結果 (L9933-9943) — 非興行週でも表示されうる
`isShowWeek` チェックはあるが、AI団体が実際に興行を行ったかの検証がない。AI側の興行処理（`Engine.rival.processAIShows` L3825付近）は別タイミングで実行されるため、ティッカー生成時点での整合性が保証されない。

#### 4. AI団体エース動向 (L9957-9966) — フレーバーだが検証なし
AI団体のOVR1位選手を「好調」と表示するが、実際のconditionや成績データとの紐付けがない。

#### 5. スカウト情報 (L9993-9996) — 完全なランダムフレーバー
12%の確率で表示。実際のスカウト動向やFA市場と無関係。

#### 6. 経済情報 (L9998-10010) — tierベースだが実態不明
AI団体のtier（S/A/B等）で「経営好調」「経営苦戦」を分岐するが、AI団体の実際の財務状態（funds等）は参照していない。

### 特に深刻な問題

- **連勝/連敗 (L9946-9955)**: `f.streak` を正しく参照しており、実データと一致する。これは問題なし。
- **負傷情報**: 健康な選手を「負傷」と表示するのは明確な虚偽。プレイヤーの意思決定に影響する。

## 変更方針

### 方針A: 検証可能な情報のみ残し、フェイクを除去

#### 変更1: AI団体負傷情報の実データ化 (engine.js L9981-9991)
```js
// 変更前: ランダム選手を負傷扱い
// 変更後: 実際にinjuryフラグが立っている選手のみ
roster.filter(f => f.injury).forEach(f => {
  if (Engine.rng.float(rng) < 0.3) {
    items.push({ cat: 'injury', data: { org: org.name, name: f.name } });
  }
});
```
該当者がいなければ何も出さない。

#### 変更2: フレーバーの無害化 (engine.js L9969-9978)
テンプレート（data.js L7340-7347）を「事実を断定しない」表現に修正。
- 「合同トレーニング」→ 「がSNSで〇〇のことに触れていた」等、確認不能なSNS情報として
- もしくは、relationships データを参照し、bond値50+のペアのみ「仲良し」系テンプレを使うよう分岐

#### 変更3: スカウト情報の実態連動 (engine.js L9993-9996)
FA市場（`state.freeAgents`）に選手がいる場合のみ表示。もしくは完全削除して他カテゴリで埋める。

#### 変更4: AI経済情報の簡易検証 (engine.js L9998-10010)
AI団体の`aiOrgs[orgId].funds`や`aiOrgs[orgId].orgPop`を参照して分岐。データが存在しない場合はtierフォールバックを維持。

#### 変更5: AI興行結果の整合性 (engine.js L9933-9943)
AI団体が当該週に興行を実施した場合のみ表示。`isShowWeek` に加え、AI興行処理の結果データ（もし存在すれば）を参照。

## 影響範囲

- **engine.js**: `Engine.news.generateTicker()` (L9928-10071)
- **data.js**: `NEWS_TICKER_TEMPLATES` (L7310-7400付近) — テンプレート文言修正のみ
- **app.js**: 呼び出し元（L4955-4956等）は変更不要
- **ui-render.js**: 表示側（L626-634）は変更不要

他システムへの影響: なし。ティッカーはGameStateを読み取るのみで、書き込みを行わない純粋関数。

## 検証方法

1. **auto-sim**: engine.js変更のため自動でフック実行（100シーズン）
2. **手動確認**: 数シーズン進めてティッカーに虚偽情報が出ないことを目視確認（ユーザー委任）
3. **検証ポイント**:
   - AI団体の負傷ティッカー → 該当選手が実際に `injury` フラグを持つか
   - 連勝/連敗 → `streak` 値と一致するか
   - フレーバーテキストが事実を断定する表現を含まないか

## 完了条件

- ティッカーに表示される全項目が実際のGameStateデータと一致する、または事実を断定しないフレーバーであること
- 負傷情報が健康な選手について表示されないこと
- auto-sim 100シーズンで違反なし

## 0. 準備

### 起動

```bash
npx serve src --no-clipboard
```

`.claude/launch.json` の `dev` 設定（port 3000、`src` を配信）と同じもの。
`file://` で直接開くと一部の読み込みが失敗するので、必ずサーバー経由で開く。

### 開発者モードを開く

**`Alt + Shift + D`**（推奨）。`Ctrl + Shift + D` は Chrome の「全てのタブをブックマーク」に
奪われることがある。開かないときはコンソールで `WrestleManagerDev.open()`。

開いた瞬間から**通常セーブは保護される**（オートセーブが `wm_dev_autosave` へ振り替わる）。
普段のプレイデータが壊れる心配はしなくていい。

### 使える機能

| 機能 | 用途 |
|---|---|
| シーズン・週を入力 →「指定週まで高速進行して保存」 | 任意の地点へ飛ぶ。対象週は**消化せずに停止**するので、その週の画面を見られる |
| プリセット「春タッグ編成」 | S現在・W11（エントリー週） |
| プリセット「夏ジュニア大会」 | S現在・W24 |
| プリセット「秋4団体対抗戦」 | S現在・W36 |
| プリセット「冬・天頂戦」 | **次に天頂戦が開催されるシーズン**のW48へ自動で飛ぶ |
| イベント即時発火「挑戦の直訴」 | 条件（heat≥90 等）を無視して即表示。forward=自団体→他団体 / inverse=他団体→自団体 |
| 「現在地を保存」 | 名前付きチェックポイント。**下記の要所で必ず取る** |
| 「開発開始地点へ戻す」 | 開いた時点まで巻き戻す |

### チェックポイント戦略（重要）

同じ地点に何度も戻れると確認が一気に楽になる。**最低この3つは取っておくことを勧める。**

1. **`S3W47`** … 年末表彰・シーズン総括の直前（何度でも表彰式を見返せる）
2. **`S3W35`** … 秋4団体対抗戦の直前
3. **天頂戦シーズンのW47** … 天頂戦の直前

ブラウザのサイトデータを消すとチェックポイントも消える点だけ注意。

### 私への報告のしかた

直せる形で受け取りたいので、**「どの画面で」「何が」「どうなっていたか」**の3点があれば十分です。
スクリーンショットがあれば最速。「気持ち悪い」「なんか違う」でも構いません（設計側の問題かもしれないので）。

## 3. MQ再設計（07-24・数値の体感なので早めが望ましい）

**時間が経つほど「どの変更のせいか」が言えなくなる**ので、優先度は高めです。

## 4. 成長リバランス（07-26）

### 4-A. ⚡ツールチップ

スマホ幅ではホバーが無いので、**タップで出るか**も見てください。

### 4-B. コーチの匂わせセリフ（48本）

**⚠ これは非常に出にくいので、出なくても異常ではありません。**

発火条件（[data.js:7612](../src/data.js) `GROWTH_CONFIG`）:

- 非興行週のコーチ報告（**25%**）が起きて、
- 担当選手の**生涯の追い込み週数が24週以上**、かつ
- **今シーズンも4週以上**追い込んでいて、
- そのうえで**35%**

実効で**シーズン1〜2回**の想定です（「忘れた頃に一回くらいでいい」という設計）。

**確認のコツ**: 特定の1人を**2シーズン以上ずっと⚡ON**にしてから、非興行週を送り続ける。
道場バナーのコーチ吹き出しに、断定しない匂わせ（「重ねた無理」の気配）が出れば OK。

**見るポイント**: セリフが**コーチ本人の口調**になっているか（voice 8系統で書き分けています）。
断定的に「怪我します」と言っていたら書き方の問題なので教えてください。

### 4-C. 追い込み常用選手が実際に早く終わるか

**確認のコツ**: 同期入団の2人を用意し、**片方だけ⚡常用**で5〜7シーズン進める。
較正では**キャリア長 9.0 → 7.0 シーズン**になる想定です。

**見るポイント**: 追い込んだ側が**先に衰え始める／先に引退する**か。
差が出ないなら係数が効いていません。

### 関連する未着手の構造問題

**「全盛期の窓が狭すぎる」**（`decayStartAge` が20〜26歳・中央値24なのに成長は3〜5年でカンスト）は
別課題として未着手です。**確認中に「伸び切る前に衰え始めている」と感じたら、それは既知**です。
係数の問題ではないので、その体感だけメモしておいてもらえると設計議論の材料になります。

## 順序についての注意（バグB との兼ね合い）

私がいま調査している**バグB（因縁のリング内効果が特別興行・対外戦に未配線）**を直すと、
**特別興行での因縁がらみの試合の中身が変わります。**

なので、次の2つは**私の修正後に回したほうが二度手間になりません**。

- 2-6 / 2-10 天頂戦の「試合の質感」の判断
- 3-C 王座戦のMQ優位のうち、**因縁が絡む試合**での体感

逆に、**以下は今すぐやって問題ありません**（バグBの影響を受けない）。

- 1 年末表彰（表示のみ）
- 3-A / 3-B 週頭通知・一面レイアウト（表示のみ）
- 4 成長リバランス（成長・消耗の系統）
- 5 音響（聴感）
- 6 挑戦試合セリフ（即時発火で完結）
- 7 派閥イベントの偏り
- 8 ヘルプ・ティップス

**おすすめの着手順**: 6（即時発火で一番楽）→ 1（今日の変更・チェックポイントを作る）→ 5（音をまとめて）
→ 3-A/3-B → 4 → 7 → 8 → バグB修正後に 2 と 3-C。

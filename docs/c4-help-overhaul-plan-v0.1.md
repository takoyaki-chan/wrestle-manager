## Phase 0 — 共通基盤(実装対象)

### 0-1 汎用ツールチップ・コンポーネント
- ランキングの teleport 型(`.rank-metric` + `.rank-metric-tooltip`、JS: ui-render.js:14594-14649、CSS: index.html:7320-7368)を**汎用名に共通化**する: `.wm-tip`(トリガ)+ `.wm-tip-body`(本体)+ 既存の `.rmt-label`/`.rmt-text` 相当
- teleport(document.body へ移設・fixed配置・0.25s遅延)の挙動は現行のまま。既存のランキング6指標は共通版へ移行(見た目・挙動は不変)
- `.rank-metric` は後方互換のためエイリアスとして残してよい(段階移行)
- 実装位置: JSは ui-common.js(全画面から使うため)、CSSは index.html の共通セクション

### 0-2 用語ツールチップの文言一元化
- `data.js` に `TERM_TIPS` 定数を新設(STAT_TIPS と同じ思想):
  ```js
  const TERM_TIPS = {
    mq:   { label: 'MQ — 試合品質', text: '...' },
    heat: { label: 'Heat — 観客の熱', text: '...' },
    ovr:  { label: 'OVR — 選手の総合力', text: '...' },
    dp:   { label: '決裁枠 — 社長の決裁エネルギー', text: '4週ごとに+2回復、上限6。...' },
    ...
  };
  ```
- ランキング6指標(評価/基礎力/平均OVR/対戦PT/レガシー/実績)の既存文言もここへ移設し、ui-render.js 内の2カ所ハードコピー(3755付近/4299付近)を解消
- ヘルパー: `termTipHtml(key, displayText)` のような生成関数を ui-common.js に

### 文言の執筆ルール
- 数式を丸見せしない(CLAUDE.md「数値の丸見せによるスプレッドシートゲーム化」禁止)。挙動の説明はするが、係数の羅列はしない(既存ランキングツールチップの粒度が上限)
- 格言・一般論を書かない(2026-07-16確定の文章方針)
- 内部変数名を出さない

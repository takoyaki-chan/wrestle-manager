## なぜ「足りない」と感じるか（分析）

ロスター8人想定で計算すると:
- 1シーズン48週で実質的に撃てる有償アクションは **17回程度**
- 8人で割ると **1人あたり半年に2回ちょい**
- スランプ・モチベ系は声かけ(コスト0)で対応可能 → 圧迫しない
- **問題は怪我対応**: `special_treatment` がストック1を食う

怪我は不可抗力で、しかも重なる時は重なる。「育成計画のために溜めていたストックが、たまたま起きた怪我で全部溶ける」のが一番のフラストレーション源と推測される。さらに大所帯になるほど怪我発生頻度は上がるが、ストック上限は固定の5。

---

## 検討した対策の方向性（前回会話で話したもの）

### 案1: 単純に回復速度を倍に
- 4週ごと+1 → **3週ごと+1**
- シーズンあたり 5+16 = 21ストック (現+24%)
- → 弱い。怪我対応の根本フラストレーションは解消しない

### 案2: 最大値とロスター連動
- `careStockMax` を `Math.max(5, Math.floor(roster.length * 0.7))` 等に
- 8人→6、12人→8
- 大所帯で自然に上限が上がる
- → 効くが、怪我問題はやはり残る

### 案3（推奨）: コスト構造の見直し + 回復速度up

| 変更点 | 現状 | 提案 |
|---|---|---|
| 回復間隔 | 4週ごと+1 | **3週ごと+1** |
| 最大値 | 5固定 | **`Math.max(5, Math.floor(roster.length * 0.6))`** |
| `special_treatment` | 1 | **0** |
| `media` | 1 | 1（据え置き） |
| `bonus`/`costume`/`trainer` | 1 | 1（据え置き） |
| `camp` | 2 | 2（据え置き） |
| `refresh_leave` | 1 | 1（据え置き） |
| `party` | 1 | 1（据え置き） |

**核心は `special_treatment` をストック0にすること。** 怪我対応は不可抗力なので、これを「お金は払うがストックは消費しない」枠に動かす。これだけで体感は大きく変わるはず。

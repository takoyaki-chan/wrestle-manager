# タッグ掛け声テーブル [personality][archetype] フルマトリクス草案 v0.1

文体方針:
1. **personality=感情の中身(言うこと)、archetype=言い方(語尾・一人称・温度)。** quiet×ojousama なら「寡黙さ」を「ですわ」で包む。CUTIN_LINES の合成規則に準拠。
2. **掛け声は短く(目安4〜14文字)。** HOT/DOUBLE/CUTIN は張り上げる第一声、BETRAYAL だけは叫ばず漏れる声で「……」多用。
3. **delinquent の一人称は「あたし」固定(「俺」禁止)。ojousama は修羅場でも「ちっ」等の下品を混ぜない。composed は「!!」を使わず「…」で間を作る。**

各テーブル: personality 7種 × archetype 7種 × 3本。

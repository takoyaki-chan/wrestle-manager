# 団体比較 & 新聞記事 豪華化提案 v2

## 概要

団体比較タブと新聞記事タブの情報量・演出を大幅強化する。
キーワード：**スポーツ新聞の特集企画風**、**辛辣な記者トーン**、**プレイヤーの成長カタルシス**。

---

## Phase 1: データ基盤（Engine側）

### 1-1. 団体間戦績レコード `orgWarRecord` の新設

現状 `battlePoints` は累積ポイントのみ。**団体ごとの直接対決 W-L** を記録する。

```
state.orgWarRecord = {
  org_s: { wars: 3, warsWon: 1, warsLost: 2, warsDraw: 0,
           summits: 1, summitsWon: 0, summitsLost: 1,
           ppvMatches: 2, ppvWon: 1, ppvLost: 1,
           totalMatchesPlayed: 11, totalMatchesWon: 5, totalMatchesLost: 6,
           lastResult: { type: 'war', won: false, season: 4, week: 18 },
           streak: -2 },  // 連勝(+)/連敗(-) ※イベント単位
  org_a: { ... },
  org_b: { ... },
};
```

**記録タイミング：**
- `applyWarOutcome()` → 対抗戦結果
- PPVサミットマッチ結果
- PPV通常カードでのクロス対戦（あれば）

**用途：**
- 団体比較タブの「戦績サマリー」セクション
- 新聞記事の「前回は○○に敗れている」等の参照
- 辛辣テキストの根拠（「通算1勝5敗。もはや鴨だ」）

### 1-2. orgPop スナップショット（シーズン推移）

シーズン開幕時のorgPopを記録し、「開幕 → 現在」の推移を可視化可能にする。

```
state.orgPopHistory = {
  player: [{ season: 1, start: 10, end: 18 }, { season: 2, start: 18, end: 35 }],
  org_s:  [{ season: 1, start: 75, end: 78 }, ...],
  ...
};
```

シーズン開始時に前シーズンの `end` を確定、当シーズンの `start` を記録。

### 2-2. 特集ヘッダー（記者の見出し）

既存の `Matchup Difficulty` グレード表示を、**記者の見出し記事風**に変える。

totalDiff に基づく見出しテンプレ（各段階5パターン以上、ランダム選択）:

**惨敗圏 (totalDiff ≤ -60)**
- 「正直、比較するのが気の毒なレベルだ」
- 「戦力差は歴然。これで興行を打つなら心臓だけは一級品」
- 「○○に喧嘩を売るのは自由だが、ファンの目が先に死ぬ」
- 「全項目で劣勢。唯一勝っているのは伸びしろの量くらいか」
- 「○○から見れば練習試合の相手。申し訳ないがそれが現実だ」

**劣勢 (totalDiff ≤ -25)**
- 「差はあるが、絶望するほどではない。問題は打つ手があるかどうか」
- 「○○とはまだ格が違う。だが、一点突破の芽はゼロではない」
- 「このまま放置すれば差は広がる一方。GM の手腕が問われる局面」
- 「弱いのは仕方ない。弱いまま何もしないのが問題なんだ」
- 「せめて一つ、胸を張れる軸を作らないとファンに申し訳が立たない」

**互角 (totalDiff -10 ~ +10)**
- 「拮抗。この均衡をどちらが先に崩すか、見応えのある構図だ」
- 「ほぼ互角の力関係。次の補強、次の一手が勝負を分ける」
- 「甲乙つけがたい戦力バランス。ここからが本当のプロモーション戦争」

**優勢 (totalDiff ≤ +40)**
- 「明確な優位。ただ油断すれば、ひっくり返されるだけの差でもある」
- 「上に立っているが、このリードを守り切る覚悟があるかどうか」

**圧倒 (totalDiff > +40)**
- 「完勝。ここまで差がつくと、もはや同じリーグの話なのか疑わしい」
- 「相手は格下と言い切っていい。問題はもっと上を見据えられるかだ」

**1行コメントのバリエーション（MQ基準 — 後述の相対評価と組み合わせ）：**

高MQ（相対的に良い）:
- 「今興行のベストバウトはこの試合かもしれない」
- 「予想以上の好勝負。両者の株が上がった」
- 「隠れた名勝負。メインに引けを取らない内容」

普通:
- 「無難にまとめた一戦」
- 「大きな波乱なし。予想通りの展開」

低MQ（相対的に悪い）:
- 「物足りなさが残る。噛み合わなかった」
- 「観客の反応は薄かった」
- 「正直、カード編成に問題があったのでは」

### 3-2. 興行総合評価（相対評価方式）

> ※ 平均MQの絶対値で評価すると、低人気団体の序盤はMQ 39でも御の字。
> 団体の規模・段階に応じた**相対評価**が必要。

**評価ロジック案：**

```javascript
// 基準MQ = 団体人気から期待されるMQ水準
function getExpectedMQ(orgPop) {
  // orgPop 10 → 期待MQ 30, orgPop 50 → 期待MQ 55, orgPop 80 → 期待MQ 70
  return Math.round(25 + orgPop * 0.6);
}

const expected = getExpectedMQ(orgPop);
const diff = avgMQ - expected;

// diff に基づく評価
// +20以上: ★★★★★ 歴史的大会
// +10~19: ★★★★  素晴らしい興行
// +0~9:   ★★★   期待通りの良興行
// -1~-9:  ★★    もう一歩
// -10~-19:★     厳しい評価
// -20以下: (星なし) ファンの怒号が聞こえる
```

**星評価は新聞記事内に表示：**
```
━━━━━━━━━━━━━━━━━
興行評価  ★★★★☆
「この規模の団体で、ここまでの試合を並べた
 のは率直に称賛に値する。次が楽しみだ」
━━━━━━━━━━━━━━━━━
```

**低評価時：**
```
興行評価  ★☆☆☆☆
「期待を大きく下回る興行。チケット代を返して
 ほしいというファンの声が聞こえてきそうだ」
```

## Phase 4: テキストレパートリー方針

### レパートリー数の目標

属性パターンがない分（選手セリフと違い記者/ファンは1人格）、
**各カテゴリ最低10パターン、目標20パターン**を用意。
同じプレイで同じ文が出にくくなる。

| カテゴリ | パターン数目標 |
|---------|-------------|
| 特集見出し（惨敗〜圧勝 5段階 × 10+） | 50+ |
| 戦績コメント（勝ち越し/負け越し/互角） | 30+ |
| マッチアップ解説（スタイル相性/年齢/h2h/勢い） | 60+ |
| 記者総評コラム（5段階 × 5+） | 25+ |
| ファン世論（4タイプ × 5段階 × 5+） | 100+ |
| 新聞ダイジェスト1行コメント | 30+ |
| 興行評価コメント（星ごと） | 25+ |
| 次回展望テンプレ | 15+ |

**合計: 335パターン以上**

初期実装では各カテゴリ最低5パターンから始めて、
プレイテスト後に追加していく方針が現実的。

## 既存テキストの修正ポイント

現状の `getMatchupCopy()` / `getEdgeState()` は機能的に正しいが、
トーンがフラットすぎる箇所がある。例：

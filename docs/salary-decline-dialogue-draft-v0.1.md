## レビューで裁定いただきたい点(Fableレビューで拾った論点)

1. **お嬢様の「！」**: シートは「お嬢様で『！』が出るのは真面目帯だけ」だが、既存 raise_open の ojousama emotional は「！」を使用。本草案は既存実装に合わせ emotional にも「！」を残した。どちらを正とするか
2. **ヤンキーの「あんた」1件**(decline_strict bold): 関係が軋む場面の対社長。ヤンキー骨格として許容か
3. **蠱惑 easygoing decline_accept「お店のランクを一つ落とすだけの話でしょ？」**: 比喩が水商売の含みに読める。蠱惑の色気の範囲か、書き直すか
4. **丁寧 shy decline_strict「わたし、そんなに、いらない人になっちゃいましたか……？」**: 卑屈語彙の一掃方針と際どい線。最も冷たい選択肢への反応なので問いかけ止まりで残したが、要判断
5. **標準 quiet の声**: 既存 raise_open の standard.quiet は敬体(「あの……社長、少しお時間……」)だが、口調シート(早見知子=乾いた短文)と乖離。本草案は**シート側を正**として書いた。既存 raise_open 側を全直しの続きで直すかは別件
6. **鷹揚 decline_strict quiet は24字**(「…………そう。……分かった。……話は、それだけ？」): 沈黙を怒りとして使う狙いの意図的な短さ。可否
7. **ヤンキーの伝法語尾**: 検品06の裁定は「伝法語尾はヤンキー骨格内として温存」だが、本草案は新規執筆のため男系の強い語尾(だぜ/だろうが)を避け、「嘘つかねえ」等の残り香に留めた。新規セリフでの伝法の濃さはこの水準でよいか

- **実在セル**: ヤンキー×ノーマル(岩屋みら)/ヤンキー×強気(本郷真理子)/ヤンキー×お気楽(生駒エリカ)の3セルのみ。quiet・shy・earnest・emotional は口調シートが存在しないため、属性骨格+既存 `CONTRACT_NEGOTIATION_LINES.delinquent` の実装済みレジスタから外挿(全28本に ※実在セルなし)。
- **レジスタの根拠**: 既存 data.js の delinquent は normal/bold/easygoing=非敬語タメ口、quiet/shy/earnest/emotional=「っす」体、で一貫している。この分割を踏襲した。
- **一人称**: 全49本で漢字「私」のみ(15本で使用、残り34本は一人称なし)。「あたし」「アタシ」「俺」は不使用。
- **二人称**: 「あんた」1本のみ(decline_strict bold)。裁定55のヤンキー既定に従い、それ以外は呼ばない。
- **「社長」呼びかけ**: 2本のみ(decline_voluntary_open の normal / quiet)。1本内での連呼なし。
- **禁句の扱い**: 「〜だぜ」「〜だろうが」「てめえ」は不使用。伝法の残り香は「嘘つかねえ」1箇所と「〜てりゃ」「〜てんなら」の音便のみに限定した。中性カジュアル(「〜じゃん」「〜っしょ」「〜だよね」)は許容範囲として使用。
- **`{tenure}`**: 3本で使用(decline_open normal / decline_voluntary_open normal・earnest)。delinquent 版 tenure 文(「もう{n}年か……早ぇもんだな。」等)の直後に自然につながる位置に置いた。
- **感情設計の軸**: 反発ではなく「体は正直」という自己認識で受ける(悲壮化の回避)。温情(hold)は照れ隠しの反発→借りの宣言、strict は爆発ではなく静かに退場、voluntary は自分から値段を言い切る姐御の誇り、で書き分けた。

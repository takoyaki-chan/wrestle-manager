# レッスルマネージャー 音楽制作計画

上位計画: [音響全面再設計マスタープラン](./wrestle-manager-audio-redesign-master-plan.md)  
対応する生成用プロンプト集: [レッスルマネージャー Suno短文プロンプト集](./wrestle-manager-suno-prompt-pack.md)

## 1. 目的

Suno の有料契約期間中に、現在の実装で必要な曲だけでなく、将来追加しそうな画面・イベントまで含めて音楽資産を制作する。

- BGM は原則 30～60 秒の短いループ
- 結果・獲得・警告などは 5～15 秒のジングル
- ボーカルは使用しない
- 基本音色はファミコン／NES 2A03 系で統一する
- 生成した原曲、採用版、ループ加工版、プロンプト、利用箇所をすべて保存する
- 契約終了後に再生成できなくても困らない状態を完成条件とする

## 3. 音楽の共通仕様

### サウンド・バイブル

| 項目 | 基準 |
|---|---|
| 基本音色 | NES/Famicom 2A03、pulse lead、triangle bass、noise drums |
| ボーカル | 全曲なし。Instrumental を有効化 |
| 通常 BGM | 30～60 秒、8 または 16 小節を基本 |
| 試合前 BGM | 最初の 1 秒から緊張と勢いを出す。静かな待機曲にしない |
| ジングル | 5～15 秒、明確な一発完結、フェードアウトなし |
| ループ | 末尾を冒頭へのピックアップとして設計。無音を入れない |
| マスター保存 | WAV、無加工の生成原音も保存 |
| ゲーム用 | OGG 推奨。MP3 はループ用マスターにしない |
| 音量目安 | BGM -18～-16 LUFS、ジングル -15～-13 LUFS、True Peak -1 dB 以下 |

### 曲の統一感

- タイトル曲の 3～5 音の主題を、王座戦、年代記、殿堂入り、エンディングで変奏する
- 通常経営系は同じコード感と音色を共有する
- 試合前系は同じドラム語彙を共有し、階級・因縁・大会ごとに旋律と重さを変える
- 季節感は戦闘感を弱めない範囲で加える
- 春夏秋冬の A は通常カード・序盤、B は注目カード・終盤向けとする

## 4. 制作台帳

|---|---|---:|---|---|---|
| WM-C01 | タイトル・オープニング | 45～60秒 loop | ゲーム開始時の既存オープニング演出 | 既存オープニング曲を継続使用 | P0 |
| WM-C07 | 契約交渉 | 30～45秒 loop | 駆け引き、判断、時間制限感 | 緊張曲を共用 | P1 |

**2026-07-23 裁定**: WM-C04（選手一覧）／WM-C05（育成）／WM-C06（スカウト）は**廃止**。経営画面はタブを問わず1曲で通す（タブ移動での曲切り替えはしない）。契約交渉（C07）とドラフト（F02）だけは独立した場面として専用曲を維持する。C04～C06 名義で生成済みの候補曲は破棄せず、他枠の候補として転用する（選定ボード上でドラッグして割当）。旧 WM-C03（通常経営）は **WM-S00 に改番**し、団体状況の並びの先頭へ移動した。

## 6. 1か月の制作日程

### 契約前

- 44曲の用途と短いプロンプトを完成させる
- 命名規則、保存先、採用判定表を用意する
- 無料生成物を商用採用しない

### 1～3日目: 音楽の基準作り

- タイトル、通常経営、軽量級、重量級、エンディングを試作
- 5曲の音色と音圧を比較し、サウンド・バイブルを確定
- 採用したタイトル主題を後続曲の共通モチーフにする

### 4～10日目: P0 コア・通常試合前

- コア 3曲
- 通常試合前 4曲
- 各曲 4～8候補を生成し、1曲を仮採用

### 11～16日目: 季節興行・大型興行

- 春夏秋冬 各2曲
- トーナメント、ジュニア大会、最終戦、PPV

### 17～21日目: 結果・ドラマ・歴史

- 結果ジングル 4曲
- 裏切り、引退、世代交代
- 年代記、殿堂入り、エンディング完成版

### 22～25日目: 経営画面・団体状況

- 選手一覧、育成、スカウト、契約交渉
- 好調、資金難、不穏、団体危機

### 26～27日目: P2・効果音

- 負傷、復帰、追悼、海外遠征、TV放送、レジェンド戦
- Sounds の One Shot／Loop で不足 SE を制作

### 28～30日目: 編集・実機確認・保管

- WAV からループ箇所とジングルを切り出す
- 音量、先頭無音、末尾、クリックノイズを確認
- OGG へ変換してゲーム内で連続再生テスト
- プロンプト、原音、採用版、不採用理由、ライセンス情報を保存
- 契約終了前に全ファイルをダウンロードする

リポジトリへ実際に追加する際は、容量を見ながら原音 WAV を別保管し、ゲーム本体には採用 OGG のみを配置する。

## 9. 採用判定

各候補を次の5項目で5点満点評価する。

1. 画面・イベントへの適合
2. 最初の5秒の強さ
3. 旋律の記憶性
4. ループ耐性
5. 他曲との統一感

合計20点未満は不採用。試合前曲は「戦闘開始が迫っている」と感じられなければ、音質が良くても不採用とする。

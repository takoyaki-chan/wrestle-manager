# LLMセリフ ブラインドテスト 採点シート(2026-08-10)

## これは何

「キャラ設定カード+口調+見本セリフ1本を渡した安価なLLMが、Keisukeの手書きセリフと並べて通用するか」を測る実験。
ランタイムLLM組み込みの是非を議論する前に、**いま一番安い価格帯のモデルの現在地**を自分の目で確かめるためのもの。

- 生成モデル: Haiku(直接API換算で1呼び出し約0.2円。「1回0.1円以下」帯の代役)
- 各キャラ、実際の勝利セリフ3本のうち**1本だけ**を見本としてLLMに渡し、新作4本を生成させた
- 生成順の先頭3本を**無加工**で採用(Fableによる添削・選別なし)
- 残り2本の実セリフ(victory-lines.js)と混ぜて5本をシャッフルした
- 合計25本 = 手書き10本 + AI産15本

## 採点のやり方

1. **`answer-key.md` は採点が終わるまで開かない**
2. 各セリフに採用判定を付ける: **○**(そのまま使える) / **△**(手直しすれば使える) / **×**(この子の言葉じゃない)
3. 余裕があれば「AI産だと思うか」も付ける(自分の書いたセリフは覚えているはずなので、こちらはおまけ。本命は採用判定)

**見るべき数字はAI産15本の○率。** 手書き10本は基準線(これが○にならないなら基準側がズレている)。

判定後の目安:
- AI産の○率が手書きと同水準 → 次回作でのランタイム生成設計を前倒しで検討する価値あり
- △中心 → 「生成→人間レビュー→焼き込み」の現行パイプライン強化が正解。ランタイムは時期尚早
- ×中心 → この価格帯では不成立。1〜2年後に同じシートで再測定

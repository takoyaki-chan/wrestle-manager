## 実験条件

- 生成モデル: Haiku(claude-haiku-4-5)。1キャラ=1呼び出し、4本生成→先頭3本を無加工採用
- コスト試算(ゲーム組み込み時の直接API呼び出し換算): 入力≈700tok+出力≈150tok、$1/$5 per Mtok → **約0.2円/回**。GPT-4o-mini級ならさらに1/5程度(≈0.03〜0.05円)。今回の実験はエージェント経由なのでこの数字より多く使っているが、組み込み時のコストは上記

## Fable所見(採点が終わってから読むこと)

出力は一切添削していない。私が気づいた点(採点への影響を避けるため、判定後に読む前提で書く):

- **生駒エリカ: AI産は一人称「俺」を使った。** カードに一人称を書かなかった(本物のセリフに一人称が出ないので書けなかった)ら、安いモデルは平気で創作する、という実例。設定カード方式の弱点がそのまま出た——**カードに書いていないことは守られない**。全キャラ分のカードを完璧に書く作業は、結局セリフを書くのと同じくらいの設計コストになる
- **大河内: 「〜と思ったが」という男性的な接続、「骨組み」「からね」など語彙・語尾レベルの揺れ。** 品格を「語彙で出す」のは安いモデルには一番難しい注文
- **橘: 「苦しみっぷり」「敗北させたかった」など、キャラの温度より一段幼い語彙が混ざる**
- **堂前: 言葉数制約は守れている。** 字数のような機械的制約は安いモデルでも守る。守れないのは「らしさ」の方
- **宇田川: 「んっしょ」など造語気味の語尾。** ギャルらしさの「軽さ」は出ているが語尾の精度が甘い

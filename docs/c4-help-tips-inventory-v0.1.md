### 2b. 実装済みなのにガイドに1節もない主要システム

- **派閥**(F01〜F09・抗争ポイント・派閥対抗戦) — システム規模に対して説明ゼロ

- **絆・因縁**(関係性2軸・相関図・険悪/裏切り・元同僚初対戦)

- **挑戦試合打診 / 離脱・裏切り・奪還挑戦**

## 4. 関連ルールとの整合

- **プレイヤー向け表記に内部変数名を使わない**: ヘルプ内「衰え(wear)」が違反。「MQ」はUI全域で表示されている実態があり扱いを裁定(§5-3)
- **数値哲学(丸見せ回避)**: 現ヘルプは倍率・確率をかなり露出(×1.2、+12、成功率15%等)。どこまで書くかの基準が必要(§5-4)

## 5. 論点(Keisuke さん裁定待ち)

1. **機構の統一方針**: 説明系ツールチップを `showCustomTooltip`(PC ホバー+スマホタップ)ベースの ℹ️/ホバー統一に寄せるか。title 属性は「なくても困らない冗長情報」限定に格下げする案
2. **ヘルプ画面の改訂範囲**: 節構成からの全面再設計(未掲載システムの追加込み)か、陳腐化箇所の差し替え優先か。読む系・派閥・タイトルをどこまで載せるか
3. **「MQ」表記の扱い**: UI 全域で MQ 表示が定着しているため公認ゲーム用語とするか、「試合品質」へ全域統一するか(後者は大工事)
4. **数値の露出基準**: ヘルプに倍率・確率を書く範囲。「操作に直結する条件(体調60未満で自動休養等)は書く、内部式(×1.35等)は書かない」あたりが叩き台
5. **フェーズ分割案**:
   - **P1: ヘルプ画面改訂** — 嘘が書いてある状態の解消が最優先。陳腐化確定2節の書き直し+全節の数値照合+未掲載節の追加
   - **P2: 今週画面+興行準備** — 操作の中心。ティップス機構統一の雛形をここで作る
   - **P3: 社長室・スカウト・ドラフト交渉**
   - **P4: データベース・経営・残り**

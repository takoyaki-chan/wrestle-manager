# 選手成長リバランス — 検証セッションまとめ（2026-03-05）

## 経緯

growth-rebalance-design-v1.0 を実装済みの状態で、プレイヤーから「緩すぎる」「全キャラ突き抜けている」という声があり、実際のバランスをMonte Carloシミュレーション（N=2000）で検証した。

---

## 発見した問題

### 核心: プレイヤーとAIで成長計算式が根本的に異なる

| | プレイヤー | AI |
|---|---|---|
| 練習成長 | 週次calcGrowth（seasonBudgetベース） | なし（一括配分） |
| 試合成長 | 毎興行 matchGrowthBase=0.7 × 24試合 | なし（seasonBudgetに含む） |
| 年間成長 | 練習~19pt + 試合~23pt = **~42pt (OVR+8)** | seasonBudget **~13-17pt (OVR+2-3)** |
| 成長速度比 | **AIの約3倍** | 基準 |

### 試合成長が支配的

- 試合成長（23pt/年）だけでAI S級のseasonBudget全体（17pt）を超えている
- matchGrowthBaseが年齢に無関係 → ageMultiplierの設計意図が機能していない
- 17歳でも27歳でも年間OVR+8程度で横並び

### 結果として起きていること

- 標準プレイヤー: **S5-6でS級と並び、以降一方的に突き抜け**
- 上手いプレイヤー: **S3-4で並び、S10で全キャラOVR95超え**
- S級1位がゲーム最強でいられるのはS7まで（S9以降は0%）

---

## 合意した方針

### 1. 案A: matchGrowthBase引き下げ（先に実装）

- 現行 0.7 → **0.40を候補値として検討中（未確定）**
- 0.40の場合: 試合成長 12.8pt/年 → OVR+2.6/年
- P1がS1を超えるタイミング: S10（51%）

**候補値の比較（AI側は現行旧式のまま）:**

| base | P1>S1が50%超え | 試合OVR/年 |
|---|---|---|
| 0.70（現行） | S7 | +4.7 |
| 0.50 | S9 | +3.4 |
| **0.40** | **S10** | **+2.6** |
| 0.30 | S11 | +2.0 |
| 0.20 | S12 | +1.5 |

**注意:** AI統一モデル導入後はAI側も強くなるため、ここで厳しくしすぎると後で不利になる。0.40は「少し甘め」の安全な選択。

### 2. AI統一モデル: 全団体同じ計算式（案Aの後に設計・実装）

- `aiSeasonGrowth`（一括配分）を廃止し、プレイヤーと同じ練習+試合の計算式をAIにも使う
- Tier差はコーチの質・施設・運営方針で表現

**統一モデルの検証結果（matchGrowthBase=0.70のまま全団体同一式で回した場合）:**
- S級1位がゲーム最強でいられる割合: S0-S12で**75-80%維持**（現行は S7で5%）
- P1がS1を超えるのはS15でも31%にとどまる
- 「弱小から始めて逆転する」カタルシスが自然に実現される

### 3. 案E: 試合成長にageMultiplier適用（検討中）

- 現状: 試合成長は年齢に関係なく固定量
- 案E: `matchGrowth *= ageMultiplier(age)` を追加
- 統一モデルと組み合わせるかは未定

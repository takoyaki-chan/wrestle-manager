# 全国統一王座 P4(記録・表彰・殿堂) 設計案 v0.1

- ステータス: 起草(2026-08-13 Fable)・**Keisuke裁定待ち(数値1点+構成3点)**
- 前提: P1〜P3はマージ済み。P4は「ベルトの歴史を記録面に残す」工程。エンジンの試合・抽選には一切触れない
- 既存の物差し(calcHofPoints実測): 団体王座=戴冠1pt+防衛1pt/回 / 天頂戦=優勝8・準優勝5・ベスト4=3 / 頂上決戦勝利=5 / JT優勝=4 / 春タッグ優勝=3 / MVP=2。殿堂レベル閾値=★15/★★22/★★★35

## 1. 殿堂ポイント(数値裁定①)

| 事績 | 加点 | 根拠 |
|---|---|---|
| 天頂戦優勝での戴冠 | **+0(追加なし)** | 天頂戦優勝8ptが戴冠を兼ねる。**二重取りを作らない**(起票時からの懸念点) |
| 防衛戦でのベルト奪取 | **+5** | 業界1位の王者を破る単発の大仕事=毎年の頂上決戦勝利(5pt)と同格 |
| 統一王座の防衛 | **+2/回** | 団体王座防衛(1pt)の一段上。挑戦者は常に他団体の看板級 |
| 返還・返上 | +0 | 防衛ptが既に累積している。記録はhistoryが背負う |

**効き方の目安**: 4年完走・防衛11度なら 22pt(=単独で★★ゴールド帯)。天頂戦優勝込みで30pt。「統一王座の長期政権=殿堂級」という格付けになる。

**対の不変条件(実装時に計測)**: 100季auto-simで殿堂レベル分布(★/★★/★★★の人数比)を導入前と比較し、**★★★が導入前の2倍を超えるようなら防衛+2→+1.5へ落として再計測**(較正条項)。既存の団体王座・大会ポイントの式は一切変更しない。

## 2. 選手個人の記録(careerRecord)

- 現状: 戴冠(`type:'unifiedTitle', result:'won'`)のみ記録済み(P1)。**防衛と奪取が個人記録に残っていない**
- 追加: 防衛成功時に `result:'defense'`、防衛戦での奪取時に `result:'captured'` を積む(天頂戦経由の戴冠は従来どおり`'won'`)。calcHofPoints と buildCareerHighlights(実績リスト)は**同じ経路で対に**追加(片方だけ直すとズレる、の教訓コメントに従う)
- 実績リスト文言(殿堂・選手詳細): 「全国統一王座 戴冠(第N代)」「全国統一王座 防衛N度」「全国統一王座 奪取」
- シーズン総括のチップ(`_collectFactChips`)に 🌐 を追加: 「🌐 統一王座防衛N回」「🌐 統一王座奪取」「🌐 現統一王者」
- 既存セーブは遡及しない(発生時点から記録。過去の防衛は`G.unifiedTitle.history`に残っており記録タブ側で読める)

## 3. 年間表彰(構成裁定②)

- **非天頂戦年のみ**、「今年の大会」部に**「全国統一王者」スライドを1枚**追加: 年末時点の保持者(自団体/AI問わず)+在位年数+今年の防衛数。金枠ではなく**オーロラ帯**(P3のトークン)
- 天頂戦年は追加しない(天頂戦優勝スライドが戴冠を兼ねる。同じ顔が2枚続く問題の再発防止=新人王統合と同じ理屈)
- 空位の年はスライド自体を出さない(不在データを説明しない原則)
- 実績ポイント(表彰式の団体スコア)への加点はしない(天頂戦優勝20ptが既にあるため)

## 4. 記録タブ(構成裁定③)

📜記録タブに**「全国統一王座」セクション**を追加:

- 歴代王者リスト(`G.unifiedTitle.history`から生成): 第N代・名前・団体・在位期間・防衛数・終わり方(返還/陥落/返上)
- 最多防衛記録・最長在位記録の2見出し
- ベルトが未創設のセーブではセクションごと非表示(不在データを説明しない)

## 5. 年代記(構成裁定④)

- 引退アーカイブ(`fighterArchive`)は buildCareerHighlights 経由なので§2の追加で自動反映(統一王座歴が引退選手の実績に残る)
- 年代記の章生成に「統一王座の移動」を独立イベントとして足すかは**見送り**(章の材料は既に新聞・大会実績で足りている。過剰化を避ける)

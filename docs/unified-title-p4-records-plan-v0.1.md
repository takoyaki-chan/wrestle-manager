## 1. 殿堂ポイント(数値裁定①)

| 事績 | 加点 | 根拠 |
|---|---|---|
| 天頂戦優勝での戴冠 | **+0(追加なし)** | 天頂戦優勝8ptが戴冠を兼ねる。**二重取りを作らない**(起票時からの懸念点) |
| 防衛戦でのベルト奪取 | **+2** | **防衛と完全対称**(統一王座戦の1勝=2pt、どちら側でも同じ)。団体王座の前例(奪取1:防衛1)と同型 |
| 統一王座の防衛 | **+2/回** | 団体王座防衛(1pt)の一段上。挑戦者は常に他団体の看板級 |
| 返還・返上 | +0 | 防衛ptが既に累積している。記録はhistoryが背負う |

**Keisuke懸念(2026-08-13)への答え — 「取ったり返したり」は得にならない**: 1勝あたりの点を奪取・防衛で完全対称にしたため、ベルトが往復しても点の入り方は「守り続けた場合」と1勝単位で同一。しかも王者は四半期ごとに必ず試合が組まれる(挑戦者側は順番待ち)ので、**最速で積めるのは腰を据えた長期政権**という序列が構造的に保証される。当初案(奪取5/防衛2)はこの逆転を生み得たため撤回。

**効き方の目安**: 4年完走・防衛11度なら 22pt(=単独で★★ゴールド帯)。天頂戦優勝込みで30pt。奪取→即陥落は2pt=防衛1回分でしかない。

**対の不変条件(実装時に計測)**: 100季auto-simで殿堂レベル分布(★/★★/★★★の人数比)を導入前と比較し、**★★★が導入前の2倍を超えるようなら防衛+2→+1.5へ落として再計測**(較正条項)。既存の団体王座・大会ポイントの式は一切変更しない。

## 1.5 MVPレース(数値裁定①-b。2026-08-13 Keisuke指摘で追加)

**現状の実測**: MVPレース(`calcSeasonPoints`)は団体王座のtitleWin/titleDefenseイベントを数える方式のため、**統一王座戦は現在1ptも入っていない**(高MQ試合のbigMatch加点が偶発的に乗るだけ)。P4で§2の個人記録イベントをレースの採点に接続する。

| 事績 | レース加点 | 既存の物差しとの整合 |
|---|---|---|
| 統一王座の防衛 | **+20/回** | 団体王座防衛13の約1.5倍。対抗戦勝利16より上・頂上決戦勝利30より下 |
| 防衛戦でのベルト奪取 | **+20** | 防衛と対称(Keisuke指摘2026-08-13で当初案24から圧縮)。団体王座の前例はむしろ防衛優位(奪取11<防衛13) |
| 年末時点で統一王者 | **+12** | 団体王者の年末保持8の1.5倍 |
| 天頂戦経由の戴冠 | +0 | 天頂戦のレース点(R1〜決勝+優勝ボーナス)が既に別枠で入っている |
| 挑戦失敗・ベルト喪失 | ±0 | 減点はしない(喪失した王者はその季の防衛ptを既に稼いでいる) |

**効き方の目安**: 1年フル防衛(3回)+年末保持=72pt。「業界の頂点を1年守った選手がMVP最有力」という格付けは説得力がある一方、**独占は単調**なので対の計測条項を置く: 100季auto-simで**年間MVPに占める統一王者の比率を計測し、9割を超えるようなら防衛20→16へ落として再計測**。AI選手も同じ式でレースに乗る(AI間防衛戦も§2のイベントを積むため自動で対称)。

## 2. 選手個人の記録(careerRecord)

- 現状: 戴冠(`type:'unifiedTitle', result:'won'`)のみ記録済み(P1)。**防衛と奪取が個人記録に残っていない**
- 追加: 防衛成功時に `result:'defense'`、防衛戦での奪取時に `result:'captured'` を積む(天頂戦経由の戴冠は従来どおり`'won'`)。calcHofPoints と buildCareerHighlights(実績リスト)は**同じ経路で対に**追加(片方だけ直すとズレる、の教訓コメントに従う)
- 実績リスト文言(殿堂・選手詳細): 「全国統一王座 戴冠(第N代)」「全国統一王座 防衛N度」「全国統一王座 奪取」
- シーズン総括のチップ(`_collectFactChips`)に 🌐 を追加: 「🌐 統一王座防衛N回」「🌐 統一王座奪取」「🌐 現統一王者」
- 既存セーブは遡及しない(発生時点から記録。過去の防衛は`G.unifiedTitle.history`に残っており記録タブ側で読める)

## 3. 年間表彰(構成裁定②)

- **非天頂戦年のみ**、「今年の大会」部に**「全国統一王者」スライドを1枚**追加: 年末時点の保持者(自団体/AI問わず)+在位年数+今年の防衛数。金枠ではなく**オーロラ帯**(P3のトークン)
- 天頂戦年は追加しない(天頂戦優勝スライドが戴冠を兼ねる。同じ顔が2枚続く問題の再発防止=新人王統合と同じ理屈)
- 空位の年はスライド自体を出さない(不在データを説明しない原則)
- 実績ポイント(表彰式の団体スコア)への加点はしない(天頂戦優勝20ptが既にあるため)

## 4. 記録タブ(構成裁定③)

📜記録タブに**「全国統一王座」セクション**を追加:

- 歴代王者リスト(`G.unifiedTitle.history`から生成): 第N代・名前・団体・在位期間・防衛数・終わり方(返還/陥落/返上)

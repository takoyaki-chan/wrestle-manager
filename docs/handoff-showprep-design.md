# 引き継ぎ: 興行準備画面デザイン改修

## 状況

集客v2の本接続が完了し、興行準備画面のレイアウトを暫定的に改修した。
機能は動いているが**デザインが未完成**。モックアップを作って詰める段階。

## 現在のモックアップ

`docs/showprep-mockup.html` — ブラウザで直接開ける静的HTML。
ゲーム本体と同じカラーパレット・フォントを使用。

### モックアップの構成（上から下へ）

1. **集客予測パネル** `.attendance-forecast`
   - 横一行: メインテキスト（「なかなかの手応えだ」等6段階）+ Heat/タイトル/王者/勢い等のタグ
2. **ファンの声** `.fan-voice`
   - 反映中のカードは緑チェック
3. **マッチカードヘッダー**
   - タイトル + 自動編成/全クリアボタン + 会場情報（右端小さく）
4. **マッチカード** `.match-card` × N枠
   - grid 3列: 左選手 | 中央(試合番号+VS+タグ) | 右選手
   - メインイベント: 顔72px、MAIN EVENT金文字、VS大、金ボーダー
   - 中盤（第3-5試合）: 顔56px、グレー文字
   - 前座（第1-2試合）: 顔40px、薄い文字、opacity 0.85
   - 空スロット: 破線ボーダー、opacity 0.4
5. **開催ボタン行** `.action-row`

## デザインの課題（未解決）

1. **全体的に「ダサい」** — ユーザーのフィードバック。プロレス興行の対戦カードらしい演出が足りない
2. **カードの顔写真がプレースホルダー** — 実際のゲームではportraitImg()で表示。モックアップでは色付きdiv
3. **選手ドロップダウンの見た目** — 素のselect要素。プルダウン自体のデザイン改善は難しい（ブラウザ制約）
4. **情報密度のバランス** — タグが多いとき中央が溢れる可能性
5. **ホバー時のツールチップ** — カード評価ツールチップ（集客力内訳）は実装済みだがモックアップには未反映

## ゲーム本体の現状（実装済み）

## 1. ゲーム概要

- **ジャンル**: 女子プロレス団体経営シミュレーション（ブラウザHTML+JS）
- **目標**: 弱小団体からS級団体へ成長させる。経営サバイバル達成が初期目標、年間ランキング1位がクリア条件。
- **シーズン制**: 48週 × Nシーズン（クリア後も継続可能）
- **UI**: シングルページ（iframe観戦を除く）。フレームワーク不使用。
- **データ**: キャラ98名、コーチ35名、技160種
- **難易度**: 通常モード（補助金あり）/ 上級モード（補助金なし）

## 3. ゲームループ（週次フロー）

### 3.1 シーズン構造
- **通常シーズン**: 48週（第1〜48週）
  - 春: Week 1〜12 / 夏: Week 13〜24 / 秋: Week 25〜36 / 冬: Week 37〜48
- **興行週**: 偶数週（Week 2,4,6,…48）= 24回/シーズン
  - Week 48 = PPV（年間最大興行）
  - 特別興行: 月末（Week 12/24/36）
  - タイトルマッチ: クォーター末（Week 12/24/36/48）のみ
- **オフシーズン**: Week 49〜52相当（offWeek 1〜4）
  - offWeek 1: シーズン末処理・引退・年末表彰式
  - offWeek 2: スカウト
  - offWeek 3: ドラフト
  - offWeek 4: 移籍ウィンドウ → 新シーズン開始

### 3.2 週次フェーズ（weekPhase）
```
null/manage → [processWeek] → settled (月末のみ停止) → [advanceWeek] → manage (次週)
                                 ↑ 非月末週は自動スキップ（_tryAutoAdvance）
```

| weekPhase | 説明 |
|-----------|------|
| `manage` | スケジュール設定・興行準備週 |
| `settled` | 月次レポート表示（week%4===0のみ） |
| `draft` | 初期ドラフト（ゲーム開始時のみ） |
| `transfer` | 移籍ウィンドウ（オフシーズン） |
| `event` | 対抗戦/頂上決戦 |
| `scoutEvent` | スカウトイベント |

### 3.3 月次自動スキップ
非月末週（week%4≠0）は processWeek 後に自動的に advanceWeek を実行し、manage画面に戻る。月末週のみ settled フェーズで停止し、月次レポートを表示する。

### 4.4 会場・集客システム

#### 会場テーブル（10段・全会場選択可能）
| # | 名称 | キャパ | 会場費（万） | 最大試合数 |
|:-:|------|------:|----------:|:---------:|
| 0 | 公民館 | 150 | 5 | 3 |
| 1 | 小ホールA | 300 | 25 | 3 |
| 2 | 小ホールB | 500 | 50 | 3 |
| 3 | 市民会館 | 800 | 100 | 4 |
| 4 | 中ホールA | 1,200 | 200 | 4 |
| 5 | 中ホールB | 2,000 | 400 | 5 |
| 6 | 大ホール | 3,500 | 800 | 5 |
| 7 | アリーナ | 6,000 | 1,600 | 6 |
| 8 | 大会場 | 12,000 | 3,200 | 7 |
| 9 | ドーム | 30,000 | 9,000 | 8 |

#### 集客計算
```
集客数 = (base + cardBonus) × multBonus × fluctuation
```

1. **基礎集客（`calcBaseAttendance`）**: orgPop → `BASE_ATTENDANCE_CURVE`（21点区間線形補間）で基礎人数を算出。キャパ非依存。
   - 例: orgPop 0→20人, 20→300人, 50→1,500人, 80→7,000人, 100→30,000人
2. **カードボーナス**: メイン・サブカードの人気合算 × 1.2（`CARD_POP_CONFIG.CARD_MULT`）
3. **乗算ボーナス**: 満員率ボーナス / タイトル / チャンプ出場 / 華特性
4. **週次揺らぎ**: ±17%（`WEEKLY_FLUCTUATION`）。seed固定で同一週内は同一値
5. **勢い補正（momentum）**: 直近の満員率実績に基づく累積補正（±15%キャップ）
6. **キャパ制限**: 最終集客は会場キャパが上限

#### 勢い補正（`attendanceMomentum`）
| 満員率 | 勢い変動/週 |
|:------:|:---------:|
| 95%+ | +0.04 |
| 80%+ | +0.02 |
| 60〜80% | ±0 |
| 30〜60% | −0.03 |
| 30%未満 | −0.05（＋orgPop −0.5） |

#### 集客予測（UI）
プレビューとして3段階テキスト表示（「盛り上がりそうだ」/「まずまず」/「少し心配」）。正確な集客数は非表示。

#### 会場規模MQボーナス（`VENUE_SCALE_MQ`）
公民館/小A: +0 / 小B〜中B: +1 / 大ホール〜大会場: +2 / ドーム: +3

#### 満員率MQボーナス（`CROWD_HEAT_MQ`）
| 満員率 | MQ効果 |
|:------:|:-----:|
| 95%+ | +3 |
| 80%+ | +2 |
| 60%+ | +1 |
| 40%+ | ±0 |
| 25%+ | −1 |
| 25%未満 | −3 |

### 4.5 Heat（注目度）
- Cold / Cool / Warm / Hot / On Fire の5段階
- 興行での高MQ → Heat上昇。興行なし・低MQ → Heat低下
- 興行週に軽減衰 -0.3

## 6. 育成システム

### 6.1 trainCap
```
trainCap = factor × Potential   (factor: 0.50〜0.80)
```
選手は trainCap に向かって成長する。trainCap を超えたステータスは成長しない。

### 6.2 週間成長（練習）
```
成長量 = calcGrowth(stat) × 0.4 × penMult × coachMult × weeklyVariance
```
- penMult: growthPenalty.multiplier（通常1.0, 軽傷0.7, 中傷0.4, 重傷0.15）
- coachMult: コーチ指導力倍率（§16参照）
- weeklyVariance: 通常 0.5〜1.5（努力家: 0.75〜1.5）
- `intensive` 設定時は成長ボーナスあり（体調消耗増）

### 6.3 試合成長
```
matchGrowthBase = 1.5 + opponentBonus + closeBonus(MQ≥65) + resultBonus
```
1〜2統計に分散。growthPenaltyが適用される。

### 6.4 growthPenalty
| 怪我重症度 | 残り週数 | 成長倍率 |
|:--------:|:-------:|:-------:|
| 軽傷 | 6週 | ×0.7 |
| 中傷 | 14週 | ×0.4 |
| 重傷 | 24週 | ×0.15 |
上書き: より重い方が優先。怪我回復後も残週数カウントダウン継続。

### 6.5 成長イベント
| イベント | 効果 | 発生条件 |
|---------|------|---------|
| ブレークスルー | OVR+1〜3 即時付与 | ランダム発生（低確率） |
| 絶好調（hotStreak） | 成長×1.5 | ランダム発生 |
| スランプ | 成長×0.5 | ランダム発生・長期不振後など |
| モチベ喪失 | 成長×0.3、24週超で自主引退 | スランプ長期継続など |

## 7. バトルエンジン・MQ

### 7.1 MQスコア構造（減点制）
```
MQ = 天井(avgOV) − ドラマ減点 − ペース減点 − 決着減点 + 特性ボーナス
```

#### 天井（OVシーリング）
両選手の平均OVRが試合MQの上限を決める。
```
avgOV ≤ 50: ceiling = 20 + avgOV × 0.60
avgOV ≤ 80: ceiling = 50 + (avgOV - 50) × 1.10
avgOV > 80: ceiling = 83 + (avgOV - 80) × 0.85
ceiling = clamp(round(ceiling), 15, 100)
```

| avgOV | 天井 | 外部+15込み最高 |
|:-----:|:----:|:--------------:|
| 30 | 38 | 53 |
| 40 | 44 | 59 |
| 50 | 50 | 65 |
| 60 | 61 | 76 |
| 70 | 72 | 87 |
| 80 | 83 | 98 |
| 90 | 92 | 100 |

#### ドラマ減点（0〜30）
見せ場不足がペナルティ。イベント発生で減点を打ち消す。
```
dramaPenalty = 30
  − min(kickouts, 2) × 8      // キックアウト: 最大-16
  − min(counters, 3) × 2.5    // カウンター: 最大-7.5
  − min(leadChanges, 3) × 1.5 // リード逆転: 最大-4.5
  − min(bigMoves, 6) × 0.4    // 大技: 最大-2.4
dramaPenalty = max(0, round(dramaPenalty))
```

#### ペーシング減点
| ターン数 | 減点 |
|:-------:|:----:|
| 7〜14 | 0（理想帯） |
| 5〜6, 15〜16 | −3 |
| 5未満（瞬殺） | −12 |
| 17+（長すぎ） | −6 |

#### 決着減点
| 決着タイプ | 減点 |
|-----------|:----:|
| フォール/ギブアップ（Climaxフェーズ） | 0 |
| フォール/ギブアップ（Endフェーズ） | −1 |
| フォール/ギブアップ（その他） | −3 |
| ピン | 0 |
| 丸め込み | −1 |
| TKO | −2 |
| 時間切れ | −10 |

#### 特性ボーナス（天井超過可能）
- 名勝負製造機: +5
- 引き出し上手: +min(8, OVR差×0.3)（OVR差>15時）

### 7.2 MQ外部ボーナスキャップ（Pass2）
- 外部ボーナス合計 **+15 上限**（`MQ_EXTERNAL_CAP = 15`）
- 因縁ボーナス: +3/+4/+6（因縁/宿敵/宿命の相手）、好敵手: +2
- タイトルマッチ: +10（世界王座）
- コーチ（引き出し上手特性）: +2
- 超満員: +3 / 大入り: +2 / 盛況: +1
- 会場規模: 0〜+3（VENUE_SCALE_MQ）
- ファン期待度一致: +5
- 野心トレイト: +2（タイトルマッチ挑戦者時）
- カード鮮度: +2（初顔合わせ）/ −3〜−8（マンネリ）
- ラストマッチ: +3（ラストラン）/ +5（メイン配置）
- 見返しモード: +2（引退勧告拒否後）
- マイルストーンバフ: 可変

### 7.3 タイトルマッチ格差ペナルティ（Pass2キャップ後に別途減算）
| OVR差（チャンプ − 挑戦者） | MQ減算 |
|:------------------------:|:------:|
| >10 | −3 |
| >20 | −6 |

### 7.4 コンディション補正（MQ）
| コンディション | MQ補正 |
|:------------:|:------:|
| 80〜100 | なし |
| 60〜79 | なし |
| 40〜59 | −10 |
| 20〜39 | −20 |
| 0〜19 | −30 |

## 9. 衰退・引退システム

### 9.1 wear蓄積
- **開始年齢**: 28 + durability 歳（durability: 正規分布 μ=0, σ=2）
- **蓄積量/シーズン**: 基本5 + 超過年数×2 + seasonInjuries×2
- **wear帯と効果**:
  | wear | 状態 | 効果 |
  |:---:|:----:|------|
  | 0〜19 | 正常 | なし |
  | 20〜39 | 衰え | 成長量×0.9程度 |
  | 40〜59 | 衰退期 | 成長減少+引退確率20%/シーズン |
  | 60〜79 | 末期 | 引退確率50%/シーズン |
  | 80+ | 確定 | 必然引退 |

### 9.2 引退ルート
| ルート | 説明 |
|-------|------|
| wear引退 | wear超過による通常引退（シーズン末） |
| 怪我引退（career-ending） | 重傷時追加判定（基本2〜3%、wear40+は5〜8%） |
| 怪我引退（wear超過型） | 重傷発生時にwear+怪我ボーナスが80超で即引退 |
| モチベ喪失引退 | motivationLoss継続24週超で自主引退 |
| 引退勧告（lastRun） | プレイヤーが勧告→受諾→ラストマッチ→引退（§25参照） |
| 手動解雇 | プレイヤーによる解雇 |

### 9.3 引き留め
- wear 40〜79のシーズン末確率引退に対してのみ「引き留め」が可能
- ペナルティ: wear+10、怪我確率+5%
- 同一選手2回まで（3回目以降は引き留め不可）

### 9.4 careerHistory（経歴記録）
- 中傷・重傷・引退時に `careerHistory` に記録
- 選手詳細TABに表示

## 11. PPVシステム（Week 44〜48）

### 11.1 スケジュール
```
Week 44: エントリー締切（プレイヤーが出場選手選択）
Week 44-47: エントリー期間（怪我→不戦敗）
Week 48: PPV当日（通常興行と同じ効果）
```

### 11.2 出場枠数（ランク別）
| ランク | 枠数 |
|:-----:|:---:|
| S級（1位） | 5 |
| A級（2位） | 4 |
| B級（3位） | 3 |
| 4位 | 2 |

### 11.3 マッチメイク
1. 因縁（rivalries）成立組を最優先
2. 盛り上がりスコア = OVR合計 + 人気合計×0.5 − OVR差×2
3. 同一団体対戦禁止

## 12. 年末表彰式（オフWeek 1）

### 12.1 フロー
引退演出完了 → 表彰式 → 新シーズン（シーズン開幕ファンファーレ）

### 12.2 各賞
| 賞 | 選出基準 |
|---|---------|
| 新人王 | 全団体 careerSeasons===1 からOVR最高 |
| ベストマッチ | 各団体1試合ずつ計4試合からMQ最高 |
| MVP | 各団体エース1名ずつ計4名からMVPスコア最高（±15乱数） |
| チャンピオン | 現王者（プレイヤー:実データ、AI:エース代理） |
| 殿堂入り | 引退者から totalTitleWins+totalDefenses≥13 |

### 12.3 殿堂入り後の処理
- 対象者: `retiredFighters` → `hallOfFame` へ移動

## 14. ランキングシステム

### 14.1 orgRatingの計算
```
rating = 基礎力スコア + 対戦ポイント
```

**基礎力スコア = TOP5平均OVR × 1.5 + TOP5平均pop × 1.0**
- TOP5: ロスター内のOVR上位5名 / pop上位5名（別々に計算）
- 少数精鋭でも大所帯でも同じ土俵で評価される

**対戦ポイント（`battlePoints`）**: シーズン中の団体間直接対決の損益合計。シーズン開始時に全団体0リセット。
- 対抗戦: 勝利で+12pt奪取
- サミットマッチ: 勝利で+10pt奪取
- 統一トーナメント: 優勝+20pt / 準優勝+8pt / ベスト4±0pt / 1回戦敗退−14pt

### 14.2 ランクティア
| ランク | 条件 | 出来ること |
|:-----:|------|---------|
| S級 | 1位 | 頂上決戦・5枠PPV |
| A級 | 2位 | 4枠PPV |
| B級 | 3位 | 3枠PPV |
| 4位 | 4位 | 2枠PPV |

## 17. 因縁・決着・カード鮮度

### 17.1 因縁段階
| 段階 | 必要matches | MQボーナス | 決着 |
|------|:----------:|:--------:|------|
| 因縁 | 2 | +3 | 不可 |
| 宿敵 | 4 | +4 | 1回目可 |
| 宿命の相手 | 7 | +6 | 2回目可 |
| 好敵手 | 決着2回完了 | +2 | なし（永続） |

### 17.2 決着条件
- 宿敵以上（matches≥4）の状態で試合を組み、MQ ≥ 動的閾値
- 動的閾値 = min(50, max(30, round(ceiling × 0.80)))（天井はavgOVから算出）
- 2回目の決着は宿命の相手（matches≥7）が必要
- 同一ペア最大2回の決着。以降は好敵手に永続移行

### 17.3 決着報酬
| | 宿敵決着（1回目） | 宿命の相手決着（2回目） |
|---|:---:|:---:|
| 両選手popularity | +4 | +6 |
| orgPop | +1.5 | +2.5 |

### 17.4 カード鮮度

| 対戦回数 | MQ効果 | ラベル |
|:-------:|:-----:|------|
| 初対戦（過去一度も対戦なし） | +2 | 初顔合わせ |
| 1〜2回 | ±0 | — |
| 3回 | −3 | マンネリ |
| 4回 | −5 | 深刻なマンネリ |
| 5回以上 | −8 | 完全なマンネリ |

## 25. 引退勧告・引き留めシステム

### 25.1 引退勧告

#### 受諾判定
内部受諾率（50%ベース）にwear段階/実績/trust/勝率の修正を加算。最低5%〜最高95%。

#### 拒否時の影響
- trust −5
- 同シーズン再勧告不可（retireAdviceCooldown = 48）
- 70%: 見返しモード（proveMode = 4週間、MQ+2）
- 30%: ロッカールーム士気 −2

### 25.2 ラストラン
受諾した選手は `lastRun = true`。4週以内に引退試合を組む。
- ラストラン試合MQ: +3（メイン配置でさらに+5）
- 王座保持中の場合: 自動タイトルマッチ化
- 因縁相手との引退試合: 追加MQ+3（永遠のライバル:+5）

### 25.3 コーチの引退アドバイス
コーチの観察眼ランクに応じて受諾率の手がかりをテキストで提供。

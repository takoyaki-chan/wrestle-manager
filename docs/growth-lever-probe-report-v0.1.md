## 2. 実装位置と `_heat` の遷移

- ブレーキ指数: `Engine.growth.calcGrowth` の `src/management.js:7213`。
- 追い込み倍率のテーブル参照: 同関数の `src/management.js:7252`。成長計算時点の `char._heat`（未設定なら 0）を参照するため、最初の追い込みはテーブル先頭を使う。
- `_heat` の更新: `Engine.tickWeek` 内の自団体 roster 週次練習処理。
  - 追い込み: `src/management.js:11041`。追い込み成長・`seasonIntensiveWeeks` 計上の直後に `min(_heat + 1, length - 1)`。
  - 通常練習: `src/management.js:11106`。`action === 'practice'` 分岐で `max(0, _heat - 1)`。
  - 休養: `src/management.js:11145`。`action` が practice / promo 以外となる休養分岐で `max(0, _heat - 2)`。

通常/休養の判別は、既存の `action` 決定をそのまま使用した。`schedule`、`balance` の解決後、condition `<60` と `<=30` の既存安全弁で `action='rest'` になったものも休養として扱う。`promo` は通常練習でも休養でもない既存の独立分岐であり、指示された通常/休養のいずれにも含めず `_heat` を変化させない。怪我・休暇・レンタルの早期 return も同様に変化させない。

## 5. 解釈を固定した箇所

1. I2 の「2週追い込み→2週通常」は、週番号で 2週追い込み相・2週通常練習相を繰り返すものとした。追い込み相では既存の condition / 連続追い込み上限を満たさなければ休養、通常相では既存の condition `<60` 安全弁を満たせば休養とした。
2. `_heat` の通常練習は `action === 'practice'`、休養は既存の最終 `else` とした。promo、怪我、休暇、レンタルは指示に通常/休養として定義されていないため、`_heat` を更新しない。
3. AI引退年齢は、`Engine.rival.processSeasonEnd` の前後AI roster差分で採取した季末除外者の加齢後年齢である。計測用フックは状態へ書き戻さない。

# VS_EX_EMPLOYER_LINES 拡張ドラフト v0.1（[personality]×[archetype] 7×7）

解雇された選手が移籍先で「自分を切った団体」の選手と対戦したときの遺恨セリフ。第一分岐=personality（遺恨の抱え方=感情スタンス）、第二分岐=archetype（口調）。personality が「何を言うか」を、archetype が「どう言うか」を決める。
文体方針：一人称「俺」は絶対に使わない（delinquent は「あたし」）。団体名・選手名・数値は出さず「あそこ」「あの団体」「切った側」「あの日」の指示語で必ず元雇用主戦と分かるようにする。win=切った側への回答、hit=HP34%以上の被弾時「この相手にだけは倒れられない」の短文。
各セル win2本・hit2本。personality ごとの感情スタンスは現行テーブルを踏襲（bold=見返し・誇示 / earnest=証明・受けてくれた団体への義理 / quiet=短い事実 / easygoing=軽いが刺さる / shy=実感が湧かない / emotional=あの日の景色が溢れる / normal=まっすぐな証明）。

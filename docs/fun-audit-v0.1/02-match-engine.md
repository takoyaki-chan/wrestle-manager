# 監査報告: 試合エンジン・MQ・試合の体験

## 1. 要約

- **試合はほぼ一本道です。** HPを削り合い、相手がHP35%以下(大一番は25%以下)になったら「フォール狙い(ピン)」で決まる。決着の64〜82%がこの経路です。
  - 脱出・粘り・丸め込みの仕組み(因縁/王座/名勝負製造機の脱出ボーナス、闘志、王者の土壇場、番狂わせ体質)は、めったに通らない分岐(HP0判定と丸め込み専用判定)にしか繋がっていません。実測でほぼ不発です。
  - ニアフォール(カウント2で返す場面)が一度もない試合が、実プレイ相当で約7割あります。
- **奇跡は十分起きています。** 格下勝ちはOVR差10〜14で約15%、差20以上で1〜3%。しかも「劣勢からの逆転」という一番絵になる形で起きます。
  - ところが、その事実は結果画面にも勝利セリフにも新聞にも拾われていません。エンジンが検出している「超過(実力以上の名勝負)」は、どこからも読まれていません。
- **「大ダメージ」判定(dmg≥15)が全ヒットの92〜100%で成立しています。** BIG HIT演出と被弾セリフが毎ターン出て、本当の山場が埋もれています。
- **看板と中身がずれている箇所が3つあります。**
  - trust/ラストラン/メイン気迫/バフは「リング内化」と呼ばれていますが、実際はMQの天井を±1動かすだけで、試合内容は完全に同じです。
  - 予約画面は、廃止済みの「因縁 評価+N」をまだ表示しています。
  - タッグの不仲ペナルティ「能力-3」は、エンジンが読まないキーを減らしていて完全に無効です。

## 2. 発見(重要度順)

### F1. 「返し」の仕組みが決着の本線に繋がっていない — ニアフォールのない試合が7割、粘り系・番狂わせ系の特性はほぼ不発
- **種別**: [効いていない]
- **根拠(配線)**:
  - 次の効果は、すべて HP≤0 のときだけ走る判定(`match-engine.js:632-671`)に集まっています。
    - キックアウト/ロープ脱出
    - 因縁・王座戦・名勝負製造機の脱出ボーナス(642-643, 659-660)
    - 防衛王者の土壇場(640-641)
    - 闘志+0.08(237)
  - 決着の本線であるフォール狙い(692-711、成功率は `calcPinAttemptSuccess` 269-277)には、上の効果が1つも入っていません。
  - 丸め込み専用判定(712-724、番狂わせ体質+8)は else-if の後ろにあります。先にフォール狙いが成立すると、ここまで到達しません。
- **根拠(実測)**:
  - 決着に占める「ピン」は、同格で通常74%/大一番82%、実プレイ相当で64〜71%。
  - HP0での脱出は試合あたり0.01〜0.24回。
  - ニアフォール0回の試合は、OVR85で67%/72%、実プレイ相当で67〜74%。
  - 相手HPが閾値以下のときに決まった丸め込み技のうち、71%(通常)/83%(大一番)が汎用のフォール狙いに吸われています。その結果、本来の決着種別「丸め込み」は0.84%/0.28%しかなく、丸め込み技なのに「ピン」扱いの決着が5.9%/7.1%あります。
- **根拠(同一seed対照)**:
  - 番狂わせ体質(OVR差10の格下に付与): 勝率差Δ0.00〜0.07pt。20000組中、結果が変わったのは0〜14組。
  - 闘志: Δ0.0〜0.2pt、MQ+0.02。
  - 因縁tier4の脱出ボーナス+0.15: ニアフォールは0.460→0.468回/試合とほぼ不変。
- **副次の不具合**: ボーナス加算後の上限(0.45/0.40、643/660)が、soft-knee式の上限(0.60/0.52、`data.js:785-786`)より低いまま残っています。MN≥90の選手がEndフェーズでHP0判定を受けると、ボーナスを足した方が脱出率が下がります(MN100: 0.487→0.45)。現状の発生はHP0判定の0.2%です。
- **なぜ削いでいるか**: 柱③「数値は嘘をつかない」の裏返しで、仕組みは書かれているのに数字として起きていません。プロレスの山場であるカウント2.9が7割の試合で一度も来ないので、「鮮烈に見せる」ための素材がありません。
- **面白くする案**:
  - 既存の「返し」ボーナスを、フォール狙いの成否判定に合流させる。因縁/王座/名勝負は両者の返し、闘志/防衛王者は片側の返しとして効かせる。
  - 丸め込み技は、丸め込み専用判定を先に評価する。丸め込みがTE主導の独立した決着になり、番狂わせ体質も効くようになる。
  - メモリ上での試算(m8): 両者にフォール返し+10〜15ptを入れると、ニアフォールは0.45→0.65〜0.76回/試合、0回の試合は67%→53〜58%、MQは+1.3〜1.9、勝率は不変。片側だけ+8ptなら勝率+1.8〜1.9ptで、spec不変条件の±2pt以内に収まります。
  - MNの係数には触りません。balance-baseline と mq-ring-calibration で縛ります。
- **規模/確度**: M / 検証済み

### F3. 番狂わせ・逆転・「奇跡」が起きても、演出に届かない
- **種別**: [ドラマの取りこぼし]
- **根拠(番狂わせの中身)**: 実ロスター、OVR差6〜19の試合で集計。
  - 通常戦の番狂わせは、95%がClimaxでの決着。
  - 45%は、勝者がHPで20pt以上劣勢からの逆転。
  - 17%は、勝者がニアフォールを返してからの勝利。
  - 順当勝ちでは、この2つはそれぞれ10%/4%しかありません。
- **根拠(見え方)**:
  - 結果画面のタグ(`ui-common.js:5887-5898`)に、番狂わせも逆転もありません。
  - 観戦の結果画面(`battle-engine-main.js:1375-1462`)は、WINNER・決着・評価・ターン数と、1キャラ3行からのランダムな勝利セリフ(1413)だけです。

  - 敗者の余韻(`app.js:9467-9486`)は、状況を問わない共通プールです。
  - 新聞は `winnerHpPct`・`isLongBattle`・`isHighBond` を計算して渡していますが、テンプレ側で一度も使っていません(`app.js:10027-10036` → `9852-9863`)。

- **なぜ削いでいるか**: 柱①のスポットライトの瞬間(逆転した子のひと言)が、ランダムな3行に埋もれています。柱③の面では、エンジンが「奇跡」のフラグまで立てているのに誰も伝えないので、本物の奇跡が本物の感動になりません。

    - (d) 超過は年に数回級の「節目」演出にする(実プレイ相当での発火は0.2〜0.6%)。
  - 「大金星」は格下が勝ったときだけに限る。
  - 番狂わせの判定は、OVR差だけでなく試合前の期待勝率(人気を含む、F7参照)で行う。
- **規模/確度**: M / 検証済み

### F4. 「リング内化」の看板と中身がずれている — trust/ラストラン/メイン/バフは天井を±1動かすだけ、予約画面は旧「評価+N」を表示
- **種別**: [効いていない]
- **根拠(配線)**: trust・バフ・メイン気迫・ラストランの実効OV補正は、平均OV(avgOV)にしか入らず、MQの天井を動かすだけです(`match-engine.js:769`、`management.js:3216-3242`)。
- **根拠(同一seed対照)**:
  - trust<35: MQ −1.00、勝率Δ0.0。カウンター数もニアフォール数も完全に一致。
  - ラストラン/メイン気迫: MQ +1.00、勝率Δ0.0。
  - mq_boost+次戦バフ: MQ +4.00、勝率Δ0.0。
  - 実プレイ相当でも、trust<35の選手が出た試合は −1.15、メイン/ラストラン/バフのみの試合は +0.99。
  - spec MQ §4.3の「心が離れたエースの塩試合が、本人の出来として現れる」は、リングの中では起きていません。
- **根拠(表示)**:
  - 予約画面と試合前カードは、因縁を「評価+N」と表示しています(`ui-common.js:5536/5580`、`ui-render.js:3948`)。
  - このNは、廃止済みの固定加算 `getRivalryMQBonus`(0〜5、`management.js:1869-1875/1978`)のままです。
  - 実際のリング内効果は、因縁tier1〜4で +0.6〜+1.3(通常)/+0.9〜+2.1(大一番)。
  - 隣の鮮度タグはP3cでMQ表記をやめているのに、因縁だけ取り残されています。
- **なぜ削いでいるか**: 数値哲学「安易な加減算で処理しない」が、天井経由の固定加算に戻っています。社長は予約時に「+5」と信じてカードを組みますが、実際は+1です(公称と実効の乖離)。
- **面白くする案**:
  - (1) すぐできること: 「評価+N」を仕組みの言葉(例「カウンター・粘りが増える」)に置き換えるか、表示を外す。
  - (2) trustとラストラン/メイン気迫を、因縁と同じリング内の経路で効かせる。例えばtrust<35はカウンター率と命中率を下げる(集中を欠く)、ラストランはF1の返し経路で「簡単には沈まない」。いずれも勝率差±2pt以内に収め、MQの差はリング上の出来事の結果として出す。
- **規模/確度**: S(表示)/M(リング内化) / 検証済み

### F5. タッグの不仲ペア(bond≤20)の「能力-3」が完全に無効
- **種別**: [断線・死蔵]
- **根拠**:
  - `app.js:7247/7395` の `_penalize` が減らしているのは power/speed/technique/spirit です。エンジンが読む pw/sp/te/st/mn ではないので、NaNのキーが増えるだけです。
  - UIは「能力-3 / 連携不可 / 相手との関係-1」と約束しています(`ui-common.js:5487`、spec relationship v2.3 §D.1)。
  - 同一seedで、適用あり/なしの3000試合が3000/3000完全一致しました。意図どおりpw/sp/te/mnを-3すると、勝率は42.1%→33.9%に動きます。
  - さらに、「残り全試合スキップ」(`app.js:7670-7690`)とheadless経路(`management.js:14640-14654`)ではtrust-1も含めて何も適用されません。押したボタンで結果が変わります。
- **なぜ削いでいるか**: 社長に見せている警告が嘘になっています(柱③)。
- **面白くする案**: Engine側に共通ヘルパーを作って3経路を統一し、キーを直して回帰テストを付けます。有効にすると不仲ペアの勝率が約8pt動くので、有効化するか表示を撤回するかはKeisukeの裁定が必要です。
- **規模/確度**: S / 検証済み

### F7. 大一番(王座戦・PPV・ドームメイン)は「長いだけ」 — 返し合いは増えず、人気の見えない倍率が効いている

- **規模/確度**: M / 検証済み

### F8. MQ(試合評価)が「OVRの写像+ニアフォールのくじ」に見えていて、★の物差しも画面ごとにばらばら
- **種別**: [見せ方]
- **根拠(中身)**:

  - 同じOVRでの差は、ほぼニアフォールの回数で決まります(OVR85の通常戦: 0回の試合67%でMQ63.4、1回23%で71.7、2回以上11%で79.4)。

  - 結果として、MQを上げる支配戦略は「高OVR同士を組む」です(平均OVR1点あたりMQ+0.85〜1.1)。
- **根拠(見え方)**:
  - 結果画面の★は `_pbStars` = MQ/20(`ui-common.js:6019-6021`)。新聞の「観客満足度」は会場補正つきの `calcShowRating`(`management.js:1588-1633`)で、人気の成長もこちらを使います。
    - 同じ興行が、結果画面では★2、新聞では★4になります(公民館満員・平均46)。
  - 色分けの閾値も、観戦は80/60/40、試合前カードは80/70/60/50/40と別々です。
  - 観戦は DMG/PWR の数値表示が既定でONです(`battle-engine-main.js:252`)。
  - MQの内訳(何で減点されたか)はどこにも出ません。
- **なぜ削いでいるか**: 数値哲学「数字はドラマの裏で動くもの」に反して、表に出ている数字が物語を語っていません(スプレッドシート化)。しかも★が画面ごとに矛盾していて、分かりにくい方向にも振れています。
- **面白くする案**:
  - 試合結果では「評価NN」を主役から外し、F3の物語タグ(「ニアフォール2回」「逆転」「カウンター応酬」)を主役にする。
  - ★は1つの物差しに統一する。人気の成長に効く新聞側を正にするか、「試合の出来」と「客の満足」を明示的に分けて表示する。
  - 観戦の数値表示は既定OFFにする。
- **規模/確度**: S〜M / 検証済み

### F9. スタイルも育成の尖りも「勝ち方」に出ない(関節系2スタイルを除く)
- **種別**: [選択の空洞化・支配戦略]
- **根拠**:
  - OVR85で、PW/SP/TE/ST/MNのどれかを+24尖らせた型と平坦型を比べると、勝ち方はどれもピン71〜74%・ギブアップ14〜15%で同じです。
  - スタイル別でも、Grappler/Striker/Aerial/Brawler/Allround はピン83〜85%で同じ。違うのは Submission(ギブアップ68%)と Technique(47%)だけです。
  - spec battle-engine §12.1 は「PWR型=フォール/TKO、TEC型=カウンター+丸め込み、MNT型=キックアウトで粘り勝ち」と約束していますが、実現していません。
  - (スタイル同士の勝率が±1pt以内で均衡しているのは意図どおりで、問題ではありません。)
- **なぜ削いでいるか**: 社長の育成方針が、勝率以外にリング上の個性として見えません(柱①②)。
- **面白くする案**:
  - 大半はF1で解消します(丸め込み判定の先行評価でTE型、返しの合流でMN型)。
  - PW型は、TKO判定(基礎14%、連続3ヒット+HP15%未満)をPW差に連動させる。
  - 勝率はベースラインのまま据え置き、「尖り×決着」の分布を新しい回帰指標にします。
- **規模/確度**: M / 検証済み

### F10. プレイヤー画面のB2団体内紛/B3挑戦状が、因縁のリング内効果を通っていない
- **種別**: [断線・死蔵]
- **根拠**:
  - B3(`app.js:14339-14340/14392-14393`)とB2(`14561-14563/14614`)は `buildRingInOpts` を呼んでいません。
  - spec MQ §2.3/§2.4 はこの画面経路も「因縁のみ(rivalryOnly)を通す」と定めていて、headless側(`management.js:10459/12244`)は呼んでいます。
  - `test/ringin-coverage-test.js` は management/match-engine/relationships しか読み込まないため、app.js の経路を検知できません。
  - 天頂戦/PPVで一度起きた「呼び忘れても症状が出ない」型と同じです。
- **面白くする案**: 因縁のみのオプションを合成して渡す。UI経路の試合シミュレーションはEngine側のヘルパーに寄せ、カバレッジテストの対象に入れる。
- **規模/確度**: S / コード読解

### F11. 同じ2人が何度戦っても試合は毎回リセット — 対戦履歴(手の内)が試合に入っていない
- **種別**: [新しい面白さの芽]
- **根拠**:
  - `simulateMatch` は対戦履歴(h2h)を受け取りません。履歴を使うのは、因縁値(カウンター/脱出ボーナス)と観戦画面の戦績バッジ(`battle-engine-main.js:361-373`)だけです。
  - 同一カードを100戦させると、決め技は51〜61種に散らばり、連続2試合の技構成の重なり(Jaccard係数)は0.05〜0.10。
  - 試合前フレーバーは「初対決」だけ(`app.js:9444-9460`)で、「N度目の対戦」「リベンジ」「連敗ストップ」を検出する仕組みはどこにもありません。
  - (固有必殺技は既知の未実装なので、ここでは除外しています。)
- **なぜ削いでいるか**: 因縁は数値としては育ちますが、試合の中身は進化しません。柱①の「シリーズを追う楽しみ」がありません。
- **面白くする案**:
  - 小さくても実在する「手の内」の仕組みを入れる。ペアごとに前回の決定打を記録し、次の対戦ではその技に対して前回の敗者のカウンター率を上げる(読んでいた)。
  - 勝った側は別の勝ち筋を探すことになり、観戦と新聞で「前回の決め技を切り返した」と見せられます。勝率への純効果は±2pt以内に抑えます。
  - 試合前に「3度目の対戦・前回○○」、試合後に「雪辱/連敗ストップ」のタグを出す。
- **規模/確度**: M / 推定(設計案)+計測(反復性)

### F12. 時間切れは常に「判定勝ち」 — 時間切れ引き分けという物語が使われていない
- **種別**: [新しい面白さの芽]
- **根拠**:
  - 時間切れのときは、常に残りHPで勝者を決めています(`match-engine.js:53-61/743-747`、コミット6322d0c3)。発生は通常戦で1.5〜2.4%、番狂わせのうち4.6%が判定勝ちです。
  - 新聞の引き分け記事(`app.js:9787-9790/9837-9840`)と観戦の「NO CONTEST」表示(`battle-engine-main.js:1402-1409`)は、使われないまま残っています。
- **面白くする案**: 拮抗した因縁戦/王座戦に限って、時間切れ引き分けを「再戦のきっかけ」として復活させる。王座は防衛扱いにするロジックが既にあります(`app.js:7828-7830`)。8/2の裁定(同HPのときの引き分けを廃止)との整合はKeisukeの判断です。
- **規模/確度**: S〜M / コード読解

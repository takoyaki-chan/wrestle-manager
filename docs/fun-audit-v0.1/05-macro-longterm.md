# 監査報告: 経済・団体の成長・AI団体・年間カレンダー・長期目標

## 1. 要約

- **序盤は階段が細かいが、7年目あたりで止まる。** 経営安定化はW8、団体王座の設立はS1のW23〜27、S2で契約枠10とPPV出場権、S5〜6で枠12。ところがS7〜9に3位へ上がった後は、構造的に届く次の段がない。無作為プレイの2シード計70季では、順位3〜4位・団体人気55〜85の往復が数十年続いた。1位との評価差は約200ptのまま縮まらない。
- **AI団体の序列が70季ずっと固まっている。** S団体の年間1位は70/70、S>A>Bの入れ替わりは0回、主要タイトルの8割以上をSが取る。選手の地力差はS−Aで中央値24ptしかない。これを評価差160ptまで広げているのが「今の王者ほど得をする仕組み」の重ね掛けで、実績ptが2年満額・大会枠が順位比例・人材は下から上にしか流れない・Sだけの補強安全網、の4つ。
- **緊張を生むはずの仕組みが働いていない。**
  - 資金危機は0週(補助金なしでも0週)。サバイバルはW8で自動的に卒業する。
  - AI団体の人気には年次減衰がなく、SとAは100に張り付く。
  - Bは0まで崩れた後、`|| 50` のせいで次の週に約50へ戻る(不具合、確認済み)。
- **会場の★補正(小会場は−18)で、「500席の箱で★5を量産」が人気を上げる最善手になっている。** 会場を固定する実験で団体人気が+19。一方UIは人気90で「ドーム圏内です」と挑戦を促すが、人気90ではどう組んでも満員にならない。

## 2. 発見(重要度順)

### ① 業界の序列が固まっている:S団体の年間1位70/70、AI間の順位入れ替わり0回
- **種別**: [ペーシング・長期] [ドラマの取りこぼし]
- **根拠(実測)**:2シード(42は40季、7919は30季)、UI進行のエミュレーションとケアあり。
  - タイトル獲得は表Cのとおりほぼ全部S。PPV頂上決戦は50年中49年が「S対A」。自団体の対抗戦の相手はB42回・A23回で、S戦は0回。
  - **中身の分解(表F)**:S−Aの評価差は中央値156〜173pt。そのうち選手の地力(基礎力)差は中央値23〜24pt、最小4ptしかない。残りは次の2つ。
    - レガシー:Sは初年度から上限の50(management.js:9056)。
    - 実績pt:Sの評価の約27%、110〜140pt。
  - **今の王者を得させている仕組み**:
    - 実績ptが2年間満額のまま残る(data.js:8438、management.js:9291-9300)
    - 大会枠が団体順位に比例:PPV・天頂戦は5/4/3/2(management.js:28470、data.js:27162)、春タッグは3/2/2/1(29149)、頂上決戦は1位と2位のエース同士(16918-16946)
    - AI間の引き抜きは下位→上位だけ(12504-12506)。FAはS優先(12575)。claimDepartedStarでSに+12(12725)。有望株の上限はS無制限・A3・B1(data.js:8797)
    - EMPRESS安全網:Sの精鋭(育成上限OVR110以上)が6人を切ると、休眠プールから最高素材を年2人まで直接補充する(draft-negotiation.js:166-172, 732-786)
    - 1位の団体は引き抜きを受けない(data.js:8971、management.js:15752-15760)
  - 選手個人の単位では動いている。各団体の王者は季末時点で1.5季に1回替わり、統一王座は34季で16人が持った。
- **なぜ面白さを削ぐか**:「シミュレーションが事実を生む」はずが、団体単位の結末は開始時のtierで決まっている。年末の表彰・頂上決戦・一面が毎年ほぼ同じ団体になり、「スポットライトは自然に巡る」に反する。自団体が1位を取った後は、同じ仕組みが今度は自団体を1位に固定すると推定され、終盤の勝ちすぎにつながる。
- **案(補正を足すのではなく、世界の仕組みとして)**:
  - (a) 実績ptの満額期間をその季だけにする(graceAgeを0に)。地力差20〜60ptの範囲で順位が揺れる余地が生まれる。
  - (b) 大会枠を団体順位ではなく個人の実績で配る(PPVはMVPレース上位、春タッグはペアの戦績)。下位団体の星が頂上決戦に届く道ができる。
  - (c) Sの層の厚さを「悩み」にする。Sは16人中8〜12人がOVR90超なので、出番の少ない控えが出場機会を求めて移籍を申し出る(信頼度と出場数で発火)。上向きの人材の流れと対になる下向きの流れで、プレイヤーには補強の好機にもなる。
  - (d) AI団体に財務(人気に応じた収入と総年俸)を持たせる。スター世代が一斉に老いたときに「王国の黄昏」が自然に起きる。EMPRESS安全網はその財務の範囲内でだけ動かす。
- **規模 / 確度**:M〜L / 計測とコードで確認済み

### ② 小会場の★補正−18のせいで、団体人気は「小ホールで★5量産」が最善手になる。人気90での「ドーム圏内」の誘いも実数と合わない
- **種別**: [選択の空洞化・支配戦略] [見せ方(公称と実効)]
- **根拠**:
  - ★の閾値は会場で変わる(venueTierOffset、data.js:3985)。一方、団体人気の増減は★だけで決まり、動員数や会場の規模は入っていない(data.js:3991、management.js:15697-15719)。
  - **実験(seed42・30季、会場だけ500席に固定)**:団体人気の平均はS11-20で78.6(通常の会場の上げ方では72.2)、S21-30で83.8(同64.9)。★5はS11-20で185/200回(通常は39/200)。順位は変わらず、資金はS30で9.1億(通常65.7億)。つまり代償はお金だけで、そのお金はもともと余っている(表D)。
  - **ドーム**:人気90になるとUIが「🏟️ ドーム圏内です！今シーズンの挑戦を検討してください」と出す(ui-render.js:4498-4504)。エンジンの計算式で8試合の満枠を組んだ前提で計算すると、人気90での入りは38〜56%。熱狂状態に最強カードを重ねても73%で、会場の熱は「閑古鳥」(観客熱−7)、収支は−1,400〜−4,500万。満員になるのは人気95〜100で最強カードと高Heatが揃ったときだけ(表E)。
  - ドームの壁そのものは既知(orgpop-rebalance DRAFT)。新しく分かったのは、★補正の抜け道と、人気90での誘いが実数と合わない点。
- **なぜ面白さを削ぐか**:数値哲学に反する。150人の公民館を沸かせても6000人のアリーナを沸かせても人気の伸びは同じで、むしろ小会場のほうが上。社長の「場づくり」の選択が、人気の面では小さい箱一択につぶれる。
- **案**:
  - (a) 人気の変化量に「届いた観客の量」を掛ける(例:動員÷reachを0.3〜1.2に丸めた値)。★は会場ごとの出来の評価として残す。
  - (b) 小会場の札止め(fp≥2.25、既存ラベル「客席が沸き返る超満員」)を、「チケットが取れなかったファンの声」「次はもっと大きな箱で」という記事やファンの期待に変え、上の会場へ誘う力にする。
  - (c) ドーム圏の案内は、既存の getAttendancePrediction で満員見込みが立つときだけ出す。
- **規模 / 確度**:S〜M / 検証済み(会場固定の実験とエンジン式プローブ)

### ③ AI団体の人気:年次減衰がなくS/Aは100に張り付き、Bは0へ崩れて `|| 50` で50へ戻る
- **種別**: [断線・死蔵] [効いていない] [ドラマの取りこぼし]
- **根拠**:

  - Bは35→0.5(seed42のS5〜8)、29→2(seed7919のS12)と崩れ、翌季に46.5・50へ跳ね戻った。
    - 原因は `(orgPop || 50)` という書き方で、人気0が「値なし」と扱われる。計13箇所:11370-71, 11434, 11472, 11496, 12008, 12024, 12035, 12039, 12226, 12273, 12289, 12302, 12312。
    - プローブで確認:人気0から1興行週で49.5になる。0.5→0、1→0.5は正常。
  - **プレイヤーに見える場所**:ランキング画面の各団体カード(ui-render.js:5141)と、団体比較の「集客力」(26063-26078)。
  - **仕組みに効いている場所**:
    - 引き抜き交渉は自団体の人気が相手より上だと成功率+10(16035-16036)。S/Aには永久に付かない。
    - AI対抗戦は人気20超(11906)、挑戦状は18超(12129)が条件なので、崩れている間のBは世界の出来事から消える。
    - BはS/Aに毎年2番手を引き抜かれ、所属が3〜5人まで痩せる年がある(seed7919のS27〜30:5,3,4,3人)。
- **なぜ面白さを削ぐか**:0から50へのワープは数値が嘘をついている。Bの経営危機・存続の危機は「辛さを避けない」ドラマの素材なのに、何も起きずに巻き戻る。
- **案**:
  - (a) `|| 50` を `?? 50` に直す(S)。
  - (b) AIにもプレイヤーと同じ人気モデル(年次減衰・低人気の保護)を当てる。
  - (c) 人気20割れや所属5人割れを「経営危機」として記事にし、有力選手をFA市場に放出させる(プレイヤーの補強機会になる)。
- **規模 / 確度**:S(不具合)・M(対称化と物語化) / 検証済み

### ④ お金が緊張を生まない:危機0週(補助金なしでも)、サバイバルはW8で自動卒業、大会賞金は世界設定と逆に団体へ入る
- **種別**: [ペーシング・長期]
- **根拠**:
  - 2シード70季で資金の最低額はほぼ開始額、危機に入った週は0。補助金なしモードでも3シード×6季で赤字の週は0で、S5には1.1〜1.35億(表G)。
  - 週次収支は、補助金ありなら第1週から毎週黒字。なしでも4週の合計はプラスになり、サバイバルの卒業条件(app.js:1907)をどちらのモードでもW8で満たす。
  - 年2〜3億の黒字そのものは既知(facility spec)。新しく分かったのは、そのおよそ3〜5割が特別大会の分配金と賞金(年6,800〜14,500万)だという点。
  - 大会賞金の入り先:PPVの賞金はコードのコメントに「国庫支出」とあるのに団体資金へ入り(17421-17449)、JTも同じ(28255-28262)。世界設定は「賞金は国庫から選手個人へ、団体財政に影響しない」なので食い違っている。
  - この結果、破産再設計・危機演出・「赤字地獄」表示は、通常のプレイでは起動しない。
- **なぜ面白さを削ぐか**:緊張の源が一つ死んでいて、社長の決断にお金の重さが乗らない。
- **案**:
  - (a) 賞金は世界設定どおり選手個人へ。懐の温まった選手は更改交渉で強気になる、他団体からの誘いが増える、など人物側の話に落とす。
  - (b) 支出を野心に連動させる。大きな会場ほど制作費がかさむ、スターの年俸がS/Aの提示額に引っ張られて上がる、など。
  - (c) 補助金を「申請してから数週遅れで交付」にして、序盤の数週を本当に際どくする。
- **規模 / 確度**:M / 計測とコードで確認

### ⑥ 人気が高い帯では、興行より一発の固定加減算(対抗戦±、秋の大会−2)で季の行方が決まる
- **種別**: [効いていない](数値哲学)
- **根拠**:
  - 興行による人気変化は、70〜85帯では逓減(×0.22)のあと★4で+0.22、1季でおよそ+5。
  - 一方で、逓減なしの固定値がある:対抗戦は勝ち+5・負け−3(17823-17855)、秋の4団体戦は優勝+4・準優勝+1・それ以外−2(30609-30625)。年次減衰は−3。
  - 秋の大会はSが58/70で取るので、自団体の優勝は70季で2回。準優勝以外は参加しただけで−2になる。
  - 季の人気の行方が数週の一発イベントで決まることが、既知の不満「上下の理由が分からない」の一因と考えられる。
- **案**:固定加算も逓減(applyOrgPopChange)を通すように揃える。または、負けても試合の中身(MQ・健闘)がよければ上がる形で出す。秋の−2は廃止するか、完敗のときだけにする。
- **規模 / 確度**:S / コードと計算

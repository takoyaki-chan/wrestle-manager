# task-73 特別興行の終わりにコーチの総括を一言

起票 2026-08-01。Keisuke 依頼:
> 各特別興行後の完了後、（画面を）変える直前にコーチから一言あるとよい。
> 「なになにで、なになにで、良い大会でした」とか「惜しかった」とか「残念だった」とか。
> 大会での各選手の結果に応じたセリフにしたい。
> **全員を網羅していなくてよい。網羅しないほうが良い。**

> **分担: セリフ本体は Opus。このタスクは「分岐設計 + 配線」で Terra / Luna 向け。**

  （`_showJTImpressionChain`。champion / postWin / postLose の3timing で**選手**が話す）
- 天頂戦・春のタッグリーグ・秋の4団体勝ち残り・PPV には**何も無い**。
  結果画面から経営画面へ戻るだけ

## やること

大会結果画面を閉じて**経営画面へ戻る直前**に、コーチ1人の総括を1枚出す。
対象は **5大会すべて**: ジュニアトーナメント / 春のタッグリーグ /
秋の4団体勝ち残り対抗戦 / PPV GRAND FINAL / 天頂戦。

### 話す内容の組み立て

「大会全体の手応え」＋「**自団体の選手1〜2名**の結果への言及」。

**網羅しないことが仕様**。出場した自団体選手が5人いても、触れるのは1〜2人。
選ぶ基準は「その大会でいちばん物語が動いた選手」:

| 優先 | 条件 |
|---|---|
| 1 | 優勝した |
| 2 | 決勝・準決勝まで行った |
| 3 | 格上を食った（OVR差 -8 以上の相手に勝った） |
| 4 | 初戦敗退だが接戦（MQ が高い / 僅差） |
| 5 | 該当なし → 誰にも触れず大会全体だけ語る |

**同じ大会で毎回同じ選手が選ばれないこと**。上の優先度が同点なら、
直近で触れられていない選手を優先する（スポットライトは巡るもの）。

### 語調の分岐

| 軸 | 段 |
|---|---|
| コーチ voice | 8系統 |
| 自団体の最高成績 | 優勝 / 決勝進出 / ベスト4 / 一回戦突破 / 初戦敗退 / 不出場 |

「良い大会でした」「惜しかった」「残念だった」は上の成績段に対応する。
**不出場の回もコーチは喋る**（他団体の大会を見ての一言。ここが薄いと大会が他人事になる）。

## 不変条件（数値目標と対で必ず守る）

1. **1画面 = コーチ1人 = 1〜2文**。長い総括は要らない。読み飛ばされる長さにしない
2. **自団体選手への言及は最大2人**。3人以上に触れない（網羅させないための上限）
3. **不出場の回も必ず何か出す**（「該当なし」で無言にしない）
4. **顔出しは既存の共通部品 `_u3bSideHtml` を使う**。新しい顔出しブロックを作らない。
   縦順は 吹き出し → 画像 → 名前 → 役割 の固定順（`mockup-baseline-v0.1.md` §4）
5. **1操作 = 1進行**。進行ハンドラは自分が動ける状態か検証してから進む（§5-D 鉄則2）。
   **待ちにはタイムアウトと二重起動防止フラグをセットで**（鉄則1）。
   ここは「大会結果 → コーチ → 経営画面」の連鎖なので、**詰まると週が進まなくなる**
6. **プレイヤー向け表記に内部変数名を使わない**（MQ / condition / orgPop を生で出さない）
7. コーチのセリフは `src/coach-lines.js` に追加し、`release/manifest.json` は既存のままでよい
   （新規ファイルを作る場合は manifest へ追記）

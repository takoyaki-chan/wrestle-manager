# task-101: care-rework2 P2-G「起用を約束する」チャンネル実装

- 起票: 2026-08-30(Fable)。実装: **Opus(隔離worktree)** → Fable検算マージ
- **前提**: task-100マージ後に着手(同領域のため並列禁止)。セリフは `docs/dialogue/pledge-lines-draft-v0.1.md`(Opus起草→Fableレビュー済みの版)を焼き込む

## 1. 目的

bold(強気)24名に「言葉が効かない」個性を保ったまま、効くケアチャンネルを1つ与える。社長が次の通常興行のメイン起用を約束し、カード編成で果たす/破る。

## 2. 仕様の正

`docs/care-rework2-p2-design-v0.1.md` §P2-G。本書は実装確定事項のみ追記:

- **同時1件のみ**: 有効な約束がある間、他の選手への約束ボタンは無効(理由表示「すでに約束がある」)。二枚舌の複雑系を作らない
- **入口**: 選手ポップアップ(personality==='bold'のみ)に「🤝 起用を約束する」— 声かけボタンの隣。⚡1・費用0・CD選手単位16週(`_decisionWeekUsed.pledge`)
- **状態**: `G.pledge = { fighterId, madeWeek(絶対週), }` 1件。旧セーブ欠落時undefined=約束なし
- **判定**(読み取り専用・F08/Common-1と同型のカード走査): 自団体**通常興行**の結果確定時のみ。対象がメイン(カード最終試合)に出場=履行 / 出場なしで興行開催=破約。特別興行・挑戦試合・遠征は判定しない。**12週判定機会がなければ静かに失効**(ペナルティなし・ログ1行のみ)
- **履行**: `applyTrust(f, 8 × finalMult × 1.3)`(1.3=約束チャンネルのbold専用係数、定数`PLEDGE_BOLD_MULT`)。スランプ/モチベ喪失中は`recoveryMomentum += 8`。興行後ポップアップ直列化キューに1枚(pledge_keptセリフ・頭上吹き出し様式)
- **破約**: `applyTrust(f, -6)`(倍率なし・**-6を超えない**)。同キューに1枚(pledge_brokenセリフ)。grievance・退団判定への直接接続はしない
- **受諾演出**: 約束実行時、声かけと同じ既存の反応様式でpledge_acceptセリフ
- **編成画面の印**: 約束が有効な間、カード編成画面に小さな印(対象選手名+「約束: メイン」程度)。社長が忘れて事故る理不尽を作らない。u3b様式・新規モーダル禁止
- **セリフデータ**: `PLEDGE_LINES = { accept/kept/broken × archetype7種 × 3本 }` をdata.jsに**宣言リテラルで**追加(ブラケット代入禁止)。personality軸はbold固定なので第二分岐なし

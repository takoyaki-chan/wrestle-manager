## §1. 本命 — 負傷でベルトを剥奪しない

`Engine.rival.processAIWeek`(`src/management.js:9424` 付近)は**毎週**こう判定している:

```js
const champAlive = champId && roster.find(f => f.id === champId && !f.injury);
if (!champAlive) {
  // 王者不在: トップOVR選手を新王者に
  const top = roster.filter(f => !f.injury).sort((a,b) => ov(b) - ov(a))[0];
  ...  championId: top.id, defenses: 0, ...
}
```

**軽傷1週間でも `champAlive` が false になり、試合をせずにベルトが移る。**
防衛回数は0にリセット。王者が回復しても戻らない。

プレイヤー側の `Engine.title.validateChampion`(`src/management.js:1949`)は
**ロスターから居なくなったときだけ**空位にする。負傷では剥奪しない。
**AI団体だけ負傷で剥奪される非対称**であり、tier・isTitle と同じ型の取りこぼし。

### 実測でこれが主因と分かっている

- AI王座交代の**約45%は敗北ではない**(負傷等による不戦の移動)
- そのうち**44%は防衛0回**のまま移動
- 同じ選手が**72〜78%**の確率で王座に戻る(代役が負傷 or 本人回復で最上位に戻るため)
- task-62(挑戦者を重み付き抽選)は、この45%に手が届かず目標未達だった

### 直す形

**負傷中もベルトは王者が保持する。** プレイヤーと同じく、
**ロスターから居なくなったとき**(引退・移籍・解雇)だけ王座を空位にする。

- 負傷中の王者は挑戦を受けない(試合に出られないので当然)。
  クールダウンの数え方が負傷でおかしくならないか確認すること
- **長期離脱をどう扱うかは判断が要る。** 現実の団体でも長期欠場なら王座を返上する。
  以下のどちらかを選び、**選んだ理由を報告に書く**:
  - (a) 期間によらず保持(いちばん単純。プレイヤーと完全に同じ規則)
  - (b) 一定週数を超える離脱なら返上(閾値は `src/data.js` の新規定数。
        「明らかに長期」の線を引く。短期の負傷では絶対に剥奪しない)
- **プレイヤー側のロジックは1行も変えない**

## §2. AI王座戦を tier 2(ビッグマッチ)にする

`simulateMatch` の `matchTier` は **1=通常 / 2=ビッグマッチ(PPV/タイトル/対抗戦)**で、
tier2 は別テーブル(`BIGMATCH_MAX_T` / `BIGMATCH_PHASES` / `BIGMATCH_ENG`)を使う。
プレイヤーは `App._normalShowMatchTier` が王座戦に必ず 2 を返すが、
`processAIWeek`(`src/management.js:9186` 付近)は **tier を `1` に直書き**している。

- **王座戦のカードだけ** tier 2 にする(判定は task-61 で入れた `isAiTitleCard`)
- **AI の通常興行は tier 1 のまま**(Keisuke 明示。ここを間違えない)
- 短い試合は運のブレが均される前に決着する。長くすればブレが平均化され強い方が勝ちやすい。
  **恣意的な下駄ではなく、王座戦を王座戦として扱うだけ**である点をコメントに残すこと

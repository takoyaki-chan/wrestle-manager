## 足す場面（Keisuke 指定 2026-08-01）

> 頂上前と頂上決戦の敗者。あと、自分の団体が試合で勝った時と、自分の団体の選手が試合で
> 負けた時に、**相手選手からの言葉**、因縁があるなら侮辱だったり、侮りだったりとかね。
> さらに**因縁がある相手を負けさせた時、相手は悔しげなことを言ったり**とか。

**今回の肝は「相手選手が喋る」こと。** 自団体の選手が自分の勝敗を語るのではなく、
**対戦相手がこちらへ向けて言葉を投げる**。だから因縁の有無で色が変わる。

| キー | 場面 | 話者 | 内容 |
|---|---|---|---|
| `summitPre` | 頂上決戦 直前 | 両者 1本ずつ | 年間最大の舞台に立つ重み |
| `summitLose` | 頂上決戦 決着後 | **敗者** | 年間最大の舞台で負けた側。現状ゼロ |
| `oppOnLoss` | 自団体が**勝った** | **相手選手** | 負けた相手がこちらへ投げる言葉 |
| `oppOnWin` | 自団体が**負けた** | **相手選手** | 勝った相手がこちらへ投げる言葉 |

### 因縁による枝分かれ（`oppOnLoss` / `oppOnWin` の中身）

| キー | 条件 | 色 |
|---|---|---|
| `oppOnLoss.grudge` | 因縁あり(rivalry 60+) の相手を**負かした** | **悔しげ**。認めたくない、次はやる |
| `oppOnLoss.plain` | 因縁なしの相手を負かした | 素直に負けを認める / 相手を称える |
| `oppOnWin.grudge` | 因縁あり の相手に**負けた** | **侮辱・侮り**。見下す、勝って当然という態度 |
| `oppOnWin.plain` | 因縁なしの相手に負けた | 普通の勝者の言葉。過剰に煽らない |

**`oppOnWin.grudge` だけが「悪意」を出す枠**です。ここでしか出さないので、
他の枠へ侮辱を混ぜないこと。逆にここは遠慮しない（因縁の相手に勝ったのだから）。

`summitPre` / `summitLose` も因縁の有無で枝を分けてよい（天頂戦決勝と同じ考え方）。

## セリフのルール（CLAUDE.md より）

1. **アーキタイプ第一分岐・性格第二分岐。** 性格は語尾の飾りではなく**態度そのものを変える**
   （`src/tenchosen-final-lines.js` の `ojousama_bold` が Keisuke 記入の原型。必ず読むこと）
2. **テンプレ表現を使わない。** 34組が似た文の言い換えにならないこと
3. **大会名を連呼しない。** 「PPV」「GRAND FINAL」はセリフ内で1割以下。指示語主体
4. 鷹揚は `specs/oyou-style-guide.md`。お嬢様の「ですわ」は語尾のアクセント程度に
5. **侮辱は `oppOnWin.grudge` だけ。** キャラを不快なだけの人間にしない——
   侮るにも品位の差がある（お嬢様の侮りと不良の侮りは別物）

## 不変条件

1. **34組 × 全モチーフに欠けが無い**。在籍0の15組は作らない
2. **重複0**（記号を除いた比較で完全一致が無い）
3. **大会名を含む行が全体の1割以下**
4. フォールバックが49組すべてで機能する（在籍0の組でも空にならない）
5. **侮辱系は `oppOnWin.grudge` 以外に出現しない**
6. 既存の `PPV_SUMMIT_VICTORY_LINES` を1文字も変えない
7. **アンダーカードで毎試合喋らせない。** 6試合すべてに出すとくどい。
   発火条件（因縁あり / 番狂わせ / 高MQ など）で絞り、**出ない試合があってよい**

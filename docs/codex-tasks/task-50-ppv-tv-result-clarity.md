## D. 年末表彰式の前に総括画面が見えてしまう

> 年末表彰式の前に総括画面が出てしまうことがある。ブレイクスルー等のポップアップが
> 一緒に出ると**それが優先されて表彰式に入るのが一手遅れ**、その間、背景に総括が見えている。
> (Keisuke実機・2026-07-31。原因分析も本人による)

**この分析は妥当。** 同じ「キュー待ちの間に背面が見える」問題であり、
PPVのちらつき(task-46 C)と同じ構造。

### 直す形

- **表彰式に入る前に、背面の画面を見せない**。PPVで採った手法(不透明な繋ぎ画面を先に出す)
  と同じ考え方でよいが、**総括は表彰式の後に見せる正規の画面**なので、
  「隠す」より **順序を確定させる**方が本質的:
  - オフシーズン第1週で、**ポップアップ(ブレイクスルー等)→ 表彰式 → 総括** の順に
    連鎖が固定されること
  - ポップアップの解消待ちの間に、**総括が先に描画されない**こと
- **task-43 で「式典後に必ず今週画面へ戻す」修正を入れている**ので、その修正と
  衝突しないよう連鎖の順序を整理すること
- **キュー待ちのコールバックには必ず保険の時限を掛ける**
  (2026-07-31 に PPV が「準備中…」で永久に止まった事故と同型。
  `_chainEventPopupQueueEmpty` は空キューなら即実行するよう修正済みだが、
  **待ちを挟むときは必ずタイムアウトを併用する**こと)

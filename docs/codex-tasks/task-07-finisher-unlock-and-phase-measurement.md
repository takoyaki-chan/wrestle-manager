## 背景

task-05 で導入した3ティア制の実測で、**フィニッシュ級（d14〜16）が 0.115回/試合・89%の試合で一度も出ない**ことが判明した。想定は1〜2回/試合であり、10分の1である。

## ① 解禁閾値の改訂（実装する）

### 変更内容

`selMove` 内でフィニッシュ級の解禁判定に使っている `eng.pinAttemptHpThreshold` の参照をやめ、**専用定数 `finisherUnlockHpThreshold` を新設**して参照する。

| 定数 | 値 |
|---|---|
| `ENG.finisherUnlockHpThreshold` | **0.50** |
| `BIGMATCH_ENG.finisherUnlockHpThreshold` | **0.40** |

`pinAttemptHpThreshold`（通常0.35 / ビッグ0.25）は**変更しない**。フォール判定は現状のまま。

### 設計意図（実装時に壊さないこと）

解禁とフォール圏のあいだに15ポイントの帯を作り、終盤を二段階に分節する。

| 防御側HP | 状態 |
|---|---|
| 50%〜（ビッグ40%〜） | 通常大技まで。フィニッシュ級は出ない |
| 35〜50%（ビッグ25〜40%） | **フィニッシュ級が解禁。削り切りにいく帯** |
| 〜35%（ビッグ〜25%） | フォール・ギブアップが飛び始める |

### 注意

- `opening-execution-spec-v0.1.md` §4.3 のとおり、**開幕大技は解禁条件を無視してフィニッシュ級を含む**（`ignoreFinisherLock` の既存挙動を維持すること）
- タッグ経路も同じ選択関数を通っているため、そちらにも自動的に適用される。これは意図どおり

## ② フェーズ到達率の計測（計測のみ・修正はしない）

平均ターン数が **12.27** であるのに対し、Climax は **13ターン目から**始まる（`PHASES`: Opening 1-4 / Mid 5-8 / End 9-12 / Climax 13-20、`MAX_T` = 16）。

**平均的な試合が Climax に入る直前で終わっている疑いがある。**そうであれば Climax 用に設計した重み（0/35/65）は少数派の長い試合にしか適用されていないことになる。

### 計測してほしいこと

1. **試合がどのフェーズで終わったかの分布** — Opening / Mid / End / Climax / 時間切れ の各割合
2. **turn 13（Climax開始）に到達した試合の割合**
3. **決着ターンのヒストグラム** — turn 1〜16 の各割合
4. **ビッグマッチについても同じ3項目**（`BIGMATCH_PHASES`: Climax は 19ターン目から、`BIGMATCH_MAX_T` = 24）
5. **フェーズ別の滞在ターン数** — 各フェーズが平均何ターン続いているか

### 重要

**②で問題が見つかっても、フェーズ境界や `tierW` を修正しないこと。** 数値を報告するのみ。対処方針は計測結果を見てから決める。

（既知の課題として、クールダウンにより大技の実効上限が約50%になっており、Climax の設定値65%が45%までしか実現していない。これも②の結果と合わせて判断するため、**本タスクでは触らない**。）

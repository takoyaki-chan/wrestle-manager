## 直すもの

### 1. 画像枠を 2:3 梯子に合わせる(全スライド共通)

素材(upper)は **256×384 = 2:3**。現在の枠は 1:1.2 なので**縦が足りず顔や体が切れている**。
ベースライン §2 の梯子から段を選んで当てる:

| 用途 | 現状 | 直す先(§2の段) |
|---|---|---|
| 単独の主役(MVP・新人王・JT優勝・天頂戦・PPV等) | 140×168 | **XL 172×258** |
| 2人が主役(タッグ優勝) | 140×168 ×2 | **L 150×224**(§2-B の隊列として) |
| ベストマッチ(2人対置) | 100×120 | **M 132×194**(両者同じ段。§2「2人を並置するときはサイズを揃える」) |

**ベストマッチだけ小さいのは誤り**。§2の梯子に載せて他と揃えること。

### 2. 吹き出しを画像の「上」へ(§3・鉄則)

現状は `margin-top` で**画像の下**に付いている。§3のとおり:

- **吹き出しはキャラクター画像の上**。画像に被せない
- 尻尾は**画像の水平中心**を指す(下向きの尻尾)
- **予約枠**にする(`position:absolute` で浮かせない)。発言が無い側にも同じ高さの空枠を置き、
  左右で画像の上端を揃える
- **名前・所属を吹き出しの中に書かない**(現状 `.speech-speaker` で名前を入れているなら外へ出す)
- 枠の高さ: XL〜M = 52px / S・XS = 46px、本文 13px、`-webkit-line-clamp: 2`

**表彰式の全スライドで**この形に統一する(MVP・新人王・JT・ベストマッチ・大会優勝・殿堂入り等)。

### 3. タッグ優勝は「1つの枠に2人」(§2-B 隊列)

現状 `_buildSeasonEventChampionAward`(`src/ui-common.js:2788` 付近)は
**個々に額縁を付けて横に並べている**。§2-B に従い:

- **枠は群の外側に1つだけ**。個々の画像に額縁を付けない
- 隣どうしを **18px 重ねる**(境目の縁は付けない)
- 落ち影は `filter: drop-shadow()`(`box-shadow` は矩形に付くので誤り)
- サイズは同格2人なので**両方 L(150×224)**
- 見出し(団体名・「タッグ王者」)は**群の頭に乗せる**

### 4. 大会優勝スライドに吹き出しを追加

`_buildSeasonEventChampionAward` は**セリフを出していない**(`_awSpeech` の呼び出しが無い)。

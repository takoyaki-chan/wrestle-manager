## A. 複数人の受賞で吹き出しが破綻している

**対象**: `_buildEventChampionAward`(`src/ui-common.js:2836` 付近)の
`fighters.length >= 2` の経路。春のタッグリーグ / 4団体勝ち残り対抗戦 / 天頂戦 /
PPV GRAND FINAL が同じ関数を通るので、**1箇所直せば全部直る**。

### いま起きていること(2つある)

1. **セリフが途中で切れる。**
   `.speech-text` に `-webkit-line-clamp:2; overflow:hidden`(`src/index.html:1670` 付近)、
   `.aw-speech-slot` に `height:52px`(同 1664 付近)。
   1人あたりの幅は `.aw-team-member{width:150px}`(同 1709)しかないので、
   2行に収まらないセリフが**文の途中でぶつ切り**になる。
2. **隣の吹き出しと繋がって1つの白い箱に見える。**
   `.aw-team-member + .aw-team-member{margin-left:-18px}` は**画像の隊列**のための重なりだが、
   吹き出しは `width:100%` で列いっぱいなので**吹き出しまで重なって**しまい、
   実機では2人ぶんの吹き出しが1つの角丸ボックスに融合して見える(添付画像)。

### 直す形

- **セリフを切らない。** 吹き出しは中身の量に応じて**縦に伸びる**ようにする
  (`line-clamp` による切り捨てをやめる)。極端に長い場合の上限を設けるなら、
  切るのではなく**そもそも収まる文字数のセリフを選ぶ**か、行数の上限を上げる
- **隣の吹き出しと明確に離す。** 画像は §2-B のとおり18px重ねたまま、
  **吹き出しだけは重ならない**ようにする
- 吹き出しは §3 のとおり**画像の上**・尻尾は**その人の画像の水平中心**・
  白(クリーム)地に黒文字。`margin-top` で下に付けない。
  **吹き出しの中に名前・所属を書かない**(いまも書いていない。維持すること)
- **複数人の画像の上端が揃うこと。** いまは `.aw-speech-slot{height:52px}` の固定枠で
  揃えている。吹き出しが伸びると高さが変わるので、揃え方を作り直すこと
  (例: 列の下端で揃える。`.aw-team-lineup` は既に `align-items:flex-end`)
- **3人以上(`is-many`)でも破綻しないこと。** 4団体勝ち残り対抗戦は3名制

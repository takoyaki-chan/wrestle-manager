### こちらで見つけた有力な原因

`src/management.js:16290` 付近、PPV週の正規化ブロックは
```js
if (s.week === PPV_SHOW_WEEK && !s.offSeason && ...)
```
と `!s.offSeason` を見ているが、**その直後の実際の発火ブロックは offSeason を見ていない**:
```js
if (s.week === PPV_SHOW_WEEK && s.ppvPhase === 'tv') {     // ← !s.offSeason が無い
  return { state: { ...s, weekPhase: 'ppvTV' }, events };
}
if (s.week === PPV_SHOW_WEEK && s.ppvPhase === 'locked') { // ← 同上
```
オフシーズンに入っても `week` が 48 のままなら、**この分岐が再度成立して
オフシーズン中にPPVが始まる**。これがKeisukeの体感と一致する。

**この仮説を実際に検証し、正しければ直す。** ただし
**「offSeasonガードを足すだけ」で本当に正しい順序になるかを確認**すること
(PPVが正規の第48週に確実に消化されるか。消化されないままオフシーズンに入ると
今度はPPVが丸ごと飛ぶ)。

## B. 文章の役割分担(renderRanking の文章生成)

v1.3確定の3層構造。**すべての数値・人名はGameStateの実データから差し込む**(Keisuke指示 2026-07-30。
モックの「5度の防衛」「高城・月村」等はダミーであり、ハードコードしたら失敗)。

### B-1. 団体説明(rp-info の文) — 団体全体のこと

現行の `_buildLeadV2` 系(タグ→文例プール)のままでよい。変更不要(depth連動タグは56d1d66で導入済み)。

### B-2. エース欄の文 — 王者・看板「個人」のこと

現行はチーム語り(「2番手3番手も強く…」)が混ざる。**個人のことだけを語る文**に置換する。
実データ: 王者か(`titles.world.championId`/AI側 titles)・防衛数(`defenses`)・在位の長さ・
年齢・OVR・看板(boardId)か・無冠か。

文例プール(この文面を使う。プレースホルダは実データ束縛。各状況2本を目安に、
トーンを合わせた追加は可):

- 王者・防衛3+: 「{def}度の防衛を重ねる王者。完成された試合運びは衰えを知らず、挑戦者に世代交代を許さない。」
- 王者・防衛3+別: 「ベルトと共に{def}度の夜を守り抜いた。彼女の王座は、もう団体の格そのものだ。」
- 王者・防衛0〜1: 「戴冠したばかりの新王者。王座の重みをまだ測りかねている。」
- 王者・若い(≤22歳): 「{age}歳の若き王者。{def}度の防衛は、まだ通過点に見える。」
- 看板(無冠): 「王座はないが、この団体の顔は間違いなく彼女だ。大一番の勝負強さが看板を支えている。」
- 看板・高齢(≥30歳): 「{age}歳、なお看板。衰えの影を経験で塗り替えながら先頭に立ち続ける。」
- 王者かつ看板: 「王座も看板も一人で背負う。彼女が立っている限り、この団体の興行は格を失わない。」
- 無冠・OVR突出(団体内差+8以上): 「ベルトはまだ巻いていない。それでも実力が頭ひとつ抜けていることは、誰の目にも明らかだ。」

### B-3. 主力層欄の文(rp-depth-note) — 「2番手以下の面々」のこと

**エース個人の話をしない。** 実データ: 2〜3番手の実名(`sorted[1]`,`sorted[2]`の姓)・
その実OVR帯・主力枠の実戦級数(`depthCoreReady`/5)・控えの一線級数(`depthReserveReady`)・
欠場数・レンタル在籍。**2〜3文で組む**(1文目=顔ぶれ、2文目=厚さの評価、3文目=展望や弱点)。

文例部品(状況タグで結合。56d1d66の `_buildDepthNoteV2` タグ機構に載せる):

- 厚い: 「{name2}・{name3}ら{band}台の主力が続き、主力枠は{coreReady}人が実戦級。誰が欠けても興行の格が落ちない。」
- 控え厚い: 「控えにも一線級が{reserveReady}人おり、連戦でも戦列が細らない。」
- 中位: 「{name2}・{name3}が主力の軸。層は形になりつつあるが、上位と分けるのは控えの最後のひと押しだ。」
- 薄い: 「{name2}の後ろが続かない。主力枠で実戦級は{coreReady}人だけで、軸が倒れれば一気に崩れる。」
- 欠場あり: 「{injured}人が欠場中で、ベンチは見た目より薄い。代役の質が興行の質を決めてしまう。」
- レンタル依存: 「レンタルの{rentalName}が戦列を支える。頼もしくもあり、借り物の厚みでもある。」
- 若手比率高: 「主力層は若い。数字はまだ並だが、来季このベンチの景色は変わっているかもしれない。」
- 極薄(4人未満): 「主力と呼べる顔ぶれ自体が足りていない。補強か育成か、決断の時が近い。」

- {band}=実OVRから「80」「70」等の十の位帯。{name2}等は**姓のみ**(モック準拠)
- 同じ団体で毎週文面が揺れないよう、既存の `_pickSeed`(シーズン+団体でシード固定)を踏襲

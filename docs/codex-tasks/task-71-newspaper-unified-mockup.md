## 一面から引き継ぐ作法（これが「統一感」の中身）

`src/index.html` の `.np-v3-*` と `docs/ui/mockups/newspaper-redesign-best-v0.3.html` が実物。

### 1. タイプスケール（面が変わっても同じ段を使う）

| 役割 | 指定 |
|---|---|
| トップ級見出し | 27px / `Noto Serif JP` 900 / `line-height:1.25` |
| 準トップ級見出し | 18px / 同上 |
| 肩・中記事見出し | 16px / 同上 |
| 小記事見出し | 13px / **Sans** 900（ここだけ Sans。一面と同じ） |
| リード（deck） | 13px bold `#5b4b34` |
| 本文 | 13px / `line-height:1.85` / `#2a2014` / `text-align:justify` / `text-indent:1em` |
| 本文（従） | 12px / 1.75 / `#3a2c18` |
| 本文（小） | 11px / 1.7 / `#4a3825` |
| キャプション・署名 | 10px `#7a6544` |

**見出しは Serif、ラベルと数値は Sans / Bebas Neue。** これを面ごとに変えない。

### 2. セクションの頭は kicker で統一

一面の `.np-v3-kicker`（金 or 赤の白抜き・10px・`letter-spacing:4px`）。
2面以降で使われている `.np-sec` / `.np-sec-gold` / `.np-page-headline` / `.np-mvprace-divider` など
**面ごとにばらばらの見出し部品を、この1系統へ寄せる**。

### 3. 罫線

- 通常の区切り: `1px solid rgba(120,84,39,.35)`
- セクション境界: `3px double rgba(120,84,39,.5)`
- 縦罫: 左に `1px` + `padding-left:16px`（一面の `.np-v3-vr`）

### 4. 写真の梯子

トップ 190×228 / 肩 84×126 / chip 46×66。枠は `2px solid #d4b87a`。
キャプションは黒グラデ帯を写真の下端に重ねる。**アッパー画像は反転禁止。**

### 5. 黒田の位置

**コラムは最下段固定**（`3px double` の上罫 + 34px 丸顔 + 11.5px Serif 本文 + 署名）。
面が変わっても同じ位置・同じ形。

### 6. パレット

紙面ローカルの既存色だけを使う。**新しい16進を足さない**
（`#f8eed2` `#f0e0ba` の紙 / `#8b1a1a` の赤 / `#9a7020` `#b08530` `#d4a82a` `#d4b87a` の金 /
`#1a0d04` `#1f1710` `#2a2014` `#3a2c18` `#4a3825` `#5b4b34` `#7a5b32` の墨 / `rgba(120,84,39,*)` の罫）。
`test/newspaper-sub-photo-test.js` E7 と `test/newspaper-front-v3-test.js` F5 がこれを機械検査している。

### 7. レスポンシブ

820px 以下で段組を1列に落とす。写真の回り込みは解除して全幅バーにする。
**375px で横スクロールが出ないこと。**

## 各面で直すべきと分かっている点

実装を読んで確認済みの具体箇所。モックではこれらが解消された状態にすること。

### 2面 団体比較
- **`.np-ace-confront` がクリーム紙の中の純黒パネル**（`linear-gradient(180deg,#1a0d04,#2a1a10)`）。
  Office/Stage のカテゴリ混在で、ここだけ別の画面に見える。紙の上の記事として組み直す
- `.np-result-line` 系の暗色バーも同じ問題
- 見出し部品が `.np-headline-section` / `.np-org-card-title` / `.np-headline-grade` と独自で、
  一面の kicker 系と繋がっていない
- GRADE の巨大数字（36px Bebas）は残してよいが、紙面の中の「囲み記事」として枠を与える

### 3面 因縁列伝
- `.np-rivalry-stand` が 240px のスタンド画像枠で、一面の写真梯子（2:3）から外れている
- `.np-rivalry-headline` / `.np-rivalry-vs` が独自スケール

### 4面 MVPレース
- `.np-mvprace-*` が Bebas 中心の「ランキング表」で、記事の紙面に見えない
- `.np-page-headline` / `.np-page-lead` / `.np-page-meta` が一面のスケールと別物
- **一面には既に MVP 小窓がある**（`.np-v3-mvpbox`）。4面は「その詳細記事」として、
  小窓と地続きに見える組みにする

## 不変条件（数値目標と対で必ず守ること）

1. **1ファイルに4面。一面は既存実装の出力そのまま**（変更しない・比較の基準）
2. **新規16進カラーを足さない**（上のパレット内で組む）
3. **選手画像は 2:3 の梯子から選ぶ**。トップの 190×228 だけは例外として既存踏襲
4. **アッパー画像を左右反転しない**（`transform:scaleX(-1)` を書かない）
5. **黒田コラムは全面で最下段固定**
6. **375px で横スクロールが出ない**
7. 見出しの font-family は Serif、ラベル・数値は Sans/Bebas。**面ごとに変えない**
8. `src/` を一切変更しない（このタスクの成果物はモック1枚だけ）

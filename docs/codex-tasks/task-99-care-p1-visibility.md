### 2.1 P1-1の確定較正値(2026-08-30 Fable実測。設計docの暫定表を置き換える)

実測(--careあり/なし各40季×2シード=42,7919、週次morale分布)により、設計docの暫定値から改定:

| 項目 | 現行 | **確定値** |
|---|---|---|
| 表示レベル閾値(`getAtmosphereText`, management.js:8067) | ds≤20/≤40/≤60/≤80/81+ | **ds≤24 / ≤41 / ≤57 / ≤65 / 66+** |
| 表示ノイズ(同関数) | int[-10,10] | **int[-4,4]** |
| 空気ログ「good」トーン閾値(management.js:12990) | morale≥70 | **morale≥58**(=L4帯の開始に一致) |

- ノイズを±10→±4に縮める理由: 帯幅が20→10前後に狭まるため、±10のままだと表示が毎週2〜3段ちらつき「読める信号」にならない。元設計の「ノイズ≒帯幅の半分」比を維持する。ノイズは表示時のみでmorale本体に触れない(現行と同じ)
- 設計docの目標「ケアなしL4+<10%」は実測により達成不能と判明(ケアなしでも興行好調期はmorale60超に正当に達する。士気の敵1位=興行MQ)。改定目標は§4参照
- 空気ログのwarning(<50)/danger(<35)閾値は**変えない**

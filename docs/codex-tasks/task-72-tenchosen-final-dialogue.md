> 戦歴・因縁・能力によったもので、ちゃんとアーキタイプにも沿った会話。
> 決着後もちょっと欲しいね。

> **分担: セリフ本体は Opus に書かせる（`docs/codex-tasks/` ではなく別枠）。
> このタスクは「分岐設計 + データ構造 + 配線」で、Terra / Luna 向け。**
> セリフが揃うまでは仮テキストで通し、差し替え可能な形にしておくこと。

## 現状（調査済み・2026-08-01）

- `_tcFocusCard`（`src/ui-common.js`）は **因縁があるときだけ** `_rivalryBubblePairHtml` で
  1往復を出す。**汎用のセリフは無い**（コメントに「天頂戦に汎用セリフは無い」と明記されている）
- **決勝だけの特別扱いは無い**。1回戦と同じカードで、ラベルが `👑 決勝` になるだけ
- **決着後の会話は一切無い**。結果 → 次のラウンドへ進むだけ
- 比較: ジュニアトーナメントは試合前の汎用セリフを持ち、大会後には
  `_showJTImpressionChain`（champion / postWin / postLose）がある

## やること

### 1. 決勝直前の会話（1往復）

決勝カード（`roundName === 'final'`）でのみ発火。既存の因縁セリフより**優先**する
（因縁があっても決勝用の言葉に差し替える。ただし因縁の事実は文脈として使う）。

**分岐軸（この5つが「戦歴・因縁・能力によったもの」の中身）**

| 軸 | 取り方 | 段 |
|---|---|---|
| 対戦歴 | `G.h2h` の history | 初対戦 / 再戦（通算あり） |
| 直近の勝敗 | h2h の直近3戦 | 勝ち越し / 五分 / 負け越し |
| 因縁 | `Engine.relationships` の rivalry | 無し / あり(60+) / 強い(80+) |
| 力量差 | `Engine.util.ov()` の差 | 格上(+8以上) / 互角 / 格下(-8以下) |
| 消耗 | `match.carryLeftPct` / `carryRightPct` | 余力あり(70%+) / 消耗(40〜70) / 満身創痍(40未満) |

**天頂戦は消耗が持ち越される**ので、満身創痍で決勝に立っているという文脈が高頻度で使える。
これは他大会に無い天頂戦固有の素材なので**必ず使うこと**。

**口調の分岐は アーキタイプ第一 / 性格第二**（`docs` の既定・[feedback_player_lines_archetype_absolute]）。
アーキタイプ7種（standard / polite / cool / composed / ojousama / delinquent / seductive）。
`getDialoguePool()` の規約に乗せる（archetype → personality、未定義は
`${archetype}_normal` → `standard` の順にフォールバック）。

### 2. 決着後の会話

決勝の決着直後、優勝発表へ進む前に**勝者→敗者の順で1本ずつ**。

- **勝者**: 4年に一度の頂点を取った重み + 相手への言及。**勝ち誇らせすぎない**
- **敗者**: 敗戦の受け止め。ここはアーキタイプ差が最も出る場所

決勝以外のラウンドには入れない（毎試合やると軽くなる）。

## 不変条件（数値目標と対で必ず守る）

1. **決勝以外では発火しない**。1回戦〜準決勝の見え方を変えない
2. **1往復まで**。往復を重ねない（試合前の間延びは体験を殺す）
3. **アーキタイプを持たないセリフを1本も作らない**。性格は第二分岐
4. **大会名を連呼しない**。「天頂戦」の語はセリフ内で1割以下。指示語主体
   （[feedback_no_name_repetition_in_dialogue]）
5. **吹き出しは画像の上**。名前・所属を吹き出しの中に書かない
   （既存 `_rivalryBubblePairHtml` / `.jt-bub-pair` の形を崩さない）
6. **因縁が無い組でも必ず何か出る**。「因縁があるときだけ喋る」現状を置き換えるのが目的
7. **待ちに時限の保険**。決着後の会話はコールバック待ちになるので、
   タイムアウト + 二重起動防止フラグをセットで書く（`docs/ui` §5-D 鉄則1）
8. セリフのテーブルは `src/data.js` ではなく**新規ファイル**に置き、
   `release/manifest.json` へ追記する（追記忘れは即バグ）

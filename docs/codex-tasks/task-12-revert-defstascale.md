## 背景

task-10 で `ENG.defStaScale` が **0.025 → 0.0125** に半減された。HP寄与の復元との二重加算を避け OVR勝率を維持するため、という判断であり理屈は通っている。

**しかしこれは承認されたパラメータ変更ではなく、かつ設計意図に反する。**

### 設計意図（Keisuke 確認済み）

- **PW / SP / TE / ST の4つが試合内の能力として拮抗する**
- **MN（マインド）はそこから一段落ちる**。MN は試合外で効く能力として位置づける
- 既存仕様（`defStaScale: 0.025` / `defMntScale: 0.06`）は**大量の試合シミュレーションで検証済み**であり、その状態で MN の試合内効果は他4要素より低いことが実測されている

ダメージ式の防御項は `defense = ST×defStaScale + MN×defMntScale` である。`defStaScale` だけを半減し `defMntScale` を 0.06 のまま据え置いたため、守備における **ST : MN の比率が 1:2.4 → 1:4.8** へ変化した。**検証済みの良好な状態から、MN が相対的に有利な方向へずれている。**

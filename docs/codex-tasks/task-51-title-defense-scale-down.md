## 現状

`src/ui-common.js:12009` `showTitleMatchCeremony(outcome, onDone)` は、
**防衛も戴冠も同じ** `showCeremonyEvent(evt, speakers, onDone)` を使っている
(`visualVariant: 'triumph'`、`titleMain: '防 衛'` の大判式典オーバーレイ、
ナレーション3行 + 全画面 + 「式典を終える」)。

防衛は年に何度も起きる。毎回この規模だと、**戴冠との差が消える**。

## 直す形

**分岐を3つに分ける。**

| ケース | 演出 | 理由 |
|--------|------|------|
| **戴冠**(`outcome !== 'defense'`) | **従来の式典のまま**(変更しない) | 頂点が移る瞬間は年に数回。ここは大ごとでいい |
| **節目の防衛**(防衛回数が 5 / 10 / 15) | **従来の式典のまま** | `Engine.news.checkDefenseMilestone(defenses) > 0` が真のとき。記録に残る防衛は特別扱い |
| **通常の防衛**(上記以外) | **派閥イベント級のA型モーダル1枚** | 今回の指摘対象 |

判定は既存の `Engine.news.checkDefenseMilestone`(`src/management.js:20093`、
15/10/5 のみ 0 以外を返す)を使う。**新しい閾値を作らない。**

### 通常防衛の見た目(参考にするもの)

`showFactionEventResult`(`src/ui-common.js:9534`)と**同じ密度・同じ部品**にする。
- `_mdlAOpen` 系のA型モーダル。全画面式典オーバーレイは使わない
- 見出しは1行(例: `🛡 王座防衛`)、その下にシーズン/週のメタ行
- 地の文は**1〜2行**(現状の3行ナレーション + 間(`narrationGaps`)は使わない)
- 王者の顔 + 頭上吹き出しでセリフ1つ。挑戦者は**出しても1枚まで**
- ボタンは1つ。文言は「式典を終える」ではなく素っ気なくする(例: 「閉じる」)

### セリフ

**現行の取得ロジックをそのまま流用する。**
- 王者: `getTraitQuote('titleDefense', champion)`
- 挑戦者: `getTraitQuote('titleChallengeLoss', opponent)`
新しいセリフを書き足さない。`src/data.js` を編集しない。

## 不変条件

1. **`onDone` はどの分岐でも必ず1回呼ばれる**。呼ばれないと年末進行や週遷移が止まる。
   早期 return するパス(王者が見つからない等)も含めて全部
2. **戴冠の見た目を変えない**(回帰させない)
3. **吹き出しは画像の「上」**。`margin-top` で下に付けない。
   **吹き出しの中に名前・所属団体を書かない**(`docs/ui/mockup-baseline-v0.1.md` §3)
4. 選手画像は**2:3の梯子**から選ぶ(同 §2。XL 172×258 / L 150×224 / M 132×194 /
   S 108×162 / chip 46×66)。1:1.2 の枠に入れない
5. アッパー画像を**左右反転しない**
6. 新規16進カラーを増やさない(`var(--*)` トークンのみ)
7. GameState への書き込みを増やさない(この関数は表示だけ)
8. `npm test`(`node test/run-all.js`)全PASS(163/163 + 新規)

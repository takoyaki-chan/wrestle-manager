## 原因の見立て(自分で確かめること)

`Engine.mq.rivalryRingEffect`(`src/management.js:2214`)は因縁の段階に応じて
`counterPt`(カウンター率) と `escape`(脱出率) を返し、`buildRingInOpts` 経由で
`simulateMatch` に渡される。`RIVALRY_RING_TABLE` は `src/data.js` にある。

**仮説**: この効果が両者に対称に掛かっていると、**弱い側のほうが得をする**。
脱出率が上がれば不利な側ほど延命し、逆転の機会が増えるため。
→ 実際に対称なのか、コードを読んで確かめること。**仮説を検証せずに直さない。**

他にも原因があり得る(因縁時のダメージ計算、フィニッシュ判定など)。
**「どこが効いて歪みを生んでいるか」を数値で特定してから直すこと。**

## 直す方向

- **不変条件4(MQ優位 +1.0〜+2.5)は維持する。** 因縁戦が凡戦になったら本末転倒

- **恣意的な「格上に下駄」は最後の手段**。まず「なぜ弱い側が得をしているか」を消す

## やること

`docs/ui/mockups/special-events-remake-v0.1.html` を1枚。

- 1ファイルに **4つ**を縦に並べる: ①基準としてのジュニア（現行のまま）
  ②春タッグ ③PPV ④秋対抗戦。**並べて見比べられること**がこのモックの目的
- ①は既存実装の見た目をそのまま貼る（比較の基準。変更しない）
- ②〜④は提案。ダミーデータでよい（画像は `../../../image/upper/*.webp` の実在ファイルを借りる）
- CSS はインライン。`src/index.html` からのコピーで構わないが、**新規/変更した規則にコメント**を付ける

### 各大会で「その大会らしさ」として残すもの

作り直しは統一であって**均一化ではない**。次は各大会固有なので潰さないこと。

- **春のタッグリーグ**: 総当たりの順位表と勝ち点。2人1組であること
- **PPV GRAND FINAL**: 年間最大興行としての格。動員のヒーロー表示（`.pb-attend-hero`）
- **秋の4団体勝ち残り**: 3人勝ち抜きの残り人数と、リングに残っている side

## 不変条件（数値目標と対で必ず守る）

1. **ジュニアは変更しない**（比較の基準として現行の見た目のまま置く）
2. **選手画像は 2:3 の梯子から選ぶ**（XL 172×258 / L 150×224 / M 132×194 / S 108×162 /
   chip 46×66。対戦カードのジュニア実測は 118×177）。**正方形の顔は 52px 以下**
3. **アッパー画像を左右反転しない**（`transform:scaleX(-1)` を書かない）
4. **吹き出しは画像の上**。尻尾は画像の水平中心。**名前・所属を吹き出しの中に書かない**
5. **縦順は固定**: 吹き出し → 画像 → 名前 → 役割ラベル → 団体バッジ → 数値(OVR)
   （`mockup-baseline-v0.1.md` §4。2026-08-01 に対戦カードをこの順へ是正済み）
6. **複数人は隊列**（群の外枠1つ・18px重ね・drop-shadow）。個々に額縁を付けない
7. **勝敗は画像から読める**こと。敗者は `grayscale(.9) brightness(.72)`、
   記号は ○×△。**`LOSE` の文字は使わない**
8. **カテゴリを混ぜない**。特別興行は Stage（暗色）。Office の Cream Panel を持ち込まない
9. **ハードコード16進カラー禁止**。色は `var(--*)` トークンを使う
   （Stage の `--stage-text-main` / `--stage-text-sub` / `--stage-text-dim` など）
10. **375px で横スクロールが出ない**
11. `src/` を一切変更しない（成果物はモック1枚だけ）

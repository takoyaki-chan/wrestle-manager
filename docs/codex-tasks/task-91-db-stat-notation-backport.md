## 4. 数値目標と不変条件(対で書く)

| # | 目標 | 不変条件 |
|---|---|---|
| I-1 | DB一覧のOVR+ステ5列を階調7帯へ | **表示のみの変更**。ソート順・列構成・フィルタ挙動・行クリック遷移は完全不変。診断: 変更前後で同一Gに対する一覧のDOM構造(色以外)が一致 |
| I-2 | 輝き=100超のみ | DB一覧・選手詳細の対象箇所から**85+の常時glowを除去**。ただし**対象外画面(社長室・ピークOVR表示等)の `_scale6Style` 適用は1箇所も変えない**(grepで呼び出し箇所を数え、対象2画面以外の件数が前後一致すること) |
| I-3 | 詳細バーを枠越え方式へ | 0–150目盛と縦線を廃止し枠=100終端+圧縮はみ出し(式はヘルパーと一致)。**バー自体にglow/box-shadowを付けない**(輝きは数値のみ) |
| I-4 | 消耗▼・季節成長+nの情報維持 | statDecayView 相当の情報(▼n の値・+n の値)を**1つも落とさない**。ゴースト(同色28%)+▼n表記で移植 |
| I-5 | レーダー軸ラベルを系統色へ | レーダーの値・クランプ(0–100)・塗り・グリッドは不変。変わるのは軸ラベルの色だけ |
| I-6 | 旧セーブ互換 | セーブ形式・G構造に非接触(表示のみなので自明だが、diffで保証: 変更が§3の3ファイル+テストに閉じる) |

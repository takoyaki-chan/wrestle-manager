# A. 1年目に年末表彰式もPPV TV観戦も発火しない

> 1年目、表彰式すら出ないし、PPVテレビ観戦もなかった。発火もしないのは良くない。

## 調査の起点(こちらで確認済みの事実)

- `pendingAwards` は `Engine.awards.generate()` で **オフシーズン第1週に生成**される
  (`src/management.js:15727` 付近)。**シーズン番号での除外は無い**
- 表示側は `App._checkAndShowAwards()`(`src/app.js:11437` 付近)。
  `G.pendingAwards` が無ければ次の演出へスキップする
- PPV TV観戦は `G.weekPhase === 'ppvTV'`(`src/app.js:3806` 付近)

## 調べること

1. **1年目に `Engine.awards.generate()` が何を返すか**を実際に出力して確認する
   (合成 state か、ヘッドレスで1シーズン進めて確認)。
   - 各賞(MVP・新人王・ベストマッチ・メディア功労賞・殿堂入り)が**空**になっていないか
   - 空になる場合、**何が足りないのか**(試合数・シーズン履歴・前年比較データ等)
2. **1年目にPPV GRAND FINAL が開催されるか / `ppvTV` フェーズに入るか**を確認する
   - エントリー条件(出場資格・団体人気・シーズン)に1年目を弾く条件が無いか
   - `tvMode` の分岐(`src/app.js:73`)で1年目が除外されていないか
3. どちらも「**仕様として1年目は出さない**」設計になっているのか、
   「**データ不足で結果的に出ない**」のかを切り分ける

## 直し方

- **データ不足が原因**なら、1年目でも成立する形にする
  (例: 該当者がいない賞は静かに省略し、成立する賞だけで式典を行う。
  **賞が1つも無いときだけ**式典自体をスキップ)
- **意図的な除外**なら、その意図が妥当か判断できるよう**報告して指示を仰ぐ**
  (勝手に外さない)
- **不在データの説明文を出さない**というプロジェクト規約は守る
  (「該当者なし」と書かず、その賞のスライドを出さない)

**1年目からゲームの節目を体験できることが目的**。表彰式は初年度こそ
「1年やり切った」実感になるので、**空でなければ必ず出す**方向で直すこと。

# B. 契約交渉: 引き止めたのに給与が据え置き

> 4人中3人はOK。1人が交渉決裂して、その後**引き止めで160万払った**が、
> **給料は据え置き**だった。給料のことで怒ったのだから、160万で納得しても
> 給料も上がるのが普通。**それも条件として先に書かれるべき**だった。

## 原因(こちらで特定済み)

`Engine.contract.resolveNegotiation`(`src/management.js:24649` 付近)の移籍志願ブランチ:

```js
if (choiceIdx === 0 || (choiceIdx === 1 && subChoice === 'retain')) {
  fundsCost = neg.retentionBonus;   // ← 一時金だけ払う
  // salaryDelta が設定されない = 給与据え置き
```

**引き止め成功しても給与が1円も上がらない。** 昇給要求から移籍志願へエスカレートした
場合でも同じで、「金で黙らせたが待遇は変えない」という不自然な結末になっている。

## 直し方

1. **引き止めに昇給を含める。** 引き止め成功時、`salaryDelta` を設定する。
   金額は**その選手が求めていた水準**から導くこと
   (`neg.raiseAmount` / `neg.counterOffer` / 適正給与とのギャップ `gapLevel` など、
   **既にあるデータを使う**。新しい乱数や恣意的な定数を増やさない)。
   採用した式は報告に明記する
2. **選択肢に両方の条件を明示する。** 交渉モーダルの選択肢テキストに
   **「一時金◯◯万 + 給与+◯万/週」**の形で、選ぶ前に分かるよう出す
   (現状は一時金しか出ていない)。表示は `showContractNegotiationModal` 側
3. **契約更新完了の一覧にも反映される**こと
   (実機スクリーンショットの「給与変動: 3名」の一覧に、引き止めた選手も出るはず)

## 不変条件(B)

- 引き止め**失敗**時は従来どおり(退団。一時金の扱いも現行のまま)
- 昇給額は選手の要求水準に基づく(**社長が得も損もしない恣意的な値にしない**)
- 給与上限(`salaryBonus` の 100 上限)を超えない
- 既存セーブの進行中交渉が壊れない

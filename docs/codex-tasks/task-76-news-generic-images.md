## なぜ要るか

新聞の写真は**人物写真（選手のアッパー画像）が最優先**だが、
**人物が特定できない記事**がある（団体の動き・興行の告知・制度の話など）。
いまはそういう記事に写真が無く、一面に載ると**写真枠が黒く空く**。

仕様（`docs/newspaper-redesign-spec-v0.2.md` §3）で優先順が決まっている:

```
人物写真 → 汎用画像 → それも当たらなければ 小記事・短信に限定
```

この「汎用画像」が存在しないので、いまは3段目に落ちるしかない。
**一面なのに写真がない、を仕組みで防ぐための素材**。

## 出力仕様（**外すと表示が崩れる**）

- 置き場: **`image/news/`**（新規ディレクトリ）
- 形式: **webp**
- 寸法: **256 × 384（2:3）**。選手のアッパー画像と同じ土俵に載るので合わせる
- 容量: **1枚 40KB 以内**が目安（既存の選手アッパーは約10KB）
- `release/manifest.json` は **追記不要**。`"image"` がディレクトリごと登録済み

## 構図の縛り（**ここが一番外しやすい**）

紙面では次のCSSで表示される:

```css
background-size: cover;
background-position: center top;
```

つまり **左右が切られ、下が切り落とされる**。表示枠は3種:

| 枠 | 実寸 | 元画像からの見え方 |
|---|---|---|
| 一面トップ | 190 × 228 | 左右をやや切って、**上半分〜2/3だけ**見える |
| 肩記事 | 84 × 126 | ほぼ 2:3 のまま |
| 小記事 | 46 × 66 | ほぼ 2:3 のまま。**豆粒**になる |

したがって:

1. **主題を画面の上寄せに置く。** 下1/3は切られる前提で構図を作る
2. **46×66 でも何の絵か分かること。** 細部で語らない。輪郭とシルエットで分かる絵にする
3. 文字を描き込まない（日本語の看板・横断幕など）。**豆粒では読めず、汚れに見える**

## 画風の縛り

- **ゲーム本編はアニメ調のイラスト**（`image/upper/` の選手画像を必ず1枚見てから描き始めること）。
  **写実的な実写風にしない。** 同じ紙面に並ぶと明らかに浮く
- **人物の顔を主役にしない。** 特定の選手に見えると、記事と絵が食い違って嘘になる。
  人が要る場面（客席・会見場・道場）は**後ろ姿・引き・シルエット・手元**で処理する
- 舞台は**日本の女子プロレス団体**。会場は日本のプロレス会場（体育館・ホール規模）。
  海外のアリーナやスタジアム然としたものにしない
- 紙面は**クリーム色の紙にセピア寄り**で載る。彩度は控えめに、
  極端に鮮やかな色や強い発色は避ける（紙面上で浮く）
- 明暗はしっかり付ける。46×66 に落ちたときコントラストが無いと灰色の板になる

## 3枚の振り分け方

同じ絵の色違いにしない。**時間帯・距離・角度のどれかを変える**。

- 会場外観: 昼の外観 / 夜のネオン / 入り口に列
- 空のリング: 客入れ前の明るい場内 / 照明を落とした試合前 / 試合後の無人
- 満員の客席: 引きの全景 / 最前列の後ろ姿 / 二階席から見下ろす
- ベルト: 台に置かれた1本 / 吊るされた1本 / ケースの中
- 調印: 机の上の書類とペン / 握手の手元 / 判を押す手元
- 道場: マットとロープ / サンドバッグと器具 / 窓から光の入る無人の道場
- 会見場: 演台とマイクの列 / 記者席側から見た演台 / フラッシュの中の演台
- 医務室: 診察台とテーピング / アイシングの氷嚢 / 松葉杖と荷物
- トロフィー: 単体 / 表彰台の上 / 花束と並ぶ

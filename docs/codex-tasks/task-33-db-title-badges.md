## 実装するもの

全選手一覧の名前の右に、**保持中の称号**をバッジで並べる。既存2種の様式(10px・角丸2px・
薄い塗り+枠・絵文字1字)を踏襲し、色だけ大会ごとに変える。

| 称号 | 絵文字 | 色の方向 | 判定 |
|---|---|---|---|
| 王座(既存) | 👑 | gold | 現行 `_champIds` のまま |
| 春のタッグリーグ優勝(既存) | 🌸 | 桃 `#ff6f9c` | 現行 `_bestTagIds` のまま |
| ジュニアトーナメント優勝 | 🏟️ | 夏系(`--ev-summer` 相当) | 下記 |
| 秋の4団体勝ち残り対抗戦 優勝 | ⚔️ | 秋系(緋・`--ev-autumn` 相当) | 下記 |
| PPV GRAND FINAL 優勝 | 🏆 | 紫(`--ppv-accent`) | 下記 |
| 天頂戦 優勝 | ⛰️ | 白金/冬系(`--ev-winter` 相当) | 下記 |

### 判定ルール(重要 — ここを間違えると嘘の表示になる)

- **王座は「今保持しているか」**(現行どおり)
- **大会優勝は「直近大会の優勝者か」= 次の大会が開催されるまで有効**にする。
  つまり `careerRecord.history` から該当 type の champion を拾い、**その大会の最新シーズンの
  優勝者だけ**にバッジを出す(過去の優勝者に永久に付けない)。
  - ジュニア: `type:'juniorTournament'` かつ `result:'champion'`
  - 秋対抗戦: `type:'autumnWar'` かつ `result:'champion'`
  - PPV: `type:'ppvMainEvent'` かつ `isSummit && won === true`
  - 天頂戦: `type:'ppvTournament'` かつ `result:'champion'`(4年に1度なので次回開催まで有効)
- 春タッグの既存 `_bestTagIds` の判定が上記と同じ思想(直近大会のみ)か確認し、
  違っていたら**揃える**(既存の意図が「歴代全部」なら報告して指示を仰ぐ)
- 全選手(自団体・AI団体・FA・引退者含む一覧の全員)に対して同じ基準で判定する

### 表示ルール

- バッジは**保持数だけ並べる**(複数称号を持つ選手は複数個)。順序は
  王座 → 天頂戦 → PPV → ジュニア → 秋対抗戦 → 春タッグ(格の高い順)
- 絵文字だけだと意味が分からないので、**各バッジに `title` 属性でツールチップ**を付ける
  (例: `title="ジュニアトーナメント優勝(第N回)"`)。テキストは日本語、内部変数名は出さない
- 名前が長い選手で行が崩れないこと(バッジは `white-space:nowrap` で折り返さない)

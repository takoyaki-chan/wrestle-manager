## A. specs/org-ranking-spec-v2.1.md(計算側)

`src/management.js` の `Engine.ranking`(`getDepthBenchmark` / `getDepthProfile` /
`calcRosterPower` / `calcOrgRating`)と `src/data.js` の `RANKING_CONFIG` を
**必ず読んで実値を確認**すること。指示書と食い違ったら**実装が正**。

反映事項:

1. **層の厚み(Depth)の再設計**: 旧「11位以下のOVR70+/75+を人数加点」を廃止し、
   **主力層(4〜8番手・最大20点)+ 控え層(9〜12番手・最大10点)の到達度評価**へ。
   各枠を baseline→target で段階評価するため、人数を増やすだけでは上がらない
2. **評価基準の業界水準連動**(2026-07-31 追加。ここが v2.1 の核):
   固定基準(主力75/控え70)だと**ゲーム後半に全団体が上限へ張り付く**ため、
   `getDepthBenchmark(state)` で全団体トップ8平均OVRの平均を「業界水準」とし、
   主力満点 = clamp(業界水準, 下限, 上限)、控え満点 = 主力満点 − offset にスライドする。
   **カーブの幅(主力30/控え20)は固定**で基準点だけ動く。
   実測: 序盤=業界水準57→満点75(旧と同一)、後半=業界水準91→満点91。
   同じロスターでも序盤6.7/30・後半26.8/30と評価が変わる
3. **怪我人の扱いの非対称**(意図的):
   - **Depth のみ**「実戦可能度」として怪我人・強制休養・レンタルを除外する
   - **Force(コア戦力)/ Marquee(看板)は在籍ベース**(怪我人も戦力として数える)。
     怪我のたびに団体評価が週次で上下すると「格」の表現として不安定になるため
4. `depthReadyOvr`(講評文が使う「実戦級」の基準値)も業界水準に連動し、rankings に載る

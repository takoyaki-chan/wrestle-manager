## 4. アッパー画像の背景に文字が見える(バグ)

記録タブの栄冠カードで、**アッパー画像の背景にイニシャル文字が透けて見えている**。

原因: `.db-record-upper`(`src/index.html:1136` 付近)が
`font-size:52px;font-weight:900;color:var(--gold-light)` を持ち、
**画像が正常に読み込まれてもフォールバックのイニシャル文字がDOMに残っている**ため。

修正: **画像が表示されているときはイニシャルを出さない**
(画像取得成功時はテキストを描画しない or `onerror` 時だけ出す等)。
同じ作りが他のカード(PPV側・最多連続防衛の肖像)にもあれば**同様に直す**。

## 5. 選手詳細の能力バーが100で頭打ち

実際のステータスは100を超える。**団体タブのロスター詳細(`src/ui-render.js:1972`)は
150目盛り**で実装済み。

**選手詳細も150目盛りに揃える**(`statDecayView(c, s.key, 100)` → `150`、
バー幅の計算 `Math.min(100, val)` も150基準へ)。
消耗で失われた天井(`lostBar`)の表示も同じ目盛りで整合させること。

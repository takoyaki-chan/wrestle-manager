### 2. 未配線SEの用途を提案し、配線する

- **既存の鳴り方と衝突しないこと**。同じ場面で二重に鳴らさない

  未配線分を無理に全部使い切ろうとしない。**用途が思いつかないものは

- 節目・演出(戴冠・引退・記録更新・大会結果など)は**印象に残る場面**なので、
  専用SEを当てる価値が高い
- 長さに注意(0.2〜0.5秒級はUI操作向き、長いものは演出向き)

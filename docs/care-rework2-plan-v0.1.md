### 1.1 「使わなくても問題ない」は実測で支持 — ただし罰は実在し、不可視なだけ

計測: auto-sim改(scratchpadコピーにケア自動実行フックを注入)、3シード×20季×ケアon/off。

| 指標 | ケアなし | ケアあり | 差 |
|---|---|---|---|
| 平均信頼 | 76.5 | 84.7 | +8.2 |
| 突然退団+移籍志願(20季) | 2.33件 | 0件 | — |
| 平均士気 | **45.5**(60未満が97.2%の週) | 59.6 | +14.1 |

- **信頼はブッキングで飽和する**: カードに乗っている限り平衡点84.6(メイン89.9/メイン+タイトル94.3)。会場の試合枠がorgPopと連動して伸びるため、ロスターが枠を超える週は3.5〜8.6%しかなく、noAppearStreak=0が91.7%。**「信頼60未満」で開くボーナス書類は対象を持てない**。平衡点を70未満に落とせるのは構造的不満(G1給与不公平/G2後輩高給/G3タイトル渇望)だけで、これはケア書類の管轄外(昇給・起用の問題)。
- **士気の罰は毎週発火している**: 慢性45.5により成長ロールゼロ化(選手週の3.43%)・コンディション回復×0.897・スランプ/モチベ回復×0.857・23%の週で信頼追加侵食。士気の敵は1位=興行の平均MQ、2位=憎い敵ペア(毎週発火)で、**平均回帰は興行週しか走らない非対称**が平衡を45に固定。
- **可視化の断絶**: エンジンは慰労会を92%の週で正しく机に出しているのに、道場の雰囲気テキストは80.7%の週でL3「特に変わった様子はない」。士気の実効レンジ41〜62に対しテキスト段階が0-100均等割りのため、L4はケアなしで7.9%、**L5(81+)と「good」トーン(70+)は実測到達率0.00%=到達不能**。trust系も、バッジ「💭よそよそしい」は40未満/ボーナス発動条件は60未満で**40〜60帯は画面上のどこにも出ない**。
- **金は判断材料ではない**: ケア0でも資金は20季で5,000万→45.7億(91倍・単調増加)。S5以降は全書類が誤差(最上位の破格ボーナスでもS12資金の1.4%)。真の通貨は決裁枠⚡(+2/4週・上限6・年30)だが、社長室の決裁タブ以外に表示がなく、**上限到達で毎季枠を捨てていることも通知されない**。
- **match-engineはtrust/morale/conditionを読まない**(trust<35のMQ実効-3のみ)。体調系ケアの説得力の細さは構造的(care-rework当時から)。
- 声かけ(無料・⚡0・CD1週)がボーナス(有料・⚡1・CD4週)の下位互換として常設。休暇辞令は休暇中も「欠場ペナルティ」を受けるため**信頼収支が赤字**(trust50で4週休暇=差引-2.45)。

### 1.4 高津小春・出羽鷹子の「不機嫌」の正体

「不機嫌」という状態変数は存在しない。不満系イベントの**発生確率にpersonalityは一切効かず**、統制実験(同格8名・42シード×8季)で高津は8人中6位=むしろ安定側、出羽は2位だが1位はnormalの阿武隈。**体感を作っているのは確率ではなく「文面」と「治し方」**:

1. **bold(強気)=怒りの語彙**(127名中24名)。同じtrust低下でも非boldは「落ち込む」、boldは「怒る」。これはトーンバイブルのアンカー通り(高津=標準×強気 / 出羽=ヤンキー×強気)の**意図された個性**。
2. **声かけ(encourage)がbold全員に倍率0.70**→「💤あまり響かなかった」が**100%確定**。最も押されるボタン×最も効かない性格の交差。実効+0.55は不出場1回(-1.4〜-2.2)すら取り返せない。
3. **ボーナス最安案(×0.5)はプライド選手(bold/ojousama)に100%侮辱帯**(非プライドは0%)。警告メモは出るが読み飛ばすと確実に逆ギレ。逆に非プライド選手には下振れが事実上存在せず(全体0.84%)、4案は学習後ただの予算スライダーになる。
4. **高津のみ**: te47+晩成+S級確定配置→実効OVRが伸びず低給のまま加齢→**G2(後輩が高給)が興行の41.5%で恒常発火(124名中2位)**+反骨心の契約不満+0.20+直談判型。出羽にはこの構造なし(79位)。
5. **2人とも初期ロスター/ドラフトで入手不可→引き抜きのみ**。引き抜きはtrust<75しか成立せず、trustは持ち越し(実セーブでは高津41.3のまま加入)→**加入初週から不機嫌帯**。

判定: **バグではなく設計の交差点**。①は守るべき個性、②③は「boldに効くチャンネルがケア側に存在しない」設計の穴、④は素データ由来のドラマ(潰すか活かすかは判断事項)、⑤は仕様。

## 2. 診断 — 何が壊れていて、何が壊れていないか

**手直しの方向は系統ごとに全く違う。ここを混ぜると失敗する。**

| 系統 | 診断 | 手直しの軸 |
|---|---|---|
| 信頼系(bonus/party/声かけ) | **罰は実装済みだが発火しない**。ブッキングで平衡84.6に飽和し、リアクティブ書類は対象を持てない | 罰の強化ではなく**役割の置き直し**(§3.3)。「出場していれば信頼が育つ=カード編成が主レバー」は社長の仕事として正しい設計であり、壊すべきでない |
| 士気系 | **罰は毎週発火しているが完全に見えない** | **可視化**(§3.2)。数値を見せず、テキスト段階と閾値を実効レンジに較正 |
| 育成系(trainer/camp) | **道具が丸めで物理的に死んでいる** | **丸め修理**(§3.1)が全ての前提。修理なしに市場をいじっても無意味 |
| 消耗・体調系(refresh_leave/special_treatment) | **元からケアで管理する設計になっていない**(conditionは試合に不参加、無料休養が上位互換、wearの桁が合わない) | 役割の振り切り(§3.3) |
| 招聘市場 | バグ+ニーズ無視+母集団の穴 | バグ修理→ニーズ接続(§3.4) |
| bold/高津・出羽 | 個性は正しい。**「効くチャンネル」の欠落**が問題 | 性格別ケア設計(§3.3) |
| 経済 | 金が拘束でない(特別大会収益+使い道の不在) | **D-3から切り出し推奨**(§3.5) |

CLAUDE.mdの魂に照らした総括: ケア書類は現在「数値操作にすら見えない(効いたかどうかも見えない)」状態。再設計のゴールは「**社長が選手の異変に気づき、その子に響く手を選び、応えた結果を覗き見る**」ループの再建であり、数値を盛ることではない。

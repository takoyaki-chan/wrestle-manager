## 1. 何であるか（体験）

団体王座の上に、**業界全体の頂点**を象徴するベルトを1本だけ新設する。
4年に一度の天頂戦の優勝者に授与され、次の天頂戦までの4年間、
**防衛・移動・奪還の物語**を業界全体で紡ぐ。

- ベルトは**団体ではなく選手個人に付く**。奪われれば奪った選手のものになり、その選手の団体へ渡る
- 社長の関与は「挑戦が来る（受ける舞台を整える）」「こちらの番が来たら挑戦者を選ぶ」の2点。試合そのものには介入しない
- 天頂戦覇者の称号（記録と名誉のみ）とは別物。**ベルトは現在進行形の緊張を作る**

## 2. 確定要件（Keisuke 2026-08-12）

1. 天頂戦の優勝者に授与する
2. 授与後は**3か月に一度**、通常興行週かつ王者が試合出場可能な状態のとき、他団体から挑戦される
3. 挑戦者は挑戦側団体の**OVR1位から差4以内**のキャラ。上位ほど少し確率が高い。**どの団体から来るかも上位団体ほど確率が高い**
4. 奪われたらベルトはその選手に移る。奪われた場合、**挑戦3回分（約9か月）後に今度はこちらから挑戦する選手を選ぶ**
5. 保持選手が引退したら**返上**され、次の天頂戦まで空位
6. 天頂戦が来るとベルトは自動で返還される。**天頂戦の前に「ベルト返還イベント」を追加**する

## 3. ライフサイクル（状態機械）

```
[未創設] --第1回天頂戦(導入後最初の season%4===0)--> [授与]
[授与/保持中] --四半期ごとの防衛サイクル--> 防衛成功(defenses+1) / 奪取(保持者・所属が移る)
[保持中] --保持選手の引退--> [空位](次の天頂戦まで)
[保持中] --天頂戦年のW47 返還イベント--> [返還保留] --W48 優勝者--> [授与]
[返還保留] --大会不成立(出場者不足)--> 前王者が保持継続(空位にしない)
```

- **周期の単位は四半期（12週）**。「3か月に一度」を quarter に対応させ、各四半期に最大1回の挑戦イベントが発生する
- 天頂戦年のQ4（返還〜大会）は防衛サイクルの対象外
- 王者がその四半期に出場不可（負傷・レンタル等）なら**その回はスキップ**（持ち越さない。次の四半期に改めて抽選）

## 4. 防衛・挑戦サイクル（設計案）

### 4.1 挑戦の向きは3態

| 保持者 | 挑戦者 | 試合の場 | 実装の下敷き |
|---|---|---|---|
| プレイヤー団体 | AI団体（団体→選手の2段抽選） | **自団体の次の通常興行**に予約として挿入（メイン枠） | B3挑戦状 `_pendingIncomingB3Match` と同型 |
| AI団体 | 別のAI団体 | AI週次処理内でシミュレート・新聞記事化 | AI間B3 `processAIB3Challenge` / `aiChampionChange` と同型 |
| AI団体 | **プレイヤー団体（こちらの番）** | 挑戦者を選んで**相手団体へ遠征** | 遠征 `_pendingAwayChallengeMatch` + 奪還 `_pendingReclaim` の折衷 |

**原則: 挑戦する側が乗り込む**。AIがプレイヤー王者に挑むときは向こうが来る、こちらが挑むときはこちらが行く。左右対称。

### 4.2 挑戦者の選定（確定要件3の実装形）

1. **団体の抽選**: 業界ランキング（`G.rankings`）から王者所属団体を除き、順位の重み減衰で1団体を選ぶ（`Engine.rng.weighted` + `Math.pow(decay, rank)`、AI王座挑戦者抽選 `AI_TITLE_CHALLENGER_CFG` と同じ形）
2. **選手の抽選**: その団体のOVR1位から**差4以内**（負傷・レンタル除外）を候補プールにし、OVR上位ほど重い抽選
3. 具体的な減衰係数などの数値は実装回に較正する（本提案では形だけ確定）

### 4.3 「こちらの番」の管理（確定要件4の一般化）

- プレイヤーがベルトを失った時点から**挑戦サイクル3回を経過した次の回**が「こちらの番」。その四半期はAI団体の抽選を行わず、プレイヤーが自団体ロスターから挑戦者を選ぶ
- こちらの挑戦者にも同じ資格ルール（**自団体OVR1位から差4以内**）を適用する（AIと対称。格の説得力を守る）
- 挑戦を見送る/敗れた場合は、次の「こちらの番」がまた3回後に巡る（輪番）

## 5. 裁定待ち論点（8件・各推奨付き）

| # | 論点 | 推奨 |
|---|---|---|
| ①| **AI保持中、AI団体間でもベルトは動くか**。「3回後にこちらの番」の3回を、AI同士の挑戦(奪い合いあり)で埋めるか、それとも9か月ただ待つだけか | **AI間でも動かす**。ベルトが業界を旅するほど新聞と物語が濃くなる(`aiChampionChange`の上位版)。プレイヤー不在でも世界が生きて見える |
| ② | **プレイヤー王者への挑戦は断れるか** | **断れない**(統一王座の宿命として強制)。ただし王者が出場不可の四半期は自動スキップ(確定要件2の「出場可能な状態の時」)。断る自由を作ると防衛回避ペナルティの設計が別途要り、重い |
| ③ | **王者への常設バフの有無** | **選手への数値バフなし**(天頂戦覇者と同じ「記録と名誉」哲学)。ただし統一王座戦そのものはタイトル戦扱い(MQ+・リング内効果・集客ボーナス)で、通常の団体王座戦より一段大きい扱いにする。人気は戴冠/防衛時に逓減加算(既存 `crownChampion`/`recordDefense` と同じ形) |
| ④ | **プレイヤーの挑戦の場**(こちらの番のとき) | **相手団体へ遠征**(§4.1の対称原則)。既存の遠征演出 `showTravelScene` を流用できる |
| ⑤ | **返還イベントのタイミングと不成立年の扱い** | 演出は**W47(エントリー週)**に返還式イベント。データ上の移動は大会確定後の `apply()` 内でのみ行い、**出場者不足で不成立の年は前王者が保持継続**(4年空位の事故を作らない) |
| ⑥ | **統一王者の天頂戦自動エントリー** | **自動エントリー**(団体王者が枠選出で先頭に差し込まれる既存仕様と同型)。優勝すれば連覇 |
| ⑦ | **引退以外の保持者異動**(移籍・引き抜き・FA化・解雇) | 移籍・引き抜きは**ベルトごと新団体へ移る**(選手個人に付く原則)。**無所属(FA)化と解雇は返上→空位**(防衛戦の舞台が組めないため)。引退と同じ整合フックで処理 |
| ⑧ | **ゲーム内名称** | 候: **「全国統一王座」**(Keisukeの呼称そのまま)。ベルトに「世界」を冠しない方針(2026-07-16)とも整合。エンブレム/ベルト画像は後日Keisuke制作(天頂戦エンブレムと同じ流れ) |

補足(裁定不要・設計メモ):
- 既存セーブへは**遡及授与しない**。導入後最初の天頂戦から創設し、新聞で「新王座創設」を告知する
- 団体王座との両立は可(同一選手が団体王者かつ統一王者になれる)。ただし**1興行1タイトル制約**(`sanitizeShowCardTitles`)には統一王座戦も参加させる(同じ興行に団体王座戦と統一王座戦は同居しない)
- 殿堂ポイント・年間表彰への加点はP4で別途設計(天頂戦優勝8ptとの二重取りに注意)

## 7. 不変条件（auto-sim検証項目・実装時にテスト化）

1. `unifiedTitle.championId` が非nullなら、その選手は**必ずいずれかのロスターに現存**し、引退済みでない
2. `unifiedTitle.orgId` は常に保持選手の現所属と一致する
3. 空位になるのは「引退/FA化/解雇による返上」「未創設」のみ。天頂戦成立年のW48以降は必ず新王者が立つ（不成立年は前王者継続）
4. 挑戦イベントは1四半期に最大1回。天頂戦年Q4には発生しない
5. 統一王座戦の予約は他の予約試合（CR/B3/F09/Common-1/奪還）と同一興行で衝突しない（`hasCompetingBooking` 経由）
6. `defenses` はベルト移動で必ず0リセット
7. 挑戦者は常に資格ルール（所属団体OVR1位から差4以内・負傷/レンタル除外）を満たす

## 9. セーブ互換

- lazy-init（`unifiedTitle: null` を `createInitialState` に追加・読み口は全て null 許容）。明示マイグレーションフラグなし（title-system-spec §X の規約どおり）
- 進行中セーブでは次の天頂戦から自然に創設される（遡及なし）
- 予約フィールドは期限切れ自動回収（`releaseExpiredAwayBooking` と同型）とロード時修復（`saveDoctor.repairOnLoad`）を対で入れる

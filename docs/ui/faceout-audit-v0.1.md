## 直す順番の提案

Keisukeの決定を前提とした提案である。

1. 毎週使う興行準備（シングル/タッグ）と興行結果共通（通常・解決済み・タッグ）を先に共通部品へ寄せる。顔の切れと§2-B違反が同時に多く、閲覧頻度が最も高い。
2. 試合エンジン（シングル/タッグ）の吹き出し下置き・重ね表示、及びタッグ群表示を直す。プレイヤーが試合中に最も大きく見る箇所で、高違反が集中する。
3. Glimpse、交渉、契約更改、社長室スカウト、年代記の「52px超face」を、主役度に応じてupper/stand/fullの梯子へ移す。
4. 春タッグ・秋対抗戦の優勝群を§2-Bの群外枠、18px重ね、drop-shadowへ統一する。
5. PPVは task-46 の対応中範囲を優先して完了させ、残る速報/頂上決戦の梯子外値だけを同タスクの完了後に再確認する。

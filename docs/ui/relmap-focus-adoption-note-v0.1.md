# 相関図フォーカス画面 採用メモ v0.1

## 決定事項

相関図の `フォーカス` 画面は、モック `A: Spring Ring Focus` を仮採用し、単独実装対象とする。

対象モック:

- `docs/ui/mockups/relmap-focus-layout-concepts-v0.1.html`
- `A: Spring Ring Focus`

## 採用する考え方

- 中心選手を固定し、関係者を中心から十分に離したリング状に配置する。
- ノードはドラッグ可能にし、離すと読みやすいホーム位置へ弾性的に戻る。
- 顔同士、名前、線、数値ラベルが近づきすぎないように最低距離を確保する。
- 信頼度は `中心 -> 相手` と `相手 -> 中心` の双方向値として見せる。
- ライバル心も `中心 -> 相手` と `相手 -> 中心` の双方向値として見せる。
- 信頼度 `41〜59` は中立域として扱い、線やフォーカス対象としては表示しない。
- ライバル心 `30未満` は関係なしとして扱い、線やフォーカス対象としては表示しない。
- フォーカス画面に出す関係者は、上記しきい値を超える信頼/不信、ライバル心、または因縁タグを持つ相手に絞る。
- 因縁や王座因縁などの特別な関係は、通常の信頼/ライバル線とは別にタグとして表示する。
- 所属団体は抽象的な `自団体/他団体` ではなく、実ゲーム内の団体名で表示する。
- プレイヤー団体、皇武館、ノヴァインパクト、春日野プロレスなど、団体ごとの色やリング表現で判別できるようにする。

## 実装時の注意

- フォーカス画面の採用方針であり、全体ネットワークや団体フィルタの採用案とは別扱いにする。
- 全体ネットワーク側の検討で別案が出ても、フォーカス画面はこの `Spring Ring Focus` を基準に進める。
- 常時すべての数値を濃く出すと情報量が多いため、通常表示とホバー/選択時表示の濃淡は実装時に調整する。
- 物理挙動は「自由に動かせるが、見やすい形へ戻る」ことを優先し、完全な自由配置よりも可読性を重視する。

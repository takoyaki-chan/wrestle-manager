## 目的

4年に一度の最高峰トーナメント「天頂戦」の進行体験一式。エントリー発表 → 16名ブラケットの勝ち上がり観戦 → 優勝演出 → 関係性ドラマまでを、JTクライムラインの上位互換として見せる。

## 遷移

- **入ってくる経路**：Week 48 PPV開始（トーナメント年のみ。通常年は既存PPVフロー）。エントリーは Week 43〜44 の既存PPVエントリーフローの変形
- **出ていく経路**：優勝演出 → 表彰/リザルト → オフシーズンへ（既存PPV終了フロー準拠）
- **戻る挙動**：進行中は戻れない（S1/S4と同じ一方向シーケンス）

## 構成要素

- **クライムライン**: JTの jtc-* 一式を流用し `--jtc-color: var(--gold)` で色替え。新規差分のみ tc-* 系クラスで追加
  - 段別画像文法（確定）: 1回戦・準々=丸アイコン / 準決勝以上=JT準拠 2:3 矩形（md/lg/peak）。勝者=大会色下ボーダー / 敗者=モノクロ
  - 次戦セルに「▶ 次戦 — 未決着」赤タグ（モック v0.3 準拠）
  - 1回戦8セル: 縮小8列 + モバイル横スクロール（🔧 実装時に2段折り4+4と比較して最終判断）
- **フォーカスカード**: JT `_jtFocusCard` 改。スタンド対面 → **アッパー画像対面(非反転)** に差し替え。開始HPに持ち越し注記
- **優勝演出**: JT頂上せり上がり → 優勝画面（エンブレム+冠2段+2:3矩形金枠+称号線「第N回 天頂戦 覇者」+CSS光条）
- **関係性ドラマモーダル**: 大会終了後、`G.ppvTournament.dramaEvents`（0〜2件）を1件ずつ表示。頭上白吹き出し（fc1m-bubble 文法）+ 関係変化チップ（因縁=深紅 / 絆・好敵手=金）。0件なら何も出さない（不在の説明も出さない）
- **エントリー画面**: 既存PPVエントリーUIの変形。特別招待2名（ランキング1位/人気1位）の発表ブロックを先頭に置き、団体枠5/4/3/2の選択は既存準拠

## 情報階層

1. 頂上（覇者/空位クレスト）
2. 現在の段と次戦セル（赤パルス+次戦タグ）
3. フォーカスカードの対面と開始HP
4. 決着済みセルの勝敗・MQ
5. ヘッダーの大会アイデンティティ（エンブレム/冠/天頂戦）

## 特有ルール

- **アッパー画像は左右反転禁止**（全画面共通。反転はスタンド画像のみ）
- 左右対置の開始HPバーは同色・右側ミラー（UI原則9/10）
- 進行文法（勝者確定→上段せり上がり・一度きり出現アニメ・全試合スキップ）はJT実装をそのまま流用

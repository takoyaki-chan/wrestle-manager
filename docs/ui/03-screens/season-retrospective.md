## 背景・なぜ作り直すか

現状のシーズン終了レポートは、オフシーズン週画面（`renderWeekScreen` の `weekPhase==='offseason'` かつ `offWeek<=1`）に出る `📊 シーズンN レポート` カード1枚（[src/ui-render.js:592-637](src/ui-render.js:592)）。数値グリッド＋gameLog 文字列フィルタ＋ランキング表のみの決算書状態で、「誰が輝き、誰が沈み、どの試合が語り草になったか」が見えない（Keisuke 指摘 2026-07-08）。

### 確定した方向（2026-07-08 Keisuke 承認・モック v4 確定）

この画面は**オフシーズン最終盤に流れる締めの1枚＝表彰式の続き**であり、日常の Office 画面ではない。ただし式典そのものでもなく、**「1年の結果を固く提示する年次記録（ANNUAL RECORD）」**。

- **寒色ダーク（紺黒）＋金**。日常 Office の暖茶/Cream からも、暖色リッチからも離れる（暖色は不採用と明示指示あり）
- **角の立った証書様式**：角丸ゼロ、金の二重罫＋コーナーティック、明朝（Noto Serif JP）＋ Cormorant Garamond
- **メリハリ**：主役は HERO の1人だけ。大きなスタンド画像の額装は HERO のみ。§I 以降の人物画像は小さく
- 数値はグラフでビジュアライズ。ナレーションは最小限・黒田トーンだが**署名「本紙 黒田」は出さない**

**確定モック**：`docs/ui/mockups/season-retrospective-ceremony.html`（画像は base64 埋め込み済み・これが唯一の正）。

### 既存のシーズン末ビートとの棲み分け

1. **年末新聞** — 世間の視点でシーズンを報じる
2. **年末表彰式（Ceremony）** — 賞の発表演出
3. **本画面** — 表彰式の余韻のまま、自団体の1年を「公式記録」として固く提示する

本画面は 1・2 の再演ではない。受賞結果は「自団体が何を獲ったか」の記録として引用するのみ。

## 目的

社長がオフシーズン冒頭に、自団体のこの1年を**公式記録**として受け取る。誰が主役だったか（HERO）、何が記録に残ったか（§I）、経営はどう動いたか（§II グラフ）、顔ぶれはどう変わったか（§III）、業界の中でどこに立っているか（§IV）。数値は嘘をつかず、演出がそれを1年の物語として固く提示する。

---

## 遷移

- **入ってくる経路**：年末新聞 → 表彰式（Ceremony）→ オフシーズン週画面（`offWeek` 0〜1）
- **出ていく経路**：末尾「ドラフト会議へ」ボタン → `advanceWeek()`
- **戻る挙動**：なし（週進行は不可逆。その週に一度じっくり読む体験）

## データ源（すべて実データ・捏造しない）

| 要素 | 取得元 |
|---|---|
| 最終順位＋前年比 | `Engine.ranking.updateRankings(G)` 再計算 + `seasonHistory[last].rank` |
| 見出し語（銘板） | 複数条件の組み合わせ判定（下記） |
| HERO 主役 | MVP（`pendingAwards`/`lastAwards` の自団体分）。**自団体 MVP 不在年は自団体 OVR トップ or 最多出場者へフォールバック** |
| §I 記録カード | 新人王・タイトル王者・JT優勝・メディア功労賞のうち**自団体該当分のみ**（0件ならセクションごと省略）。**ベストマッチは出さない**（2026-07-08）。**勝敗記録（勝率）は出さない**（同） |
| 団体人気の歩み | `seasonHistory[].orgPop` + 現在値。**旗揚げから**（10年超は直近10年ローリング） |
| 資金の推移 | `G.fundsHistory`（**今季内**の週次を間引き）。**資金は旗揚げからにしない**（2026-07-08 Keisuke：1年の変化でよい） |
| 今季の収支 | `seasonStats.totalRevenue/totalExpense` 横バー＋純益 |
| 引退者 | `retiredFighters`（今 season）。**セリフは載せない**（引退ポップアップの領分） |
| 加入者 | 今季加入（careerSeasons===0 / gameLog） |
| 最も伸びた/陰りの見えた | `roster[].seasonGrowth` 合計の最大/最小。**陰りは毎年実名で名指しする**（2026-07-08 確定・婉曲や間引きをしない） |
| ランキング | `Engine.ranking.updateRankings(G)` 全団体 |

**見出し語の判定例**（実装時に閾値確定・単純加減算にしない）：
- 順位上昇＋黒字＋受賞複数 → 「飛躍」 ／ 順位維持＋収支均衡 → 「地固め」 ／ 順位下降 or 赤字 → 「雌伏」「試練」 ／ 大量引退 → 「世代交代」 ／ タイトル奪取 or 年間1位 → 「戴冠」
- 銘板は漢字2文字程度に凝縮した一語

## 情報階層・メリハリの原則

1. **HERO**（主役の大スタンド額装＋銘板＋順位）— この画面で大きいのはここだけ
2. **黒田トーンのリード文**（署名なし）
3. **§I 記録**（小型横カード。人物はアッパー画像 92px 幅）
4. **§II グラフ**（金オン紺黒の折れ線・バー）
5. **§III 顔ぶれ**（小サムネ台帳行）
6. **§IV ランキング＋締め**

**主役以外を大きくしない。**均一なカードの積み重ねにしない。

## 特有ルール

- **画像**：HERO＝`getStandUrl(id, ovr)` 全身、§I・§III＝`getUpperUrl(id)` バストショット（全身を小枠で切ると頭が切れるため）。`object-position` は顔基準（モック準拠：§I カード `center 12%`）。画像無しはグラフィック背景/emoji フォールバック
- **チャートは dataviz 準拠**：単一系列＝ゴールド1色・凡例なし、線 2.5px・最新点マーカー強調、低コントラストグリッド、dual-axis 禁止（人気と資金は別カード）。ランキングは自団体のみゴールド強調
- **ナレーションはテンプレ禁止・キー選択制**：エンジンが条件分岐でキーを選び、文面テーブル参照。**本文の確定文面は Phase 3 で Opus 4.6 執筆＋Keisuke 全文レビュー**。Phase 1 は事実ベースの仮文でスロットのみ
- **該当データが無い枠は静かに省く**（「該当なし」を書かない）
- **前年比矢印・人気推移チャートは 2年目以降のみ**
- **内部変数名をプレイヤーに見せない**（orgPop→団体人気 等）
- **CSS はスクリーンスコープのトークンを新設**（鉄則「ハードコード16進禁止」順守）：`--sr-void/--sr-panel/--sr-panel-2/--sr-hair/--sr-hair-dim/--sr-hair-neutral/--sr-ink/--sr-ink-sub/--sr-ink-dim/--sr-grid/--sr-pos/--sr-neg` を index.html `:root` に追加（値はモックの `:root` が正）。金は既存 `--gold`/`--gold-light` を流用
- 旧セーブ・1年目セーブでも破綻しない（HERO＋§II＋§IV は最低限常に出る）

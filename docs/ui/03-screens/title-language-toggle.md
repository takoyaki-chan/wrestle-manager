### カテゴリの扱いについて（注記）

タイトル画面（`#titleScreen`）は 01-foundations.md の Office / Stage / Ceremony のどれにも正式分類されていない画面（`--title-bg:#161b21` というこの画面専用のローカル変数を持ち、Office/Stage/Ceremony いずれの背景色トークンとも一致しない）。本トグルは**タイトル画面の現行の見た目に合わせる**方針で実装し、新規に色を追加する際は既存の `.title-btn` と同じ考え方（`var(--gold)` を基準に、半透明部分はゴールドの rgba 値を流用）に揃えた。タイトル画面全体の正式カテゴリ分類は本仕様書のスコープ外（別途、階層1〜3の見直しが必要になれば起票する）。

## 目的

プレイヤーがタイトル画面から表示言語（日本語 / English）を自分で切り替えられるようにする。従来は開発者モード（Ctrl+Shift+D）経由でしか切り替えられなかった。

---

## 遷移

- **入ってくる経路**：タイトル画面が表示されるたびに常時表示（`App.showTitleScreen()` 内で毎回ハイライト状態を同期）
- **出ていく経路**：なし（画面遷移を起こさない。押すとページをリロードして同じタイトル画面に戻る）
- **戻る挙動**：該当なし

## 情報階層（視線誘導の優先順位）

1. WRESTLE MANAGER ロゴ・NEW GAME ボタン（最優先、既存のまま変更なし）
2. 言語トグル（右上に小さく常設。目立たせすぎない — 初見のプレイヤーが最初に見るのはロゴとボタン）

---

## 特有ルール

- **ラベル自体は翻訳しない**。「日本語」「English」はそれぞれの言語で固定表記（`data-i18n` を付けない）
- 現在選択中の言語は `.is-active`（ゴールド背景＋濃色文字）でハイライトする。ハイライトは `App.showTitleScreen()` が呼ばれるたびに `WM_I18N.lang` を見て同期する
- 押すと `WM_I18N.setLang(lang)` で `localStorage.wm_lang` を書き換えたのち `location.reload()` で全面反映する。**確認ダイアログは出さない**（タイトル画面には進行中データが無いため）
- 既に選択中の言語を押した場合は何もしない（無駄なリロードをしない）
- `pseudo`（擬似ロケール、開発者モード専用）はこのUIには出さない。開発者モードでのみ選べる
- UI自動走破ハーネスのスコアラーに拾われないよう、`primary` / `btn-gold` 等のクラスを持たせず、オーバーレイの外に置いている（`.title-lang-btn` は `title-links` と違いスコア対象外。onclick 関数名 `App.setTitleLanguage` は他のハンドラと衝突しない専用名にした）

## 状態バリエーション

| 状態 | 表示 |
|---|---|
| 通常 | 上記レイアウト。現在言語がハイライト |
| 空 | 該当なし（常に2択固定） |
| 読込中 | 該当なし（静的HTML、JS実行前から存在） |
| エラー | `WM_I18N` 未ロード時は `localStorage` へ直接書いてフォールバック（fail-open） |

## 関連トークン

- `--gold`（アクティブ状態の背景）
- `--bg-dark`（アクティブ状態の文字色）
- `--text-dim` / `--text-sub`（非アクティブ状態の文字色）
- ボーダー・背景の半透明色は `.title-btn` と同じ考え方でゴールドの rgba 値を流用（新規のハードコード16進カラーは追加していない）

作成: 2026-09-05(Keisuke 裁定 A-1「`WAR_DECLINE_DIALOGUE` 58本は配線して出す」に基づく)
実装状況: **実装済み(2026-09-06、P7-41、worktree agent-a6a95ed4ed56e4ab1)**。`src/ui-common.js` `_showWarDeclineReaction`/`_warDeclineContinue`。特有ルール1〜5すべて反映。観察文は候補3本のうち①を採用(候補と選定理由は `docs/worklog.md` の P7-40/41 エントリ)。実機確認は `docs/実機確認バックログ.md` 参照。
既存画面: `src/ui-common.js` の挑戦状モーダル(A型モーダル `_mdlAOpen`、`data-war-choice="accept|decline"` の2択)。本書は既存画面の全体仕様ではなく、**辞退を選んだ直後の1幕**を追加定義する。

## 基本属性

| 項目 | 値 |
|---|---|
| カテゴリ | Office → Stage 寄り(A型モーダル・dark) |
| レイアウト | 既存の A型モーダル(P5 相当)。構造変更なし |
| シーケンス | S3(対抗戦導入)の入口。辞退はここで終端 |
| データ | `data.js` `WAR_DECLINE_DIALOGUE[personality][archetype]`(相手エースの性格×アーキタイプ、参照順は他の B3 セリフ表 `WAR_CHALLENGER_DIALOGUE` と同じ) |

## 目的

今は「辞退」を押した瞬間にモーダルが閉じ、相手団体の反応は新聞・ログの1行(`war_challenge_declined`)だけ。挑戦状を突きつけてきたエース本人が、断られてどう言うかを**その場で一言**見せる。皮肉・落胆・見下しは性格で違う(58本)。「逃げた」という後味を残すのが目的で、罰則(団体評価↓/関係悪化)の数字は既に決断カードのヒントで見せているので繰り返さない。

## 遷移

```
挑戦状モーダル(2択)
   ├ 受けて立つ → 既存どおり acceptWarChallenge()
   └ 辞退 → [同じモーダル内で 相手エースの反応の一幕] → TAP → skipEvent()(既存の辞退処理)
```

- 辞退の処理(`skipEvent` と `war_challenge_declined` イベント)は**変更しない**。反応の一幕は表示だけ。
- 一幕の表示中に再度クリックされても二重に `skipEvent` しない(§5-D 鉄則2: 進行フラグ)。タイムアウトは不要(ユーザー操作待ちのみ)。

3. 一幕は**辞退のときだけ**。受諾側は既存どおり(受諾後の代表選択画面へ)。
4. 全画面セレモニー級の演出にしない(節目ではない・原則11)。モーダル内で完結。
5. 音: 既存の A型モーダルの効果音のみ。追加しない。

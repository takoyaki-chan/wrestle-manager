## 目的

4団体各3名による勝ち抜き戦を、単なる試合一覧ではなく「誰が生き残り、誰が脱落し、どの程度消耗しているか」を読みながら采配する大会として見せる。代表選出、現在の戦況、決勝前の並び替え、優勝結果を一貫した秋色の大会ブランドで接続する。

## 共通画面骨格

### A. 週35 代表編成（Office / Cream Panel）

```text
┌─ 4団体勝ち残り対抗戦 代表編成 ─────────────────────┐
│ 候補カード（上半身画像・名前・OVR・スタイル）       │
│ [選手] [選手] [選手] [選手] [選手] [選手]           │
├──────────────────────────┬───────────────────────────┤
│ 選択金枠・最大3名         │ 出場順                    │
│                           │ 先鋒 / 中堅 / 大将        │
├──────────────────────────┴───────────────────────────┤
│ 選出済み 3/3      [おまかせ編成] [この布陣で確定]    │
└──────────────────────────────────────────────────────┘
```

既存の春タッグ編成モーダルの Cream Panel、上半身候補カード、選択金枠、人数不足時 disabled を流用する。選択順を先鋒・中堅・大将へ反映し、確定前に並べ替え可能とする。

### B. 週36 大会進行（Stage / P7）

```text
┌─ 秋エンブレム / 大会名 / 現在の対戦 ────────────────┐
│ 4団体の生存・脱落・消耗、または勝ち上がりライン      │
├──────────────────────────────────────────────────────┤
│ NEXT MATCH  リング上の選手 VS 次の挑戦者              │
│                [観戦する] [結果を見る]                │
└──────────────────────────────────────────────────────┘
```

StageではトップバーとOfficeナビを非表示にし、純黒背景、秋エンブレム、緋色＋金のイベント色を使用する。試合単位で勝者が残り、消耗状態が次戦へ引き継がれることを明示する。

### C. 決勝前の采配

準決勝勝者がプレイヤー団体の場合のみ、回復後の状態を見せて3名を再配置できる。相手の最終布陣は決勝開始時まで伏せ、決断の意味を残す。

### D. 大会結果

優勝団体、決勝スコア、大会MVP、最多勝ち抜き数を表示する。結果画面は大会専用ブランドのまま完結し、既存の汎用試合結果へ見た目を戻さない。

## 比較モックアップ3案

比較用HTML：[`docs/ui/mockups/autumn-gauntlet-war-ui-3patterns-v0.1.html`](../mockups/autumn-gauntlet-war-ui-3patterns-v0.1.html)

| 案 | 主眼 | 既存UIからの継承 | 長所 | 注意点 |
|---|---|---|---|---|
| **案1 布陣ボード（推奨）** | 4団体×3名の戦況把握 | 春タッグの編成カード、JTのフォーカスカード、天頂戦のStage規格 | 生存・脱落・消耗・NEXTが同時に読め、勝ち抜き戦固有の面白さが最も伝わる | 専用の4団体ボード部品が必要 |
| 案2 クライムライン | 大会群の統一感 | JT・天頂戦の縦クライムライン | 既存大会と同じ操作感で、新規実装量を抑えやすい | 各団体の残り人数と消耗の俯瞰は案1より弱い |
| 案3 リングサイド | 観戦ドラマ | 既存バトル画面の左右対面、速報バー | 「勝者がリングに残る」瞬間が最も強い | 4団体全体を把握するには補助画面または速報が必要 |

### 推奨判断

大会進行の主画面は案1を基準にし、観戦直前のフォーカス部だけ案3のリングサイド表現を取り込む構成を推奨する。案2は全面採用ではなく、準決勝→決勝の位置関係を示す小型クライムラインとして補助利用すると、既存大会との統一感を残せる。

## 状態と表示ルール

| 状態 | 表示 |
|---|---|
| 控え | 通常彩度、コンディションバー表示 |
| リング上 | 金枠または緋色発光、`RING` ラベル |
| 脱落 | 低彩度・低輝度、`OUT` ラベル。カード自体は消さない |
| 元気 | 緑系バーと短い文言 |
| 疲れが見える | 黄系バーと短い文言 |
| 消耗が大きい | 緋色バーと短い文言 |
| 次戦 | 対戦者2名を中央フォーカスカードへ表示 |

数値だけでなく短い日本語を併記し、色覚だけに依存しない。脱落者も履歴として残し、「誰を倒してここまで来たか」を読めるようにする。

---

## 実装時の受け入れ条件

- 代表は出場可能選手から3名を選び、先鋒・中堅・大将を確定できる
- 3名未満では確定できず、未編成で週を送ると自動編成される
- 全4団体について残り人数、各選手の生存／脱落、消耗状態が確認できる
- 現在の対戦者と次の操作（観戦／結果確認）が一画面で判別できる
- 決勝前の並び替えは準決勝を勝ち上がったプレイヤー団体にだけ表示される
- 大会結果に優勝団体、決勝スコア、MVPを表示する
- OfficeとStageを同一画面内で混在させず、Stage中は通常ナビを隠す
- 1024px幅で横スクロールを発生させず、キーボードフォーカスを視認できる

## 目的

追い込み(⚡)の熱量は今、**道場コーチの観察**(`HEAT_STATE_COACH_LINES`)としてだけ語られる。本人がどう感じているかを、練習中の立ち姿の頭上に**一言**で見せる。数値(_heat・倍率)は一切出さない。「体が軽い / 効きが薄い / 重い」の3段を、コーチの客観と本人の主観の2方向から読ませる。

## 遷移

なし。今週タブを開いたときに描画される。吹き出しの選手をクリックすると既存どおり選手ポップアップ(`showFighterPopup`)。

```

│                                    (顔34)[休憩の一言]  │ ← 既存の休憩中(右下)

```

- 本人セリフは**練習中の選手の1人**の頭上。休憩中(右下)の吹き出しとは別枠で、**同じ週に両方出てよい**(別の選手)。
- 吹き出しは画像の「上」。名前・所属は吹き出しに書かない(`title` 属性と選手ポップアップが担う)。

## 情報階層(視線誘導の優先順位)

1. コーチ吹き出し(既存・最上段)
2. **本人セリフ吹き出し**(練習中の列の上・1つだけ)
3. 練習中の立ち姿
4. 休憩中の一言(右下)

## 特有ルール

1. **1週に最大1つ**。複数出さない(スポットライトは巡る)。
2. **出す条件と頻度**(草案 §7-4 の前提を採用):
   - `heavy` の選手がいれば**必ず**その1人(複数なら最も _heat の高い1人)。その選手が練習中の列にいなければ**列に割り込ませる**(`picked` の先頭に強制追加、上限人数は超えてよい)
   - `heavy` がいなければ、練習中の列から `warm` の選手を 30% で1人
   - それも無ければ、**練習週(追い込み可能な週)に限り** `fresh` の選手を 20% で1人
   - 乱数は `Engine.rng.derive(G.rngSeed, season, week, fighterId, 0x48534C46)` で週固定(リロードで変わらない)
3. **コーチ吹き出しとの重複回避**: コーチが今週その選手の熱量を語っている(`heatFighter` と同一)場合、本人セリフは**同じ選手には出さず**、条件2の次候補へ回す。候補が無ければ出さない。「将来のツケ(strain)」と「今週の効き(heat)」を同じ週に同じ選手で言わせない(草案 §7-5)。
4. 怪我中・休暇中・レンタルは対象外(練習中の列の既存フィルタに従う)。
5. 文言はセリフのみ。「◯◯は」の主語や名前を吹き出しに足さない。
6. 言語: JA/EN とも台帳経由。`test/heat-lines-test.js` の「選手詳細へ戻さない」ガードは**選手詳細ポップアップへの配線を禁じるもの**であり、道場シーンは対象外。実装時にガードの文言を「道場シーン以外へ戻さない」に改める。

## 道場シーンの吹き出しの共通規則(2026-09-26 追記)

休憩中の吹き出しの4行化(Keisuke 裁定・案A)に合わせて、道場シーンの3つの吹き出しを見直した。同日、コーチと熱量の本人の吹き出しも広げた(Keisuke 裁定「広げる」)。

| 吹き出し | 幅 | 行数 | 出る表と、切れていた本数(広げる前 → 今。JA / EN) |
|---|---|---|---|
| コーチ `.dojo-scene-bubble` | **210px**(旧190) | **最大4行**(旧2) | COACH_VOICE_REPORT_LINES 184本 JA 101→0・EN 104→0 / HEAT_STATE_COACH_LINES 21本 JA 9→0・EN 12→0 / 報告の無い週の ATMOSPHERE_TEXTS 33本 0→0(`{name}` は表示言語でいちばん幅の広い名字 JA「シュタインフェルト」・EN「Tsubakiyama」で数えた)。予約枠は下限40pxで上へ伸びる。4行になるのは長い名字の入った最長の報告だけ |
| 熱量の本人 `.dojo-heat-bubble` | **160px**(旧150) | **最大3行**(旧2) | HEAT_STATE_SELF_LINES 75本 JA 37→0・EN 49→0。横に広げず行数で受ける(練習の列の幅をほとんど変えない) |
| 休憩中の選手 `.dojo-rest-bubble` | **200px** | **4行** | 2026-09-26 に150px・2行から広げた(mockup-baseline §3 の例外)。道場に出る全1,365本(GLIMPSE_A/B GL-01〜11・引き留めの表)が JA/EN とも切れない |

- 幅の決め方(休憩中と同じ): 表の全行を実UIに流し、N行に収まる最小幅を Noto Sans JP・Meiryo・Yu Gothic・Arial・Segoe UI で測って、最大に余裕を足した。コーチ4行の最小は JA 192px・EN 166px、熱量3行の最小は JA 137px・EN 151px(Meiryo)
- 共通の見た目: クリーム地(`--office-panel-cream-card`)・黒文字(`--cream-text-main`)・11px・行間1.35・角丸 `--radius-lg`・尻尾は吹き出しの水平中心(=下の顔の水平中心)
- **行数の打ち切りは本文 `<span class="dojo-bubble-text">` に掛ける**。以前は吹き出し本体に `overflow:hidden` を付けていたため、3つとも尻尾(`::after`・bottom:-6px)が切れて見えていなかった
- バナーの画像は `min-height:156px`(幅が狭いと 6:1 の画像は背が低くなり、コーチの群(4行の吹き出し+顔+名前 約140px)・休憩中の群 約108px の上端が切れるため。旧136px)
- **熱量の吹き出しと隣の顔の間を14px空ける**(列の端の側は空けない)。隣の選手の掛け声(顔の中心に置く・最大幅約75px)が吹き出しの端に掛かっていた(広げる前から、どの幅でも。検査を足して見つけた)
- コーチ不在時の雰囲気の文(`.dojo-scene-atmosphere`)は幅210px まで(コーチの吹き出しと同じ列)。英語の長い一文が約330px に伸び、熱量の本人が列に割り込んだ週に列の顔へ掛かっていた
- **幅820px以下**では画像を背景に敷き、コーチ・練習中の列・休憩中の選手を流し込みで並べる(入りきらなければ折り返して下へ)。切り替えは旧760px。コーチの吹き出しを広げたぶん、横並びでは「端10+コーチ210+余白」と「列の半分約160+端の顔の掛け声のはみ出し約18」がバナーの半分に収まる必要がある(821px=バナー797px の横並びで重ならないことを検査で確認。旧760pxの切り替えのままだと、761px でコーチの吹き出しと熱量の吹き出しが重なる)。流し込みの練習の列は左右に20px(掛け声のはみ出しの分)を持ち、スマホ幅で「熱量の吹き出し+顔3人」が1行に入らないときは列を折り返す。すべてが最大になる週のバナーの高さは 761〜820px で約270px、360〜375px で約460px(旧 約350px)
- 休憩中の選手は1人だけ(`DOJO_REST_MAX = 1`)。4行の吹き出しで2人を縦に積むとバナー(最大200px)に収まらない
- **休憩中の枠の地の文**: GL-12「第三者の証言」(tone `narration`、話者のいない文)は吹き出しにせず `.dojo-rest-narration` で出す — 雰囲気の文と同じ見せ方(塗りなしの斜体の文字)・顔なし・鉤括弧なし・幅200px 右寄せ・休憩中の吹き出しと同じ22秒周期。以前は当事者の一人の頭上の白い吹き出しに鉤括弧付きで出ていた(mockup-baseline §3「地の文は吹き出しにしない」とずれ)
- 検査: `node test/ui-walkthrough/dojo-rest-bubble-fit-check.js`(手動実行・約5分。JA/EN × 1920〜360px × 4つの場面(コーチ+列4人の先頭に熱量/コーチ+3人の列の真ん中に熱量/コーチ不在+熱量/列なし)で、3つの吹き出しと GL-12 の地の文・雰囲気の文の全行について、切れ・バナーからのはみ出し・要素どうしの被り(掛け声はいちばん幅の広いもの)・尻尾を機械確認)

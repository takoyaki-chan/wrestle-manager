## 目的

ゲーム開始前に、全127名の能力基準値とプロフィールを閲覧できる名鑑。**潜在能力値はどの形でも見せない**(開発率などpot派生の表示も含めて)。ソート・検索の作法はゲーム内データベースと同一にし、本編で同じ画面に再会する感覚を作る。

## データの前提(最重要)

- タイトル画面時点ではセーブデータ `G` が存在しない。**`ALL_CHARS` + `CHAR_PROFILES` + `PORTRAIT` + `TRAIT_DEFS` の静的データのみで完結**させる(既存 `showFighterPopup` は流用不可)
- 表示する値: 名前 / 身長 / スタイル / ロール / 能力基準値5種(pw,sp,te,st,mn) / OVR(5値平均round) / 特性 / 紹介文
- **出さない値**: `pot`・`trainCap`(潜在)/ 団体・年齢・人気・戦績・体調・給与(ランタイム値)/ personality・archetype(内部語彙)

## 遷移

- **入ってくる経路**: タイトル画面の Credits 横の小リンク「Fighter File」(`.title-credits-link` と同格の並び)
- **出ていく経路**: ✕ボタン / ESC → タイトル画面へ戻る(Creditsオーバーレイと同じ z-index 200 の開閉)
- 一覧の行クリック → 詳細モーダル(情報閲覧のみ: ✕ / 背景クリック / ESC で閉じる)

## 構成要素

- **タイトル画面の変更**(同タスクで実施):
  - Credits 横に小リンク「Fighter File」を追加(Creditsと同スタイル)
  - **配色リフレッシュ 案2「会場の夜」**: `.title-screen` 背景を `#161b21`、`.title-bg::before` のグローを `rgba(110,150,190,0.09)`(下から)へ。ロゴ・ボタンの金は不変。顔マーキー彩度 0.4→0.55。ゲーム内Officeの暖茶は変えない
- **機密注記**(確定文言・一字一句変更禁止):
  > 潜在能力値は、本ファイルには記載されない。
  > 各選手の潜在能力は機密事項。さらに同じ選手であっても、その数値はプレイごとに変化する。
  > ※ 記載の能力値は各選手の能力基準値。
- **フィルタバー**: スタイルセレクト(6種)+名前部分一致検索+件数表示(`全127名 / 表示中: M名`)。団体フィルタは無し
- **一覧テーブル**: `.db-table` 準拠。`<th>`クリックソート(同列再クリックで昇降トグル・別列は降順から・アクティブ列=金+` ▲/▼`)。顔=face 1:1 40px(§2-C row段)。数値の塗りは stat-notation §1
- **詳細モーダル**: upper 2:3 **XL 172×258**(下辺3px金)/名前 title 18px/OVR display 28px(金階調)/レーダー(stat-notation §3)/バー5本(stat-notation §2。基準値のみなので枠越えは出ないが部品は共通実装)/特性(TRAIT_DEFSのicon色+説明)/紹介文(CHAR_PROFILES)/脚注「※ 記載の能力値は各選手の能力基準値。潜在能力・成長タイプ・体調・戦績は、本ファイルには記載されない。」

## 情報階層

1. 機密注記(読み飛ばされない位置・ファイルの世界観を規定)
2. 一覧: 顔と名前 → OVR → 5能力の階調
3. 詳細: 上半身とOVR → レーダー/バー → 特性 → 紹介文

## 特有ルール

- 全127名を素の table で描画(ゲーム内DBと同規模)。顔画像は `loading="lazy"`+onerror でイニシャルのフォールバック
- 数値の階調・バー・レーダーは `stat-notation-v1.0.md` の共通ヘルパーを使う(再実装禁止)
- 名前ソートは `localeCompare('ja')`
- デフォルトソート: OVR降順(ゲーム内DB準拠)
- モーダル閉止は「情報を見るだけ」型: 背景クリック+ESC+✕(mockup-baseline §5-C)

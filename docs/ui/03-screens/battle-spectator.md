## 目的

シミュレーション済みの試合を、初心者にも現在の攻防が分かる実況・技説明・視覚演出へ変換して見せる。勝敗や数値を操作する場所ではなく、選手の動きと試合の流れを観察する場所である。

---

## 遷移

- **入ってくる経路**：親画面がシングル戦を開始し、`START_MATCH` メッセージで選手・試合情報・完成済み `result.frames` を渡す。
- **出ていく経路**：決着演出と結果表示の後、既存の完了メッセージで親シーケンスへ戻る。
- **戻る挙動**：「ひとつ戻る」は表示中のReplayを1フレームだけ戻す。試合結果の再計算は行わない。

## 構成要素

- Battle HUD
  - 両選手のface、名前、HP、ターン、フェーズ、モメンタム
- Live Ring
  - 会場背景、full画像2人、攻撃方向、衝撃、ダメージ、危険域、台詞カットイン
  - 角型の中央実況パネル
- Fighter Stat Card × 2
  - upper画像、名前、ロール、スタイル、OVR、PWR/SPD/TEC/STA/MNT
  - 右選手の能力バーは画像側から左へ伸びる鏡映し
- Exchange Panel
  - 直近の攻防は最新行を先頭に積む
  - 現在技はカテゴリー、技名、初心者向け説明、結果を表示
- Replay Controls
  - 中央に主操作「次の攻防」
  - 左に1フレーム戻る・自動再生・速度
  - 右にカメラ自動／全景／アップ・正確な数値の表示切替

## 特有ルール

- 観戦画面は `result.frames` の表示専用で、`simulateMatch()` を呼ばない。
- 実況はプロレスの状況を自然文で伝え、正確なダメージと技威力は技説明側の任意表示へ分離する。
- 自動カメラは Opening/Mid の通常攻防を全景で見せる。End/Climax の大技、クリティカル、カウンター、フォール／ギブアップ／TKO／決着ではアップにし、最低でも次の攻防まで保持する。
- 手動の全景／アップを選ぶと自動判定を上書きする。自動へ戻すとフレーム計画へ復帰する。
- アップでも両選手のfull画像は同一倍率にする。固定キャンバス内に記録された身長差と頭上余白を維持し、キャンバス上端を切らず下側だけをクロップする。倍率はライブリングの縦横比に応じて自動で抑え、ウィンドウサイズの手動調整を不要にする。
- リング背景・カラーグレード・照明は固定の正レイヤーに置き、攻撃時に移動する透明な選手パネルと分離する。選手の周囲へ黒い親背景が追従して見えないようにする。
- BIG MATCH／RIVALRY MATCHは独立した横長帯を置かず、選手画像のない文字だけの小型バッジとしてライブリング上端中央へ内包する。空いた高さはライブリングへ戻す。
- MISS、カウンター、大技、ダメージ、危険域、因縁／フェーズ台詞、フォール、丸め込み、キックアウト、ギブアップ、TKO、勝利演出とSFXは従来どおり再生する。
- 大技の溜め・危険域・丸め込み等、選手に付随する発光は透過full画像の輪郭へ沿わせる。透明キャンバスや選手パネルの矩形外周は光らせない。
- 決着後の選手本人のセリフは白い吹き出し＋黒文字とし、金色の実況文とは分離する。シングル／タッグで同じ会話規則を使う。
- 左右の同種情報に側固定色は使わない。左右差は配置と鏡映しで示し、能力バーの色は能力種別を表す。
- full画像はリング上で大きく使い、成長時のOVR差し替えを反映する。下段データカードはupper画像を使う。
- 顔・名前・画像は既存の選手詳細を開ける導線を維持する。

## 状態バリエーション

| 状態 | 表示 |
|---|---|
| 開始前 | 両選手・初期HP・案内実況・空ログ |
| 通常攻防 | 全景、実況、技説明、最新ログ、各種ヒット演出 |
| 見せ場 | 自動アップ、大技／カウンター／決着の既存演出を重畳 |
| 自動再生 | 現在速度でReplayを進め、演出の最低表示時間を優先 |
| モバイル | リングと攻防情報を先に積み、能力カードを下段2列、操作は画面下へ固定 |
| 終了 | 既存の勝利オーバーレイと結果カード |

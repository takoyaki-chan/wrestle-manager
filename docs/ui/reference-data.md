## 1. 参照方針

このファイルの目的は3つある。

- 画面に載る日本語の密度を現実に合わせる
- 数値の強弱を、実際のゲーム内分布に寄せる
- 派閥、団体、選手まわりの文言トーンを固定する

参照元:

- `src/data.js`
- `src/factions.js`
- `docs/ui/mockups/*.html`

## 3. 数値帯の目安

UIで見せるときは、以下の感覚を基準にする。

### OVR相当の印象

- 100超: たまに出る本当に強いレジェンド級
- 90台: ゲーム後半の中心選手、主力選手
- 80台: ゲーム前半から中盤での主力選手
- 70台: ゲーム序盤での主力選手
- 60台: 第2戦級の選手
- 60未満: まだ主戦力とは言いづらく、下支え寄り

### 能力値のサンプル感

- 強豪主力: `pw 90前後 / sp 70前後 / te 70前後 / st 75前後 / mn 80前後`
- 技術型: `te 80台 / 他60〜70台`
- パワー型: `pw 80台 / sp低め / te控えめ`
- 若手下位: `40〜60台中心`

## 5. 団体・人数まわりの基準

`src/data.js` の基礎設定より:

- S級団体スロット: `16`
- A級団体スロット: `13`
- B級団体スロット: `10`

モック作成時の推奨人数:

- S級ロスター画面: 14〜18人で見せる
- 派閥詳細: 3〜7人で見せる
- 2派閥並立時: 4〜6人 + 3〜5人くらいで組む

派閥は“ずっと巨大化する集団”というより、  
3〜5人を中心に動き、たまに6〜7人まで膨らむものとして扱う。

---

## 6. 派閥フレーバーの表示文言

現在の最小実装で使う文言基準:

- `bond_first` → `結束型`
- `meritocratic` → `実力主義`
- `neutral` → `自然型`

補助文の推奨:

- `結束型` → `絆でまとまりやすい派閥`
- `実力主義` → `実力ある選手が集まりやすい派閥`
- `自然型` → `自然発生的にまとまった派閥`

## 8. 使い方

モックアップ作成時は、まずこのファイルから名前と数値帯を引く。  
そのうえで、必要なら画面固有の仕様書にだけ追加サンプルを置く。

基準から大きく外れる名前の長さ、数値帯、人数を使う場合は、意図を明記すること。

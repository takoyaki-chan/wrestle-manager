変更点と、判断が要る点

0. 2026-08-01 レビューの反映

  • PPV は差し戻し。作り直さない。 冬の丸エンブレムと冬カラーを撤去し、--ev-winter / --ev-winter-rgb は定義ごと削除。§③ は .pb-* の写しに置き換えた（①と同じ「基準」扱い）。 作り直す対象は ② 春タッグ と ④ 秋対抗戦 の2つ
  • 吹き出しの中に話者名・団体名は入れないを全画面に適用。①ジュニアも例外にしない裁定が出たので、 .jt-bub .sp を規則ごと削除した
  • 春の OVR 2つはこのままで OK（チーム平均に変えない）— 判断待ちから外した
  • 秋の選手画像・春の次戦カード・進行の俯瞰はそのまま通過
  • 吹き出しに尻尾を付ける（ジュニアも含めて全部）。 「誰が言っているかがわかる方がいい」。全9吹き出しに尻尾を付け、話者の画像の水平中心を指す。 隊列や左右2人のときはどちらが話しているかで尻尾の位置を変える。 ジュニアは尻尾を正確に刺すため吹き出しをグリッドの1行目へ移した（前項の判断待ちは解消）
  • 所属団体のエンブレムを出す。「OVR から力関係は分かる。でもどの団体に所属しているかが 非常に重要」。選手を出す全箇所に 26px のエンブレム実画像を添えた（頭文字の代用はしない・§5）。 縦順は固定のまま（… → 役割ラベル → 団体バッジ → OVR）

1. 共通部品 .sfc を1つ作る（これがこのモックの本体）

  • ジュニアの _jtcFcCore / .jtc-fc-* を春・秋にも使えるよう一般化したもの。骨格・サイズ・余白はジュニアと同じで、大会色だけ --ev-c / --ev-rgb で差し替える（ジュニアの --jtc-color と同じ仕組み）
  • 実装時はジュニアと天頂戦が既に乗っている _jtcFcCore を拡張するのが筋。新しい部品を別に作らない
  • 拡張が必要なのは3点 — (a) 吹き出しを予約枠＋尻尾＋話者名は箱の外にし、画像と同じグリッドの1行目に置く、 (b) 名前ブロックに役割ラベルと団体バッジ（26px エンブレム実画像）の段を足す、 (c) 左右を隊列にできるようにする（春の2対2用）
  • 尻尾のずらし量は % ではなく px で持つ（--tail-dx）。 列幅は 1fr なのでビューポート幅で変わり、% だと尻尾が画像からずれていく。 隊列のときは (画像幅 - 重なり18px) / 2 ぶんだけ話者側へずらす （S 108 なら 45px、狭幅で 84 に落ちたら 33px）。段を変えたらこの値も一緒に変える
  • PPV には入れない。 PPV は既存のままなので、この部品の適用先は春・秋（＋既存のジュニア・天頂戦）だけ

2. 判断が要る点

  1. PPV の .pb-fighter-meta にエンブレムを足した件。 「PPV は既存のまま」と「エンブレムはどの文面でも」が正面からぶつかる唯一の箇所で、 後から出たエンブレムの裁定を優先して 26px を足してある。 PPV を1ドットも動かしたくないなら、ここだけ戻す（§③ の注釈にも同じことを書いた）
  2. クライムラインのセルはエンブレムだけにした（団体名テキストなし）。 幅76pxのセルに「ブルームハート」まで入れると潰れるため。 エンブレムだけで団体が判別できるという前提でよいか（本エンブレム制作後に再確認したい）
  3. 次戦カードの画像サイズ 118×177。 ジュニアの実測値で、②④もこれに合わせた（並べたとき同じ大きさに見えることを優先した）。 ただし §2 の梯子は S 108 と M 132 で、118 はその間。 まとめて M 132 へ上げるか、118 を「対戦カードの段」として梯子に正式登録するかのどちらかに決めたい。 このモックは前者に倒しやすいよう、幅を1箇所（.sfc-up）でしか持っていない
  4. 文字サイズをタイプスケールへ寄せた。 ②④の選手名は subtitle 15px、OVR は display 28px。 ジュニアは 17px / 23px で、§1が禁じている中間値。 ②④を先に正しくしたので、①も後で 15 / 28 へ寄せることになる（別タスク）
  5. --ev-spring-rgb / --ev-autumn-rgb の追加。 共通部品を rgba() で色替えするために要る（現状は --ev-summer-rgb と --gold-rgb しか無い）。 値は既存の16進と同一で、新色ではない。--ev-winter-rgb は作らない（PPV が冬を使わないため）
  6. 16進直書きのトークン化 6件。 いずれも値は変えていないので見た目は1ドットも動かない。 --bubble-bg / --bubble-ink（.jt-bub / .tcdr-bub の #f0f0f0 / #1a1a1a）、 --ppv-crimson（VSマークの #e94560。.jtc-fc-uppers .vs-mark / .jtc-fc-vl / .tc-vs の3箇所）、 --stage-portrait-bg（.jtc-fc-upper の下地 #121110）、 --ppv-red / --ppv-red-rgb（.pb-theme-ppv の #d63d46）、 --pb-portrait-top / --pb-portrait-bottom（.pb-portrait の #1a1816 → #0a0907）。 実装時に一緒に片付けるかどうか

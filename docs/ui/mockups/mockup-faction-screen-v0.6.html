v0.6 変更点

  • 中央対比構造: 左カード ─ 中央VS軸 ─ 右カード を1グリッドで連結。左右カードはVS軸を挟んで完全に対峙する。
  • RIVALRY POINTSバーをカード内へ: 上下段の独立 pp-row を廃止。各カード上部に内蔵し、左派閥のバーは右端起点で左へ、右派閥のバーは左端起点で右へ伸びる。中央軸に向かってぶつかる構図。
  • OVR/POP をキャラに寄せる: 行右端から、portraitとnameの間に挟む位置へ移動。dashed border で stats 列を視認しやすくし、左右でミラー配置。
  • 中央軸: 上から VS / 抗争週 / GOAL 100 / 縦の血の線（spine）。spine が左右カードを縦に貫く演出。
  • キャラの中央軸揃え: 左右で大将/中堅/副将/RANK&FILE の高さを揃え、中央線で対峙。

3案の比較

VARIANT A（暫定エース・単独）：実装コスト最小。既存単独エースレイアウトの「ラベル変更＋彩度を落とす」だけで成立。中心人物を1人に絞ることで読みやすいが、「主役を勝手に決める」感が出るリスク。

VARIANT B（旗揚げ世代グリッド）：CLAUDE.md整合度が最も高い。「主役未定」を貫いて5人を等価で並べる。気風の暫定傾向も控えめに表示。新しいグリッドUIの実装コストはあるが、序章としての美しさはこれが一番。

VARIANT C（暫定二枚看板）：王者vs挑戦者という分かりやすい対立軸を活用。物語性が前に出る。ただし対戦相手が頻繁に変わる序盤では仮固定の不自然さが出やすい。

推奨：哲学整合性で B。実装の軽さで A。

§2 — 詳細モーダル: バーは「枠越え・圧縮はみ出し」方式

バーの枠は100で終わる。旧0-150目盛は「150まで育つ」と錯覚させるため廃止(100超の黒い空きトラックは存在しない)。天井はプレイごとに変わり120〜150台も実在するため、100超は実寸に比例させず圧縮してはみ出す(バー自体は光らせない——規格外の輝きは数値側が担う)。枠を越えた=規格外が一目で伝わり、正確な量は数字が語る。

数値はOVR=金階調・各ステ=系統の段階調(案X)。レーダー軸ラベルとバーの塗りは系統色のまま(軸識別)。選手ファイル本体は基準値のみ(最高95)なので、枠越えが実際に出るのはこの方式をゲーム内選手詳細へ展開したとき。

§3 — 判断が要る点(v0.7)
  1. はみ出しの圧縮率 — 100超(〜150)を枠の右18%区画に圧縮(110で枠+3%、150で枠+18%)。110がもっと目立ってほしければ区画を広げる/平方根カーブにする等の調整可。バー自体の発光は廃止済み(輝き=数値のみ)
  2. 枠越え方式の適用範囲 — この方式はゲーム内の選手詳細ポップアップ(現在0-150目盛+縦線)にも展開すべきと考える(150錯覚は本編でも同じ問題で、実測120〜150台の選手が本編には実在する)。展開するなら別タスクとして起票
  3. 案Xの帯割り微調整 — 70台の淡い系統色(50%混色)が薄すぎるなら60%へ上げられる
  4. 低域グレー2色の色味 — 暗灰#63615b/明灰#a8a59d。暗すぎないか
  5. 配色の適用範囲 — タイトルに続く団体設立・難易度画面も案2の地色に揃えるか
  6. 選手ファイル画面の地色 — モックはゲーム内DB準拠の暖ダークのまま。タイトル(案2)の上に開く画面として微青地に追従させる選択もある

  • 派閥カード単体の構造は B1-a 標準と同じ（情報量維持）。
  • [長所] PAIR-Aを既に上で見た後でも一覧で再度「対決中」を強く感じる。中立派閥との階層差も明確。
  • [短所] 1派閥カードの幅が狭くなる（中央軸80px占有）。情報が縦長化する。

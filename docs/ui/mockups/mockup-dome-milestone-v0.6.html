Mockup v0.6 設計ノート

  • オーディオエラーの可視化：読込失敗（404等）や再生失敗を nav バーのヒント欄に赤枠で表示。ファイル名・エラー種別も表示されるので問題切り分けが容易に

BGM状態の見方（nav バーのヒント表示）

  • 🟢 緑：♪ 再生中: ファイル名 — 正常再生中
  • 🟡 金（点線）：▷ 画面クリックでBGM開始 — 自動再生ポリシーでブロック中、初クリック待ち
  • 🔴 赤：⚠ 読込失敗: ファイル名 — パス解決失敗（404 / 配置場所ミス）
  • 🔴 赤：⚠ 非対応: ファイル名 — ブラウザがそのフォーマット非対応

v0.5 からの変更点（BGM組み込み・継続）

  • 興行前（first_dome_show）：bgm_kaimaku_v1.mp3（SB1 開幕ドラフト）
  • 興行後（first_dome_sellout）：8bit-ending-theme_Loop.ogg（FB6 年末表彰式）
  • 音量：0.10（既存派閥イベント・PPV演出と同水準）
  • ループ：両方とも有効
  • フェーズ切替時：BGM は Phase 1→2 遷移で継続再生

実装時の BGM 制御（既存パターン参考）

  • 派閥イベント _factionAudioOpen / _factionAudioClose パターンを踏襲
  • イベント開始時：Audio.fileBgm.play('../bgm/bgm_kaimaku_v1.mp3', { loop: true, volume: 0.10 })（※src内パスは実装時の呼び出し元に応じて調整）
  • イベント終了時：Audio.fileBgm.fadeOut(1500)
  • 興行前BGM→試合本編BGMへの切替は、試合開始時に既存のbattle BGM起動ロジックが上書き

v0.3 からの変更点（レイアウトバランス修正・v0.4から継続）

  • 問題：v0.3 では両フェーズが flex の子要素として縦に積まれていて、非アクティブ側も空間を占有していたため、アクティブ側の内容が上に寄ったり下に寄ったりしていた
  • 修正：両フェーズを同じ絶対領域に重ねて配置（position: absolute; inset: 0）し、3ゾーングリッド（grid-template-rows: minmax(160px, 22vh) 1fr minmax(150px, 22vh)）で上段・中段・下段を固定
  • 効果：タイトルは常に上段ゾーン、ナレーション＆選手トリオは常に中段ゾーン、続けるボタンは常に下段ゾーン。フェーズ遷移しても視覚的な位置が揺れない

3ゾーン構造の内訳

  • 上段ゾーン（minmax 160px〜22vh）
    • Phase 1: タイトルバンド（「到 達」「満 員」）
    • Phase 2: 予約された空白
  • 中段ゾーン（1fr = 残り全部）
    • Phase 1: ナレーション本文（クリック進行で蓄積）
    • Phase 2: 主力選手3名トリオ
  • 下段ゾーン（minmax 150px〜22vh）
    • Phase 1: 予約された空白
    • Phase 2: 続けるボタン（3人揃った後にフェードイン）

フェーズ別シーケンス

  • Phase 1 ・ NARRATION
    • タイトル帯が自動フェードイン（1.2秒）
    • クリックごとにナレーション1行追加（蓄積式、以前の行は残す）
    • ナレーション全行表示後、さらにクリックで Phase 遷移が発動
  • Phase 遷移：Phase 1（タイトル＋ナレーション）がフェードアウト（1秒）→ 画面クリア → Phase 2 がフェードイン（1秒）
  • Phase 2 ・ CHARACTERS
    • クリックで選手1（赤コーナー）が下から浮き上がって出現＋吹き出し表示（0.2秒遅れ）
    • クリックで選手2（青コーナー）
    • クリックで選手3（ベテラン代表）
    • 3人揃うと「続ける」ボタンが自動フェードイン

吹き出しデザインの設計根拠

  • 色の選定：既存の年末表彰式 .speech-bubble（#f0f0f0）とオフィスパネル --office-panel-cream-card（#ede8dc）を比較検討。後者を採用した理由は、ドーム到達という「厳粛」な瞬間には冷たい白より温かみのあるクリーム（紙片の質感）の方が格式に合うため
  • 枠線：Keisuke 指示通り「黒」を基本とするが、ピュア黒（#000）は暗い背景に対して硬すぎるため、ほんのり暖色寄りの近黒（#2a1f18）を採用。ゴールド基調のCeremony色と調和
  • 文字色：同じ理由で近黒 #181614（既存の --office-panel-dark トークン）
  • 角の非対称：既存 .speech-bubble を踏襲。左下だけシャープ（2px）で他は丸い（10px）＝ 紙を傾けて差し出したような形
  • 尻尾：CSS の二重 ::before/::after 三角形で、枠線付きの尻尾を実現

Phase 2 のレイアウト

  • 選手3名が横並び（タブレット以下は縦並び）
  • 各選手：吹き出し（上）→ ポートレート画像 → 役割ラベル → 選手名（下）の縦配置
  • 選手名は var(--font-body) + Bold + 金色上線（オープニング演出 .opening-portrait-name と同等）
  • Phase 2 にはタイトル・ナレーションは出さない（「真っさら」）。続けるボタンは3人揃った後に出現

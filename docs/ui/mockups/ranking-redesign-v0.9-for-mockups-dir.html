v0.9 Changes

v0.8 → v0.9 の変更

  • OVR 階調を5刻みに：80-84 / 85-89 / 90-94 / 95-99 / 100+ の5段階で黄色味グラデ。v-elite-low（85-89）を新規追加して8階調に。80を黄色開始、79以下は完全に白〜グレー。
  • v-mythic を明るく彩度MAXに：旧の深金 #c89028（暗くて目立ちにくい）→ 純金 #ffd700 + 強glow。100+の選手が画面で確実に目立つ。
  • 01ヒーロー段を削除：縦幅を大幅圧縮。代わりにマスト下に細い「勝利条件バー」を追加して「1位 vs 自団体・あと-134pt」のサマリーは保持。
  • 02の1位カードを拡大：grid-template-columns を 1.3fr/1fr/1fr/1fr に。1位の rank 番号 38→48px、フォーメーション 180→220px、pos-1 130×165→150×195px、評価値 26→32px。「1位感」を視覚的に強化。
  • サンプル選手データ更新：花村 桜子 85 と 猪瀬 凛 86 を v-elite-low に変更（新階調の例として）。
Implementation Hint

実装時のヘルパー（v0.9 確定版）

// src/ui-common.js などに
// OVR のみ階調適用（評価値には使わない）
function valueClassOvr(ovr) {
  if (ovr >= 100) return 'v-mythic';     // 100+ — 殿堂入り（最大120まで全部同色）
  if (ovr >= 95)  return 'v-elite-mid';  // 95-99 — 強金
  if (ovr >= 90)  return 'v-elite';      // 90-94 — 中金
  if (ovr >= 85)  return 'v-elite-low';  // 85-89 — 淡シャンパン金（NEW）
  if (ovr >= 80)  return 'v-high';       // 80-84 — クリーム白（黄色味スタート）
  if (ovr >= 70)  return 'v-mid';        // 70-79 — 暖白
  if (ovr >= 60)  return 'v-low';        // 60-69 — 淡グレー
  return 'v-poor';                       // ~59  — 暗グレー
}

閾値は data.js に OVR_TIER_THRESHOLDS = { mythic: 100, eliteMid: 95, elite: 90, eliteLow: 85, high: 80, mid: 70, low: 60 } として定数化推奨。

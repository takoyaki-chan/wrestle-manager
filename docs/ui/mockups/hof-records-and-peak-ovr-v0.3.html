v0.3 の狙い
・天頂戦 = 栄冠の列(主役) — アッパー画像を大判(132×198)で正面に。名前は画像下部の帯、足元に月桂樹+開催シーズンのプレート、「第N回 王者」。次回開催枠は破線の空席で「4年に一度」の重みを見せる。回を重ねるほど列が伸び、壁面が埋まっていく
・PPV = 同じ文法でひと回り小さく(96×144) — 紫の照明で書き分け。直近から並べ、溢れたら横スクロール
・最多連続防衛 — 王冠+アッパー画像の「王者の肖像」。大きな防衛数と在位期間
・MQ名勝負の額 — 下段にコンパクト化(縦書きの「歴代最高の一戦」+評価点+顔小+対戦カード)。額縁の意匠は維持
・アッパー画像は左右反転しない(既存ルール)。タップで選手詳細へ。記録更新週は該当枠に「記録更新!」点滅
・実装は getUpperUrl(id, peakOVR) を流用(年代記のエースカードと同じ)。画像が無い選手はイニシャル色面フォールバック
② ピークOVR — 確定済みの再掲(A-1案 + 団体タブ)
✔ 確定: A-1案(OVRの真横)

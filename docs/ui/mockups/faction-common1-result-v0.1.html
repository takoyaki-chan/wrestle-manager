提案の構成要素
1. バナー: カテゴリ「FACTION INTERNAL MATCH」+ タイトル「派閥内対決 決着」+ 派閥名/週
2. 対峙ステージ: ポートレート 140×170 / 名前(クリック可) / OVR / WIN/LOSE バッジ。敗者は saturate(0.55) で沈ませる
3. 中央の決着情報: 決め技名(ゴールド) / フィニッシュタイプ / ターン数 · MQ
4. 試合スタッツ: 残 HP / 大ダメージ数 / カウンター数(3 行 × 3 列)。高い側にゴールドハイライト
5. 黒田ナレーション: 試合の流れを 1 文で物語る(ゴールド帯付き)
6. 勝者/敗者セリフ: 既存 `COMMON1_LINES.resultLeader / resultLoser` を勝者/敗者の頭上吹き出し風に。性格別ローテ
7. 影響: 「信頼度」など日本語化 + ± で色分け(緑/赤)、因縁は「-41(解消)」のように意味を補足

実装メモ
・新規関数 `_renderCommon1MatchResult(payload, matchResult, winner, loser)` を `ui-common.js` に追加
・`_finalizeCommon1Match` で `showFactionEventResult` 呼び出しを `_renderCommon1MatchResult` に差し替え
・matchResult から finMove / finType / turns / mq / hpLeft.final / log を流用
・大ダメージ数・カウンター数は log を集計(既存 B3 結果画面で似た計算を行っているので参考になる)
・勝者/敗者セリフは新規 `getCommon1ResultLine(role, leader, vars)` を性格別に拡張(現状 `_any` のみ)
・選手詳細は `showFighterPopup(id, 'roster')` で打診モーダルと同じ動線

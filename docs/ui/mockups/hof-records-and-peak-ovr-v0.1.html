置き場所の比較
・案A(推奨): タブ列は現状のまま。記録が1画面として綺麗に収まり、盾グリッドの視界も奪わない。将来記録が増えても記録ページ内で拡張できる。難点はワンタップ奥に入ること(記録更新週は🏅殿堂タブ自体にNEWバッジを出して誘導)
・案B: 常に見えるが、記録は頻繁に変わらないため毎回スクロールの上に乗るのはやや邪魔。殿堂入りが増えるほど窮屈になる
・タブを7つに増やす案は、モバイル幅でタブ列が折り返すため非推奨
設計メモ
・MQ2枚看板は G.mqRecord / G.mqRecordTag をそのまま表示(保持者・団体・S/W・舞台まで既に記録済み)。舞台名はエンジンの STAGE_LABELS を流用
・「最多連続防衛」「天頂戦歴代優勝」「PPV歴代優勝」は全選手の careerRecord.history 走査で算出(過去データにも遡って効く。新規トラッキング不要)
・「試合評価」表記は内部変数名(MQ)をプレイヤーに見せないための日本語化。既存UIの表記に合わせて調整可
・記録更新週は該当カードに 🔥NEW バッジを点灯させる(新聞記事とリンク)
・個人ベストMQ TOP5 は数字丸見せ感があるため任意。不採用なら破線枠ごと落とす

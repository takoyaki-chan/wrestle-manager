OVR 90+ 滑らかグラデ — 100+ 対応版

OVRは最大120まで到達しうる前提を反映。100以上は v-mythic として全部同色で表示する。 105・110・120 などの外れ値が登場したとき、すべて同じ「神話級マーカー」として一目で識別できる。 3案の違いはトップ（v-mythic）の見せ方のみ。

5段階構成：
v-high (80-89) → v-elite (90-94) → v-elite-mid (95-99) → v-mythic (100+ すべて)

100以上の値（100, 105, 110, 115, 120）は全部 v-mythic 同色になる。差をつけない理由は、 外れ値であるほど「希少な目印」として認識されるべきだから。105と110で色を変えると、希少さの認識がブレる。

P1：ナチュラル深化

99の中金から100+で深い金に「沈む」。重厚な王者表現。100超えは100でも120でも同じ深金で輝く。

P2：ハイライト終端

99の濃い金から100+で白金へ反転。希少な100超えが「白く輝く」のは見つけやすい。神話級の表現に最適。

P3：強光トップ

色は中金のまま、強いglowで「光って」目立たせる。文字は読みやすく、控えめに別格感を出せる。
選定の補助観点：
  • 視認性：100超えがリストに混じったとき、瞬時に発見できるのは P2（白金）。色相が99と反転するので一番目立つ。
  • 読みやすさ：P1（深金）は一番落ち着いて読める。glow も控えめで、テキストとして安定。
  • 派手さ：P3（強glow）は中間。色は読みやすく、光だけで特別感を演出する。
採用時の実装： 
function valueClassOvr(ovr) {
  if (ovr >= 100) return 'v-mythic';     // 100+ すべて同色（最大120まで）
  if (ovr >= 95)  return 'v-elite-mid';  // 95-99
  if (ovr >= 90)  return 'v-elite';      // 90-94
  if (ovr >= 80)  return 'v-high';       // 80-89
  if (ovr >= 70)  return 'v-mid';        // 70-79
  if (ovr >= 60)  return 'v-low';        // 60-69
  return 'v-poor';                       // ~59
}

閾値は data.js に OVR_TIER_THRESHOLDS = { mythic: 100, eliteMid: 95, elite: 90, high: 80, mid: 70, low: 60 } として定数化。

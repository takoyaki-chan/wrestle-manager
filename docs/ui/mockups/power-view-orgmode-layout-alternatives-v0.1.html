勢力図 / 団体モード 動的配置案 v0.2

条件: OVR/人気バッジは顔を隠しすぎない。ノード同士は重ならない。ドラッグ可能で、離すとフォーメーションへ戻る。
以前のピラミッド感を残しつつ、OVR差・人気・王者補正で自然に地位差が出る案を4つ並べています。
AElastic Pyramid
基本形はピラミッド。Yは地位スコアで連続補正し、物理で押し合う。
良い点一番「勢力図」らしい。三角形の強さを残しつつ、71帯は84/81帯より自然に下がる。
弱い点人気の横方向表現は控えめ。
実装候補現行の見た目を活かすなら最有力。
BSpring Crown
王者/エースを頂点に、支配層・追随層が弧を描いて広がる。
良い点トップ中心の団体像が見やすい。動かした時の戻り方も気持ちいい。
弱い点厳密な上下序列はAより少し柔らかい。
実装候補王者中心のストーリー感を重視する場合。
CGap Terrace
能力差が大きいところだけ段差を作る。人数固定の段組みではない。
良い点トップ層/上位層/中堅層の切れ目が分かりやすい。
弱い点同じ層の中では横並び感が残りやすい。
実装候補段組みの読みやすさを残したい場合。
DInfluence Fan
上ほど地位、左右は人気/話題性。扇形だがピラミッドの頂点感も残す。
良い点OVRと人気のズレが見える。人気だけ高い選手も埋もれない。
弱い点情報量が多く、純粋な序列はAより読みにくい。
実装候補「地位=実力+人気」を強く見せたい場合。

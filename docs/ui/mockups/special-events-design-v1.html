SPECIAL EVENTS — DESIGN LANGUAGE v1

特別大会(春タッグリーグ / 夏ジュニア / 秋 勝ち残り対抗戦 / 冬 C-6)の共通デザイン言語の提案 + 方向性3案。
共通で固定するもの: フォント階層(Bebas Neue=大会名・数値 / Oswald=ラベル / Noto Sans JP=本文)、アングル -12°(skew/斜断ち)、金の細ルール、純黒Stage背景。
大会ごとに変えるもの: カラーキー1色のみ。同じ部品に色を差し替えるだけで四季が出る構造。
各案とも「春のリーグ表画面」と「夏のトーナメント表画面」の2枚 + 色替えデモ付き。
§0 共通言語 — 四季のカラーキー
部品・フォント・角度は全大会共通。左端の色柱と斜めの差し色だけが季節で入れ替わる。

比較メモ
A 斜幕: 興行の熱・煽り感が最強。リーグ/ブラケット両対応が素直。消耗バー等の情報も乗せやすい。
B エンブレム: 格式・記念感。優勝演出(Ceremony)と地続きだが、進行中の画面としては静的。
C ブロードキャスト: 可読性と実況感。テロップで「いま何が起きたか」を語れるのがリーグ戦向き。ブラケットの樹形図は捨ててリスト型になる。

組み合わせ(例: 進行中=C、優勝発表=B、ヘッダーはA)も可能。方向性の指名をください。

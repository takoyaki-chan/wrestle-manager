現→変(v0.3→v0.4): 階調を二段構成へ
  • 共通の形: 0=グレー(#6e6e69) → 60=白(#f2f0e8) → 100=その列の一番濃い色。60未満は「灰から白へ登る」=まだ色が付かない帯、60を超えると色が乗り始め、高いほど濃くなる
  • OVR: 白 → 薄い金 #f0d078(78付近) → 濃い金 #d4a843(100)。金2色は実装の `--gold-light`/`--gold` の実値
  • PW〜MN: 白から系統の純色へ一直線に濃くなる。系統色は実装 `_STAT_COLORS` の実値(PW赤/SP緑/TE青/ST橙/MN紫)
  • 100オーバー: 少し明るく+その色のglowで「輝く」(前版のまま。凡例右端に成長域見本)
  • 白の折り返しは `WHITE_POINT` 定数1つ(60採用・50へ変更可)。85以上の太字も前版のまま
  • ソート・検索・行クリック→詳細・身長列(階調対象外)は不変
§2 — 詳細モーダル: 数値が同じ階調に追随

OVR大数字=OVR階調、バー右の数値=各系統の階調。レーダー軸ラベルとバーの塗りは系統色のまま(軸識別)。SP/TE訂正はここにも効いている(レーダーのSPが緑・TEが青に)。

§3 — 判断が要る点(v0.4)
  1. 白の折り返し=60(報告) — 50か60は一任いただき60を採用。既存実装の「60以上=通常表示」と一致し、色が付いたら平均以上、のサインになる。`WHITE_POINT` 定数1つで50へ戻せる
  2. 低域グレーと白点の色味 — 0点=#6e6e69(無彩・やや暖)、白点=#f2f0e8。この2色だけが新規定義(他はすべて実装実値)。暗すぎ/明るすぎの感触を見てほしい
  3. 輝きの強さ — 100超のglowは元実装と同じ6px+外側14pxの二重。もっと控えめ/派手にも振れる
  4. 太字の閾値 — OVR・ステとも85以上を太字。不要なら外す
  5. 配色の適用範囲 — タイトルに続く団体設立・難易度画面も案2の地色に揃えるか
  6. 選手ファイル画面の地色 — モックはゲーム内DB準拠の暖ダークのまま。タイトル(案2)の上に開く画面として微青地に追従させる選択もある

4. どちらを採るか

案サイズ効果気になる点
案A
推奨		 既定 → M 132×194
small → S 108×162		 いまの印象をほぼ保ったまま梯子に載る。切れが無くなるぶんだけ良くなる。 モーダルの縦は既定で +10px、small で +2px。レイアウトへの影響がほぼ無い 「直したのに変わって見えない」— ただし今回の目的は規約違反の解消なので、それでよいとも言える
案B 既定 → L 150×224
small → M 132×194		 表情と体格がはっきり読める。キャラを「覗き見る」ゲームとしては主役の見せ方が強くなる モーダルの縦が既定 +40px / small +34px。派閥イベントは頻度が高いので、 毎回この大きさが出ることをどう感じるか。王座防衛を派閥級に落とした判断とも噛み合わない
現状維持 140×184 / 120×160 — 2:3素材が切れたまま。梯子の外なので、今後も「サイズをその場で決める」判断が残る

※ 案A・案Bとも 吹き出しは画像の上・尻尾は画像の水平中心のまま。名前と所属は吹き出しの外（画像の下）。

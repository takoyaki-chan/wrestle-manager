勝敗は1勝2敗で塔子が先行されている。しかし、勝者と敗者という言葉だけでは、この関係は語りきれない。リング下に降りた両者の表情に、観客はいつも何かを読み取ろうとする——それは、両者が単なる対戦相手ではなく、互いの存在を必要としているからだ。

次の対戦は、おそらく長くは待たされない。そして、それを最も待ち望んでいるのは、おそらく当の二人自身である。

友情と勝負心は、ふつう両立しない。だが、この二人だけは違う。3度の対戦、いずれもMQ78以上の好評価——リング上で全力を尽くせるのは、互いが信頼しあっているからにほかならない。

「あいつとの試合は、観客のためじゃなくて、自分たちのためにやってる」——どちらかがいつかそう漏らしていた。本当のところ、それが真実なのだろう。

このカードが組まれるたび、業界の目が集まる。次の試合がいつになるかは分からない。だが、組まれれば必ず、紙面の一面を飾る試合になる。

互いの背中を押し続ける——そんな関係が、業界にはいくつあるだろうか。3年の歳月、3度の対峙、最高評価89点。これらの数字は、二人の関係の深さを物語る指標に過ぎない。本質はもっと別のところにある。

塔子が伸びた理由の半分は、玲美の存在だ。玲美が緩まない理由の半分は、塔子の存在だ。これは取材を続ける中で、本紙が確信するに至った見立てである。

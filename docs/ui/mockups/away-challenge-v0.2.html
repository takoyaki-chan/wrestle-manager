■ 実装メモ

・`_challengeRequestResultReaction`/`_challengeRequestOpponentReaction`(ui-common.js)を2拍シーケンスに再構成。 scene選定に代表本人の試合結果(result.matches[0].winner)の軸を追加
・B1の主役選定: 勝利側の代表戦勝者を優先、代表が負けていればその陣営で最高MQの勝者
・コーチ要約はモーダルから週次レポート1行へ移す(モーダル連発回避。ポップアップ直列化の方針とも整合)
・進行画面は `.show-pregame-a.away` の色替え+試合カードのステ表示差し替え(fc1m部品の流用)

機密指定
潜在能力値は、本ファイルには記載されない。
各選手の潜在能力の基準値は機密事項。さらに同じ選手であっても、その基準値はプレイごとに変化する。
※ 記載の能力値は入団前査定の初期値。入団後の育成と経験で変わっていく。
現→変(v0.1→v0.2): 系統色ハイライト(PW赤/SP青…75以上のみ)を廃止し、OVR〜MNの全列を「値の階調」で塗る。
  • 階調は実装済みのランキング画面のOVR階調(ranking v0.9 / OVR_TIER_THRESHOLDS)をそのまま全能力列へ展開: 100+/95+/90+/85+/80+/70+/60+の7段(白→金)。低域は 60未満=sub / 45未満=dim をモックで追加定義
  • 80以上は太字。高いほど「金に近づく」ので、初期値でも階調が読める(見本の最高値は阿武隈PW95)
  • 身長は数値だが能力ではないので階調対象外
  • ソート・検索・行クリック→詳細は v0.1 から不変(承認済み)
§2 — 詳細モーダル: 数値のみ階調に追随

OVRの大数字とバー右の数値を階調カラーへ。レーダーの軸ラベルとバーの塗りは系統色のまま(どの軸がどの能力かの識別を担うため)。閉じる: ✕ / 背景クリック / ESC。

§3 — 判断が要る点(v0.2)
  1. タイトル配色 — 案1 グラファイト vs 案2 会場の夜。推奨は案2(「爽やか」への一番素直な答え。金看板は微青の上でも締まる)。現状維持+グローだけ除去、という最小案もあり得る
  2. 配色の適用範囲 — タイトルに続く団体設立・難易度画面(同じ `--bg-dark` 地)も揃えて差し替えるか
  3. 選手ファイル画面の地色 — モックはゲーム内DB準拠の暖ダークのまま。タイトルの新地色に追従させる(タイトルの上に開く画面なので一体感は出る)か、ゲーム内DBと同色を保つか
  4. 小リンクのラベル — 「Fighter File」(英字・Credits と並び) vs 日本語「選手名鑑」。位置はCredits横で確定方向
  5. 階調の低域定義 — 60未満=sub / 45未満=dim(モック追加)。実装のランキングは60未満を扱わないため、ここだけ新規定義になる
  6. 顔マーキーの彩度 — 爽やか化に合わせ 0.4→0.55 に上げた。やり過ぎなら戻す

阿武隈塔子、ついに王座奪取
3年越しの雪辱——7度目の対戦で生駒エリカを下す
ベルトを掲げる阿武隈塔子

第14週興行のメインイベントで阿武隈塔子（31）が生駒エリカを破り、世界王座を獲得した。試合時間18分42秒、最後は正面からの組み技で3カウント。初挑戦で敗れてから3年、7度目の対戦で初めてベルトが腰に巻かれた。

序盤は王者のペースだった。生駒の打撃が阿武隈の出足を止め、場内には嫌な沈黙が流れる。だが中盤、阿武隈は被弾を覚悟で距離を詰め、試合の重心を組みに引きずり込んだ。6度の敗戦で学んだ答えを、この夜のリングで出し切った形だ。

通算成績はなお生駒の4勝3敗。数字の上では王者だった側が上回る。それでも今夜の歓声は、この3年間を見続けた者への報酬だった。敗れた生駒は無言で花道を下がったが、その足取りに崩れはない。

防衛戦線は来月から始まる。挑戦者には因縁の富岡加奈子の名が早くも挙がっており、新王者に休む間はない。ベルトを取る物語が終わり、守る物語が始まる。

――黒田幸子(本紙)

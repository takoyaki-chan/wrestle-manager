比較メモ
案1 ライズ・タワー: 実装が素直、情報の収まり最良。動的出現(せり上がり)もカード単位で作りやすい。
案2 クライムライン: 画の迫力とアッパー画像の見栄えが最強。合流線のSVGが実装コスト増、横幅も食う。
案3 サミットライト: 案1+照明演出。「登った者だけが照らされる」の物語性。実装は案1+α。

3案とも: 下段=準々決勝で開幕し、勝者確定のたびに上の枠がせり上がって出現(§0)。試合情報は「決着時間 / MQ」チップで統一。

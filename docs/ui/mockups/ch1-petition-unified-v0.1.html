判断メモ — CH-1 実装前に決めたいこと

前提の共有: 07-25時点のCH-1は「直訴を派閥と同じOffice書式へ統合する」でしたが、 その統合はU3(07-26)と団体戦化で既に完了しています(同じ枠・同じ部品・同じ縦順)。 残っている固有の設計判断は以下です。

  1. 同行2名の選択を直訴画面へ統合するか（案Aの「🚌 同行する2名を選ぶ」ブロック）
    推奨A統合する — 現行は 直訴YES → 別画面で2名選択 → 送り出し の3枚。 「誰と行かせるか」まで見てから受けるか決められる方が社長の判断として自然
    B現行維持（YES後に別画面）
  2. 迎撃（相手発）の差別化
    推奨専用タイトル「⚔ 挑戦状、届く」+ヘッダ敵対色+敵意がこちらへ向いた専用セリフを新設。
    現状の問題: タイトル・役割ラベルが「挑む」側と完全に同一な上、セリフは自団体用 （「社長、…と挑みたい」）が敵選手からも出る向きの矛盾がある。セリフはOpus起案→全文レビュー
  3. 直訴セリフの供給をどうするか
    現状: 団体戦化の際に CHALLENGE_GROUP_PETITION_LINES（アーキタイプ7種×2本=14本のみ・性格軸なし）に切り替わり、 07-25に書いた34セル×3本=102本の petition は参照されない死蔵になっている。
    推奨A34セル102本を団体戦の文脈（「三人で」「団体戦」）へ改修して復活させる（Opus・全文レビュー）
    B14本のまま増補だけ（アーキタイプ×性格の34セルへ拡張）　C現状維持
  4. 送り出し(sendoff)画面の枠 — 直訴・遠征選択はOffice書式なのに、送り出しだけ別系統の枠(mdl-a)で 相手・遠征先の情報が一切出ない。
    推奨Office書式へ寄せ、行き先(相手団体バッジ)と3人の顔を添える。「送り出す」の瞬間自体は残す

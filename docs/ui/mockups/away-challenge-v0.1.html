■ 実装の要点(結果画面)

・現行 `_challengeRequestResultReaction` / `_challengeRequestOpponentReaction`(ui-common.js)は scene を 団体勝敗だけで選んでいる(playerWon ? 'win' : 'lose')。代表本人の第1試合結果(result.matches[0].winner)を第2軸に追加
・グレースケール(defeated)とラベルも本人基準へ差し替え。ヘッダー/コーチ行/スコア帯は現行どおり団体基準(変更なし)
・スコア帯に「団体として敗北/勝利」の明記を追加(誤読の余地を消す)

■ 進行画面の判断点

① 配色 = 敵地黒+相手団体カラー照明(candidate切替は上のボタンで確認)
② 能力値 = バー10本廃止→中央対比行(勝っている側だけ点灯)。生値を出し続けるか、階調色だけにするかは要判断(現行も生値表示のため踏襲した)
③ OVR = ランキングと同じ階調カラー
④ 画像・チップ・縦積み構成は現行踏襲(変えるのは「色」と「数値の整理」だけ)

■ この設計で変えないもの

・画面遷移/操作(試合を観る・スキップ)・カード数・宿命/友好の表示意味・明細3行の構成

惜敗
紅蓮社中とブラックスター・ローの比較が、ここに来て興味深い様相を呈している。エース対決は阿武隈塔子が+2と逆転、しかし層の厚みと集客力では依然として大きな差。だが10週後を見据えれば——本紙はあえて言う。逆転は射程内、と。

まずエース対決。阿武隈塔子の今期の伸びは、関係者の予想を上回る。OVR 75は、ブラックスター・ローの看板である橘玲美の73を、今期初めて上回った数字だ。集客面でも、塔子の入場時の歓声は他団体エースに引けを取らない。

問題はNo.2以下だ。深町真琴(OVR 68)は生駒エリカ(OVR 73)に5ポイント差で押されている。三番手は五分だが、戦力の厚みで勝負すると、こちらの薄さが余計に目立つ構図。集客力の-13という数字は、団体としての地力の差そのものを示している。

とはいえ、10週もあれば状況は変わりうる。塔子の覚醒が本物なら、その背中を追いかける深町・高津の数字も上がるはずだ。「社長次第」という黒田の評は、決して見放した言葉ではない。

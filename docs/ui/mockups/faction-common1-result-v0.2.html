このゲームの試合データ仕様(matchResult の中身) を確認した上で、表示するのは以下のみ:
  • winner → 勝者名 + WIN/LOSE バッジ
  • mq → スコア + ★ 表示(既存 _pbStars と同パターン)
  • finType + finMove → Engine.formatFinish で「{技名} → 3 カウント / ギブアップ / レフェリーストップ」
  • turns + finishPhase → 「12 TURNS · CLIMAX」のように決着フェーズも添える(Climax 決着なら名勝負感が出る)
  • hpLeft.final / hpRight.final → 残 HP バー(既存 _pbHpMini と同)
削除した架空の数値:
  • 大ダメージ数 — matchResult に集計値として無い(bigMoves はローカル変数でクローズ後に消える)
  • カウンター数 — 同上(totalCounters もローカル)
これらは MQ の dramaPenalty 計算に内部で使われているだけで、UI 表示用の field にはなっていない。出すなら matchResult の戻り値に追加する必要があるが、別件のスコープなのでこの v0.2 では出さない。 セリフ配置の修正:
  • 左右並列の独立カードではなく、勝者/敗者それぞれの頭上に吹き出し(打診モーダルと同じ #f0f0f0 + 三角尻尾下向きルール)
  • 勝者吹き出しの話者名はゴールド、敗者は沈ませた色(#8a6a52)
  • セリフは既存 COMMON1_LINES.resultLeader / resultLoser を性格別に拡張(現状 _any のみ → personality 6 種化が次の課題)
その他確定要素:
  • 敗者ポートレート: filter:saturate(0.55) opacity(0.78) で沈ませる(クロニクル退団カードと同手法)
  • 名前・ポートレートクリックで showFighterPopup(id, 'roster')
  • 影響行は色分け: 信頼度 + → 緑、 - → 赤、因縁解消 → ゴールドで「-41(解消)」と意味補足
  • 「2 名間の因縁」など内部変数名(rivalry / trust)は表に出さず日本語化
実装メモ:
  • 新規関数 _renderCommon1MatchResult(payload, matchResult, fA, fB, impactSummary) を ui-common.js に追加
  • App._finalizeCommon1Match で showFactionEventResult 呼び出しを差し替え
  • 使用 utility: Engine.formatFinish / _pbStars / showFighterPopup / pickDialogueLine
  • セリフは Engine.factions.getCommon1Line('resultLeader', {choice:'A', leader, vars}) と ('resultLoser', ...) で引く(既存 API そのまま)

F07 v2.2 改訂（2026-05-02）: spec §9.7 / factions.js 実装に厳密準拠。
DEMAND_ABSTRACT（権威要求）の効果は trust／ロッカー士気／dictatorTag・authoritativeTag といった「内政メーター」。
DEMAND_MAIN（メインカード要求）の A 選択は、6 興行の縛りが入るよう拡張済み。期間中、各興行のメインに当該派閥メンバーが 1 名以上含まれていればメンバー trust +1、含まれていなければリーダー trust -2 が興行精算時に発火し、興行編成画面に「残り N/6 興行」のバナーが表示される（specs/faction-system-spec-v0.1.md §9.7 参照）。

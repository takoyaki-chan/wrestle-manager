差が出たのは四番手から八番手の五人だ。ノヴァインパクトはこの帯に七十台を四人並べており、興行の中盤をそのまま任せられる。対して我が団体は同じ帯に二人しか居らず、残る三枠は六十台前半で埋めている。エースが勝っても中盤で貯金を吐き出す——今季ここまでの対抗戦で繰り返されてきた形だ。

もっとも、四軸のうち三軸で先行しているのは事実である。集客力の差は八点あり、同じ会場を押さえたときの動員では我が団体が上回る。数字が示しているのは弱さではなく、偏りだ。

一面と揃えるために捨てた表現

捨てたものあった場所理由
純黒パネル（linear-gradient(180deg,#1a0d04,#2a1a10) ＋ 内側の光）二面 .np-ace-confront／三面 .np-rivalry-mainクリーム紙（Office）の中に Stage の黒を持ち込んでいた。ここだけ別の画面に見える最大の原因
暗色バー .np-result-line の系統二面同上。紙の上に置く帯は罫と地の色で作る
240〜280px のスタンド写真枠三面 .np-rivalry-stand写真の梯子（190×228／84×126／46×66）の外。人物の大きさが面ごとに変わって見える
3:4 の写真枠四面 .np-mvprace-photo（aspect-ratio:3/4）素材は 2:3。3:4 に入れると脚側が切れる（mockup-baseline §2-0）
28px／32px／36px の Bebas 数値ブロック四面 順位オーバーレイ・OVR ボックスランキング表に見えて記事に見えない。36px の GRADE だけは囲み記事の中に残した
26px 中央寄せ見出し＋囲みラベル三面 .np-rivalry-headline27px は一面トップの予約席。中央寄せの見出しも一面に無い
22px 見出し＋赤帯付きリード四面 .np-page-headline / .np-page-lead一面のスケールに無い中間値。18px 見出し＋13px リードへ
字間演出の区切り（「— 4 位 以 下 ・ 追 走 集 団 —」）四面 .np-mvprace-divider見出し部品を面ごとに増やさない。kicker へ
.np-sec / .np-sec-gold（赤・金のセクションラベル）二面・三面kicker と役割が重複。kicker 1系統に寄せる
📊 などの絵文字見出し四面紙面に絵文字が出るのは新聞に見えない
「◆」区切りの金文字ファクト帯三面 .np-rivalry-facts一面の短信（▼区切りの連結ベタ）と同じ形にまとめた
角丸カード＋落ち影の一覧（border-radius:8~10px ＋ box-shadow）二面 .np-org-card／.np-spotlight、三面 .np-relation-card紙面に「カード」は無い。罫と余白で区切る

判断が要る点（Keisuke 確認事項）

#論点本モックでの選択
1面の頭の見出しを 27px にするか 18px にするか18px。27px を一面トップの専用にしないと、大きさの階段＝ニュースバリューが崩れる。特集面が弱く見えるなら 27px へ上げる余地はある
2GRADE の 36px Bebas指示どおり残した（囲み記事の中）。ただし一面のタイプスケールには無い値なので、消して 27px 相当に落とす選択もある
3比較バーの色（自陣＝赤／相手＝金）紙面パレット内での選択。赤は紙面の主色でもあるため、自陣＝金／相手＝墨 に入れ替える案もある

ビジュアルの狙い
・名勝負の額 — MQ記録は「数字」ではなく「一戦」として飾る。両者の顔が対峙し、中央にスポットライトを浴びた評価点。額縁(四隅の金飾り+二重ボーダー)で「会館に飾られた記念額」の趣。シングル=金、タッグ=青の照明で書き分け
・王者の肖像 — 最多連続防衛は王冠を頂く顔写真+大きな防衛数。在位期間を添えて「時代」を感じさせる
・月桂樹の歴代優勝列 — 天頂戦(金)とPPV(紫)は顔メダリオン+🌿+シーズン番号の横列。直近から並べ、増えたら横スクロール。天頂戦の次回開催枠は破線の空席で「4年に一度」を予感させる
・記録更新週は該当額に「記録更新!」バッジが点滅(新聞の大ニュース記事とリンク)
・同一選手が複数箇所に登場するのは意図どおり(時代の主役が壁面を占拠していく)。顔タップで選手詳細へ

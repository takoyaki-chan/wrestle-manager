・現行 JT の試合結果画面(renderJuniorTournamentMatchResult)は既に天頂戦(renderTenchosenMatchResult)と同じ pb-container / pb-mrow.is-main.is-jt を共有しており、アッパー画像(2:3矩形・108×162)・勝者色枠・敗者モノクロは両者ともすでに同一構造。 本モックは アッパー画像をさらに大きく主役化(168px幅)し、スコアストリップ(Round/Match/MQ/Finish の4分割グリッド)を廃してシンプルな中央チップ列に統合したヒーロー版の提案

試合後の流れ(自動進行のテンポ)— 天頂戦の流儀に統一
・この結果画面から「次の試合へ ▶」を押す(またはタップ)と、天頂戦と同じテンポで ①勝者リングが点灯 → ②クライムラインの該当セルが「せり上がりアニメ」(jtc-rise)で出現 → ③次段のフォーカスカードが自動で下に続く、という一連の流れで進行する。 決勝決着時のみ、頂上ブロックのせり上がり後に 1.6秒の自動遷移(タスク1で app.js に実装済み・App._jtPeakTimer)が入り、無期限のタップ待ちは発生しない
・「全試合スキップ」時も App.jtSkipAll が段単位で 0.5秒間隔でせり上げてから優勝発表へ渡す、天頂戦の tcSkipAll と同一のテンポ設計を踏襲(実装済み・変更不要)

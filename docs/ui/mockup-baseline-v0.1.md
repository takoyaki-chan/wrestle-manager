# モックアップ共通ベースライン v0.1

> 起案 2026-07-25。**UI統一リデザインで作る全モックアップは、この物差しの上で作る。**
> バラバラのルールで作ったモックを並べても比較にならず、判断ができないため（Keisuke 指示）。

## この文書の位置づけ

- `docs/ui/01-foundations.md`（色・カテゴリ）を前提に、**サイズと配置の基準**を補うもの
- 既存実装には**フォントサイズの基準が存在しない**（9〜32px が場当たりに使われている）ため、ここで定める
- **モックアップ作成時は必ずこの値を使う。** 逸脱する場合はその理由をモック内に明記する

---

## 1. タイプスケール

実装の実測（`font-size` 出現頻度: 11px=300回 / 10px=252 / 12px=208 / 13px=168 / 9px=140 / 14px=122 …）を踏まえ、**使用実績のある値に寄せて7段階**に整理する。

| 役割 | サイズ | 用途 | フォント |
|---|---|---|---|
| `display` | **28px** | 大会名・最重要の数値（スコアなど） | `--font-display` (Bebas Neue) |
| `title` | **18px** | モーダル見出し・画面タイトル | `--font-body` 太字 |
| `subtitle` | **15px** | 選手名（主役）・セクション見出し | `--font-body` 太字 |
| `body` | **13px** | セリフ本文・説明文 | `--font-body` |
| `label` | **11px** | 役割ラベル・団体名・補助情報 | `--font-body` or `--font-label` |
| `caption` | **10px** | 注記・単位・日付 | `--font-body` |
| `micro` | **8px** | 英字キッカー・記号ラベル（`OVR` `MQ` など） | `--font-label` 字間広め |

**禁止**: 上記以外の中間値（16px, 17px, 21px, 22px…）を新規に使わない。既存実装の値をモックへ持ち込まない。

### 数字の扱い
- スコア・OVR・MQ などの**数値は `--font-display`**（Bebas Neue）で大きく
- 数字が縦に並ぶ表は `font-variant-numeric: tabular-nums`

---

## 2. 選手画像（アッパー）のサイズ

実装には 100×120 / 100×150 / 120×160 / 132×194 / 140×168 / 150×225 / 160×240 が混在。**3段階に統一**する。

| 段階 | サイズ | 縦横比 | 用途 |
|---|---|---|---|
| `hero` | **172×200** | 1:1.16 | 1人を主役として見せる（勝利報告・優勝発表・敵将の落胆） |
| `duo` | **132×194** | 1:1.47 | 2人を対置する（試合結果の左右・対戦カード） |
| `chip` | **46×56** | 1:1.22 | 一覧・隊列・小さな並び |

- 角丸は `--radius-md`(6px)。下辺のみアクセント色の3px境界（勝敗・所属を示す）
- 敗者は `filter: grayscale(.9) brightness(.72)` ＋ 下辺境界を無彩色に

## 3. 吹き出し

| 項目 | 値 |
|---|---|
| 位置 | **キャラ画像の上**（被せない・横や下に置かない） |
| 中身 | **セリフ本文のみ**（名前・所属を入れない） |
| 高さ確保 | **予約枠**（`position:absolute` で浮かせない）。発言が無い側にも同じ高さの空枠を置き、左右の画像上端を揃える |
| 枠の高さ | `hero`/`duo` = **52px**（2行想定）／`chip` = 40px |
| 行数制限 | `-webkit-line-clamp: 2` |
| 本文サイズ | `body`(13px)。`chip` 併用時は `label`(11px) |
| 尻尾 | 画像の**水平中心**を指す |
| 角丸 | `--radius-lg`(10px) |

※ 実データの最長セリフは43文字（`VICTORY_LINES` / `AUTUMN_WAR_MATCH_LINES`）。52px で2行に収まる。

---

## 4. 縦の並び順（顔出しブロック）

```
吹き出し（予約枠）
  ↓
選手画像
  ↓
名前            subtitle(15px) 太字
役割ラベル       label(11px)
団体バッジ       ← 他団体が絡むときのみ
数値(OVR等)      display(28px) + micro(8px)の単位
```

**この順序は固定**。画面ごとに入れ替えない。要らない要素は省く（順序は変えない）。

---

## 5. 団体バッジ

| 項目 | 値 |
|---|---|
| エンブレム | **実画像を使う**（`orgIconHtml()`）。頭文字の代用は禁止 |
| サイズ | バッジ内 26px ／ 単独掲示 40px ／ 見出し上の強調 62px |
| 団体名 | `label`(11px) `--font-label` |
| 囲み | 角丸ピル。自陣=`--c-positive` 系／敵陣=`--accent-hostility` 系の枠線＋薄い塗り |
| 出す条件 | **他団体が絡む試合のみ**。自団体内の試合では出さない（配置は変えずバッジだけ省く） |

---

## 6. 余白のリズム

既存の `--space-*` を使う。**新しい余白値を作らない**。

| トークン | 値 | 主な用途 |
|---|---|---|
| `--space-xs` | 4px | 要素内の細かい隙間 |
| `--space-sm` | 8px | 名前と役割ラベルの間など |
| `--space-md` | 12px | ブロック間 |
| `--space-lg` | 16px | セクション間・カード内側の余白 |
| `--space-xl` | 24px | 画面の外周 |

- カード外周は `--space-lg`
- 左右対称レイアウトの中央カラムは **150px**（試合結果系）

---

## 7. 色

`docs/ui/01-foundations.md` の3カテゴリ（Office / Stage / Ceremony）に従う。

- **ハードコード16進カラー禁止。** 必ず `var(--*)` を使う
- モックアップでも**実トークン値を再現**する（実装時に色が変わるのを防ぐ）
- 勝敗: 勝=`--c-positive` / 負=`--accent-negative` / 引分=中間色
- 陣営: 自=`--c-positive` 系 / 敵=`--accent-hostility` 系

---

## 8. モックアップの作り方（運用）

1. **現状の全バリエーションを1枚に並べる**（何がどう違うか可視化する）
2. その下に**リデザイン案**を置く。左右または上下で比較できる形に
3. **注釈で「現→変」を明記**する
4. 変更点・判断が要る点を**画面末尾にリスト**する
5. **この文書の値を使う。** 逸脱するなら理由を書く

### やってはいけないこと
- モックごとにフォントサイズ・画像サイズ・余白の基準を変える
- 既存実装の場当たりな値をそのままモックへ持ち込む
- 「既にそうなっているから」を理由に設計判断を省く（既存部品が正しい保証はない）

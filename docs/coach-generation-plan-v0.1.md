## 1. 引退サイクル(裁定済み: 在籍年数基準)

- **対象**: 雇用中の常任コーチ。招聘の限定トレーナー(4週)は対象外
- **腰を据える年数(tenureLimit)**: 雇用時にコーチごとに決定論的に決まる(シード+コーチID)。**年齢帯で幅を変える** — 〜44歳: 6〜8季 / 45〜54歳: 5〜7季 / 55歳以上: 3〜5季。「引退の引き金は在籍年数」の裁定を守りつつ、高齢コーチほど残り時間が短い実感を出す
- **退任予告**: 期限の**1季前のオフ**に「次の季限りで退任したい」通知(道場バナーのコーチ吹き出し+週次レポート1行)。社長に後任を探す時間を与える
- **退任**: 期限季のオフに退任。コーチの一言(voice 8系統・後日執筆)+通常モーダル1枚(セレモニー級にはしない — 原則11)。市場からも消える(復帰なし)
- **再雇用**: 同じコーチを雇い直した場合、tenureLimitは引き直し(通算ではなく今回の在籍で数える — 出戻りの短期契約を許す)
- 将来接続: 引退選手→コーチ転身(scout-system-spec §8.2)は本サイクルの供給源として別途起票

## 2. 市場の回転(供給側)

- **新コーチ25名は一括登場させない**。データとしては全員 `ALL_COACHES` に追加するが、市場には**「コーチが1人引退するたびに、近い帯(grade±給与帯)の新顔が1人市場入り」**する段階供給(＋雇用と無関係に年1名の自然入場)。市場が60名に膨れて選択画面が壊れるのを防ぎ、「世代が入れ替わっていく」体感を作る
- **未雇用の市場コーチも緩やかに回転**: 市場に出てから8季雇われなかったコーチは静かに市場から退場(通知なし・データ上は引退扱い)。ただし**各coachingType・観察眼A・希少アビリティの「最後の1人」は退場させない**(機能の絶滅防止・fail-safe)
- 既存セーブ: 雇用中コーチは**ロード時点から在籍年数を数え始める**(遡及しない=急に追い出さない)

## 4. 裁定点(5点)

1. **tenureLimitの形** — 年齢帯で3〜8季・雇用時に確定(推奨どおりか)
2. **退任予告** — 1季前に通知する(推奨: あり。後任探しのゲーム性と「別れの準備」のドラマ)
3. **市場の段階供給+未雇用8季で静かに退場**(絶滅防止セーフガード付き) — 推奨どおりか
4. **S級(伝説コーチ)は今回作らない** — 推奨どおりか
5. **25名の配分表(§3)** — この割り付けでキャラ起草に入ってよいか

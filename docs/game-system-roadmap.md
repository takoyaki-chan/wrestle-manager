**旧設計（セッション10時点）** — 以下はセッション12で改訂済み。最新仕様は `specs/ppv-awards-spec.md`、`specs/v1.3-1-decay-retirement-spec.md`、`specs/v1.3-3-retirement-presentation-spec.md` を参照。
- ファンファーレで開始
- 賞を一つずつ順番に発表：新人王 → ベストマッチ → 各タイトルチャンピオン（在位週数付き） → 1位団体チャンピオン（特別枠） → トーナメント優勝者（開催年のみ）
- 最後に全受賞者を一覧表示
- 新人王：その年のデビュー選手中、年末時点OVR最高
- ベストマッチ：試合スコア（注目度・レーティング）が最高だった試合

**殿堂入り（条件を満たした引退選手のみ）**
- 条件：通算獲得回数＋防衛回数の合計**13回以上**、または**全タイトル制覇（グランドスラム）**のいずれか

- 演出：ファンファーレ→荘厳な音楽に切り替わり→金の盾表示→フェードアウト
- 複数人の場合は一人ずつ順番に表示

**金の盾に刻む内容**
- 選手名・所属団体・現役期間（〇〇年〜〇〇年）
- 保有タイトル名・在位週数・防衛回数・複数回制覇の明記
- 達成偉業（グランドスラム等、該当するもの）
- 選手の顔アイコン

**実装に必要なデータ（v1.3で対応）**
- `titleHistory`：選手ごとに取得週・喪失週・防衛回数を記録

- **発生条件**：チャンピオンが3回以上防衛済み、かつタイトルマッチ当日に20%の確率で発生

- **結果**：勝利で人気+2、敗北でヒート-15〜-20（ハイリスク・ローリターン）

## 確定済み設計決定事項

- **年齢割引は導入しない** — ティアベース評価額（assessedValue）を維持
- **ランダム生成キャラは廃止** — スカウトは全員ALL_CHARSの既存キャラのみ
- **ランキング色は順位ベース** — 団体固有色ではなく順位で色が変わる
- **社長キャラは廃止** — 敵団体は看板選手（★看板）がストーリー上の顔
- **エース制度は廃止** — チャンピオンが団体の顔。引き抜き防御・残留・スキャンダル保護はすべてチャンピオンに統合
- **団体名はランダム** — RIVAL_ORG_NAME_POOLからゲーム開始時に決定
- **引き抜きは交渉制** — 4週間の交渉期間＋成功率判定
- **ロスターランダム化** — potTotal重み付き配分。S級≥690, A級≥640。シリーズボーナス+0.3。dormant動的計算
- **チャンピオン集客ボーナス** — チャンピオン出場時に集客×1.10
- **乱入マッチ** — チャンピオン3回防衛後、タイトルマッチ当日に20%で発生。隣接団体OVR90%以上の選手が乱入。勝利+2/敗北-15〜-20
- **フレーバーイベント** — チャンピオン or 人気55以上に12%/週。雑誌取材（人気+2〜3）・TV出演（ヒート+2〜3）
- **殿堂入り条件** — 獲得＋防衛合計13回以上、またはグランドスラム
- **衰退・引退はdurability + wear方式** — 年齢ベースの旧テーブルを全廃。durability（正規分布μ=0,σ=2）で個人差。wearは28+durability歳から蓄積。wear 20〜39で軽度衰退、40〜59で本格衰退（引退20%/年）、60〜79で末期（50%/年）、80+で確定引退
- **壊滅的怪我（career-ending injury）** — 重傷時に追加判定。基本2〜3%、ベテラン(wear40+)は5〜8%。年齢・wear問わず即引退。数シーズンに1回程度の稀少イベント
- **怪我引退（wear超過型）** — 重傷発生時にwear+怪我ボーナスが80超で引退確定。ベテランほど起きやすい
- **引退演出は1種類** — 全選手共通ポップアップ（顔画像＋経歴＋セリフ）。殿堂級も同じ構成（セリフが1行多い程度）。殿堂入り発表は年末表彰式で
- **引退セリフは引退ルート×キャリア×性格で分岐** — シーズン末（達成感/悔しさ/強がり/愛着）、怪我（若手の無念/全盛期の残酷/ベテランの覚悟/王座返上）
- **PPVは全団体合同大会** — エントリー制（4週前締切）、対戦相手は当日まで不明、枠数はランク依存（S=5,A=4,B=3,4位=2）、エントリー後の怪我は不戦敗
- **PPVマッチメイクは盛り上がり優先** — 因縁最優先、次に盛り上がりスコア（OVR合計+人気-OVR差）。リアリティではなくかっこよさで選ぶ
- **PPVに特別なシステム効果なし** — 人気・ヒート変動は通常興行と同じ。体験そのものがご褒美
- **新人王トーナメントは廃止** — 表彰式の「新人王」に統合（全団体の1年目選手からOVR最高を選出）
- **年末表彰式3賞** — 新人王（全団体1年目OVR最高）、ベストマッチ（各団体1試合ずつ計4試合から最高MQ）、MVP（各団体エース1名ずつ計4名からスコア最高）
- **MVP/ベストマッチは各団体1枠** — S-tierの数の暴力を防ぐため。AI団体のデータはティアベース＋ランダムで生成

### v1.3-2: 個人実績記録システム（careerRecord）

**データ構造** — `fighter.careerRecord`:
- `history[]`: 時系列イベントログ。選手の歩みをポップアップ詳細で表示可能
- `totalTitleWins` / `totalDefenses`: 殿堂入り判定用キャッシュ
- `peakOVR` / `peakOVRSeason`: 全盛期記録

**イベントタイプ**:
| type | 記録タイミング | フック箇所 |
|------|-------------|-----------|
| `debut` | ドラフト/FA契約/スカウト獲得 | app.js |
| `titleWin` | 戴冠 | engine.js `crownChampion` |
| `titleDefense` | 防衛成功 | engine.js `recordDefense` |
| `titleLoss` | 王座陥落 | engine.js `crownChampion`（前王者側） |
| `war` | 対抗戦出場 | app.js `finalizeWar` |
| `summit` | 頂上決戦出場 | ui-common.js `executeEvent` |
| `transfer` | 移籍（交渉/引き抜き） | engine.js `resolveNegotiation`/`resolvePoach`/`playerPoach` |
| `retire` | 引退 | engine.js `advanceWeek` offWeek1 |
| `peakOVR` | シーズン末 | engine.js `applySeasonEnd` |

**GameState追加**:
- `retiredFighters[]`: 引退者一時保管（年末表彰式後に殿堂入り者のみ `hallOfFame` へ移行、残りは破棄）
- `hallOfFame[]`: 永続的な殿堂入り記録

**マイグレーション**: `_migrated_v1_3` フラグで既存セーブの全選手に空のcareerRecordを付与

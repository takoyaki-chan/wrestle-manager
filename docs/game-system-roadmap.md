#### アイデア: 上限撤廃＋「過去最高MQ」を基準にした相対評価（2026-07-20 Keisuke 起案・**決定ではない**）

**MQの上限を撤廃し、名勝負かどうかを絶対値ではなく「過去最高MQからの距離」で判定する。**

- 上限を外すと、いずれ100を超える試合が出てくる
- 過去最高が105になったら、**105を基準にそこから−5点までを名勝負扱い**とする
- 団体が成長し名勝負が生まれるほど、次に名勝負と認められるハードルも上がっていく

絶対値の天井を撤廃したうえで、「その団体がこれまでに到達した最高点」を動く基準線にする案。名勝負の希少性が自動的に保たれ、記録更新そのものがドラマになる。年代記・新聞・実績といった既存の記録系システムとも噛み合う。

**検討時に詰めるべき点**（着手時にフェーブルと議論する）:

- **基準のスコープ** — 自団体の過去最高か、全団体を通じた世界記録か、シーズン内の最高か。どれを取るかで意味が変わる
- **序盤の扱い** — ~~開始直後は過去最高そのものが低いため、名勝負のハードルも低くなる~~ → **基準の初期値を100として開始する案（2026-07-20 Keisuke 追記）**。ゲーム開始時点の「過去最高」を100と置くことで、序盤のハードルが下がりすぎる問題が解消する。誰かが100を超えるまでは実質的に現行と同じ体感で、記録が破られた瞬間から基準が動き出す
- **下流への波及** — MQを絶対値で閾値比較している箇所（trust・実績・ニュース・年代記など）が相対判定に置き換わる。影響範囲は `docs/mq-inventory-report.md` §6 の一覧を参照
- **プレイヤーへの見せ方** — 「100点満点」という直感的な分かりやすさが失われる。記録更新型の表示（過去最高◯◯点／今回はそこから−3点）に置き換えるなら、その演出設計が要る

#### 論点

- 上限を外すと「100点満点」という分かりやすさが失われる。一方で名勝負に天井があると、**最高の試合ほど差が潰れて見える**。**表示上は100点満点のまま内部で上限を持たない**、という折衷も含めて設計判断する
- 外部ボーナスをフラット加算からどう作り替えるか（乗算／条件付き／素点の性質に応じた効き方の変化など）
- 特性の効果をどう表現するか

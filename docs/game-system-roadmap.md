### なぜやるか

段階的に「触るときに直す」方式では**触られない画面が永遠に取り残される**（実例: `.speech-bubble` が画像の下に付いたまま8画面で放置）。
そこで **①用途ごとにリデザイン → ②モックアップで承認 → ③その用途を一括改変** の順で進める。
**既存の共通部品は「既にある」だけで設計として正しい保証はない**（Keisuke 裁定）。既存に寄せることを前提にせず、必ずモックアップで判断する。

- **画像サイズは 2:3 固定の5段の梯子**（XL 172×258 / L 150×224 / M 132×194 / S 108×162 / chip 46×66）。主役度で段を選ぶだけにし、画面ごとにその場で決めない。段の間は12%以上空ける（当初6段だったが M→S が4.5%しか違わず差が読めなかったため統合）
- **画像の素材は2系統**（U7 で明文化）。**アッパー=2:3**（主役として見せる／上の梯子）と **face=1:1**（一覧の行に差し込む／`card` 52・`row` 40・`row-sm` 24 の3段）。2:3の梯子を正方形に当てはめると顔が切れるので、正方形には別の段が要る。**大きく見せたい画面は正方形を拡大せず 2:3 に乗せ替える**
- **顔が出ているなら押せば選手詳細が開く**（U7）。ただし**開けるデータが無い選手には手を付けない**（年代記の退団者・旗揚げ時点の候補）。「押せそうなのに無反応」は押せないより悪い
- **セリフの吹き出しは白（クリーム）＋黒文字。例外なし。** ただし**この規則が掛かるのはセリフだけ**で、地の文・ナレーション・雰囲気テキストは白でなくてよい（むしろ白でないことがセリフとの見分けになる）
- **隊列は1つの群として囲む**（案C）。一人ずつ額縁を付けず群の外枠1つ、18px重ね。アッパーは透過画像なので1枚ごとの背景・枠・境目は付けず、落ち影は `drop-shadow` を使う
- **丸い顔アイコンは一覧・通知専用として残す**。同じ画面に複数同居するときは大きさで階層を作る（道場バナー: コーチ48px ＞ 練習中40px ＞ 休憩中34px）
- **勝敗の格差は、2人を並置する画面ではサイズで付けない**（灰色化と下辺の色で表す）。**1人ずつ見せる画面では勝者を一段上げてよい**（左右の対称性を保つ必要がないため）
- 団体エンブレムは**実画像を使う**（頭文字の色丸で代用しない）

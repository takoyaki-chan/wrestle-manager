## UI統一リデザイン（U1〜U8） — 現在の本線

> 起案 2026-07-25。着手順は同日確定。
> **仕様の正**: `docs/ui/ui-unification-plan-v0.1.md`（作業単位）／`docs/ui/mockup-baseline-v0.1.md`（全モックアップ共通の物差し）

### なぜやるか

段階的に「触るときに直す」方式では**触られない画面が永遠に取り残される**（実例: `.speech-bubble` が画像の下に付いたまま8画面で放置）。
そこで **①用途ごとにリデザイン → ②モックアップで承認 → ③その用途を一括改変** の順で進める。
**既存の共通部品は「既にある」だけで設計として正しい保証はない**（Keisuke 裁定）。既存に寄せることを前提にせず、必ずモックアップで判断する。

### 確定した決定事項

- **通常興行のテーマ色 = 自団体の金（案A）**。現状は専用色が未定義で `.emr-layer` 既定の `--ev-winter`（金茶）を継承しており冬と同色に見えていた。U1で適用
- **天頂戦 = PPVの深紅**（`.emr-layer.is-tenchosen,.emr-layer.is-ppv` と同じ色言語）
- **特別興行の優勝者は全て金枠**。優勝チーム／MVPの称号文字はチャンピオン相当の派手な金
- **タッグリーグは2名を必ず横一列**、**秋4団体対抗戦は3名を横一列**（先鋒左／大将中央／中堅右・カード枠で区切らない）。**MVPは主役にせず一段小さく添える**（実装時に判明: この game の役職は先鋒／中堅／大将で「次鋒」は存在しない）
- **画像サイズは 2:3 固定の6段の梯子**（XL 172×258 / L 150×224 / M 132×194 / S 126×188 / XS 120×180 / chip 46×66）。主役度で段を選ぶだけにし、画面ごとにその場で決めない
- **勝敗の格差は、2人を並置する画面ではサイズで付けない**（灰色化と下辺の色で表す）。**1人ずつ見せる画面では勝者を一段上げてよい**（左右の対称性を保つ必要がないため）
- 団体エンブレムは**実画像を使う**（頭文字の色丸で代用しない）

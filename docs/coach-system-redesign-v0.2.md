## 3. 設計原則（v0.1から継続）

- MQや勝率を数値で直接いじる能力はNG
- 直接的すぎるイベント操作はNG
- つけ外しの悪用を防ぐ設計（効果は「ついてる間ずっと」が基本）
- A級の能力に見合った金額（週135〜160万でも価値があるなら払う）

### 検証中に発見された重要な知見

1. **距離比率ベース成長の特性**: 速度倍率を上げても最終値が変わらない（trainCapに収束）。天井を変えるか、到達経路を変えるかの2方向で考える必要がある
2. **ステ特化は練習選択率UP方式が正解**: trainCapを上げるとC能力としては強すぎる。選択率UPなら「育成方向を選ぶ」能力として最終値を変えずに機能する
3. **才能開花は「ピーク前倒し」ではなく「ペナルティ緩和」が正解**: 前倒しは成長期間短縮でピークOVRを下げてしまう
4. **人心掌握の当初候補（×0.5〜0.7）は強すぎた**: ×0.90が適正。trust系は微調整が効く

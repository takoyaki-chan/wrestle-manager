## 1. 転用できる資産

レッスルマネージャーが持っている「見せ方の発明」のうち、創作作品に持ち出せるもの。

| 資産 | 実体 | 創作作品への転用価値 |
|---|---|---|
| 紙面メタファー | `.np-paper` 780px・クリーム紙・赤ヘッダー・1面/2面/3面 | フィクションを「当時の報道」として提示すると実在感が出る |
| 黒田叙述 / 記者の目 | データから叙述文を生成する語り手レイヤー | 作者の声ではない第三者視点で語らせる |
| 年代記の章構造 | `focusSeason` ベースの**重複を許す**章分割 | 同じ子を「世代の希望」「時代の覇者」「老兵」として何度も照らす目次 |
| 因縁列伝 | 9象限分類 + `h2h.history[]` + context バッジ | 関係性を数字ゼロで言葉にする紙面 |
| クライムライン | `jtc-*` 縦積みブラケット + アッパー対面フォーカスカード | 進行表そのものを読み物の骨にできる |
| Ceremony テイクオーバー | レターボックス・明朝・600〜1200ms・スライド進行 | クライマックスだけ時間の流れを変える |
| Glimpse Cascade | 白吹き出しが 260ms 間隔で降ってくる | 会話劇・群像のざわめき |
| 経歴年表 | キャリア相対年での折りたたみ年表 | 一人の人生を縦に読ませる |

## 2. 検討した 5 案

| 案 | 内容 | 状態 |
|---|---|---|
| **1. 架空専門誌のバックナンバー棚** | 作品を「週刊グラップル」の全号として並べる。読者は年を選び、その週の紙面を読む。物語は記事の集積として浮かび上がる。読者は最後まで**外側の人**でいられる（三本柱「覗き見る」と一致） | 🟢 v0.1 試作 |
| **2. 一試合を縦スクロールで読む「実況譜」** | スクロール位置＝試合経過時間。両者の HP バーが上部に固定で貼り付き、スクロールに従って減る。技名は出し手の側からカットインし、観客熱が背景の明度を押し上げ、決着だけ組版が変わる | 🟢 v0.1 試作 |
| **3. 関係性から入るトップ** | トップがキャラ一覧ではなく相関図。線をクリックすると 2 人の因縁列伝が開き、そこから該当試合へ潜る。キャラ中心ではなく関係中心のナビゲーション | 未着手 |
| **4. 同じ子を何度も照らす目次** | 年代記の重複章構造をそのまま読み物の目次にする。「CH.1 で脇役だった子が CH.5 の主役」を重複バンドで可視化。読む順で意味が変わる | 未着手 |
| **5. 引退式から遡る** | 入口が引退セレモニー（Ceremony 全画面）。そこから逆順に人生を読ませる。結末を知った状態で読み始める構造 | 未着手 |

**採った構成**: 案 1 を器にして、案 2 を中の一記事として通す。
紙面棚を歩いていると、ある一戦だけ「全文実況譜あり」のリンクがある。そこを開くと縦スクロール実況譜に落ちる。
器で実在感を作り、一点で殴る。記事を 1 本ずつ足して育てられる。

## 3. 試作物

**`backnumber-shelf-and-scroll-v0.1.html`** — 単一ファイル。ブラウザで直接開ける。

### 3 ビュー構成

```
紙面棚 (Office)
  └─ No.1146 をクリック
       └─ 一面 (Office / Cream Panel)
            └─ 「全文実況譜を読む」
                 └─ 実況譜 (Stage → 決着で Ceremony 混入)
```

### Foundations への準拠

- **3 カテゴリを混同しない**: 棚と紙面は Office（暖茶＋クリーム）、実況譜は Stage（純黒）。
  実況譜に Cream Panel は一つも置いていない
- **カテゴリ間の遷移で照明を落とす**: 紙面（クリーム）↔ 実況譜（純黒）の切替時に 520ms の暗転を挟む。
  Office と Stage が画面内で同居しない原則を、遷移の演出として使った
- **ハードコード 16 進はトークンブロックのみ**。以降は全て `var(--*)`
- **左右対置ルール（原則 9・10）**: HP バーは側で色分けしない（同色。危険域でのみ変色）。
  左は左端から右へ、右は右端から左へ伸びる鏡映し。側の違いはレイアウトだけで示す
- **アッパー画像は左右反転禁止**: 対面カードでも両方そのまま置いている
- **紙面のみ明朝を許容**: `newspaper-mockup-v8.html` が Noto Serif JP を使っている既存慣行に合わせた

### ダメージセリフ / ボイスの発動ルール（CLAUDE.md）を演出に反映

実況譜のセリフは HP 残量で出し方を変えている。

| HP 帯 | 出したもの | 該当ビート |
|---|---|---|
| 66% 超 | 通常のセリフ | 高津 74%「……っ、まだ、序盤でしょ」 |
| 34〜66% | 短いセリフ or 悲鳴 | 高津 58%「──あぐっ」／塔子 44%「……いい夜だね」 |
| 33% 以下 | **ボイスのみ。長文セリフは出さない** | 高津 29%「……ぁ」＋ `Voice only` 表記 |

`.beat-cry` は「言葉にならない」ことをそれ自体で見せるビート型として独立させた。

### モック用の中身

架空の一戦。素材はゲーム内のキャラと画像を流用している。

- 誌名 週刊グラップル No.1146 / 7年目 秋 第11週
- 団体 燈火女子プロレス『秋螺旋 −AUTUMN SPIRAL−』最終戦・シングル王座 第7次防衛戦
- 王者 **阿武隈塔子**（34歳/16年目/Grappler/`personality:normal` × `archetype:composed`）

  短く切る・「…」で間を作る・ベタな勝利宣言をしない

- 全 26 ビート / 22分34秒 / 観衆 6,842

## 4. 機械検証済みの項目

Chromium で自動確認した（実機の見た目は未確認）。

- JS エラー 0 / 画像リクエスト失敗 0
- 3 ビューの往復（棚 → 一面 → 実況譜 → 一面 → 棚）が全て通る
- スクロール連動が実際に動く: HP 100/100 → 93/58 → 78/39 → 44/29 → 19/29 と補間、
  危険域クラス（`is-warn` 66% / `is-danger` 33%）が閾値で切り替わる
- 観客熱 10% → 98% まで連動、背景グロウの opacity が 0.009 → 0.823 まで追従
- フェーズラベル Opening → Early → Middle → Late が進行
- 決着ビート到達でレターボックスが 67.5px 出る（`body.is-finale`）。ビュー離脱で解除される
- 375px で横方向のはみ出し無し（3 ビューすべて scrollWidth = 375）

## 5. 次にやるなら

1. **実況譜の 2 本目を書く**。1 本では形式の当たり外れが判断できない。
   タッグ戦か、逆に「何も起きない試合」で持つかを試す
2. **棚の既刊を読めるようにする**。器の価値は「隣の号も開く」ことで出る
3. **案 3（相関図トップ）を足す**。棚は時間順の入口、相関図は関係順の入口。二つの入口で同じ作品に入れる
4. **案 4 の重複章目次**を上に被せる。棚＝発行順、目次＝照らし方の順
5. 音を入れるか決める。実況譜のカットインにベル系 SE を当てるなら Glimpse Cascade の順次再生の作法が使える

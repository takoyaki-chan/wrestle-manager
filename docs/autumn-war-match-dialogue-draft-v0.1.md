# 4団体勝ち残り対抗戦 — 試合中セリフ草案 v0.1

秋の年次大会「4団体勝ち残り対抗戦」(各団体3名の勝ち抜き＝イリミネーション。勝者はリングに残り、消耗したまま次の相手と連戦)向けの、**試合中セリフ草案**。試合前 / 決勝前 / 勝ち残り後の3文脈を、秋大会専用に書き下ろした。

> **ステータス: 草案。`src/` は未変更。** レビュー用。承認後に `src/data.js` へ組み込む想定。

## 0. 執筆メモ(レビュー前に)

### 参照した既存表
- **`src/data.js` L5962〜 `AUTUMN_WAR_MVP_LINES`**(`gauntlet` / `champion` / `defiant`) — 秋大会の声・文脈(連戦/消耗/リングを譲らない)の到達点。**同一 personality×archetype がこの表と矛盾しない声になるよう合わせた**。特に「息が上がる」「膝はつかなかった」「このリングを明け渡す理由にはならない」等の語彙・温度を survivor 文脈に接続。
- **`src/data.js` L14125〜 `JUNIOR_TOURNAMENT_LINES`**(`preMatch` / `preFinal` / `postMatchWin`) — 現状これを「仮」で流用中。**構造(文脈→personality→archetype→_default)のみ踏襲し、文面は流用禁止。** ジュニアには無い「連戦・勝ち抜き・消耗・次の挑戦者・リングに残る」を全文脈に織り込んだ。
- **`specs/oyou-style-guide.md`** — composed(鷹揚)口調。短文/「…」/断定回避/感情的×鷹揚のギャップ造形を反映。
- **`src/data.js` L13〜 `ALL_CHARS`** — 各組の実在キャラの traits/role をサンプリングして声を接地(下表)。

### 文脈ごとの消耗の描き分け(重要)
- **preMatch(試合前)** = 各フォール開始前、左右**両選手**に出る。第1フォール(両者無傷)や、リングに入る新たな挑戦者(まだ誰も倒していない)にも出るため、**"自分が既に何人か倒した"前提を一切持たせない**。「これから戦う」中立の集中/闘志/覚悟に振る。連戦性は「どんな相手でも」「一戦ずつ繋ぐ」で匂わせる程度に留め、"直前に勝った"は断定しない。→ これで survivor との弁別も明確化。
- **preFinal(決勝前)** = 勝ち上がり、**満身創痍でも立つ覚悟**。「傷だらけ」「身体は限界」＋「最後まで降りない」。
- **survivor(勝ち残り後)** = たった今フォールを奪った **直後の疲弊**。「息が上がる」＋「まだ終わらない」＋敵陣営の次を待つ「次、来い」。ここは実際に直前に1人倒しているので「一人落とした」前提で正しい。

### カバレッジ
指定34組すべてを3文脈とも充足。加えて各 personality に `_default`(保険)を配置。

**基本は各セル2本。頻出6組のみ3文脈(preMatch/preFinal/survivor)すべてで3本に増量**(抽選バリエーション拡張)。3本目は既存2本と別個の切り口。
- `earnest.polite`(earnest×polite)
- `normal.polite`(normal×polite)
- `earnest._default`(earnest×normal を代替。earnest 配下に `normal` キーは新設せず `_default` を3本化)
- `normal.composed`(normal×composed)
- `bold._default`(bold×normal を代替。bold 配下に `normal` キーは無いため `_default` を3本化)
- `bold.delinquent`(bold×delinquent)

| personality | archetype(この草案でカバー) |
|---|---|
| normal | _default, composed, ojousama, polite, seductive, delinquent, cool |
| bold | _default, composed, ojousama, polite, seductive, delinquent |

> 注: `emotional._default` と `emotional.normal` は同一内容にせず別文で用意(呼び出し側が normal を明示参照する場合の受け皿)。

## 1. 試合前 (preMatch)

> 各フォール開始前に**両選手**へ出る。第1フォール(両者無傷)や新たな挑戦者にも出るため、**"自分が既に何人か倒した"前提は持たせない**。「これから戦う」中立の集中・闘志・覚悟。連戦性は「どんな相手でも」「一戦ずつ繋ぐ」で匂わせる程度。(★=頻出3本組)

### normal
- **_default**
  - 「どんな相手が来ても、やることは一つ。真っ向から受けて、次に繋ぐ」
  - 「このリングは譲らない。目の前の一人に、全部ぶつけるだけ」
- **composed ★** — 動じない。目の前に集中する余裕
  - 「…相手は選べない。来た順に、真っ向から受けるだけだよ」
  - 「…焦らない。目の前の一人に集中する。それでリングは渡さない」
  - 「…この一戦から、始まる。落ち着いていこうか」
- **ojousama** — 気高く場を支配
  - 「どなたが来ようと、この場所は明け渡しませんわ」
  - 「お相手が誰であれ、覚悟してお越しなさいまし」
- **polite ★** — 仲間へ繋ぐ責任
  - 「相手がどなたでも、全力でお相手します。ここで足を止めるわけにはいきませんから」
  - 「一戦一戦、丁寧に。仲間に繋ぐまで、退けません」
  - 「まずは目の前の一人に集中します。それが、繋ぐってことですから」
- **seductive** — 余裕、思わせぶり
  - 「来るなら誰でもいいわ。全部、受け止めてあげる」
  - 「この一戦、たっぷり付き合ってもらうわよ。逃がさないから」
- **delinquent** — 挑発、ぶっきらぼう
  - 「相手は誰だ? 何人来ようが、あたしがここで止めてやる」
  - 「このリング、通れると思ってんのか。かかってこいよ」
- **cool** — 体言止め、最小語
  - 「…相手は誰でもいい」
  - 「真っ向から受ける。それだけ」

### bold
- **_default ★**
  - 「何人並んでようが関係ない。真っ向から薙ぎ倒して、次に繋ぐ」
  - 「来るなら来い。このリングを抜けさせると思ってんのか」
  - 「相手が誰だろうと、結果は変わらない。最後に立ってるのはあたしだ」
- **composed** — 王者の余裕、ガツガツしない強さ
  - 「相手が誰でも、受けて立つよ。慌てる場面じゃない」
  - 「何人でも並びなよ。…上等。並んだだけ、倒すから」
- **ojousama** — 高慢、格の差
  - 「次から次へと殊勝なこと。ですが、わたくしを越えるのは無理ですわ」
  - 「どなたがお相手でも、このリングの主はわたくしですのよ」
- **polite** — 丁寧だが押し通す芯
  - 「相手がどなたでも、全力で止めます。ここを通すわけにはいきませんので」
  - 「誰が立ちはだかろうと、私のやることは変わりません。押し通ります」
- **seductive** — 挑発的な妖艶
  - 「相手は誰? 何人来ても…最後まで残るのは、こっちよ」
  - 「もっと骨のあるのを出してきて。全部相手にしてあげる」
- **delinquent ★** — 荒々しい挑発
  - 「相手は誰だ! 何人来ようがまとめてかかってこいや」
  - 「一人ずつしか来れねえのか? じれってえな。全員まとめて潰してやる」
  - 「このリング、渡すわけねえだろ。出てこいよ、順番に沈めてやる」

### quiet
- **_default**
  - 「……相手は誰でもいい。倒す」
  - 「……真っ向から。まだ、これから」
- **composed** — 静かで重い
  - 「……誰が来ても、退かない。それだけ」
  - 「……焦らない。目の前から、片づける」
- **polite** — 無口だが丁寧
  - 「……相手がどなたでも、全力で。止まりません」
  - 「……一戦ずつ、繋ぎます」
- **seductive** — 静かな妖艶
  - 「……相手は誰。…来なよ」
  - 「……まだ、これから。楽しませてよ」
- **cool** — 極限の寡黙
  - 「……次」
  - 「……倒す。残る」

### shy
- **_default**
  - 「つ、相手が来る…。怖い、けど…ここで逃げたら、繋げないから」
  - 「足が震えてる…でも、私の番だから。行かなきゃ」
- **polite** — おどおど＋腰が低い
  - 「つ、相手の方…がんばります。仲間が待ってるので、退けません…」
  - 「こ、怖いです…でも、ここで止まったら、みんなに申し訳なくて…」

### easygoing
- **_default**
  - 「相手は誰かなー。まあ、来た子と真っ向勝負するっきゃないよね」
  - 「よーし、あたしの番だ。止まってらんないし、いっちょやりますか」
- **composed** — ヌケた大物感
  - 「…相手が来るね。ま、真っ向から受けるよ」
  - 「一戦ずつか。…慌てない慌てない。ちゃんと繋ぐから」
- **ojousama** — 余裕綽々
  - 「あら、お相手はどなた? 次から次へと、賑やかですこと」
  - 「賑やかな一日になりそうですわね。…面白いですわ」
- **polite** — 軽いが丁寧
  - 「相手の方ですね。えーと、気楽に…いや、ちゃんとやります」
  - 「一戦ずつ、しっかりお相手しますよ。ま、任せてください」
- **seductive** — 気楽な妖艶
  - 「相手は誰が来るのかしら。何人でも、退屈しなさそうね」
  - 「まだまだお楽しみは続くの? いいわね、乗ってあげる」
- **delinquent** — 軽口ヤンキー
  - 「相手は誰だ? ま、来た奴から順にぶっ倒すだけだ」
  - 「いいぜいいぜ、次々来いよ。まとめて相手してやるって」

### earnest
- **_default ★**(earnest×normal を代替)
  - 「どんな相手でも、全力で。仲間に繋ぐ、それだけは絶対です」
  - 「目の前の一戦から、正面で受けます。手を抜く理由がありません」
  - 「一戦ずつ、確実に。託されたものを、途中で放り出せませんから」
- **polite ★** — 一途＋腰が低い
  - 「相手がどなたでも、全力でお応えします。手を抜くのは失礼ですから」
  - 「一戦ずつ、丁寧に。託された役目、途中で放り出せません」
  - 「まずは目の前の一人に、心を込めて。それが私の役目ですから」
- **composed** — 騒がない実直さ
  - 「…相手が誰でも、正面から。手を抜く理由がない」
  - 「一戦ずつ、確実に。…それが、繋ぐってことだろう」
- **ojousama** — 生真面目な気高さ
  - 「どなたがお相手でも、全力で臨みますわ。それが礼儀ですもの」
  - 「この一戦に、気を緩めるところなど一つもありませんの」
- **seductive** — 誠実さ×妖艶
  - 「相手が誰でも、ちゃんと向き合うわ。手を抜くなんて、できないの」
  - 「繋ぐ相手がいる。だから、この一戦も手は抜けないの」

### emotional

  - 「来い…! この一戦、絶対に退かねえ…!」

- **composed** — ギャップ造形。沸点を超え低温化
  - 「…相手は誰だ。…言葉はいらない。来たら、倒す」
  - 「…この一戦で、始まる。…かかってこい」
- **seductive** — 昂りが漏れる妖艶
  - 「お相手は誰かしら…っ…ふふ、もう身体が疼いてるの」
  - 「早く来てよ…! この昂り、ぶつける相手が欲しいの…!」
- **normal** — 溢れる熱
  - 「来い…! 目の前の一人から、全部倒して繋いでやる…!」

## 4. レビュー時に特に見てほしい点

1. **survivor と MVP(gauntlet)の重複回避** — MVP は表彰式の総括、survivor は各フォール直後。「息が上がる」「まだ立ってる」等の語彙は意図的に共有しつつ、survivor は「次、来い」で敵陣営を待つ即時性に寄せた。温度が MVP と被りすぎていないか。
2. **preMatch の中立化(v0.1→確定稿の主修正)** — preMatch は各フォール前に両選手へ出るため、"自分が既に倒した"前提の語(「一人倒した/落とした/潰した」等)を全排除し、「これから戦う」中立に振り直した。第1フォールの無傷の選手が口にしても矛盾しないか。survivor(直後の疲弊「息が上がる」＋実際に1人倒している)との弁別が明確か。
3. **emotional×composed のギャップ造形** — 3文脈とも怒り/昂りを圧縮した低温の短文にした(「…言葉はいらない」「…痛みは、後だ」)。スタイルガイド§5の意図に沿うか。
4. **delinquent の音量** — 秋大会の消耗文脈でも「出てこいや」「渡すかよ」を維持。他 archetype との差が出ているか。
5. **固有名詞・大会名の不使用** — 全セリフで大会名/選手名を排し、指示語(「次」「ここ」「このリング」)主体で構成。徹底できているか。

## §0 設計原則

社長が支払えるものを4通貨に整理する: **資金 / 決裁枠 / 選手の時間(欠場) / 選手の寿命(wear)**。
現状はほぼ「資金+枠」の2通貨で、資金が安すぎて実質フリー。本リワークの軸は「本当のコストを金以外にも払わせる」こと。

- 金額の上限で強さを縛らない。**機会の希少さ(候補ローテ・同時1件・消化力)で縛る**
- 数値の丸見せをしない。相場や相性は演出(秘書メモ・レポート・セリフ)を通してぼかして伝える
- 性格×アーキタイプの不確実性(shachoshitsu Phase 8, ±50%)は全書類で維持

## §1 ボーナス支給の交渉化

**書類名は「ボーナス支給願」のまま**。中身を「50万固定」から「額を積む交渉」に変える。

### §1.1 フロー

1. 対象選手を選ぶ(発動条件: trust<60 の選手がいる — 現行同様)
2. **秘書が起案した4案から選ぶ**(スライダーは不採用 — 自由入力は選ぶための思考コストが重すぎる、2026-07-06 Keisuke 判断)
   - 4案 = 基準額 × {0.5 / 1.0 / 2.0 / 3.0} 🔧 を丸めた金額(50万〜100万単位に丸め+±10%ノイズで式を透けさせない)
   - 例: スター(基準1,080万) → 「550万 / 1,100万 / 2,150万 / 3,200万」/ 新人(基準350万) → 「170万 / 350万 / 700万 / 1,050万」
   - 各案のホバーに秘書の一言(§1.4)
3. ハンコ → 即時発現(現行同様)

**最安案は安全牌ではない**: r=0.5 は「気持ち程度」帯だが、プライドの高い性格の選手には侮辱域として扱われる(§1.3 の帯境界が性格で±シフトする 🔧)。同じ4案でも相手によってリスクが変わる。

### §1.2 基準額(選手の相場)

```
基準額 = max(週給 × 6, 査定額(assessedValue) × 25%) 🔧
```

- ベテランエース(週給180万) → 基準 約1,080万
- 新人逸材(週給35万・査定1,400万) → 基準 350万(将来を買われている分)
- 基準額は**プレイヤーに直接表示しない**。選手の格・給与から察する+秘書メモで間接的に伝える

### §1.3 効果カーブ(r = 支給額 ÷ 基準額)

| r | 帯 | trust 効果 🔧 | 備考 |
|---|---|---|---|
| < 0.4 | 侮辱 | 0、プライド高い性格は **-2〜-5** | 「はした金」専用リアクション |
| 0.4〜0.8 | 気持ち程度 | +2〜4 | |
| 0.8〜1.5 | 相場 | +8〜12 | 現行効果はここに位置づけ |
| 1.5〜2.5 | 誠意 | +14〜18 | 専用リアクション |
| ≥ 2.5 | 破格 | +18〜22 | 性格により「会社は大丈夫なのか」フレーバー |

- Phase 8 不確実性(±50%)を最終値に乗算(現行踏襲)
- **逓減は「効果半減」から「相場の吊り上がり」に変更**: 同一選手への再支給は基準額 ×1.5 🔧(「前ももらった」— 物語として自然)
- CD: 同一選手 **4週** 🔧(現行1週は乱発可能すぎ)。決裁枠1(現行同様)

### §1.4 秘書の一言(4案の各ホバー・文章系→Keisuke レビュー必須)

各案のホバーに秘書の短い一言を出す。効果を数字で明かさず「無難な線かと」「彼女の格に見合う額です」「思い切りましたな…」程度のぼかし表現。プライド高い選手の最安案には「……お気を悪くされるかもしれません」のような警告トーンを混ぜる。

### §1.5 位置づけ

給与交渉(シーズン開幕の契約)が本道。ボーナスは**シーズン中の応急処置だが、まともな額を積まないと効かない**。「50万で信頼が買えるなら給与交渉不要」問題を構造的に解消する。

## §2 休暇辞令 v2

### §2.1 フロー

1. 対象選手を選ぶ(発動条件: **常時可に変更** — スランプ限定をやめ疲労管理ツールに昇格)
2. **休暇週数スライダー 1〜4週** 🔧
3. **注意書きを明記**(確定事項): 「休暇中の試合には欠場します」
4. ハンコ → 休暇開始

### §2.2 費用

```
費用 = 週給 × 週数 + 手配費50万 🔧
```
働かない期間も給料は出る+代替の手配、という逸失利益の理屈。エースの長期休暇ほど高い。決裁枠1。

### §2.3 効果(週数比例)

| 項目 | 効果/週 🔧 | 上限 |
|---|---|---|
| 体調(condition) | +10/週 | 100 |
| **wear(消耗)回復** | 2週ごとに -1 | 1回の休暇で最大 -2 |
| 信頼 | 基本+3、週数で微増(+1/週)、Phase 8 不確実性あり | |
| スランプ/モチベ喪失 | 回復モーメンタム大(現行効果を継承) | |

- wear 回復は**ゲーム唯一の寿命ケア手段**。安易にしないため少量+上限。数値は auto-sim で引退年齢分布を観察して調整
- **休暇中は欠場**(確定事項): 興行のカード編成に載せられない・プロモ不可。試合に出せない選手として UI 上でも明示
- CD: 同一選手 **12週** 🔧

## §3 専属トレーナー → 外部コーチ招聘制

現行 trainer 書類(160万一律 / 4週+30% / CD1週 / 並行貼り放題)を**廃止**し、招聘制に置き換える。

### §3.1 候補の供給(合意済み)

- **四半期(12週)ごとに候補入れ替え、常時2〜3名** 🔧 を提示。抽選元は未雇用コーチ35名プール
- 自団体・招聘中のコーチは出ない。**招聘直後のコーチは次回抽選を1回休む**(借り続け防止)
- **格の出現率は orgPop 連動**(雇用の minOrgPop 閾値 C:0 / B:30 / A:55 を流用)。弱小はC中心、55+でA級が稀に顔を出す
- 提示情報: 名前 / 格 / 得意スタイル / 特殊能力 / **指導タイプ**(§3.3) / 招聘費

### §3.2 費用(合意済みの理屈)

```
招聘費 = コーチ週給 × 4週 × スポット割増1.5 (±10%ブレ) 🔧
```

| 格 | 招聘費目安 |
|---|---|
| C級 | 約160〜290万 |
| B級 | 約270〜440万 |
| A級 | 約810〜960万 |

- 雇用(hireFee=週給×8+週給継続)と地続き: 長く使うなら雇用、短期スポットなら招聘(割増)
- **効果は価格に比例させない**(Keisuke 指示)。A級の価値は特殊能力・レポート質・化ける確率という「質の違い」
- 決裁枠 **2** 🔧。**同時招聘は1件まで**(招聘は団体の一大イベント)

### §3.3 相性システム

効果倍率 = 基礎(格) + スタイル一致 + 指導相性:

| 要素 | 値 🔧 |
|---|---|
| 基礎倍率 | C +25% / B +30% / A +35% |
| スタイル一致 | specialist一致 +8% / allround +5%(既存 COACH_STYLE_BONUS 流用) |
| 指導相性 良 | +10% + 良イベント方向 |
| 指導相性 普通 | ±0 |
| 指導相性 悪 | -10% + ごく稀に衝突イベント |

- **指導タイプ**(新設データ): 全35コーチに スパルタ / 理論派 / 見守り型 等のタグを付与 🔧(タイプ数はデータ設計時に確定)
- 指導タイプ × 選手の性格(6種)の相性マトリクスで判定。**事前には完全に分からない**(コーチの評判・観察レポートでヒントのみ)
- **コーチの特殊能力が招聘中その選手に適用される**(ステ特化/弱点克服/延命術/スター製造など)。「この子に今必要なものは何か」の処方がプレイヤーの仕事になる
- 招聘中はそのコーチの観察レポートが対象選手について濃く出る(観察眼ランク準拠)

### §3.4 期間と過程イベント(合意済みの頻度感)

- **期間は4週固定**。スライダーにしない
- **中間報告**: 2週目に50% 🔧 で様子が一言(毎回は出ない — くどさ回避)
- **衝突イベント**: 指導相性「悪」の組み合わせのみ、期間中1回 20% 🔧 — **ごく稀**。続行/中止の選択、中止は返金なし+選手の心に跡
- **延長打診**: 指導相性「良」のとき 25% 🔧 でコーチから「もう2週」— 追加費用は週給×2×1.5
- **卒業レポート**: 終了時必ず。何が伸びたか+コーチの一言+選手の一言(アーキタイプ別、文章系→Keisuke レビュー必須)
- **化ける**: 相性良+ポテンシャル残あり(残成長余地10%以上 🔧)で終了時 5% 🔧 — trainCap 全stat +1(限界突破の弱版)。**稀**。数値をねじ曲げない本物のご褒美

### §3.5 一強化の根絶(合意済み)

- **消化力逓減**: 同一選手への再招聘は前回終了から12週以内 🔧 なら効果半減(「詰め込みすぎ」)
- **二重指導なし**(確定事項): 招聘中は雇用コーチのアサインから自動で外れ、終了で自動復帰
- 同時1件・候補ローテ・格の orgPop ゲートにより、金が余っていても機会は買えない

### §3.6 合宿との住み分け

合宿(camp)は現状維持(全員+短期+絆)。招聘=個人+深さ。将来拡張: 招聘中コーチの合宿帯同(全体効果に個性が乗る)は本 spec のスコープ外。

## §6 指導タイプ設計(🟢 確定 — 2026-07-06 Keisuke 承認)

### §6.1 5タイプの定義

| タイプ | 指導像 | 代表例 |
|---|---|---|
| **スパルタ** | 厳しく追い込み、壁を越えさせる | 鬼塚剛志「力なき技は無力」、赤城凛「甘やかして強くなった人間はいない」 |

| **職人気質** | 寡黙に反復、背中と手本で語る | 鶴見正嗣「技は千回の反復から」、冴島楓「身体が覚えるまで何度でも」 |

| **人情家** | ノリと人情で一緒に走る | 朝日義男(面倒見の良い苦労人)、土屋弘美「あんたはまだまだやれる」 |

| | 熱血 | 寡黙 | 気楽 | 真面目 | 情熱 | 内気 | 普通 |
|---|---|---|---|---|---|---|---|
| スパルタ | ◎ | ○ | ✕ | ◎ | ○ | ✕ | ○ |
| 理論派 | ✕ | ◎ | ○ | ◎ | ○ | ○ | ○ |
| 職人気質 | ○ | ◎ | ✕ | ◎ | ✕ | ○ | ○ |
| 見守り型 | ✕ | ○ | ○ | ○ | ◎ | ◎ | ○ |

◎=良(+10%・良イベント方向) / ○=普通 / ✕=悪(-10%・稀に衝突) — 数値は §3.3 準拠 🔧

- 読み方の例: 熱血はスパルタで燃えるが、理屈っぽい理論派や優しい見守り型には物足りない。寡黙は職人と黙々やれるが、人情家の距離の近さに疲れる
- **真面目はどのタイプでも腐らない**(悪なし) — 努力家への招聘は相性より「能力の噛み合わせ」(§3.3 特殊能力)で選ぶ設計意図

# Wrestle Manager 固有特性（Traits）リスト v1.0

## 概要
- 各キャラクターに **2〜4個** の特性を割り当て
- 特性は **バトル系 / 成長系 / 経営系 / メンタル系** の4カテゴリ
- 効果は既存エンジンの変数に対する補正値として実装可能

---

## 🥊 バトル系（試合中の戦闘に影響）

### 1. 鉄壁（Iron Wall）
**効果**: 被ダメージ -10%
**説明**: 頑丈な体で打たれ強い。どんな攻撃も耐えてみせる。
**フック先**: `defStaScale` / ダメージ計算時の防御補正

### 2. 爆発力（Explosive）
**効果**: Climaxフェーズでの攻撃力 +15%
**説明**: 試合終盤に真価を発揮する大技の使い手。
**フック先**: `PHASES[3].mult` への加算補正

### 3. 速攻（Fast Starter）
**効果**: Openingフェーズでの命中率 +5%、ダメージ +10%
**説明**: 試合開始直後から全力で畳みかける。
**フック先**: `PHASES[0]` 補正

### 4. カウンターの女王（Counter Queen）
**効果**: カウンター発生率 +4%
**説明**: 相手の攻撃を読み切り、鮮やかに切り返す。
**フック先**: `counterBase` への加算

### 5. 必殺の一撃（Devastating Finisher）
**効果**: フィニッシュ技のダメージ +20%
**説明**: 決め技の破壊力が段違い。一撃で試合を終わらせる。
**フック先**: フィニッシュ判定時のダメージ乗算

### 6. 関節技の鬼（Joint Lock Master）
**効果**: ギブアップ成功率 +8%
**説明**: 一度極めたら絶対に逃がさない関節技の達人。
**フック先**: `guEscapeMnScale` の相手側ペナルティ

### 7. 脱出の天才（Escape Artist）
**効果**: ピンフォール・ギブアップからの脱出率 +10%
**説明**: どんな体勢からでも返してみせる驚異の粘り。
**フック先**: `kickoutMnScale` / `guEscapeMnScale` 補正

### 8. 受け身の達人（Bump Master）
**効果**: 被ダメージの乱数下限を引き上げ（相手の最大ダメージを抑制）
**説明**: 美しい受け身で致命傷を避ける。派手に飛んで実は効いていない。
**フック先**: `dmgRandRange` を相手側で制限

### 9. ラフファイター（Dirty Fighter）
**効果**: ヒール時、相手の命中率を -3% 低下させる（反則行為）
**説明**: レフェリーの死角で反則を仕掛ける。目潰し、急所攻撃お手の物。
**フック先**: 命中判定時のデバフ（role=Heel条件）

### 10. 空中殺法（Aerial Ace）
**効果**: 命中時のダメージ乱数上限 +10%（ハイリスク・ハイリターン）
**説明**: 華麗な飛び技で会場を沸かせる。決まれば絶大。
**フック先**: `dmgRandRange` 上限拡張

## 📈 成長系（トレーニングとキャリアに影響）

### 11. 天才（Prodigy）
**効果**: 全ステータス成長速度 +15%
**説明**: 何を教えてもすぐに吸収する天性の才能。
**フック先**: `growth` 計算時の全体乗算

### 12. 大器晩成（Late Bloomer）
**効果**: notionValue超え後の成長鈍化を緩和（40% → 55%）
**説明**: 周りが頭打ちになる頃に伸び始める。真の強さはこれから。
**フック先**: `convergenceFactor` の notionValue超え後係数

### 13. 努力の人（Hard Worker）
**効果**: 集中トレーニングの効果 +20%、怪我リスク -50%
**説明**: 地道な反復練習を厭わない。怪我をしない体づくりも万全。
**フック先**: `intensiveMult` / `intensiveInjuryChance`

### 14. 鉄の体（Iron Body）
**効果**: 怪我の回復速度 +1週
**説明**: 驚異的な回復力。怪我をしても復帰が早い。
**フック先**: 怪我回復週数計算

### 15. ガラスの脚（Glass Legs）⚠️ **マイナス特性**
**効果**: 怪我発生率 +50%
**説明**: 実力はあるが故障しやすい。繊細な体が弱点。
**フック先**: 怪我判定確率

### 16. ピークが長い（Extended Prime）
**効果**: ピーク期間ボーナスが +2シーズン延長
**説明**: 年齢を感じさせない安定感。衰え知らずの肉体。
**フック先**: `peakBonusSeason` 加算

## 💰 経営系（人気・集客・経済に影響）

### 17. スター性（Star Quality）
**効果**: 試合後の人気上昇量 +30%
**説明**: リング上で輝くオーラを持つ。ファンを惹きつける天性の華。
**フック先**: 人気上昇計算の乗算

### 18. 名勝負製造機（Match Maker）
**効果**: 試合品質（MQ）+3
**説明**: 誰と組んでも好勝負にしてみせる。試合構成の天才。
**フック先**: `matchQuality` 計算への加算

### 19. ドル箱（Box Office Draw）
**効果**: 出場試合の観客動員 +10%
**説明**: この選手が出るだけでチケットが売れる。団体の看板。
**フック先**: 観客数計算の乗算

### 20. カリスマ（Charisma）
**効果**: 人気の自然減衰を 50% 軽減
**説明**: 試合がなくてもファンが離れない。存在そのものがコンテンツ。
**フック先**: 人気減衰計算

### 21. 安い給料（Low Maintenance）
**効果**: 年俸要求 -20%
**説明**: お金より試合。プロレスが好きでやっている純粋な選手。
**フック先**: salary計算

### 22. 高額要求（Diva）⚠️ **マイナス特性**
**効果**: 年俸要求 +30%
**説明**: 自分の価値を知っている。それに見合う待遇を要求する。
**フック先**: salary計算

## 🧠 メンタル系（精神面・モメンタムに影響）

### 23. 逆境○（Clutch Performer）
**効果**: HP30%以下でGrit発動率 +15%、Grit中のカウンター補正 +5
**説明**: 追い詰められてからが本番。満身創痍で底力を見せる。
**フック先**: `gritDuration` / `gritCounterBonus` 補正

### 24. 闘志（Fighting Spirit）
**効果**: モメンタム回復速度 +15%
**説明**: 打たれても打たれても立ち上がる不屈の闘志。
**フック先**: `momDmgScale` の回復方向補正

### 25. プレッシャーに弱い（Choke Artist）⚠️ **マイナス特性**
**効果**: タイトルマッチ時、全ステータス -5%
**説明**: 大舞台になると実力を発揮できない。期待を背負うと硬くなる。
**フック先**: タイトル戦フラグ時のステ補正

### 26. 威圧感（Intimidation）
**効果**: 試合開始時、相手のメンタル実効値を -8% 低下
**説明**: リングに立つだけで相手が萎縮する。圧倒的な存在感。
**フック先**: 試合開始時の相手MN補正

### 27. ムラっ気（Inconsistent）⚠️ **マイナス特性**
**効果**: 試合ごとに全ステータスに ±10% のランダム変動
**説明**: 調子の波が激しい。ハマれば最強、ダメな日はとことんダメ。
**フック先**: 試合開始時のステ乱数補正

### 28. 負けず嫌い（Sore Loser）
**効果**: 前回負けた相手との再戦時、全ステータス +5%
**説明**: 同じ相手に二度は負けない。雪辱に燃える情熱。
**フック先**: 対戦履歴参照 → ステ補正

## 🔗 複合・特殊系

### 29. エースの器（Ace Material）
**効果**: エース指名時、団体全体の人気上昇 +5%
**説明**: 団体の顔としてファンを牽引する。背中で語るリーダー。
**フック先**: エース補正計算

### 30. 後輩育成（Mentor）
**効果**: 同団体の若手（入団2シーズン以内）の成長速度 +10%
**説明**: 練習相手として最高。若手の才能を引き出す姉貴分。
**フック先**: 同団体内の若手成長計算

## 📊 割り当てガイドライン

### 個数の目安
| キャラクターランク | 特性数 | 備考 |
|---|---|---|
| トップ（影響力★★★★〜★★★★★） | 3〜4個 | プラス特性多め |
| 中堅（影響力★★〜★★★） | 2〜3個 | バランス混在 |
| 若手・下位（影響力■〜★） | 1〜2個 | 成長系やマイナス特性もあり |

### マイナス特性のルール
- マイナス特性は **最大1個** まで
- マイナス特性を持つキャラは、補填として **プラス特性を1個多く** 持てる
- 例: ガラスの脚 + 天才 + 爆発力 = 弱点ありだが光る才能

### スタイルとの親和性（参考）
| スタイル | 相性の良い特性 |
|---|---|
| Striker | 爆発力、速攻、闘志 |
| Grappler | 鉄壁、関節技の鬼、威圧感 |
| Submission | 関節技の鬼、カウンターの女王、脱出の天才 |
| Speed | 速攻、空中殺法、脱出の天才 |
| Allround | 名勝負製造機、スター性、後輩育成 |
| Brawler | ラフファイター、逆境○、闘志 |

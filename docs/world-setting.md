# 🌍 Wrestle Manager — 世界観設定

> このドキュメントはゲーム内で直接表示されるものではなく、セリフ・イベントテキスト・キャラクター描写を作成する際の基準線として使用する。

---

## 世界の前提

この世界では、女性にとってプロレスは「当たり前のもの」である。現実世界におけるサッカーのような位置づけで、学生時代から誰もがプロレスに触れ、経験する。「なぜプロレスをするのか」という問い自体が成立しないほど、それは生活に根付いた文化である。

プロレスは女性だけのスポーツ文化であり、男性はプロレスをしない。女性のプロスポーツの代名詞であり、社会的な注目度・人気も高い。

---

## プロ団体と選手

### 団体の構造

プロレス団体は実際には無数に存在する。ゲームではこれを4団体（S/A/B/それ以下）に簡略化して表現しているが、世界の中では大小さまざまな団体が階層的に存在している。

### 選手の生活

選手は本業を持ちながらプロレスと両立している。医者、教師、学生、会社員など、それぞれの職業を持ちながらリングに立つ。本業との両立はこの世界における美徳であり、「プロレスだけの人生」ではなく「プロレスもある人生」が自然な姿である。

### プロになる動機

プロになる理由は人それぞれで、単一の物語に収まらない。

| 動機 | 説明 |
|------|------|
| 憧れ・夢 | 幼い頃から見てきたチャンピオンに憧れて |
| 名誉・プライド | 最強を証明したい、頂点に立ちたい |
| 金銭 | 本業より稼げるから、生活のために |
| 闘争本能 | 戦うこと自体が好き、リングが居場所 |
| 使命感 | 師匠の教え、故郷の期待、託された想い |
| 成り行き | スカウトされて気づいたらプロに |

## プレイヤーの立場

プレイヤーは1つの団体のオーナーとして、この世界に存在する。選手のスカウト、育成、興行運営を通じて団体を成長させていく。

## キャラクターについて

ゲームに登場する98名のキャラクターは、制作者の複数のオリジナル作品から集められたキャラクターたちである。ゲーム世界は元作品とは独立したパラレルワールドであり、各シリーズのキャラクターが同一世界に自然に共存している。

キャラクターのプロフィール（職業・性格・背景など）は元作品に準拠するが、物語上のつながり（作品間の因縁やストーリー）はゲーム世界には引き継がれない。あくまで「この世界にもともといる人物」として扱う。

## リーグと国家

女子プロレスリーグは**国家の後押しを受けて運営されている**。リーグ自体は独立した運営組織だが、国からの委託・資金援助のもとで成り立っている。現実世界でいうところの、国が支援するプロスポーツリーグ（Jリーグにおけるtoto助成金、韓国のKリーグにおける体育会支援など）に近い位置づけである。

この設定により、以下が世界観として自然に成立する：

- **大型イベントの賞金は国庫から支出される。** PPV Grand Final やジュニアトーナメントの賞金は団体が負担するものではなく、リーグ（≒国家基金）から選手個人に支給される。団体の財政には一切影響しない。
- **全国規模のトーナメントへの参加は「召集」に近い。** 国家主催の大会に選出された選手は、団体の意向に関わらず出場する。これは名誉であり義務でもある。
- **プロレスの社会的地位が高い理由の裏付け。** 国家が公認・支援するスポーツであることが、プロレスが文化として根付いている世界の説得力を補強する。

## リアリティレベル

世界の設定にリアリティを求めすぎない。「こういう世界だから」で成立する部分はそのまま受け入れる。設定はゲーム体験を支えるための土台であり、設定自体が目的ではない。

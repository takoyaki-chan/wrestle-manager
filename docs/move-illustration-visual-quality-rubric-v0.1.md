## 1. 合格基準チェックリスト

### HARD GATE（1つでもFAILなら差し戻し）

- **G-1 レイヤー構造**: master が `alpha=0` 背景を持ち、attacker/receiver の塗り分けが独立マスクとして存在する。判定: `alpha=0` 画素が全体の40%以上。（平坦化画像へのバケツ塗りはFAIL）
- **G-2 塗り分けの純度**: 「黒線でも attacker色でも receiver色でも透明背景でもない」中間色画素が**着色面積の2%以下**（5%超はFAIL）
- **G-3 線幅（512px換算）**: 水平ラン中央値 **3.0〜5.5px**、p90 **6.0〜11.0px**（master 1680幅なら中央値11〜18px / p90 20〜36px）。中央値2.5px未満・6.5px超はFAIL
- **G-4 3秒スクイントテスト**: 512px表示を3秒見て、攻守2体に分離して見え、技名が言い当てられる

## 2. v2試作（16_powerbomb）の判定: 総合差し戻し

ハードゲート4項目すべてFAIL: G-1（alpha=0が0%）/ G-2（中間色15.8%）/ G-3（線幅1.22px＝旧作の1/3.7）/ G-4（512で2体が融合）。GRADED も L系6件・C系5件・S系全件が該当。主な部位指摘: 攻め手頭部が真円+髪残骸の二重弧(670-850, 290-470)、右ブーツ二重線(1420-1445, 820-900)、受け手の指が開端スクリブル(540-620, 1040-1100)、元3D衣装の皺線残存(900-1080, 260-330)、青腿エッジの灰色ハロー(1000-1030, 520-745)、両者中間の白穴(1030-1180, 570-860)、線の無い場所での色接触(930-990, 690-730)。

## 3. 旧作との水準差

**旧作は「完成した絵」、v2は「トレース途中の下描き」。差は技術の細部ではなく工程数**（清書・陰影の工程が丸ごと欠落）。ただし旧作から継承すべきは様式ではなく**線の階層・抑揚・陰影・可読性という仕上げの水準**（旧作は関節ボールマネキンで様式は別物。寄せすぎるとマネキンに戻る）。

## 4. 512px縮小後の確認（Sol運用手順）

- masterを等倍で見て合格判定しない。**512px WebP実寸+256pxサムネで判定**
- 3秒スクイント / サムネの塊判別 / 色に頼らない攻守判別 / ティント適用状態で確認 / 穴チェック
- 潰れやすい部位: **編み上げ紐（512でループが見えないなら×3〜4本の簡略記号に置換）**、手指（シルエットのみ可）、ニーパッド帯、卵型輪郭、接触影
- 定量: 512版で線幅中央値3.0〜5.5px / 中間色比3%以下 / alpha=0比率
- 計測はSystem.Drawingスクリプトで再現可能（PowerShell 5.1は日本語パスが化けるため先にASCII名へコピー）

## 5. GPT Imageプロンプト改善と工程提案

**方針転換（最重要）**: GPT Imageに最終品質の線画を期待しない（線幅階層・閉輪郭・重複線ゼロは構造的に保証不能）。**GPT Image=様式変換まで、線の清書・線幅階層・陰影・マスク分離=後工程**（ベクタ化+線幅プロファイル機械適用など）。

プロンプト改善の要点: `line art` の語を避け `bold inked cartoon outline with varied line weight` / 3階層明示（外輪郭=内部線の約3倍） / `tapered strokes` / `solid opaque black strokes only` / `single clean stroke per contour` / `every contour must be fully closed` / セル調3値陰影+左上固定光源+接触影 / `no hair...head is a smooth egg shape with a tapered jaw and a visible neck` / 衣装の翻訳指示 / 正方形・図88%占有 / **`this image will be viewed at 512 pixels — omit detail that would not survive; draw boot laces as 3–4 simple crossing strokes; draw hands as simple silhouettes`**

工程提案: attacker/receiverを別マスクで管理（平坦化バケツ塗り廃止でC系指摘が工程ごと消える）/ 陰影は独立レイヤーでティントの上に乗算 / masterは正方形・alpha付きで統一。

## 6. 改善の最短順序（効果順）

1. G-1 マスク分離 → C系7件が自動解消
2. G-3 線幅3倍・3階層化 → G-4可読性が大幅改善
3. S 陰影レイヤー追加 → 前後関係が読める
4. L-6/L-3 ゴミ・重複線の清掃
5. F-1/F-2 正方形化+図を88%へ拡大

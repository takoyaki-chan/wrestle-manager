# 能力値の限界寄与レポート

計測元: task-12（`test/task12-marginal-contribution.js`）

条件: 各セル10,000試合（5,000 seedを左右入れ替えた2試合）、base seed 120042

本レポートでは、1能力だけを±10した個体が、全能力を基準値へ揃えた個体に勝つ割合を示す。「効果」は50%からの乖離の絶対量で、−10側は `50 - 勝率` とした。勝率は勝数を全10,000試合で割った値で、引き分けは勝数へ加えていない（各セル0〜6件）。

task-12で全条件の勝点率は保存されていたが、純粋な勝率は表として残っていなかった。そのため同じスクリプト・試合数・seedで再実行し、推定値ではなく勝数由来の値を整形した。

## 所見

### 1. PW / SP / TE / STは概ね拮抗

task-12適用後の上下平均寄与は、基準90で通常4.225〜4.740pt、大一番4.785〜5.565pt。通常戦ではSPが最大、PWが最小、大一番ではTEが最大、STが最小だが、いずれも1pt未満の範囲に収まる。

基準75・通常戦だけはSTが5.620pt、PWが4.480ptで1.140ptの開きがあり、STがやや上振れしている。それ以外の基準75/60では4能力の幅は0.6pt前後で、恒常的に突出・沈下する能力はない。

### 2. MNは明確に一段下

task-12適用後のMN平均寄与は、通常戦で基準90/75/60の順に2.005/2.500/2.880pt、大一番で2.610/3.090/3.345pt。対応する他4能力平均の約45〜51%である。

勝敗へ無関係ではないが、他4能力のおおむね半分という明確な差があり、「試合能力の主役4つより一段落ちる」という意図は十分に表れている。差は小さくはないため、MNを準主能力として期待する設計なら大きすぎるが、試合外効果も持つ補助能力として見る限り整合的である。

### 3. 上下は完全対称ではないが、`effPivot`由来ではない

基準90・通常戦のtask-12適用後では、+10効果と−10効果の差はPW +0.210、SP +0.100、TE +0.150、ST +0.100、MN −0.090pt。大一番ではPW −0.540、SP −0.070、TE −0.470、ST −0.150、MN +0.060ptだった。方向は能力・試合種別で揃わず、最大でも0.54ptである。

`ENG.effPivot`は100だが、`effSlopeAfterPivot`は1.0であり、実装の `eff(x)` は100以下も100超も数値的に `x` を返す。したがって基準90の+10が転換点へ着地しても、現設定には傾きの変化がなく、観測非対称をpivotの仕様効果とは説明できない。試合進行の非線形性、勝率という離散結果、有限標本による差と見るのが妥当である。

なおtask-12計測スクリプトはtask-10/task-12で異なる`configIndex`をseed導出へ含めるため、適用前後の個々の試合は厳密なペアではない。小差をすべてパラメータ変更の因果効果と解釈してはいけない。

### 4. 低い基準ほど10点の価値が大きい

task-12適用後の他4能力平均寄与は、通常戦で基準90/75/60の順に4.453/4.985/5.906pt、大一番で5.209/6.009/6.751pt。MNも同じ順に通常2.005/2.500/2.880pt、大一番2.610/3.090/3.345ptと上がる。

`eff()`自体は線形なので、これは能力値の直接変換に逓減があるためではなく、互角の高能力戦ほど1能力10点差が勝敗へ反映されにくくなる試合系全体の結果である。MNと他4能力の比率は水準が変わってもおおむね半分で、相対的な役割は安定している。

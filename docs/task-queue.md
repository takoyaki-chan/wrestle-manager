# Wrestle Manager タスクキュー

運用ルール: 上から順に1タスクずつ処理する。各タスク完了後、チェックを入れて次へ進む。 1ターミナル1タスク。並走する場合は変更ファイルが被らないことを確認してから。

## キュー（処理順）

### ① BUG-02: ティッカー表示が虚偽の情報を流す
* 対象: メニュー画面のLINE風スクロール表示（ver1）
* 症状: 実際には起きていない出来事（連勝など）が表示される
* 対処: ティッカーに流すデータの生成・フィルタリングロジックを見直し、実データと一致させる
* 完了条件: ティッカーに表示される全項目が実際のゲームデータと一致すること
* [x] 完了

### ② TASK-03: ファン希望カードのマンネリ重複回避
* 対象: ファン希望対戦カードの生成ロジック
* 現状: ファンが希望するカードがstaleness（マンネリ）の高い組み合わせと被る
* 対処: ファン希望カード生成時にstaleness値を参照し、マンネリ度の高い組み合わせを除外 or 優先度を下げる
* 完了条件: ファン希望カードにマンネリ度の高い組み合わせが出にくくなること
* [x] 完了

### ③ TASK-01: ジュニアトーナメントのシード配置改善
* 対象: ジュニアトーナメントの組み合わせ生成ロジック
* 現状: OVR上位選手が序盤で潰し合う配置になりうる
* 対処: OVR上位選手を各ブロックに分散配置（シード方式）。残り枠はランダム。完全固定にはしない
* 完了条件: OVR上位4名程度が別ブロックに分かれること。かつランダム性が残ること
* [x] 完了

### ④ BUG-01: 試合中セリフポップアップが消えない（要再現確認）
* 対象: ver2の試合中セリフポップアップ
* 症状: ポップアップが自動で消えず、決着後も試合が続行→結果が逆転する。ライバル同士で発生しやすい
* 対処: まず再現確認。過去セッションで対処済みの可能性あり → 再現しなければスキップ
* 完了条件: ライバル同士の試合を複数回実行して再現しないこと。再現する場合はポップアップの自動消去/決着判定の競合を修正
* [x] 完了（予防的修正適用: showSpタイマー管理+勝者決定時強制消去）

### ⑤ TASK-02: 今週画面のソート＆一括操作
* 対象: 今週画面の選手リスト
* 追加機能:
   * ソート: 各項目（OVR、コンディション、人気等）で選手リストを並び替え
   * 一括選択: 全選択 / 全解除 / 個別チェック
   * 一括行動プリセット: 「練習重視」「試合重視」「バランス」等を選択し、チェックした選手にまとめて適用。プロモ設定も同様に一括指定可能
* 完了条件: ソート・一括選択・プリセット適用が動作すること
* [x] 完了

### ⑥ TASK-04: 給料交渉から勝率ロジックを撤去（設計込み）
* 対象: 移籍・給料交渉ロジック
* 現状: 勝率を根拠に強気交渉してくるが、勝率が低くても強気に出るなどロジック不整合。そもそも勝率を交渉材料にすること自体が不自然
* 対処: 勝率を交渉の判断材料から外す。代替材料（OVR、人気、タイトル歴など）は実装時に設計する
* 完了条件: 交渉ダイアログ・ロジックから勝率参照が除去され、代替材料で自然な交渉が成立すること
* [x] 完了

## 共通ルール（Claude Code向け）
* 実装前に必ず計画を説明し、承認を得てから着手する
* 数値パラメータは3点根拠（基準スケール・相対比較・プレイヤー体験）を示す
* 内部は浮動小数点、表示は整数
* 完了後に game-system-roadmap.md を更新してファイルを提供する
* スクリーンショット検証・ブラウザ起動・サーバー起動は不要（ユーザーが自分でテストする）

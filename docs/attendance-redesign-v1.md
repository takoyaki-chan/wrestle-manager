## 新・集客システム設計

### 基本思想

**「なぜ客はチケットを買うか」を正直���モデル化する**

1. この選手が出るから観に行く（個人の集客力）
2. この対戦が観たいから行く（カードの魅力）
3. この団体が盛り上がってるから行く（heat）
4. 興行が充実してるから行く（カードの充実度）

### 全体構造

```
① 各試合のappeal算出
   = 個人drawPower(pop, OVR, 華, ファンサ, 王者, 勢い, 復帰, 所属年数)
   + カード魅力(OVR拮抗, rivalry, タイトル戦, ファン期待, ヒールvsベビー)
   + promoStack

② 興行全体の集客力
   = 試合appeal積み上げ（メイン重い→前座軽い）
   + 興行全体ボーナス（promo非出場分）
   × heat倍率

③ 最終集客数
   = orgPopから算出される天井 × 集客力によるコンバージョン率
```

**orgPopの役割変更**: 「ベース集客の支配的要因」→「天井（リーチ）」。
orgPopは「団体を知っている人の数」。カード内容は「その何割が実際に来るか」。
orgPop 100でもカードが悪ければ客は来ない。カード編成が常に意味を持つ。

**興行後:**
```
④ ショーレーティング算出（★1〜5）
   = MQ重み付き積み上げ + 占有率 + ファン期待実現 + タイトル名勝負 + 因縁決着 + 充実度

⑤ heat更新
   = ショーレーティングに基づいて上下
   + 大型イベント後バズ
```

### C. 興行レベル

#### C1: メインイベントの格 → ショーレーティングに統合
試合appealの重み付けで自然に処理。メイン＝最も重い。

#### C2: カードの試合数 → 試合appeal積み上げで自然に処理
- 良い試合を追加 → appeal積み上がる → 集客増
- ゴミ試合を追加 → 小さなマイナス（「組まなきゃよかった」程度）
- 平均は一切取らない。純粋な積み上げ
- **会場規模別の適正試合数**あり。少なすぎるとペナルティ
  - 公民館〜小ホール: 適正2-3試合
  - 市民会館〜中ホール: 適正3-4試合
  - 大ホール〜アリーナ: 適正4-5試合
  - 大会場〜ドーム: 適正5-6試合

#### C3: promoStack
- **出場選手のpromoStack → その試合のappealに加算**（大きい効果）
- **非出場選手のpromoStack → 興行全体に微量ボーナス**（小さい効果）

#### C5: orgPop → 天井（リーチ）
- orgPopは「潜在的な客の数」を決める
- カード内容は「その何割が来るか（コンバージョン率）」を決める
- orgPop 100でもカードが悪ければ客は来ない
- orgPop 30ではどんな神カード組んでも大会場は埋まらない

## ショーレーティング（興行採点）

### 概要
興行後に毎回算出される「この興行は成功だったか」の評価スコア。
**新聞に掲載**（★1〜5）。プレイヤーが振り返って改善できる。

### 評価要素
- **各試合のMQ（重み付き積み上げ）**: メインが最も重く、前座は軽い。平均は取らない
- **占有率**: 満員ならボーナス、ガラガラならペナルティ
- **ファン期待カード実現**: 期待に応えたらボー���ス
- **タイトル戦の名勝負**: タイトル戦のMQが高ければボーナス
- **因縁カードの決着**: ストーリーが進んだらボーナス
- **試合数の充実度**: 会場規模に対して適正かどうか

### 効果
- **ショーレーティング → heat更新**: 良い興行はheat上昇、悪い興行はheat低下
- heat＝「団体の勢い」。集客に乗算で効く（現行のHEAT_LEVELS: ×0.7〜×1.3）

### heatに統合される要素
- C4: 直近興行MQ → ショーレーティング経由でheatに反映
- C6: 大型イベント後バズ → heatに直接大きくプラス
- 旧momentum（占有率ベース） → ショーレーティングの占有率要素に吸収

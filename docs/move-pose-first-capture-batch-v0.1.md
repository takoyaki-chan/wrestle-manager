# 技ポーズ初回撮影候補台帳 v0.1

最終更新: 2026-08-09

## 1. 目的と扱い

`D:\TDCG\pose\■技` にあるポーズ名・連番を、試合エンジンの技カテゴリと照合して初回の**撮影確認候補**へ束ねた台帳である。

これは採用済みの画像リストではない。番号から攻め手／受け手／完成構図の役割を決め打ちせず、3Dカスタム少女で読み込んだ結果を人間が確認してから撮影する。撮影・加工・ゲーム実装はこの台帳だけでは開始しない。

## 2. 読み取り結果

- 投げ・極め・打撃・フォール等の主要カテゴリで、同名＋連番のセットを多数確認した。
- BWPの一部セットでは `(1)` が約6MB、後続が約5〜11KBだった。完成構図＋関連ポーズである可能性は高いが、ファイル容量は役割の証拠ではない。
- 同じ技名でも番号帯が離れているものがある。番号の近さは「同じ撮影セット候補」の絞り込みにのみ使い、採否や役割の判定には使わない。
- `ネックシザース` と `首四の字 BWP` の両方を確認した。ゲームに追加する技名・どちらを採用するかは、読み込み後の構図レビューで決める。

## 3. 初回バッチ

初回は、現在の試合エンジンにある投げ／極め／打撃／フォールの見え方を一通り検証でき、かつ連番束がある以下10件を対象にする。順番は優先順位であり、1件ずつ完了させる必要はない。

| 2 | STF | 極め・大技 | `■極め技・絞め技\\STF (1207)/(1208)/(2131)/(2132)`、BWP版 | 伏せた受け手と攻め手の分離 |

## 4. 1セットの確認手順

1. 同名・近番の候補を3Dカスタム少女で順に読み込む。
2. 2人完成構図として成立している候補を1つ選び、攻め手を画面右、受け手を画面左、攻め手は左向きに合わせる。
3. 同じカメラ・解像度・無地背景で、完成構図／攻め手のみ／受け手のみを撮影する。
4. 撮影PNGを候補プールへ保存する。ここではGPT Image加工、分離、ゲームへの登録をしない。
5. 複数の候補が溜まった段階で、人間が構図・向き・技としての読みやすさを比較する。

## 5. 現時点の制約

3Dカスタム少女（`ObsDX9.exe`）の起動は確認済みだが、CodexのWindows画面操作はOS権限エラーでウィンドウ取得・クリックができない。そのため初回のポーズ読込と撮影は人間操作が必要であり、Codexは撮影済みPNGの台帳化・加工・QAを担当する。

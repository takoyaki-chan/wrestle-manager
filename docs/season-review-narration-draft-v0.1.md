## 執筆メモ／レビューで判断してほしい点

- **`taikan_summit` と `taikan_belt` の分岐条件**：実装（`_decideHeadline`）は「rank===1 または titleWonThisSeason」で一律「戴冠」を返す。仕様表では 1位＝summit／非1位でタイトル奪取＝belt と2分岐だが、配線時にこの分岐（`rank===1` か否か）を lead キー選択側で追加する必要がある。文面はその前提で書き分けた。
- **`champion` の帯分岐と `{defenses}` 非使用**：カードに `V{defenses}` が出るため一言では数字を繰り返さない方針にした。数字を文中でも見せたい意向があれば champ_low/mid に `{defenses}` 版を追加できる。
- **`champ_low`（V1〜2）の言い回し**：「一度ならず」等の複数前提表現は V1 で破綻するため避け、防衛数に依存しない表現にした。
- **`ace` は「今季も」を使わない**：継続前提の語は旗揚げ初年度のエースで矛盾するため、単年で閉じる表現に統一した。
- **`sedaikoutai` で順位に触れていない**：3名以上離脱は順位不問（上昇年にも起こりうる）のため、順位ではなく「別れと空席」を軸にした。順位も併記したい場合は `{rank}`/`{prevRank}` を差せるが、話の焦点がぶれるため見送っている。
- **`{gap}` が 0 になる可能性**：`chase_close` は `Math.max(0, …)` で 0 pt もあり得る。「差は0点／手を伸ばせば届く」でも自然に読めることを確認済み。ほぼ拮抗の年に出る想定。
- **感嘆符**：全文で不使用（掟の「使うなら数カ所まで」に対し、年次記録の固さを優先し0にした）。もし主役文や締めで1〜2箇所だけ熱を入れたい箇所があれば指示ください。

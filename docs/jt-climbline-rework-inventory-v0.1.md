## §1 現行フローの概観

```
週25 advanceWeek
 └ App.initJuniorTournament
    ├ [summon]      召集通知(自団体出場者がいる場合のみ、1人ずつ)
    ├ [bracket]     ブラケット画面(横型SVG・左右対称) ←→ 試合ごとにループ
    │   ├ フォーカスカード(現在の試合: stand対峙+セリフ+開始HPバー)
    │   ├ [watching] battle-engine iframe 観戦(リプレイ専用) ─┐
    │   └ スキップ ──────────────────────────────────────────┤
    ├ [matchResult] 試合結果画面(pb形式、勝者HP回復アニメ) ←──┘
    ├ [finalResult] 優勝発表(ジングル+pbバナー+チャンピオンカード)
    ├ 感想戦チェーン(自団体出場者の一言、1人ずつモーダル)
    └ 終了処理(apply→新聞→BGM復帰)
```

実装: `app.js` initJuniorTournament/jtWatchMatch/jtSkipMatch/jtSkipAll/_receiveJTBattleResult(12236-12680付近) + `ui-common.js` renderJuniorTournamentSummon/Bracket/MatchResult/Result + `_jtFocusCard`/`_jtBkMatch`/`_showJTImpressionChain`(14329-14930付近)

## §3 クライムライン化の設計(置換部分)

- **構成**: 下段=準々決勝(8名/4名ブラケット両対応)、上段へ準決勝→決勝→頂上(王者)。エンブレムは画面最上部の1個のみ(`image/emblem-summer.png`)
- **動的出現**: 開幕時は下段の枠のみ。勝者確定のたびに上段へ**せり上がり出現**(フェード+上昇アニメ)。TBD枠は「存在しない」(現行のTBD表示は廃止し、枠自体が未出現)
- **画像**: 顔アイコン→**アッパー画像**(`getUpperUrl`)。勝者=夏空色リング、敗者=モノクロ落ち
- **試合情報**: 各消化済み試合に「N分N秒 / MQ nn」チップ(match.turns × 90秒)
- **回次・称号表記**: 「第{season}回 ジュニアトーナメント」(既存踏襲)、王者は「**第{season}回大会ジュニアチャンピオン**」
- **合流線**: 山型SVG、勝者ラインのみ大会色点灯。8名時の横幅が課題になったら線を短く詰める🔧
- **現在試合の示し方**: 下段の該当ペアを大会色点灯+フォーカスカードを直下に表示(既存の .act ハイライトの継承)

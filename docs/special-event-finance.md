# 5大特別大会 共通収益仕様

対象は次の5大会。

1. 春のタッグリーグ
2. U-20ジュニアトーナメント
3. 秋の4団体勝ち残り対抗戦
4. PPV GRAND FINAL
5. 4年に一度の天頂戦

## 固定興行収入

| 大会 | 固定興行収入 |
|---|---:|
| 春のタッグリーグ | 7,000万 |
| U-20ジュニアトーナメント | 7,000万 |
| 秋の4団体勝ち残り対抗戦 | 7,000万 |
| PPV GRAND FINAL | 1億1,000万 |
| 天頂戦 | 1億1,000万 |

固定興行収入は参加チーム・参加選手が増えても増額しない。30%を出場枠への均等配分、70%を延べ試合出場数による配分とする。賞金は固定興行収入とは別に従来どおり加算する。

## ブランド収入

ブランド収入は共通原資を分配せず、各出場枠について個別に計算してから団体別に合算する。

`ブランド基礎額 = (出場選手の通常興行グッズ収入 + 団体人気・大会★評価による興行放映収入) × 大会場2興行分`

`ブランド収入 = ブランド基礎額 × (1 + 順位ボーナス + 勝利ボーナス + MVPボーナス)`

| ボーナス | 加算率 |
|---|---:|
| 優勝 | +100% |
| 準優勝 | +50% |
| 準決勝敗退・3位 | +20% |
| 4位 | +15% |
| 準々決勝敗退・その他参加 | +10% |
| 1勝 | +5%（最大+25%） |
| MVP所属枠 | +15% |

同一団体から複数チーム・複数選手が出場する大会では、各出場枠のブランド収入がそれぞれ発生する。このため将来参加チーム数を倍増した場合、固定興行収入は据え置きだが、大会全体のブランド収入は追加チーム分だけ増える。

通常週に毎週発生するグッズ・メディア基礎収入は週次決算側で処理する。特別大会側は興行連動分のみを計上し、旧PPV/JT出演料や旧PPVランク別出場報酬とは重複させない。

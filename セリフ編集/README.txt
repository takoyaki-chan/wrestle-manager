■ セリフ編集フォルダ

このフォルダの Excel を編集すると、ゲーム内のセリフを差し替えられます。


● 手順（バッチをダブルクリックするだけ）

  1_エクセルに書き出し.bat
      ゲームの最新セリフを Excel に書き出します。
      ※ 編集を始める前に必ず実行してください（古いまま編集すると反映されません）

  ↓ Excel を開いて「改訂」列に新しいセリフを書く

  2_変更内容を確認.bat
      何がどう変わるかを表示します。まだゲームには反映しません。

  3_ゲームに反映.bat
      「改訂」列の内容をゲームに反映します。


● Excel の書き方

  ・「改訂」列だけに書いてください。直したい行だけでOKです。
  ・「ID(編集不可)」列は絶対に変更しないでください。反映先を特定するための鍵です。
  ・「現在」列も変更しないでください（照合に使います）。
  ・「備考」列は自由に使えます。反映時は無視されます。

  archetype（口調）と personality（性格）の列で絞り込むと、
  同じタイプのセリフをまとめて見比べられます。


● 安全のしくみ

  ・「現在」列がゲーム側と一致しない行は、反映せず警告します。
    （古い Excel で上書きしてしまう事故を防ぎます）
  ・反映前に元ファイルを .bak として控えます。
  ・反映後に自動でテストが走ります。失敗した場合は自動で元に戻します。


● 困ったとき

  ・「Node.js が見つかりません」と出る → Node.js をインストールしてください。
  ・反映されない → 1 を実行してから編集し直してください。
  ・元に戻したい → src フォルダの .bak ファイルから戻せます。

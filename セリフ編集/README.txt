■ セリフ編集フォルダ

このフォルダの Excel を編集すると、ゲーム内のセリフを差し替えられます。


● フォルダ構成(2026-07-25 改訂)

  編集は「その属性(archetype)と性格(personality)の一人を想像して、
  その人の全セリフを通しで直していく」という単位が基本です。
  そのため、以下のフォルダに分かれています。

  キャラタイプ別/
      実在する archetype×personality の組み合わせ(34組)ごとに1ファイル。
      例: 「丁寧×真面目.xlsx」「ヤンキー×強気.xlsx」
      各ファイルの1枚目シート「在籍キャラ」に該当キャラの一覧があります。
      2枚目シート「全セリフ」が編集対象です(場面をまたいで通しで並んでいます)。
      「_該当者なし.xlsx」は、現在そのタイプのキャラがいない組み合わせの
      予備セリフをまとめたものです。

  キャラ個人別/
      勝利セリフ.xlsx / プロフィール.xlsx
      「その子固有」のセリフ・紹介文(キャラ名の列つき)。

  ナレーション・記事/
      話者のいないテキスト(新聞・見出し・通知・黒田記者コラム・年代記など)。

  コーチ/
      コーチ関連のセリフ・紹介文(選手とは別人格系統)。

  その他セリフ/
      話者はいるが、archetype×personality 以外の軸で分岐するセリフ
      (派閥イベント・Glimpse Cascade など)。

  _キャラ対応表.xlsx
      どの archetype×personality に誰がいるかの一覧(マトリクス表つき)。
      迷ったらまずこれを開いて、直したいキャラのタイプを確認してください。


● 手順(バッチをダブルクリックするだけ)

  1_エクセルに書き出し.bat
      ゲームの最新セリフを Excel に書き出します(上記フォルダ構成で再生成)。
      ※ 編集を始める前に必ず実行してください(古いまま編集すると反映されません)

  ↓ Excel を開いて「改訂」列に新しいセリフを書く
  ↓ (キャラタイプ別 で一人格を選んだら、そのファイルの「全セリフ」シートを
  ↓  上から順に通しで見ていくのがおすすめです)

  2_変更内容を確認.bat
      何がどう変わるかを表示します(セリフ編集/ 配下の全ファイルを対象)。
      まだゲームには反映しません。

  3_ゲームに反映.bat
      「改訂」列の内容をゲームに反映します。


● Excel の書き方

  ・「改訂」列だけに書いてください。直したい行だけでOKです。
  ・「ID(編集不可)」列は絶対に変更しないでください。反映先を特定するための鍵です。
  ・「現在」列も変更しないでください(照合に使います)。
  ・「備考」列は自由に使えます。反映時は無視されます。
  ・ファイルをどこに動かしても(フォルダをまたいで移動しても)、
    IDだけで反映先を特定するので問題ありません。


● 安全のしくみ

  ・「現在」列がゲーム側と一致しない行は、反映せず警告します。
    (古い Excel で上書きしてしまう事故を防ぎます)
  ・反映前に元ファイルを .bak として控えます。
  ・反映後に自動でテストが走ります。失敗した場合は自動で元に戻します。


● 困ったとき

  ・「Node.js が見つかりません」と出る → Node.js をインストールしてください。
  ・反映されない → 1 を実行してから編集し直してください。
  ・元に戻したい → src フォルダの .bak ファイルから戻せます。
  ・どのファイルに何のセリフがあるか分からない → まず _キャラ対応表.xlsx を開く。

# Task 13: MQ上限の最悪ケース計測

計測日: 2026-07-20

実行: `node test/mq-ceiling-worstcase.js 20000 130042`

## 結論

**MQ上限・外部キャップは実際に結果を切り捨てている。上限撤廃が無意味という結論にはならない。**

- 現実寄りのOVR95上位カードでも、`Engine.executeShow` の+12外部キャップは20,000/20,000試合で到達し、平均2.428点（最大4点）を切り捨てた。それでも最終MQは5.320%が100を超え、最大108だった。
- 同じOVR95カードを画面経路の順序で再構成すると14.350%が100クランプに掛かり、該当試合で平均5.347点、最大14点が切り捨てられた。
- 人工最大シングルでは、headlessの外部キャップが毎試合15点を捨て、最終MQは13.445%が100超、最大112。画面経路は35.570%が100クランプに掛かった。
- タッグはエンジン内部の100クランプが2.855%で発動し、該当時平均3.465点、最大16点を切り捨てた。その後headless経路が会場+6・ラストラン+5を加えるため、最終MQは23.665%が100を超え、最大111になった。

したがって問題は「100に届くか」ではなく、**同じ高品質試合でも、画面経路は100へ丸め、headless経路は外部加算後に100を超え、タッグは素点だけ100へ丸めた後に再び超える**という経路不一致にある。

## 構成

各構成20,000 seed。全試合を実際の `Engine.executeShow` に通し、その同じ結果・寄与情報を `App._finalizeShowImpl` の加算順序へ非接続で再投入した。後者はDOM/UIそのものを実行した値ではない。

### 現実寄り上位シングル

- 両者の全能力95（avgOV 95）、全快、高人気
- 「名勝負製造機」「引き出し上手」
- 団体王座+5、通常因縁最大+5
- 最上位会場・高人気8試合カード。通常範囲の勢い補正を使用し、会場/観客MQは実測+3〜+6
- 初対戦（画面経路のみ鮮度+2）
- マイルストーン、ラストランは積まない

能力を一律95にした点は上位ケース抽出用の人工化だが、加算要素自体は通常プレイで組み合わせ可能である。

### 人工最大シングル

- 両者の全能力100（avgOV 100）、全快、高人気、上記2特性
- 団体王座+5、通常因縁最大+5
- ドーム超満員+6。テスト用stateの集客勢いを十分高くし、実際の集客計算結果を会場定員へクランプさせて固定
- 全試合MQバフ+3、指定ペア次戦MQ+3
- ラストラン選手のメインイベント+5
- 初対戦（画面経路のみ鮮度+2）

headlessの正方向外部補正は合計27点。画面経路にはマイルストーン2種、ラストラン、+12外部キャップがなく、代わりに鮮度+2があるため、適用される外部補正は18点。

### 好敵手・宿怨

人工最大と同じOVR100・王座・超満員・初対戦条件から、通常因縁・マイルストーン・ラストランを外し、解決済み好敵手または宿怨を設定した。両者ともMQ寄与は+2で、同一seedでは全結果が一致した。

### 人工最大タッグ

- 4人の全能力100、全快、高人気。「名勝負製造機」あり
- ドーム超満員+6
- ラストラン選手のメインイベント+5
- タッグ経路では王座、因縁、マイルストーン、+12外部キャップ、鮮度は適用されない

## 観測最大ケース

### シングル

人工最大構成では、Climax決着かつドラマ・ペーシング・決着減点がすべて0の試合を観測した。

- エンジン素点: `100 - 0 - 0 - 0 = 100`
- headless無制限: `100 + 因縁5 + 王座5 + 会場6 + MQバフ3 + 次戦3 + ラストラン5 = 127`
- headless実値: 外部27を+12へ切り、`100 + 12 = 112`
- 画面無制限: `100 + 因縁5 + 王座5 + 会場6 + 鮮度2 = 118`
- 画面実値: 各段階の100クランプにより100（18点消失）

### タッグ

観測最大の内部素点は、Climax決着で `100 - drama 0 - pacing 10 - finish 0 + tagBonus 26 - tagPenalty 0 = 116`。

- タッグエンジンが116を100へクランプし、16点消失
- headlessは会場6・ラストラン5を加えて111。全上限なしなら127
- 画面経路は会場6だけを加えて再び100へクランプ。全上限なしなら122

## プレイヤーが到達できるか

人工最大の「全能力100・2種マイルストーン・ラストラン・強制超満員」の同時成立は意図的な最悪ケースで、通常セーブでは非常に稀である。

一方、マイルストーンとラストランを外したOVR95カードでも、王座+5・最大通常因縁+5・最上位会場+3〜6だけで+12外部キャップへ100%到達し、実最終>100と画面100クランプの両方を観測した。全能力一律95という作り方自体は統制用だが、平均OVR95級の王座因縁戦、初対戦、上位会場という材料はプレイヤーが組みうる。したがって、**人工的に全要素を積まなければ上限へ届かない、とは言えない**。

実セーブ全体での発生率は高OVRカードの頻度に左右されるため、本計測の割合を通常興行全体へ外挿してはいけない。しかし上限・capが到達可能で、上位カードの値を実際に圧縮することは確定した。
